# 공통 스킬 진입

먼저 [공통 SKILL.md 정본](../../../.agents/skills/mirror-app-ui-readability/SKILL.md)을 읽고 그 절차를 적용한다. 이 파일은 발견용 진입이며 별도 작업 규칙을 복제하지 않는다. 정본 안의 상대 경로는 정본이 있는 폴더를 기준으로 해석한다.

대상 checkout의 AGENTS와 현재 요청·판본·실행 소유를 먼저 확인한다. 정본 경로가 없으면 필요한 공유 코드·문서를 확인하고, 다른 절차를 추측해 실행하지 않는다. 이 연결만으로 작업 배정이나 제품·운영·Editor 실행권을 만들지 않는다.
