# Hongdal Preview Site

Hongdal의 제품 방향을 로그인이나 API 서버 없이 둘러보는 읽기 전용 체험 사이트입니다.

체험의 시작점은 역할별 업무 메뉴가 아니라 생활 게시판과 글쓰기입니다. 사용자는 일반 글을 읽다가 판매·공동구매 같은 구조화 정보를 붙여 보고, 이후 주문자·해외 공급자·화주·운송 기사·창고 관리자 관점의 화면으로 이동할 수 있습니다.

공개 체험은 다음 흐름을 화면으로 전달합니다.

1. 게시판에서 생활 이야기, 질문, 판매와 공동구매 글을 가볍게 탐색합니다.
2. 글쓰기에서 상품, 수량, 가격 같은 업무 정보를 필요할 때만 추가합니다.
3. 참여 의사가 모이면 가원장과 필요한 역할을 확인한다는 제품 방향을 보여 줍니다.
4. 역할별 화면에서 당사자가 합의한 뒤 이어질 주문·운송·창고 업무를 살펴봅니다.

체험 사이트는 주문, 배차, 계약, 결제, 알림과 데이터 변경을 실행하지 않습니다. 특정 운송사·전문가·거래 상대를 추천하거나 배정하는 운영 서비스도 아닙니다.

공개 주소: <https://hongdal-role-preview.cheolwo.chatgpt.site/>

`scripts/build.ps1`은 `src`와 Cloudflare Worker 진입점을 Sites 배포 형식인 `dist`로 조립합니다. 공개 경로는 모두 클라이언트 라우팅과 Worker의 HTML fallback을 함께 사용합니다.
