# Windows 음식 배차 경영 체험 · Claude 작업본

`tools/Ssalddel.BatchMonitor.Windows`(원본)를 복사해 아래 세 기능을 더한 별도 작업본이다. 원본 폴더와 `Ssalddel.Sagajeong.Core`는 수정하지 않았다. 원본 안내는 [README-원본.md](README-원본.md)에 그대로 있다.

| 추가 기능 | 근거 기획 | 화면 위치 |
| --- | --- | --- |
| 기사 무념·경 시간·등급·개인 타로 | r124 · r125 · r126 | 경영 체험 왼쪽 아래 **지사 기사 · 무념과 경 시간** |
| 결산의 경 시간당 순소득 | r133 | 회차 결산 아래 **무념·경 시간 결산** |
| 생산·소비 병목 비교 | r134 | 경영 체험 위쪽 **생산·소비 흐름 · 이번 회차** |

## 실행

```powershell
cd C:\Users\user\source\repos\Hongdal
dotnet run --project tools/Ssalddel.BatchMonitor.Windows.Claude.Checks      # 규칙 점검
dotnet run --project tools/Ssalddel.BatchMonitor.Windows.Claude             # 앱 실행
```

창 제목에 **Claude 작업본**이 붙는다. 상단 **경영 체험**을 누르면 스테이지 선택 화면에서 바로 기사 카드와 흐름 패널이 보인다.

저장 위치는 원본과 섞이지 않도록 `%LOCALAPPDATA%\Ssalddel\BatchMonitor.Claude\`를 쓴다.

- `food-campaign-v1.json`: 스테이지 진행. 원본의 해금 기록은 이어받지 않는다.
- `rider-mind-v1.json`: 기사별 무념 기록. 지우면 처음 상태로 돌아간다.

## 규칙 요약

### 기사 무념과 경 시간 (r124·r125·r126)

- 기사마다 시작 등급과 유지 가능 시간이 고정돼 있다. 신사 6분, 문사 8분, 학사 10분이다.
  - 중랑 A는 신사, 중랑 B는 문사, 광진 A는 학사로 시작한다.
- **경 시간**은 업무(출발 → 전달) 동안 가상 시계로 줄어든다. 매장에서 음식 준비를 기다리는 시간도 업무에 들어간다. 배차 대기와 휴식 중에는 줄지 않는다.
- 남은 경 시간을 넘어서는 순간 무념이 깨진다.
  - 개인 타로가 **역방향**으로 바뀌고 "무념 상태가 깨졌습니다"가 표시된다.
  - 회차 사건에도 기록된다.
  - 진행 중인 배달은 끝까지 마치지만, 새 배차는 막힌다.
- 배차 후보마다 **예상 업무 + 여유 1분**을 남은 경 시간과 비교해 충분·부족을 보여준다.
  - 부족해도 배정은 할 수 있다(r125: 권고).
- 같은 기사의 경 시간은 회차가 바뀌어도 이어진다. 그래서 같은 기사를 계속 쓰면 다음 회차에서 부족해진다.
- **휴식·점검 · 근무 마감**은 회차가 끝난 뒤 누를 수 있다.
  - 경 시간이 가득 차고, 무념이 회복되고, 타로는 정방향으로 돌아간다.
  - 배달 1건 이상을 정산하고 무념을 지킨 근무는 **유효 근무**가 된다. 다음 근무의 유지 가능 시간이 +1분 늘어난다.
  - 다음 등급 기준(문사 8분, 학사 10분) 이상을 유지한 유효 근무가 두 번 쌓이면 한 단계 승급한다.
  - 양사부터의 기준은 기획이 미정이라 2분 간격 **임시값**이다.
- 등급 색은 r126 오토바이 색 배정을 따른다.
  - 기사 카드의 원에만 적용했고, 지도 오토바이 색은 아직 바꾸지 않았다.
- 개인 타로 슬롯의 장착 카드는 기획 미정이라, 경영 타로 4장 중 하나를 기사별로 시안용으로 고정했다. 카드의 수치 효과는 없다.

### 경 시간당 순소득 (r133)

- 주문 하나의 보수 중 무념 유지 구간의 비율만큼을 **경 구간 연결 소득**으로 본다.
- 경 시간당 순소득 = 연결 소득 ÷ 경 유지 시간
- 비용 범위가 아직 없어서 순소득은 가상 기사 보수와 같다.
- 회차가 짧아 시간당 값이 크게 나온다. 예: 2분 24초에 3,600원이면 시간당 90,000원.

### 생산·소비 흐름 (r134)

- 현재 엔진 기준으로 지역별 세 가지를 비교한다.
  - **주문**: 이번 회차 주문 수
  - **준비**: 매장 수. 매장마다 회차당 1건
  - **배송**: 무념을 유지하고, 경 시간이 대표 업무 2분 30초 + 여유 1분 이상 남은 기사. 이미 배정된 기사도 포함
- 셋 중 최소가 **완료 상한**이다.
- 배송이나 준비가 주문보다 적은 지역이 있으면 주황색으로 **먼저 볼 곳**을 알려준다.
