## 생성과 검증

PDF 스킬의 작업 시작 hook을 한 번 실행한 뒤 번들 Python의 ReportLab과 Windows 맑은 고딕으로 생성했다. PDF는 Poppler로 6쪽 전체를 PNG로 렌더해 확인했고 페이지 수·텍스트·원문 링크도 검사했다. HTML은 설치 Chrome의 격리 headless 브라우저에서 390/1280px 가로 넘침·스크립트 오류·6개 절·8개 원문 링크를 검사했다. 실제 기관 신청·앱/DB/Unity·운영 실행은 이 문서 작업에서 하지 않았다.

최종 검증과 산출물 해시는 `artifacts/local/cargo-info-publication-r2/legal/final-validation.json`, 렌더는 같은 폴더의 `page-1.png`부터 `page-6.png`에 있다. 스크립트는 hook을 자동 반복하지 않으며 동일 작업의 문구/배치 수정 뒤 재생성에도 같은 내용 원본을 사용한다.
