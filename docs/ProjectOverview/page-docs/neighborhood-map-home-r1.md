# 공통 생활 지도 홈 r1

2026-10-05. 사용자가 승인한 지도 중심 생활 교류 계획의 구현 책임 카드다.

## 페이지 책임

| 항목 | 기록 |
| --- | --- |
| 주 사용자·페이지/소스 | 일반 이용자, `/community/map`, Web와 SsalddelApp Android의 공통 생활 진입 |
| 대상·진입 문맥 | 공개 동네·제공/필요 글, 로그인한 본인의 진행 중인 생활 배송, 선택 동네·표시 항목 |
| 한 문장 목적 | 이용자가 지도 또는 목록에서 동네의 제공·필요 물품과 본인 배송 진행을 찾아 선택한다. |
| 완료 결과·상태별 주 행동 | 동네/물품/배송 선택 후 해당 상세로 이동. 물품 등록은 독립 작성 화면으로 인계하며 지도 선택만으로 저장·배차하지 않음. |
| 기본 정보 | 지도/목록 전환, 동네 선택, 표시 항목, 등록 진입, 선택 대상의 간결한 상태·다음 행동 |
| 보조 정보 | 공개자료 레이어는 선택 시 표시. 경로 출처·차량 기준·조회 시각, 최근 위치의 확인 시각 |
| 독립 업무·제외 정보 | 물품 작성·로그인·배송 접수·정보 제공 동의·전달 확인은 기존 독립 route에 둔다. 공개 지도에는 배송 주소·연락처·기사 GPS 없음. |
| 진입·실패·복귀 | 명시 진입 옵션 → 기기 저장 설정 → 지도/제공/필요/본인 진행 배송 기본값. loading/empty/error/retry/지도 실패 시 목록. 레이어 토글은 viewport 유지. 작성 복귀 시 동네 보존. |
| 코드·API·DB | 공통 Page/VM → 공개 지역/교류 Client 및 본인 배송 Client → 권한 검사 UseCase → 글의 optional 동네 코드/운송 원장·배정 이벤트. renderer와 설정 저장은 platform adapter. |
| 책임 판정·검증 | 같은 목적의 탐색 구성. 작성·업무 수행과 분리. 현재 구현 및 시험/실제 Web/Android 지도 실행 증거는 변경 기록에 별도로 기록. |

## 변경 전후 정보 배치

| 정보 또는 행동 | 필요한 이유 | 변경 후 위치 | 근거 |
| --- | --- | --- | --- |
| 제공/필요 글 | 동네 교류 대상 탐색 | 동네 단위 지도 집계와 목록 | 사용자 승인 |
| 개인 배송 | 본인 물품의 진행 확인 | 로그인한 본인에게만 선택 배송 패널 | 기존 본인 조회·개인정보 경계 |
| 등록 | 독립 입력·저장 | 기존 작성 페이지 | 페이지 단일 책임 기준 |
| 표시 설정 | 원하는 정보만 탐색 | 작은 레이어 선택 영역, 기기별 기억 | 사용자 승인 |
| 정확 위치·이력 | 배송 업무에 필요한 개인정보 | 권한 있는 본인 배송 지도만; 실제 trace는 후속 | 공개 위치는 동네만, 예정 경로·최근 위치 승인 |

## 첫 구현 기본값

- Web와 Android를 구현하며 기존 전문 역할 앱 및 세계 공개자료 지도는 보존한다.
- 검증된 공식 동네 코드/대표점만 공개한다. 지역 없는 기존 글은 목록에 유지한다.
- 정확 주소·기사 위치·전체 이동 이력·인증 값을 기기 설정에 저장하지 않는다.
- 최근 기사 위치는 현재 배정 이후 측정·수신 모두 10분 이내이고 미래 시각이 아닌 경우만 제공한다. 종료·계정 변경·재배정 시 제거한다.
- 실제 지도 타일 준비, 인증 오류, 앱 빌드, APK, 단말 실행은 서로 다른 검증 사실이다.
