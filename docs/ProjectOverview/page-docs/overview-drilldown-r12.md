# 운영 요약·세부 조회와 목록 복귀 r12 첫 구현

기준은 [승인 계획](../../AI/Planning/공통/PLAN-OPERATIONS-DISPATCH-CORE/platform-overview-drilldown.r12.md), [단일 책임 원칙](../../Architecture/WholeRoadmapPagePrinciple.md), [역할 앱 시각 기준](../../Architecture/RoleAppVisualDesignStandard.md)이다.

| 대상 | 한 문장 책임 | 기본 정보·주 행동 | 경계·복귀 |
| --- | --- | --- | --- |
| 공통 홈의 화물 참여 요약 | 전체 누적 참여의 범위를 보고 세부 집계를 선택한다 | 기존 누적 숫자·기준 시각, 세부 조회 진입 | 개인별 원장·미확정 금액을 공개하지 않으며 기존 역할 진입 유지 |
| 공개 참여 세부 화면 | 화물 완료 기록의 전체 누적과 월별 근거 집계를 확인한다 | 같은 기준의 누적·한국 시각 기준 월별 집계·고정 크기 페이지·짧은 집계 기준 | 월별 계정 수를 더해 전체 계정으로 표시하지 않음. 개인 식별자 없음. 홈/내 업무 진입으로 명시적 이동 |
| 관리자 운송 목록·상세·하위 전문 화면 | 선택한 분야/목록에서 운송을 확인하고 원래 목록으로 돌아간다 | 기존 분야·상태·이벤트 조건과 허용된 세부 행동 | 기존 관리자 권한·명령 유지. 분야를 증명할 수 없는 기록을 임의 분류하지 않음. 원래 필터·경로 복귀 |
| 관리자 지원 목록·상세 | 선택 종류·페이지의 사건을 확인하고 같은 목록으로 돌아간다 | 기존 사건 목록·선택 상세·담당 행동 | 종류·페이지와 안전한 내부 복귀 보존. 비공개 증거는 명시적으로 열 때만 기존 감사 조회 |
| 모바일 커뮤니티 글 상세 | 기존 내부 행동 뒤 원래 게시판 목록 문맥으로 돌아간다 | 기존 글 내용·행동 | 기존 ListReturnPath 전달의 웹/모바일 호환만 보완 |

전체 누적·월별·현재 상태를 구분한다. 조회 실패·미집계·실제0을 구분하고 과거 숫자를 최신 성공으로 표시하지 않는다. 로그인 성공이 업무 명령을 실행하지 않으며 업무/권한은 서버가 다시 검증한다. 내부 복귀 경로 검사·현재 요청 취소·오래된 응답 무시는 기존 구현을 재사용한다.

공통 UI·서버 시험과 소비 앱 빌드, 실제 브라우저의 요약→세부·페이지·복귀·오류를 확인한다. APK·물리 기기·실제 운영 검증은 수행한 범위만 별도로 보고한다. 기존 원장·DB 스키마·운영 권한·실제 지급·후원 수납은 변경하지 않는다.
