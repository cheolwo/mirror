## 왜 필요한가

사용자가 홈 테마의 창작자, 사용 위치, 가격, 패키지 버전, 8개 슬롯과 실제 적용 모습을 확인한 뒤 구매 또는 전체 적용을 선택하게 한다.

## 사용자와 화면 책임

홈 테마는 펼친 패널·접힌 손잡이·밝은 배경·어두운 배경을 전환해 미리 본다. 무료 또는 보유 상품은 8개 슬롯을 한 번에 적용하고, 유료 미보유 상품은 결제 페이지로 보낸다. 괘상과 노드 상품은 기존처럼 개별 자산을 선택한다.

## 권리·접근성 점검

크리에이터 상품은 검수 상태와 사용권을 확인해야 한다. 이미지가 표시되지 않거나 사용자가 꾸미기를 끈 경우에도 기호, 대체 텍스트, 기본 업무 아이콘으로 기능을 유지한다.
