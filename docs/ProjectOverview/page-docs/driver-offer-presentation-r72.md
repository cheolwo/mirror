# 기사 추천 배차 표시 책임 r72

## 페이지 책임 카드

| 항목 | 기준 |
| --- | --- |
| 사용자·질문 | 현재 제안은 어떤 일이며, 내가 어디까지 맡고 얼마를 받을 예정인가? |
| 기존 진입 | DriverApp 추천 목록/상세·신규 제안 배너, FDriverApp 지도 상단 최신 제안 배너·추천 목록 |
| 완료 결과 | 서버가 제시한 업무·작업 범위·지급 예정액을 확인하고 기존 명시적 수락 또는 복귀로 이어진다. 배너를 읽는 것만으로 수락하지 않는다. |
| 기본 정보 | 음식/물품·화물/창고/복합 업무 이름과 단색 아이콘·색 막대, 실제 맡을 작업, 지급 예정 합계. 색만으로 의미를 전달하지 않는다. |
| 상세 정보 | 직선거리 기준 거리비, 기본/최소 지급액, 작업비·할증의 확인된 근거. 기존 주행거리와 요금 기준 직선거리는 별도다. |
| 색 | 음식 #2563EB, 물품·화물 #DC2626, 창고/미확인 #64748B. 직접 피킹·포장·출고와 배송을 실제 함께 맡는 제안은 파랑·빨강 두 막대다. |
| 분류 근거 | 서버의 업무 유형과 실제 배정 작업 목록. 개인이 여러 업무를 허용한 설정, 창고 선행 bool, 다른 작업자의 포장 이력으로 복합을 추정하지 않는다. |
| 여러 알림 | 배너의 색과 작업 이름은 열리는 최신 제안 한 개의 값이다. 미확인 알림 총건수를 조합해 복합 배차로 표시하지 않는다. |
| 독립 업무 | 업무 선호 설정·정산·운행 종료는 기존 진입을 사용한다. 새 창고 단독 배차나 통합 추천함을 이 화면 변경으로 생성하지 않는다. |
| 실패·복귀 | 조회/수락 오류·만료·불확실 응답 재조회는 기존 흐름을 유지한다. 요금 근거 누락은 0원으로 대체하지 않고 미확인으로 표시한다. |
| 코드와 원장 | 기존 전문 제안 API → 선택적 AssignedActivities/Pricing → 공통 DriverOffers 표시 해석기 → native/Razor. 권한·금액 산정·수락은 서버 전문 원장/정책이 소유한다. |
| 검증 경계 | 순수 표시·Razor 렌더·소비 앱 빌드, 브라우저 공통 표시와 실제 네이티브 단말을 구분해 변경 기록에 기록한다. |

현재 구현·검증 수준은 [r72 변경 기록](../../Changes/2026-10-15-straight-line-driver-pricing-r72.md)을 따른다.
