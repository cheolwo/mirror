# 역할별 페이지와 통합 판단표

기존 앱을 다듬기 위한 개발 검토 색인입니다. [검색·필터 보기](role-pages.html), [원본 소스·호스트 목록](current-pages.md), [첫 모바일 검증 결과](mobile-polish-r1.md).

Razor 466개 + 네이티브 ContentPage 15개. 소스는 전체에서 한 번만 세며 역할 문맥은 중복 참조할 수 있습니다.

역할 분류와 유지·통합 판단, 실제 Android 검증은 서로 다른 상태입니다. 미검토는 불필요를 뜻하지 않으며 후속 버전 페이지를 자동 폐기하지 않습니다.
