## 검증 경계

신규 독립 native 화면이며 기존 음식 지도·정산 UI를 대체하지 않는다. 카메라 없이 코드 직접 입력으로 검증하며 실제 프린터·단말·실운영 성공을 의미하지 않는다. 화면은 구현 검토용이며 확정 UI 시안이 아니다.
