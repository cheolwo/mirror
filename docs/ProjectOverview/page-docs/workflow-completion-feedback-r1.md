# 기사·현장 단계 완료 안내

## 페이지 책임 카드

- 사용자·질문: 기사와 현장 작업자가 방금 실행한 픽업·상하차·피킹·적재·전달이 저장됐는가?
- 결과: 기존 명령 응답과 같은 대상의 정본 재조회로 확인된 단계만 완료 안내로 보여준다.
- 기본 정보: 완료한 단계, 확인한 결과, 다음 업무 안내. 고객 정보·금액·내부 요청번호는 새 알림 기록에 복제하지 않는다.
- 주 행동: `확인`으로 안내를 닫는다. 보조 행동은 기존 업무 화면으로 이동하며 다음 단계 명령을 실행하지 않는다.
- 실패·복귀: 기존 미확정 결과 보호·권한·재조회 경로를 유지한다. 최초 과거 완료 조회만으로 새 완료창을 띄우지 않는다.
- 독립 업무: 추천 알림, OS 알림, 수령 확인, 정산과 입금은 별도다.
- 표시 선택: 현재 화면 수명에서 단계마다 창 / 짧은 안내 / 최종 전달만 창. 계정 전역 설정 저장을 주장하지 않는다.
- 구현·검증: [변경 기록](../../Changes/2026-10-23-workflow-completion-feedback-r1.md). 실제 업무·단말·서버·시험 수준은 그 기록에 구분한다.
