# 생활 배송 가정 수행처 비교와 결과 확인 r28

## 페이지 책임

생활 이용자가 기존 배송 작성 화면에서 물품과 인계 조건을 입력하고 허용할 수행처·비용 상한·정보 제공 범위를 확인한다. 기본 정보는 물품·선택적 포장 크기·픽업/전달 조건·견적·동의다. 가정 수행처와 검증용 요금·시간은 같은 비용 영역에 모의로 표시한다.

기존 배송 상세는 현재 접수·배정·픽업·전달과 허용된 취소·결과 확인만 표시한다. 생활 약속의 양측 완료 확인·기록 공개와 실지급은 별도 행동이다. 정확한 인계 장소·연락처를 공개 지도나 캡처에 넣지 않는다.

첫 조회 오류·빈 후보·조건 미충족·응답 유실·취소 미확정은 성공이나 0원으로 표시하지 않는다. 입력과 원 요청 번호를 보존하고 같은 실행을 확인하며, 기존 지도·목록·약속으로 복귀한다. 별도 홈이나 새 역할 앱은 만들지 않는다.

기준은 [승인 r28](../../AI/Planning/공통/PLAN-OPERATIONS-NEIGHBORHOOD-MICRO-HUB/assumed-providers.implementation.r28.md)이다. 실제 공통 UI 320/390px 렌더와 시험 결과는 구현 반환에 연결하며 이 책임 카드를 실행 증거로 취급하지 않는다.

## 구현 반환

서버 목록만 표시하고 포장 크기 변경 시 견적·정보 제공/자동 접수 확인을 무효화한다. 빈 후보·불명 결과·기능 중지·로그아웃 상태를 유지한다. 실제 공통 컴포넌트 11상태×320/390px 22장면과 변경/원 결과 확인 4흐름을 [검증 기록과 샘플 PNG](../../Changes/2026-10-07-assumed-fulfillment-r28.md)에 연결했다. 합성 서비스이며 확정 시안·Figma 동기화·실제 서버 업무·Android/휴대폰의 증거는 아니다.
