# 누적 참여 현황 홈 r10

| 책임 | 기준 |
| --- | --- |
| 사용자·진입 | 통합앱 `/`, 웹 `/`와 `/apps`의 공통 홈 |
| 한 문장 목적 | 누적 참여와 이익 공유의 확인 가능한 현황을 보고 자신의 업무로 이동한다. |
| 상단 정보 | 플랫폼 확정 이익·분배 지급액의 집계 여부, 화물 완료 기록과 확인된 참여 계정 수, 전체 누적·기준 시각·시험 여부 |
| 독립 책임 | 금액/참여 집계는 서버 읽기 전용 투영, 조회는 client, 요약은 표시 component, 역할 선택은 기존 카탈로그가 소유한다. |
| 주 행동 | 기존 화물3·음식4·생활·창고 진입. 조회 중·실패에도 즉시 사용할 수 있다. |
| 미집계·0·오류 | 확정 근거 없음은 미집계, 조회한 실제 0은 0, 통신 실패는 확인 불가와 재시도. 실패를 0이나 모의 자료로 치환하지 않는다. |
| 의미 경계 | 계정 역할별 중복 가능. 기사 하차 완료 기록은 화주 수령·정산·지급과 별개. 실행 모드는 개별 기록의 실제 운영 감사 증거가 아니다. |
| 보조 정보 | 하단의 기존 거래·개인정보 고지와 서비스 안내 링크 |
| 제외 | 개인 정보·운송 번호·좌표·수행 명령·관리자 원본 응답·가상 이익·수익 배분 알고리즘 변경 |
| 검증 | 집계 필터와 정보 최소화, 실패 시 진입, 공통 client 빌드, 좁은/넓은 실제 렌더·스크린샷 |

사용자 요청으로 [r9](business-role-bundles-r9.md)의 역할 선택 우선 구성을 갱신한다. 기존 r9 결과·권한·업무별 원장 책임은 보존한다. 시각 기준은 [역할 앱 기준](../../Architecture/RoleAppVisualDesignStandard.md)을 따른다. 무채색 아이콘과 공통 토큰을 사용한다.
