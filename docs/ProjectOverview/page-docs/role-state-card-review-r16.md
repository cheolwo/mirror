# 역할별·업무 상태별 카드 검토표 r16

[OS 생명주기와 실제 상태의 추가 대조](os-state-card-audit-r17.md)에서 현재 준비 회차·배차·픽업 이후·검수·예외 조회의 결손을 확인했다. 아래 표와 화면은 기본 구성 검토용이며 모든 복합 상태의 정합성이나 실제 서버 전이를 검증한 결과로 사용하지 않는다.

| 구분 | 내용 |
| --- | --- |
| 기준일·용도 | 2026-10-05. 실제 제품 adapter의 기본 카드와 기존 상태 분기를 대조한 사용자 후속 검토용 기본 초안이다. |
| 확정 범위 | r16에서 기존 정보의 기본 표시와 위치 갱신을 보완했다. 아래 모든 상태의 정보 구성·강조 순서·업무 정책을 최종 승인받았다는 뜻은 아니다. |
| 표 읽는 방법 | 기본 정보는 접힌 카드의 제목·상태·Summary·주행동을 뜻한다. 보조 행동과 같은 대상의 기존 섹션은 상세에서 펼친다. 행동은 서버가 허용한 경우에만 실행하며, 수량·사유·증빙 입력은 기존 독립 화면에서 처리한다. |
| 후속 결정 | 마지막 열은 사용자가 화면을 보고 판단할 구성 항목이다. 새로운 업무 규칙이나 자동 처리로 적용하지 않는다. |
| 공통 기준 | [역할별 페이지 책임](role-map-workspace-r11.md), [페이지 원칙](../../Architecture/WholeRoadmapPagePrinciple.md), [시각 기준](../../Architecture/RoleAppVisualDesignStandard.md)을 따른다. |
| 증거 상태 | 실제 공통 웹 UI의 일곱 역할 기본 카드와 320/390px 화면을 확인했다. 주문자 위치 만료·목록 전환, 음식점 상세·재조리, 운영자 지도 자료 실패, 화물·창고 다음 현재 업무 예시를 확인했다. 표의 모든 세부 상태를 브라우저에서 확인하거나 최종 승인한 것은 아니다. 실제 서버·GPS·휴대폰·Azure 실행 증거와 구분한다. |

## 공통 상태

| 대표 상태 | 기본으로 보이는 정보 | 상세 정보 | 주행동 | 사용자가 후속 결정할 사항 |
| --- | --- | --- | --- | --- |
| 정상 조회·대상 선택 | 대상 제목·진행 상태, 역할별 목적지와 핵심 항목, 가능한 행동 | 같은 대상의 기존 정보 섹션과 긴 설명 | 역할·계정·현재 대상에 허용된 행동 | 핵심 항목의 순서와 강조, 기본 카드 길이 |
| 업무 목록 / 상세 없는 카드 | 업무 목록은 제목·상태로 표시. 상세 없는 카드에서는 목록 API 정보만 사용하며, 주문자는 진행·조리 예정·금액·선택 안내, 운영자는 주문 상태·담당 확인 필요 등이 표시될 수 있음 | 선택 후 별도 상세 조회에서 확인되는 항목 | 상세가 필요한 행동은 선택·조회 후 확인 | 목록과 상세 카드 차이를 이해하기 쉬운 표시 |
| 자료 없음·업무 없음 | 빈 목록 또는 현재 처리할 업무가 없다는 안내. 값이 빠진 항목은 미확인·미확정 등 기존 표현 | 조회되지 않은 상세를 만들지 않음 | 기존 새 주문·의뢰 등록·운행 설정 또는 재조회가 해당 역할에 있는 경우 사용 | 빈 화면에서 필요한 안내와 진입 행동의 우선순위 |
| 조회 중·조회 실패 | 불러오기·실패·재조회 안내. 실패를 업무 없음이나 완료로 바꾸지 않음 | 성공적으로 받은 현재 대상의 정보만 사용 | 재조회. 처리 결과 확인 대기는 해당 입력 화면의 기존 확인 흐름 | 기존 정보를 남길 때의 실패 안내 위치 |
| 지도 사용 불가·좌표 없음 | 카드와 목록으로 대상·주소·상태 확인, 지도 안내 | 주소·위치 확인 안내와 기존 업무 상세 | 목록 보기·지도 재시도, 기존 업무 행동 | 지도 없이 일할 때 주소와 목록의 배치 |
| 위치 만료·시각 이상 | 만료된 기사 위치와 연결된 만료 경로 제거. 주문자는 위치 기록·조회 시각과 지연 안내, 화주는 위치 최신성 안내 | 기존 위치 안내와 업무 진행 정보 | 제한된 재조회 또는 기존 상태 확인 | 지연 안내의 눈에 띄는 정도, 시각 표시 형식 |
| 권한 만료·계정 또는 역할 변경 | 로그인·접근 안내. 이전 계정의 비공개 정보·위치·늦은 응답 정리 | 새 권한을 확인한 대상만 조회 | 기존 인증·권한 확인 | 접근 안내 문구와 복귀 동선 |
| 화면 이탈·복귀 | 표시 중인 역할만 제한적으로 재조회하는 소스 흐름. 복귀한 대상과 현재 정보를 확인 | 독립 입력 화면에서 돌아온 같은 대상의 상세 | 역할별 기존 행동 | 선택·접기·지도 위치의 복귀 방식 |

공통 표시 근거: [공유 화면](../../../Ssalddel.Ui.Common/Areas/App/RoleWorkspace/Core/RoleMapWorkspace.razor), [공유 ViewModel](../../../Ssalddel.Ui.Common/Areas/App/RoleWorkspace/Core/RoleWorkspaceViewModel.cs). 지도 카메라 중심은 관측 GPS가 아니다. 예시 웹에서 재조회와 시간 경과 후 만료 핀 제거를 확인했으며, 실제 기기 수신과 서버 업무는 별도 확인한다.

| 추적 상세 미선택·미확인 / 자료 없음 | 목록 주문 상태·담당 확인 필요·상세 확인 필요 또는 빈 목록 | 선택 후 허용된 추적 상세 | 대상 선택·조회 | 목록에서 우선 확인할 운영 항목 |

근거: [운영자 adapter](../../../Ssalddel.Ui.Common/Areas/App/RoleWorkspace/Food/OperatorRoleWorkspaceAdapter.cs). 관리 원장과 추적 조회가 기준이다. 선택적 지도 조회의 일반 장애만 카드와 분리하며 401·403이나 사용자의 조회 취소를 통과시키지 않는다. 지도는 `Source == "actual"` 자료만 사용한다. 음식점·운영자의 명시적 선택은 유지한다.
