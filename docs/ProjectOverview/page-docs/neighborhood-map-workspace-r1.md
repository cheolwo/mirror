# 생활 지도 작업공간 r1

2026-10-05. 구현 전 책임 카드. 승인 범위는 일반용 Android, 통합 Web, 독립 01 Community Web이다.

| 항목 | 책임 |
| --- | --- |
| 주 사용자·진입 | 일반 이용자, `/community/map`. 기존 글·협업·공간·배송 route도 유지한다. |
| 목적·결과 | 동네의 제공·필요·보관 정보를 고르고, 선택한 대상과 현재 할 일을 지도 옆/아래에서 확인하고 처리한다. |
| 기본 정보 | 주변 보기 / 내 할 일 / 등록, 지도, 현재 선택 대상, 서버가 허용한 다음 행동. |
| 보조 정보 | 표시 설정과 출처는 펼쳐서 확인. 선택하지 않은 업무의 상세 정보는 표시하지 않는다. |
| 독립 업무 | 글·협업 조건·공간·배송의 등록/수정 및 인증은 입력 전용 페이지. 문의 작성은 기존 독립 상세 입력 화면으로 이동한다. |
| 상태 소유 | 지도 작업공간 세션은 계정별 선택·카메라·목록 맥락만 메모리에 유지. 각 업무 조회·초안·명령의 수명과 서버 원장은 기존 소유자를 유지한다. |
| 이동·복귀 | 지도에서 입력 진입 시 안전한 returnUrl 전달. 저장은 새 stable ID의 패널로, 취소는 기존 선택으로 복귀. 로그인은 인증만 하고 원 입력으로 돌아간다. |
| 실패 | 레이어별 loading/empty/error/retry를 구별. 지도 실패 시 목록 유지. 현재 입력 화면의 미확정 저장은 기존 요청 ID와 복구 경로를 보존한다. 배송 작성은 기존 설계상 화면 이탈·401 때 비공개 초안을 지우므로 지도 복귀를 초안 복원으로 해석하지 않는다. |
| 개인정보 | 공개 동네 대표점 유지. 주소·연락처·정확 좌표·초안·토큰은 URL/영구 설정에 넣지 않는다. 계정 변경/종료 시 개인 표시 제거, 재진입은 권한·현재 원장 재조회. |
| 표시 어댑터 | Web Google 지도, Android native 지도는 기존 키·출처 제한을 유지. native 지도와 HTML 패널은 겹치지 않는 영역으로 배치한다. |
| 검증 | focused/Task 시험, 실제 shared UI의 좁은 화면·선택·작성 복귀·오류, APK 내장 실행 파일 확인. 개인 휴대폰·Azure·native 타일·Figma는 별도 증거. |

같은 목적의 조회·선택·처리를 구성하되 입력 업무를 지도 VM에 합치지 않는다. 레이어 조회·장면 구성·세션·플랫폼 렌더를 나누며 전문 역할 앱과 기능 관문은 보존한다.

Figma `01 Community`의 기존 지도 화면과 `/community/map`을 대응 대상으로 삼는다. 현재 연결된 Figma 편집 도구/확인된 node ID가 없으므로 이번에는 실제 코드와 PNG를 기준으로 차이와 미동기화 상태를 기록한다. Figma 갱신 완료로 보고하지 않는다.
