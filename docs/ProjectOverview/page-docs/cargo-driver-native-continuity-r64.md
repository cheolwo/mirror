## 코드와 데이터 책임

- `DriverNativeHomeWorkspaceState`는 한 계정·세션·전경 화면의 갱신과 마지막 확인 상태, 미확정 변경 식별값을 관리한다. 전경 30초 간격 보완 조회와 복귀 즉시 조회를 합류하고 이탈·계정 변경 뒤 늦은 응답을 버린다.
- `IDriverSampleDataService`의 기존 정본 조회가 현재 운송·추천·운행 상태를 제공한다. `CurrentTransport` 실패 slice도 예외와 같은 실패로 처리한다.
- `DriverOperationalDispatchApiService`는 기존 인증 client로 공통 수신 의사·실효 상태를 조회하고, 사용자가 실제 화면에서 확인할 수 있게 표시된 유효 최신 추천의 ID·차수를 ACK한다. ACK는 사람의 읽음이나 알림음 청취 증명이 아니다.
- 운행 시작의 최초 수신 ON은 시작 전에 본 판본을 조건부로 비교해 저장한다. 그사이 수동 OFF가 발생하면 덮어쓰지 않고, 미응답 자동 중지는 기사 본인의 토글 ON으로만 해제한다.
- 원장은 기존 `운송원장`·`용달기사`·`운영배차활동원장` 및 기존 운행 복구 저장소를 사용한다. 현재 운송을 위한 별도 원장·복제 완료 상태를 만들지 않는다.
