# 페이지 → 코드 → DB 문서화·보완 r1

2026-10-02 사용자 승인 범위: 먼저 전체 페이지를 현재 코드와 대조하고, 배차·정산의 기존 네 화면을 상세 문서화하며 재현된 기존 결손을 보완한다. 새로운 요율·공제/보상 정책·정산 화면·운영 DB 적용은 포함하지 않는다.

## 전체 목록

[현재 소스·호스트 목록](current-pages.md)은 466개 물리 Razor 페이지·538개 route 선언·17개 제품 호스트를 연결한다. [JSON](current-pages.json)과 [고정 ID 대장](page-identities.json)은 별칭·호스트 재사용·상세 검토 범위를 구분한다. 기존 P ID·캡처·옛 표는 보존했다. 새로운 상세 검토는 네 화면이며 나머지는 소스 색인 또는 기존 문서로 남긴다.

실제 MSBuild `Content/RazorComponent` 평가를 사용한다. MAUI의 Android target 평가, 역할 Web host의 조건부 include를 확인하고 공용 진입 화면도 해당 호스트의 컴파일 입력으로만 분류한다. 같은 URL의 Web/MAUI 소스는 자동으로 같은 구현으로 묶지 않는다. ID가 동일한 여러 파일은 기존 단계별 페이지 묶음의 호환 ID를 유지한다.
