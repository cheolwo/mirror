# 배달 영상 작업공간과 MYBOX 경로

2026-09-25 사용자 요청으로 Hongdal 프로젝트에서 배달 영상의 보관 위치와 최신 공유본을 찾을 수 있도록 기록한다.

| 용도 | 경로 또는 링크 |
| --- | --- |
| 최신 배달 영상 공유 폴더 | [MYBOX 배달영상-공유용](https://naver.me/GP2n94w4) |

공유용 폴더에는 **날짜별 최신 완성 번호의 영상 한 개씩** 둔다. 2026-09-25 확인 당시 09.22 V15, 09.23 V25, 09.24 R4이며 이후 현재 번호는 최신 공유 영상 목록에서 확인한다. 이전 확정본 보관 등록부의 번호보다 최신 공유 선택을 우선하고, 이전 영상은 보관한다.

2026-10-01 사용자 요청으로 같은 공유 폴더에 촬영·쇼츠 편집 안내서 `배달기사_촬영과_쇼츠_편집_안내서_v1.pdf`와 공유자료 `배달기사_쇼츠_촬영편집_공유자료_v1.zip`을 추가했다. ZIP에는 안내서, 빈 기록 양식, 공통 편집 설정과 읽기 전용 UXP 연결 확인 예제를 넣었다. 문서·자료는 영상과 별도로 보존하고, 원본 영상·개인 경로·API 인증 정보는 공유하지 않는다. MYBOX 드라이브 복사, 비로그인 서버 목록의 두 파일과 전송 완료 상태, 공개 링크에서 내려받은 PDF·ZIP의 SHA-256 일치를 확인했다. 휴대폰에서 실제 열기는 미확인이다. GitHub 기본 브랜치 README에도 같은 공개 폴더 링크와 자료 설명을 게시했다.

공유 링크는 읽기 전용이며 기간·접근 횟수 제한 없이 만들었다. 2026-09-25 로그인하지 않은 브라우저에서 세 영상의 폴더 목록을 확인했다. 원격 재생 전체 검수를 뜻하지 않는다. `N:`은 해당 PC에 연결된 MYBOX 드라이브 경로이며 다른 장치에서는 웹 공유 링크를 사용한다.

새 버전 완성·검증 후 같은 공유 폴더에 반영하며 상시 자동 동기화 서비스는 아니다. 로컬 복사, MYBOX 서버 반영, 개인정보 전체 검수, 유튜브 업로드는 별도 상태로 관리한다.

이 문서는 편집·보관 위치 안내다. 영상 경로를 운영 API나 Unity의 공개 방문 기록 계약에 추가하지 않는다. 관련 기록은 [지역 디오라마용 방문 기록](../Changes/2026-09-22-delivery-record-preview.md)을 참고한다.
