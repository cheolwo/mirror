# Ssalddel 2.0

## 목표

`2.0`은 **국내 화물·운송 이행** 단계입니다. 수요와 공급 조건을 먼저 확인한 뒤, 실제 이동이 필요한 확정 원장만 운송 의뢰, 수행자 인계, 배차, 증빙과 정산 준비로 연결합니다.

## 핵심 흐름

```text
확인된 구매·출고 원장
  → 운송 필요와 책임 주체 확인
  → 운송 의뢰
  → 허가·보험·약관이 확인된 수행자 인계
  → 배차·상차·하차·인수
  → 증빙과 정산 후보
  → 2.5 입고·판매 이행으로 인계
```

## 운영 경계

- 운송 기능은 `1.0` 공동구매의 선행조건이 아닙니다.
- 플랫폼이 운송 계약 당사자 또는 주선자가 되는 시점은 사업 모델, 허가, 보험과 약관 검토 뒤 별도로 결정합니다.
- 준비 전 운영에서는 `Simulation`과 정보 전달만 허용하고 실제 자동 배차·대금 보관·기사 지급을 실행하지 않습니다.
- 공동구매가 아닌 기존 화주 운송도 같은 운송 원장과 책임 경계를 사용할 수 있습니다.
