# 문화교통 1.0

## 목표

문화교통 `1.0`은 **같이 주문과 주문자 집단화** 단계입니다. `0.5`에서 사용자가 관리하는 개별주문 가운데 같이 주문 참여에 명시적으로 동의한 원장만 품목·지역·수령 조건별로 모아 비구속 같이 주문 모집으로 보여 줍니다.

## 핵심 흐름

```text
음식·재료 탐색
  → 저장 없는 공동구매 체험(선택)
  → 0.5 개별주문 원장과 같이 주문 참여 동의 재확인
  → 서버 집단화 미리보기
  → 주문자 집단·같이 주문 모집 원장
  → 공급자 후보와 조건 협의
  → 1.5 공급·무역 준비로 인계
```

## 원칙

- 체험 모드는 로그인 없이 명시적으로 표시된 가상 이웃과 집단화를 연습하며 세션·대화·수요를 서버에 저장하지 않습니다.
- 체험 완료는 개별주문이나 같이 주문 참여 동의를 자동 생성하지 않고, 0.5 화면에서 상품·수량·수령권과 철회 가능 상태를 다시 확인하게 합니다.
- 0.5 개별주문은 기본적으로 한 사람의 원장이며 별도 같이 주문 참여 동의가 없으면 1.0 집단화 대상이 아닙니다.
- 집단화는 상품, 수량, 지역, 수령 조건과 시간창처럼 구매 이행에 필요한 정보만 사용합니다.
- B2B/B2C는 회원 계정 등급이 아니라 개별 수요의 구매 목적입니다. 한 사용자가 두 목적의 수요를 각각 낼 수 있습니다.
- 한 모집에서 B2B와 B2C 참여를 함께 받을 수 있지만 가격 표시, 구매 조직, 계약·세금 검토 단위는 별도 집단으로 유지합니다.
- B2C 가격은 부가세 포함 기준으로 비교하고, B2B는 부가세 포함·별도 기준을 명시합니다.
- B2B 수요는 조직 이름 또는 내부 참조를 요구하되 사업자등록번호는 모집 단계에서 받지 않고 계약 전에 별도 검증합니다.
- 국적·언어 등 비관련 속성으로 참여자를 배제하거나 가격을 차별하지 않습니다.
- 수요 등록은 주문, 결제, 계약 또는 수입 신고가 아닙니다.
- 서버는 멱등 키로 중복 수요와 중복 집단 생성을 막고 사용자의 철회를 반영합니다.
- 기본 모집 기간은 14일이며, 종료 시 목표 충족 여부와 다음 검토 단계를 명시합니다.
- 운송사·창고·관세사·판매자를 자동 선정하지 않습니다.

## 다음 단계

거래유형별 목표 수량, 참여 의사, 공급 조건과 운영 주체가 검토 가능한 상태가 되면 기존 같이수입원장의 `1.5` 준비 블록으로 넘깁니다. 공급자·포워더는 전체 물량을 물류 검토용으로 참고할 수 있지만 B2B/B2C 계약 수량을 합쳐 확정하지 않습니다. 국내 공동구매는 통관 준비를 생략할 수 있지만 공급·가격 근거는 남겨야 합니다.
