# Hongdal 1.0 Checklist

- [ ] [0.0 집중 로드맵](../v0.0/focus-roadmap.md)의 1.0 재개 조건과 0.0 릴리즈 게이트 통과 확인
- [ ] [Hongdal 0.0 릴리즈 체크리스트](../v0.0/checklist.md)와 0.0 공통 게이트 통과 확인
- [ ] `CommunityTrustWorkflow=true` 상태에서 0.0 원장이 1.0 운송 의뢰로 인계되는지 확인
- [ ] 화주 운송 의뢰 등록 흐름 확인
- [ ] 화물/용달 기사 추천 후보 생성 확인
- [ ] 추천 수락/거절/보류 상태 변경 확인
- [ ] 기사 앱 운송 상세 정보 표시 확인
- [ ] 상차 완료 사진 처리 확인
- [ ] 하차 완료 사진 처리 확인
- [ ] 수령자 정보 노출 범위 확인
- [ ] 결제/정산 기본 정보 확인
- [ ] 배차대기 → 상차지도착 → 상차완료 → 하차지도착 → 인수완료 상태 전이 확인
- [ ] 상태 전이가 순서를 건너뛰지 못하는지 확인
- [ ] 상차/하차 완료 시각과 증빙이 운송 기록에 남는지 확인
- [ ] 배차 전 수령자 상세정보 비노출 확인
- [ ] 배차 수락 후 운행에 필요한 범위만 수령자 정보 노출 확인
- [ ] 인수완료 후 수령자 정보 마스킹 확인
- [ ] 인수완료 후 인수증/정산 후보/증빙 기록 생성 확인
- [ ] 화주/기사/수령자 각각의 1.0 핵심 화면에서 다음 행동이 명확한지 확인
- [ ] 같은 업무 대상의 상세 정보가 여러 페이지에 반복 노출되지 않는지 확인
- [ ] DriverApp 운송 하단 바가 접힌 상태에서도 다음 행동을 보여주는지 확인
- [ ] 당일 의뢰는 `DispatchQueue:당일미배정공개전환분`, 예약 의뢰는 `DispatchQueue:예약상차전공개전환시간`과 `DispatchQueue:예약최소추천유지분` 기준으로 공개 화물 전환되는지 확인
- [ ] 음식 멀티배차와 용달 멀티배차가 같은 조합 서비스로 처리되지 않는지 확인
- [ ] 용달 멀티배차 후보는 기사 명시 동의, 화주 혼적 허용, 독차/민감 화물 제외, 시간창, 휴식/복귀 부담 안전 정책을 통과한 경우에만 검토되는지 확인
- [ ] 화주 의뢰의 차량별 기본운임, km당 단가, 최소운임이 직선거리 기준운임으로 계산/기록되는지 확인
- [ ] 재알선금지 의뢰에서 2차 이상 알선 단계가 차단되는지 확인
- [ ] 화주 결제액과 기사 지급 예정 운임 사이의 설명되지 않은 차액이 정책 이벤트로 남는지 확인
- [ ] 0.0 커뮤니티가 1.0 운송 모듈과 분리되어 독립 동작하는지 확인
- [ ] 1.0 범위 밖 기능의 기본 노출이 꺼져 있는지 확인
- [ ] Admin/User 기능 설정 화면에서 0.0 기반, 1.0 실행 모듈과 1.5 이후 확장 기능이 버전 그룹으로 구분되는지 확인
- [ ] `CargoYongdalV1=true` 확인
- [ ] `WarehouseV15`, `CustomsHsV20`, `OrdererGroupOrderV25`, `FoodDeliveryV30`, `HongdalMartV35` 기본 비활성 확인
- [ ] [공통 릴리즈 게이트](../release-gates.md) 통과 확인
