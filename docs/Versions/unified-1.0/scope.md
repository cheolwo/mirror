# 통합 앱 1.0 범위

제품 범위는 기존 0.0~3.5의 합집합이다. 기존 전문 기능을 제거하거나 역할별 원장을 하나의 상태로 합치지 않는다. 본문과 최신 완료 기준은 [단일 목표](README.md)를 따른다.

| 포함 | 기존 업무·권위 |
| --- | --- |
| 커뮤니티·공공데이터 | 게시글·공개 문의·출처·동의·개인정보 경계 |
| 개별·공동 주문 | 본인 원장·참여 수락/철회·조건 판본·모집과 실제 주문 구분 |
| 공급·가격·무역 준비 | 기존 공급 자료·견적·원가·전문 확인 필요 상태. 실제 해외 실행의 새 확장은 별도 준비 |
| 화물·퀵 | 운송 의뢰·추천·수락·상하차·증빙·취소/반송·정산 준비 |
| 창고·판매·마트 | 입고·재고·수량 예약·피킹·포장·인계·판매 연결 |
| 음식 배달 | 음식 주문·음식점·음식 기사·주문자와 음식 정책 |
| 공간·인력 협업 | 기존 공동운영·예약·수락·약속 영향·전문 업무 참조 |
| 운영·정산 | 미확정·신고·담당·명세·수납/재원·지급 결과의 분리 |

통합 앱·웹과 기존 전문 앱을 유지한다. 서버 원장은 하나의 업무 사실을 소유하고 각 앱은 권한에 따라 같은 결과를 재조회한다. 통합 원장의 역할 수락은 전문 기사 배정·입고·생산·지급 완료가 아니다.

이번 목표 통합만으로 Unity 게임, 새 인사급여 엔진, 외부 플랫폼의 실제 API 계약, 신규 해외 실행, 운영 배차·실금융·클라우드 자원 생성을 추가 실행하지 않는다. 운영 준비 항목은 마감표에서 별도로 확인한다.
