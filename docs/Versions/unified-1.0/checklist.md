# 통합 앱 1.0 업무별 마감표

2026-10-25 기준. 완료 상태는 현재 소스·시험 서버·APK 판본이 일치하는 근거로 갱신한다. 과거 통과를 최신 판본의 완료로 승계하지 않는다. 아래 표는 제품 1.0의 내부 업무 묶음이며 별도 제품 버전이 아니다.

2026-10-26 공통 절차 연결: [앱 공통 제작 절차](../../AI/Planning/시스템/PLAN-SYSTEM-PLANNING-IMPLEMENTATION-CHECKLIST/app-production-input-guide.md)로 같은 업무의 입력·역할 인계·실패/복구와 판본별 근거를 연결한다. 첫 [화물 마감 파일럿](../../AI/Planning/공통/PLAN-OPERATIONS-DISPATCH-CORE/cargo-lifecycle-pilot.evidence.r1.md)은 앱별 입력과 검증 계획을 등록한 단계다. 아래 r121 등 기존 관측은 당시 결과로 유지하고 새 입력 작성·도구 시험을 서버/휴대폰 완료로 올리지 않는다.

## 모든 업무에 적용할 확인

- [ ] 최신 APK의 첫 실행·반복 실행과 데이터 보존 업데이트
- [ ] 공개 탐색과 로그인 후 원래 업무 복귀
- [ ] 정상 처리 후 같은 원장을 모든 관련 역할에서 재조회
- [ ] 종료·통신 단절·응답 유실 후 복구, 자동 재전송·중복 완료 없음
- [ ] 다른 계정·서버·대상으로 전환한 뒤 이전 자료/응답 차단
- [ ] 취소·거절·변경·사진 실패·미확정·신고의 복귀 경로
- [ ] 모바일 읽기·터치·키보드·하단 메뉴·시스템 막대 확인
- [ ] 실제 업무·수령·정산 준비·실수납·실지급을 별도 확인

체크박스는 전체 역할에 공통으로 완료했을 때만 채운다. 일부 업무가 확인된 것은 위 표와 변경 기록에 남긴다. r2 전체 회귀는 16,210개 통과·실패0·환경 의존16개 생략이다. 그 뒤 마지막 읽기 전용 링크 표시 조정은 Fast292와 소비 빌드로 별도 확인했다. 실제 기기에서 검토한 APK는 r121의 시험 번호 0.1.122이며 이번 r2를 휴대폰에 설치한 것은 아니다. 제품 1.0의 공개 완료 표시는 아니다.

표의 `HTTP 완료`는 합성 자료를 이용한 현재 제품 API/격리 DB 검증이며 실운송·카메라·GPS·실금융·운영 공개가 아니다. 세부 결과는 [r121 변경 기록](../../Changes/2026-10-25-mobile-app-closeout-r121.md)에 연결한다.
