# 통합 앱 1.0

2026-10-25 사용자 결정. **기존 0.0~3.5에 나누었던 제품 범위를 하나의 1.0 완성 목표로 통합한다.** 새 제품판을 공동주문만의 옛 `1.0`과 혼동하지 않는다.

커뮤니티·공공데이터, 개별/공동 주문, 공급 준비, 화물·퀵, 창고·판매, 음식 배달, 마트·도심 물류, 공간·사람의 예약 협업을 포함한다. 통합 앱을 중심으로 기존 화주·기사·주문자·음식점·창고·운영자 전문 앱을 함께 유지한다. 플랫폼 표시명과 기존 내부 namespace·stable ID는 이번 결정으로 바꾸지 않는다.

## 완성 방식

제품 목표는 하나이며 각 업무를 **준비 / 구현 / 서버 완주 / 휴대폰 확인 / 제한 사용 / 공개 준비**로 관리한다. 화면이나 기능 수를 제품 완성률로 환산하지 않는다. 앱을 껐다 켜도 이어서 처리하고, 상대 역할에서도 같은 원장의 결과를 확인할 수 있어야 한다.

모든 앱 작업의 입력·통과·실패 후 복귀는 [앱 공통 제작 절차](../../AI/Planning/시스템/PLAN-SYSTEM-PLANNING-IMPLEMENTATION-CHECKLIST/app-production-input-guide.md)를 따른다. 기존 기획·작업 입력·코드·결과는 제작 관계 대장으로 연결하고, 이 제품 목표에는 업무별 현재 마감 상태만 기록한다.

현재 첫 작업은 [모바일 마감 r121](../../AI/Planning/공통/PLAN-OPERATIONS-NEIGHBORHOOD-MICRO-HUB/mobile-app-closeout.implementation.r121.md)의 실행 안정성·화물 흐름이다. 이 순서는 개발 순서이며 화물만 먼저 공개한다는 뜻이 아니다. [전체 역할 통합 공개 r105](../../AI/Planning/공통/PLAN-OPERATIONS-NEIGHBORHOOD-MICRO-HUB/integrated-public-release.r105.md)의 준비 범위와 운영 조건을 유지한다.

| 업무 묶음 | 사용자가 끝까지 할 수 있어야 하는 일 |
| --- | --- |
| 공통 기반 | 첫 실행·공개 탐색·로그인 복귀·종료 후 복구·계정 전환 |
| 커뮤니티·정보 | 출처가 있는 자료 탐색·제공/필요 글·공개 문의·동의·신고 |
| 주문·공급 준비 | 개인 의향·공동 참여·조건 협의·공급 근거·가격/수량 확인 |
| 화물·퀵 | 접수·추천/공개 콜·수락·상하차 증빙·인수·정산 준비 |
| 창고·판매 | 입고·검수·적재·재고·피킹·포장·인계·반환 |
| 음식 배달 | 주문·음식점 수락·기사 배정·조리·픽업·전달·수령 확인 |
| 마트·도심 물류 | 주문 수량과 재고 예약·피킹/인계·배송 결과 연결 |
| 통합 협업 | 공간 제공자·생산자·주문자·작업자의 예약·수락·취소 영향·업무 연결 |
| 운영·정산 | 현재 담당·미확정/신고 대응·비용·보수·지급 준비/실지급 구분 |

## 현재 상태와 호환

`1.0 목표 통합`은 기존 기능이 전부 완성되거나 공개됐다는 선언이 아니다. 검증 결과는 [업무별 마감표](checklist.md)에 근거별로 기록한다. 운영 서버·금융·실물 업무의 완료는 로컬 화면이나 모의 흐름으로 대신하지 않는다.

기존 `0.0`, `0.5`, 옛 공동주문 `1.0`, `1.5`, `2.0`, `2.5`, `3.0`, `3.5`는 API·저장 자료·기능 도입 이력의 호환 코드로 보존한다. 새 통합 릴리스의 버전과 이전 업무 분류를 같은 필드에서 재해석하지 않는다. 기본 기능 설정·권한·실행 모드·운영 배차·결제·지급은 버전 통합만으로 활성화하지 않는다.
