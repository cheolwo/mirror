# 통합 앱 1.0 제품 완성 계획

2026-10-25 사용자 결정으로 **기존 0.0~3.5의 전체 제품 범위를 하나의 통합 1.0 목표로 묶습니다.** 현재 기준은 [통합 앱 1.0](unified-1.0/README.md)입니다.

커뮤니티·공공데이터, 개별/공동 주문, 공급 준비, 화물·퀵, 창고·판매, 음식 배달, 마트·도심 물류, 공간·사람의 협업을 포함합니다. 기존 통합 앱과 역할별 전문 앱을 함께 유지합니다.

## 완성과 공개 관리

제품 목표는 하나이며 공통 기반·화물·음식·창고·마트·협업·운영의 업무 묶음별로 완성합니다. 각 업무는 구현, 서버 완주, 실제 휴대폰, 제한 사용, 공개 준비를 따로 확인합니다. 처음부터 끝까지 같은 원장으로 처리하고 종료·통신 실패에도 복구할 수 있어야 합니다.

## 기존 코드와 문서

기존 숫자 분류는 기능 도입 이력·API·저장 자료의 호환 코드로 보존합니다. 옛 공동주문 분류 `1.0`은 새 통합 릴리스 `1.0`의 전체 범위를 뜻하지 않습니다. 현재 기본 노출·기능 플래그·권한·실행 모드는 별도로 유지하며 목표 통합만으로 운영을 켜지 않습니다.

기존 `v0.0`~`v3.5` 폴더는 각 업무의 이전 설계와 검증을 찾는 참조입니다. 새 개발을 여덟 제품 버전으로 나누는 기준으로 사용하지 않습니다. [이전 제품 분류 원문](history/20261025-before-unified-1.0.md)을 보존합니다.
