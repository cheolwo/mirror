# Ssalddel 2.5

## 목표

`2.5`는 **창고·판매 이행** 단계입니다. 공동구매 또는 일반 판매의 물품을 입고하고, 재고·피킹·포장·출고·판매채널과 주문자 최종 배분까지 연결합니다.

## 핵심 흐름

```text
운송·입고 예정
  → 수령·검수·적재
  → 재고 로트
  → 주문자 예약분 우선 배분
  → 소유권·동의가 확인된 잔여재고만 판매상품·판매채널로 분기
  → 피킹·포장·출고
  → 판매 정산·공동주택 수익귀속 후보
  → 관리사무소 확인을 거친 관리비 절감 반영
```

`2.5`는 공동구매 수요를 새로 만드는 단계가 아닙니다. 주문자 집단과 모집 원장은 `1.0`, 공급·HS·수입 준비는 `1.5`, 운송은 `2.0`에서 입력받습니다.

## 운영 경계

- 실제 보관·출고·판매 책임은 계약된 창고, 판매자와 수행 주체가 확인합니다.
- 재고, 피킹, 포장과 출고 상태는 stable ID와 역할 권한으로 전이합니다.
- 외부 판매채널 발행·주문 동기화는 명시적 연결과 운영 승인을 거칩니다.
- 주문자 집단 내부 역할·보수·고용은 별도 법적 운영 주체와 계약을 확인합니다.
- 참여자의 예약분과 미수령분은 잔여재고로 자동 전환하지 않으며, 자금 출처·소유권·처분 동의를 먼저 확인합니다.
- 총매출이 아니라 원금·환불·세금·물류·노동비 등을 뺀 귀속 가능액만 공동주택 수입 승인 대상으로 삼습니다.
- 실제 관리비 절감은 플랫폼 계산으로 확정하지 않고 관리규약·예산·의결, 지정 계좌 입금과 관리사무소의 부과 반영을 대사합니다.

세부 원장·상태·권한 흐름은 [공동주택 공동구매 잔여재고 판매와 관리비 절감 흐름](../../Architecture/ApartmentGroupPurchaseSurplusRevenueFlow.md)을 따릅니다.
