# Hongdal 0.0 Scope

| 기능 | 포함 여부 | 관련 앱/모듈 | 완료 판단 |
| --- | --- | --- | --- |
| 커뮤니티 홈·게시판·글쓰기 | 포함 | `Hongdal.Ui.Common`, 역할별 앱 홈 | 운송 메뉴 없이도 대화와 탐색이 가능함 |
| 댓글·첨부·추천 | 포함 | 커뮤니티 API와 공통 UI | 권한과 개인정보 정책을 지키며 저장됨 |
| 모집·투표·숙고·결의 초안 | 포함 | 커뮤니티 투표·대화 | 합의 과정과 이견을 참여자가 확인할 수 있음 |
| 공동 원장·다이어그램 | 포함 | 원장 API, 다이어그램 작업공간 | 대화에서 원장 생성·공유·완료까지 이어짐 |
| 연락 정보 상호 동의 | 포함 | 참여자·문의 흐름 | 일방 열람 없이 필요한 범위만 공개됨 |
| 신고·차단·운영 기록 | 포함 | 커뮤니티 API, 관리자 화면 | 신고 처리와 운영자 조치가 감사 가능함 |
| 활동 신호·후기·신뢰 기록 | 포함 | 커뮤니티 신뢰 워크플로우 | 원본 개인정보 없이 다음 판단을 도움 |
| 완료 원장 자동 사례 게시 | 포함 | 원장 이벤트, 커뮤니티 게시글 | 중복 없이 익명화된 절차와 다이어그램이 게시됨 |
| 국내 공동구매 직접 협의 | 제한 포함 | 생산자 연결·협상 UI/API | 메모리 저장을 영속 저장으로 전환하기 전에는 파일럿 한정 |
| 기사 운행 가능 상태 공개 | 제한 포함 | 기사 앱, 커뮤니티 공개 보드 | 구 단위 위치·별도 동의·만료 정책을 지키는 파일럿 한정 |
| 국내 화물/용달 실행 | 보류 | `HongdalApp`, `DriverApp`, 운송 서버 | 1.0에서 다룸 |
| 실제 결제·정산·주선 | 보류 | 결제·배차·정산 서비스 | 허가·제휴·법률·운영 준비 후 별도 판단 |

`CommunityTrustWorkflow=true`, `DomesticTransportWorkflow=false`, `CargoYongdalV1=false`가 0.0의 기준 실행 구성입니다.
