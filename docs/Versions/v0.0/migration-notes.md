# Hongdal 0.0 Migration Notes

## 2026-07-15 커뮤니티 선행 버전 분리

- `HongdalProductVersion.V0_0`과 표시 라벨 `0.0`을 추가했습니다.
- 커뮤니티·공동 원장·신뢰·알림·상호 연결 API의 최초 제품 버전을 0.0으로 분류했습니다.
- `CommunityTrustWorkflow`를 국내 화물/용달 플래그와 독립적으로 활성화할 수 있게 했습니다.
- 국내 화물/용달 워크플로우는 커뮤니티 기반이 활성화된 경우에만 열리도록 의존 방향을 정리했습니다.
- 기본 설정은 커뮤니티 0.0을 켜고 국내 화물/용달 1.0을 끈 개발 집중 구성으로 변경했습니다.

DB 스키마 변경은 없습니다. 생산자 연결, 공동구매 협상, 기사 공개 상태처럼 현재 메모리 저장을 사용하는 파일럿 기능은 0.0 릴리즈 전에 영속 저장 마이그레이션을 별도로 추가해야 합니다.
