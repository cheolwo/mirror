# Hongdal 0.0 Release Checklist

작업 순서는 [0.0 집중 로드맵](./focus-roadmap.md)의 `0.0-A`부터 `0.0-E`까지를 따릅니다. 이 문서는 각 단계가 실제로 완료되었는지를 판정합니다.

## 독립 실행

- [ ] `CommunityTrustWorkflow=true`에서 커뮤니티 홈과 API가 정상 동작함
- [ ] `DomesticTransportWorkflow=false`, `CargoYongdalV1=false`에서도 0.0 핵심 흐름이 동작함
- [ ] 운송·창고·통관·음식·마트 실행 화면이 0.0 기본 사용자에게 노출되지 않음

## 참여와 신뢰

- [ ] 가입·로그인·프로필·역할 전환이 커뮤니티 참여자 기준으로 이어짐
- [ ] 게시글·댓글·첨부·추천·검색 흐름이 서버 영속 데이터로 동작함
- [ ] 모집·투표·숙고·결의 과정과 변경 이력이 참여자에게 보임
- [ ] 신고·차단·운영자 조치·이의 처리 기록이 감사 가능함
- [ ] 익명 또는 별명 활동의 책임 범위와 운영자 식별 정책이 정해짐
- [ ] 스팸·반복 요청·악성 사용을 제한하는 속도 제한과 운영 정책이 적용됨

## 원장과 다이어그램

- [ ] 커뮤니티 대화에서 공동 원장을 만들 수 있음
- [ ] 참여자·역할·상태·관계·선택적 증빙이 다이어그램과 일치함
- [ ] 공개 범위와 연락처 공개가 당사자 동의에 따라 변경됨
- [ ] 이견과 문제 상황을 원장 대화에서 숙고하고 처리 결과를 남길 수 있음
- [ ] 완료 원장은 중복 없이 개인정보를 줄인 사례 글로 게시됨
- [ ] 사례 글에서 같은 절차의 새 원장 또는 모집을 시작할 수 있음

## 개인정보와 운영

- [ ] 상세 주소·연락처·정확한 GPS가 공개 게시물과 활동 신호에 노출되지 않음
- [ ] 개인정보 수집·이용·공개 동의와 철회 이력이 저장됨
- [ ] 데이터 열람·수정·삭제·보유기간 정책이 실제 API와 화면에 연결됨
- [ ] DB 마이그레이션, 백업·복구, 오류 관측과 운영 알림이 검증됨
- [ ] Android/iOS/Web에서 커뮤니티 핵심 화면과 푸시 딥링크를 확인함
