# Ssalddel 3.0

## 목표

음식점 일반 음식 배달을 운영 가능한 흐름으로 확장합니다.

3.0은 주문자, 음식점, 음식 배달 기사 사이의 짧은 시간창 배달을 다룹니다. 알뜰살뜰 마트/도심 즉시배송은 창고형 재고, 피킹, 포장, 도심 재고 보충이 함께 붙으므로 3.5로 분리합니다.

## 포함 범위

| 영역 | 내용 |
| --- | --- |
| 음식점 주문 | 주문자 앱에서 음식점 상품 주문 |
| 음식점 접수 | 주문 접수, 조리 상태, 픽업 예상 시각 |
| 음식 배달 기사 배차 | 조리/픽업 시간과 고객 도착 시간을 기준으로 기사 추천 |
| 픽업/배송 | 음식 배달 기사 픽업, 고객 배송, 완료 확인 |
| 묶음 배달 | 시간/거리 기준으로 묶음 가능성 판단 |

## 보류 범위

- 2.0 핵심 운송 흐름을 흔드는 대규모 구조 변경
- 알뜰살뜰 마트 도심 즉시배송 실운영
- 창고형 재고 보충, 피킹, 포장과 음식점 배달의 강한 결합

## 안정화 기준

- 음식점 주문이 접수되고 조리/픽업 예상 시각이 배차 판단에 연결된다.
- 음식 배달 기사 앱에서 픽업/배송에 필요한 정보만 확인한다.
- 음식점 일반 배달과 알뜰살뜰 마트 도심 즉시배송이 주문/정산/배차 정책에서 섞이지 않는다.
- 음식 배달 흐름이 2.0 화물/용달 운송 흐름을 침범하지 않는다.
- 음식 멀티배차 후보는 음식 배달 OS 전용 판단근거를 조회해 조리 완료, 고객 전달 마감, 같은/인접 배달권, 6km 안팎의 묶음 거리 조건을 설명 가능한 형태로 남긴다.
