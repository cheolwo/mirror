# 공통 근거 판본과 건별 배차 기록 r25

새 화물 추천의 기록을 공통 설명과 당시 개별 사실로 나눴다. [r24](2026-10-28-cargo-dispatch-explanation-feedback-r24.md)의 기존 보호 사건·의견 ID를 그대로 사용하고, 새 추천 원장이나 사용자별 공통 문구 사본을 만들지 않았다. [승인 범위](../AI/Planning/공통/PLAN-OPERATIONS-DISPATCH-CORE/cargo-dispatch-evidence-library.r25.md).

## 무엇을 어디에 남기는가

| 구분 | 보관과 의미 |
| --- | --- |
| 공통 설명 | `Ssalddel.Contracts/Common/Dispatch/CargoDispatchBasisCatalog.cs`가 독립 정본이다. `cargo-dispatch-basis.r1`의 코드·한국어 설명·종류·순서를 고정하고 내용 SHA256을 결속한다. 공개 목록은 수정할 수 없으며 문구를 바꾸려면 새 판본을 추가한다. |
| 건별 사실 | 기존 SQL `운송이벤트`의 보호 payload가 추천 당시의 중량·운송 방식·온도·마감·전달받은 수행계획 확인값과 공통 판본/hash·기록/누락 코드를 함께 저장한다. 같은 추천 저장 집합에서 처리한다. |
| 내부 입력 참조 | 판정 경로가 제공한 현재 의뢰/기사의 입력·차량·고정조건·수행·위치 관측 지문과 조회 범위/시각·원자적 조회 여부를 첫 await 전에 복사해 같은 보호 payload에 보존한다. 다른 후보 사전·원시 사유·점수·GPS 좌표는 복사하지 않는다. 입력 참조가 없으면 만들지 않는다. |
| 개인 안내 자료 | 저장된 사건과 정확한 공통 판본을 읽어 표현 판본 `cargo-dispatch-notice.r1`의 제목/문구/조건을 구성한다. 이메일 주소나 새 발송 기록을 만들지 않는 읽기 전용 입력이다. |

공통 r1은 접수 정보5개(중량·운송 방식·온도·상하차 마감)와 판정 자료4개(수행계획·구간 적재·이번 상하차 순서)를 정의한다. 기록된 항목 수, 그중 접수/판정 수, 미기록 수를 구분한다. `false`는 기록된 미확인 결과이고 `null`은 누락이므로 서로 바꾸지 않는다. 이 수는 공통 안내 항목의 기록량이며 AI 신뢰도·확률·선택 기여도나 내부 전체 근거 수가 아니다.

공통 설명의 판본은 알고리즘·모델 버전이 아니다. 접수 정보는 **추천 저장 때 접수 원장에서 관측한 값**으로, 최초 Mongo 접수의 과거 원본을 새로 확보한 것이 아니다. 실제 알고리즘 판본·최초 접수 근거·모든 후보 비교를 저장한 것으로 표현하지 않는다. 기존 현재값 기반 정책/RAG 검색을 과거의 선택 원인으로 붙이지 않았다.

## 조회·후속 개인 안내

기존 설명 API 항목에 선택적 `Basis`를 추가했다. 새 기록은 당시 고정 판본의 라벨/설명으로 조립하며 현재 catalog로 바꾸지 않는다. 구형 사건은 `legacy-unlinked`, 미확인 판본은 `catalog-unavailable`, hash/기록 코드 불일치는 `mismatch`로 보류한다. 개별 사실과 본인 의견 제출은 계속 유지한다. core 저장 `SchemaVersion=1`을 보존한 추가 필드이며 기존 Fact 생성자·Deconstruct·EvidenceId·의견 요청/내용 지문은 변경하지 않았다.

`GET api/v1/cargo-dispatch-explanations/{requestId}/notice-context/{evidenceId}`는 기존 본인 권한을 다시 확인한다. 화주/주문자와 해당 사건의 대상 기사만 읽으며, 만료/재추천 뒤에도 다른 기사의 이력을 열지 않는다. 응답 `Purpose=preparation-only`는 안내 입력 조회다. 현재 의뢰를 바꿔도 당시 문구/값이 변하지 않으며 조회는 원장·의견·Outbox·이메일에 쓰지 않는다.

실제 이메일을 연결할 후속 단계는 사용자별 수신 설정/동의·수신자 확인, 발송 시 권한/공통 판본 재확인, 실제 발송 문구의 보호 보존, 채널별 멱등 처리·전달/실패 추적이다. 이번 구현으로 발송·자동 개인 연락·예약 발송·자동 학습을 켜지 않았다.
