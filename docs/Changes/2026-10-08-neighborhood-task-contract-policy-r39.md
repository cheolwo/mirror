# 건별 프리랜서 계약 기본·꺼진 미성년 정책 준비 r39

사용자의 **“서버에 꺼진 정책 옵션까지 준비”** 범위를 수용했다. 새 건별 의뢰의 계약 준비 기본값은 `PerTaskFreelance`로 두고, 미래 정책 후보를 기록할 옵션을 추가했다. 미성년 참여는 현재 판본에서 설정만으로 활성화할 수 없다.

## 변경 내용

- 공유 정책 DTO와 인증된 기존 통신판매 Controller 조회를 추가했다. 준비 정책만 반환하며 계약 생성과 법적 분류 확정은 모두 `false`다.
- 설정을 기존 통신판매 서비스 등록에 연결하고 시작 시 검증한다. 미래 법령·검토 참조·시행 기간·나이·업무·시간 후보를 수용하지만 `Enabled=true`는 항상 거부한다. 서비스 직접 호출에서도 검증한다.
- 같은 서비스를 두 번 등록해도 후보 배열이 중복 바인딩되지 않도록 등록 전체를 한 번만 수행한다.
- 기존 신규 통신판매 성인 확인, HR 고용계약, 음식·화물 배차, 작업 사진과 정산 원장은 보존했다. DB 테이블·migration·앱·APK는 추가하지 않았다.

정책의 단일 기준은 [승인 r33](../AI/Planning/공통/PLAN-OPERATIONS-NEIGHBORHOOD-MICRO-HUB/task-contract-policy-preparation.implementation.r33.md), 실제 책임 연결은 [페이지·서버·DB r39](../ProjectOverview/page-docs/neighborhood-task-contract-policy-r39.md)다.

## 검증

| 검증 | 실제 결과 |
| --- | --- |
| 영향 프로젝트 Fast 빌드 | Contracts·Tests·서버 통과 |
| 공유 소비자 Task 빌드 | `Ssalddel.v3.5.slnx` 통과 |
| Fast 관련 시험 | 통과101·실패0·환경 의존 MongoDB 건너뜀1 |
| Task 전체 시험 | 통과9,008·실패0·환경 의존 MongoDB 건너뜀2 |
| 전용 정책 시험 | 22개 모두 통과. 위 Fast/Task에 포함 |
| 소스 동일성 | 최종 소스8개가 검증 전후 동일 |
| 기존 작업 보존 | 다른 변경15,131개 해시 동일, 공용 문서 기존 본문·정산 시험 원 검증 항목 보존 |

전용 시험은 기본 비활성·설정 활성화 거부·직접 생성 검증·후보 유효성·등록 중복·HTTP 인증 및 정보 노출 경계를 포함한다. HTTP 시험은 정책 조회에 한정한 로컬 Kestrel/MVC와 시험 인증이다. 다른 신원기관·거래·DB 액션의 실제 실행 검증은 아니다.

처음 전체 시험은 기존 `NeighborhoodSettlementPersistenceTests` 두 사례에서 EF 내부 서비스 제공자 누적 경고로 실패했다(`20261008-174446`). 해당 시험은 보호 모델 격리를 위해 캐시를 끄고 있었으나 전체 프로세스의 provider 누적에 영향을 받았다. 시험 인스턴스가 소유하고 해제하는 전용 SQLite provider를 명시해 격리를 유지했다. 경고 무시·시험 생략 없이 기존5개 시험과 전체 Task가 모두 통과했으며 제품 DB·정산 업무 코드는 바꾸지 않았다.

최종 로그는 `artifacts/local/validation/20261008-174914`(Fast)·`20261008-175017`(Task), 소스·작업 보존 근거는 `artifacts/local/neighborhood-task-contract-policy-r39-20261008/verification.json` 및 같은 폴더의 개별 확인 기록이다. 이 로컬 자료는 공유·실운영 증거가 아니다.

## 남은 범위

실제 프리랜서 계약 생성·성립, 근로자성 검토 완료, 참여자/법정대리인 검증, 동의 저장, 전 업무 경로의 자격 적용, 보험·세무·사고 운영과 실제 미성년 배차는 준비하지 않았다. 후속 적용은 r33의 별도 검토·구현·운영 전환 기준을 따른다. 휴대폰·Azure·실운영·실송금·Unity·영상·commit/push는 이번 작업의 완료 범위가 아니다.
