## 변경된 동작

음식 배차 후보를 고를 때 확인된 주문량과 기존 기사의 수행 여력을 먼저 보고 신규 참여 순서를 권고한다. 기존 활동 기사는 우선 보호하고 신규는 실제 대기 순서로 비교한다. 오래 기다렸거나 주문 지연이 생기면 추가 기회를 준다. 유효 제안·수락 업무·기사의 수신 의사는 유지한다.

조회 상한 전에 순서를 적용하며 GPS·음식 근무·수신 ON·수행 상한·반경·픽업 시간 관문은 보존한다. 가장 적절한 픽업 단계 안에서 참여 우선권을 적용하며 해당 단계에 허용 기사가 없으면 적격 대기 기사로 이어가고 적시성 예외 사유를 남긴다. 수요 대기 예외 재탐색은 적격 기사만 사용한다. 직접 기사 지정도 활성 기능의 후보 선정 결과를 검증한다. `FoodDemandParticipation:Enabled=false`가 기본이며 운영 구성은 켜지 않았다.

SQL 정본과 기존 인덱스를 읽는 서비스·순수 정책·공유 계약을 분리했고 탐색용 메타데이터를 제공한다. 현재 근무 유형, 같은 주문의 최신 시도, 플랫폼 책임 중단, 만료 시각 없는 기존 제안도 대조한다. 미확인·만료·조회 실패·잘림은 0건 수요로 가정하지 않고 기존 규칙에 인계한다. 업무 원장 쓰기는 없지만 기존 수신 조회의 캐시 복구 가능성은 메타데이터에 남긴다.

## 로컬 AI 준비

[실행 안내와 경계](../../eng/local-dispatch-ai/README.md). 공식 Ollama portable `v0.40.2`와 `qwen3:1.7b` Q4_K_M을 사용자 폴더에 준비했다. 공식 SHA-256·실행 파일 서명·모델 layer 해시가 일치한다. 실행 파일과 모델의 실제 합계는 3,301,108,946바이트(약 3.07GiB)이며 임시 ZIP은 검증 후 정리했다.

기본 dry-run·합성 집계 세 가지·응답 JSON 검사·오류 시 규칙 유지 도구를 제공한다. 방어 시험 14건이 통과했다. 실제 주소·고객·기사·원장을 읽지 않으며 서버 배차는 이 도구를 호출하지 않는다. 실제 최적 배차·수요 예측 학습·소득 보장 근거가 아니다.

자동 승인 검토가 루프백 Ollama 서버 프로세스 시작을 두 차례 `blocked by policy`로 거절했다. 상세 사유는 없었으며 다른 실행 도구로 우회하지 않았다. **실제 추론·GPU 사용·속도·로컬 API 응답은 미검증**이다. 자동 시작·Windows 서비스·방화벽·PATH 설정을 바꾸지 않았고 실행 프로세스·포트 리스너도 남아 있지 않다.

## 검증

- 실행 근거: Git 제외 `artifacts/local/food-demand-participation-r44/`와 `artifacts/local/local-dispatch-ai/`.
- 첫 집중 시험은 구현 변경과 빌드가 겹친 기준선에서 60건 통과·1건 실패했다. 미적격 후보를 예외 재탐색에서 제외하고 소스를 다시 빌드하여 검증했다.
- 이어진 집중 시험의 컴파일 오류는 신규 시험의 네임스페이스 누락으로 수정했다. 74건 통과·8건 실패는 .NET 10 배열 `Contains`의 span 오버로드 선택이 EF 조회 번역을 막은 문제로, 명시적인 `Enumerable.Contains`로 수정했다. 실패 기록은 `focused.log`, `focused-final.log`, `focused-final.trx`에 보존한다.
- 첫 Fast는 빌드 통과·87건 중 85건 통과·2건 실패했다(`artifacts/local/validation/20261011-103214/`). 신규 SQLite 시험의 수신 ON 변경 시각 누락을 수정하고 시각 없는 ON을 거절하는 사례를 추가했다. 실제 수신 관문은 완화하지 않았다. 읽기 검토에서 발견한 픽업 적시성 우선 문제도 수정하고 참여 허용/대기 두 경우를 나누어 검증한다.

## 후속 한계

이번 구현은 소프트 참여 순서다. 권역 전체 원자적 정원·영속 대기열·시간당 소득을 보장하지 않는다. 권역/인접 권역의 중첩과 동시 추천은 남아 있다. 실행 투영의 대량 지역 집계 최적화, 실제 대기 자료 품질, 운영 표본 관측과 전문 경로 최적화는 후속으로 평가한다. 음식과 화물의 기존 원장·업무 의미는 합치지 않는다.
