# 일반 입고 예정 목록의 작업 열기 문구

가상 입고 세 건의 작업 버튼은 좁은 화면에서 화살표만 보였다. 일반 입고 예정 목록에서는 기존 접근성 이름인 **입고 작업 열기**를 화살표 옆에도 표시한다. 기존 본문 색을 적용한 문구는 흰 카드에서 명암 대비 10.05:1로 측정됐다. 320px·390px에서 버튼 너비가 26px에서 약 126px로 늘었고 기존 40px 높이와 20px 화살표는 유지됐다. 가로 넘침 없이 문구 전체가 보였다. 1280px에서는 기존 화살표 배치가 유지됐다. [2026-11-07 390px 가상 입고 목록](../assets/changes/2026-11-07-warehouse-inbound-action-label/list-390.png)

수정 전 브라우저 검사 39개와 수정 후 41개가 통과했다. 가상 입고 세 건으로 도움말과 키보드 초점, Enter로 같은 입고 번호의 작업 경로에 도착, 목록 복귀 뒤 재조회와 검색 조건 해제를 확인했다. 작업 화면 도착 지점은 검증용이었다.

최종 스타일에서 Fast 관련 시험 103개와 창고 앱을 포함한 통합 3.5 Task 전체 시험 17,051개가 통과했다. 별도 환경이 필요한 17개는 생략했다. 빌드 오류는 0개였고 Fast 경고는 0개, 통합 빌드 경고는 62개였다.
