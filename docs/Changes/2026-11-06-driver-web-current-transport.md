# 화물기사 웹 현재 운송의 조회 실패와 정상 빈 상태 구분

화물기사 웹의 현재 운송 화면은 진행 중인 운송이 없는 경우뿐 아니라 조회 중이나 서버 오류, 로그인 필요 상태에도 빈 상태와 추천 배차를 표시했다. 웹 화면은 기존 현재 운송 GET이 운송 없음 코드와 함께 404를 반환했을 때만 정상 빈 상태와 추천 배차를 표시한다. 연결이나 조회 오류에는 기존 GET을 다시 호출하는 **다시 조회**를 제공한다. 로그인 필요에는 현재 화면으로 돌아오는 로그인 링크를, 권한 오류에는 기사 홈 링크를 표시한다. 수락 결과를 확인하는 동안에는 조회 진행을 안내한다. [현재 운송 화면](../../Ssalddel.WebApp/Pages/DriverCurrentTransportPage.razor)

합성 응답을 실제 웹 페이지와 ViewModel에 연결했다. 320px·390px에서 수정 전 60개 검사 중 26개 불일치를 재현했다. 수정 후 같은 60개와 권한 안내 14개가 통과했다. 첫 조회, 정상 빈 상태, 503 뒤 같은 조회의 복구, 로그인, 권한 확인, 수락 후 확인을 구분했고 가로 넘침과 브라우저 오류는 없었다. [조회 실패 320px](../assets/changes/2026-11-06-driver-web-current-transport/error-320.png) · [정상 빈 상태 390px](../assets/changes/2026-11-06-driver-web-current-transport/empty-390.png)

합성 HTTP 응답으로 운송 없음 코드, 다른 404, 401·403·503, 운송 데이터가 없는 200과 정상 운송을 확인했다. 기존 운송을 읽은 뒤 권한이 거부되면 다음 읽기가 끝날 때까지 권한 안내를 유지하는 회귀도 확인했다. 첫 Fast에서 페이지 조립 검사 한 건이 파일 길이 제한을 넘어서 실패했고 중복 import를 제거한 뒤 통과했다.

관련 시험 31건과 전체 시험 17,043건이 통과했다. 환경 조건이 필요한 17건은 생략했다. 화물기사 전용 웹 앱과 통합 0.0 빌드 오류는 0개였다. 브라우저와 HTTP 검증은 합성 자료로 수행했다. 실기기와 제품 서버·DB 검증은 미실행이다. 판본, 화면, 시험 결과는 artifacts/local/mirror-ui-assist/20261106T093121633Z-driver-web-current-transport/completion.json에 연결했다.

다음 회차에는 운영자의 국내화물 AI 배차 검토에서 조회 실패 후 다시 확인과 정상 빈 결과의 안내를 대조한다.
