# 커뮤니티 글쓰기 LLM 근거 초안

## 변경 기록

| 변경 축 | 화면 변경 여부 | 시각 증거 |
| --- | --- | --- |
| 관리자 글쓰기의 LLM 근거 초안 도구 | 화면 변경 | 실제 공통 Razor 컴포넌트의 데스크톱·모바일 간접 렌더링 확인 |
| 수집 자료와 YouTube·SNS 읽기 전용 Adapter | 간접 확인 | service 단위 테스트와 도구 실행 결과 표시 |
| 구조화 출력과 출처 URL 검증 | 간접 확인 | 허용·차단·위조 URL service 단위 테스트 |
| 현재 글과 다이어그램에 명시적으로 적용 | 화면 변경 | ViewModel 단위 테스트와 적용 버튼 상태 |
| HIOPS AI 예산·비활성 경계 | 간접 확인 | 차단 상태에서도 근거 유지, 게시 불가 응답 확인 |

## 동작 범위

- 운영자는 글의 목적, 주제, 원천, 검색어, 국가, 기간과 최대 근거 수를 정한다.
- 기본 도구는 기존 공통 수집 자료를 조회한다.
- `YouTube·SNS 다시 조사`는 운영자가 명시적으로 선택했을 때만 현재 YouTube·SNS 탭의 조건을 사용한다.
- 서버는 등록된 읽기 전용 Adapter만 실행하고 근거를 정규화한 뒤 HIOPS AI에 한 번의 구조화 출력 요청을 보낸다.
- 결과에는 글 초안, 확인 질문, 다이어그램 단계 제안, 사용 근거와 호출 비용을 함께 표시한다.
- 생성 결과는 현재 글을 자동으로 바꾸지 않는다. `현재 초안에 적용`과 `다이어그램 단계로 가져오기`는 별도의 운영자 명령이다.

## 운영 경계

- 임의 API, URL 또는 모델이 만든 tool key는 실행하지 않는다.
- 근거가 없거나 HIOPS AI가 비활성·예산 차단이면 LLM을 호출하거나 대체 초안을 만들지 않는다.
- 모델이 조회하지 않은 출처 URL을 반환하면 결과 전체를 적용 불가로 판정한다.
- 모든 결과는 검토 필요이며 게시 가능 응답을 반환하지 않는다.
- 글 등록, 예약 발행, Mongo 작업공간 저장, 다이어그램 저장, 가원장, 알림, 계약, 주문, 결제, 배차와 이메일 발송은 자동 실행하지 않는다.

## 화면 확인

실제 `CommunityAuthoringAiDraftTool`을 화면 검증용 host에서 렌더링해 다음을 확인했다.

- 1440px 데스크톱에서 글 편집기와 LLM 도구가 2열로 배치되고 가로 넘침이 없다.
- 390px 모바일에서 도구가 단일 열로 전환되고 긴 출처 URL과 본문이 컨테이너 안에서 줄바꿈된다.
- 모바일 문서 폭 380px, LLM 패널 폭 380px, 패널 scroll width 380px로 가로 넘침이 없다.
- 실제 Admin route는 서버관리자 인증 경계 때문에 로그인하지 않은 시각 검증에서는 열지 않았다.
- 브라우저 캡처 기능이 시간 초과되어 이번 기록은 PNG 대신 DOM·계산 스타일·viewport 수치와 빌드 결과를 이용한 `간접 확인`으로 남긴다.
