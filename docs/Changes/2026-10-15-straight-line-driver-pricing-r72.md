# 기사 직선거리 요금과 추천 배차 표시 r72

[승인 범위](../AI/Planning/공통/PLAN-OPERATIONS-NEIGHBORHOOD-MICRO-HUB/straight-line-driver-pricing.implementation.r72.md)와 [작업 명세](../AI/Planning/공통/PLAN-OPERATIONS-NEIGHBORHOOD-MICRO-HUB/straight-line-driver-pricing.r72.work-order.json)에 따라 음식·소형 배송의 기사 거리비와 추천 표시를 보완한다. 음식/화물 배차 엔진과 전문 원장은 유지한다.

## 기사 요금

픽업→전달 좌표의 지표면 직선거리 원값에 1,000원/km를 곱해 거리비만 원 단위 AwayFromZero 반올림한다. 포함거리 0m이며 2.34km는 2,340원이다. 기본비·최소 보전·작업비·할증은 별도 유효 정책을 따른다. 기사 접근거리·주행거리·ETA·고객 청구액과 구분한다.

음식은 기존 음식 기사 정책의 기본/최소액과 할증을 보존한다. 새 옵션 ON이며 기존 선택 합의가 없는 신규 제안에서만 직선 정책을 적용한다. 실제 경로의 안전·시간 검사도 유지하므로 직선 계산 성공이 배차 가능을 의미하지 않는다.

소형 cargo 실행은 생활 배송과 확인된 오토바이/승용차에 한정한다. 명시한 `SmallGoodsPolicyRevision`, 유효 기간, 기사 기본비·최소 지급액이 없으면 새 제안은 보류한다. 작업비·할증의 명시 정책 기본값은 0원이다. 고객 견적이나 차량 기준운임을 기사 기본비로 가져오지 않는다. 글로벌 기사 정책의 동일 가격을 원장에 한 번 동결해 추천·공개 콜이 같은 근거를 읽는다. 기존 기사별 약정은 별도 권위로 보존한다.

공개 콜을 바로 만드는 생활 배송 접수, 추천 시작과 공개 전환에서 같은 준비 절차를 사용한다. 추천·공개·전국콜 조회는 새 정책의 미준비 항목을 제시하지 않는다. 수락은 원좌표 digest·지급액·정책 근거를 재확인하며 고객 최종운임/견적 거리를 바꾸지 않고 기사 지급 예정 운임을 기록한다. 옵션을 끈 뒤에도 이미 제시한 r72 금액을 새로 계산하거나 손상 근거를 유효하다고 간주하지 않는다.

## 추천 표시

[페이지 책임](../ProjectOverview/page-docs/driver-offer-presentation-r72.md)에 따라 음식 파랑·물품/화물 빨강·창고 회색·실제 창고 작업과 배송 결합은 파랑/빨강으로 표시한다. 서버가 명시한 작업과 저장 요금만 읽으며 개인 선호나 창고 선행 bool로 복합을 만들지 않는다. 두 앱의 배너와 DriverApp 추천 목록/상세에 공통 규칙을 적용한다. 여러 미확인 알림의 개수와 열리는 최신 제안의 종류는 별도다.

## 검증 상태

구현·로컬 검증 완료. 명시한 소유 Paths의 Fast 집중 시험 246개와 Task 전체 회귀 11,636개가 통과했다. 실패는 0개이며 Task의 환경 의존 시험 16개는 건너뛰었다. 전체 `Ssalddel.v3.5.slnx` 소비 앱 빌드는 오류 0개·경고 61개다. 기존 Firebase 미설정 등 경고를 실제 푸시 연결 완료로 해석하지 않는다. 코드맵 검사와 `git diff --check`도 통과했다.

실제 공통 Razor 렌더로 음식·물품·창고·복합·미확인 5상태의 HTML/CSS를 보관했다. CUA의 브라우저 목록이 비어 있어 브라우저 화면 캡처·시각 검증은 하지 못했다. 네이티브 화면 픽셀·터치·실제 휴대폰·실운행·외부 HTTP/DB 연동은 이번 증거에 포함되지 않는다. 기존 r70 APK는 r72 변경을 포함하지 않으며 새 APK 빌드·배포·설치는 수행하지 않았다.

시작 당시 변경 파일 356개 중 이번 소유 범위 밖의 341개는 바이트 해시가 같고, Git HEAD도 유지됐다. 최종 Fast 시작 때 고정한 생산/시험/설정 소스 43개도 전체 시험 종료 뒤 동일했다. 세부 로그·렌더·보존 검사는 `artifacts/local/straight-line-driver-pricing-r72/`에, Fast/Task 실행 증거는 각각 `artifacts/local/validation/20261015-120736/`, `artifacts/local/validation/20261015-121221/`에 있다.

새 `StraightLineDriverPricing:Enabled`는 기본 OFF다. 운영 활성화·공용 DB·실제 금전·클라우드·Unity·commit/push는 수행하지 않았다. 일반 화물 전체, 독립 창고 배차와 음식/화물 혼합 운송으로 적용 범위를 넓히지 않았다.

## 다음 연결 순서

운영자가 음식·생활 소형 배송의 기본비·최소 지급액과 유효 정책을 정하고 격리 환경에서 옵션을 켠 뒤, 실제 접수→추천/공개 콜→조회→수락의 동일 지급액을 확인한다. 이어 새 APK를 빌드해 연결된 휴대폰에서 배너·상세·수락·지도 흐름을 확인한다. 직선거리 자체는 좌표로 계산하므로 지도 거리 API를 추가 호출하지 않지만, 기존 주행 경로·ETA·안전 검사는 유지한다.
