# 공개 웹의 가상 음식배달 체험

공개 정보에서 **가상 음식배달 체험**을 열면 가상 주문 번호와 현재 담당·상태를 볼 수 있다. 주문 등록부터 수령 확인까지 일곱 단계를 기존 합성 검증 원본의 순서와 상대 시각으로 재생한다. 당시 원본은 음식점 수락과 조리 시작을 한 단계로 기록했다. [원본 검증 결과](../AI/Planning/시스템/PLAN-SYSTEM-MYEONMOK-OBSERVER/observer-phone-result.r2.md)

| 항목 | 적용 |
| --- | --- |
| 진입과 복귀 | 공개 정보의 체험 링크 → `/information/food-delivery-replay` → 공개 정보로 돌아가기 |
| 화면 분류 | 로그인 없이 여는 체험으로 등록하며 상단에 **체험 · Simulation**을 표시한다. |
| 회차 | 기준 시각의 매분에 새 가상 주문을 표시한다. 원본의 수령 확인까지 첫 50초에 비례 재생하고 10초 뒤 다음 주문으로 바뀐다. |
| 화면 조작 | 잠시 멈추면 현재 화면을 읽을 수 있다. 계속하면 그때의 회차로 이동한다. |
| 자료 경계 | 브라우저가 회차별 표시 상태를 계산한다. 공개용 자료는 역할·단계·상대 시각과 가상 주문 번호로 구성된다. |

## 화면 검증

로컬 Chrome에서 공개 정보 링크의 진입·복귀, 일곱 단계, 키보드 정지·재생, 새로고침과 탭 복귀를 확인했다. 390px에서 실제 시각으로 회차가 연속 두 번 바뀌는 동안 이전 주문이 사라지는 것을 관찰했고, 320px에서는 체험 영역의 가로 넘침을 확인했다. 체험 검증 중 브라우저 오류와 쓰기 요청은 0건이었다. 공개 배포 상태는 별도다.
