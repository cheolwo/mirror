# 2026-09-24 — 메뉴 재료·HS·국내 가격·수출입 단위가액 첫 대조

## 결과와 범위

기존 [메뉴·레시피 관계](2026-09-24-menu-recipe-relations.md)를 출발점으로 재료 12종과 HS2022 6자리 후보 16개를 대조했다. 기존 MySQL의 2025년 한국 수입 통계와 HS 품명을 재사용하고, UN Comtrade의 2025년 한국 수출 통계 및 KAMIS의 2026-09-23 가격 응답을 추가 수집했다. 로컬 MySQL `hongdal_dev`의 기존 공공자료 원본/정규화 저장소를 사용했다.

이는 일반 구성 참고 재료의 **검토용 가격 조사**이다. 실제 음식점의 배합·매입가격·원산지·납품처·메뉴 원가·통관 분류가 아니다. 레시피 사본이나 운영 음식점 테이블을 덮어쓰지 않았고, Unity·영상·영업 API·자동 가격 책정에는 적용하지 않았다.

- 재료: 쌀, 밀가루, 소고기, 돼지고기, 닭고기, 우유, 감자, 양파, 마늘, 당근, 토마토, 커피.
- [대조 범위와 규격 조건](../../eng/public-data/menu-ingredient-prices/scope.r1.json): 기존 메뉴 조사 판본·식약처 사본 hash에 결속한 수동 후보. 공공 레시피에 있는 재료가 그 매장의 재료라는 뜻은 아니다.
- 코드: [메뉴재료가격조사.cs](../../eng/Ssalddel.PublicDataPortalImport/메뉴재료가격조사.cs), 기존 가져오기 Program에 `menu-prices-*`만 추가.
- 상태: 전부 `PendingHumanReview`, `PrivateReviewOnly`, `NoPublication`. 조사 데이터 공개·게임 배포·정기/유료 수집 승인 아님.

## 국내 가격 예시

아래는 KAMIS **2026-09-23** 응답이며 수집일과 구별한다. 식량·채소는 서울 코드 `1101` 요청, `p_convert_kg_yn=N`으로 원 조사 단위를 보존했다. 등급·품종이 다른 값을 임의 평균내지 않았다. KAMIS의 도매/소매·지역·단위 파라미터는 [공식 API 설명](https://www.kamis.or.kr/customer/reference/openapi_list.do?action=detail&boardno=1)에서 확인했다.

| 재료·규격 | 소매 요청 응답 | 도매 요청 응답 |
| --- | --- | --- |
| 쌀, 상품 | 62,738원 / 20kg | 59,000원 / 20kg |
| 감자 수미(노지), 상품 | 263원 / 100g | 36,600원 / 20kg |
| 양파, 상품 | 1,857원 / 1kg | 18,800원 / 15kg |
| 당근 무세척 국산, 상품 | 3,658원 / 1kg | 51,300원 / 20kg |
| 토마토, 상품 | 7,344원 / 1kg | 26,200원 / 5kg |
| 깐마늘 국산, 상품 | 10,417원 / 1kg | 대서 165,000원 / 20kg, 남도 173,000원 / 20kg |

닭 육계는 5,683원/1kg, 흰우유는 2,970원/1L로 응답했다. 다만 축산물은 이번 01/02 응답 본문이 동일했고, [KAMIS의 업종별 관심품목 안내](https://kamis.or.kr/customer/trend/economic/interest.do)는 축산물 도매가격을 조사 비대상으로 설명한다. **축산물 class=02 응답을 도매가격으로 표시하지 않으며, 두 응답을 독립 가격으로 합산·평균하지 않는다.** 축산물의 서울 한정 적용 여부도 미확인이다. DB에 별도 `research.source.caveat`를 결속했다.

국내 가격 응답 79행 중 숫자는 76행이다. 79개 독립 시세가 아니다: 같은 축산물 27행이 두 요청에 반복돼, 조사 조건 중복을 제거하면 52행(가격 50, 결손 2)이다. 닭 절단육의 원문 `0`은 무료로 간주하지 않고 null·`SourceZeroPrice`로, 당근 중품의 `-`도 null로 남겼다. 밀가루·커피의 KAMIS 후보는 이번 범위에서 확보하지 못했다.

## 수입·수출 참고 단위가액

한국 신고국 `410`, 상대국 세계합계 `0`, 연간 **2025년**, 분류 `H6 = HS2022`. 같은 방향·기간·코드의 무역금액(USD)을 순중량(kg)으로 나누고 분모가 없거나 0이면 계산하지 않는다. 아래는 보기용 소수점 3자리, DB에는 금액·중량 원값과 소수점 10자리 계산값을 분리해 보관했다.

| 뼈 없는 소고기, 냉장 | 020130 | 12.924 | 57.516 |
| 뼈 없는 소고기, 냉동 | 020230 | 6.822 | 55.598 |

`*` 수출 순중량에 UN Comtrade 추정 표시가 있다. 기존 수입 정규화 사본에는 이 표시가 보존되지 않아 수입의 추정 여부는 `Unknown`으로 유지한다. 토마토 수입은 금액 39 USD만 있고 순중량이 없으므로 단가를 만들지 않았다. 냉장 닭 수입 `NoReportedRows`는 0원/수입 0의 증거가 아니다.

수출입 차이는 수익·마진이 아니다. 품질·거래 구성·원산지·시점·수량이 다르고, 수입은 통상 CIF, 수출은 통상 FOB 계열의 평가 차이가 있다. 이 조사에서는 `primaryValue`와 응답의 CIF/FOB 값도 근거로 남기되 통화 환산·관세·유통비·세금·매장 수율을 임의 더하지 않았다. [UN Comtrade 평가 기준](https://uncomtrade.org/docs/trade-valuation/), [공식 API 안내](https://uncomtrade.org/docs/un-comtrade-api/) 참조.

## 저장과 재조회

- 기존 서비스 `평창군공공공간원본등록Service`와 `EfExternalDataIngestionStore`를 호출한다. 새 DB·서버·Migration·운영 스케줄러 없음.
- dataset: `menu-ingredient-prices-20260924-r1`.
- 190 정규화 행: 후보 12 + 수입 수치 45/결손 1 + 수출 수치 48 + 국내 응답 79 + 최초 요청 실패 이력 3 + 축산물 해석 주의 2.
- 서로 다른 원본 hash 12개. 수집 파일 15개에는 같은 `{}` 실패 본문과 같은 축산물 본문도 있어 내용 기준 중복 제거된다. 파일별 요청 조건/시각은 receipt에 따로 보존한다.
- 로컬 원본·receipt·전체 조회 결과: `artifacts/local/public-data/menu-ingredient-prices/20260924-r1/`. 비공개 Git 제외. KAMIS의 인증값 반향 가능성이 있는 `condition`을 제거하고 `data`만 보존하며, 원문 전체 보존이라고 주장하지 않는다.
- receipt SHA256: `3c49e51aeba20f0e51d6a83639ec811b656039a308cae6e140950ec9b0ab39ac`.
- 수입 사본은 원래 RecordKey·원본 hash·수집 시각을 연결한다. 재조회 날짜를 원래 수집 날짜로 바꾸지 않는다.
- 수출 최초 일부 요청 실패 후 한 번의 제한된 재조회로 16개 모두 확보했다. 최초 오류 세부는 예외 종류만 남아 있어 당시 HTTP 상태를 추정하지 않는다. 재조회 결과와 실패 이력을 구별한다.

예를 들어 다음 조회로 수치·단위·주의 상태를 읽는다. `DimensionKey`의 요청 class와 실제 가격 조사 채널을 혼동하지 않도록 함께 `research.source.caveat`를 조회해야 한다.

```sql
SELECT SourceId, MetricCode, DimensionKey, NumericValue, UnitCode,
       EvidenceAsOfUtc, TextValue, QualityCode
FROM public_data_normalized_records
WHERE DatasetId = 'menu-ingredient-prices-20260924-r1'
  AND (DimensionKey LIKE '%ingredient=onion;%'
       OR DimensionKey LIKE '%hs6=070310;%'
       OR MetricCode = 'research.source.caveat')
ORDER BY MetricCode, DimensionKey;
```
