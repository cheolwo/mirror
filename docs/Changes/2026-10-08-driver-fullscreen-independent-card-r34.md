# 기사 전체 화면 지도와 독립 하단 카드

사용자는 우선순위 1·2번을 승인한 뒤 카드 높이에 맞춰 지도를 조정하지 말고, 지도는 그대로 두면서 카드만 접었다 펼치도록 정정했다. [기사 페이지 책임 r10](../ProjectOverview/page-docs/driver-workspace-sections-r1.md#전체-화면-지도와-독립-하단-카드-r10--최신-사용자-정정)에 따라 기존 수행 화면을 보완한다.

## 바뀐 표시와 유지한 업무

- 배달 수행 영역은 상단 진입 행과 본문 행 전체에 걸쳐 같은 네이버 지도 인스턴스를 표시한다. 카드와 지도는 별도 높이 행 대신 같은 영역에 겹쳐 배치한다. 앱의 시스템 안전 영역은 유지한다.
- 지도 위 상단의 기존 배달·내 정보·추천 알림과 범례·현위치는 유지한다. 투명한 header·도구의 빈 공간은 지도 입력을 통과시키고 실제 버튼은 입력을 받도록 배치한다.
- 하단 카드만 내용·고정 주 행동을 포함한 높이를 제한한다. 기존 접힌 요약·펼친 단계별 정보·본문 스크롤·상태별 주 행동을 재사용한다. 접힘40%/펼침70%는 카드의 상한이며 지도 높이를 빼는 계산이 아니다.
- 지도 범례·현위치 높이를 예약해 카드와 지도를 조정하던 계산을 제거했다. 카드 접기/펼치기는 지도 크기·중심·줌·카메라 맞춤·따라가기를 변경하지 않는다. 사용자가 허용한 카드 뒤의 핀·경로 가림을 자동 보정하지 않는다.
- 내 정보는 기존 상단 진입 아래의 독립 표시로 유지한다. 완료 목록·상세·3일 고객 정보 열람·현장 중단·인증/복귀·업무 수명·r33 아이콘·금액/권한/명령을 보존한다.

제품 변경은 `MainPage.xaml`, `MainPage.xaml.cs`, `MainPageModel.FoodPresentation.cs` 세 파일이다. 기존 지도 handler·카메라·경로 조회·GPS 취득·API/DB는 수정하지 않았다. 목적지/단계 전환 때의 기존 경로 맞춤과 현위치 버튼, 사용자가 탐색한 중심·줌 보존은 유지한다. 경로 대기 중 추가 핀 맞춤은 이번 최신 정정 범위에서 구현하지 않는다.

## 검증과 APK 경계

수정 직전 세 파일 사본과 비교해 기존 Binding·명령·가시/권한 조건·클릭·마커·스크롤 연결이 보존됨을 독립 검토했다. 지도 인스턴스, 카드 본문과 주 행동 footer, 프로필 본문은 기존 subtree와 동일하며 수명/예외/navigation 코드는 이번 배치 계산 밖에서 동일하다. 차단 결함은 발견하지 못했지만 이 검토는 실제 Android 측정·입력·표시 순서의 실행 증거가 아니다.

기존 카드 높이 시험을 새 계약에 맞추고 잘못된 측정값을 보완했다. 이동·픽업 대기·전달 세 상태와 따라가기·지도 탐색 두 모드에서 카드 접기→펼치기가 선택 배달, marker/route source, 지도 중심·줌·GPS 상태·재중앙화 요청 및 지도 관련 변경 알림을 유지하는 회귀를 추가했다. 해당 모델 시험도 native 지도 크기·카메라 paint의 직접 시험으로 표현하지 않는다.

Fast 관련 187개와 Task 전체 8,608개가 통과했다. 실패는 0개이며 격리 Mongo 시험 연결 조건이 없는 2개는 미실행이다. 기사 Android 빌드와 전체 `Ssalddel.v3.5.slnx` 빌드는 오류 0개이며 전체 빌드의 기존 패키지 경고 64개는 남아 있다. 검증 전후 제품 3파일과 회귀 시험 1파일의 SHA-256은 일치한다. 실행 근거는 `artifacts/local/validation/20261008-091549/`와 `20261008-091829/`, 결과·구조 보존 대조는 Git 제외 `artifacts/local/fullscreen-map-independent-card-r34-20261008/`에 보관한다.

r34 개인 Debug APK(`0.1.34/34`) 포장과 검증을 완료했다. r33의 별도 보존 소스 2,614파일 중 승인한 제품 3파일만 바꿨으며 나머지 소스와 r33·r32·r31 원본/APK를 보존했다. 양 ABI의 내장 XAML에서 지도·카드가 같은 영역에 있고 상단 진입/도구가 겹쳐 표시됨을 대조했다. 컴파일된 4인자 카드 높이 계산과 카드 배치 갱신의 지도/카메라 setter 부재, 기존 아이콘·GPS·교통정보 OFF·개인 지도 입력·Debug 서명을 확인했다. Fast/Task 결과는 승인 제품 소스와 실제 APK 지문에 결속했다. 이 내장 구성 확인은 실제 화면·지도 터치 실행 검증이 아니다.

로컬 파일은 `artifacts/local/fullscreen-map-independent-card-r34-20261008/apk/0.1.34-34/handoff/driver-usb-debug.apk`이며 153,302,967 bytes, SHA-256은 `21aaeb029890ee8a51a1706eab83c709728d7c8ce8b0989f74f88d20ab037ae2`다. `apk/build-result.json`과 `apk/bound-validation.json`에 최종 검증과 시험 결속을 기록했다. 개인 로컬 USB 시험용 Debug APK이며 설치와 공개 배포는 하지 않았다.

사용자는 추가 에뮬레이터 검증 없이 다음 휴대폰 USB 연결 때 검증·설치하도록 요청했다. 이번 수정의 실제 화면, 지도 터치 통과, 카드 접기/펼치기 때의 native viewport·카메라 불변, 좁은 화면·테마·주 버튼 접근과 내 정보/내역 복귀는 그때 확인한다. 애저·실운행·실제 도로/GPS 안정성·금융 지급·commit/push와 구분한다.
