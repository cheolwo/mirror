## 적용 범위

- YouTube 영상은 글의 중심 자료로 두고 Reddit RSS와 Apify 기반 Reddit·X·Instagram·Facebook 공개 자료는 하위 출처 묶음으로 수집한다.
- Apify 토큰이 없는 환경에서도 무료 Reddit RSS 원천을 선택할 수 있으며, 외부 수집 실패는 원천별 실패 내역으로 남긴다.
- 조사 결과, 선택한 출처, 글 초안, 공동행동 초안, 수입 여정과 업체 후보는 하나의 Mongo 작업공간에서 revision으로 갱신한다.
- 서원 글은 곧바로 거래나 원장을 확정하지 않고, 알아볼 사람·업체·조건과 다음 질문을 정리하는 운영자 초안으로 사용한다.
- 예약 발행은 RDB의 게시 상태와 재시도 시각을 이용하고, 공개 조회에는 발행 완료 글만 나타나도록 한다.
- 업체 후보는 공개 출처와 검증 상태를 함께 기록하며 플랫폼 제휴나 운영 가능 업체로 자동 간주하지 않는다.
- Win-Win 점검과 근거 그래프는 의사결정을 대신하지 않는다. 참여자가 입력한 비용·노동·위험과 원문 자료의 한계를 드러내는 작성 보조 도구다.

## 구조 정리

- 글쓰기 보조 도구 ViewModel을 도구 종류, SNS 조사, 다이어그램 책임으로 분리했다.
- YouTube Mongo 작업공간 저장소를 CRUD·동시성 제어, DTO-문서 매핑, Mongo 문서 모델로 분리했다.
- Admin 페이지 카탈로그의 필터·상태 조립과 seed projection을 별도 파일로 분리했다.
- ABS SDMX 응답 읽기와 농수산 정보 overview 생성을 공급자 service에서 분리했다.
