# 영상만 제공받아 위치 후보를 분석하고 일일 자료를 연결하기

2026-10-26. [직접 승인 범위와 검증 기준 r111](../AI/Planning/시스템/PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION/video-diorama-daily-connection.implementation.r111.md).

## 바뀐 동작

- 새 OCR 표본 실행이 디코더의 정수 PTS/time_base·선택 순번·프레임 hash·원본 MP4 시간표·별도 시계 근거를 보존한다. 기존 실수 초와 영수증 호환은 유지하되 구형 결과를 정밀 시계로 재사용하지 않는다. 유일 비디오·0원점·연속 CFR 지원 밖은 추정하지 않고 보류한다.
- 일일 배치 연결 도구가 기존 접수·실행 영수증·기존 선분/외관 결과를 원본 SHA별로 검증해 새 비공개 manifest·summary로 묶는다. refresh는 이전 판본을 보존하고 현재 입력으로 다시 검사한다. 원본은 stat만 확인하며 별도 원본 복사/해시·DB·사용자 승인·접수 state/공통 포인터 갱신은 하지 않는다.
- 건물 대응 도구가 공개 원형과 현재 지도 도형을 기존 ENU 변환으로 대조한다. source ID·공개 원형 참조·현재 base/content hash·좌표계를 검사하고 유효하지 않은 도형을 수리해 맞추지 않는다. 겹침은 후보이며 동일성 확정이나 Unity 적용 승인이 아니다.
- 운영 절차·정의 JSON·배달 공통 AGENTS를 실제 도구와 연결했다. 실제 위치 판독은 Codex가 공개 간판·표지·기존 주소와 시간순 화면을 대조한다. 무인 전체 의미/위치 추론 실행기나 가중치 학습을 구현한 상태와 구분한다.

기하 비교는 기존 설치된 GIS 자원과 [공유 영역 연산](https://shapely.readthedocs.io/en/stable/reference/shapely.intersection.html)·[도형 유효성 검사](https://shapely.readthedocs.io/en/stable/reference/shapely.is_valid.html)를 사용한다. Unity Scene·EditorPrefs·원본 Synty 자산은 변경하지 않았다.

## 실제 원본 구간에서 확인한 위치 후보

기존 0112의 300.300~355.355초 실제 PTS 사진 12장을 직접 판독했다. 정다운한의원·서울앞선치과 → 우리한의원·이브자리의 순서와 공개주소를 대조해 용마산로 교차부에서 영화사로4→16 방향 상업도로로 진입하는 후보를 기록했다. 동명 매장·옆길 표지·시선 변화와 차량 회전의 차이·지도 노드 공백은 대안/미확인으로 보존한다.

영화사로 선분 후보 `GJ-S000015`·`GJ-S002389`·`GJ-S002411`은 공통 관측창에서 찾은 탐색 자료다. 용마산로 교차부의 별도 context와 가장 가까운 자전거도로 후보를 실제 차량 경로로 자동 채택하지 않았다. 선분별 진입/이탈 시각·차량 GPS·전체 원본 816.34초 경로는 미확정이다. 관측창 55.055초를 연속 시청 시간이나 중복 없는 경로 길이로 집계하지 않는다.

새 프레임 추출·원본 전체 해시·원본 복사는 0이다. 기존 원본의 시간표를 따로 읽어 12개 PTS와 1/30000 기준을 확인했고, 실제 카메라 원본 전체 디코딩과 구분했다. 저장된 native 프로젝트 31개·프로젝트 집합·현재 웹 보호 메모·원본 보호창을 대조했다. 미저장 앱 상태는 미확인이다.

## 현재 공간 자료의 경계

기존 외관 연구 3개와 현재 Overture 2,247개 도형을 대조했고 잘못된 도형은 0건, 이 판본에서 겹치는 대응 후보도 0건이었다. 가까운 건물로 대신 배정하거나 과거 ALD 사본이 어디에도 없다고 단정하지 않았다. 정본 적용은 0건이다. 원자료 범위/판본 및 정확 대상 결속은 후속으로 남긴다.

## 검증 마감

집중 통합 시험 **160/160**을 통과했다. 표본/OCR 48·원본 시간표 6·접수/재개 35·외관 근거 25·건물 대응 17·일일 배치 29이며 실패·생략 0이다. 시험 중 소스 hash 불변도 확인했다. 일부 합성 영상은 실제 FFmpeg 디코더를 사용했으나 실제 카메라 원본 전체 디코딩은 수행하지 않았다.

예비 실행 뒤 독립 검토에서 거절 파일의 오류 기록 재해시 우회·정수/표시 시각의 공동 오기 허용·이전 manifest의 refresh 중 변경 누락을 발견해 보완했다. 공개 원형의 JSON pointer 안에서 장소/GIS ID의 유일성·도형 동일성도 검증한다. 해당 반례 회귀와 출력 중단 시 반쪽 최종 폴더를 남기지 않는 회귀를 포함한다. 예비 `daily-link-r1/r2`는 이전 코드 근거로 보존하고 마감 증거로 재사용하지 않았다.

최종 실제 `daily-link-r3/r4`에서 기존 접수 원본 13개·구형 실수 시각 표본 761개의 근거를 연결했다. 구형 시각은 정수 PTS 검증으로 승격하지 않았다. r4 재검사 신규 SHA 0·신규 결속 참조 0·재사용 단계 26개이며 현재 입력/manifest 검증을 통과했다. 이 실행은 접수/영수증의 읽기 결속이고 13개 원본을 새로 판독·위치 확인한 결과가 아니다.

최신 결과 포인터는 배달 `edit-kit/private/video-diorama-daily-batch/current-review.json`, 보고서는 `20261026-r2/결과와-다음작업.html`, 검증 묶음은 같은 폴더 `result.private.json`이다. 실제 시험·0112 구간 판독·원본 시계·일일 연결·건물 후보를 각각 참조한다. 원본·지도·사용자 승인·Premiere 컷/마커·운영 DB·Unity 장면·공개 상태는 변경하지 않았고 commit/push는 수행하지 않았다.
