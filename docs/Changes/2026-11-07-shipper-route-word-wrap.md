# 화주 의뢰 상세의 상·하차 주소 줄바꿈

390px 가상 의뢰의 **경로**에서 상·하차 시설명이 글자 중간에 끊겼다. 480px 이하에서는 상·하차 주소의 띄어쓰기를 우선해 줄바꿈한다. 카드보다 긴 한 단어는 카드 안에서 줄바꿈된다. [공용 요약 스타일](../../Ssalddel.Ui.Common/Areas/App/Components/Transport/ShipperRequestSummaryScreen.razor.css) · [이전 390px 주소와 운임](../assets/changes/2026-11-06-shipper-detail-cargo-name-wrap/route-cost-390.png)

같은 가상 의뢰의 390px 화면에서는 두 시설명이 각각 한 줄에 보였다. 주소 전체는 각각 두 줄에서 세 줄로 늘었다. 결제 예정액 142,000원과 최종 운임 138,000원, 같은 의뢰 재조회와 목록 2페이지 복귀를 확인했다. [2026-11-07 390px 가상 의뢰의 주소와 운임](../assets/changes/2026-11-07-shipper-route-word-wrap/route-cost-390.png)

320px에서는 하차 시설명이 한 줄에 들어왔고 주소 전체 줄 수는 유지됐다. 카드보다 긴 공백 없는 주소도 320px 안에서 모두 표시됐다. 1440px의 시설명과 주소 줄 수는 유지됐다. 정상 주소와 긴 주소를 합쳐 수정 전 61개, 수정 후 63개 브라우저 검사를 통과했다.

Fast 관련 시험 33개와 화주 소비 화면을 포함한 통합 3.5 Task 전체 시험 17,051개가 통과했다. 별도 환경이 필요한 17개는 생략했다. 빌드 오류는 0개였고 Fast 경고는 0개, 통합 빌드 경고는 62개였다.

격리 브라우저에서 공용 요약 화면과 실제 화주 화면 배치에 가상 조회를 연결했다. 제품 서버·DB와 실기기는 미검증이다. 음식기사의 기존 웹 미리보기는 배달 내역의 조회 모델만 재사용하므로 실제 음식기사 화면 확인은 보류했다. 전후 캡처·측정·시험 근거는 `artifacts/local/mirror-ui-assist/20261106T171627624Z-shipper-route-word-wrap/completion.json`에 연결했다.
