# 국내화물 AI 배차 검토의 의뢰 선택 상태

기존에는 선택한 의뢰의 버튼 모양과 지도 핀이 바뀌어도 브라우저 접근성 정보에 버튼의 눌림 상태가 없었다. [국내화물 AI 배차 검토](../../SsalddelAdmin/Components/Pages/DomesticCargoDispatchAIReview.razor)에서 의뢰별 기존 선택값을 **선택** 버튼의 눌림 상태로 전달한다. [390px 가상 의뢰 화면](../assets/changes/2026-11-07-operator-dispatch-map-height/dispatch-review-390.png)

2026-11-07 로컬 Chrome의 320px·390px·1280px에서 운임 12,000원과 42,500원의 가상 의뢰 두 건을 대조했다. 처음에는 첫 의뢰가 선택됐다. Enter로 첫 의뢰를 해제하고 Space로 둘째를 선택한 뒤, 터치나 클릭으로 첫 의뢰도 선택했다. 각 버튼의 눌림 상태가 해당 상·하차 핀과 일치했고 키보드 초점은 조작한 버튼에 남았다. **새로고침**으로 기존 초기 선택을 다시 읽었다.

전후 선택 검사 각각 192개와 조회 상태 회귀 검사 128개가 통과했다. 선택 조작 중 추가 조회와 쓰기 요청은 0건이었다. 같은 폭과 선택 상태의 전후 캡처 세 쌍은 해시가 일치했다.

Fast 관련 시험 16개와 통합 1.5 Task 시험 17,054개가 통과했다. 환경 조건이 필요한 시험 17개를 건너뛰었다. 빌드 경고는 Fast 0개, Task 8개였고 오류는 각각 0개였다.

브라우저의 접근성 트리에서 상태를 확인했다. 실제 보조기기, 제품 서버·DB와 판단 저장은 미검증이다. 가상 조회 기록과 전후 캡처는 `artifacts/local/mirror-ui-assist/20261107T011605034Z-operator-dispatch-selection-state/validation.json`에 연결했다.
