# 최신 변경과 검증 판본 정리

사용자가 제안된 우선순위1번만 진행하도록 요청했다. [통합1.0 최신 검증 판본](../Versions/unified-1.0/current-validation-baseline.md)에 최근 변경을 업무 맥락별로 묶고 현재 소스·자동시험·마지막 서버 실행·역할별 기기 기록을 분리했다. [업무별 마감표](../Versions/unified-1.0/checklist.md)는 r14~r28의 실제 근거와 남은 확인을 반영했다.

정리 전 브랜치 `dev/mirror-integration`, HEAD `8a97384604e6c68a1b00fc71a612d699a3651825`, Git139상태항목/개별155파일의 지문을 로컬에 보존했다. 이번 작업의 수정 대상은 이 문서와 최신 판본 문서·마감표·통합1.0/변경 목차·CURRENT_WORK의 문서6개다. 기존 제품 코드·설정·원본·앱·서버/DB·기기·Git index를 보존한다.

## 근거 재확인

- 배차 근거 r25의 최종 범위10/10과 음식점 r28의13/13 소스가 현재 해시와 일치한다. r28 Windows EXE/DLL도 당시 기록과 일치한다. 이 좁은 재대조를 전체 빌드 입력/실제 서버·휴대폰 완주로 확대하지 않는다.
- 기존 Fast TRX536통과와 Task TRX16,681통과·실패0·환경17생략을 다시 읽었다. 새 빌드·자동시험 실행 결과는 아니다.
- r24·r26·r27의 일부 소스는 후속 판본으로 바뀌었다. 해당 시험을 당시 이력으로 보존하고 현재 판본으로 승계하지 않는다.
- 마지막 화물 서버·세 역할APK128·기사131·미설치 알림133·합성 HTTP 지도135와 최신 음식점 Windows 시작/Android 빌드를 구분했다. 같은 서버·전체 앱의 최신 통합 패키지는 이번에 제작하지 않았다.

## 문서 검사와 범위

이번 문서6개의 링크와 좁은 Fast/공백 검사를 실행하고, 정리 전 파일 중 허용 문서 외 내용 변경0·HEAD/index 불변을 확인한다. 실제 결과와 파일 지문은 로컬 `artifacts/local/unified-validation-baseline-20261028-r1/verification-summary.json`에 기록한다. 문서 Fast가 빌드/시험을 생략하는 것은 문서 검사의 범위이며 제품 회귀를 새로 통과한 것으로 세지 않는다.

신규 기능·서버/앱 실행·휴대폰 설치·재빌드·실물 출력·금융·외부 발송·운영 활성화·stage·commit·push·배포는 실행하지 않는다. 현재 작업표의 다른 사용자/스레드 변경은 보존한다.
