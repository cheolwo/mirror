## 보완한 경계

- Session은 로그인 의도·계정 수명·토큰 판본을 구분해 캡처한다. 로그인 응답은 최신 의도에, refresh 성공/거절은 정확한 요청 토큰 문맥에 결속한다. 같은 계정의 새 로그인도 이전 요청과 구분한다.
- 로그인 시작만으로 기존 인증을 지우지 않는다. 현재 계정의 정상 토큰 갱신이 진행 중인 최신 로그인을 무효화하지 않게 하고, 로그아웃은 아직 익명인 상태에서도 진행 중 로그인을 무효화한다.
- 최초 장치 복원·갱신 대기 전에도 계정/로그인 세대를 보존한다. 저장된 계정의 정상 복원은 허용하되 대기 중 로그아웃·새 로그인이 끼면 이전 로그인/업무 요청을 시작하지 않는다. 로그인 저장 중 같은 계정의 정상 갱신은 로그인 성공을 취소하지 않는다.
- 저장·삭제·복원은 직렬화하고 읽은 값을 로컬 snapshot으로 모은 뒤 현재 판본일 때만 메모리에 반영한다. 최신 저장/삭제가 마지막에 남으며 이전 작업은 새 세션의 성공이나 변경 알림으로 보고하지 않는다. 프로세스를 저장 도중 강제 종료하는 영속 원자성 검증은 아니다.
