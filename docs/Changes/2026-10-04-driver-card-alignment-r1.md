# 기사 수행 카드 정렬 보완

2026-10-04. 이전 [수행 단계별 화면](2026-10-04-driver-stage-cards-r1.md)의 접힌 요약에는 카드 표면이 없고 상태 제목도 카드 밖에 있었다. 320 DIP·글자 200% 화면에서는 긴 주소 전체의 굵은 글자와 지도 미설정 안내/도구의 겹침이 정렬을 흐트러뜨렸다.

[페이지 책임 카드 r6](../ProjectOverview/page-docs/driver-workspace-sections-r1.md#카드-정렬-보완-r6--구현-전-책임-카드)에 따라 접힌 요약도 흰 표면·얇은 테두리로 묶고, 단계 제목을 접힌 요약 또는 펼친 픽업/전달 카드 안으로 이동했다. 카드 내부 여백은 16 DIP로 통일했다. 주소는 본문 16·일반 굵기·왼쪽 정렬·줄바꿈/줄높이 1.15를 사용하며 전체 주소와 접근성 글자 확대를 유지한다. 제목·음식점명·금액의 강조는 유지한다.

네이티브 지도는 기존 `NaverMapReadiness.Status == Ready`를 읽기 전용 View 표시 상태로 투영한다. 실제 타일 준비 전에는 지도 범례·현위치를 숨겨 미설정/로딩/오류 안내를 가리지 않는다. UI 스레드와 연결 해제 가드를 유지하고 준비 상태 변경 시 예약 높이를 다시 계산한다. 지도 준비 콜백과 타일 로드를 구분하며 GPS 복구·경로 안내는 본문에서 계속 표시한다.

제품 변경은 `MainPage.xaml`, `MainPage.xaml.cs`, `FDriverNativeMapView.cs`, `FDriverNativeMapViewHandler.Android.cs` 4경로다. 상태 전환·가능 행동·접기 의도·전체 주소·배달료·서버/API/DB·경로/카메라·다음 건 선택은 보존했다. 새로운 기능이나 정보를 추가하지 않았다.
