## 확인 범위

- 자동 게시 기능은 기본 비활성 상태이며 운영 설정으로 명시적으로 활성화한다.
- KAMIS 글은 출처·조사일·단위·등급을 표시하고 검증된 관측값이 없으면 게시하지 않는다.
- 성찰문은 특정 사상가의 실제 인용으로 가장하지 않고 시스템 작성 글임을 밝힌다.
- 활동 요약은 완료 원장 유형별 건수만 사용하며 참여자, 주소, 금액, 증빙과 거래 원문을 포함하지 않는다.
- 같은 출처와 기간의 글은 결정적 시스템 작성자 식별자로 중복 게시를 막는다.

## 검증

- `dotnet build Hongdal/Hongdal.csproj --no-restore`
- 자동 게시·배치 실행기·기존 원장 완료 게시 관련 테스트 10개 통과
- 전체 테스트 1,287개 중 1,286개 통과, 기존 Apify 배열 응답 테스트 1개 실패

이 커밋은 서버 배치, API 응답 분류와 운영 문서를 다루며 Razor 화면 변경은 포함하지 않는다.
