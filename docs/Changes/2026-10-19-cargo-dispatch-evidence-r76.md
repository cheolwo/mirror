## 구현과 책임

- 기존 용달기사의 비공개 적재 JSON과 독립 판본을 추가한다. 관리자 기존 차량 API의 기사별 `actual-loading` 조회/수정에서 현재 실차·차종, 확인한 값과 근거·장비·기간, 기대 판본을 검사한다. 법정 자격 승인만으로 물리 적재 확인을 만들지 않는다. 새 실제 수치는 등록하지 않는다.
- 기존 조율 Factory는 공통 시각과 실제 순차 조회 구간·주문/기사의 비교 지문을 보존한다. SQL과 위치 저장소를 하나의 원자적 snapshot으로 부르지 않는다. 조회 때의 미확인과 실제 차단을 구분한다.
- 기존 수락 구간 검사를 순수 공통 검사로 추출해 초기 적재부터 각 typed 상하차를 검사한다. 원 decimal 중량·r75 보수 CBM·물리/운영 상한·비적층 면적을 재사용하며 문자열 ID 끝부분 비교로 화물을 연결하지 않는다.
- 기존 조율기의 제안 전체를 기존 일정 삽입기와 공유 구간 검사로 재검증한다. 기존 수행 순서를 보존하며 가능한 연속/분리 삽입을 비교한다. 탐색 범위의 안전한 계획이지 전체 최적성 증명은 아니다. 작업시간 누락을 확인된 0분으로 쓰지 않으며 비용 누락도 0원으로 합산하지 않는다. 검토 요약에는 고객 주소·좌표를 복제하지 않는다.
- 상하차 작업시간과 준비 대기를 전체 소요시간에 포함하고 작업 완료 시점으로 마감을 검사한다. 새 검증 계획은 명시된 작업시간이 필요하다. 구형 일정의 작업시간 없는 호환 계산은 한계로 남긴다.
- 추천 저장은 Serializable/기사별 잠금 안에서 현재 근거·수신·업무·자격·적격성·보수를 다시 확인한다. 계획과 source 근거를 함께 저장하며, 저장 전 최신 검사에도 명시 작업시간을 넘긴다. 추천 준비가 기사 경고 동의를 대신하지 않는다. 수락의 라운드·응답 유실·본인 중복 복구를 유지한다.
- 기존 검토 도구의 기본 28사례는 유지하고 `--plan-review`로 새 미검토 5사례를 추가한다. 합성 경로/물리값임을 표시하며 실제 일정·적재 순수 검사를 실행한다. 가능한 계획만 모델에 보내고 모델 원문·검사·규칙·코덱스 의견·사람 판정을 분리한다. 계획 사례의 순수 검사를 규칙 배차 선택 실행으로 표시하지 않는다. 모델 재실행 뒤 이전 승인을 내보내지 않는다.

## 통합 점검에서 보완한 연결부

- 새 계획의 상하차 시간을 추천 저장 직전 검사에도 넘긴다. 이 값 없이 구형 계산이 적용되던 연결을 보완했다.
- 추천 기록으로 대기 순위가 초기화되어도 추천 자체를 무효화하지 않는다. 수락 안전 조건의 지문과 당시 순위 관측을 구분하고 배치 입력에는 둘을 함께 결속한다.
- 현재 수행은 추천·일정·수락 모두 양쪽 기사 ID와 큐 확정 상태, 정본 의뢰 ID로 조회한다. 취소/해제 뒤 남은 기사 이력을 새 일정으로 만들지 않으며, 반납 잔량 책임은 기존 조회를 공유해 계속 차단한다. 근거가 없는 1,440분 상한도 제거했다.

- 참여 관문 비활성 및 수량/회전/적층 원입력 누락은 확인 완료로 승격하지 않는다. 구형 입력의 호환 계산과 r76 전체 계획의 확인 상태를 분리한다.

- 기존 차량 관리 Controller의 실행 기능 분류 누락을 보완해 국내 운송 기능 경계를 소비한다. 기존 관리자 전용 정책과 기능 OFF를 유지하고, 다섯 동작의 OFF/ON 필터를 대조한다.

## 운영에 적용하기 전

GPS 관측 갱신이나 같은 기사의 첫 수락으로 현재 근거가 바뀌면 이전 추천은 보류하고 현재 판본으로 다시 추천해야 한다. 이동 중 연속 갱신과 동일 묶음의 연속 수락까지 운영 실증한 상태는 아니다.

생활배송 간편 입력에는 부피/포장 제원을 받지 않는 경로가 남아 있다. r75 시나리오 회귀는 이 입력 그대로 수락 차단을 먼저 검사한 뒤 명시 합성자료를 보강해 흐름을 재개한다. 이 포트가 실제로 제원을 수집했거나 자동 보강됐다고 표시하지 않는다.

새 nullable 3열 migration은 준비만 했다. 실제 DB 적용, 기사별 실측/근거 확인, 기본 비활성인 업무 정책의 운영 준비, 상하차 작업시간 입력, 허용 우회·조합 대기·최대 묶음·가중치의 사람 결정은 별도다. 미확인 실차/작업시간/상태를 합성값으로 채워 자동 추천을 켜지 않는다. 실제 단말·외부 알림·실수납/지급·가중치 학습·공개 운영·Unity/영상·commit/push는 수행하지 않는다.
