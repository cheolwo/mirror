# 배차 학습자료 1차 제작 r51

사용자의 `학습 자료 제작을 좀 시작` 요청에 따라 [수락 설계](../AI/Planning/공통/PLAN-OPERATIONS-DISPATCH-CORE/training-materials.implementation.r51.md)와 [작업 명세](../AI/Planning/공통/PLAN-OPERATIONS-DISPATCH-CORE/training-materials.r51.work-order.json) 범위의 자료 제작을 완료했다. 제품 서버·앱·기존 정책·원본 기록은 바꾸지 않았다. 모델 호출·가중치 학습·사람 승인·운영 적용은 모두 0이다.

## 원자료와 답안의 의미

r50의 중랑·동대문·광진 504건·339지점·확인 메뉴 488항목을 출처로 재사용했다. 메뉴는 출처 대장에만 보존하며 모델 입력에는 넣지 않는다. 가상 수요·기사·시간·전달점을 결합해 현재 음식 수요 참여 정책과 조합 검토 서비스, 후속 픽업 fixture를 직접 실행했다. 답안은 `CurrentPolicyDraft / Pending / eligibleForTraining=false`이며 최적 배차나 사람이 승인한 정답이 아니다.

전달 위치는 공개 매장 주변의 합성 오프셋이다. 기하 근사·합성 차량 경로를 실제 도로·고객 위치·기사 GPS로 표시하지 않는다. 역사 메뉴에서 현재 가격·조리 시간·무게를 추론하지 않았고 방문 요약 메뉴를 개별 주문에 배분하지 않았다. 현재 기본 처리율 3.5건/시간도 유지했다.

## 산출물과 검토

[도구 안내](../../eng/local-dispatch-ai/TrainingMaterialRunner/README.md)의 별도 .NET 생성기와 Python 검사기를 사용한다. Git 제외 비공개 루트는 `artifacts/local/local-dispatch-ai/training-materials-r51/`다.

- 원시: `raw/c090994c7fd22380e98c1bd66ffa7586b46ee72b05fe36b0c5126b3f8fdd7564/`
- 후보·요약·검토서: `compiled/2b6f24ce0fb5f8592f54fac40b8584a2d61b2c251a7ad3d997a8e4b2f7ed5f73/`
- `candidates/train.jsonl`, `validation.jsonl`, `test.jsonl`은 익명 수치·토큰·정책 코드로 된 messages와 별도 감사 메타데이터를 보관한다. 실제 주소·좌표·상호·메뉴·원주문 ID는 messages에 없다.
- `ready/`의 세 파일은 모두 0행이다. 사람 승인이나 학습기 연결 기능은 추가하지 않았다.
- `review.md`의 대표 24개는 상황·기사 전원·대기 시간·요청 순서·선택/보류 이유를 한국어 표로 보여 준다. 두 주문 검토에서 단건이 선택된 예외와 격리된 후속 픽업 사례도 포함한다.

사용자가 사례 번호로 판단·수정 의견을 주면 입력·답안·출처 해시에 연결된 별도 검토 기록으로 축적하는 것이 다음 단계다. 현재 정책 답안을 자동 승인하거나 기존 Ollama 응답을 정답으로 재사용하지 않았다.

## 검증과 한계

별도 도구 최종 빌드는 경고 0·오류 0이다. Python 반례 시험 45개가 통과했다. 개인정보 추가 필드·잘못된 타입/토큰·NaN·중복 JSON 키·분할 오염·중복/상충 답안·소스 누락/변조·허위 승인·출력 변조·요청 순서·검토표를 확인했다. 원시 생성과 후보 컴파일을 각각 다시 실행해 동일 바이트 재사용도 확인했다.

처음 원시 생성의 `SameFoldValidPairUnavailable` 실패와 컴파일의 필수 교사 의존 소스 두 개 누락에 따른 `SOURCE_HASH_SET_MISMATCH` 실패를 로그로 보존했다. 각각 실제 단건 선택 보존과 필수 소스 목록 일치로 보완했으며 교사 정책·거리 제한·해시 검사를 약화하지 않았다.

독립 감사는 원시 4,041건·정책/자료 소스 70개·익명 입력·분할·답안 토큰을 대조한다. 두 주문 검토의 선택 위치는 첫째 152·둘째 171·셋째 181개여서 항상 첫 항목이 답이 되는 위치 지름길을 줄였다. 단건 504개는 유일 후보라 이 분포에서 별도로 해석한다. 검사 결과는 `independent-raw-audit.json` 및 최종 감사 기록에 보존한다.

Fast `artifacts/local/validation/20261011-174350`와 Task `20261011-174402`는 차이 검사를 통과했다. 현재 검증 스크립트가 `eng/`와 문서를 guidance-only로 분류하므로 이 두 실행은 제품 build/test를 생략했다. 이를 보완하는 실제 도구 실행 증거는 별도 .NET 빌드·Python 45개·4,041건 생성·4,032건 컴파일·각 재실행이다.

`final-integrity-audit.json`에서 시작 때 dirty 102개 중 허용 범위 밖 98개와 출처 소스 70개 불변, 후보의 504원주문·339지점 보존, 원주문/지점 교차 분할·후보 입력 중복 0, 연결 출력 8개 해시·ready 0바이트·문서 링크 17개·Git 제외를 독립 확인했다. 새 자료와 검토 상태는 비공개 로컬에 보관하며 기존 기록을 덮어쓰지 않았다.

자료 제작은 모델 학습·판단 개선·실배차·실제 알림·단말 설치·Azure 배포·Unity·외부 이체·커밋/푸시와 별개다. 전체 제품의 이전 r50 시험 기록을 이번 자료 제작에서 다시 실행한 것으로 표현하지 않는다.
