로컬 Editor 샘플이며 확정 시안·실제 AIS·운항 항로가 아니다. 기존 지구본에 동해, 중국 연안, 중국·동남아, 일본 주변, 일본·미국 태평양, 서태평양·호주 총 6개 가상 항로와 12척을 배치했다. 객체는 재사용하며 계속 왕복한다.
