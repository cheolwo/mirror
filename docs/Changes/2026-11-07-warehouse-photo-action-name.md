# 분산 입고 사진 버튼의 접근성 이름

분산 입고에서 완료 사진을 여러 장 촬영하면 재촬영과 제거 버튼은 사진마다 같은 이름으로 전달됐다. [공용 사진 영역](../../Ssalddel.Ui.Common/Areas/App/RoleWorkspace/DistributedFulfillment/분산사진업무Screen.razor)은 화면에 있는 번호를 버튼의 접근성 이름에 붙인다. 예를 들어 두 번째 사진의 버튼은 **이 사진 다시 촬영 (사진 2)**와 **사진 제거 (사진 2)**로 구분한다. 이름과 버튼 동작은 같은 사진 위치를 참조한다.

가상 입고 계획의 실물 확인 수량 2개와 가상 카메라 입력 세 장으로 현재 Razor 구성요소를 렌더했다. 수정 전에는 번호가 붙은 버튼이 0개라 새 회귀 시험이 실패했다. 수정 후에는 여섯 버튼의 이름을 확인했다. **사진 제거 (사진 2)**를 실행하면 첫째와 셋째 사진이 남았고, 번호가 바뀐 둘째를 다시 촬영하면 첫째 사진이 유지됐다. 사진 전송과 업무 완료 요청은 가상 전송 기록에서 각각 0건이다.
