## 확인 범위

- 공개 게시판 목록과 관리자 신청 검토 목록을 API에서 분리했다.
- 신청자와 검토 관리자 계정 식별자는 인증 Claim을 기준으로 저장한다.
- 신청자가 입력하는 이름은 공개 별칭이며 계정 식별자와 분리한다.
- 사용자당 승인 대기 신청을 최대 3개로 제한하고 기본 게시판 이름의 중복 신청을 차단한다.
- 게시글 생성·수정 시 고정 게시판 또는 승인된 사용자 게시판인지 다시 검사한다.
- 기존 게시판 개설 신청 및 관리자 승인 화면을 재사용하므로 이 커밋에는 새 Razor 화면이 없다.

- `dotnet build Hongdal/Hongdal.csproj --no-restore`
