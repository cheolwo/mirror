# 음식기사 배달 내역의 0건 표시와 조회 실패 구분

완료 배달이 0건인 날짜에서 새로고침이 실패하면, 이전 조회 결과라는 안내와 ‘이 날짜에 완료한 배달이 없습니다’가 함께 표시됐다. 가장 최근 조회에 성공해 0건일 때만 빈 목록 문구를 표시한다. 조회가 실패하면 이전에 확인한 목록과 실패 안내를 표시하며, 기존 **새로고침**으로 같은 날짜를 다시 읽을 수 있다. 재조회에 성공해 여전히 0건이면 빈 목록 문구가 다시 표시된다. [목록 상태 모델](../../FDriverApp/PageModels/FDriverCompletedDeliveryListPageModel.cs) · [배달 내역 화면](../../FDriverApp/Pages/CompletedDeliveryListPage.xaml)

새 회귀시험으로 정상 0건 → 일시적 조회 실패 → 같은 날짜 새로고침 성공을 재현했다. 수정 전에는 오류 중 빈 목록 조건이 참이었고, 수정 후에는 같은 시험이 통과했다. 화면이 이 조건과 기존 새로고침 명령을 사용하도록 연결돼 있음을 확인했다. 이 확인 범위는 화면 바인딩과 합성 응답을 사용한 상태 시험이며 실제 기기·좁은 화면 렌더·제품 API는 미검증이다.

음식기사 앱과 통합 3.5 빌드는 오류 0개였다. 관련 시험 119건과 전체 시험 17,032건이 통과했고, 환경 조건이 필요한 17건은 생략했다. 수정 전 실패와 최종 시험 결과는 `artifacts/local/mirror-ui-assist/20261106T070119418Z-food-driver-empty-refresh/completion.json`에 기록했다.

다음 회차에는 판매자가 주문 목록에서 조회 실패 후 주문을 다시 찾는 흐름을 살핀다.
