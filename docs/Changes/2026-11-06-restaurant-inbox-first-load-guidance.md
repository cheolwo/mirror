# 음식점 수신함 첫 조회 실패 안내

음식점 주문 수신함은 첫 조회가 실패해도 이전 목록을 표시한다는 경고를 띄웠다. 주문 알림 연결까지 실패하면 그 경고가 알림 안내로 바뀌었다. 첫 조회 실패에는 기존 **다시 확인** 버튼과 30초 자동 조회를 안내한다. 같은 시점에 알림 연결도 실패하면 목록 재조회 안내를 우선 표시한다. 조회 이력이 있는 상태에서 갱신에 실패하면 마지막 목록과 갱신 실패 안내를 함께 표시한다. [주문 수신함 소스](../../RestaurantDeskApp/Components/Pages/OrderInbox.razor)

실제 수신함 Razor와 버튼 콜백을 메모리 자료로 확인했다. 최초 실패, 알림 연결과 동시 실패, **다시 확인** 한 번으로 목록 복구, 마지막 목록 유지와 복구, 정상 빈 목록, 알림 연결만 실패한 경우의 6건이 통과했다. 실제 브라우저의 좁은 폭, 기기와 제품 서버는 미검증이다.

음식점 앱 빌드 오류 0개와 관련 시험 74건 통과를 확인했다. 통합 빌드는 오류 0개였으며, 전체 시험은 17,031건 통과, 실패 0건, 환경 조건으로 17건 생략이었다. 결과와 소스 판본은 `artifacts/local/mirror-ui-assist/20261106T060118347Z-restaurant-inbox-first-load/completion.json`에 기록했다.

다음 회차에는 주문자가 주문 내역에서 조회 실패 후 같은 주문을 재확인하는 흐름을 살핀다.
