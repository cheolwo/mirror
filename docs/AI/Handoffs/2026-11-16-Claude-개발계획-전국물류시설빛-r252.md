## 1. 한 줄

1. 전국 지도의 자료 층에 **「물류 시설 빛」**을 더한다.
   - 공공 자료의 창고 · 항만 구역 · 공항이 작은 점과 부드러운 번짐으로 보인다.
   - 색과 모양을 함께 써서 종류를 가른다.
2. 멀리서는 **어디에 몰려 있는지** 보이고, 확대하면 **하나씩** 보인다. 누르면 **어떤 자료인지** 카드로 확인한다.
3. **보기만 한다.** 빛의 밝기나 크기는 물량 · 가동 · 소유를 말하지 않는다. 시간 · 돈 · 주문 · 저장은 그대로다.
4. 좌표가 없는 자료는 그리지 않는다. NLIC 등록창고 6,011, 물류단지 59, 물류터미널 30, 보세 구역 후보 764가 여기에 든다.
   - 이 자료들은 「위치 자료 보완 중」 목록에만 둔다.
   - 신청해 둔 도로명주소 내비게이션용DB가 오면 주소를 자리에 이어 전국으로 넓힌다.

## 2. 근거

### r252에서 확정된 것

- 전국 지도에서 물류시설 · 보세 관련 시설 · 항만 · 공항의 위치를 빛으로 찾게 한다.
- 시설 종류와 실제 위치 근거를 보존한다.
- 필요한 공공 자료 수집은 허용됐고, 실제 수집과 검증도 끝났다.

### r252의 제안(이 계획이 따르거나 결정으로 올린 것)

- **모양:** 작은 중심점과 부드러운 후광을 쓰고, 색만으로 가르지 않는다. 이 계획은 이것을 따른다.
- **공공과 게임의 구별:** 공공 참고는 옅은 정적 빛으로, 게임 상태와 이어진 대상은 더 뚜렷하게 둔다. 기획에서 `Asked` 상태다 → **L1**.
- **전국 축소:** 개수 표시나 확대로 개별 관측에 닿게 한다. 묶음 수는 관측 수다. 좌표를 흩뜨리지 않는다. 적용 줌은 시안 뒤에 정한다 → **L3**.
- **카드:** 이름 · 종류 · 주소/좌표 근거 · 기준일 · 대표점 여부 · 출처를 보인다.
  - 같은 자리의 여러 관측은 후보 목록으로 보인다.
  - 창고 이름은 실제 업체 상호라서 이 시안에서는 가렸다 → **L2**.
- **층과 거점:** 시설 층과 해상 · 항공 통계선은 따로 켜고 끈다. 통계 기간을 바꿔도 시설 빛은 그대로다. 기존 통계 거점(대략 좌표 14곳)을 덮어쓰지 않는다.

## 4. 자료 팩

**도구:** `WindowsGame/Tools~/make_nation_facility_pack.py`(새 파일)

- **입력:** Codex의 `map-candidates.wgs84.geojson`과 `manifest.json`. 고치지 않고 읽기만 한다.
- **출력:** `WindowsGame/Resources/hongdal-nation-facilities.json`(+ meta)
- **좌표:** `make_nation_pack.py`와 같은 식, P(lon, lat) = [600 + (lon − 127.6) · 88·cos36°, 337 − (lat − 36) · 88].
  - 도구는 서울 기준점 (127.0, 37.56) → (557.28, 199.72)를 확인한다. 어긋나면 팩을 쓰지 않는다.
- **팩 구조:**

```json
{
  "schema": "hongdal-nation-facilities.v1", "pack": "2026.11.16-1", "space": "hongdal-nation-space.v1",
  "sources": [{ "id": "gg-warehouses", "title": "경기도 물류 창고업체 현황", "provider": "경기도", "asOf": null }],
  "points": [{ "id": "<관측 ID>", "k": 0, "x": 0.0, "y": 0.0, "s": 0, "m": 0, "area": "여주시", "name": null }],
  "portAreas": [{ "id": "<관측 ID>", "name": "인천항", "ring": [[0.0, 0.0]] }],
  "pending": [{ "title": "NLIC 등록창고", "count": 6011, "why": "좌표 없음" }]
}
```

- **창고 칸:**
  - `name`과 주소는 넣지 않는다(L2).
  - `area`는 원본 도로명주소의 두 번째 낱말이 시나 군으로 끝날 때만 넣는다. 아니면 비운다.
  - 이번 1,005건은 모두 시군이 나왔다.
- **항만 · 공항 칸:** `name`을 넣는다.
  - 원본 이름은 정리해서 넣는다. 「평택, 당진항, 평택,당진항」→ 「평택·당진항」. 바꾼 이름은 목록으로 남긴다.
- **항만 구역 도형:** 원본은 30만 점이다. 세계 좌표에서 단순화해 전체 5,000점 이하로 줄인다. 이 칸은 S4에서 넣는다.
- **크기:** 점만 넣으면 50KB 안팎이다.

## 5. 그리기

**차례:**

- 바탕 → 지명 → 흐름 → 회차 → **항만 구역 테두리 → 시설 번짐 → 시설 점** → 거점 → 출입구 → 이름표 → 고른 것
- 시설 빛이 거점 표지와 이름표 아래에 깔린다.

**빛:**

- `roamGlow`로 번짐을 그리고 그 위에 점을 찍는다. 숨(깜빡임)이 없다.
- 섞기는 알파 덮기다. 겹치면 그 색에 다가갈 뿐 더 밝아지지 않는다(1곳과 30곳의 밝기가 거의 같다. N-4).
- 색과 모양:
  - 창고: 호박빛 둥근 점
  - 항만 구역: 해상 물동량과 같은 계열(`NationSea`)의 마름모
  - 공항: 항공과 같은 계열(`Lilac`)의 십자
- 세기를 정하는 함수는 종류와 관여(L1)만 받는다. 어떤 수치도 받지 않는다.

**확대 단계(L3):**

| `nationScale` | 그리는 것 | 마우스 · 누름 |
| --- | --- | --- |
| 1 ~ 1.5 | 번짐 + 작은 점 | 올리면 반경 14 안의 건수 |
| 1.5 ~ 2.4 | 번짐 + 화면 48칸마다 묶음 숫자(5건 이상) | 숫자를 누르면 그 칸으로 확대 |
| 2.4 ~ 3 | 하나씩 + 항만 구역 테두리(L6) | 누르면 카드 |

**비용:**

- 화면 밖 점은 건너뛴다.
- 1.5배 아래에서는 화면 4칸마다 한 번만 그린다. 셈은 그 칸의 수로 `1 − (1 − a)^n`을 쓴다.
- 촬영에서 시설 빛을 켠 프레임과 끈 프레임의 시간을 잰다.
  - 더해지는 시간이 1ms를 넘으면 번짐을 텍스처 한 장에 미리 굽는 쪽으로 바꾼다.
  - 텍스처 크기는 점 범위만, 세계 1단위당 2픽셀이다.

## 6. 고르기와 카드

**고르기 차례:**

1. 기존 `PickNation`(거점 · 출입구 · 선)이 먼저다.
2. 아무것도 안 걸리면 2.4배 이상에서 7(논리 픽셀) 안의 가장 가까운 시설을 고른다.
3. 3 안에 여러 관측이 겹치면 카드가 **후보 목록**이 된다. 5건까지 보이고 「외 n건」을 붙인다.
- 좌표는 옮기지 않는다.

**카드:** 고른 시설은 `NationPanel`의 거점 카드 자리를 쓴다. 「카드 닫기」를 누르면 거점 카드로 돌아간다.

- 머리: 종류와 출처
- 제목:
  - 창고는 「창고 · {시군}」(시군이 없으면 「창고 · 시군 자료 미확인」)
  - 항만은 「{이름} 구역」
  - 공항은 이름
- 네 칸:
  - 종류
  - 원본 상태
  - 자리: 주소 대표 좌표 / 구역 안 대표점 · 부두 아님 / 공항 기준점
  - 기준일: 없으면 「자료 미확인」
- 창고만: 같은 시군 건수(관측 건수 · 시설 수 아님)
- 출처 두 줄, 주의 세 줄
- 「가운데로 보기」는 지도만 옮긴다. 추적 · 계약 · 시설 만들기 · 운송은 없다.

## 7. 자료 층 · 범례 · 보완 중 목록

- **「물류 시설 빛」 줄:** 누르면 층 전체를 켜고 끈다. 종류 칩은 종류마다 켜고 끈다.
  - 처음 상태는 켬이다(L5).
  - 저장하지 않는다. 해상 · 항공 층과 같다.
- **「보완 중 4종 ›」:** 오른쪽 카드 자리에 목록을 연다(N-4 왼쪽 아래).
  - 자료마다 건수 · 지금 상태 · 다음 할 일이 적힌다.
  - 끝줄에 경기 창고 중 좌표가 빈 2건을 따로 적는다(4종에 넣지 않는다).
  - 맨 아래에 「추정 자리로 그리지 않음」을 적는다.
- **표시 칸:** 한 줄을 더한다.
- **위 띠(배너):** 「전국 · 해상·항공 자료 관찰」은 그대로 둔다. 시설 출처는 카드에 적는다.

## 8. 지키는 것

- 보기만 한다. 층을 켜고 끄거나 시설을 골라도 세계 시계 · 턴 · 원장 · 주문 · 저장이 바뀌지 않는다. 기존 `NationHoldsClock`도 그대로다.
- 공공 시설을 게임 시설 · 제휴 · 소유로 만들지 않는다. 이름이 크다고 대형 센터나 보세 허가로 판정하지 않는다.
- 창고의 실제 상호와 주소는 화면과 문서에 쓰지 않는다(L2가 바뀌기 전까지).
- 「표현」인 것: 빛의 색 · 크기 · 번짐, 묶음 숫자의 모양.

## 11. 곁가지

- **수도권 이름표가 빛을 가림(N-1).** 첫 조각은 그대로 두는 것을 추천한다. 해상 · 항공을 끄면 바로 보이기 때문이다(N-2).
