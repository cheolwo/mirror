## 조립과 검증

실제 WindowsGame 소비 코드는 `C:\Users\user\ssalddel`의 `unity/workstream-transition` 작업본(HEAD `605e87e`)에서 읽었다. `SagajeongDispatchDongModules`의 파일 지문·원점 검사, HDIO 판독기, 기존 렌더러와 건물 선택 진입점을 재사용했다. 제품명·회사명과 저장 위치가 독립적인 검토판을 Hongdal의 로컬 산출물 경로에 만들었다. 외부 작업본에 기록된 입력 파일 230개의 SHA-256은 작업 후에도 일치했다.

원자료 ZIP, 건물 색인, 메시의 지문과 전수 대조 결과는 [굽기 영수증](../../../artifacts/local/myeonmok38-unity-r3/bake/receipt.json)과 [메시·인허가 전수 검사](../../../artifacts/local/myeonmok38-unity-r3/bake/verification.json)에 있다. 재현용 [굽기 스크립트](../../../artifacts/local/myeonmok38-unity-r3/bake/bake.py), [격리 프로젝트 준비](../../../artifacts/local/myeonmok38-unity-r3/work/stage.py), [건물 카드 패치](../../../artifacts/local/myeonmok38-unity-r3/review-card/prepare.py), [Windows 빌드](../../../artifacts/local/myeonmok38-unity-r3/work/build-player.ps1)를 같은 작업 경로에 두었다.

최종 증분 빌드는 Unity 6000.5.6f1에서 오류 0·경고 0이었다. 첫 빌드 때 기존 공유 패키지의 nullable 문맥 경고 786건이 기록됐다. 새 플레이어에서 검토한 범위는 면목제3·8동 하나다. [최종 빌드 결과](../../../artifacts/local/myeonmok38-unity-r3/player-final/build-result.json) · [커널 검사](../../../artifacts/local/myeonmok38-unity-r3/player-final/kernel-checks.txt)
