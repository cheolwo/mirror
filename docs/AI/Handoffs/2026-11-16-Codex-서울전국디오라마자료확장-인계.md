# Codex → Claude · 서울 전체·전국 디오라마 입력 확장

**지형 소비 경계:** 원본 Point 격자 위상 오류를 발견해 `terrain-grid-phase-correction-20261116-r2`로 별도 보정·검증했다. 원본26타일과 지역 색인·건물/벡터DB는 정상이다. 기존21대표 클립·수도권 파생 DEM·`reference-bundles`의 보정 전 지형은 쓰지 않는다. 수정 참조는 `reference-bundles-r2`, 전체 서울427동 묶음도 같은 보정을 반영했다. 교체표의 새 경로를 사용한다.

2026-11-16 KST. 사용자 요청은 서울 전체·전국 디오라마를 위해 여기서 가능한 자료 수집·정규화·지역별 준비를 계속하는 것이다. **Claude의 도로 폭 적용·면목 6동 재굽기는 그대로 유지**했다. 이번 결과는 굽기 전 입력이며 Unity 코드·Resources·Scene·공용 DB·예약을 바꾸거나 새 게임 기능을 구현한 반환이 아니다.

## 권하는 첫 소비

새 게임 구현을 시작하기 전에 기존 승인 범위에서 서울의 새 동 하나를 골라 다음을 비교한다.

- 사직동 `1111053000`, 면목제3·8동 `1126057500`, 신사동 `1168051000`의 건물 추출 파일이 `seoul-diorama-building-inputs-20261116-r2/samples/`에 있다. 수량은 각각 1,900·2,722·1,393개다.
- 같은 행정동 코드로 전국 벡터 도구의 `extract --region <코드>`를 실행하면 경계·차량 도로·하천을 얻는다. 지형 조회 도구는 동 코드에 맞는 원본 타일과 지문을 반환한다.
- 동별 준비표의 수량·원본 지문, 교차한 건물의 분할/고리 보존, 도로·건물 침범, 수면/지형의 과장과 주소 선택을 확인한다. 확인 전 Resources에 일괄 복사하지 않는다.
- 새 도로는 9월14일 판본이다. Claude 폭 측정에 사용한 원본과 링크 ID·판본을 대조하고 원본 행 번호나 공간 근접만으로 폭을 새 링크에 붙이지 않는다.

정확한 명령은 결과 정본의 「재조회·추출 예」에 있다. Python/공간 패키지는 이미 있는 것을 사용하며 새 신청·API 키가 필요하지 않다. 출력은 현재 모듈의 입력으로 변환할 자료이며 Unity에 바로 넣는 완성 메시·행동 그래프가 아니다.

## 반드시 유지할 구분

- 경계는 2026-10-01 편집 후보다. 공식 최신 행정동 원본을 확보한 것으로 승격하지 않는다.
- 서울 건물의 무효 도형44개·외곽 고리 미확인2개는 보류했다. r1 대신 **r2만 최종 소비**한다. 미배정300개를 공터·없는 건물로 표시하지 않는다.
- 전국 대장에는 옛/미확인 지역 코드와 비정상 높이가 남아 있다. 대장 PK·필지를 건물 고유관리번호로 부르거나 시군구 기록을 행정동에 균등 귀속하지 않는다.
- 도로 PRJ의 ITRF2000 datum, 건물 EPSG:5186, 하천/대표 지형 EPSG:5179, 지형 높이 EGM96을 보존한다.
- NASADEM은 2000년 레이더 원관측이다. 타일 결손0은 현재 정밀 지표면·전체 영토 완비 인증이 아니다.
- `native-terrain-verification.json`에서 서울674,085셀 전체를 원본 직접 변환과 대조했다. 최대 차이0.00003052m는 계산 일치이며 현실 지형의 밀리미터 정확도 인증이 아니다.
- 다른 시도의 다중 SHP 레이어는 원문 행수다. CRC 통과를 고유 건물 수·정확도·행정동 정밀화 완료로 해석하지 않는다.
- OSM은 ODbL1.0 별도 보조층이다. 골목/보행 분류·철도/녹지가 있어도 실제 폭·통행·개별 나무·지상/지하 시설·공식 지정 경계를 확정하지 않는다. 가로수/가로등/출입구 등의 전국 공식 공통 품질과 구분한다.
- 공용 DB/예약·제품·기존 원본·기존 65동 모듈은 보존했다. 공개 배포·Goal/E·공통 디오라마 규칙 승격은 없다. **새 디오라마 규칙 후보 없음.**
