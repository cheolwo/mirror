## 6. 주로 기획·시안/개발 계획에 있는 확장

- **홍달 플레이스 후속** — 인구 기반 가상 고객 검색량, 구간 색인 정본/저장·운영자/근거 뷰, 판매 태그 개선의 전후 비교, 실제 주문 연결. 주문자 조회 화면과 구별한다.
- **광고·인물 카드** — 정식 광고 집행/결과, r239 중개업자 인물·계약·잠정 점수/감쇠·검증·회복. 개발 종합 계획에 반영됐으나 실제 계약·비용 처리·가짜 관여 생성은 없음.
- **센터 내부와 미니게임** — 지붕 없는 층별 공간, 랙/위치 바코드, 입고→피킹→포장→컨베이어→상차. 건물/사업 카드나 다른 업무 시제품이 이 일반판 플레이의 구현 증거는 아님.
- **점포 확장과 테크트리** — 초보 직원 육성·현장 책임자·가족/외부 인재 협력·2~5호점·플랫폼 성장·분야별 연구. 기존 집계 고용/지역 진출과 실제 개인·점포 성장의 차이가 남음.
- **계절·관찰·공급망** — 사계절 수목/지형의 변화, 외부 음악 반응, 독립 관찰 모드·데이터 팩 다운로드, 커피 수입/검사·통관·전국 공급망의 일관된 플레이, 세계 지구본. 현재 군중/녹지 자료·구/전국 지도·고정 공급 사슬 등은 재사용 기반.
- **역할 앱 재연** — 실제 앱의 페이지 문법을 게임 속 주문자·음식점·기사·창고의 휴대폰으로 보여 주는 최신 제안. 기존 역할 앱의 구현 실적을 게임 내 구현 실적으로 더하지 않음.

## 7. 다음 구현의 추천 순서

1. **지금 열린 주문자 화면에서 주문 한 건을 잇기.** 같은 주문 ID로 매장 수신→5분 제조→픽업 준비→기사 배달→당일 결산을 읽는다. 기존 즉시 가상 판매와 배송 금액의 중복을 먼저 정리한다.
2. **검색의 실제 게임 활동과 관리 화면.** 정본·저장·가상 고객 검색/노출을 준비하고 주문자/운영자/근거 뷰가 같은 판본을 보게 한다. 이는 현재 조회 화면과 다른 작업 범위다.
3. **일을 한 사람과 성장.** 개별 직원·점포·위임/초보 학습·명덕·정신차림을 같은 활동 기록/주체 ID에 연결한다.
4. **연결이 닫힌 뒤 분야 확장.** 정식 광고·중개업자, 65동 실제 음식점 조회, 창고 내부·무역·연구를 작은 범위로 붙인다.

기존 계획/승인과 담당이 진행 중인 범위를 그대로 존중하는 우선순위 제안이다. 새 기능을 이 문서로 수용하거나 다른 작업을 취소하지 않는다. 직접/맡김 각각의 첫날 1배속 완주와 일반 저장 종료/재시작 검증은 위 작업과 함께 필요하다.

## 8. 이번 작업 결과

현재 구현 상태 보고서와 진입 상태만 갱신했다. 제품·수집기/예약·DB·기획 판본/승인·Goal/WI·Graph Map·commit/push는 변경하지 않았다. 소스/기존 빌드·촬영 대조와 문서 검사를 수행했고 새 제품 빌드·게임 실행·사람 입력 시험은 수행하지 않았다.
