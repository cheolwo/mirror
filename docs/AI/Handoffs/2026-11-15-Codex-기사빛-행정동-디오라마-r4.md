# 기사 빛과 네 구의 행정동 디오라마 r4

면목제3·8동에서 출발한다. 왼쪽 위 동 이름을 누르면 구·동 목록이 열리고, 옆의 **이전**과 **다음**으로 한 곳씩 볼 수 있다. 동을 바꾸면 그 동의 경계에 맞춰 카메라가 이동한다. 건물을 누르면 지번·용도·높이 근거를 읽을 수 있다.

## 기사 표시

[Claude의 기사 빛 반환](2026-11-14-Claude-기사를빛으로-반환.md)에서는 배차 기사 A를 민트색, B를 연보라색 빛으로 표현한다. r3 실행판에서는 이동용 그래프를 제공하지 않을 때 오토바이 이미지가 다시 나타났다. WindowsGame 작업본의 기사 그리기와 선택을 실제 기사 위치의 빛에 연결하고 오토바이 이미지 읽기를 제거했다. 같은 빛으로 정보를 보거나 기사를 선택한다. 순찰용 도로망을 확보한 곳에서만 별도 순찰을 표시한다. 운영 자료가 없는 동은 그 동의 공간 자료를 보여 준다.

## 다른 행정동을 굽는 방법

행정동 코드로 메시·건물 선택 외곽·지번·인허가 참조를 독립 보관한다. 게임의 공통 원점·미터 환산값을 사용한다. 단독 모듈의 건물 ID는 동을 묶는 순서와 무관하다. 선택한 여러 동을 한 실행판에 넣을 때만 전역 선택 색인과 메시의 대응 값을 다시 계산한다. [굽기 도구](../../../eng/neighborhood/bake_dong_unity_modules.py) · [HDIO 메시 조립](../../../eng/neighborhood/dong_hdio_mesh.py)

개별 모듈은 중랑 16동·광진 15동·동대문 15동·노원 19동, 모두 65동이다. 전수 대조한 건물 117,551조각은 원본 116,780행에 해당한다. 도로 10,303조각, 지표 도보선 45,305조각과 공원 계획면 356조각을 담았다. 압축 모듈 저장량은 91.46 MiB다. 이 가운데 위 표의 여섯 동을 실행판에 포함했다. [65동 목록](../../../artifacts/local/admin-dong-unity-r4/bake/modules/catalog-all.json) · [65동 전수 검증](../../../artifacts/local/admin-dong-unity-r4/bake/library-verification.json)

Hongdal 루트에서 프로젝트 GIS 환경의 Python으로 실행한다. 첫 명령은 동 이름과 코드를 보여 주고 둘째 명령은 기존 캐시에서 화양동과 월계1동만 새 출력 폴더에 조립한다. 결과의 `Resources`에 있는 지도 명세·건물 색인·선택한 동 메시를 한 묶음으로 사용한다.

```powershell
python eng/neighborhood/bake_dong_unity_modules.py --list
python eng/neighborhood/bake_dong_unity_modules.py --code 1121571000 --code 1135056000 --output artifacts/local/hwayang-wolgye-review
```

## 검증 범위

Unity 6000.5.6f1에서 [Windows 검토판](../../../artifacts/local/admin-dong-unity-r4/player/HongdalSimulation.exe)을 빌드했다. 실행 파일을 다른 폴더나 PC로 옮길 때는 옆의 Unity 데이터와 DLL이 든 `player` 폴더 전체를 복사한다. 빌드 오류 0건, 기존 공유 패키지의 nullable 문맥 경고 786건, 커널·공간·경영 등 기존 검사 329개 통과다. [빌드 결과](../../../artifacts/local/admin-dong-unity-r4/player/build-result.json) · [검사 목록](../../../artifacts/local/admin-dong-unity-r4/player/kernel-checks.txt) · [작업본 기사 표시 수정과 원본 지문](../../../artifacts/local/admin-dong-unity-r4/rider/claude-source-receipt.json)

실행 인자를 주지 않은 창에서 시작 동과 모듈 6/6 로드를 확인했다. 같은 실행 파일의 화면 검증에서 여섯 동을 순서대로 열고 각 시점에 활성인 동이 하나임을 확인했다. 동마다 화면 좌표에서 되찾을 수 있는 옥상 8곳을 확인하고, 첫 건물의 지번과 원본 도형 ID를 독립 대조했다. 예를 들어 면목제3·8동에서는 ‘면목동 600-32’, 용두동에서는 ‘용두동 39-153’이 일치했다. 평면에서 기사 A·B가 모두 빛으로 그려졌고, 면목제3·8동 확대 화면에서 이동용 그래프가 없어도 기사 A를 빛으로 선택했다. 다른 다섯 동에서는 면목동 기사 표식이 표시되지 않았다.
