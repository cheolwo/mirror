## 조회 예시

아래 좌표 범위 조회로 면목역 주변 정류장 23곳을 확인했다. `transport_point_rtree`에서 후보를 줄이고 `transport_point`의 원문 정밀도 좌표로 최종 필터링한다.

```sql
SELECT r.name, r.provider_id, p.longitude, p.latitude
FROM transport_point_rtree AS i
JOIN transport_point AS p ON p.point_id = i.point_id
JOIN transport_record AS r ON r.record_id = p.record_id
WHERE r.source_id = 'bus_stop'
  AND i.min_lon <= 127.092 AND i.max_lon >= 127.081
  AND i.min_lat <= 37.591 AND i.max_lat >= 37.585
  AND p.longitude BETWEEN 127.081 AND 127.092
  AND p.latitude BETWEEN 37.585 AND 37.591
ORDER BY r.name, r.provider_id;

SELECT legal_dong_code, eup_myeon_dong_name, observed_date, total
FROM legal_dong_population
WHERE sigungu_code = '11260'
ORDER BY legal_dong_code;
```

DB 무결성·외래 키·공간 색인, 네 종류별 전량 수, 주민 총수와 성별·연령 합을 확인했다. 관련 지도 자료 도구 검사 23개가 통과했다. 이번 저장은 로컬 자료 검증이다. 기존 공공 API DB, Claude의 굽기 파일, Unity 실행과 수집 예약은 기존 상태를 유지한다. 새 디오라마 규칙 후보 없음.

추가 파일을 반입할 때는 원본 판본을 확인해 영수증에 등록하고 새 출력 이름으로 [반입 도구](../../../eng/data-collection/downloaded_map_data.py)를 실행한다. 교통 입력의 필드 정의는 [교통 CSV 읽기](../../../eng/data-collection/downloaded_public_transport_rows.py)에 있다.
