# 음식점 판 — 기준 문서(가게를 열고 꾸리는 일)

2026-11-27 18:25 · Claude · 내부 검토용 · 배포 아님
배달 판과 따로 묶는다. 음식점 판의 결정 · 만든 것 · 남은 것은 여기에 이어 적는다.

## 사용자의 말(18:25)

> 음식점은 가게를 열고 그런 거는 그 음식점 관련 패키지에서 주로 다루면 괜찮겠다 … 배달 이쪽에서 다루지 말고. 그거는 그거대로 좀 묶어서 구체화시켜 나가면 좋을 것 같아.

## 가른 것

| 일 | 어디서 |
| --- | --- |
| 가게 열기 · 메뉴 · 재료 · 생산 · 입고 · 인건비 · 임대 | **음식점 판**(이 문서) |
| 가게를 플랫폼에 들이는 일(입점 영업 · 가게 수 늘리기) | **배달 판의 배달 플랫폼 자리**(18:37 사용자) |
| 입점 제안을 받을지 · 수수료를 견딜지 | 음식점 판 — 가게 사장의 눈으로 |
| 기사 모집 · 기사 배치 · 지사 열기 · 소통 · 베이스라인 · 운영 조절판 | 배달 판([기준](2026-11-27-Claude-배달판-기준.md)) |
| 두 판이 만나는 곳 | 같은 동 · 같은 주문. 배달 판은 입점한 가게 수를 **읽기만** 한다(동 카드 「제휴 가게 n곳」) |

## 이미 있는 것(옮겨 올 자리)

- 입장 카드 「음식점 사장」(자료 보기) · 2.0의 가게 창(재료 · 설비 · 직원 · 주문 기록, 장면 `52-store-*` ~ `60-store-building-card`).
- 오늘 시안: 가게 사장 첫 화면(배달 반경 · 주문 · 기다림 · 남는 돈 · 할 일 「점심 몰림 전 재료 채우기」) · 카페 1호점 현금 흐름표(매출 / 재료 · 플랫폼 수수료 · 배달비 부담 · 인건비 · 임대) · 줄 → 카메라 자리(매출 → 주문 온 집들, 재료 → 창고형 마트 …).
- 지사장판 개발 계획의 「음식점 사장 다음 할 일: 생산 · 식자재 입고 · 메뉴」.

## 아직 정하지 않은 것

- 음식점 판도 사다리가 있나(가게 하나 → 여러 가게 → 프랜차이즈 …)? 배달 판처럼 「만드는 일은 늘 기본, 오를 때마다 더해진다」로 할까?
- 시작 화면에서 들어가는 길(지금은 「다른 입장으로 자료 보기」 안의 카드).
- 배달 판 다음에 다룬다(배달 판을 먼저 다듬는다 — 17:22).

- 18:37 사용자: 「음식 가게를 늘리는 거는, 입점하는 가게를 늘리는 거는 배달 플랫폼의 역할로서 자리 잡으면 좋을 것 같아」 → 입점 영업은 배달 판 플랫폼 자리. 음식점 판은 받는 쪽.
