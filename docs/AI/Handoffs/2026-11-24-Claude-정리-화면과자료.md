## 2. 개발자 자료(정리한 것)

새 폴더 `artifacts/local/public-data/_catalog/`

- `hongdal-data-catalog.json`: 게임이 읽는 생활 자료 묶음 13개를 한 줄씩(무엇 · 범위 · 만드는 스크립트 · 화면 · 입장 · 보안).

- `README.md`: 자료가 사는 곳(원본 → 굽기 → Resources → 코드 → 화면), **자료 머리 규격 v1**(schema · topic · title · release · sources 필수, asOf · note 권장), 새 자료를 더하는 여섯 걸음.

머리 규격 맞춤:
- 유동인구 · 농수산물 흐름: 만드는 스크립트에 v1 머리를 넣고 다시 구움.
- 위치 확인 표식 · 서울 25구: 스크립트에 v1 머리(파일 안에 이미 있는 지표 · 갈래별 출처를 sources로 모음)를 넣고, 지금 파일에도 같은 셈을 적용.
