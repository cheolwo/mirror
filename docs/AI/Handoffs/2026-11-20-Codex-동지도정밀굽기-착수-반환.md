# 동 단위 정밀 굽기 착수 반환

[Claude 전국 인계](2026-11-20-Claude-인계-동지도정밀굽기-전국-Codex.md)의 P0과 P1을 수행한다. 실행과 재개 기록은 같은 PC의 `artifacts/local/hongdal-unity-claude-20261112/dong-bake-national-20261120-r1/STATUS.md`에 둔다. 기존 굽기판과 그 입력은 보존했다.

## 준비와 기준

- 건물 원본 16개, 공식 경계 16개, 내비, 표준노드링크, OSM의 크기와 SHA-256이 기존 영수증 35개와 모두 일치했다.
- 기존 결과의 동별 품질표는 서울 공식 427행, 경기 후보 601행, 경기 공식 16행이다. 두 경기 판에 있는 13동을 각각 기록했다. 무리의 주 길망 통계와 동의 출입구 통계를 각각 그 집계 단위에 보존했다.
- Windows에서 구리·중랑·와부·가평·연천 기준 다섯 묶음을 재굽고 패키지 지문을 남겼다. 중랑구는 기존 환경에 빠진 `openpyxl` 3.1.5와 그 XML 의존성을 PC의 설치 자료에서 보완한 뒤 굽기를 재개했다.
- 구리에서는 스위치를 끈 실물 굽기 결과의 미리보기 목록 한 파일이 처음에 달랐다. 목록이 압축 생성 시각을 포함한 입력 파일의 지문을 기록했기 때문이다. 두 실행의 미리보기 입력을 같은 압축 시각으로 재생성하고 GeoJSON 내용과 실제 패키지 11개 파일의 SHA-256이 모두 일치하는 것을 확인했다. 최초 결과와 비교 기록은 함께 보존했다.

## 도구와 실제 입력

| 항목 | 확인한 범위 |
| --- | --- |
| 끊긴 길 진단 | 구리·중랑·와부의 실제 포장 파일에서 분리망과 문이 없는 건물을 세고 가까운 변의 거리를 계산했다. 근접 간격은 검토 후보에 기록한다. |
| 원본 끝점 | 같은 노드링크의 같은 원본 정점을 확인한 경우에만 0.5m 이내의 맞춤을 시험한다. 구리의 실제 스냅 시험에서 추가 변은 0개였고, 문 수와 길망 지표가 기준과 같았다. |
| 경계 밖 길 | 구리 후보판 400m 범위의 원본 조각 2,547개를 추출했다. 조회한 건물 도형과 교차 없음 1,673개, 교차 229개, 원본 범위 미확인 645개였다. 실제 패키지의 경계 밖 원본 변 673개와 접촉 변 13개에 근거를 남겼다. 길망 덩어리는 511→509, 출입구 7,829/8,479채 유지, 건물 관통 0이었다. |
| 차로 수 | 원본 `MOCT_LINK.dbf` 1,562,356행의 링크 ID·차로 수·도로 등급을 전수 대조했다. 원본에 시도 열이 없어 링크 ID로 조회하는 전국 표를 쓴다. 구리 실제 굽기의 1,348개 링크가 기존 표와 같은 차로 수 판정을 받았다. 서울의 측정 차선 자료는 별도로 유지한다. |
| 건물 외곽 | 새솔동의 전자지도 보완 후보 771채를 실제 동 모듈에 반영해 경계와 높이 근거를 확인했다. 지상층수×3m 765채, 층수 결측의 상징 높이 4m 6채였다. 서로 면적이 겹친 후보 2채를 제외했다. |
| 경계 준비 상태와 실행기 | 공식·후보·미확인 표시와 선택 입력의 바이트 호환을 합성 실행에서 확인했다. 검증 실패와 메모리 부족에 따른 동별 재시도, 15GB 하한, 지문 검증, 이어 굽기를 Windows에서 시험했다. 구리 실물 시험에서 Windows 경로 길이 오류가 나 임시 경로를 줄여 다시 시작했다. |
| 품질표 연결 | 남양주 실물 보관본 사본으로 검증된 동을 기존 1,044행에 한 줄 추가했다. 재실행 때 중복이 없고 지문 변경 시 갱신을 거절했다. |
| 경기 첫 입력 | 구리시 공식 경계 8동·22,844채를 3개 묶음으로 만들고 실행기의 계획 검사를 통과했다. |
| 인천 입력 | 공식 경계 158동과 건물 원본 310,126행을 대조했다. 검단구 원당동 한 곳의 건물 2,091채 중 657채에 내비 주소·출입구를 연결했다. 전자지도 수령은 미확인이다. |

## 접속 근거가 남은 곳

- 구리의 미연결 영향 상위 5개 분리망을 원본 OSM·경기 전자지도와 대조했다. 평면 교차 후보는 있으나 확정 접속은 0건이다. OSM 후보 하나는 건물 안으로 18.90m 겹쳤다.
- 중랑 면목의 OSM 후보 71.87m는 원본 내부에서 이어지지만 기존 모형과의 양 접속은 미확인이다. [면목 r58](../Planning/시스템/PLAN-SYSTEM-ADMIN-DONG-DIORAMA/myeonmok-alley-links-and-precision-priority.r58.md)에 적힌 0.46m·0.42m는 모형과 OSM의 거리다. 같은 원본 접점이라는 증거로 사용하지 않는다.
- 미확인 갈래는 그대로 기록한다. 남은 무리의 P1 끔·켬 검증과 실제 수치가 모두 확인되기 전에는 생산 순서를 열지 않는다. Unity 실행판 검증은 별도다.
