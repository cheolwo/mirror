# 조사 · 지도에 올릴 분야별 공공자료와 신청 목록

2026-11-19 00:17 KST · Claude. 내부 검토용 · 배포 아님. **조사만 했다.** 이 문서를 쓸 때까지 내려받기 · 로그인 · 신청은 하지 않았다.

- 사용자: 「지도로서 표현을 하는데 좀 정확해야 되거든 … 자료 조사를 더 해야 된다거나 그런 거 있으면 알려줄래 … 국가에서 관리하는 분야 … 농업, 어업, 축산업, 도소매업, 물류업, 창고업, 무역 수출입 통계 … 싸그리 다 조사 … 내가 신청해야 될 정보가 있으면 그런 것도 다 남겨놓고」
- 방법: 네 갈래(기반 지도 / 농림축수산 / 유통 · 물류 · 무역 · 산업 / 통계 · 시설 · 환경)로 나눠 공식 페이지를 열어 확인했다. 대부분 공공데이터포털(data.go.kr) 등록 페이지 기준이다.
- 표의 「확인」: ● 공식 페이지 직접 확인 · ◐ 일부만(목록 · 메타 · 기사) · ○ 미확인. 번호는 `data.go.kr/data/<번호>`다.
- 열지 못한 사이트(자동 접근 차단 · 스크립트 화면): 브이월드, 국토정보플랫폼, 환경공간정보서비스, 건축HUB, 산림청, 팜맵 사이트, tradedata.go.kr, 오피넷, WAMIS, 국가유산 GIS. 이곳의 신청 절차는 **브라우저로 직접 확인이 필요하다.**
- Codex가 이미 가진 자료와 겹친다. 실제 수집은 Codex 영역이므로 이 문서는 목록과 신청 안내다([수집 현황](../DataCollection/README.md)).

## 0. 먼저 알아둘 변화

- **통계청 → 국가데이터처**(2025-10 출범). `kostat.go.kr` → `mods.go.kr`, SGIS는 `sgis.mods.go.kr`. KOSIS는 `kosis.kr` 그대로.
- **지방행정 인허가(옛 LOCALDATA) → 공공데이터포털로 통합**(2026-01 발표). 인허가 195종 + 생활편의 14종 = 209종, 전부 오픈API. 일부 파일 주소는 아직 옛 주소라 API 쪽이 안전하다.
- **국가공간정보센터 자료(연속지적 · GIS건물통합 · 용도지역)는 브이월드 내려받기**로 연결된다. 지리원 자료는 국토정보플랫폼, API · 표준데이터는 공공데이터포털이다.
- **서울 생활인구 행정동 단위는 2026-07-31 이후 생산 종료** → 250 m 격자로 바뀌었다. 보유한 서울 행정동 인구가 이 계열이면 갱신 경로를 바꿔야 한다.
- 환경부 자료의 기관명은 「기후에너지환경부」로 나온다. 일부 행정구역 이름 · 코드가 바뀌었다(코드 변경 이력 확인 필요).

## 6. 주의

- **정밀 표고의 문턱:** 3차원 좌표가 있고 90 m보다 정밀하면 공개제한이다. 같은 별표에 「인터넷 · 내비게이션 등에서는 1:5,000 이상 지도의 등고선 · 표고값을 표시할 수 없다」는 문구가 있다. 현행본 여부와 게임 적용 범위는 지리원 확인이 필요하다.
- **상업 이용 금지(공공누리 4유형):** 연속지적도 파일 · 용도지역 연속주제 파일 · 산업단지 경계 · 흙토람. 나중에 서비스를 하려면 이 층은 빼거나 기관과 협의해야 한다. 3유형(변경 금지): 에어코리아.
- **좌표계:** 인허가 계열은 EPSG:5174, SGIS는 EPSG:5179, 표준데이터 · 상가정보는 위경도다. SHP 대부분은 페이지에 좌표계가 없어 받은 뒤 확인한다.
- **좌표가 없는 자료:** 저수지 · APC · 위판장 · 도매시장 · 경찰서 · 우체국 · 실거래가 · K-apt는 주소 · 이름뿐이다.
