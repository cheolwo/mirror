# 면목제3·8동 카페 한 곳의 낮 재질 시험

2026-11-15, [③의 반실사 건축 모형 시안](../../assets/changes/2026-11-15-hongdal-diorama-art-direction/myeonmok-material-study.png)을 [r229에서 수용한 범위](../Planning/시스템/PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION/daylight-cafe-first-unity-trial.confirmed.r229.md)에 따라 별도 Windows 검토판으로 옮기는 작업이다.

## 어느 건물을 썼나

기존 카페 1호점의 OSM 건물 외곽은 2026년 10월 경계 후보에서 면목7동에 속한다. r4 면목제3·8동 경계와 가장 가까운 거리는 약 56.7m다. 그래서 면목제3·8동 안의 매장 A 근처에 자료상 2층이고 길을 향한 벽면이 있는 건물 하나를 골랐다. 동 코드는 `1126057500`, 선택 색인의 원본 도형 ID는 `al-d010:row:180706:dong:1126057500`이다. 길 쪽 면은 길이 16.54m, 중점에서 도로 중심선까지는 10.95m다. 층수를 기준으로 지도에 표시한 건물 높이는 6m다. 시험에서 붙인 가게 정면과 입구 방향은 미술 설정이다. 시작 시나리오의 기사 A는 이 정면에서 약 39.3m 떨어진 도로 위에 있다. [좌표·윤곽·원본 지문](../../../artifacts/local/dong-cafe-art-trial-r228/site.json) · [독립 재계산](../../../artifacts/local/dong-cafe-art-trial-r228/site-verified.json)

## 무엇을 만들었나

Blender 5.2.1 LTS에서 민트색 금속 프레임, 크림색 천 차양과 창틀, 목재 카운터·펜던트 조명·커피잔을 만들었다. 정면 폭은 7.20m, 높이는 3.50m, 최대 돌출은 0.90m다. Blender 원본은 127개 부품을 편집할 수 있고, Unity용 FBX는 하나의 메시로 합쳤다. 삼각형은 14,204개, 재질은 12종이다. ## 검증 결과와 남은 일

- **실행판.** Unity 6000.5.6f1 Windows 빌드 오류·경고 0건, 기존 커널 검사 329건 통과. 인자 없이 실행한 창이 D3D12로 면목제3·8동과 카페 정면을 불러오고 응답하는 것을 확인한 뒤 정상 종료했다. 별도 회사·제품 설정으로 저장 위치를 분리했다. [기본 실행](../../../artifacts/local/dong-cafe-art-trial-r228/normal-launch/normal.json) · [빌드 결과](../../../artifacts/local/dong-cafe-art-trial-r228/player-final/build-result.json) · [기존 검사](../../../artifacts/local/dong-cafe-art-trial-r228/player-final/kernel-checks.txt)
- **실제 화면.** D3D11 창 1440×900에서 세 축척의 전후 여섯 프레임을 얻었다. 각 쌍의 화면 좌표와 카메라 값이 같고 역선택한 건물 ID도 일치했다. 다른 동에서 외장이 숨겨지고 복귀하면 다시 보였다. 이 동작 동안 게임 상태 사본이 같았다. 원래 r4의 자료·관련 소스·실행 파일 78개 지문을 다시 대조했다. [실행 캡처 원장](../../../artifacts/local/dong-cafe-art-trial-r228/capture-final/capture.json) · [프레임·원본 독립 대조](../../../artifacts/local/dong-cafe-art-trial-r228/capture-final/independent-review.json)
- **버튼.** 같은 입력 코드 지문으로 격리 Unity Editor GameView에서 네 버튼에 마우스 누름·뗌을 여섯 번 보냈다. 300m → 65m → 미술 끄기 → 켜기 → 동 전체 → 300m 복귀의 화면 폭과 외장 표시가 모두 예상과 일치했다. [입력 결과](../../../artifacts/local/dong-cafe-art-trial-r228/smoke/run-20261115-131909-473/toolbar-input.json)
- **성능.** 이 PC의 RTX 5050, D3D11, 60Hz 창 모드와 수직동기화 1에서 포커스를 가진 300m 장면을 미술 켬·끔 각각 90프레임 측정했다. 프레임 간격 중앙값은 끔 259.7ms, 켬 260.3ms였다. 양쪽 모두 초당 약 4프레임이며, 화면 표시 대기가 각각 256.2ms, 256.9ms로 대부분을 차지했다. 외장 1개·재질 12종을 더한 한 번의 비교여서 다른 PC나 여러 점포의 성능을 예측할 수 없다. 실제 드로 콜은 측정기에 값이 없었다. 다음 성능 시험은 일반 실행에서 화면 표시 대기가 길어지는 원인을 확인하는 것이다. [계측 원본](../../../artifacts/local/dong-cafe-art-trial-r228/capture-final/capture.json)
