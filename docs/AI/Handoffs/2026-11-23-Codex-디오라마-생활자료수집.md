# 홍달 디오라마 공개자료 인계

[분야별 수집 보고서](../DataCollection/Research/2026-11-23-diorama-data-field-report.md)에서 이용자가 검토할 소재와 확보·보류 범위를 먼저 읽을 수 있다. MYBOX의 `디오라마-분야별-수집보고서.md`는 그 폴더에서 열 수 있는 ZIP 링크를 제공한다. [MYBOX 열람본 확인](../../../artifacts/local/public-data/diorama-public-layer-intake-20261123/mybox-field-report-verification.json)

2026-11-23에 서울 공개 자료를 받아 중랑구로 좁혀 확인했다. 기존 상품 카탈로그는 생활용품·가구와 가격 자료로 계속 참조한다. 이번 시설 색인은 기존 지도 색인과 같은 레이어·행정동·공간 검색 구조를 사용하며, Claude의 게임·공간 관련 작업과 별도 파일에 있다. [기존 상품 자료](2026-11-23-Codex-디오라마-상품자료와-꾸미기.md) · [Claude 나눔 설계](2026-11-23-Claude-설계-홍달플레이스-나눔과소통.md) · [지도 색인 규격](../../../eng/data-collection/map_spatial_index.sql)

- PC에서는 [전체 자료목록 SQLite](../../../artifacts/local/public-data/diorama-public-layer-intake-20261123/디오라마-자료목록.sqlite)의 `data_pack`에서 자료 이름, 조회 시작점, 폴더, 기준 파일 지문을 읽는다.
- 탑재 MYBOX의 비공개 `개인/Hongdal/공공데이터보관/2026-11-23-디오라마-생활시설/`에서는 [보관용 조회 안내](../../../artifacts/local/public-data/diorama-public-layer-intake-20261123/MYBOX-자료찾기.md)와 `디오라마-보관목록.sqlite`의 `open_data_pack`을 연다. 원하는 묶음의 이름과 ZIP 안 DB 경로가 함께 있다. [MYBOX 목록 검증](../../../artifacts/local/public-data/diorama-public-layer-intake-20261123/mybox-catalog-verification.json)
- 좌표가 확인된 곳은 시설 참조나 거리 소품 후보로 검토하고, 치수만 있는 물체는 별도 카탈로그에서 형태나 배치를 결정할 때 참고한다. 상태가 남은 항목은 현재 위치·모델·운영 사실로 간주하지 않는다.
- [장면별 자료 조회](../../../artifacts/local/public-data/diorama-public-layer-intake-20261123/r29-scene-reading-order/장면별-자료조회.json)에는 사가정역과 골목, 용마폭포공원, 봉화산 옹기문화마당, 매장 작업대의 조회 예를 담았다. 13개 입력을 원본 DB에서 다시 조회했고 대표점·출입구·규격·소품의 의미와 참고 범위를 구분했다.
- [중랑구 16개 동 위치 참고점 색인](../../../artifacts/local/public-data/diorama-public-layer-intake-20261123/r49-jungnang-reference-index/읽는법.md)에서 24개 범주·3,181행을 한 번에 검색한다. 13개 공개 DB의 원본 행·자료 시점·위치 유형·파일 지문을 확인할 수 있다. 중랑 외 지역은 전체 자료목록의 해당 DB를 연다.

기존 MySQL 가져오기 도구로 로컬 대상의 소유와 연결을 확인했다. 원본 기록 `399`~`403`과 `PrivateReviewOnly` 관측을 별도 연결에서 재조회했다. 두 반입 명세를 재실행한 결과 추가 저장 0건이었다. 점등·소등 값은 `region:kr:seoul`의 한국 표준시 자정부터 지난 초이며, 날짜 기준 표지와 개별 기기의 실제 작동 시각은 서로 다른 열의 의미다. 큰 편차·결측과 같은 값의 반복행은 PC SQLite와 원본에서 볼 수 있다. [역사 원본 재실행](../../../artifacts/local/public-data/diorama-public-layer-intake-20261123/mysql-reference/repeat-noop.json) · [가로등 재실행](../../../artifacts/local/public-data/diorama-public-layer-intake-20261123/mysql-reference/lamp-repeat-noop.json)

PC 전용 15개 DB에는 승인 경계 결속, 일부 건물·환경 자료, 생활인구 세부 원본, 별도 사용 조건의 자료가 있다. MYBOX는 사용 범위를 확인한 내부 묶음을 Windows에서 읽은 수준이다. 원본에 조건이 붙는 경우에는 공개 근거와 사실값, 제한 대상 파일을 구분했다. 클라우드 서버까지의 동기화·출시 배포와 Unity 배치는 확인 범위 밖이다.

자료는 기존 디오라마의 출처·시점·공간 단위 분리 원칙을 지지한다. 같은 자료의 다른 배포 경로, 정류장·노선의 다른 식별자, 도시 집계와 실제 위치의 차이를 보존했다. 출시 조건이 미확정인 가로수 원본, 지리 위치를 특정하지 못한 번호별 출입구, 최신 자전거길 실측 선, 개별 가로등 작동은 보류했다. 새 디오라마 규칙 후보 없음.

## 검증과 보관

- SQL 무결성·외래 키·공간 검색 범위, 원본 파일 SHA-256, 중랑구 GeoJSON 행 수를 대조했다. 주요 공원 원본은 기존 두 파일과 SHA-256이 일치했다. 개방화장실에서 구·유형이 비어 있고 좌표가 동일한 22행은 배치를 보류했다. 역 승강기 2026년 목록은 별도 조사 시점이라 2020년 점의 현재 소속 출입구를 확정하는 데 사용하지 않았다. [2026년 승강기 목록](https://www.data.go.kr/data/15044261/fileData.do)
