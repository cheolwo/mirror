# N1b 부분 반환 — 규암면 팜맵과 농지 소유 공개 자료

2026-11-26 작성 · 2026-11-27 공간 교차 검증 · Codex → Claude · PC 내부 검토

규암면 `4476031000`의 팜맵 경작 도형 9,072개를 공식 연속지적도와 교차했다. 경작 도형 전부에서 하나 이상의 필지가 확인됐고, 농경지 합집합 **15,680,440.90㎡(1,568.04ha)** 중 **99.9954%**가 지적도와 겹쳤다. 현재 소유 구분별 면적은 미확인이다. [N1b 인계](2026-11-26-Claude-인계-농지소유공개자료-Codex.md) · [N1 반환](2026-11-26-Codex-팜맵농촌판-반환.md)

11월 26일 재시도에서 사용자 로그인과 Chrome 권한 허용을 확인하고 충남 최신판 한 건을 선택했다. 브이월드 도움말을 따라 사용자가 승인한 RAON K 2018 설치를 완료했다. 설치 파일은 RAONWIZ 서명이 유효하고 브이월드 다운로드와 SHA-256이 일치했다. 설치 후 목록을 새로 불러와 선택 다운로드를 재실행했다. 전용 프로그램은 시작했고 저장·전송 창이나 충남 ZIP은 확인되지 않았다. 공식 점검 공지는 포털 서비스가 불안정할 수 있다고 안내한다. 이번 다운로드 중단의 원인은 확인되지 않았다. [다운로드 상태](../../../artifacts/local/public-data/farmmap-ownership-n1b-20261126/cadastre-status.json)

공식 선택 동작이 연 전송 페이지를 전면 탭에 띄워 라온K 저장 창을 열었다. 11월 27일 바탕 화면에서 `AL_D002_44_20261108.zip`(659,656,143바이트)을 확인하고 SHA-256·ZIP CRC를 검증했다. 원본은 4개 SHP 묶음이며 DBF·SHX 건수 합계는 3,777,044개다. 네 PRJ의 EPSG:5186 표기와 투영 값·단위를 확인한 뒤 EPSG:5179로 변환했다. 원본 도형 18개는 분석 중 유효한 면으로 보정했다. ## DB와 개인정보 검사

공식 팜맵 원본의 `PNU`를 N1 분석 ID와 다시 대조했다. 경작 도형 9,072개 중 9,071개에 유효한 형식의 대표 필지 후보가 있으며 고유 후보는 6,895개다. 본번·부번이 모두 0인 자리표시 한 건은 빈값으로 뒀다. 대표 PNU는 팜맵 제공자가 선택한 조회 후보이므로 이 후보에 경작지 전체 면적이나 현재 소유 구분을 배정하지 않는다. DB의 `farmmap_pnu_candidate`로 조회한다. ## 재실행·소유 속성 조건과 확장량

1. 확보한 충남 연속지적도 2026-11-08 ZIP과 확인한 SHA-256을 [추출 도구](../../../artifacts/local/public-data/farmmap-ownership-n1b-20261126/cadastre_extract.py)에 넣는다. 모든 SHP 묶음과 부속 파일을 확인하고 EPSG:5179로 변환해 규암면 경계와 교차한 필지를 추린다. 경계에 걸친 필지도 양의 교차 면적이 있으면 포함한다.
2. [규암 시범 집계 도구](../../../artifacts/local/public-data/farmmap-ownership-n1b-20261126/build_gyuam.py)의 `--cadastre`로 CSV를 받아 교차 면적과 지적 도형 연결률을 계산한다. 소유 구분은 별도 보관 근거와 실제 속성 파일을 확인하는 단계에서 결속한다. [실행 결과](../../../artifacts/local/public-data/farmmap-ownership-n1b-20261126/receipt.json)
3. 규암 응답 34,529행은 고유 필지 수가 아니다. 조회 상한 1,000행/쪽으로 규암은 이론상 35쪽이다. 597곳이 모두 규암과 같다고 가정하면 약 20,895회이며 초당 1회 예시로 호출만 약 5시간 48분이다. 실제 건수·허용량·가져오기 시간은 미측정이다. 보관 근거가 확인된 시도별 전체 파일을 사용할 수 있으면 같은 판본은 시도마다 한 번씩 받아 재사용한다.

N1b는 자료와 검증만 반환한다. 새 디오라마 규칙 후보 없음.
