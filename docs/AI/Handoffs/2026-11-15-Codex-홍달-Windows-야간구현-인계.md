## 관2·편1 상호작용 검증 명세

같은 매장의 주문 A와 B, 해당 기사·가게, 고른 동과 카메라를 준비한다. 플레이어는 주문 A를 골라 상대를 보거나 관찰을 끝내고, 중·화를 전환한다. 읽기와 모드 전환은 해당 주문·돈의 권위 값을 보존하며 실제 업무는 기존 명령과 검증을 따른다.

| 단계 | 논리와 표현에서 확인할 내용 |
