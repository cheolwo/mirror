# 2026-11-15 Claude 검증 — 생명주기와 플레이 루프(인지된 범위)

- **작업실 역할.** 개발 작업실(Claude)의 검증 반환이다. 기획 문서와 `Kernel/` · Core는 고치지 않았다. 게임 코드는 관찰용 촬영 장면 하나만 더했다(업무 규칙 변화 없음).
- **사용자의 말(2026-11-15 20시 20분 무렵, 요지).** 구현된 것들을 전반적으로 보고, 생명주기 안에서 일이 마무리되는지, 플레이 폐 루프가 닫히는지 검증할 필요가 있겠다. 일단 인지된 범위 하에서.
- **방법.**
  1. 일의 고리마다 단계 · 누가 움직이나 · 끝 상태를 코드에서 읽었다(Kernel 모듈 · Core 캠페인 · 화면 명령).

  3. 새 관찰 하나: 방향 촬영 끝에서 **맡김을 켜고 사람 손 없이 날을 넘기는 장면**(`ViewProofSoak`, 장면 104)을 더해 돌렸다. 메모리에서만 연 회차이고 사용자 저장은 읽지도 쓰지도 않는다.
- **한계.** 사람이 1배속으로 하루를 끝까지 해 본 것, 일반판을 끄고 다시 켜서 대조한 것(r240 단계 0)은 아니다. 「인지된 범위」는 지금 코드 · 검사 · 촬영과 r240 · 첫 읽기 안내서까지다.
