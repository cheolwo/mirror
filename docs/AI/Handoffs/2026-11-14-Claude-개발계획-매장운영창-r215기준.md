## 1. 한 줄로

**내 매장을 한 번 누르면 왼쪽(동 관리 창 자리)에 그 매장의 운영 창이 뜬다.** 첫 제작은 카페 1호점 한 곳에 묶은 창이다. 지금 오른쪽 카드에 있는 발주 · 검수 · 제조를 이 창의 「요약」 「재료」로 옮긴다. 설비 · 인력 · 원두 구매 · 직접수입은 업무가 아직 없으므로, 첫 판에서는 빈 자리와 흐름, 「업무가 아직 없습니다」만 보인다. 가짜 값으로 채우지 않는다.

## 4. 걸음

**매1. 창 뼈대와 들어가는 길 (카페 1호점 한 곳)**

- 새 파일 `Runtime/SagajeongDispatchStoreDesk.cs`. 왼쪽 동 관리 창 자리에 매장 창 하나. 머리(`← 동 관리` · 이름 · ×), 소재 동 · 가맹/독립 · 상태 한 줄, 탭 다섯.
- 매장 창을 열면 동 관리 창 · 운영 현황은 닫히고, 그 반대도 같다(한 자리에 하나).
- 들어가는 길: 카페 빛 한 번 누르기, 동 관리 창 「이 동의 내 곳」의 카페 줄, 신호 줄 「가서 보기」(카페 신호일 때), 아래 사업 띠의 가맹점(카페) 단추.
- 지도에서는 그 매장에 지금 쓰는 고름 표시(얇은 흰 고리)와 이름표 「카페 1호점 · 고름」. 명덕의 빛과 다른 모양이다.
- 조회만 한다. 여는 것 · 탭을 바꾸는 것 · 닫는 것으로 시간 · 돈 · 주문이 바뀌지 않는다.

**매2. 요약 · 재료 (지금의 카페 카드 옮기기)**

- 요약: 지금 작업 · 기다리는 주문 · 재료 · 자금(사업 공용) 네 칸과 「왜 막혔나」. 까닭은 `chain.ActionKey`에서 읽는다: order → 「우유 1L가 없어 라떼 n잔이 기다립니다」 + 「본부 발주로」, inspect → 「차가 와서 검수를 기다립니다」 + 「검수로」, produce → 「만들 수 있습니다」 + 「1잔 제조」.
- 재료: 재고(가용 · 격리), 오는 물량, 본부 발주(수량 · 추천 · 미리보기의 금액 · 확정), 차가 온 뒤의 검수(인수 · 격리 · 거절), 1잔 제조. 명령은 지금과 같은 `SendBusiness`다. 발주 뒤에는 같은 창에서 진행(발주 → 꺼내 싣기 → 운송 → 하차 → 검수 → 재고)을 읽는다.
- 다른 길(국내 구매 · 직접수입)은 줄만 두고 까닭을 보인다: 「가맹 계약 허용 여부 자료 미확인」, 「수입 담당 없음」.
- 오른쪽 건물 카드의 카페 칸은 발주 · 검수 · 제조를 걷고 「왼쪽 매장 창에서 운영」 줄 하나로 줄이는 것을 권한다. 같은 명령이 두 창에 있으면 헷갈린다(D3).

**매3. 이력**

- 읽기만: 본부 발주(`FranchiseSupply` 주문), 입고 · 검수(`Receipts`), 제조(`Productions`), 매출(`Sales`). 시각순 한 줄씩, 칩으로 거른다.
- 비용 줄은 원장에서 이 매장으로 이어진 것만. 이어지지 않은 것은 「자료 미확인」. 같은 비용을 두 번 빼거나 보이지 않는다.

**매4. 설비 · 인력 탭의 빈 자리**

- 지금 설비 · 직원: 「자료 미확인」. 설비 들이기(고르기 → 구매 확정 → 도착 → 설치 · 점검 → 사용 가능)와 바리스타 고용(후보 → 조건 → 고용 확정 → 근무 시작 → 제조 자리 배치)의 흐름을 회색으로 보이고, 단추는 「업무가 아직 없습니다」로 꺼 둔다.
- 「구입만으로 잔 수가 늘지 않는다」 「동의 기사 고용과 다르다」를 한 줄씩 적는다.

**매5. 누르기 분기 정리 (입력 명세)**

| 누른 것 | 열리는 것 |
| --- | --- |
| 내 매장(카페) 빛 한 번 | 왼쪽 매장 창 + 지도에서 고름 |
| 내 매장 빛 두 번 | 매장 창을 그대로 둔다(D6) |
| 동 이름표 · 땅 두 번 | 동 관리 창(지금 그대로) |
| 기사를 고른 채 배달 매장 | 기존 배정(지금 그대로). 매장 창 열기와 섞지 않는다 |
| 입점 자리 고르는 중 | 자리 고르기가 먼저(동3에서 생길 때) |
| 제휴 음식점 · 남의 건물 | 기존 카드. 운영권으로 보지 않는다 |
| ESC | 설정 화면. 매장 창은 그 아래 그대로 남고, 설정이 떠 있는 동안 눌리지 않는다 |

- 매장 창 안의 누르기 · 휠은 뒤 지도로 새지 않는다(`MapOverlayCovers`에 매장 창 자리를 더한다).

**매6. 방향 촬영과 반환**

- 새 장면: 카페 빛 한 번 → 매장 창(요약), 재료 탭, 발주 미리보기 → 확정 한 번 → 진행, 설비 · 인력 · 이력 탭, 동 관리로 돌아가기.
- 받은 값: 여는 것만으로 시계 · 원장 · 발주 수가 그대로인가, 확정 한 번에 발주가 꼭 하나 · 원장 줄이 그만큼 늘었는가, 매장 창이 떠 있는 동안 지도 누르기가 막히는가, 동 관리 창과 동시에 뜨지 않는가.
- 실제 마우스로 누르는 것은 사용자에게 부탁한다.

**나중 (업무 계약이 먼저 필요하다 — 첫 제작에 넣지 않는다)**

## 7. 그대로인 선

- 열기 · 탭 · 지도 이동만으로 지출 · 발주 · 고용 · 배정이 일어나지 않는다. 확정은 단추를 눌러서만.
- 매장 창 열기에서 `ConnectStore`를 부르지 않는다.
- 전역 하나의 점포 사본은 카페 1호점에만 묶는다. 다른 매장 창에 그 값을 보이지 않는다.
- 자금은 「사업 자금(공용)」으로 적는다. 점포 지갑처럼 이름을 바꾸지 않는다.
- 이어지지 않은 값은 「자료 미확인」. 0이나 추정으로 채우지 않는다.
- ESC는 설정 화면 그대로. 설정이 떠 있는 동안 게임 시간이 멈추고 매장 창도 눌리지 않는다.
- 매1~매4는 Kernel · Core · 팩을 바꾸지 않는다. 검증 촬영(`--sagajeong-…`)은 전과 같다.
- 고름 표시는 명덕의 빛과 다른 모양(얇은 흰 고리 · 이름표)이다.
