## 전달할 한 문장

**지도의 물류센터를 누르면 지붕을 걷어낸 5층 건축 모형이 열리고, 층을 골라 보거나 소포 하나를 따라 내려와 1층의 분류·보류·직원 상차까지 이해한다.** 먼저 내부 전체 대표 한 장으로 읽히는지 보고, 그 구성을 유지하며 상세 장면을 보완한다.

## 대표 장면과 보조 장면

장면들은 같은 센터의 **서로 다른 시점/관점**이다. 예시 소포가 매 장면 새로 생성된 것처럼 그리거나 한 화면의 여러 층에 중복 배치하지 않는다. 시간·수량은 가상 예시로 표시한다.

| 순서 | 화면에서 읽혀야 할 것 | 필요한 상태·조작 표식 |
| --- | --- | --- |
| 먼저: 내부 전체 | 지붕/앞벽을 걷고 5개 층을 벌려 보여주는 비스듬한 모형. 랙·통로·포장·하향 이송·1층 분류/도크가 하나의 건물로 이어짐 | `전체 / 5F / 4F / 3F / 2F / 1F`, 시설/역할명, `가상 내부 모형`, `지도로 돌아가기`. P-001 위치와 내려갈 길 |
| 보조: 지도 진입 | 일반 건물은 회색, 관리 관계가 있는 센터만 민트 계열 운영 표식. 선택 센터와 내부 진입 관계 | 단일동은 선택→내부, 여러 동/역할은 대상 선택. 모형이 없을 때의 준비 중 카드도 짧게 설명 |
| 보조: 3층 상세 | 위층을 가려 랙·피킹 통로·포장 작업대와 하향 투입부가 보임. P-001은 포장완료→투입 대기/인계 중 한 상태 | `3F · 포장 구역`, 선택 소포 현재 위치/다음 인계, `따라보기`, 다른 층 연결 요약. 건물 전체로 돌아가는 `전체` |
| 보조: 1층 상세 | 상층 집결 버퍼와 외부 차량 하차가 분류 투입으로 만남. 읽기·출구 A/B·보류·직원·대차/케이지·상차 차량이 구별됨 | P-001은 A 출구 도착 또는 후속 확인 후 차량 인수 중 한 시점. 읽기 실패 예외는 다른 예시 소포로 구별. 하차/상차 도크 이름과 `지도로 돌아가기` |

첫 시안은 내부 전체 한 장에 집중한다. 전체를 검토하기 전부터 상세 장면을 서로 다른 배치로 독립 제작하지 않는다. 최종 보조 장면 수·크기는 읽힘에 맞춰 조정할 수 있다.

## 도형과 동작을 그릴 때

층별 용도와 연결은 r164의 배치표/흐름도가 소유한다. 3~5층은 재고·피킹·포장 작업 구역의 반복, 2층은 합류/완충, 1층은 분류와 도크라는 **가상 추천안**이다. P-001의 예시는 3층 포장완료→하향 이송→2층 합류→1층 분류→A 출구이며 모든 층 작업대를 순례하지 않는다.

- 층을 잇는 한쪽 이송 영역과 층별 투입/합류점을 읽히게 한다. 주 외형은 경사 컨베이어를 먼저 비교하되 치수/경사 확정값을 쓰지 않는다. 나선형/승강형 대안은 경로가 더 명료할 때 이유와 함께 제안한다.
- 벨트는 이송, 읽기 지점은 감지/식별, 소터는 분기, 작업자는 재확인·소분·상하차, 도크는 차량 인계 장소로 구별한다. 구조가 끊긴 곳에 박스가 공중으로 넘어가는 그림을 넣지 않는다.
- 외부 도착 소포는 포장된 상태로 1층에 투입된다. 모든 외부 물건을 상층으로 보내거나 다시 포장하는 화살표를 넣지 않는다.
- 1층에서 집결/투입 대기·정상 출구·보류·차량 인수는 서로 다른 구역/상태다. 출구 옆에 차량을 그렸다는 이유로 ‘배달 완료’를 붙이지 않는다.
- 상차 장면은 직원이 대상 물건/케이지를 대상 차량에 인계하는 관계가 읽히면 충분하다. 이번 시안은 실제 AnimationClip·작업자 Rig·물리 적재나 설비 제어의 검증이 아니다.
- 전체 모형의 층 펼치기와 벽 가리기는 관찰 표현이다. 선택 층을 바꾸어도 물건·시계·집중/이완 상태가 달라지지 않는다는 설명을 붙인다.

## 표현 기준

모델하우스처럼 내부 공간과 작업대가 먼저 읽히게 한다. 벽·바닥·랙의 낮은 대비를 유지하고 선택 소포·활성 작업·관리 표식만 제한적으로 강조한다. 지도에서 관리 건물에 쓴 민트를 내부 전체 벽/바닥에 칠하지 않는다. 출구/보류/선택은 색 외에 이름·기호로도 구별한다.

기본은 `간단히` 상태다. 정적 방향과 짧은 위치/대기 문구만으로도 흐름을 이해할 수 있어야 한다. 자동 카메라 비행·과한 광선/파동·보상 팝업·새 사업 해금 UI는 이 장면에 추가하지 않는다. 따라보기/추가 효과는 선택형으로 제안한다. 지도 진입/내부 관찰을 직접 조작 미니게임 시작처럼 그리지 않는다.

소포/작업자/차량·층별 물량·배치·시간·동작은 가상 예시다. 실제 업체명·로고·주소와 실제 내부처럼 보이는 표기는 쓰지 않는 쪽을 기본으로 한다. 공식 공개 자료는 r163의 유형 근거이며 사진/도면의 재사용 권리가 확보됐다는 뜻은 아니다. 범용 랙·작업대·벨트 모형으로 표현하고 실재 특정 센터의 정밀 복원을 주장하지 않는다.

## 시안을 돌려줄 때 확인할 것

1. 전체 한 장에서 ‘층별 업무·층간 연결·1층 출구/차량’이 읽히는가? 연결이 가려지면 가림/단면을 먼저 수정한다.
2. 전체 보기와 3층/1층 상세가 같은 건물·설비 연결·소포 ID를 유지하는가? 층 선택과 따라보기의 차이가 보이는가?
3. 정상 A/B와 읽기 실패 보류, 하차와 상차, 출구 도착과 차량 인수가 구별되는가?
4. 전체/층 전환은 관찰 조작이며 지도로 돌아갈 때 기존 시설·카메라·업무 맥락이 유지됨을 설명했는가?
5. 실제 근거·가상 배치·미연결/준비 중을 표시하고, 이미지 제작을 Unity/입력/저장/업무 완료로 보고하지 않았는가?
