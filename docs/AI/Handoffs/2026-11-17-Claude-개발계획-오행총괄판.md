## 2. 구조 제안 — 새 원장 없이 '조회 + 표시'

```text
범위 선택(동/구/전국 + 대상 ID + 집계 대상 + 기준 시점)
  → FiveElementBoardQuery          읽기 전용. 기존 상태 사본·원장·업무에서 다섯 줄을 만든다
      목: 주문 대기/발생     ← 주문 원장
      화: 점포 준비/제조     ← 09 점포 상태
      토: 기사 여력/배차 대기 ← 08 배차 · 기사
      금: 재고/검수/출고     ← 창고·검수
      수: 픽업·전달 진행/완료 ← 배달 업무
      + 실제 활동 분포        ← 기존 오행 활동 발자국(독립 누적). 연결 전이면 '미연결'로 표시
  → PlanImpactMap                   12의 계획 항목 종류 → 영향 칸 + 기존 미리보기 문구
  → OutcomeLink                     계획 → 실제 업무 ID → 결과(완료/미달/대기/실패 이유)
  → UI: OhaengBand(접힌 띠) · OhaengBoardPanel(펼침) · PlanImpactCard(하위 창 옆)
```

| 계획 항목(기존 `SagajeongDispatchNextTodo`) | 영향 칸 | 예상 표시 근거 |
| --- | --- | --- |
| 검수(인수/격리/거절) | 금 → 화 → (조건부) 목 · 수 | 수량은 기존 검수 미리보기 값 |
| 배차(기사 선택) | 목 · 토 · 수 | 대기 −1, 기사 여력 −1, 진행 +1. 조건은 `BusinessPreview.CanConfirm` |
| 발주 · 보충 | 금 · 화 | 기존 발주 미리보기의 수량 · 비용 |
| 제조 | 화 → 수 | 1잔 제조 → 전달 1건 생김(조건부) |
| 모집 · 제휴 | 토 / 화 | 비용은 즉시, 처리 여력은 '교육 · 계약 뒤'의 조건부 예상으로 |

**지킬 것(검사로 고정):**

- 예상은 실적 · 명덕 · 활동 분포에 더하지 않는다.
- 근거가 없는 칸은 0이 아니라 '모름'이나 '미연결'로 표시한다.
- 동 사이 배달은 구 · 전국 합계에서 원 주문 한 번만 센다.
- 판을 열거나 칸을 누르는 것만으로 계획 · 보상을 만들지 않는다.
- 턴 뒤의 현장 수행에 판 승인을 강제하지 않는다.
- 여러 계획의 예상을 단순 합산하지 않는다. 겹치는 자원은 '함께 쓰는 자원' 표시로 알린다.

**범위 결속:**

- 판은 **선택된 동**을 따른다(기존 `PickDong()`, 팔방 이동이 완료되면 그 진입).
- 카메라에 이웃 동이 보인다고 판의 대상이 바뀌지 않는다.
- 계획은 처음 적용한 동 · 거점에 남는다. 계획 줄에 적용 지역을 표시한다.
