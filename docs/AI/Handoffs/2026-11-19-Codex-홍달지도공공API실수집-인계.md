## 불완전 범위와 재개

- 건축물대장은 처음 8페이지 단위로 요청한 뒤 건별 실패의 영향을 줄이기 위해 한 페이지 단위로 이어받았다. 계속 빈 응답 또는 503이 나온 구역은 이전 검증 페이지를 유지했다. [법정동별 완료·다음 페이지](../../../artifacts/local/public-data/hongdal-map-api/building-continuation-20261119.json)
- 상가 수정일 API는 시험한 날짜에 0행이다. 26동 상가 조회는 끝까지 받았다. 브이월드 API는 별도 현재 키·발급 도메인이 필요해 이번에 새로 받지 않았다. 이전에 취득한 필지 파일은 기존 출처를 따른다.
- [수집 범위](../../../artifacts/local/public-data/hongdal-map-api/authenticated-batch-scope-20261119.json) · [버스와 상권 도형](../../../artifacts/local/public-data/hongdal-map-api/bus-and-market-geometry-20261119.json) · [교통량 지점 후속](../../../artifacts/local/public-data/hongdal-map-api/traffic-sites-20261119.json)에서 선행·후속 요청 범위를 찾는다. 같은 요청을 이어받을 때 페이지 크기를 유지한다.
- DB `quick_check`와 외래 키 검사 통과. 검증 기록에 DB·건물색인·연결 파일 지문과 지역별 행 수를 남겼다. 인증값이 DB의 요청·저장 필드에 섞이지 않았음을 로컬에서 확인했다. [재실행·조회 절차](../DataCollection/Runbooks/hongdal-map-public-api.md)

첫 검토에서는 서울 공식 26동 굽기판의 지문과 건물 ID를 대조한 뒤, 면목제3·8동의 소수 업종 점을 기존 지도에 올려 본다. 출입구·층에 대한 사실은 해당 건물과 점포의 자료에 있을 때만 표시한다. 이 인계는 같은 PC의 로컬 자료 준비이며 Unity 적용 권한이나 외부 배포 상태를 바꾸지 않는다.
