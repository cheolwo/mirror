소유 · 동의 정리는 여기까지로 멈춘다(사용자 15:03). N3를 「보정 굽기」로 한다.

| 보정 | 무엇으로 | 표시 |
| --- | --- | --- |
| 논 · 밭 · 과수 | 팜맵 필지 그대로 + 줄 방향(긴 변) · 절기 무늬 | 원본 |
| 하우스 | 팜맵 「시설」 필지 안에 동 간격으로 반원통을 줄지어 세움(동 수는 필지 폭에서 셈) | 모양은 보정 |
| 산 | 표고 · 경사(NASADEM, 이미 있음)로 지형을 세우고, 팜맵 · 건물 · 길이 없는 경사지를 숲으로 채움 | 숲은 보정 |
| 끊긴 길 | 원장의 연결 후보를 그림에서만 이어 보이게(경로 계산에는 쓰지 않음) | 보정 |
| 임시 높이 4m 건물 | 농가 · 창고 꼴의 낮은 지붕으로(높이는 그대로 4m) | 모양은 보정 |
| 물 | 하천 경계(이미 있음) · 논 물길은 그리지 않음(자료 없음) | 원본 |

- 원장 값은 바꾸지 않는다. 보정은 농촌 판을 뽑을 때만 얹고, 필지 · 건물마다 「원본 / 보정」 표시를 남긴다.
- 화면에서 누르면 「이 숲은 보정(경사 + 빈 땅)」처럼 근거가 보인다.
