## 1. 지금 무엇이 읽기 어렵나

- **무엇을 눌렀는지가 글자로만 보인다.** 매장 운영 창도, 기사 카드도 제목 글자 말고는 생김새가 같다. 지도에서 누른 빛의 색(가맹 카페 라일락 · 기사 연두)이 창에는 이어지지 않는다.
- **이름표와 값이 같은 크기로 늘어선다.** 요약 탭의 네 칸은 「지금 단계 · 시작 전」, 「재료 · 우유 1L · 없음」처럼 글 두 줄씩이고, 아래에 「들어오는 차 · 설비 · 직원」 줄이 이어진다. 눈이 어디서 시작할지 정해 주는 것이 없다.
- **흐름이 글 줄이다.** 재료 탭의 진행(본부 발주 → 센터 출고 → 화물 운송 → 점포 검수 → 제조 → 배달 · 수령)이 줄글이라 「지금 어디」를 한눈에 못 본다.
- **빈 탭이 같은 말을 되풀이한다.** 설비 탭은 글 16덩이 가운데 「자료 미확인」이 셋, 꺼진 흐름 다섯 칸, 꺼진 단추, 긴 주의 한 줄이다.
- **기사는 왼쪽 창이 없다.** 기사 빛을 한 번 누르면 오른쪽에 글 카드(「기사 운영 · 고용한 기사」, 「면목제3.8동 · 기사 1」, 상태, 설명 두 줄)가 뜨고, 두 번 누르면 동 관리 창의 「고용」이 열린다. 기사의 그림이나 지금 하는 일의 그림은 없다.

## 2. 원칙

1. **창 머리에 누른 것의 그림.** 색은 지도의 그 빛과 같은 대상 색이다(가맹 카페 라일락 `#C6ACFF` · 음식점 주황 · 기사 연두 `#C9F25A` · 창고 · 센터 하늘). 막힘이 있으면 머리 오른쪽 위에 지도와 같은 「!」.
2. **아이콘은 글의 뜻을 먼저 알린다.** 아이콘만 두지 않고 짧은 이름은 남긴다.
3. **모양을 정해 둔다.** 양은 막대, 개수는 작은 그림 n개(5팩 = 우유 그림 5개), 흐름은 아이콘을 이은 가로 줄(끝난 칸 민트, 지금 칸 금색), 원인 → 결과는 그림 두 개와 화살표.
4. **상태 색 한 벌.** 막힘 빨강 · 할 일 · 지금 금색 · 오는 중 하늘 · 끝 민트 · 자료 미확인 회색. 창 어디서나 같은 뜻.
5. **글은 칸마다 한 문장.** 숫자는 크게, 단위는 작게. 긴 설명은 아이콘에 마우스를 올리면 뜨게 하고 늘 적어 두지 않는다. 같은 값은 한 곳에만.
6. **값은 게임에서 읽는다.** 없는 값은 회색 「자료 미확인」이고, 그림으로 채우거나 0으로 적지 않는다.

## 3. 제안

| 시안 | 무엇 | 지금과 다른 점 |
| --- | --- | --- |
| ② 머리 그림 | 카페는 라일락 가게 그림(차양 · 문 · 잔 간판), 아래에 이름 · 소재 동 · 본부 · 가맹 표 | 제목 글자 → 그림 + 이름. 머리 높이는 지금 제목 칸보다 조금 크다(논리 단위 약 95) |
| ②③⑤ 탭 아이콘 | 요약 · 재료 · 설비 · 인력 · 이력에 아이콘 | 글자 탭 → 아이콘 + 이름 |
| ② 원인 → 결과 카드 | 우유(빗금) → 라떼 그림, 「우유가 없어 라떼 1잔이 기다림」, 「본부 발주로 →」 | 「왜 막혔나」 글 상자 → 그림 두 개 + 한 문장 + 단추 |
| ② 아이콘 칸 넷 | 우유(재고 막대) · 기다리는 주문 · 본부 대금 · 매출을 아이콘 + 큰 숫자로 | 같은 회색 글 칸 → 아이콘 · 상태 색 |
| ②③ 흐름 줄 | 발주 · 출고 · 운송 · 검수 · 제조 · 배달 아이콘 여섯을 이은 줄. 재료 탭에서는 줄 위의 화물차 아이콘이 남은 시간만큼 간다 | 줄글 → 그림 줄 |
| ③ 재고 막대 · 팩 그림 | 가용 · 격리 · 오는 중 세 색 막대, 수락된 5팩 = 우유 그림 5개 + 금액 | 「가용 0 · 격리 0」 글 → 막대 |
| ④ 기사 창 | 기사를 누르면 왼쪽에 기사 창: 연두 오토바이 그림, 소재 동, 상태, 지금 하는 일(픽업지 → 전달지 줄 위의 오토바이), 오늘 건수 · 달린 거리 · 정신 차림, 「지도에서 따라가기」 · 「이 동의 기사」 | 오른쪽 글 카드 → 왼쪽 그림 창 |
| ⑤ 빈 탭 그림 | 설비 · 인력에 업무가 없으면 점선 그림 + 한 문장 + 단계 아이콘 다섯 | 글 16덩이 → 문장 3개 + 그림 |
| ⑥ 아이콘 한 벌 | 매장 · 본부 · 센터 · 화물차 · 오토바이 · 기사 · 바리스타 · 우유 · 원두 · 얼음 · 라떼 · 머신 · 그라인더 · 돈 · 매출 · 시간 · 이력 · 끝 · 막힘 · 동 · 거리 · 정신 차림 · 따라가기 등 28개 | 선 굵기 · 둥근 끝을 맞추고 대상 색으로 칠한다 |

- **기사 창의 값.** 지금 게임에 있는 기사 값은 소재 동 · 번호 · 상태 셋(「잠깐 멈춤 · 픽업지로 가는 중 · 전달지로 가는 중」)뿐이다. 지금의 기사 움직임은 표현이라 주문 · 돈과 이어지지 않는다(카드에 그렇게 적혀 있다). 그래서 ④의 오늘 건수 · 달린 거리 · 오늘의 흐름은 **예시**이고, 만들 때 값이 없으면 「자료 미확인」으로 둔다. 「반쯤 왔다」 같은 진행은 지금 움직임에서 읽을 수 있다.
- **같은 틀.** 매장 창 · 기사 창 · 동 관리 창이 「머리 그림 → 탭 → 지금 한 가지 → 아이콘 칸 → 흐름 줄」의 같은 틀을 쓰면, 무엇을 누르든 읽는 순서가 같다.

## 4. 그림을 어디서 얻나

| | 길 | 좋은 점 | 걸리는 점 |
| --- | --- | --- | --- |
| **A (권함)** | 직접 그린 아이콘과 머리 그림. 원본 SVG, 게임에는 흰 PNG(아이콘 64px, 머리 그림은 큰 그림)로 넣고 대상 색으로 칠한다 | 저작권 걱정이 없다. 게임의 색 규칙을 그대로 쓴다. 시안의 그림이 그 예 | 대상 하나마다 머리 그림 하나를 그려야 한다(카페 · 음식점 · 창고 · 기사 · 동) |
| B | 지도의 그 건물을 게임 안 카메라로 한 번 찍어 머리에 둔다 | 진짜 그 건물이다 | 지도 효과 · 밤 장면에서 흐리고(시안 ⑧의 작은 그림), 창마다 찍는 비용이 든다 |

- 쓰지 않는 것: 실제 사람 사진, 실제 가게 로고 · 간판, 알려진 캐릭터.

## 6. 정할 것

1. **그림 출처.** A 직접 그림(권함) · B 건물 찍기 · C 공개 아이콘 묶음.
2. **머리 그림.** 그린 그림(권함) · 건물을 찍은 그림 · 그린 그림 위에 작은 건물 그림.
3. **기사를 한 번 누르면.** 왼쪽 기사 창(권함, 매장 창과 같은 자리 · 같은 틀) · 지금처럼 오른쪽 카드에 그림만 더하기.
4. **글을 얼마나 줄이나.** 칸마다 한 문장 + 마우스를 올리면 설명(권함) · 지금 글은 두고 아이콘만 더하기.

## 7. 그대로인 선

- 코드 · Kernel · 팩 · 기획 문서는 바꾸지 않았다.
- 값은 게임에서 읽고 없으면 「자료 미확인」. 실제 주문 · 배차 · 결제와 잇지 않는다.
- 동 이름표 · 깃발 · 「!」, 명덕의 빛(고리 없음)은 그대로. 고른 표시(흰 고리)는 명덕의 빛과 다른 모양 그대로.
- 예약은 멈춘 그대로다. git 커밋 · 푸시는 하지 않았다.
