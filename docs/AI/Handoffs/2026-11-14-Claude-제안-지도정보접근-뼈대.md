- **견준 기획.** 이 기획 폴더에서 「우클릭 · 오른쪽 버튼 · 더블클릭 · 두 번 클릭 · 컨텍스트 메뉴」를 찾았으나 손짓을 정한 문서는 찾지 못했다. 아래 규칙은 r162(보는 것은 시간을 넘기지 않는다), r141·r185(차츰 드러내기), r143(관리색), r190(점포로 돌아가기)과 맞췄다.

## 1. 결론

**대상 하나에 손짓 넷, 화면 셋.** 무엇을 누르든 같은 방식으로 정보에 닿는다.

| 손짓 | 뜨는 것 | 지도 |
| --- | --- | --- |
| 올리기 | 이름과 상태 한 줄 | 그대로 |
| 한 번 누르기 | 오른쪽 **정보 칸** | 그대로. 고른 곳에 흰 테두리 |
| 오른쪽 단추 | 그 대상의 **메뉴** | 그대로 |
| 두 번 누르기 | **상세 페이지**(탭) | 뒤에 흐리게 남는다 |

- **지도 위에는 빛만 둔다.** 「매장 A」 같은 이름표는 걷는다. 누를 수 있는 곳은 빛과 점으로 보인다.
- **대상.** 점포 · 매장 · 창고 · 건물 · 동 · 역 · 기사 · 화물차 · 배송지처럼 지도에서 누를 수 있는 모든 것이다.
- **돌아가기.** Esc나 「← 지도로」는 보던 자리 · 확대 · 고른 것으로 돌아간다. r190 제안의 「점포로 돌아가기」와 같은 한 벌이다.

## 2. 대상이 내놓는 것 (뼈대의 약속)

대상의 종류마다 아래 칸을 채운다. 화면은 이 칸만 읽는다.

| 칸 | 어디에 쓰나 | 예: 카페 1호점 |
| --- | --- | --- |
| 이름 · 종류 | 올리기, 정보 칸의 머리 | 카페 1호점 · 가맹점(가상) |
| 상태 한 줄 | 올리기, 정보 칸 | 확인 필요 · 우유 1L 재고 없음 |
| 사실 (세 줄까지) | 정보 칸 | 재료 · 손님 · 메뉴 |
| 할 수 있는 일 (둘까지) | 정보 칸과 상세의 단추 | 보충 발주 · 우유 5팩 |
| 메뉴 줄 | 오른쪽 단추 | 재료 사슬 보기, 개업 준비 보기, 오늘 결산에서 보기 … |
| 탭 | 상세 페이지 | 개요 · 재료 사슬 · 개업 준비 · 결산 · 기록 |
| 이어진 곳 | 상세 페이지에서 다른 대상으로 가는 길 | 본부, 공급사, 물류센터, 화물차, 이 동 |
| 지도 자리 | 「지도를 여기에 맞추기」 | 게임 안 가상 자리. 없으면 「위치 미확인」 |

**새 아이디어는 셋 가운데 하나로 붙는다: 사실 한 줄 · 메뉴 한 줄 · 탭 하나.** 화면의 틀은 건드리지 않는다.

- 예: r190 개업 준비 그래프는 점포의 탭 하나와 메뉴 한 줄이 된다. 점포 카드에 단추를 따로 달지 않는다.
- 예: r174 결산은 점포와 동의 탭 하나, r187 운영 회차는 동의 사실 한 줄이 될 수 있다.

## 3. 규칙

- **보는 것은 아무것도 바꾸지 않는다.** 올리기 · 누르기 · 메뉴 · 페이지 열기 · 돌아가기는 시간과 업무 상태를 바꾸지 않는다(r162).
- **한 번 누르기는 지도를 옮기지 않는다.** 지도를 옮기는 것은 메뉴의 「지도를 여기에 맞추기」와 페이지의 「이어진 곳」뿐이다.
- **돈과 시간이 드는 일은 단추로만 한다.** 메뉴는 보는 곳으로 갈 뿐이다. 단추에는 무엇이 얼마 드는지 적는다.
- **잠긴 것은 흐리게, 이유와 함께 보인다.** 숨기지 않는다(r141 · r185).
- **자료가 없으면 「자료 미확인」.** 0이나 추정으로 채우지 않는다.
- **고른 것은 흰 테두리.** 관리색(민트)은 내 건물에만 쓴다(r143).
- **글자를 늘 보고 싶은 사람.** 설정 칸에 「이름 늘 보기」를 남긴다.
- **마우스 없이도.** 목록(결정 순회 · 신호 줄)과 키보드로 같은 대상을 고르고 같은 정보 칸에 닿는다.

## 4. 지금 화면과 견주기

| 지금 | 뼈대에서 |
| --- | --- |
| 「매장 A · B」 이름표. 기사를 고른 채 이름표를 누르면 바로 배정된다 | 빛나는 점. 올리면 이름, 한 번 누르면 정보 칸. 배정은 정보 칸의 단추 |

| 건물을 누르면 건물 카드 | 건물도 대상이다. 같은 정보 칸에 뜬다 |
| 오토바이를 누르면 기사 무념 카드 | 기사도 대상이다 |
| 동 이름표와 동 사업 칸 | 동도 대상이다. 동 사업 칸이 동의 정보 칸이다 |
| 마우스 단추를 구분하지 않는다. 두 번 누르기와 메뉴가 없다 | 새로 만든다 |
| 올리면 이름이 뜨는 것은 구 지도뿐 | 동네에서도 같게 |
| 넓은 지도에서 「동네로 돌아가기」(단계만 돌아간다) | 보던 자리까지 기억하는 돌아가기 한 벌 |
| 오늘 결산 · 운영 현황 · 설정 · 결정 순회 | 대상이 아닌 늘 있는 단추다. 그대로 두고, 상세 페이지의 틀은 함께 쓴다 |

- 마우스 단추 구분은 코드에서 `GetMouseButton`, `.button ==`, `clickCount`, `ContextClick`을 찾아 확인했다(없다).

## 6. 정할 것

1. **이 뼈대를 기획 정본으로 올릴지.** 올린다면 판본은 Codex가 매긴다. 그 전에는 개발 쪽 제안이다.
2. **두 번 누르기의 뜻.** 이 제안은 상세 페이지다. 지도에서는 두 번 누르기를 확대로 쓰는 관습도 있다. 건물이 아닌 빈 땅을 두 번 누를 때만 확대로 둘 수 있다.
3. **한 번에 되던 일.** 지금은 기사를 고른 채 「매장 A」 이름표를 누르면 바로 배정된다. 정보 칸의 단추로 옮기면 한 번 더 눌러야 한다. 자주 하는 일은 메뉴의 맨 윗줄에 두는 길도 있다(이 경우 3절의 「메뉴는 보는 곳으로만」에 예외가 생긴다).
4. **동 이름표도 걷을지.** 시안에서는 남겼다.
5. **상세 페이지의 크기.** 시안은 지도 위에 크게 덮고 위아래 띠는 남겼다.
6. **K1부터 구현을 시작할지.** r190의 첫 걸음(팩과 규칙)보다 이 뼈대를 먼저 두면 r190은 탭으로 바로 붙는다.
