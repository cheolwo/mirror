## 세 장
| 장 | 단위 | 보이는 것 | 실제 값 | 예시(모양만) |
|---|---|---|---|---|
| A | 동(면목7동) 2.5D | 건물(굽기 결과) · 도로 · 상가 점(업종 색) · 버스정류장 · 학교 · 주차 · 시장 · 공원 | 건물 · 경계 · 도로(굽기), 상가 832곳(2026-09), 정류장 18곳(2026-11), 시설(표준데이터) | 도로 색 교통량(「하루 3.2만 대」 등) |
| B | 구(중랑구 16동) · 서울(25구) | 동별 상가 밀도 색칠, 동별 업종 막대, 25구 상가 수 막대, 정류장 점 | 상가 수 · 밀도 · 업종, 정류장 | 중랑구 수출입 품목, 서울 교통 · 물류 |
| C | 시도 · 전국(17 시도 타일) | 시도별 수출 색칠, 항만 · 공항 원, 층별 자료 상태표, 전국›서울›중랑구›면목7동 내려가기 | 서울 상가 552,422곳(25구 합) | 시도 수출액, 항만 · 공항 물동량 |

- 붉은 지붕 = 높이 임시값(SymbolicHeightFallback) 건물.
- 위 단계 값은 아래 단계 장부의 합으로 만든다(동 → 구 → 시도 → 전국).
- 예시 숫자는 실제 값이 아니다. API 키가 승인되고 호출이 되면 같은 자리에 실제 값을 넣는다(Claude 셸에서는 apis.data.go.kr · api.vworld.kr가 막혀 있다 — Codex 또는 PC에서 부른다).

## 정할 것
1. A: 상가를 **점**으로 둘까, **건물 색**으로 칠할까?
2. B: 구 · 서울 기본 색을 **상가 밀도**로 할까, **인구**로 할까?
3. C: 전국 지도를 **같은 크기 칸(타일)**으로 둘까, **실제 시도 경계**로 그릴까?
