## DB 관계와 조회

- 통합 SQLite(`artifacts/local/public-data/hongdal-price-freight-20261124/hongdal-price-freight.sqlite`)의 관계는 `source → source_file`, `source + region → series → observation`이다. 자료마다 공표처·이용 조건·원본 지문을 보존한다. 같은 값도 가격 종류·규격과 시간 단위가 다르면 별도 계열로 읽힌다.
- `v_display_observation`은 카드용 읽기 조회다. `map_key`는 연결이 확인된 전국·시도·시군구 등만 들어 있다. NULL인 조사권역·위판장은 이름과 목록으로 읽는다. 산지–시장 선은 `originRegionKey`와 목적지의 관계가 확인된 표본에 쓰고, 지명만 있는 사실에 좌표를 만들지 않는다.
- `v_latest_period`는 같은 계열의 마지막 기간을 고른다. 당일과 월평균, 연간과 하반기 조사를 별개 계열로 유지한다. `period_start`·`period_end`와 단위·통화를 카드에 함께 출력한다.
- `v_daily_by_term`은 한국천문연구원 절기 계산표에서 전환일을 날짜 단위로 읽는다. 절입시각은 `calendar_term.ingress_kst`에 남긴다. 월·연간·고시기간은 화면에서 기간으로 표시한다.
- 재생성 도구(`artifacts/local/public-data/hongdal-price-freight-20261124/build_index.py`)와 화면 샘플 내보내기(`artifacts/local/public-data/hongdal-price-freight-20261124/export_screen_examples.py`)는 같은 묶음의 정리본과 기존 절기표를 로컬에서 읽는다. 같은 PC에서 재검사만 하려면 `build_index.py --verify-rebuild`로 원본을 읽고 기존 파일은 열람용으로 유지한다. 게임 실행 중 공급처 API 호출은 필요 없다.

```sql
SELECT label, region_label, value, unit, period_start, period_end, basis, official_url
FROM v_display_observation
WHERE metric = 'auction_origin_trade_price_median_krw'
  AND period_start = '2026-09-02'
  AND unit = '원/10kg'
  AND json_extract(details_json, '$.variety') = '고냉지배추'
  AND json_extract(details_json, '$.grade') = '특(1등)';
```

## 검증 범위와 남은 자료

- 검증 기록(`artifacts/local/public-data/hongdal-price-freight-20261124/verification.json`)에 출처 25묶음, 계열 23,480개, 관측 행 수, 절기 연결, DB 무결성과 외래키 검사, 지문을 기록했다. 25건에는 대조·보류 원본의 출처가 포함된다. 원본 68개 지문을 대조했고, 별도 재생성의 SQLite 지문이 같았다. 재생성 검증(`artifacts/local/public-data/hongdal-price-freight-20261124/rebuild-verification.json`) 화면 카드 23행 재조회(`artifacts/local/public-data/hongdal-price-freight-20261124/screen-verification.json`)에서 모든 행을 DB 원래 값과 대조했다. 9월 2일은 처서, 11월 23일은 소설로 확인했다.
- KAMIS 일부 인증 API는 403이었다. 공개 원본과 공표 화면에서 값을 확보했다. 한 월별 파일의 중복과 기준월 불일치는 검증에 남기고 비교 조회에서 제외했다. 수산 단가는 판매액과 중량의 대응을 원본 두 종류에서 대조했고, 질량과 맞지 않는 단가칸 대신 합계비를 별도로 계산했다.
- 2026년 현재의 산지–시장 냉장차 단건 실결제 운임, 위판장 좌표의 전국 대조, 도로망으로 계산한 실제 주행거리·시간은 미확보다. 연결이 모호한 지역과 없는 관측은 NULL로 둔다. 기준거리를 정해 운임을 추정하는 경우 현장 조건과 계산식을 명시하는 별도 작업이 필요하다.
- 공공누리 제4유형의 조사 보고서와 협의가 필요한 유가 등은 원본별 조건을 보존했다. 현재 파일의 공개 배포 승인, Unity 연결·실행, 예약 변경은 이번 검증 범위 밖이다. 새 디오라마 규칙 후보 없음.
