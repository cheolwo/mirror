## 데이터 관계를 다시 검증할 때

1. `new-packs.json`에서 신규 묶음의 읽기 범위와 DB 위치를 확인한다. 표 변경은 원천에서 확인한 같은 판본 파일로 재구축한다.
2. `build_catalogue.py`는 두 차수의 실제 SQLite 메타데이터와 지문을 읽어서 정규화한다. 각 DB 표 내부의 외래키와 서로 다른 DB의 검토된 연결을 별도로 기록한다.
3. `build_scene_relations.py`와 `verify_relations.py`로 교차 조회를 만든 뒤 사가정역·시장·공표 이동·둘 이상의 판본을 확인한다. `build_catalogue.py --portable`과 `verify_relations.py --portable`은 비공개 보관판 검수다.
4. `archive_pack.py`는 묶음마다 지정된 파생 DB와 근거를 사본으로 저장한다. `archive_readback.py --all-baseline-databases`는 연결 드라이브의 1·2차 보관 DB를 실제로 열어 조회한다. `archive_index.py`는 보관판 목록과 주요 조회 DB를 한 번 더 검증해 연결 드라이브에 둔다.
5. 다른 장치에서 같은 보관판을 읽을 때는 [MYBOX ZIP 격리 복원](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/archive-isolated-join-review/읽는법.md)을 따라 두 보관 폴더와 영수증을 사용한다. 사가정역·시장, 단월 인구, 따릉이 네 사례와 중랑구 지역내총생산을 보관본의 DB만 열어 재현했다. [독립 격리 복원](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/latest-portable-forbidden-audit/isolated-relationships-50.json) · [자치구 생산 조회의 재현](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/latest-portable-forbidden-audit/isolated-grdp-jungnang-50.json)
6. `verify_portable_provenance.py`는 실제 MYBOX 색인과 자료 ZIP에서 출처 기록을 읽고, 관계 목록의 근거 경로를 확인한다. 281개 출처 참조를 보관 기록으로 찾았으며 30개 관계 근거 파일의 위치를 확인했다. [출처·관계 참조 검증](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/portable-provenance-readback.json)

표 내부 외래키와 교차 DB 연결을 통과한 결과는 [조회 검증](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/relation-query-verification.json), [목록 검증](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/catalogue-same-pc-verification.json), [보관 검증](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/archive-readback-verification.json)에서 읽는다. [조회 예 실행](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/query-example-verification.json)과 [장소 조회 DB 재생성](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/scene-replay-verification.json)을 확인했다.

기존 로컬 MySQL `hongdal_dev`는 수질 관측 216개와 혼잡도 출처 2개를 저장했다. 혼잡도 수치 본문은 SQLite에서 읽는다. MySQL에 저장된 3개 원천은 동일한 참조를 별도 읽기로 확인했고 같은 입력의 재실행은 쓰기 0을 반환했다. [MySQL 확인](../../../artifacts/local/public-data/diorama-data-relations-20261123-r2/mysql-reference/verify.json)

연결된 MYBOX 비공개 폴더의 보관본은 읽기 지문을 검증한다. 클라우드 서버의 동기화와 출시판 공개 배포 권리는 별도 확인 대상이다. 같은 PC 자료는 사용 범위가 표시된 로컬 DB에서만 읽는다. 공개자료 검증은 Unity Game View, 실제 입력 또는 E 단계 근거를 부여하지 않는다. 새 디오라마 공통 규칙 후보는 없다.
