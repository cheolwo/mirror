## 그림이 전제하는 화면 규칙

1. **사업은 건물의 역할로 얹힌다.** 새 화면을 만들지 않고 같은 동네에 색이 있는 건물이 늘어난다. 색은 사업마다 하나(음식점 금색, 가맹점 연보라, 창고·화물 파랑, 배달 민트).
2. **엔진은 추천 칸으로 나온다.** 배차·출고 배치·적재 엔진은 "후보와 이유"를 내고 운영자가 고른다. 스케줄링 정책은 운영 방침 카드로 보인다.
3. **사업 사이는 인계 사슬로 잇는다.** 발주 → 센터 출고 → 화물 운송 → 점포 검수 → 제조 → 배달이 한 줄로 보이고, 지금 단계가 강조된다.
4. **높이가 바뀌어도 시간은 하나다.** 위쪽 줄(시각·경 유지·가장 급한 일)은 어느 높이에서도 같다.
5. **축소하면 아래 높이는 묶음 하나로 줄어든다.** 동네 → 배달권 원, 구 → 판 하나.

## 그림과 지금 구현의 차이

- 지금 실행판에는 동네 높이의 배달 배차와 건물 주소 카드까지만 있다. 사업 층·역할 건물·인계 사슬·구 지도의 법정동 판·광역 지도는 없다.
- 그림은 HTML 캔버스로 그린 것이다. Unity 화면이 아니다. 배치·색·글자 크기는 방향만 본다.
