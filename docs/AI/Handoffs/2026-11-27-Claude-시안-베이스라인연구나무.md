## 바로잡은 것

- 베이스라인은 **기사가 자기 배달 내역을 정밀하게 보는 도구**다. 추천 배차(배차 갈래) · 모집 홍보(지사 운영 갈래)는 베이스라인이 아니다. 아침 계획의 연구 표에서 이 둘을 베이스라인과 나란히 둔 것을 고친다.
- 뿌리 마디는 **플랫폼 연결**이다: 지사 대표 계정 → 플랫폼에 API 요청 · 승인 → 지사 · 배달권(중랑 A · B, 광진 A · B) · 기사 자료 → 기사는 자기 계정으로 자기 것만, 지사 대표는 지사 전체 · 배달권별로.
