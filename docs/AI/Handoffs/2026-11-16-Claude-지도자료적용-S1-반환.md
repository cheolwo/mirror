## 2. S2 첫 조각 — 동 메시 손실 없이 싸기

- **까닭:** 사직동이 15.3 MB였다. 지금 굽기로 서울 427동이면 용량이 크다(M4 목표 서울 2 GB 안).
- **잰 것**(`size_probe.py`, 동 메시 7개):

  | 방법 | 크기 |
  | --- | --- |
  | 원래 | 81.9 MB |
  | deflate(손실 없음) | 17.1 MB |
  | 정점 압축(위치 16비트 등) | 55.6 MB |
  | 정점 압축 + deflate | 10.9 MB |

  손실 없는 deflate만으로 충분해서 그것만 했다.
- **한 것:**
  - `Tools~/pack_dong_resources.py`가 굽은 메시를 `HDIZ` 꼴로 싼다. 꼴: 머리에 원래 길이 · 원래 SHA-256, 본문은 raw deflate.
  - 명세의 `bytes` · `sha256`은 싼 파일 값이고, 원래 값은 `rawBytes` · `rawSha256`에 둔다.
  - 게임(`행정동모듈Policy.UnpackModule`)은 머리가 `HDIZ`이면 풀고, 원래 길이 · 해시가 머리와 명세 모두와 맞을 때만 읽는다. 안 싼 `HDIO`도 그대로 읽는다.
- **면목 6동 자원:** 66.6 MB → **12.8 MB**(19%). 빌드의 `resources.assets`는 135 MB → **81 MB**가 됐다.
- **바뀐 코드**(WindowsGame/Runtime):

  | 파일 | 내용 |
  | --- | --- |
  | `행정동모듈Policy.cs` | 풀기 함수 |
  | `SagajeongDispatchDongModules.cs` | 명세의 rawBytes · rawSha256 두 칸, 읽을 때 풀기 한 줄 |
  | `행정동모듈Checks.cs` | 검사 4건(싸고 풀면 같음 · 안 싼 것은 그대로 · 해시 다르면 거절 · 명세와 다르면 거절) |

  원본 사본은 PC 작업 공간 `~/edit-20261116/bak-s2/`에 있다.
