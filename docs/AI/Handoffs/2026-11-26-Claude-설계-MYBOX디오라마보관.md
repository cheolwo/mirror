# 설계 — MYBOX 디오라마 보관 폴더(시도 → 시군구 → 읍면동)

2026-11-26 · Claude 설계 · 내부 검토용

## 사용자의 말

> 로컬에다가 다 저장을 해둘 수는 없을 테니까 … 마이박스에 폴더 구조를 좀 설계를 해가지고 … 도단위, 구단위, 동단위, 면단위 이런 식으로 내려가면서 … 각자 층에 알맞게 그렇게 디오라마 단위들을 이렇게 좀 저장을 해두면 좋겠다 (15:48)

## 지금

- **PC 디스크:** 929 GB 중 69 GB 남음(93%). 전국 굽기 중지 기준은 15 GB다.
- **MYBOX:** PC에 `N:` 드라이브로 붙어 있다.
  - `N:/개인/Hongdal/공공데이터보관/`: 11-17에 Codex가 공개 건물 ZIP을 날짜별로 옮겨 SHA를 확인했다.
  - `N:/개인/Hongdal/옛작업보관-20261123/`
- **크기 어림:** 농촌 땅 층은 면 하나에 약 6 MB(규암면 5.9 MB). 동 메시는 동 하나에 1 ~ 15 MB(싼 것). 전국 3,500여 읍면동이면 수십 GB다.

## 폴더 구조

```
N:/개인/Hongdal/
├─ 공공데이터보관/                  (있음 · 그대로) 공개 원천 자료, 받은 날짜별
├─ 옛작업보관-20261123/             (있음 · 그대로)
└─ 디오라마/                        (새로)
   ├─ README.md                     등급 · 규칙 · 이 문서 요약
   ├─ 목록/
   │   ├─ dioramas.sqlite           전국 색인(아래)
   │   └─ dioramas.csv              같은 내용(엑셀로 보기)
   ├─ _전국/                        전국 단위 판(전국 바탕 · 전국 칸)
   ├─ 11-서울특별시/
   │   ├─ _시도/                    시도 단위 판(수도권 지도 등)
   │   └─ 11260-중랑구/
   │       ├─ _시군구/              구 단위 판(구 지도 · 구 타일)
   │       └─ 1126058000-면목본동/
   │           ├─ 바탕/r2-20261117/  동 메시 · 길 · 영수증
   │           ├─ 땅/                (서울은 없음)
   │           └─ 보기/ · 폰/         (나중 판)
   └─ 44-충청남도/
       └─ 44760-부여군/
           ├─ _시군구/
           └─ 4476031000-규암면/
               ├─ 바탕/r2-20261123/
               └─ 땅/r1-20261126/   hongdal-land-4476031000.bytes · .json · preview-*.png · SHA256SUMS
```

- **이름:** `<코드>-<이름>`. 코드가 앞이라 정렬이 행정 순서와 같고, 이름이 있어 사람이 찾기 쉽다.
- **층:** 읍 · 면 · 동은 모두 행정동 단위라 시군구 밑에 나란히 둔다. 시도 · 시군구 단위 판은 `_시도` · `_시군구`에 둔다(밑줄로 맨 위에 보임).
- **판:** 목적별 판(바탕 · 땅 · 보기 · 폰) 밑에 `r<번호>-<날짜>` 폴더를 둔다. 옛 판을 지우지 않는다. 지금 쓰는 판은 목록에 적는다(바로 가기 파일을 쓰지 않는다).
- **지문:** 판 폴더마다 `SHA256SUMS`를 둔다. 올린 뒤 MYBOX 쪽 파일을 다시 읽어 지문을 맞춘다(11-17 Codex 방식).

### 목록(dioramas.sqlite) 칸

`코드 · 이름 · 단위(전국/시도/시군구/읍면동) · 상위 코드 · 판 종류(바탕/땅/보기/폰) · 판 · 파일 · 크기 · SHA-256 · 품질 등급 · 공개 등급 · 자리(PC/MYBOX/둘 다) · 올린 시각`

게임과 도구는 이 목록을 보고 필요한 판을 PC로 가져온다.

## PC와 MYBOX 나누기

| 자리 | 무엇 |
| --- | --- |
| PC에 둠 | 지금 굽는 판 · 게임에 들어간 판 · 다음에 구울 입력 |
| MYBOX로 옮김 | 다 구운 옛 판 · 게임에 안 쓰는 지역 · 확인 그림 |
| 옮긴 뒤 PC에서 지우기 | MYBOX 지문 확인 뒤에만. 지우기는 매번 사용자 승인 |

## 반드시 정할 것 — 보안각서 자료

바탕 판에는 주소기반산업지원서비스 자료(행정동 경계 원문 · 내비게이션용DB 출입구)가 들어간다. 지금 프로젝트 규칙은 **「원문 PC 밖(클라우드 · git 원격 · Azure) 반출 금지」**이고, MYBOX도 클라우드다.

| 갈래 | 파일 | 가안 |
| --- | --- | --- |
| **올려도 됨(공개)** | 땅 층(팜맵 + NASADEM) · 확인 그림 · 공개 원천 자료 | MYBOX |
| **PC에만** | 바탕 입력(`modules.tar.gz` — 경계 원문, `extras.json.gz` — 출입구), 도로명주소 · 내비DB 원본, 주소가 든 건물 색인 | PC 밖으로 안 냄 |
| **사용자 판단** | 구운 동 메시 `hongdal-dong-<코드>.bytes`(경계로 자른 그림 · 원문 아님) · 길 그래프 | 보안각서 문구를 사용자가 확인한 뒤 정함. 그 전에는 PC에만 |

- PC에만 두는 것이 커지면 MYBOX 대신 **외장 디스크**에 둔다. 외장 디스크는 PC 밖 반출이 아니다.

## 순서(가안)

1. 사용자가 `N:/개인/Hongdal`에 폴더 접근을 허락한다(이 세션 한 번).
2. `디오라마/` 뼈대와 목록을 만든다.
3. 규암면 땅 층(공개)을 첫 판으로 올리고 지문을 확인한다.
4. 농촌 판 대량 굽기(B6)가 끝난 면부터 땅 층을 차례로 올린다.
