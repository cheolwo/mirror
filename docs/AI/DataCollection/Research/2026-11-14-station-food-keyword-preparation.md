## 기존 원자료와 연결한 수준

음식점 인허가 정리표와 두 메뉴 CSV는 [11월13일 수집 기록](2026-11-13-restaurants-regions-menus-intake.md)을 참조하며 복사하지 않았다. 입력 경로/hash는 [manifest.json](../../../../artifacts/local/station-food-keywords-20261114/manifest.json)에 남겼다. 영업신고 상태 인허가의 업태 별칭과 메뉴명 필드의 문자열 근거만 집계한다. 실제 현재 영업·음식 전문점 자격·전체 메뉴·역 반경 식당 집합은 확정하지 않는다.

| 메뉴명에 포함된 문자열 | 서울 메뉴786관측 중 | 행안부 대표메뉴469관측 중 |
| --- | --- | --- |
| 피자 | 4 | 0 |
| 치킨 | 5 | 4 |
| 족발 | 5 | 2 |
| 파스타 | 2 | 0 |

위 숫자는 각각의 원천에서 메뉴명만 검색한 **관측 행수**이며 고유 매장 수·현재 전체 메뉴 수가 아니다. 두 원천을 합산하거나 상호명으로 메뉴를 확인하지 않는다. 메뉴 문자열 근거가0이어도 검색어 후보는 삭제하지 않고 관측 범위의 부족으로 읽는다. `중식→중국식`, `카페→커피숍` 등은 수집 원문을 바꾸지 않는 후보 별칭이다.

역 기준은 [과거 공식 역사정보 수집 보고](../../../Reports/중랑구-7호선-역-기준자료-수집-2026-09-13.md)를 참고했다. 사가정/면목은 공식 원천 수집 이력이 있지만 그때 원본 폴더가 현재 없어 `HistoricalOfficialSourceReport / RawMissing / NotRevalidated`로 구분한다. 강남역은 사용자 요청 seed이며 해당 과거 수집 범위 밖이다. 이번 후보 파일에는 정식 stationId·좌표를 신규 결속하지 않았다. 사가정/면목은 중랑구 음식점 자료가 있으나 역세권별 조인이 미검증이고, 강남은 현재4구 음식점/메뉴 범위 밖이다.

## 공식 API 재확인과 다음 수집의 경계

2026-11-14 공식 문서를 열어 재확인했다. [이전 API 조사/인증 상태](2026-11-14-naver-keyword-api-intake.md)의 수치 수집 보류를 해제하지 않는다. 이번에는 인증 탐색·계정 API 요청을 하지 않았다.

- [SearchAd keywordstool 명세](https://naver.github.io/searchad-apidoc/assets/json/ncc-keywordstool.json): `hintKeywords`는 최대5개. 검색량은 최근30일, 일부 평균 광고 지표는 최근4주다. `<10`은 검열 문자열로 보존해야 한다. 역명이 포함돼도 그 역 주변 사람의 유동인구·주문 수가 되지는 않는다. 공백 금지는 열람한 명세에서 확인하지 못했으므로 입력 변형을 검증한 값으로 저장하지 않았다.
- [API HUB 검색 트렌드](https://api.ncloud-docs.com/docs/naver-api-hub-search-trend): 상대지수이며 기간·기기·그룹 등 요청 문맥이 필요하다. 다른 배치를 자동 합산/정규화하지 않는다. 이번에는 비교 요청 계획을 새로 만들지 않았다.
- [API HUB 지역 검색](https://api.ncloud-docs.com/docs/naver-api-hub-search-local): `display`1~5, `start`1이다. 1·2·3페이지의 플레이스 일반 순위를 수집하는 API로 사용하지 않는다. 메뉴 필드도 없다.
- [개발자센터 이용약관](https://developers.naver.com/products/terms/): 개발자센터 검색 결과/지역정보에는 별도 DB·저장/가공·제공 제약이 있다. 이를 신규 HUB 계약에 자동 확대 적용하지 않으며 서비스별 저장/재배포 검토를 유지한다. 자체 검색어 조합과 실제 응답의 이용 조건은 별개다.

SearchAd의 후보22배치는 기존 `naver-keyword.jobs.json`에 합치지 않았다. 기존6요청 상한과 수집 간격·인증/권한/저장 관문을 먼저 유지해야 한다. 후보 파일이 있다는 이유로 실행 예약이나 게임 자동 반입을 만들지 않는다.
