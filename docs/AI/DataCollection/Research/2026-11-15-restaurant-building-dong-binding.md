## 연결 수량과 의미

기준은 서울 일반·휴게음식점 인허가 2026-11-13 수집본의 자료상 영업 상태다. 관리키는 데이터셋과 관리번호를 함께 쓴다. 같은 상호라도 관리키가 다르면 각각 보존하고, 인허가 건수를 고유한 실제 매장 수로 환산하지 않는다.

| 건물 연결 | 기존 | 보완 후 |
| --- | ---: | ---: |
| 해당 필지의 원본 건물이 하나인 인허가 | 10,273 | 13,458 |
| 같은 필지에 원본 건물이 여러 개인 인허가 | 1,858 | 3,530 |
| 건물 후보 연결 합계 | 12,131 | **16,988** |
| 건물 연결 미결 | 7,673 | **2,816** |
| 자료상 영업 인허가 전체 | 19,804 | 19,804 |

원본 건물이 하나인 13,458키 가운데 13,273키는 모듈 한 곳에 나타나고, 185키는 동 경계에서 같은 건물이 여러 조각으로 나뉘어 여러 동에 나타난다. 전체 동별 파일에서의 인허가 출현은 17,384회이며, 전역 집계는 관리키로 중복 제거한 16,988키다.

연결된 건물 조각은 16,639개다. 건물과 음식점의 양방향 후보 관계 41,087개를 검사했다. 같은 건물의 여러 음식점은 목록으로 유지하고, 복수 건물 필지의 음식점은 후보 건물들을 함께 기록한다. 한 건물 안의 실제 점포·층·출입문은 후속 근거가 필요한 정보다.

인허가에 기재된 관할구 기준으로 연결된 고유 키는 중랑구 3,944, 광진구 4,891, 동대문구 4,207, 노원구 3,946이다. 각 동의 조회 범위는 고정한 건물·행정동 도형 판본을 따른다.

## 주소 보완

기존에 ‘주소 없음/복합주소’로 분류된 7,062키 중 실제 주소 결측은 12키였다. 층·호·건물명이 붙은 주소와 복수 지번을 구별하도록 기존 기록을 다시 읽었다.

총 5,337키의 필지를 추가로 확인했다. 그중 4,857키는 실제 건물 후보까지 연결됐고 480키는 해당 필지가 건물 원본에 없었다. 보완 방법은 층·호 전체 표기를 해석한 903키, 독립된 공공 상가자료에서 도로명주소가 같은 단일 필지를 가리키는 것으로 대조한 4,420키, 별도 수식 없는 단일 지번 14키다.

소진공 상가자료는 2026-06-30 관측을 사용했다. 여기서는 주소와 필지의 대응을 확인하는 근거로 썼다. 해당 인허가와 소진공 상호가 같은 실제 점포라는 확정으로 올리지 않는다. 다중 필지·법정동 코드 충돌·공공주소 간 충돌은 보류 사유를 남겼다. [주소 보완과 원본 행 검증](../../../../artifacts/local/dong-restaurants-building-binding-20261115/address-supplement/README.md)

## 음식점 정보와 메뉴

건물에서 다음 정보를 조회할 수 있도록 준비했다.

- 건물 고유 ID, 원본 행, 지번 필지와 연결 방식
- 음식점 인허가 관리키, 상호, 일반·휴게 구분, 업태·위생업종
- 원문 도로명주소·지번주소와 자료상 영업 상태
- 인허가일·폐업일·원본 수정일·자료 갱신일, 원본 행과 출처 지문
- 허가번호로 연결한 과거 대표 메뉴 관측과, 이름·주소만 맞는 별도 메뉴 후보

연결된 인허가 313키에는 허가번호로 대조된 대표 메뉴 관측 315건이 있다. 이름·도로명주소로만 대조된 16키의 메뉴 관측 59건은 후보 필드로 보존했다. 메뉴의 기준시점·출처와 원본에 기재된 경우 가격을 보존한다. 허가번호 일치 315건은 주된음식 관측으로 가격이 비어 있고, 가격이 있는 59건은 이름·주소 후보 자료다. 전체 메뉴판과 현재 가격 확인은 후속이다.

## 행정동별 자료를 읽는 방법

[보완판 목록](../../../../artifacts/local/dong-restaurants-building-binding-20261115/pack/supplemented-r4/catalog.json)은 65동의 파일 경로·SHA·건물 색인과 메시의 지문을 갖는다. 개별 파일은 modules/{행정동코드}.json.gz다. 음식점 정보와 양방향 참조가 들어 있어 해당 동 파일만 읽고 건물의 후보 목록을 조회할 수 있다.

면목제3·8동에는 인허가 390키와 연결된 건물 조각 335개가 있다. 면목본동은 381키·314조각, 화양동은 940키·727조각, 신설동은 286키·358조각, 월계1동은 312키·251조각이다. 복수 건물 후보 때문에 음식점보다 건물 조각이 많은 경우가 있다.

저장소 루트에서 기존 Python 환경으로 데이터 조회를 검산할 수 있다.

    python -X utf8 artifacts/local/dong-restaurants-building-binding-20261115/query.py --dong 1126057500 --limit 3

특정 건물을 찾을 때는 --building 뒤에 건물 고유 ID를, 특정 음식점에서 건물 후보를 볼 때는 --restaurant 뒤에 관리키를 쓴다. 준비 자료의 조회 도구이며 게임 화면을 조작하는 명령은 별도다.
