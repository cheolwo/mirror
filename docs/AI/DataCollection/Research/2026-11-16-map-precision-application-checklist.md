# 공통 지도 정밀화 자료 신청 확인표

2026-11-16 KST 조사. [Claude 공통 지도 정밀화 계획](../../Handoffs/2026-11-16-Claude-개발계획-공통지도정밀화.md)과 [1회차 반환](../../Handoffs/2026-11-16-Claude-공통지도정밀화-1회차-반환.md)의 W2~W6·W9에 필요한 사용자 신청을 구분했다. 공식 공개 안내를 조회했으며 새 신청·계정 설정·다운로드·제품 변경은 하지 않았다.

**후속 상태:** 사용자가 이후 필요한 신청은 모두 마쳤다고 알렸다. 아래 추가 신청 목록은 당시 조사 이력이며 재신청 지시가 아니다. 승인·수령 파일은 아직 확인하지 않았다. Codex는 별도 신청 없이 받을 수 있는 건축물대장·하천·지형과 경계 후보를 실제로 확보했으며 [후속 수집 결과](2026-11-16-map-precision-public-intake.md)에 기록했다. 당시 Whale 접근 실패와 이후 로그인된 브이월드 공식 다운로드 성공을 구분한다.

## 이미 신청한 자료

사용자가 내비게이션용 DB 신청을 완료했다고 알렸다. 추가 신청 목록에서 제외한다. 기존 [오전 신청 기록](../../Handoffs/2026-11-16-Claude-건물출입구자료-신청.md)에는 내비게이션용 DB와 도로명주소 출입구 정보가 함께 기록되어 있다. 두 자료의 현재 승인·파일 수령 상태를 새로 확인한 것은 아니다.

사용자가 열어 준 Whale의 `주소기반산업지원서비스 - Whale` 창 제목은 확인했다. 두 공식 UI 제어 도구에서 같은 창 소유권 검사 오류가 나서 본문에 접근하지 못했다. `신청 완료`는 사용자 보고이며 승인 완료나 파일 수령 완료로 승격하지 않는다. 개인정보·인증정보·신청번호를 수집하거나 저장하지 않았다.

[내비게이션용 DB 공식 안내](https://www.data.go.kr/data/15050419/fileData.do)는 건물 중심점·주출입구·보조출입구 좌표를 제공한다고 설명한다. 건물 단위 출입구이며 개별 점포 문 확정 자료와 구분한다.

공공데이터포털의 세 제품 설명은 신청서·본인확인·이용목적 심사를 거쳐 제공한다고 안내한다. 세 카탈로그는 무료와 공공누리 1유형 또는 이용허락범위 제한 없음을 표시한다. 실제 신청서의 조건과 승인 범위도 별도로 보존한다. 이 조사에서 제출·본인확인·약관 동의는 하지 않았다. ### 기존 계획에서 보완할 점

전자지도 카탈로그는 경계를 시도·시군구·읍면동·법정리로 소개하지만 행정동을 별도로 명시하지 않는다. 반면 구역의 도형 카탈로그는 법정 읍면동과 행정동을 명시적으로 구분한다. 따라서 전자지도 하나로 현재 필요한 행정동까지 모두 확보된다고 확정하지 않는다. 구역의 도형을 함께 신청하거나 실제 전자지도 레이어에 행정동이 포함되는지 제공기관·수령 파일로 확인한다. 전자지도에 행정동이 반드시 없다고 단정하는 것도 아니다.

건물 도형·실폭도로를 얻는 목적은 전자지도의 제공 항목과 겹친다. 이 목적만으로 별도 건물 도형·도로 도형 신청을 추가하지 않는다. 내비게이션용 DB도 재신청하지 않는다.

## 신청보다 다운로드 경로를 먼저 확인할 자료

### 건물 높이·층수

[건축HUB 대용량 제공](https://www.hub.go.kr/portal/opn/lps/idx-lgcpt-pvsn-srvc-list.do?opnLgcptTaskSeCd=03&srvcNm=%ED%91%9C%EC%A0%9C%EB%B6%80)의 건축물대장 **표제부**를 우선 검토한다. [표제부 공식 카탈로그](https://www.data.go.kr/data/15044720/fileData.do)는 높이·지상층수·지하층수와 대장 식별자를 포함한 파일을 무료·이용허락범위 제한 없음으로 안내한다. [건축HUB 서비스 소개](https://www.hub.go.kr/portal/psg/idx-arch-data-sub.do)는 대용량 누적분/월변동분 파일을 제공한다고 설명한다.

공개 목록과 활용목적 선택은 확인했으나 마지막 파일 수신 시 로그인 필요 여부는 미확인이다. 사용자가 반드시 지금 새 API 키부터 신청해야 하는 것으로 처리하지 않는다. 대용량 확보가 어려워 개별 조회가 필요하면 [건축HUB 건축물대장 API](https://www.data.go.kr/data/15134735/openapi.do)를 활용 신청한다. API 공식 안내는 무료·개발/운영 자동승인, 인증키 필수를 표시한다. 기존 활용승인이 있으면 중복 신청하지 않는다.

### 산·경사 지형

[국토정보플랫폼](https://map.ngii.go.kr/ms/map/NlipMap.do?tabGb=total)의 공개 DEM을 필요한 지역부터 선택해 내려받는 경로다. [공식 DEM 안내](https://www.data.go.kr/data/15059920/fileData.do)는 무료 IMG 자료·이용허락범위 제한 없음·대용량 전송 프로그램 필요를 표시한다. 로그인과 다운로드 이용목적 입력은 제공 화면에서 확인할 사용자 단계이며 새 계정·프로그램 설치는 수행하지 않았다. 상세한 비공개·고해상도 자료 신청과 공개 DEM 다운로드를 구분하고 해상도를 실제 파일 수령 전 확정하지 않는다.

## 신청 목적 초안

> Unity 기반 홍달 경영 시뮬레이션의 수도권 지도 정밀화를 위해 건물·도로·행정동 경계·수계 도형을 정합하고, 기존 출입구 좌표와 연결하여 지형 표현 및 이동 경로를 검증하려 합니다.

사용자가 실제 활용 범위와 일치하도록 수정해 쓰는 초안이다. 상용 게임 배포를 계획한다면 그 목적도 신청서에 포함하고 제공 조건을 확인한다. 이 초안을 실제 제출하거나 이용목적을 사용자 대신 확정하지 않았다.

첫 수령은 전체분을 기준으로 원본 ZIP·SHP 구성 파일과 제공 명세를 함께 보존한다. 이후 변동분의 제공 방식·주기·권한을 확인한 뒤 갱신 절차를 정한다. 원천 좌표계·기준일·ID·라이선스·SHA-256을 남기며 실제 게임 사용·외부 배포 승인과 구분한다.
