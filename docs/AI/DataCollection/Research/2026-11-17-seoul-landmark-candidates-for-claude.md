## 4. 실제 자료에서 찾은 대조 사항

1. **용마폭포와 큰 공원권:** 공원 원본의 동명 행은 면목동 산1-4·면적5107964㎡와 아차산/용마산 권역을 설명한다. 관광안내의 용마산로250-12 폭포시설과 동일한 모델 영역으로 자동 연결하지 않는다. [관광기관 안내](https://access.visitkorea.or.kr/ms/detail.do?cotId=017d92d5-9a20-4700-8420-d71bb6c37a0e)의 중앙 폭포 설명은 2단이며 취소된 모델의 단수·시설 배치는 근거가 아니다.
2. **자료 판본 차이:** 수령한 2026하반기 공원 파일은155행, 같은 날 공개 API가 반환한 전체 건수는133이다. API 표본은5행만 받았으므로 차이22개가 무엇인지 확인했다고 쓰지 않는다.
3. **면적의 잘못된 단위:** 중랑캠핑숲 행의 원문은 `179666㎥`이다. 숫자를 임의로 제곱미터로 정정하거나 모델 치수로 쓰지 않는다.
4. **서울 관리와 서울 소재:** 공원 API에 과천시 주소의 서울대공원이 포함된다. 데이터셋 이름만 보고 서울 행정동에 배치하지 않는다.
5. **언어·서비스·입주 관계:** 관광명소 공개 표본은 요청 경로가ko여도 여러 언어와 수하물보관 서비스가 포함됐다. 전체 조회 필터의 실제 동작은 후속 검증한다. 코엑스 아쿠아리움과 63빌딩 내부 업장을 전체 건물로 합치지 않는다.
6. **좌표 축:** 문화공간 명세는 X_COORD를 위도, Y_COORD를 경도로 설명하며 표본도 그 범위다. 공원 파일의 WGS84 X/Y·GRS80TM 열과 동일한 축 이름으로 통일하지 않는다. 관광 대표점·관리사무소 주소·건물 중심·출입구는 서로 다르다.
7. **주소 충돌:** 푸른수목원은 과거 자료의 연동로240과 최근 리플릿/공원 파일의 서해안로2117 관리사무소를 함께 보존했다. 새 근거가 늘어도 실제 출입구·부지 범위를 검증한 상태는 아니다.

[자료 대조 기록](../../../../artifacts/local/research/seoul-landmarks-20261117-r273/public-data-links.json)은 DDP·세종문화회관의 이름/대표주소 일치2건을 기록한다. 지도상의 건물이나 실제 출입구를 검증한 연결은0건이다.

## 5. 사진·안내도·정밀 형상은 분리해서 다룬다

카탈로그의 공공누리 표기와 링크된 외부 이미지·건축/공공미술의 이용 조건은 구분한다. 서울의 위 목록은1유형 표기를 관찰했다. KTO 국문·무장애 사진에는1·3유형이 혼재한다. [포토코리아 공식 안내](https://phoko.visitkorea.or.kr/main/index.kto)를 따라 이미지별 출처·작가·유형을 보존한다. [서울의 공원 E-BOOK](https://data.seoul.go.kr/dataList/OA-22829/S/1/datasetView.do)은4유형 표기를 관찰했으므로 자유 변형 자산으로 묶지 않는다.

이번에는 사진·안내도 URL을 목록으로 확보했으며 해당 이미지를 내려받거나 텍스처로 가공하지 않았다. 관광 데이터는 정밀 건물 외곽·높이·북 방향·지붕·입면 치수·BIM/IFC를 대신하지 않는다. Claude가 범위를 정한 후보에 대해 필요한 정면/측면/후면/위쪽 참고, 건물 주소키, 실제 접지·출입 자료를 후속 조사한다.

## 6. 검증과 인계 경계
