# 네이버 플레이스 이용자 활동 기록과 검색 순위 조사

- 확인일: 2026-11-17 KST. 네이버 공식 고객센터·운영원칙·개인정보 처리방침·공식 연구 보고서만 사용했다.
- 목적: 이용자가 남기는 활동을 분류하고, 기록의 존재와 검색 반영의 공개 근거를 구별해 홍달 플레이스 설계의 참고자료로 삼는다.
- 범위: 공개 문서의 일회성 조사다. 실제 이용자의 계정·검색 이력·IP·예약 내역은 수집하지 않았다. 공공자료 수집 예약은 중지 상태를 유지한다.

## 1. 판정 방법

| 구분 | 의미 |
| --- | --- |
| 공식 기능/통계 확인 | 활동을 저장·조회하거나 지표로 제공한다는 설명이 있다. 순위 가산을 뜻하지 않는다. |
| 공식 검색 반영 확인 | 일반 플레이스 검색 설명이 해당 요소를 직접 언급한다. 가중치·증가 방향·개별 행동당 점수까지 공개됐다는 뜻은 아니다. |
| 홍달 모형 제안 | 현실 기능을 참고해 게임에 도입할 후보다. 네이버 내부 구현을 확인했다는 의미가 아니다. |
| 미확인 | 확인한 공식 문서에서 기능별 수집 범위 또는 순위 효과를 특정하지 못했다. 사용하지 않는다는 단정도 하지 않는다. |

## 2. 검색에 관해 공개된 범위

[S01](https://new.smartplace.naver.com/help/policy?menu=abuse&tab=smartplace)은 업체 인기도의 입력으로 언급·이미지·클릭 수를 든다. [S02](https://help.naver.com/service/30026/contents/23472?lang=ko&osType=COMMONOS)는 검색 의도와 업체의 관련성, 인기도, 거리, 정보 충실도, 방문 리뷰의 내용·사진, 자체 검색자료를 함께 설명한다. 따라서 **클릭을 고려한다는 사실은 공개돼 있다.**

다만 클릭의 종류·중복 제거 단위, 체류 몇 초부터 유효한지, 저장·길찾기·예약별 점수와 유효기간, 계정·IP별 인정량은 공개된 산식으로 확인하지 못했다. 한 매장에 검색어·위치·시점과 무관한 고정 점수 하나가 붙는 구조라고도 단정하지 않는다.

## 3. 활동별 기록과 해석

각 행의 ‘미확인’은 **해당 활동의 직접적인 일반 검색 순위 효과**를 뜻한다. 사업주에게 개인별 전체 행적이 공개된다는 뜻은 어느 행에도 포함하지 않는다.

## 4. 누가 무엇을 확인하는가

| 보는 주체 | 이번에 확인한 범위 | 확인하지 않은 범위 |
| --- | --- | --- |
| 이용자 본인 | 저장 리스트, 인증한 방문 타임라인, 작성한 리뷰, 해당 리뷰에서 반응·취소 | 본인 활동이 검색 순위에 기여한 정확한 점수, 전체 반응 이력 조회 기능 |
| 사업주 | 매장 유입과 일부 집계, 이용 중인 예약·주문·스마트콜의 업무 기록/통계 | 방문자별 전체 검색·체류·타 매장 이동 이력, 내부 순위 산식 |
| 서비스 내부 | 공식 설명의 검색자료·품질평가·일반적인 이용기록 처리 | 기능별 실제 사건 구조·모델·가중치·계정/IP 처리 공식 |

일반 상세 통계의 유입 검색어는 **우리 매장에 들어온 검색어**다. 지역 전체의 키워드 검색 수나 클릭하지 않은 이용자 수를 그대로 알려 주는 지표로 읽지 않는다. 예약 유입의 세션 규칙도 예약 통계라는 범위를 유지한다.

## 5. 추정으로 참고할 수 있는 것과 한계

**모형상의 가설:** 메뉴를 확인하고 저장하거나, 실제 주문을 완료한 반응은 단순 열람과 다른 의도를 나타낼 수 있다. 재방문·취소·정보 불일치도 서비스 경험을 설명할 수 있다. 다만 이 때문에 네이버가 각 활동에 같은 방식의 가산/감점을 한다고 결론 내리지 않는다.

**반례:** 바로 전화해 목적을 달성한 짧은 방문은 나쁜 체류가 아니다. 메뉴를 찾기 힘들어 오래 머문 방문은 좋은 체류가 아닐 수 있다. 길찾기를 눌러도 오지 않을 수 있고, 공유한 사람이 구매하지 않을 수 있다.

[S06](https://help.naver.com/service/30026/contents/20474?lang=ko&osType=COMMONOS)의 10초 이상 통화 집계는 연결된 통화에 관한 지표다. 이를 장소페이지 체류10초의 순위 가산 기준으로 옮겨 읽지 않는다.

2026-10-22 [S14](https://new.smartplace.naver.com/notices/1140)는 10월29일 블로그·카페 리뷰 표시 수 집계의 변경이 기본 검색/광고 순서에는 영향을 주지 않는다고 밝혔다. **보이는 개수의 증가=순위 상승**으로 일반화할 수 없는 구체 사례다. 리뷰 품질 자체가 전혀 사용되지 않는다는 뜻은 아니다.

[S01](https://new.smartplace.naver.com/help/policy?menu=abuse&tab=smartplace)은 부정 클릭·허위 리뷰/예약의 제외와 제재도 설명한다. 따라서 ‘기록된 활동이 모두 유효 점수’이거나 ‘돈을 주면 실제 순위가 보장됨’이라는 근거로 사용하지 않는다. 홍달의 가상 중개 사건은 별도 게임 기획에서 다룬다.
