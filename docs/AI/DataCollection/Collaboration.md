# 데이터 작업 담당과 Codex·Claude 교대 진입

게임 작업은 [혼용 운영 기준](../Handoffs/Codex-Claude-혼용운영안-2026-11-12.md)에 따라 건별로 담당을 정한다. 현재 구현은 [Unity Windows 현황](../Handoffs/Unity-Windows-구현현황.md)에서 확인한다. 아래 표는 데이터 작업의 배정이다.

## 현재 담당

| 구분 | 현재 상태 | 향후 인계 후보 |
| --- | --- | --- |
| Codex | 기존 수집·정리·앱·서버 담당 | 수용한 반환 범위와 증거를 현재 구조에 대조 |
| Claude | 데이터 수집기·정리는 별도 배정 전까지 미지정 | 인계에 명시된 범위 검토 |
| 정기 수집 프로그램 | 기존 예약과 출처별 주기 유지 | 검증 뒤 한 작업씩 실행 환경 이전 검토 |

게임 역할 변경을 데이터·USB·영상이나 앱/서버의 자동 재배정으로 확대하지 않는다. 실제 기능·경로·판본을 대조하기 전에는 공유 계약·정책·게임 파일의 실행 소유를 부여하지 않는다. 기존 공개자료 네 예약과 배달·원가 예약도 복제하거나 재개하지 않는다.

## 공통 문서와 교대 기준

모든 도구는 루트 [AGENTS.md](../../../AGENTS.md), 가까운 지침, [현재 작업](../CURRENT_WORK.md)과 해당 작업의 현행 문서를 읽는다. Claude 진입점은 [CLAUDE.md](../../../CLAUDE.md)의 `@AGENTS.md`이며 별도 지침 사본을 유지하지 않는다. 실제 로딩 방식은 사용하는 Claude 버전·설정에서 확인한다.

다른 PC·클라우드 또는 같은 작업본에 직접 접근할 수 없는 별도 계정의 개발 인계는 기존 [GitHub 교대 운영 체계](../../Architecture/GitHub기반기획개발교대운영체계.md)를 따른다. 같은 PC의 미커밋 게임 교대는 위 혼용 운영 기준을 따른다. 정확한 저장소·branch·commit 또는 로컬 파일 지문, 필요한 PLAN·작업지시서, 허용 경로, 완료 조건, 시험 명령, 반환 위치를 작업마다 정한다. 자료 확인용 예시를 `Approved`·`ReadyToDispatch`·실행 소유로 자동 승격하지 않는다.

동시에 개발하면 독립된 작업본을 사용하고 같은 checkout이면 교대로 작업한다. 공통 계약·CURRENT_WORK·수집 정책과 원본을 여러 도구가 동시에 수정하지 않는다. 다른 dirty 변경을 옮기거나 stage·정리·덮어쓰지 않는다. 현재 PC의 미커밋 코드와 `artifacts/local`은 GitHub나 다른 도구에 자동 공유되지 않는다. 이번 로컬 인계 재현은 push·실제 클라우드 개발을 뜻하지 않는다.

## 자료의 공통 형식

별도 데이터 모델 대신 [현재 수집 정책](../../../eng/data-collection/jobs.json)과 기존 원본·영수증 형식을 재사용한다. `sourceId`, `datasetId`, 원본 SHA-256, 관측 기준시각과 취득시각, 단위, `kind`, 요청·검증 정책 지문을 보존한다. 정리 작업에서 좌표계·통화·결측과 기준 지역을 임의로 추정하지 않는다.

공급자 안내 `metadata`와 실제 관측 `dataset`, 미도달·거절·부분 저장·실패를 구분한다. 같은 입력·판본의 기존 검증은 재사용하고 새 판본을 검증하기 전 과거 성능·완료로 승계하지 않는다. 원본을 수정하지 않고 정리 결과와 근거를 별도로 반환한다.

## 내부 인계용 원본 묶음

[transfer_snapshot.py](../../../eng/data-collection/transfer_snapshot.py)는 기존 공개자료 한 작업의 현재 원본과 상태를 오프라인으로 묶고 검사한다. 출처별 `latest.json`과 연결된 본문, 필요한 거절·실행 기록의 허용 범위만 다룬다. ZIP에는 내부 협업 목적과 공개 배포 미승인을 표시한다. 개인 배달 DB·checkpoint·고객 정보·계정·인증·전체 artifacts·실행 중 잠금은 넣지 않는다.

아래 명령은 저장소 루트에서 실행한다. `python`은 해당 환경에 준비한 실행기를 뜻하며 Windows의 기존 번들 Python과 예약 명령은 그대로 사용할 수 있다. 새 의존성은 없다. 이번 로컬 검증 실행기는 Python 3.12.14이며 다른 버전·OS의 실제 실행은 별도로 기록한다.

```text
python -B -X utf8 -m unittest discover -s eng/data-collection -p "test_*.py" -v

python -B -X utf8 eng/data-collection/transfer_snapshot.py export --manifest eng/data-collection/jobs.json --job geography --output artifacts/local/geography-handoff-r1.zip

python -B -X utf8 eng/data-collection/transfer_snapshot.py verify --bundle artifacts/local/geography-handoff-r1.zip --manifest eng/data-collection/jobs.json --job geography
```

`export`는 현재 수집 잠금을 얻은 경우에만 원본을 읽고 새 ZIP을 만든다. 기존 출력은 덮지 않는다. `verify`는 자료를 추출·수집·복원하지 않고 파일과 참조·원본 지문을 검사한다. 성공·실패와 별도로 누락·보류 상태를 읽는다. 같은 PC 안의 OS 잠금은 다른 PC·클라우드와 공유하는 잠금이 아니다.

다른 환경에 전달할 때는 export 결과의 `sha256`을 ZIP과 별도로 인계하고 verify의 `--expected-sha256` 값으로 대조한다. 검사에 쓰는 수집기와 manifest도 같은 지문이어야 한다. 자료의 관측 기준시각을 취득시각이나 현재 날짜로 바꾸어 맞추지 않는다.

이 검증 통과는 입력 묶음이 일치한다는 뜻이다. Claude 작업 수용, 공유 자료의 진위·최신성·권리 승인, Drive 업로드, DB 반입, 게임 적용, 외부 이용자 배포를 승인하지 않는다. `redistributionApproved=false`인 원본의 공개 사용 판단도 바뀌지 않는다.

## 첫 Claude 작업 후보와 반환

첫 후보는 **법정동 원본 한 판본의 지역 계층·폐지·중복·누락 검사**다. 실제 배정 때 공유 코드 판본과 묶음 SHA, 읽기 범위, 허용한 새 출력 경로를 지정한다. 새 네트워크 수집·DB 쓰기·Unity 변경 없이 정리 샘플과 검증 보고서를 반환하게 한다. 현재는 후보이며 Claude에게 배정하거나 실행한 상태가 아니다.

반환에는 기준 branch·commit과 필요한 미커밋 변경 지문, 입력 묶음 SHA, 변경한 경로, 실제 실행 명령·종료값·검증 원본, 남은 문제와 재개 위치를 연결한다. 구현·자동시험·실제 화면·클라우드 실행·공개 배포를 각각 구분한다. Codex가 현재 계약과 대조해 검토하고 필요한 소비 앱·실제 화면 검증을 이어간다.

## 클라우드와 자료 배포의 후속 경계

코드·개발 지침은 Git 기준 판본으로, 자료·보고서는 검증한 판본 묶음으로 전달한다. Drive나 다른 보관함을 연결할 때도 각 실행이 필요한 묶음을 내려받아 자기 작업본에서 처리하고 결과를 반환하도록 한다. 사용 중인 DB·공통 `latest.json`을 여러 환경이 동시 동기화하는 방식은 쓰지 않는다.

클라우드 수집을 시작하려면 기존 원본뿐 아니라 최근 수집·거절 기록과 출처별 주기도 전달해야 한다. 한 작업의 실행 장소와 보관함 갱신 담당을 하나로 정하고, 새 환경의 실제 검증 후 기존 예약과 중복되지 않게 전환한다. 이 준비 도구는 자동 복원·업로드·구독·클라우드 환경 생성·예약 변경을 하지 않는다.

등록 USB와 Windows·WPF·Unity의 실제 화면 확인은 현재 로컬 절차를 따른다. 내부 협업 묶음과 Steam 이용자용 자료는 다른 산출물이다. 이용자 배포는 재배포 범위와 호환성·원본 검증을 통과한 별도 자료로 준비하고, 진행 중인 게임 회차의 입력 판본은 유지한다.

이번 실제 변경·회귀·원본 보존·다른 경로에서의 재현 결과와 환경별 미실행 범위는 [검증 기록](../../../artifacts/local/ai-collaboration-preparation-20261111/completion.json)에 연결한다.
