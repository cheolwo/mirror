# 인구·이동·교통 관측

2026-11-12에 [상권·행정동 인구 CSV 실제 수집과 법정동·보행링크 연결 절차](../../SeoulPopulationRoadContext.md)를 추가했다. 최신 인구 관측은 2026년 2분기이며 도로별 인구 관측과 구별한다. 기존 예약 안에서 원본을 주기 갱신한다.

언제 어디에 수요와 이동이 몰리는지 무엇으로 판단하나요?

인구·생활인구·이동·교통·날씨의 관측과 게임 수요 해석을 구분하는 묶음입니다.

## 지금 있는 자료

- KOSIS 지역 통계·지표의 기존 등록과 수집기
- 과거 생활인구 기록과 현재 원본 누락 상태
- 신규 250m 인구·이동·TOPIS의 참고 목록, 날씨 조회의 접근 상태

## 게임과 연결할 맥락

동네별 수요·혼잡 표현의 근거를 검토하고, 합성 인구와 실제 관측의 기준 시점을 구분합니다.

## 상태를 읽는 기준

- 현재 감사의 메타데이터·수집기 준비를 신규 인구·교통 본문 수집 성공으로 표현하지 않습니다.
- 인구가 주문으로, 교통량이 이동 시간으로 바뀌는 비율은 별도의 게임 해석입니다.
- 개인의 이동 궤적을 새로 모으지 않고 지역·시간대 집계의 사용 가능 범위를 검토합니다.

2. 실측과 합성 수요를 화면에서 어떻게 구별할까요?
