# 생산·가공·물류·원가

무엇이 어디서 만들어져 어떤 비용으로 소비자에게 가나요?

생산·공장 가공·창고·운송·매장 조합·판매를 연결하는 흐름과 단위를 살펴보는 묶음입니다.

## 지금 있는 자료

- 농사로·농수산 생산 참고, 국내외 가격 catalog와 수집 등록
- 수협 입출고·재고·위판, 화물·통관·무역·항공·해운 자료
- 재료·원가·공급가 조사와 생산–소비·공장–가맹점 기획

## 게임과 연결할 맥락

생산자 → 가공 → 보관·운송 → 가맹점 준비 → 주문·배달의 인계와 수량·비용 기준을 검토합니다.

## 상태를 읽는 기준

- 가격에는 품목·등급·단위·통화·시장·관측일을 함께 확인합니다. 해외 지표를 국내 동네 가격으로 그대로 적용하지 않습니다.
- 2025년 고정 무역 자료를 최신 운송 상태로 보지 않으며 재고 이동·주문·지급을 구분합니다.
- catalog 등록과 실제 취득은 다릅니다. 게임 반영과 재배포는 출처별 기존 승인 상태를 따릅니다.

## 하나씩 생각할 점

1. 음식 배달 다음에 어떤 공급 인계 한 구간을 먼저 이해할까요?
2. 현실 가격 참고와 게임 내부 가격을 어떻게 구분할까요?
