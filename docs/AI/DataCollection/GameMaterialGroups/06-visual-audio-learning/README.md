# 시각·음향·카드·학습 참고

어떤 그림과 소리·설명으로 게임의 의미를 전달하나요?

구매 자산·생성 이미지·타로·학습 참고를 용도와 권리별로 살펴보는 묶음입니다.

## 지금 있는 자료

- Synty 구매 팩의 배치 지침과 실제 모델 렌더 시안
- 기존 생성 게임 이미지·교육 장면·기사·오토바이·타로 참고의 색인
- 메뉴 이미지, 지역 사진의 보유/누락 상태와 강의·OCR·카페 학습 후보

## 게임과 연결할 맥락

도로 위 객체의 외형, 대상 상세와 카드 슬롯, 교육·성장 표현에 연결할 후보를 검토합니다.

## 상태를 읽는 기준

- 구매한 Synty 원본 파일은 이 검토 ZIP에 넣지 않습니다. 게임에 포함하는 방식과 원본 재배포는 구분합니다.
- 타로 이미지의 개별 출처·권리와 강의·OCR·카페 텍스트의 권리는 별개입니다. 후보가 존재해도 게임 탑재 승인을 뜻하지 않습니다.
- 시안·정적 렌더·게임 내 실제 적용은 서로 다릅니다. 새 이미지·영상·음향 생성은 이번 정리에 포함하지 않습니다.
- 공식 메뉴 이미지·사진도 파일별 이용 조건과 현재 실재를 확인해야 합니다.

## 하나씩 생각할 점

1. 현재 디자인에서 먼저 사용할 외형·카드·설명은 무엇일까요?
2. 학습용 내부 참고와 이용자에게 보여줄 내용을 어떻게 나눌까요?
