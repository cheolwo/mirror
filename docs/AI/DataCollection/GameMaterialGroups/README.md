## 보는 순서

마음에 드는 묶음 하나를 열어 **지금 있는 자료 → 게임과 연결할 맥락 → 하나씩 생각할 점** 순서로 읽습니다. 기존 구현은 연결한 실행 안내와 코드를, 아직 정하지 않은 내용은 해당 기획 문서의 상태를 따릅니다. 03에는 자료 목록과 별도로 현재 게임 구현·기획을 연결했습니다.

한 자료는 주 묶음 한 곳에 두고 필요한 다른 묶음에서 참조합니다. 따라서 인구와 도로, 매장 위치와 메뉴, 생산지와 운송을 함께 생각할 수 있지만 원본을 중복 복사하지 않습니다.

## 목록과 실제 자료의 차이

기존 감사 색인 168행을 모두 연결했습니다. 중복·하위 목록·메타데이터가 포함되어 **168개 고유 데이터셋이나 수집 성공 수가 아닙니다.** 빈 sourceId와 기존 entryIndex·datasetId·status도 그대로 보존했습니다. `collector_ready`는 수집기 준비이며 본문 취득 성공이나 게임 배포 승인이 아닙니다. 과거 원본 누락과 접근 보류도 그대로 둡니다.

이 정리는 내부 검토용입니다. 공개 후보, 권리 검토 중인 자료, 개인 배달 참고를 한 배포 묶음으로 승인하지 않습니다. 출처별 원래 이용 조건과 재배포 상태는 기존 대장을 따릅니다. 게임에 적용할 때는 검토·승인된 판본을 회차 시작에 고정한다는 기존 기획과 대조합니다.

플레이어 개인 세이브·해금·결산은 공통 게임 자료와 별도로 둡니다. 고객·주소·개인 정산 원문, checkpoint 내용, 계정·키, 구매 에셋·강의·카페 원본은 이 검토 묶음에 포함하지 않았습니다.
