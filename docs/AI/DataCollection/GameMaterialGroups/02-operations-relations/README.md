# 운영 대상·관계

누가 무엇을 운영하고, 어떤 주문과 시설로 연결되나요?

기사·매장·메뉴·주문·생산자·공장·창고·가맹점의 관계를 살펴보는 묶음입니다.

## 지금 있는 자료

- 개인 배달 관측에서 파생한 매장·메뉴와 레시피 후보의 기존 색인
- 공개 사업체·시장·창고·제조업소·공동주택 등의 목록·메타데이터
- 프랜차이즈 공급·직영·제휴 관계의 기존 조사와 운영 현황 시안

## 게임과 연결할 맥락

대상을 클릭했을 때 연결된 주문·역할·상태를 보여주고, 운영 대상끼리 인계하는 지점을 검토합니다.

## 상태를 읽는 기준

- 개인 배달 원본·checkpoint는 내부 참고입니다. 고객 정보나 주문 상세를 이 묶음으로 복사하지 않습니다.
- 지도에 매장이 보이는 것과 플레이어가 소유·운영·제휴하는 것은 다른 사실입니다.
- 레시피 후보·상품 후보는 실제 식당 조리법·현재 재고·체결 계약으로 확정하지 않습니다.

## 하나씩 생각할 점

1. 내 운영 현황에서 직접 운영·소속·제휴를 어떻게 구분할까요?
2. 메뉴·재료·수량·준비 시간 중 먼저 연결할 관계는 무엇일까요?
