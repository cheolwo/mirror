# 지역·공간·이동망

게임의 동네는 어디까지이며, 무엇을 따라 이동하나요?

법정동·배달권·도로·건물·지형의 기준을 함께 살펴보는 묶음입니다.

## 지금 있는 자료

- 법정동 코드와 행정동 대응, 법정 경계
- 면목동·상봉동·중화동·묵동 OSM 도로·건물 표본
- NodeLink·보행망·차선·교차로, 고도·토지피복·세계 경계

## 게임과 연결할 맥락

동네 선택, 배달권 구성, 지도 확대·이동, 경로와 오토바이 표현의 공통 바탕으로 검토합니다.

## 상태를 읽는 기준

- 상세 표본과 전국 경계의 정밀도·시점은 다릅니다. 한 동네 표본을 전국 상세 지도로 간주하지 않습니다.
- 도로 형상은 교통량 관측이 아닙니다. 교통량은 04 묶음에서 따로 다룹니다.
- 행정동과 법정동은 별개이며 배달권은 사용자가 구성하는 게임 단위입니다.

## 하나씩 생각할 점

1. 어느 법정동부터 상세 공간을 확보할까요?
2. 배달권 경계와 지도 표시 범위를 어떻게 구분할까요?
