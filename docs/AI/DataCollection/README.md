# 데이터별 수집 채팅과 정기 갱신

## 2026-11-12 유동인구·상권 실제 원본 추가

사용자 요청으로 [서울 유동인구·법정동·보행링크 절차](SeoulPopulationRoadContext.md)를 추가했다. `city-activity`는 상권 인구·행정동 인구·상권 영역·행정동 영역 CSV 네 개를 실제 수집하며 기존 매일 09:20 예약 안에서 최소 648시간 간격으로 갱신한다. 첫 취득은 36,281/9,350/1,650/425행이고 인구 최신 기준은 2026년 2분기다. 법정동·도로 연결은 관할 후보·보행링크 참조이며 도로별 인구값을 생성하지 않는다. 아래 2026-11-11 초기 조사의 metadata-only 상태와 구분한다.

2026-11-11 사용자는 기존 프로젝트의 수집 자료를 전수 조사하고 데이터 맥락별 채팅과 정기 수집 절차를 마련하도록 요청했다. 이 문서는 수집 운영의 진입점이다. 기존 공급자 catalog·원본·출처·단위·DB 원장을 교체하지 않고, 무엇을 어느 채팅에서 어떤 주기로 취득할지 연결한다.

현재 Codex가 전체 작업을 계속 맡으며 미래 Claude Code의 담당은 미지정이다. 공통 지침·정확한 코드 판본·검증된 자료 묶음으로 도구를 교대하는 방법은 [공통 협업 진입](Collaboration.md)을 따른다. 기존 수집기·출처 ID·예약은 유지하며 내부 자료 인계 준비와 클라우드 실행·이용자 배포를 구분한다.

게임에 쓸 자료를 하나씩 검토하려면 [맥락별 여섯 묶음](GameMaterialGroups/README.md)에서 시작한다. 지역·공간, 운영 대상, 게임 규칙, 인구·교통, 생산·물류·원가, 시각·학습 참고를 연결한 내부 검토용 목록이다. 기존 감사 색인 168참조 행의 출처·상태는 보존하며 원본 복사·이용자 배포 승인은 포함하지 않는다.

## 확인한 범위

Hongdal의 공통 공공 API metadata 25개, 포털 활용 API 목록 33개/10모듈, 별도 가격 catalog 13개, 농사로 catalog 17개, 농업 공통 등록 7개와 미국 경영체 catalog 10개를 전수 대조했다. 이 목록은 서로 중복하고, API 하나에 여러 operation이 있으므로 총 데이터셋 수로 합산하지 않는다. 과거 포털의 37API·7파일은 과거 관측이며 현재 계정 접근 허용으로 승계하지 않는다.

공간·도시·교통·세계·무역·운송은 33개 자료 묶음으로 대조했다. `artifacts/local/public-data`의 27개 폴더에는 2,186파일/1,798,117,499바이트가 있다. 복사본·라이브러리·파생물이 포함되어 별도 데이터셋 수와 다르다. 과거 생활인구·사업체·시설·사진 등의 기록이 가리키는 원본 경로 7개는 현재 없다. 과거 수집 성공·DB 반입 근거와 현재 원본 보유를 구분한다.

배달 작업 폴더는 12개 맥락의 DB·자료 묶음을 읽기 전용으로 점검했다. 앱 관측 1,462건과 통합 DB 배달 1,995건은 출처 범위가 달라 합산하지 않는다. 통합 매장 1,206개·메뉴 3,752개·레시피 134개와 메뉴 이미지 3,194개 등도 서로 다른 모집단이다. 고객 값과 금액 원문은 조사 보고에 복제하지 않았다.

학당영상 프로젝트의 9개 자료 묶음도 추가로 대조했다. 현재 파일에서 학습 카드 474후보·159영상, OCR 192문서, 타로 JPG 78개를 확인했으며 카페 자료와 과거 DB 수량을 별도로 기록했다. 전체 색인에는 중복·계층 참조를 포함한 168항목이 있고, 이를 168개 고유 데이터셋이나 수집 성공 건수로 표현하지 않는다. 새 강의·카페 취득이나 생성 예약은 추가하지 않는다.

## 정기 회차

각 수집 채팅은 이 문서와 해당 감사 자료, [실행 정책](../../../eng/data-collection/jobs.json)을 먼저 읽는다. 공통 catalog와 기존 수집기 계약에 맞는 `ready` 항목만 실행한다. 현재 코드·정책의 지문과 OS 수집 잠금을 확인한다. 정책 수정이나 collector 개발을 정기 회차의 수집 작업에 섞지 않는다.

공개 자료 원본 취득은 다음 명령을 쓴다. `작업ID`는 `geography`, `city-activity`, `production-prices`, `logistics-trade` 중 자신의 맥락 하나다.

```powershell
& 'C:/Users/user/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe' -B -X utf8 'C:/Users/user/source/repos/Hongdal/eng/data-collection/collect_public_snapshots.py' --manifest 'C:/Users/user/source/repos/Hongdal/eng/data-collection/jobs.json' --job 작업ID
```

첫 채팅 등록 턴은 읽기 전용으로 자신의 범위와 입력만 검토한다. 실행 입력을 따로 점검할 때는 `--dry-run`을 사용한다. 공개 자료의 첫 실제 취득은 이번 설정 작업에서 확인했으며, 이후 예약에서는 출처별 주기가 지난 경우만 요청한다. 다른 맥락의 채팅은 자신의 작업ID를 대신 실행하지 않는다.

수집기는 무료·무키의 명시된 HTTPS URL과 정해진 POST 입력만 사용한다. 재시도·리디렉션·TLS 우회·키 발급·서버 기동·DB migration을 하지 않는다. 기본 한 회차 최대6요청·12MiB이며 `city-activity`만 CSV 네 개를 포함해 7요청·20MiB다. 연결·본문 읽기에는 요청당30초 한도와 원본별 추가 상한·ZIP/CSV 검증을 적용한다. OS의 DNS 해석까지 전체 실시간30초 안에 강제 종료한다는 보장은 아니다. 오류나 거절은 부분/실패로 기록하고 계속 탭하거나 다른 경로로 우회하지 않는다.

원본은 `artifacts/local/data-collection-runs`에 저장한다. 출처 ID, 데이터 ID, 취득 시각, 실제 기준시각, 단위, 원본 SHA-256, 검증 결과, 이전 원본 위치를 연결한다. 같은 본문은 한 번만 보관하고 변경 없음·주기 미도달·대기·실패를 새 자료 취득과 구분한다. HTML/공식 catalog JSON은 metadata로 별도 집계하며 인구·가격·운송 관측 수집 건수에 더하지 않는다. 변경 원본을 정규화·기존 DB·게임에 자동 반영하지 않는다.

새 출처·새 자격·새 비용·공개/배포·기존 보호를 약화하는 변경은 별도 검토다. `blocked`는 수집 성공이 아니며 자료 없음/0값으로 대체하지 않는다. 공급자가 원문을 바꿨다고 동결 importer의 hash·기준월·판정 정책을 자동 수정하지 않는다.

## 배달 관측과 원가 조사

USB는 이 원본 취득 도구를 사용하지 않고 기존 `delivery-records/phone_app_intake.py`, `phone_session.py`, 작업 폴더 AGENTS와 예약4의 전체 지시를 따른다. 현재 공유 checkpoint는 과거 미완료 요청이 남아 있어 회차 소유 확인 없이 새 날짜로 덮지 않는다. 앱 관측 저장과 통합 DB 반영 결과는 따로 보고한다. 기존 원가 예약7의 일자별 조사와 출처/가격 비교도 별도다.

## 검증과 남은 범위

2026-11-11 첫 실제 취득에서 법정동 코드 53,403행, World Bank 한국 경지면적 1관측, BLS 쌀 가격 22행을 확인했다. World Bank의 관측 기준은 **2024년**이며 공급자 갱신일2026-10-08과 다르다. BLS는 숫자21행·2025-10 결측1행이며 최신 유효 관측월은2026-10이다. 결측 표기 `-`를 0원으로 바꾸지 않는다. 서울 안내3개와 무역·항공·항만 catalog5개는 **metadata 8개**로 따로 보관했다.

준비되지 않은 출처는 `blocked`로 남기므로 일부 원본을 저장한 회차도 종료코드2일 수 있다. `sourceResults`와 `summary`의 실제 저장·실패·보류를 함께 읽는다. 초기 BLS 해석 실패와 수정 전 World Bank 기준시각 기록도 보존하며, 최종 검증 영수증을 현재 결과로 사용한다. 회귀34개와 같은 정책에서 주기 미도달 시 HTTP를 생략하는 결과를 마감 기록에 연결한다.

등록 성공, dry-run, 실제 원본 취득, parser 검증, DB 반입, 게임 적용, 공개 이용은 서로 다른 사실이다. 현재 실행·회귀와 등록 결과는 [마감 기록](../../../artifacts/local/data-collection-audit-20261111/completion.json)에 연결한다. 이 절차의 첫 도입은 프로젝트의 모든 원천을 현재 DB에서 재조회하거나 모든 provider의 live 수집을 검증한 결과가 아니다.

최근의 지도 이미지 시안은 가상 군중 표현이다. 프로젝트에 실제 보행망 표본과 과거 생활인구 수집 기록이 있다는 사실과, 현재 Unity의 이동 경로·신규 실시간 자료가 연결되었다는 사실은 별개다.
