## 주기와 반복 방지

**30분은 작업 확인 간격이며 원천 재취득 주기가 아니다.** [수집 정책](../../../../eng/data-collection/jobs.json)과 원천별 마지막 취득·실패·정책 지문을 우선한다. 법정동 120시간, 인구 CSV 648시간, 해당 안내 메타 20시간 등 기존 간격을 유지한다. 음식점은 원천별 최소 24시간 간격과 실패 시도 후 24시간 냉각을 지킨다. 공급자의 매일 갱신 안내를 30분 재수집 근거로 쓰지 않는다. 기존 분야별 예약을 복제·재개하지 않는다.

실행 잠금을 얻은 회차만 상태 파일을 갱신하며 직전 실행 중이면 건너뛴다. source/query/판본/SHA/수집기·정책 지문으로 완료 결과를 재사용하고 안전한 재개 위치를 남긴다. 권장 회차 상한은 25분, 새 다운로드 원천 1개·1GiB, 새 산출물 2GiB다. 더 작은 원천별 한도가 우선한다. 가용 디스크 20GiB 미만에서 큰 쓰기는 보류한다.

경남 48·전국 도로면 30179·중심선 30182는 새 완결 파일이나 확인 가능한 연결 복구 근거 전까지 같은 실패를 반복하지 않는다. 부분 ZIP·목록 HTML은 수신 완료가 아니다. blocked·미도달·로그인·권리 경계를 우회하거나 좌표계·결측을 추정해 채우지 않는다.

## MYBOX 보관과 정리 상태

현재 중랑구·우선 인접구 입력과 공통 의존자료는 로컬에 둔다. 저빈도 공공자료 보관 위치는 `N:/개인/Hongdal/공공데이터보관/2026-11-17/`이다. 부산·제주·강원 ZIP 3개 278,535,987바이트를 복사하고 **탑재 MYBOX 드라이브에서 읽기 SHA를 대조**했다. 클라우드 서버 동기화 완료는 미확인이므로 로컬 정본을 삭제하지 않았다. [보관 영수증](../../../../artifacts/local/public-data/jungnang-expansion-readiness-20261117-r1/storage-review/mybox-archive-copy.json)과 보관 위치의 `archive-manifest.json`을 따른다.

obj 캐시 3곳 692,032바이트의 삭제는 **자동 승인 검토에서 정책 차단**됐다. 실제 삭제는 0바이트이고 원본 캐시는 남아 있다. 같은 대상을 예약 재시도하거나 다른 삭제 방법으로 우회하지 않는다. [삭제 결과](../../../../artifacts/local/public-data/jungnang-expansion-readiness-20261117-r1/storage-review/cache-cleanup-result.json)를 보존한다.

공공자료만 보관하며 전체 artifacts·비공개 배달기록·키·세이브·현재 실행판·사용 중인 DB·소유 미확인 파일은 자동 보관·정리하지 않는다. 참조·소유·재생성 가능성과 절대 경로를 확인하고 보관 미검증을 로컬 정본 삭제 허가로 삼지 않는다.

추가 수집·정규화·작은 동별 입력·검증·자료 인계와 허용된 공공자료 보관을 담당한다. 제품·Unity·공용DB·Claude 담당 파일·운영 데이터·commit/push는 바꾸지 않는다. 진행 중 게임 입력을 자동 교체하지 않는다. 새 디오라마 규칙 후보 없음.
