# AI 협업 기록

Mirror는 GPT Chat과 Codex를 기획 문답, 저장소 조사, 구현, 검증과 문서 현행화에 사용한다. 대화 자체를 프로젝트의 최종 권위로 삼지는 않으며, 반복해서 나타난 사용자 의도를 추출해 검토 가능한 문서 후보로 만든 뒤 별도의 승인·코드·시험 근거와 연결한다.

```text
사용자 문답
  → AI 의도 후보 추출
  → 반복·변경·미정 구분
  → 기획 문서 또는 작업 후보
  → 사용자 승인
  → 코드·시험·실행 증거
```

## 공개 원칙

- 원문 채팅 전체, 개인정보, 비밀값과 관련 없는 대화는 Git에 넣지 않는다.
- 집계 결과는 사용자의 확정 결정 수나 구현 완료 수로 해석하지 않는다.
- 뒤의 대화에서 변경된 생각을 앞선 표현보다 우선하되, 실제 정본은 `PLANNING.md`, `DECISIONS.md`, `CURRENT_WORK.md`와 코드·시험이다.
- AI가 만든 분류와 요약은 검토 보조 자료이며 스스로 기획을 승인하거나 제품 상태를 변경하지 않는다.
