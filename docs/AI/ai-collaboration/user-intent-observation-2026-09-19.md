## AI가 이 기록을 사용하는 방법

1. 새 요청이 들어오면 관련 `AI-INTENT-*`를 검색해 반복되는 목적을 찾는다.
2. 최신 대화와 현행 기획 문서가 다른지 확인한다.
3. 일치하면 기존 기획·계약·코드를 재사용하고, 다르면 새 후보나 대체 관계로 제안한다.
4. 사용자 승인 전에는 의도 후보를 확정 결정, 개발 승인 또는 Evidence 승격으로 바꾸지 않는다.
5. 구현 뒤에는 코드·시험·실행·commit·push 상태를 별도로 기록한다.
