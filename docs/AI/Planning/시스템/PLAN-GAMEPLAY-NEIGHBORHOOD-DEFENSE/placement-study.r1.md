## 표현과 관계 기준

- 원형 자리 기호 지름 12m, 인원 기호 높이 6m. 실척 인간이 아닌 확대 기호다. 좌표와 건물 높이를 변경하지 않고 기호만 표면 위에 둔다.
- 근접 카메라 orthographicSize 90: 720p 기준 12m는 약 48px, 6m는 약 24px. 전체에서는 이름표와 배치색으로 식별하고 위치 선택 시 개별 focus한다.
- 레벨1 관계: 지휘자 → 배치 지시 → 인원 → 한 자리 점유. 레벨2: 두 자리는 각각 원자료 다각형 내부이고 인원 동시 점유는 한 곳. 레벨3: Core의 AssignedSlotId → 읽기 사본 → View의 동일 ID 위치. 이 모판 관계는 보행·사격·H 공간성립을 정의하지 않는다.
- 후보 visual key: `visual:station-defense:roof-slot.r1`, `visual:station-defense:unit.r1`. Synty Prefab/Clip 사용은 보류. 단색 Cylinder/Capsule fallback을 주 표현으로 사용하며 이동·오르기·총기 동작은 없음.
- 기존 지도·카메라만 재사용하고 운영 객체의 ID/수명/원장을 변경하지 않는다. 선택 미리보기는 노랑, 배치 결과는 파랑, 비점유 자리는 청록으로 구분한다.
- 지휘 UI는 화면 좌측 카드, 전체/운영 복귀는 우상단. 기존 하단 모드 선택바를 덮지 않는다.
