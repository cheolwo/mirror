## 확정 — 목표와 원본 경계

목표는 **실제 사가정역 주변의 배치·건물 규모를 알아볼 수 있도록 근사하고, 외관은 게임용 디오라마로 단순화하는 것**이다. 사진처럼 완전히 동일한 외관은 완료 조건이 아니다.

- 실제 자료의 도로·건물 위치와 바닥 윤곽을 기준으로 삼는다. 생성 이미지는 색감·조명·입체감 참고이며 실제 배치의 근거가 아니다.
- 건물에 대응하는 사용 가능한 높이 자료를 우선하고, 높이가 없으면 확인된 지상 층수에 근거한 추정을 허용한다.
- 원문 높이, 층수, 추정값, 최종 표현값을 혼합하거나 원문에 덮어쓰지 않는다. 자료에 높이가 있다고 해서 현장 실측 또는 현재 상태로 단정하지 않는다.
- 외벽·창문·간판의 동일 복원은 필수가 아니다. 건물 높낮이와 배치의 현실 근사를 먼저 개선한다.
- 게임상 도로 폭·건물 간격 조정은 별도 표현 계층의 정책으로 다룬다. 이번 승인은 임의 건물 이동이나 폭 확대 수치를 확정한 것이 아니다.
- 층수 추정 허용은 자료의 이용조건·검토보류를 해제하지 않는다. 공개·게임 사용 가능 여부와 형식 대응을 먼저 확인한다.

## 구현 준비 제안 — 아직 실행 계약이 아님

| 구분 | 후속 관리 내용 | 금지하는 해석 |
| --- | --- | --- |
| 자료에 명시된 높이 | 원천 건물 ID, 값, 단위, 높이 정의, 출처·기준 시각·판본 | 모두 실측값이거나 같은 기준면이라는 가정 |
| 층수 기반 추정 | 지상 층수 원문, 적용 계수와 산식·정책 판본, 추정 결과 | 추정치를 공식 높이로 저장·표시 |
| 높이·층수 모두 미상 | 결손 사유와 임시 표현 여부 | 주변 건물이나 기본값을 실제 정보로 위장 |
| Unity 표현 | 승인된 건물 대응과 표현값을 입력받고 원본·추정 근거로 역추적 | Unity에서 원천을 재수집하거나 업무·통행 권위를 생성 |

구체 층고, 1층 상가·옥탑·지하층 처리, 높이 충돌의 우선순위, 미상 건물의 기본 표현값은 미정이다. 지하층을 지상 높이에 단순 합산하거나 지형 고도와 건물 높이를 혼동하지 않는다. 추정치는 정책 판본을 통해 다시 계산할 수 있게 하는 방향을 제안한다.

## 작은 검증 구역부터 진행하는 후속 작업

1. 사가정역 주변 작은 블록을 정하고 기존 확보 자료·건물 윤곽·높이·층수의 대응 가능성과 이용조건을 확인한다. 기존 자료로 충족되지 않는 항목만 추가 수집 대상으로 삼는다.
2. 자료 수집은 기존 수집·비공개 검토 저장·독립 재조회·중복 방지 경로를 사용한다. 수집 결과와 공개·게임 적용 승인은 구분한다.
3. 같은 건물인지 확인된 대응, 후보 대응, 불일치·결손을 나눈다. 추정 허용으로 모호한 주소·필지 대응을 자동 확정하지 않는다.
4. 높이의 단위·기준면·층수와 산식을 확인하고 원문/추정/표현 값을 분리한다. 먼저 코드와 자동 검증을 준비한다.
5. 준비된 작은 변경 묶음만 기존 Unity 지도에 반영하고 건물 윤곽·높낮이·도로 간섭·옥상 표식 위치를 확인한다. 실제 Game View 검증은 코드·시험과 별도 증거로 남긴다.

위 순서는 구현 준비 제안이며 이번 문답에서 수집·DB 저장·코드·Scene 변경을 실행한 결과가 아니다. 지역 전체 일괄 수집, 유료 자료, 원격 운영 DB, 외부 게시, 자동 인계는 포함하지 않는다.

## 문답 영향 묶음

- 지금·여기: 사가정역 주변을 관찰하거나 방어 준비를 하는 시점의 지상 디오라마.
- 나·너·이렇게: 플레이어가 주변 도로와 건물의 상대 위치·높낮이를 읽는다. 현실 근거를 가진 규모와 단순화한 외관을 통해 장소를 구별한다.
- 직접 결과: 장소와 건물 규모의 판독 개선. 추정 때문에 세부 오차가 남을 수 있다. 새 자원·전투 결과·회복 규칙은 이번 범위가 아니다.
- 오행·상위 목적: 공간 판독을 지원하는 보조 표현 층이며 새로운 괘·성장 수치를 부여하지 않는다.
- 재사용: 기존 도로·건물 지도, 방어 준비와 옥상 배치 표현. 신규 WI/H 식별자는 발급하지 않는다.
- 레벨 1: 새 플레이 관계 없음. 레벨 2: 높이·시야·간격·옥상 기준점 영향 검토 필요. 레벨 3: 기존 지도 생성·높이 입력·건물 Mesh·옥상 표식 결속 검토 필요.
- 영향 전파: 건물 높이 → 외곽 범위·옥상 기준점 → 표식·카메라 판독까지 검토한다. 실제 접근·안전·사격·통행 가능성으로 전파하지 않는다.
- 검증 상한: 이번에는 기획 문서 정합성만 확인한다. 자료 수집, 추정 코드, Unity 실행 완료를 주장하지 않는다.
