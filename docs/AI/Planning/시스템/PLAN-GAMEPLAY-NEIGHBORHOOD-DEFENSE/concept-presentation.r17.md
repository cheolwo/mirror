- 기준 이미지·자료: [r16](spatial-depth-visual-target.r16.md)의 목표 이미지와 동결 지도, 검증된 높이 보완층.

플레이어가 사가정 전체와 역 주변을 내려다볼 때 벽·창문·옥상·도로 가장자리·그림자·모형 바닥을 판독할 수 있게 한다. 선택·주소 조회·방어 준비의 결과와 비용, 실패·회복·귀환은 기존 승인 기획 그대로다.

## 구현 범위

1. 동결 건물 다각형·높이를 직접 쓰는 절차적 건물 표현을 기본으로 한다. 기존 Synty 대장은 선택 가능한 표현으로 유지한다.
2. 고유 식별자에 따른 벽·지붕 색, 창문·층 경계·옥상 가장자리·차양을 동일 입력에서 재현한다. 창문 개수와 외형은 장식이며 실제 층수·용도·입주 사실이 아니다. 옥상 장식은 기존 높이 이내에 둔다.
3. 큰길 노면 표시, 보도·연석, 두께가 보이는 받침대와 사선 명암을 구현한다. 차선은 게임상 표현이며 공식 차로 수 판정이 아니다.
4. 도로와 건물에 겹치지 않는 가상 장식 녹음을 별도 묶음에 둔다. 나무 위치는 실제 식재·공원 자료로 저장하거나 공급하지 않는다.
5. 지도 좌표/hash·주소·업무·방어 배치 상태는 보존한다. 실제 Game View와 원자료 불변·회귀·성능을 검사한다.

## 구현·검증 결과 (2026-09-13)

별도 Unity 저장소에서 이 판본을 기본 표현으로 구현했다. `사가정모형MeshBuilder`·전용 shader2개·관찰 카메라 SMAA를 연결하고 기존 Synty는 선택형으로 유지했다. 실제 Play Mode의 전체1km/역 주변 확대 화면은 Unity 저장소 `Documentation/Changes/2026-09-13-sagajeong-concept-diorama/`의 PNG와 README에 있다.

- 컴파일 오류0, 새 응답으로 확인한 동기식 EditMode69/69, 실제 렌더러30개, PC Editor5,769프레임 평균212.20fps·95백분위6.38ms.
- 원자료/높이/주소/Scene 파일은 HEAD 대비 불변. 기존 임시4m·건물 결손을 유지하므로 목표 이미지보다 낮고 성긴 구역이 남는다. 추가 식재·외관은 실제 시설 증거가 아니다.
