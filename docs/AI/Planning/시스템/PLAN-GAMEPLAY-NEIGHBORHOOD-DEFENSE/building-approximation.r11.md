## 확정

높이와 층수 자료가 모두 없는 건물은 **기존 임시 높이 표현을 유지**한다. 자료 결손을 이유로 건물을 없애거나 주변 건물의 값을 실제 높이처럼 채우지 않는다. 근거가 확보되고 건물 대응·이용조건 검토를 마친 항목부터 교체한다.

표현에 사용하는 값의 구분은 다음과 같다.

1. **자료 높이:** 출처가 있는 높이. 현장 실측·현재 상태인지는 별도 확인한다.
2. **층수 기반 추정 높이:** 확인된 층수와 산식에 따른 값. 추정 근거와 정책 판본을 보존한다.
3. **임시 높이:** 높이·층수 결손으로 유지하는 표현값. 실제 정보나 층수 기반 추정으로 분류하지 않는다.

임시값을 유지한다는 승인은 새로운 일괄 수치를 정하거나 원문에 임시값을 덮어쓰는 승인이 아니다. 실제 정보·추정·임시의 구분을 데이터에 보존하며, 플레이 화면에서 색상이나 표식으로 구분할지는 아직 결정하지 않았다.

## 문답 영향과 남은 검토

- 지금·여기·나·너·이렇게: 플레이어가 사가정 주변을 관찰할 때 자료 없는 건물도 화면에 남겨 공간의 연속성을 유지한다. 세부 높이의 부정확성은 감수한다.
- 직접 결과와 대가: 건물 누락 없이 동네를 읽을 수 있지만, 임시 높이는 실제 규모를 보증하지 않는다. r10의 보조 표현 목적과 오행·권위 경계는 유지한다.
- 실패·보완: 새 자료가 없거나 건물 대응이 불확실하면 임시 상태를 유지한다. 후속 자료 확보·대응 검토 뒤 해당 건물만 보완한다.
- 배치 영향: 교체 시 높이·외곽 범위·옥상 표식·카메라 판독을 함께 확인한다. 실제 통행·접근·안전·전투 판정으로 전파하지 않는다.
- 미정: 층수 환산 계수, 건물 용도·옥탑 처리, 충돌 자료 우선순위, 구체 교체·검증 묶음.
- 다음 문답: 확보 자료의 높이·층수 정의를 검토한 뒤 **층수 환산 기준을 어떻게 둘지** 한 질문으로 좁힌다. 근거 확인 전 임의의 층고 수치 승인을 요구하지 않는다.
