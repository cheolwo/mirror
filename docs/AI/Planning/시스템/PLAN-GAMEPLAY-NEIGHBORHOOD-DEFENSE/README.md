## WI와 주체

- WI: `WI-CITY-STATION-DEFENSE-ASSIGN`, 가상 지휘자의 방어 인원 옥상 배치 지시.
- 지휘자 `subject:station-defense-commander.v1`, 대기 인원 `subject:station-defense-unit.v1`, 허용 옥상 자리 `subject:station-defense-roof-slot.v1`.
- 초기 상태는 명시적인 준비 검증 세션, 인원 1개·후보 2개다. 한 인원은 한 자리만 점유하며 두 자리를 동시에 차지하지 않는다. 인원 수는 경제 규칙이 아닌 기술 검증 fixture다.
- 선택/미리보기는 무변경, 확인에서 예상 판본과 명령 ID를 검사한 뒤 한 자리로 배치한다. 다른 자리를 고르면 동일 인원의 재배치다. 대가는 기존 자리 점유 해제이며 재화·탄약·현금 비용은 아직 적용하지 않는다.
- 실패: 미등록 자리·다른 세션·오래된 판본·같은 명령 ID의 다른 내용. 실패는 원상태 유지, 재조회와 다시 선택으로 회복한다. 미리보기 취소·전체 보기로 귀환은 무변경이다.
- 권위는 Unity 의존 없는 Simulation Core의 준비 세션이다. Unity는 인터페이스로 명령하고 재조회한 사본만 표시한다. LocalProcess에서 실행하며 RemoteHost도 같은 Core를 사용하는 계약이되 실제 Hosted/HTTP는 후속이다.
- 메모리 전용 세션이며 모드 전환은 보존, 컴포넌트 종료/Play 종료는 폐기한다. 운영 데이터는 Save/Replay에 복사하지 않는다. 같은 초기 입력과 명령의 재생 결정성은 단위 시험으로 검증한다.
- 성공하면 명령·판본·이전/새 자리의 행위 기록이 한 번 남는다. 성장/보상·다른 WI 파생 작용은 NotApplicable이다.
