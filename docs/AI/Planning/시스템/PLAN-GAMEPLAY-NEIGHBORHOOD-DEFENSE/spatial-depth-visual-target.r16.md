## 목표와 자료 권위

이 이미지는 **구도·깊이·재질·조명·밀도에 대한 표현 목표**다. 생성 이미지의 도로선, 건물 위치·외형·높이, 식재, 철도처럼 보이는 요소를 실제 사가정 지리나 새 공공자료로 해석하지 않는다. 실제 구현은 기존 `SagajeongReference.json`의 좌표와 동결 hash, 도로명 표현층, 검토 상태가 명시된 높이 자료를 계속 기준으로 삼는다.

Synty 적용 후보 v2는 설치된 `PolygonCity`, `PolygonTown`, `PolygonNature`, `PolygonConstruction`, `PolygonGeneric`의 형태·색·조립 밀도를 목표로 다시 가공한 시안이다. 실제 Prefab 캡처 두 장을 재질·모듈 형태 참고로만 사용했다. 시안 속 개별 건물·도로 차선·역사 시설·나무 위치는 Prefab 배치 명령이나 공공자료가 아니며, 실제 후보 선택과 크기 검증 전에는 `VisualReviewPending`이다.

따라서 목표는 현실 배치를 생성 이미지에 맞추는 것이 아니라, **현재 자료로 만든 같은 배치를 생성 이미지처럼 입체적으로 읽히게 하는 것**이다. 지도 자료가 없는 곳을 이미지에서 보인다는 이유로 채우지 않으며, 건물 외형도 실제 건축물 복제 대상으로 삼지 않는다.

## 표현 목표

1. 카메라는 전체 1km 범위를 유지하되 현재보다 낮은 사선 시점으로 조정하여 건물 벽면과 디오라마 바닥 두께가 읽히게 한다.
2. 도로 좌표는 보존한다. 큰길·생활도로·골목을 폭, 연석 높이, 보도, 색과 재질로 구별하며 골목은 게임상 사람 두 명이 교행 가능한 최소 판독 폭을 유지한다.
3. 건물은 확인 높이·층수 추정·임시 높이를 서로 구분한 채 높이군과 지붕 변화를 표현한다. 자료가 없는 건물을 무근거 고층으로 만들지 않는다.
4. 한 방향의 따뜻한 주광, 접지 그림자, 약한 주변광 차폐, 모서리 강조로 건물과 도로가 바닥에서 분리되어 보이게 한다.
5. 식재·횡단보도·역사 입구·옥상 방어 자리·큰길 방어 소켓은 별도 표현·게임 레이어 후보로 둔다. 실제 위치 자료나 승인된 배치가 없으면 기호 수준을 넘지 않는다.
6. 운영 업무 표식, 도로명주소, 방어 게임 UI는 같은 지리 위의 독립 레이어로 유지한다. 공간 표현 개선이 운영 권위·주소 권위·통행 가능성·방어 판정을 바꾸지 않는다.
7. Synty Prefab은 데이터 객체를 대체하지 않고 교체 가능한 `VisualRoot` 아래에서만 조립한다. 602개 건물 전체를 일대일로 바꾸지 않고, 역 주변·큰길·높이군별 대표 건물과 가로 소품부터 제한적으로 적용한다.

## 구현 순서

```text
동결 지도 좌표와 현재 Game View
├─ 1. 카메라 각도·전체 맞춤·디오라마 바닥 두께
├─ 2. 도로 폭 계층·연석·보도·교차로 표현
├─ 3. 건물 높이군·지붕·재질·접지 그림자
├─ 4. Synty 후보 대장·크기 측정·VisualRoot 표본 배치
├─ 5. 제한된 식재·역사 중심 표식
└─ 6. 운영/주소/방어 레이어 재결속과 Game View 비교
```

각 단계는 작은 구역과 전체 보기에서 따로 검증한다. 앞 단계가 원본 지도 hash, 선택 좌표, 주소 페이지, 방어 준비 전환을 깨뜨리면 다음 장식을 진행하지 않는다. 첫 구현은 카메라·바닥·광원과 도로/건물 재질의 좁은 절편으로 제한하며, 전체 건물 자산 제작이나 실제 Scene 배치 완료를 이 이미지 하나로 승인하지 않는다.

## r16 첫 구현 결과

- 별도 Unity 저장소의 canonical `SimulationWorldShell`에 `sagajeong-synty-visual.r1` 표현 판본을 연결했다.
- 전체 후보 120동을 결정적으로 선정해 크기·높이 오차를 검사했고 90동은 보유 `PolygonCity` Prefab, 맞지 않는 30동은 원문 외곽 Mesh로 유지했다. 역세권 150m 표본은 13/13이 배치 조건을 통과했다.
- Synty 표현은 하나의 `Synty VisualRoot · 표현 전용` 아래에만 조립하고 Collider를 제거했다. 운영 원장, 도로·건물 좌표, 주소, 통행 가능성, 방어 판정은 바꾸지 않았다.
- 큰길·생활도로·보행로, 연석·보도, 저층·중층·고층 fallback 재질, 접지 그림자와 따뜻한 사선 광원을 분리했다.
- Unity 6000.5.6f1 Play Mode에서 사가정역 확대와 전체 1km Game View를 직접 확인했다. 10초 3,898표본은 평균 237.4fps, 95백분위 frame time 5.41ms였다.
- 회귀는 도로명주소 21/21, 건물 높이 19/19, 역사 방어 준비 8/8, 운영 관찰 5/5, 사가정 디오라마 7/7, 최종 Synty 필터 7/7 통과했다.
- canonical Scene의 서버 미연결 진단 9건은 기존 범위로 남아 있으므로 전체 Scene `Console 0`이나 서버 연결 완료를 주장하지 않는다. 세부 화면과 한계는 Unity 저장소 `Documentation/Changes/2026-09-13-sagajeong-synty-diorama/`에 보존한다.

이 결과는 첫 시각 절편의 실제 Game View 검증이며 방어 폐루프 E 승격, 플레이어 입력 완주, 실제 건물 외형 동일성 승인이 아니다.

## 완료 판독 기준

- 전체 보기에서도 건물 벽면, 높이 차, 큰길과 골목의 위계, 교차로가 한눈에 구분된다.
- 확대 보기에서 도로가 검은 선처럼 보이지 않고 폭과 가장자리 높이를 가진 공간으로 보인다.
- 실제 자료와 추정·임시 표현의 계보가 유지되고 기존 지도·Scene hash 변경은 의도적으로 검토된다.
- 도로명 선택·건물번호 확대·휠·드래그·전체 귀환·방어 준비 분리 회귀가 통과한다.
- 실제 Play Mode/Game View 비교 화면과 Console 범위를 별도로 남긴다. 자동 시험만으로 시각 목표 달성을 선언하지 않는다.

## 미정

- 첫 구현 카메라 pitch/yaw와 전체 보기 여백의 최종 미감 승인.
- 큰길·생활도로·골목의 최종 Unity 폭 배율 및 차로 수 자료 적용 범위.
- 임시 높이 건물의 층수 추정 규칙과 시각적 구분 강도.
- 식재·역사 입구·방어 소켓의 실제 배치 자료와 자산 후보.
- Synty 후보 v2의 최종 미감 승인과 90동 이후 확대 기준.

다음 개발 절편에서는 현재 Game View와 목표 이미지를 나란히 비교해 식별 가능한 건물 다양성, 역 출입구·횡단보도·식재의 근거 자료와 실제 입력 판독을 정밀화한다. 이 문서는 표현 방향과 첫 절편 결과를 기록하지만 생성 이미지 속 임의 지형이나 실제 건물 동일성을 승인하지 않는다.
