# 역 방어 준비 · 공간/배치 적용 연구 r2

상태: `Accepted / PreparationFixtureOnly`. 2026-09-12 월드·공간·배치 담당의 독립 재검산과 개발 통합의 제한 수용. [r1](placement-study.r1.md)의 닫힘 변 거리 누락을 보존하고 대체한다. 실제 옥상 배치 안전·출입·사격 적합성은 승인하지 않는다.

## 수정한 기술 기준

원자료는 `SagajeongReference.json`, `sagajeong-reference.r3`, SHA-256 `4B81E60C3C389A69AA765C8CC8D20E4457102C359A5FFBCD7EBDFA880F7E84E3`로 동일하다.

- `markerDiameter=12m`, `markerRadius=6m`: Cylinder 확대 기호.
- `additionalPolygonEdgeMargin=2m`, `minimumCenterToPolygonEdge=8m`: 기호 외곽이 다각형 경계에서 최소 2m 안쪽에 남도록 한다. 이전 12m 기준 통과를 주장하지 않고 새 근거의 판본으로 교체한다.
- 모든 변(마지막 닫힘 변 포함)에 대한 점-선분 최단거리와 내부 여부를 함께 검사한다. 두 자리 중심 간 약 230.98m로 기호 상호 겹침도 없다.

높이 출처는 `OsmHeightTag`다. 좌표는 원자료 local XZ, 동일 부모 좌표계의 시각 기호 모판에만 적용한다. 비균일 부모 scale·실제 지붕 장애물·구조 하중·난간·접근·추락 안전·보행·사격은 검증하지 않았다. 물리 Collider는 비활성이다.

인원 Capsule의 XZ 크기는 자리보다 작으며 중심은 같은 자리다. 선택→확인→읽기 사본의 AssignedSlotId→표현 관계, 카메라/UI, 무비용 재배치, 운영 상태 불변은 r1의 표현 기준을 유지한다. 지도·기호 크기·부모 변환·실제 이동/전투 도입 시 연구를 다시 연다. 코드 검사, EditMode, 실제 화면 증거는 별도로 기록한다.
