## 추천 · 건물의 인상이 달라지는 순서

**거리에서 먼저 보이는 1층, 층이 읽히는 몸체, 위에서 보이는 지붕**을 차례로 만든다. 외곽과 높이로 덩어리를 잡고 면을 나눈 뒤 문·창·장식을 배치하는 절차를 참고한다. [절차적 건물 모델링 원 논문](https://doi.org/10.1145/1179352.1141931)

| 보는 부분 | 제작 제안 | 화면에서 확인할 변화 |
| --- | --- | --- |
| 길과 만나는 1층 | 출입구 접근점, 연결된 도로, 해당 벽면을 함께 확인한다. 근린생활시설의 확인된 길 쪽에만 유리·문·얕은 차양을 조립한다. 모퉁이에 도로가 둘이어도 전면이 확인되지 않은 면은 단순하게 둔다. | 교차로에서 상가 입구가 어느 쪽인지 읽히고 옆 골목에서는 셔터나 벽면이 구별된다. |
| 위층의 벽 | 층수와 벽 길이에 비례해 창 묶음과 여백을 잡는다. 단독주택은 작은 창과 조용한 측벽, 공동주택은 발코니 묶음과 세로 계단실, 근린생활시설은 1층보다 작은 상층 창으로 시안을 잡는다. | 색이 비슷해도 주택·상가·공동주택을 창의 배열과 깊이로 구별한다. |
| 지붕의 윤곽 | 기존 옥상 소품 중 대표 건물마다 파라펫(옥상 테두리), 작은 옥탑 또는 처마에서 한 가지를 강조한다. 벽돌·콘크리트·금속판·방수층의 거칠기와 모서리 명암은 가까울 때 드러나게 한다. | 위에서 볼 때 옥상 선이 구별되고 판처럼 평평해 보이는 벽에 깊이가 생긴다. |
| 낮과 밤 | 낮에는 유리와 벽이 다르게 빛을 받게 한다. 밤에는 창·외부등의 밝기를 조명 비교에서 따로 조정하고 활동·기사·선택 표식의 색은 기존 값으로 고정해 촬영한다. | 야간에도 옥상선과 창틀이 읽히고 밝은 건물 위에서 경영 표식을 찾을 수 있다. |

용도와 출입 방향을 먼저 정한 뒤 건물별 색과 재질을 고른다. 같은 계열의 반복은 안정된 건물 키에서 창 묶음·재질·옥상 소품 후보를 고르는 방식으로 줄인다. 가구·실내 공간은 전면 창 너머의 기존 표현을 우선 사용한다. 실제 도로 폭과 이웃 건물까지 간섭하는 차양이나 출입구를 발견하면 해당 장식을 줄인다. 실제 외관을 확인하지 않은 매장에는 가상의 정면을 사용한다.

## 먼저 제작할 범위와 검수

1. **세 채와 결손 대조 한 채부터.** 사가정역 근처에서 색인과 길 그래프를 다시 읽을 수 있는 2층 단독주택, 2층 근린생활시설, 5층 공동주택을 골랐다. 세 채는 역 표기점에서 23~79m 안이다. 네 번째는 용도·층수 자료가 없고 접근점도 벽과 떨어진 건물이다. 시점 이동으로 실제 세 채가 읽히는 구도를 찾아 후보를 확정한다. 시장 골목형 점포는 첫 비교가 만족스러우면 두 번째 장면으로 검토한다.
2. **같은 장소에서 순차 비교.** 격리 기준판에서 기존 외형 → 정면·창 개선 → 지붕 디테일 추가 순으로 비교한다. 같은 시각·카메라·화면 크기에서 560m 화면 너비로 유형과 동네 윤곽을, 200m 화면 너비로 문·창·모서리를 본다. 길 쪽과 뒤쪽을 각각 확인하고 낮과 밤을 함께 비교한다. 밤의 발광만 바꾼 대조는 외형 변경과 별도로 찍는다. 지도 판본이 다른 외형 입력은 기본 외형을 표시하는지 시험한다. 직접 입력으로 같은 건물 선택, 출입 경로와 지도 복귀를 확인한다.
3. **가까운 화면의 비용을 잰 뒤 확대 검토.** 기존 지붕 설비와 창 셰이더를 먼저 재사용한다. 가까운 곳의 필요한 돌출만 덧그리며 기존 건물 묶음 렌더링을 활용한다. 동일 기기에서 로딩 시간, 정점, 렌더러, 프레임 시간의 전후를 남긴다. r1에서 제안한 동별 덧굽기 방식이 준비되면 같은 건물 키와 범위 판본에 연결되는 외형 입력을 검토한다. 동 지도 외곽, 출입 경로, 클릭 대상, 운영 역할은 비교의 기준이다. ## 정면 비교 시안 r1

사용자가 세 가지 건물의 정면 비교를 진행해 달라고 요청해, 03:09 URP 화면의 색과 위쪽 시점을 참고한 이미지 한 장을 만들었다. 왼쪽부터 2층 단독주택, 2층 근린생활시설, 5층 공동주택이다. 문과 창을 읽기 위해 기준 화면보다 가까이에서 보며, 건물의 나란한 배치와 개별 외관은 연출이다. 근린생활시설의 1층 전면 유리와 측면 셔터, 공동주택의 층별 발코니를 확인할 수 있다. 이 시안은 사용자 검토용이다. ## 미정

첫 시안의 정면 선택과 외형 강도, 층별·지붕 자료 사용 대상, 야간 발광, 성능 허용 범위는 비교 결과를 보고 정한다. 현재 자료 묶음은 내부 검토용이며 새 외형, 플레이 테스트, 제품 합류, 공개 범위, 공통 규칙 승격은 이 제안에서 검증 대기다. 새 디오라마 규칙 후보 없음.
