# 공공 이용허락 사진 우선 수집 방향

- 상태: `ApprovedSourceDirection / OwnCaptureUnavailable / KOGLType0Or1PriorityConfirmed / CollectionNotStarted`
- 상위 기획: [역세권 디오라마 모듈 표준 r10](README.md)
- 선행 정책: [무료 Steam 외관 사진·건물 모델 이용 제안 r9](photo-source-and-building-model-use-policy.r9.md)
- 기획 근거: 2026-09-13 사용자가 직접 현장 촬영은 어렵고, 현재는 공공누리 사진처럼 확보·변형·배포 조건을 확인할 수 있는 공공 사진을 활용하는 방향을 선택함.

## 확정

- 직접 촬영은 첫 수집 경로에서 제외한다.
- Blender 모델 제작 후보는 개별 항목에 **변경과 배포가 허용된 공공 사진**이 확인된 경우에만 연다.
- 기본 허용 후보는 공공누리 제0·1유형, CC0, 변경·재배포가 가능한 CC BY, 또는 별도 명시적 허락 자료다.
- 공공누리 제2·3·4유형, 이용조건이 없는 웹 사진과 거리뷰는 `ReferenceOnly`로 두며 Blender 형상·텍스처 근거로 승격하지 않는다.
- 현재 게임이 무료여도 향후 광고·후원 가능성을 보존하기 위해 첫 배포 자원은 `CommercialCompatible=true`를 요구한다.
- 정확한 건물 사진이 없으면 다른 건물 사진을 실제 외관처럼 대체하지 않고 기존 절차적 매스를 유지한다.

## 사진 근거의 세 단계

| 단계 | 조건 | 허용되는 사용 |
| --- | --- | --- |
| `BuildingSpecificVisualEvidence` | 정확한 건물·촬영 방향·시점이 확인되고 개별 변경·배포 권리가 있음 | 해당 건물의 외관 비례·실루엣·재질군 모델링 |
| `RegionalFacadeGrammarEvidence` | 사가정·면목·중랑구처럼 같은 지역의 사진이지만 정확한 건물 결속은 없음 | 창호·차양·색상·옥상 설비의 일반화 모듈 |
| `StyleResearchOnly` | 다른 지역이거나 권리·정확 위치가 불명확함 | 로컬 기획 참고만 가능, 모델 브리프 입력 금지 |

공공누리 제1유형 사진이라도 정확한 건물이 다르면 `BuildingSpecificVisualEvidence`가 되지 않는다. 반대로 건물이 정확히 일치해도 개별 이용조건이 없으면 배포 가능한 외관 근거가 아니다.

## 첫 검색 순서

1. `사가정시장`, `사가정역`, 정확 도로명주소와 건물명으로 공공누리 제0·1유형 사진을 찾는다.
2. 정확 일치 자료가 없으면 `중랑구 전통시장`, `면목동 골목`, `중랑구 생활권`으로 넓혀 지역 외관 문법 후보를 찾는다.
3. 역세권 1km 안의 공공시설·공원 시설·독립 건물 중 개별 공공누리 사진이 있는 후보를 찾는다.
4. 개별 항목의 원문 페이지, 제공기관, 작성자, 기준일, 공공누리 유형, 원본 URL과 hash를 보존한다.
5. 검색 결과를 실제 건물 교체 후보, 지역 외관 문법 후보, 참고 전용, 사용 불가로 나눈다.

검색 결과가 없다는 것도 결과로 남긴다. 사진 부족을 거리뷰 캡처나 임의 생성 외관으로 숨기지 않는다.

## 수집 대장 최소 필드

- `EvidenceStableId`, `LandmarkCandidateStableId`, 후보 `BuildingStableIds[]`
- 원문 제목·제공기관·작성자·원문 URL·직접 이미지 URL
- 수집 시각·자료 기준일·원본 SHA-256·MIME·byte 길이
- `LicenseCode`, 라이선스 확인 URL·확인 시각·출처표시 문구
- `ModificationAllowed`, `ModelDerivationAllowed`, `CommercialUseAllowed`
- `GameDistributionAllowed`, `StoreMediaAndPromotionAllowed`, `SponsorshipContextAllowed`
- 건물 일치 수준, 촬영 방향, 보이는 면, 누락 면
- 얼굴·번호판·연락처·간판·로고·벽화 검토 결과
- `BuildingSpecificVisualEvidence / RegionalFacadeGrammarEvidence / StyleResearchOnly`
- 검토 상태·검토자·재검토 조건·철회 상태

사진 원본은 로컬 비공개 검토 영역에 두고, 권리 검토 전에는 Git·Unity `Resources`·StreamingAssets·빌드에 넣지 않는다. 배포 자원에는 승인된 모델과 필요한 출처 영수증만 포함한다.

## Blender·Unity 적용

### 정확한 건물 사진이 있을 때

- 공식 건물 polygon·높이와 사진의 정면·측면 특징을 같은 `BuildingStableId`에 결속한다.
- 사진의 원근과 조명을 그대로 복제하지 않고 저폴리 geometry와 프로젝트 제작 재질로 다시 만든다.
- 간판·상표·벽화는 별도 허락이 없으면 일반화한다.
- r8의 Prefab 선생성·검증 후 절차적 매스 숨김 순서를 따른다.

### 지역 사진만 있을 때

- 해당 사진은 정확한 건물 교체에 쓰지 않는다.
- 중랑구형 저층 근린상가, 다세대주택, 시장 차양처럼 반복되는 `FacadeGrammarKey` 후보를 만든다.
- 실제 위치·상호·건물 정체성을 주장하지 않는 배경 표현에만 쓴다.

### 적합한 사진이 없을 때

- 기존 건물 도형·높이 기반 매스를 유지한다.
- `MissingVisualEvidence`를 남기고 Blender 작업을 열지 않는다.

## 첫 수집 묶음 제안

첫 실행은 다음 두 묶음을 함께 검색하되 결과를 섞지 않는다.

1. **사가정시장 입구·대표 골목 정확 자료**: 시장 overlay를 실제 근거로 보강한다.
2. **사가정역 1km 독립 건물 정확 자료**: polygon 하나와 결속 가능한 첫 완전 교체 후보를 찾는다.

정확 자료가 없으면 세 번째 산출물로 **중랑구 지역 외관 문법 후보**만 남긴다. 이것은 실제 건물 교체 증거가 아니다.

## 제외

- 직접 현장 촬영을 필수 선행조건으로 요구
- 공공누리 검색 결과의 무차별 다운로드
- 검색 썸네일·거리뷰·웹뷰어 화면을 원본 사진으로 저장
- 제2·3·4유형을 무료 게임이라는 이유로 변경·배포 후보로 승격
- 다른 지역 사진을 사가정 실제 건물 외관이라고 표시
- 권리 검토 전에 Blender·Unity 작업 시작

## 미정

- 공공누리에서 실제로 확보할 수 있는 사가정·중랑구 사진의 수량과 품질
- 정확한 건물 교체 후보가 먼저 나올지 지역 외관 문법 후보가 먼저 나올지
- 공공누리 외에 서울시·중랑구가 별도 변경·배포 허락을 표시한 자료를 같은 수집기로 받을지

## 다음 질문 하나

공공누리 제0·1유형을 우선해 **사가정시장 정확 자료와 사가정역 1km 독립 건물 자료를 실제 검색하고, 원문·라이선스·hash를 가진 비공개 후보 대장으로 수집할까?**

추천은 그렇게 하는 것이다. 정확 건물 자료와 지역 분위기 자료를 같은 검색에서 찾되 서로 다른 증거 등급으로 저장하면, 자료가 부족해도 사실을 꾸미지 않으면서 Blender 제작 가능성을 확인할 수 있다.

## 현재 검증 상한

사용자의 직접 촬영 불가와 공공 이용허락 사진 우선 방향을 기획·수집 경계로 확정했다. 실제 공공누리 검색, 사진 다운로드, 개별 원문·이용조건 확인, 파일 hash·DB/MongoDB 저장, Graph Map·배치맵·Blender·Unity 작업은 아직 수행하지 않았다.
