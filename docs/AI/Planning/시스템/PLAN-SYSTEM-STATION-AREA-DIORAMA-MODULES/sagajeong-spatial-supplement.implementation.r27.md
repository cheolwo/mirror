# 사가정역 1km 공간 보충 자료 수집·원장화 r27

## 확정 범위

- 기준 역은 `station:kr:kric:s1107:0722`, 표현 창은 기존 사가정역 WGS84 경계 `127.0825,37.5762,127.0942,37.5854`를 그대로 사용한다.
- 기존 건물·주소·높이·도로·차선·신호·횡단보도 자료를 교체하지 않고, 보행망·엘리베이터·공원·버스 정류소·가로수 보충층을 별도 원천과 판본으로 수집한다.
- 공식 원본은 `artifacts/local/public-data/sagajeong-spatial-supplement-20260914-r1/`에만 비공개 보존하고 Git에는 링크·hash·건수·제약을 가진 대장만 둔다.
- 정규화 자료는 기존 로컬 Docker MySQL 공공자료 원장에 저장하되 `PendingHumanReview`로 유지한다. 공개·Runtime·통행·게임 권위는 부여하지 않는다.
- 이번 절편은 Unity Scene·Prefab·Renderer·Collider·NavMesh를 수정하지 않는다.

## 구현

- `sagajeong-spatial-supplement-acquire|self-test|preview|apply|verify` 명령을 추가했다.
- 서울 열린데이터광장 화면형 자료는 모든 페이지를 읽어 원본 응답 묶음으로 고정하고, 파일형 자료는 정확한 파일명과 연결된 다운로드 번호만 사용한다.
- 버스 정류소 XLSX는 현재·이전 두 헤더 계약을 명시적으로 구분하고 실제 데이터 시트를 선택한다. 필드 설명 파일을 실제 자료로 오인하지 않는다.
- WGS84 점·선 자료는 기존 `sagajeong-reference.r3`과 같은 ECEF→ENU 방식으로 읽기 전용 중심 좌표를 만든다.
- 원천에서 같은 식별자가 중복되면 자료 순서를 버리지 않고 `source-occurrence`를 기록해 원장 고유성을 유지한다.
- 대량 보행망은 200행 단위로 저장해 DB 명령 크기를 통제한다. 같은 입력을 다시 적용하면 갱신 없이 기존 행으로 판정한다.

## 미완료와 차단

- 공원 SHP의 EPSG:5174 도형은 비공개 원본과 공원 정체성에 결속했지만 좌표 변환을 완료하지 않았다. Unity에서 공원 경계로 사용하면 안 된다.
- 국토지리정보원 수치지도 V2와 수치표고모형은 국토정보플랫폼 로그인·전용 전송 도구가 필요해 `BlockedExternalAccess`다. 다른 자료나 평지로 성공 처리하지 않았다.
- 새 시각 원본은 내려받지 않았다. 기존 시각 대장의 권리 판정을 그대로 따르며 프로젝트 정책상 CC BY-SA 자료는 계속 모델 파생·배포에 사용하지 않는다.
- 자료가 있다는 사실은 보행 가능성, 현재 시설 존치, Collider/NavMesh, 방어 게임 경로 또는 운영 상태를 증명하지 않는다.
