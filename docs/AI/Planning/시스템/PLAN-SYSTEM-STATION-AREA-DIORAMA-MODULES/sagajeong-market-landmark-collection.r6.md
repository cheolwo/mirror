- 기획 근거: 2026-09-13 사용자가 역별 대표 랜드마크를 조사하고 이미지·공간 근거를 바탕으로 Blender 모델링 후 디오라마에 배치하는 방향을 제안했고, 첫 대상을 사가정시장 입구와 대표 골목으로 정해 자료 수집 명세부터 진행하는 범위를 승인함.

## 목적

사가정역 1km 디오라마에서 시장을 점 하나로 표시하지 않고, 역에서 시장으로 접근할 때 읽히는 **입구 경계**와 시장의 반복적인 **골목 공간 문법**을 첫 랜드마크 모듈 후보로 정리한다.

이 문서는 수집 항목·판정 상태·권리 관문·Blender 인계 조건을 정한다. 사진 다운로드, 현장 실측, Blender 모델링, Unity 자원 생성·배치는 아직 수행하지 않는다.

## 수집 패킷

### 1. 식별·현행성

- 최신 공식 전통시장 현황의 사가정시장 행과 원본 파일 hash
- 표시명, 시장 종류, 도로명주소, 원천 기준일, 운영 상태의 필드별 근거
- 기존 2025-11-10 관측과 새 자료의 동일 시장 판정 근거
- 사가정역과 시장의 거리는 관찰 편의 정보로만 계산하며, 역세권 포함·광고 대상·상권 경계를 자동 확정하지 않음

### 2. 공간

- 모든 확인된 출입구의 점·방향·접근 도로와 확인 방법
- 시장 운영 구간의 중심선 또는 영역 후보와 근거 정밀도
- 대표 골목의 구간별 폭, 차양 하부·최고 높이, 단차, 지붕선, 주요 분기와 종단
- 기존 도로·건물 고유 식별자와의 연결 후보. 실제 점유·영업·통행·출입구 권위는 선언하지 않음
- 좌표·도형을 얻지 못한 구간은 `MissingGeometry`로 남기고 사진만으로 위치를 짐작하지 않음

### 3. 시각 참고 캐프처

1. 주접근로에서 입구를 정면으로 본 전체 실루엣
2. 역에서 시장으로 다가가는 방향의 연속 접근 장면
3. 입구에서 대표 골목 축을 바라본 장면
4. 골목 중간의 폭·차양·건물 전면 관계가 드러나는 횡단 장면
5. 주요 분기·교차·종단의 방향별 장면
6. 디오라마 원경에서 읽힐 지붕선·차양·인접 건물 실루엣

캐프처마다 시각, 찍은 방향, 거리/화각의 대략적 정보, 작성자·출처, 사용·변형·상업적 배포 조건을 함께 보존한다.

## 이미지·모델 권리 관문

- 데이터셋 이용조건과 개별 사진의 저작권은 따로 판정한다. 데이터셋이 변형·상업 이용 가능해도 연결된 사진이 그렇다고 해석하지 않는다.
- 배포용 모델의 형태·텍스처 근거로 쓸 수 있는지 개별 자료별로 확인한다. 조건이 불명확하면 로컬 검토 참고로만 보관한다.
- 직접 촬영하거나 명시적 허락을 받은 자료를 우선한다. 인물 얼굴, 차량 번호판, 연락처, 실내 개인정보는 배포 자원에 남기지 않는다.
- 상호·로고·상품 표현은 배포 전 별도 권리 검토를 통과하거나 비식별 가상 표현으로 대체한다.

## Graph Map·배치맵·Blender 인계

- Graph Map은 후보와 사가정역·서버 역세권 manifest·기존 도로/건물 식별자의 `CandidateLandmarkFor`, `DerivedFrom`, `LocatedIn` 관계만 받는다.
- 배치맵은 검증된 입구 점·방향, 골목 중심선/영역, 높이·폭 근거, 앞뒤 도로 연결을 소유한다. 현재 참고점 `X=635.556, Z=50.628`은 배치 승인값이 아니다.
- Blender 후보는 `입구 경계`, `반복 골목`, `분기/종단 변형`, `원경 실루엣`을 서로 다른 조립 단위로 나눈다.
- 식별·공간·이미지 권리·모델 브리프가 모두 승인되기 전에는 Blender 작업을 시작하지 않는다.
- Blender 결과는 역세권 manifest와 바로 결합하지 않고, 에셋 hash·LOD·피벗·스케일·재질·충돌 검사를 통과한 뒤 별도 배치 후보로 전환한다.
- Unity는 서버가 배포 승인한 자원 키와 읽기 전용 배치 사본만 사용한다. 모델이 있다는 사실로 운영 장소·통행·gameplay 권위를 만들지 않는다.

## 광고·후원 경계

랜드마크 선정, 공간 크기, 배치 위치, 표현 정밀도는 공개 근거와 표현 필요성으로 결정한다. 광고주·후원자가 이 값을 바꾸지 못한다. 후원 표시는 추후 승인된 광고 레이어에서 실제 정보·광고 표시·노출 기간을 구분하고, 랜드마크 정본과 따로 갱신한다.
