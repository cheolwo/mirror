## 확정

- 공공데이터포털의 한국관광공사 관광사진 API, 국문 관광정보 API, 여행기사 목록을 공식 조사 경로로 등록했다.
- 관광사진 API v4.2 안내서와 여행기사 CSV 1,332행을 로컬 비공개 자료로 수집하고 원문 SHA-256을 보존했다.
- 여행기사 목록에서 사가정·면목동·중랑구·용마산의 정확 대응 행은 0건이었다. `진면목` 같은 부분 문자열은 대상이 아니므로 제외했다.
- 한국관광공사 공급자 페이지에서 사가정공원, 용마랜드, 용마산 야경 기사 미리보기 사진 3건을 제한적으로 수집해 시각 확인했다.
- 사가정공원 사진은 대상 장소 대응은 확인했지만 개별 이용조건을 API에서 재확인하지 못했다. 용마랜드 사진은 제3자 저작권 표기가 보이고, 용마산 여행기사 사진은 제4유형 문맥이므로 모델링 근거에서 제외했다.
- 현재 저장된 공공데이터포털 키로 관광사진 검색을 시도했으나 HTTP 403으로 차단됐다. 응답 원문과 키는 저장하지 않았고 오류 사유를 추정해 확정하지 않았다.
- 사진 3건, API 접근 상태 1건, 공식 사진 자료군 1건, 정확 범위 여행기사 결손 1건을 로컬 MySQL `hongdal_dev`의 비공개·검토 보류 원장에 6개 레코드로 저장했다.
- 첫 적용은 신규 6건, 같은 입력 재적용은 신규 0·기존 6건, 독립 재조회는 6건이다.
- 이 조사로 Blender·Unity·배포가 승인된 사진은 0건이다. 기존 도형 디오라마와 절차적 매스를 변경하지 않는다.

## 미정

- 관광사진 API 활용 신청 또는 현재 키의 활용 범위 추가 뒤 `gallerySearchList1`로 사가정·면목동·중랑구·용마산 항목을 조회할 수 있는지
- 조회된 개별 관광사진의 공공누리 유형, 촬영자, 촬영일, 원본 URL과 대상 장소 대응이 첫 모델링 기준을 충족하는지
- 사가정공원 사진이 개별 제1유형으로 확인될 경우 공원 석재 표식·보행로·수목 배치 중 어느 요소까지 지역 외관 문법 근거로 사용할지
