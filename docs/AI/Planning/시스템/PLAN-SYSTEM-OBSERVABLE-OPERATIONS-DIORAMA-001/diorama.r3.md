# 사가정역 생활 디오라마 r3

- 기획 ID: `PLAN-SYSTEM-OBSERVABLE-OPERATIONS-DIORAMA-001`
- 판본: `observable-operations-diorama.r3`
- 상태: `Approved / ImplementationAuthorized / SampleOperationsOnly`
- 승인: 2026-09-12 콘셉트 이미지 수용, 지도·상태 관찰 우선 선택 및 `Implement the proposed plan.` 요청.
- 이전: [r2](README.md). 운영 API·완료 상태 사본 계약은 유지한다.
- 시각 기준: [승인 콘셉트 이미지](assets/sagajeong-concept-r3.png). AI 생성 시안이며 실제 지리·구현 증거가 아니다.

## 목표

사가정역 중심 1km × 1km의 동결 도로·건물 자료 위에서 음식 배달·화물 운송·창고·마트의 여섯 합성 완료 결과를 관찰한다. 콘셉트는 구도·색감·판독성의 참고이고 좌표·높이·입주·영업 사실의 근거가 아니다. 실제 GPS·운영 효과·차량 이동·새 WI·새 Scene·모바일/Web 개편·공개 배포는 제외한다.

## 구현 계약

- 기존 지도 조립을 배달 Controller에서 분리해 독립 읽기 전용 지리 View로 재사용한다.
- `SimulationWorldShell/OperationalOsWorldRoot`는 검증된 지도와 지역 배치 대장을 조립한다. 다른 영역의 권위·상태·카메라 설정을 변경하지 않는다.
- 배치 대장은 지도 revision/hash/좌표 기준과 `semanticPlaceStableId`별 좌표·방향·표현 역할을 소유한다. 공개 상태 사본 계약은 바꾸지 않는다.
- 표본 위치는 가상이며 실존 건물의 입주·영업 관계를 만들지 않는다. 미연결·판본 불일치는 배치를 보류하고 임의 위치로 숨기지 않는다.
- 무채색 건물·녹회색 바탕·도로와 업무별 색상, 전체/근접 보기·선택 상세를 제공한다. 주소 검토 패널은 이 관찰 화면에서 사용하지 않는다.
- 상태 사본은 메모리만 사용한다. 실패 시 마지막 정상 상태도 TTL까지만 유지한다. 비활성화 시 사본을 지우며 재활성화는 새 조회로 시작한다.

## 검증

지도 판본·배치 중복·범위·미등록 키, 객체 재사용·동결·회복·만료·재활성화, 관련 EditMode와 공유 계약 회귀를 확인한다. 실제 서버와 Game View는 별도 검증한다. 픽셀 일치가 아니라 지도 전체 가시성·확대 판독·업무별 구별·선택/귀환을 완료 기준으로 삼는다.

## 표현 사전 준비와 수직 작업 명세

기존 r2 대표 작업(완료 상태 사본 한 건을 같은 고유 식별자 객체로 관찰)을 유지하는 표현 확장이다. 새로운 gameplay WI와 운영 Command는 `NotApplicable`이다. 관찰자 입력은 카메라 이동·선택·전체 보기이며 비용은 근접 시 전체 맥락이 줄어드는 것, 실패는 자료 불일치/통신 실패, 회복은 정상 자료 재조회, 귀환은 전체 보기다.

- Logic E1~E2: 서버 권위와 v2 읽기 계약 유지. E3: 배치 판정·TTL·호환 시험. E4~E7: 기존 합성 표본 증거를 재사용하되 실제 업무 순차 실행이라고 주장하지 않는다.
- Presentation E1~E3: 관찰자/지도/완료 업무 구분, 지도 조립·배치 조회 분리 및 시험.
- Presentation E4: `VisualKey`는 기존 완료 표식과 역할별 도형. 주 후보는 자료 외곽 Mesh 및 코드 조립 음식점/차량/창고/마트, 대체는 중립 상자·상태 표식. 신규 외부 자산과 Synty 동작 연구는 `NotApplicable`이다.
- Presentation E5: 지도 hash와 배치 대장의 같은 판본을 공식 Root에 연결. E6: 입력·상태 갱신·실패·만료 검증. E7: 실제 전체/선택/귀환 화면과 서버 결과를 별도 기록.
- 자료 판본·개인정보·배치 의미·카메라 범위가 바뀌면 관련 E3/E4를 재검토한다. 자동 Evidence 승격은 하지 않는다.

## 결과 기록

완료 결과는 CURRENT_WORK와 별도 검증 기록으로 갱신한다. 이 승인 명세 자체를 실행 증거로 사용하지 않는다.
