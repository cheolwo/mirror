# [기획 · 월드·데이터·관찰 · PLAN-SYSTEM-KOREAN-PENINSULA-PUBLIC-DATA-WORLD · 제안 r32]

## 목표

`SimulationWorldShell`을 Play Mode로 시작했을 때 한반도가 Game View 정중앙에서 가장 먼저 읽히고, 중국은 왼쪽 맥락, 일본은 오른쪽 맥락으로 함께 선명하게 보이는 동아시아 시작 구도를 만든다.

## 확정

- 시작 카메라는 임의의 현재 회전값이 아니라 안정 식별자를 가진 `KoreanPeninsulaHeroPose`를 사용한다.
- 시각 중심은 대한민국만이 아니라 한반도 전체로 잡는다. 남북한 경계나 운영 권위를 한쪽으로 합친다는 뜻이 아니며 지리적 관찰 중심만 공유한다.
- 한반도는 화면 중앙의 주 대상, 중국 동부 해안은 왼쪽의 넓은 맥락, 일본 열도는 오른쪽의 길게 이어지는 맥락으로 구성한다.
- 중국과 일본을 흐린 배경 실루엣으로 처리하지 않는다. 국가 경계와 해안선은 판독할 수 있게 유지하되 한반도보다 채도·윤곽 강조를 한 단계 낮춘다.
- 국가 이름은 최소 `대한민국`, `조선민주주의인민공화국`, `중국`, `일본`을 서로 겹치지 않는 화면 공간 표지로 배치한다. 실제 경계·명칭 자료의 출처와 표기 원칙은 기존 국가 Catalog를 따른다.
- 시작 구도는 Presentation 기본값이며 국가 선택, 운영 상태, Simulation 상태를 바꾸지 않는다.
- 사용자가 드래그·확대하면 즉시 자유 조작으로 전환하고, `전체 보기` 또는 명시적 `한반도 보기`에서만 이 구도를 다시 적용한다.

## 화면 판독 기준

```text
┌──────────────────────────────────────┐
│          중국 동북부                 │
│  중국 동부 해안       한반도       일본 열도 │
│       왼쪽 맥락        정중앙        오른쪽 맥락│
│          황해           동해          태평양   │
└──────────────────────────────────────┘
```

- 한반도 중심선이 Game View 가로 중앙에서 크게 벗어나지 않는다.
- 한반도 남단부터 북단까지 한 화면에서 잘리지 않는다.
- 중국 동부 해안과 일본 열도의 대표 윤곽이 동시에 화면 안에 남는다.
- 상단 안내 패널과 하단 출처 패널이 한반도 윤곽을 가리지 않는다.
- 국가 경계선, 해안선, 배경 바다의 명도 차이가 Game View 캡처에서도 구분된다.

## 다음 개발 묶음 후보

1. `세계지구본View`에 시작 구도 Anchor와 명시적 복귀 명령을 둔다.
2. 현재 Globe 회전·카메라 거리를 시작 Anchor로 초기화한다.
3. 한반도·중국·일본의 선택 가능 윤곽과 화면 표지 명암을 조정한다.
4. EditMode에서 시작 회전·거리·중심 허용 오차를 검증한다.
5. 실제 Play Mode와 Game View에서 시작 화면, 자유 조작, 복귀 화면을 각각 캡처한다.
