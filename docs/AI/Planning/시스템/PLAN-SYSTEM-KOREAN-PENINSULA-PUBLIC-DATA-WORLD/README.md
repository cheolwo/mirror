## 목표

천천히 자전하고 사용자가 직접 돌릴 수 있는 구체 지구본에서 세계를 조망하고, 대한민국·중국·일본·동남아시아·아메리카 등 국가와 지역을 선택해 출처가 있는 정보를 확인한 뒤, 계속 확대하면 대한민국 행정동과 사가정역 1km 상세 디오라마까지 들어가는 서버 기반 관찰 세계를 장기 목표로 둔다. 한반도의 공간·생활·환경·산업·문화·교통 관련 공개 자료는 출처와 한계를 보존해 총괄한다. Unity는 전체 원본을 한 Scene에 적재하는 저장소가 아니라, 사용자가 선택한 지역과 자료층을 판본화된 상태 사본으로 받아 지구본·지도·정보 카드·아이소메트릭 디오라마·센서·시간 흐름으로 관찰하는 `World Projection Client`이자 공공정보 탐색 소프트웨어다.

이 목표에서 `모든 자료`는 무제한 수집이나 완전성 선언을 뜻하지 않는다. 공식 제공 여부, 이용 조건, 공간·시간 범위, 최신성, 개인정보, 품질과 재현 가능성을 대장에 등록하고 `사용 가능 / 부분 가능 / 역사 자료 / 제한 / 결손 / 거절`을 함께 보여 주는 것을 뜻한다.

## 확정

- 대한민국의 국가·지방자치단체·공공기관 공개 자료를 첫 권위 자료군으로 삼는다. 같은 현상을 여러 기관이 제공하면 원본별 출처·기준 시각·공간 단위·좌표계·이용 조건을 보존하고 임의로 하나의 사실처럼 합치지 않는다.
- 북한 지역과 남북 접경 자료도 한반도 범위 안에서 표현할 수 있게 식별자와 타일 체계는 열어 둔다. 다만 대한민국 공공자료와 같은 행정·운영 권위를 부여하지 않고, 공개된 국제·연구·원격 관측 자료만 별도 `ExternalObservation` 계보로 취급한다. 자료가 없으면 빈 공간을 추정으로 채우지 않는다.
- 원본·보호 자료·검증·집계·현재 판본은 서버와 자료 저장 계층이 소유한다. Unity는 필요한 지역·확대 수준·자료층만 읽고, 원본 전체·개인정보·상세 주소·운영 비밀을 보유하지 않는다.
- 기존 `SimulationWorldShell` 하나 안에서 지역 모듈을 교체·결합한다. 전국·한반도 범위를 이유로 공식 Scene을 지역마다 늘리지 않는다.
- 지구본은 세계 공간을 탐색하는 읽기 전용 상위 표현이다. 대한민국·중국·일본을 같은 지구본에서 볼 수 있지만, 국가별 상세 자료의 출처·권리·정밀도·최신성은 독립 계보로 관리한다. 대한민국 상세 자료가 준비됐다는 이유로 중국·일본의 상세 현실을 추정 생성하지 않는다.
- 지구본은 실제 구체 mesh를 사용하고, 유휴 상태에서는 지구의 실제 자전 방향인 서쪽에서 동쪽으로 천천히 회전한다. 사용자가 드래그하면 자동 자전을 잠시 멈추고 어느 방향으로든 직접 돌릴 수 있으며, 조작 종료 뒤에는 충분한 유휴 시간을 두고 자동 자전을 재개한다. 화면 기준 시계·반시계 방향을 권위 값으로 저장하지 않는다.
- 국가는 저해상 국가 경계 선택 영역과 ISO 표준 기반 안정 식별자로 판독한다. 클릭은 국가의 업무 상태를 바꾸지 않고 선택 강조·정보 조회만 수행한다. 같은 클릭을 Simulation 명령이나 운영 정책 확정으로 해석하지 않는다.
- 사용자가 느끼는 확대는 연속적으로 보이게 하되, 지구 반지름부터 건물 1m 단위까지 하나의 Unity 좌표계에 물리적으로 억지로 넣지 않는다. 확대 관문에서 지구 좌표, 지역 tile 좌표, 행정동 투영, 로컬 ENU 좌표를 안전하게 인계한다.
- 행정동·법정동·시군구·시도·국가·격자·역세권·생활권·배달권은 각각 별도 안정 식별자와 판본을 유지한다. 행정 경계를 게임 권역이나 서비스 권역으로 자동 변환하지 않는다.
- 자료층은 개별 켜기·끄기와 확대 수준별 단순화를 지원한다. 꺼진 자료층은 로딩·렌더·NPC·Simulation 판단에 영향을 주지 않아야 한다.
- 공공자료 관찰과 가상 Simulation을 합치지 않는다. 실제 관측은 `ReadOnlyObservation`, 가상 시간·정책·NPC 결과는 `SimulationAnalog`로 구분하고 화면에서도 출처와 시점을 표시한다.
- 현재 첫 깊은 기준점은 면목제3·8동과 그 안의 사가정역 1km 상세 창이다. 동북서울 30개 행정동은 공통 계약 검증 범위이고, 전국 확장은 이 기준점의 출처·성능·결손 표시·재생성 검증을 통과한 자료층부터 단계적으로 진행한다.

## 전국 공통 지역 계층

```text
지구
  └─ 동아시아
       ├─ 대한민국
       ├─ 중국
       ├─ 일본
       └─ 한반도 외부 관측 권역
            └─ 시도·광역 권역
                 └─ 시군구
                      └─ 행정동 / 법정동
                           └─ 공용 공간 격자·tile
                                └─ 상세 관찰 창
                                     ├─ 사가정역 1km
                                     ├─ 시장·대학·공원·산업 거점
                                     └─ 검증된 건물·도로·시설 확대
```

행정 단위는 자료 귀속과 집계의 기본 축이고, 공용 격자는 경계 변경·인접 지역·대용량 전송을 견디는 공간 축이다. 역세권과 거점은 상세 표현 창이며 상위 행정 경계의 대체물이 아니다.

## r4 지구본에서 사가정까지의 확대 계약

사용자에게는 다음 이동이 한 번의 연속 확대처럼 보여야 한다.

```text
지구본 회전·국가 선택
  → 동아시아 곡면 조망
  → 한반도·대한민국 지역 tile
  → 시도·시군구·행정동 경계
  → 면목제3·8동 로컬 창
  → 사가정역 1km 아이소메트릭 디오라마
  → 건물·도로·시설 선택
```

내부 구현은 정밀도와 성능을 위해 다음 구간을 분리한다.

| 확대 구간 | 좌표·표현 | 적재 범위 | 인계 기준 |
| --- | --- | --- | --- |
| 지구 | 정규화된 구체 또는 지구중심 좌표 기반 저해상 지구본 | 해안선·국가 윤곽·저해상 지형·국가 표식 | 선택 지점의 위경도와 안정 지역 ID |
| 동아시아·한반도 | 곡면 또는 지역 지형 tile | 해안·광역 지형·광역 교통·자료 가용성 | 지역 manifest, source revision, tile 집합 |
| 대한민국 행정 권역 | 지역 투영·행정 경계 tile | 시도·시군구·행정동·선택 자료층 | 행정구역 안정 ID와 경계 판본 |
| 로컬 관찰 창 | `WGS84 → ECEF → ENU`, 1 Unity unit = 1m | 인접 로컬 tile과 필요한 표현층 | 로컬 원점·범위·projection hash |
| 디오라마·건물 | 사가정 기존 로컬 모형과 선택 객체 | 현재 창의 도로·건물·시설·overlay | 객체 stable ID와 상태 사본 revision |

전환할 때 이전·다음 구간만 잠시 함께 유지하고 카메라 이동·곡률 완화·교차 흐림으로 경계를 감춘다. 전환이 끝나면 이전 구간의 고정밀 mesh·tile·표식을 회수한다. 확대를 되돌리면 같은 지역 ID와 카메라 이동 경로를 따라 상위 단계로 복귀한다.

미래의 확대 인계 계약은 최소한 `TargetStableId`, `Latitude`, `Longitude`, `Altitude`, `SourceRevision`, `ProjectionHash`, `TargetPackage`, `MinZoom`, `MaxZoom`, `ReadinessCode`를 가져야 한다. 준비되지 않은 상세 단계는 상위 지도에서 `상세 자료 없음`으로 멈추며 가짜 건물이나 지형으로 통과시키지 않는다.

## r4 구체 지구본 첫 경험

```text
SimulationWorldShell
  └─ WorldMapRoot
       ├─ GlobeRoot
       │    ├─ GlobeSurface
       │    ├─ AtmospherePresentation
       │    ├─ CountrySelectionSurface
       │    ├─ CountryHighlight
       │    └─ CountryMarkers
       ├─ GlobeCameraRig
       ├─ ScaleBreadcrumb
       ├─ CountryInformationPanel
       └─ DataQualityAndSourcePanel
```

위 트리 가운데 `WorldMapRoot / GlobeRoot`, 구체·육지 표본·국경선·전용 카메라·국가 정보 UI는 r4 첫 슬라이스로 실제 조립했다. 지역 지형·행정 투영·전환 전용 뿌리는 후속 범위다.

첫 화면의 상호작용은 다음처럼 고정한다.

1. 지구본은 유휴 상태에서 매우 느리게 자전한다. 마우스·터치 드래그가 시작되면 즉시 자동 자전을 멈춘다.
2. 사용자는 드래그로 지구본을 회전하고 휠·핀치로 확대하거나 축소한다. 카메라는 지구 표면을 통과하거나 방향을 잃지 않도록 최소·최대 거리를 가진다.
3. 포인터가 국가 위에 오면 경계를 가볍게 강조하고 국가명만 미리 보여 준다.
4. 한 번 클릭하면 국가를 선택하고 자전을 멈춘 채 `CountryInformationPanel`을 연다. 다시 클릭하거나 `자세히 보기`를 선택하면 해당 국가 중심으로 확대한다.
5. 대한민국은 준비된 행정·공간 manifest가 있으므로 시도·시군구·행정동과 사가정 상세 창으로 내려갈 수 있다. 다른 국가는 준비된 상세 자료 수준까지만 내려간다.
6. `지구본으로 돌아가기`와 확대 경로 breadcrumb를 항상 제공하고, 돌아왔을 때 직전 회전 방향·카메라 거리·선택 국가를 복원한다.

국가 정보 패널은 화면을 채우는 장식 카드가 아니라 서버 자료 대장의 읽기 전용 관점별 조회 결과다. 첫 계약은 다음 묶음을 가진다.

- 식별: 공식 표시명, ISO 코드, 수도·행정 계층 후보, 국가 stable ID.
- 공간: 대륙·중심점·경계 판본·면적과 단위.
- 기본 현황: 인구 등 공개 통계의 기준 연도·제공기관·단위. 최신값처럼 보이게 만들지 않는다.
- 자료 가용성: `사용 가능 / 부분 가능 / 역사 자료 / 제한 / 결손 / 거절`과 최대 확대 수준.
- 주제별 진입: 지형·행정·교통·환경·문화·생활 자료층. 자료가 없는 주제는 비활성 상태와 이유를 표시한다.
- 계보: 출처, 관측 시각, 가져온 시각, license, revision, hash, 품질·배포 상태.

Unity는 이 패널을 렌더하지만 국가 통계나 공공자료 원본의 최종 권위는 서버가 가진다. 네트워크나 자료 조회에 실패하면 마지막 검증 캐시인지, 완전한 결손인지, 일시 실패인지 구분하며 임의의 더미 국가 정보를 사실처럼 채우지 않는다.

## 전 세계 표현 범위

- 세계 해안선·국가 경계·저해상 지형은 전 세계 공통 라이선스를 가진 별도 기초 자료군으로 둔다. 한반도 공공데이터의 권위를 세계 전체에 확대 적용하지 않는다.
- 대한민국·중국·일본·동남아시아·아메리카는 지구본 회전과 국가 선택 범위에 처음부터 포함한다. 다만 첫 상세 관찰 권역은 대한민국이며, 다른 국가의 행정동·건물·사업체·실시간 생활상을 자료 없이 생성하지 않는다.
- 국가 경계 분쟁 지역은 하나의 정치적 결론을 Unity가 임의로 확정하지 않는다. 자료 제공자의 경계 판본과 표시 정책을 밝히고, 필요한 경우 중립적인 경계 상태와 별도 주석을 사용한다.
- 야간 조명·구름·대기·별 배경은 정보 판독을 방해하지 않는 표현층이며 실제 실시간 관측처럼 보일 때만 해당 출처와 시각을 요구한다. 장식이면 `Decorative`로 명시한다.

## 현행 기반 감사와 재사용 경계

- 현행 `SimulationWorldShell`에는 기존 평면 World Map과 별도로 Natural Earth 1:110m 동결 국가 경계를 사용한 첫 구체 지구본 표현이 추가됐다. 이는 저해상 관찰 표현이며 정밀 지형·법적 경계 자료는 아니다.
- 현행 `PublicWorldMapPresenter`의 위경도 변환은 평면 투영이다. 기존 공공 지도 상태 사본·stable ID·출처·최신성 계약은 보존하고, 추후 판본화된 지구본 투영 전략을 추가한다. 기존 평면 표현을 조용히 다른 의미로 바꾸지 않는다.
- 현행 공간 tile streaming과 floating-origin 기능은 지역·로컬 구간에서 재사용한다. 지구본 자체의 좌표 권위나 행정 경계 권위로 승격하지 않는다.
- 사가정 기준점의 `WGS84 → ECEF → ENU`와 1m 단위 로컬 좌표는 상세 단계의 첫 기준 구현으로 유지한다. 지구본에서 전달받은 좌표·지역 ID가 이 로컬 manifest와 일치할 때만 디오라마로 진입한다.
- `WorldMapRoot / GlobeRoot`와 첫 지구본 표현은 canonical `SimulationWorldShell`에 실제 결속했다. `RegionalTerrainRoot`, `AdministrativeProjectionRoot`, `TransitionRoot`는 계속 책임 구조 후보이며 아직 구현하지 않았다.

## 자료층 대장

첫 전국 대장은 다음 자료군을 독립 계보로 등록한다.

1. 행정·기초 공간: 행정 경계, 지명, 지형, 해안선, 수계, 필지, 건물, 주소.
2. 이동·교통: 도로, 차로, 보도, 교차로, 신호 시설, 철도, 역, 정류장, 항만, 공항.
3. 인구·생활: 인구·가구·생활인구·주거 유형·공공시설·상권 집계. 개인이나 세대를 식별하지 않는다.
4. 산업·물류: 사업체·시장·산업단지·농림수산·창고·물류 거점. 현재 영업과 업무 가능 상태는 별도 검증한다.
5. 환경·기상·재난: 날씨, 대기, 수질, 산림, 토양, 홍수·산불·폭염·한파·지진 관측과 경보.
6. 문화·교육·관광: 문화재, 박물관, 도서관, 학교, 대학, 축제, 공원, 관광지와 이용 조건.
7. 경제·주거·에너지: 공시·실거래·가격 관측, 에너지·충전·공급 시설. 가격과 현재 가용성은 기준 시점과 단위를 필수로 표시한다.
8. 시간 변화: 계절·절기·주야·과거 판본·통계 시계열. 서로 다른 기준 시점의 자료를 현재 한 장면으로 조용히 혼합하지 않는다.

각 자료층 항목은 최소한 `SourceId`, `DatasetId`, `Revision`, `ObservedAt/ValidFrom`, `FetchedAt`, `License`, `Coverage`, `CRS/Unit`, `Quality`, `Privacy`, `Distribution`, `Freshness`, 원본·파생 hash와 결손 사유를 가진다.

## r5 공공데이터포털 분야 분류와 MySQL 수집 준비

로그인된 공공데이터포털의 현재 활용 목록을 읽기 전용으로 확인해 Open API 37건과 파일데이터 7건을 `행정·공간·주소·건축`, `지역 생활·공동주택·시장`, `식품·영양·안전·사업장`, `물류·수산·급식 유통`, `경제·가격·통계·무역`, `문화·교육·관광`, `환경·에너지`, `검증·보호 업무`로 분류했다. 인증키·개인정보·활용신청 내부 식별자는 기록하지 않았다.

기존 `ExternalDataSourceCatalog → ExternalDataIngestionRuntime → PublicDataIngestionDbContext`를 재사용한다. 원본 본문은 비공개 원본 저장소에 두고 MySQL에는 수집 실행, 원본 위치·hash·판본, 정규화 관측, 지역 코드 매핑과 필요한 분야별 읽기 원장을 저장한다. 첫 실제 적재 후보는 면목동 제한 범위의 `행정표준코드 법정동 + 건축HUB 건축물대장`이며, 상세 절차와 완료 조건은 [공공데이터포털 분야 분류·MySQL 수집 계획 r5](data-go-kr-domain-classification-mysql-collection-plan.r5.md)를 따른다.

## r6 지구본 다중 규모 수집 방향

지구본이 세계·국가·한반도·행정동·건물을 잇게 됐으므로 수집을 면목동에서 위로만 확장하지 않는다. 국가별 무역·광역 통계·기상·해양처럼 큰 단위로 제공되는 자료는 하향식으로 보존하고, 건물·주소·시장·창고·현장 검증처럼 작은 단위 자료는 상향식으로 축적한다. 두 방향은 `RegionStableId`, 거점 식별자, 기간, 출처 판본과 품질로 결속하되 서로의 결손을 추정으로 채우지 않는다.

첫 독립 묶음은 `L1 면목동 행정코드·건축물`과 `G1 대한민국 국가별 수출입 집계 흐름`이다. 무역 통계는 지구본의 집계 흐름 호로 표현할 수 있지만 실제 선박 항적은 아니다. 실제 배의 입출항·이동 표현은 공식 항만 호출 또는 위치 시계열 근거가 확인된 뒤 별도 단계로 연다. 상세 계약은 [지구본 다중 규모 상향식·하향식 수집·표현 계획 r6](multiscale-top-down-bottom-up-collection-projection-plan.r6.md)를 따른다.

## r7 무역 품목에서 대표 상품까지의 조회

국가별 수출입 흐름에서 관세 품목, 소매 카테고리 후보, 대표 상품 관찰을 차례로 조회할 수 있게 하되 세 원장을 분리한다. HS 품목과 쇼핑몰 카테고리는 다대다 검토 연결이며, 개별 상품 링크만으로 제조국·원산지·수입국을 확정하지 않는다. Unity는 승인된 서버 조회를 표시하고 외부몰 이동 전 고지하지만 구매·결제는 수행하지 않는다.

네이버의 기존 쇼핑 검색 API는 2026-07-31 종료됐으므로 신규 자동 수집 기반에서 제외한다. 쿠팡 일반 Open API도 판매자 운영 중심이므로 소비자 전체 상품 검색으로 오해하지 않는다. 첫 후보는 `커피류·바나나류·냉동 새우류`의 사람이 검토한 플랫폼별 1~2개 일반 링크이며 가격 자동 갱신·제휴 링크·이미지 배포는 후속 승인 범위다. 상세 계약은 [무역 품목·소매 카테고리·대표 상품 연결 계획 r7](trade-retail-product-link-projection-plan.r7.md)를 따른다.

## Unity 표현 원칙

- 지구 조망에서는 해안선·국가 윤곽·저해상 지형·자료 가용성만 표현한다. 대한민국·중국·일본은 선택할 수 있지만, 각 국가의 상세 단계는 검증된 자료가 있는 범위까지만 열린다.
- 한반도 전체 조망에서는 해안·지형·광역 교통·자료 가용성만 표현하고 건물·주소·NPC를 적재하지 않는다.
- 지역 선택 시 서버 manifest를 통해 필요한 tile과 자료층을 요청하며 확대할수록 도로·건물·시설·생활 관측을 점진적으로 결합한다.
- 카메라는 지구본 궤도 관찰에서 지역 목표 고정, 행정동 상공, 아이소메트릭 디오라마 관찰로 전환한다. 카메라가 바뀌어도 서버 상태나 Simulation 권위를 변경하지 않는다.
- 전국 건물·NPC를 지구본에 미리 적재하지 않는다. 구간 전환 동안 인접 두 수준만 함께 유지하며, 상세 수준을 벗어나면 로컬 mesh·collider·표식·상태 사본을 회수한다.
- 사실 기반 배경을 먼저 만들고 운영 상태·NPC·캠페인·절기·오행·광고는 별도 overlay로 올린다.
- `MissingCoverage`, `Stale`, `HistoricalOnly`, `Restricted`, `AwaitingReview`를 화면에서 숨기지 않는다. 자료가 없는 곳을 반복 건물이나 임의 지형으로 채워 완성된 현실처럼 보이게 하지 않는다.
- 원본 정밀도가 낮거나 현재성을 증명하지 못한 자료는 시각적 단순화보다 먼저 품질 표시를 가진다.

## 단계적 구축

1. `K0 자료 대장`: 제공기관·자료셋·권리·갱신·공간 키·결손을 등록하되 무차별 원본 복제는 하지 않는다.
2. `K1 지역 정본`: 대한민국 시도·시군구·행정동·법정동과 공용 격자 식별자·경계 판본을 확립한다.
3. `K2 공통 공간`: 건물·도로·주소·필지·시설을 지역 manifest/tile로 결정적으로 생성하고 독립 재조회한다.
4. `K3 생활 자료`: 인구·상권·교통·환경·문화 자료를 개인정보 제거 집계와 관측 overlay로 연결한다.
5. `K4 지구본 골격`: 저해상 세계 구체, 유휴 자동 자전, 직접 회전·확대, 전 세계 국가 선택 영역, 대한민국·중국·일본을 포함한 국가 정보 패널, 출처 표시와 선택·복귀를 읽기 전용으로 검증한다.
6. `K5 확대 인계`: 지구본 → 동아시아 → 한반도 → 면목제3·8동 → 사가정역 기존 디오라마의 카메라·좌표·stable ID·메모리 회수를 검증한다.
7. `K6 전국 확장`: 같은 생성·검증 계약으로 대표 도시·농촌·산림·해안 지역을 통과한 뒤 범위를 넓힌다.
8. `K7 한반도 외부 관측`: 북한·접경 자료는 별도 출처·낮은 권위·결손 표시를 유지한 채 선택적으로 연결한다.

첫 구현 결과는 전 세계 정밀 지형 수집이 아니라 `저해상 구체 지구본 + 유휴 자전·직접 회전·확대 코드 + 177개 국가 선택 + 국가 정보 카드 + 대한민국 사가정 상세 진입·복귀`의 작은 읽기 전용 골격이다. 중국·일본 등은 같은 선택 계약에서 기본 식별·자료 가용성까지만 제공한다. 동결 catalog SHA-256은 `B18AB971C957620A8184E0A0B53FC0F3060158B0366E2E06ABB8A4963F767D9A`다.

## 검증 관문

- 서울·사가정·중국·일본의 알려진 WGS84 기준점이 지구본과 지역 지도에서 허용 오차 안에 놓인다.
- 유휴 자전, 직접 회전, 확대·축소, 국가 hover·선택, 패널 닫기, 지구본 복귀가 마우스와 향후 터치 입력에서 같은 의도로 동작한다.
- 대한민국·중국·일본·동남아시아·아메리카의 대표 국가를 선택했을 때 올바른 국가 stable ID가 반환되며 경계 반대편 국가나 바다를 오선택하지 않는다.
- 국가 정보의 값마다 출처·기준 시점·단위·품질·최대 확대 수준을 확인하고, 미지원 주제와 네트워크 실패가 사실 값으로 대체되지 않는다.
- 지구본에서 사가정까지 확대하고 다시 지구본으로 돌아와도 선택한 stable ID·출처 판본·카메라 이동 경로가 보존된다.
- 확대 인계 전후에 건물·도로가 중복 생성되지 않고, 벗어난 로컬 tile·mesh·collider·상태 사본이 회수된다.
- 지구본·지역 지도·디오라마 카메라 조작이 서버 사실·업무 상태·Simulation 결과를 변경하지 않는다.
- 준비되지 않은 지역은 최대 확대 수준과 결손 이유를 보여 주고, 반복 건물·임의 지형으로 상세 화면을 만들지 않는다.
- 실제 Unity 검증은 최소 `지구본 전체`, `한반도 확대`, `사가정 디오라마 진입` Game View와 Console·메모리 회수 기록을 서로 분리해 남긴다.

## 제외

- 지금 즉시 전국 원본을 전부 다운로드하거나 DB·Unity에 적재하는 작업.
- 자료 이용 조건·개인정보·공간 판본을 확인하지 않은 자동 수집.
- 대한민국과 북한 자료의 권위·시점을 동일하게 취급하는 것.
- 공공자료만으로 현재 영업, 출입 가능, 도로 통행 가능, 개인 활동, 배달 가능을 확정하는 것.
- 전국을 하나의 거대한 Unity Scene·Mesh·NavMesh로 만드는 것.
- r9은 커피·바나나·냉동 새우의 HS6 분류, 2025년 대한민국 수입 통계와 수동 상품 관찰을 실제 로컬 MySQL에 45행 저장하고 독립 재조회·동일 입력 중복 방지를 검증했다. 쇼핑몰 자동 검색, 읽기 API·Unity 구현, 구매·결제, Graph Map과 E 자동 승격은 계속 제외한다.
- r10은 반복 가능한 배치 실행기를 추가하고 커피 생두·소포장 녹차·소포장 홍차·무가당 코코아 가루를 첫 배치로 처리했다. HSK10·내부 소매 카테고리·쿠팡 말단 카테고리 후보를 분리해 저장했으며 무역 48행, 분류 4행, 카테고리 후보 4행, 상품 관찰 4행 등 60행을 로컬 MySQL에서 독립 재조회하고 동일 입력 신규 0행을 확인했다. 쿠팡 숫자 카테고리 코드·개별 상품 HS 결속·읽기 API·Unity 투영은 계속 보류한다.
- r11은 같은 실행기로 분쇄 후추·고추류·계피·커민 배치를 추가했다. 공식 원본 111행에서 무역 48행, 분류 4행, 카테고리 후보 4행, 상품 관찰 4행 등 60행을 별도 저장하고 독립 재조회·동일 입력 신규 0행을 확인했다. 두 반복 배치는 합계 120행이며 상품·카테고리 결속은 계속 검토 보류다.
- r12는 WCO 법정 HS6 `5,612개`와 UN 통계 특수 `999999`를 분리한 전수 대장을 만들었다. 공식 분류 5,613행과 코드별 소매 조사 상태 5,613행, 합계 11,226행을 로컬 MySQL에 저장·재조회했다. 통후추·건고추·실론계피·커민 씨 배치 60행도 추가해 반복 배치 기준 12개 코드를 관찰했고 5,600개는 대기 중이다. 동일 입력 재실행은 전수 대장과 상품 배치 모두 신규·수정 0행이었다.
- r13은 볶은 커피·바닐라·정향·생강 8개 코드를 한 배치로 추가해 120행을 저장·재조회했다. 반복 배치 관찰 범위는 법정 HS6 20개, 대기는 5,592개가 됐고 전수 대장 갱신 뒤 동일 입력 신규·수정 0행을 확인했다. 네 반복 배치 정규화 자료는 합계 300행이다.
- r14는 관세청 2026 HS 부호 계층 12,469행과 말단 HSK10 성질별 분류 11,327행을 별도 계보로 동결했다. 합계 23,796행을 로컬 MySQL에 저장·독립 재조회했고 동일 입력 반복 적용은 신규·수정 0행이었다. 국내 특수 `2424000000`과 UN 통계 특수 `999999`는 분리했다.
- r15는 관세청 소비재 분류를 참고해 마테·육두구·카다멈·코리앤더·강황·카레·월계수류 HS6 10개를 추가했다. 공식 원본 195행에서 정규화 150행을 저장·재조회했고 같은 입력 신규 0행을 확인했다. 반복 배치는 5개·450행, 관찰 코드는 30개, 대기는 5,582개다. 순중량이 없는 사프란은 값을 꾸미지 않고 별도 결손 계약으로 넘겼다.
