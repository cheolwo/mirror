# [기획 · 월드·데이터·관찰 · PLAN-SYSTEM-KOREAN-PENINSULA-PUBLIC-DATA-WORLD · 구현 r41]

## 범위

생활 밀착 조사 우선순위의 네 번째 P0 묶음으로 제15류 가정용 식용유 HS6 10개를 조사했다. 대두유·올리브유·해바라기유·카놀라유·옥수수유·참기름을 우선하고 기술용·사료용·비식용 지방은 앞당기지 않았다.

## 공식 자료와 동결 입력

- 관세 분류: 관세청 2026 HS 부호 총대장과 HSK10 성질별 분류의 자식 19개 세번
- 무역 통계: UN Comtrade 2025년 대한민국 수입, H6, 세계 합계와 품목별 상대국
- 소매 관찰: 2026-09-21 쿠팡 공개 검색 색인의 품목·형태·가공·보관 상태 확인 결과
- 공개 승인: 모두 `distributionApproved=false`
- 상품–HS 결속: 확인 가능한 후보 6건 모두 `PendingHumanReview`

관세청 성질별 분류에서는 선택 HSK10을 모두 `원자재`로 분류한다. 이 사실을 가정용 소매 상품의 부재로 바꾸지 않고, 법정 분류와 공개 상품 관찰을 서로 다른 원장으로 보존했다.
