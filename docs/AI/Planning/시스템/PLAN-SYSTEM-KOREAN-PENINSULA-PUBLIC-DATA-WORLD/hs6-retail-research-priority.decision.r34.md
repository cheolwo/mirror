# [기획 · 월드·데이터·관찰 · PLAN-SYSTEM-KOREAN-PENINSULA-PUBLIC-DATA-WORLD · 확정 r34]

## 배경

법정 HS6 5,612개를 숫자 오름차순으로 모두 같은 깊이로 조사하면 생활에서 자주 접하는 식품·생필품보다 희귀 동물·산업 원료·특수 장비에 조사 비용이 먼저 쓰인다. 전수 대장은 완전성 확인용으로 보존하되 상세 상품 조사는 생활 밀착도와 디오라마 관찰 가치를 기준으로 우선한다.

여기서 우선순위는 실제 검색량이나 판매 순위라는 주장이 아니다. 검색량 자료가 없는 상태에서 `사람들이 많이 본다`고 표시하지 않고, 관세청 소비재 분류·일상 사용 가능성·지역 생활상 표현 가치·공식 수입 규모를 이용한 **조사 효용 순서**로만 사용한다.

## 확정

1. 기존 HS6 전수 대장 5,612개와 각 코드의 조사 상태는 그대로 유지한다. 우선순위는 코드를 삭제하거나 법적 분류를 바꾸지 않는 별도 작업 순서다.
2. 앞으로 자동 조사는 단순 오름차순 대신 `P0 → P1 → P2 → P3` 순서로 미처리 코드를 고른다.
3. 같은 우선순위에서는 하나의 생활 상품군을 8~12개 코드로 묶는다. 관세청 직접소비재 여부와 일상 사용성을 먼저 보고, 대한민국 2025년 수입액은 동률 정렬 보조값으로만 쓴다.
4. 생체동물·희귀 종·부산물·산업 원료·전문 장비·민감 품목은 공식 제한 판정이 필요하지 않은 한 후순위로 둔다.
5. 후보가 없거나 채널에 맞지 않는 코드는 0건을 정상 결과로 기록한다. 우선순위가 높다는 이유로 상품을 억지 결속하지 않는다.
6. 조사 결과는 계속 비공개·`distributionApproved=false`로 저장하며, 상품과 HS6의 법적 결속은 `PendingHumanReview`를 유지한다.

## 첫 전환 배치

다음 자동 조사는 숫자상 다음인 `030195`를 무조건 고르지 않는다. 첫 P0 묶음은 `040110`, `040120`, `040140`, `040150`, `040320`, `040510`, `040520`, `040610`, `040630`, `040690`, `040721`, `040900`의 우유·요구르트·버터·치즈·식용란·꿀 12개다. 부화용 종란과 산업용 유성분은 같은 제4류라도 뒤로 보낸다.

이 판본은 조사 순서만 바꾼다. 기존 136개 판정, MySQL 자료, 전수 대장, Unity 투영 상태를 다시 쓰지 않는다.
