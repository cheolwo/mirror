## 범위

- 관세 분류: 관세청 2026 HSK10 분류 12개 세번, 모두 직접소비재
- 무역 통계: UN Comtrade 2025년 대한민국 수입, H6, 세계 합계와 품목별 상대국
- 소매 관찰: 2026-09-23 공개 검색 색인에서 쿠팡 상세 결과 확인
- 공개 승인: 모두 `distributionApproved=false`
- 상품–HS 결속: 생알땅콩·생 해바라기씨·생 참깨 3건을 `PendingHumanReview`로 보존

품목·가공 형태·보관 상태·가격을 함께 확인한 경우에만 후보를 기록했다. 나머지 6개 코드는 법정 품목과 비가공 상태를 충분히 확인하지 못해 `SearchNoCandidate`로 보존했다. 검색 결과의 구매 문구를 판매량이나 인기 근거로 사용하지 않았다.
