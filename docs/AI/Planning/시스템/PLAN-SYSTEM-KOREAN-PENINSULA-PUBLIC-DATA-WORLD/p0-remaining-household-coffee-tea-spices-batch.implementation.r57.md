## 범위

생활 밀착 조사 우선순위의 P0 묶음으로 제9류에 남아 있던 커피·차·향신료 HS6 10개를 `chapter09-remaining-household-coffee-tea-spices-03` 배치로 처리했다. 이미 완료된 볶은 커피·소포장 차·후추·계피·정향·육두구·생강 배치와 겹치지 않는다.

## 공식 자료와 소매 관찰

- 관세 분류: 관세청 2026 HSK10 분류 15개 세번
- 무역 통계: UN Comtrade 2025년 대한민국 수입, H6, 세계 합계와 품목별 상위 상대국
- 소매 관찰: 2026-09-22 공개 검색 색인에서 품목·형태가 확인된 쿠팡 상세 결과
- 공개 승인: 모두 `distributionApproved=false`
- 상품–HS 결속: 모두 `PendingHumanReview`

디카페인 생두, 통계피, 팔각, 사프란 후보 4건을 남겼다. 정확한 커피 껍질·커피 함유 대용물, 3kg 초과 차, 메이스, 분쇄 아니스류 후보를 확인하지 못한 6개는 유사 상품을 붙이지 않고 `SearchNoCandidate`로 보존했다. 우선순위는 인기·판매량 주장이 아니다.
