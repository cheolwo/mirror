## 범위

생활 밀착 조사 우선순위의 두 번째 P0 묶음으로 제7류 생활 채소·뿌리류 HS6 12개를 조사했다. 숫자상 다음 코드를 소진하지 않고 감자·토마토·양파류·마늘·양배추류·상추·당근·무·오이류·완두·콩류를 하나의 생활 상품군으로 묶어 반복 배치 `chapter07-everyday-vegetables-01`에 결속했다.

## 공식 자료와 동결 입력

- 관세 분류: 관세청 2026 HS 부호 총대장과 HSK10 성질별 분류의 자식 23개 세번
- 무역 통계: UN Comtrade 2025년 대한민국 수입, H6, 세계 합계와 품목별 상대국
- 소매 관찰: 2026-09-21 쿠팡 공개 검색 색인의 품목·형태·가공·보관 상태 확인 결과
- 공개 승인: 모두 `distributionApproved=false`
- 상품–HS 결속: 확인 가능한 후보 7건 모두 `PendingHumanReview`

UN Comtrade 원본은 70행이며 원본·H6 참고 목록·상대국 참고 목록의 SHA-256을 수집 영수증에 보존했다. 수입액이나 순중량이 없는 경우 0으로 꾸미지 않고 원본 결손을 유지했다.
