## 범위

제12류 미처리 코드 중 가정에서 직접 관찰 가능한 조리 씨앗·식용 식물 재료 8개를 `chapter12-household-culinary-seeds-plants-02` 배치로 처리했다. 겨자씨·양귀비씨·식용 해조류·사탕무·로커스트콩·사탕수수·치커리 뿌리·곤약 계열을 파종용 종자·약용 전문재·사료·산업 원료보다 먼저 보았다.

## 공식 자료와 소매 관찰

- 관세 분류: 관세청 2026 HSK10 분류 49개 세번, 모두 직접소비재
- 무역 통계: UN Comtrade 2025년 대한민국 수입, H6, 세계 합계와 품목별 상대국
- 소매 관찰: 2026-09-23 공개 검색 색인에서 쿠팡 상세 결과 확인
- 공개 승인: 모두 `distributionApproved=false`
- 상품–HS 결속: 건조 미역 1건을 `PendingHumanReview`로 보존

품목·가공 형태·보관 상태·가격을 함께 확인한 경우에만 후보를 기록했다. 나머지 7개 코드는 법정 품목과 원물 상태를 충분히 확인하지 못해 `SearchNoCandidate`로 보존했다. 검색 결과의 배열이나 문구를 판매량·인기 근거로 사용하지 않았다. 겨자씨와 양귀비씨의 UN Comtrade 세계 합계는 금액은 있으나 공식 순중량이 비어 있어 0으로 바꾸지 않고 `OfficialMeasureUnavailable`로 저장했다.
