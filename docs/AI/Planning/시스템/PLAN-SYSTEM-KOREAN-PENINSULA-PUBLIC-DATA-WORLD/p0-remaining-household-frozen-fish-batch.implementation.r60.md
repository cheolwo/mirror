## 공식 자료와 소매 관찰

- 관세 분류: 관세청 2026 HSK10 분류 13개 세번, 모두 소비재

- 공개 승인: 모두 `distributionApproved=false`

참다랑어 색인 결과는 급냉 1미 선택지를 설명했지만, 한 결과는 생물 출고 가능성이 함께 적혀 있었고 다른 결과는 해당 냉동 선택지의 안정적인 관찰 가격을 확인할 수 없었다. 품목·형태·보관 상태·가격을 모두 충족한 후보를 꾸미지 않고 12개 전부 `SearchNoCandidate`로 보존했다. 손질 필렛·가공품이나 다른 어종을 대신 붙이지 않았다.
