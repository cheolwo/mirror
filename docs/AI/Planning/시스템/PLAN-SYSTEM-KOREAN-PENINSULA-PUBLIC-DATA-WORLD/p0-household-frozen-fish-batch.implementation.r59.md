## 범위

제3류 미처리 코드 중 일상 식탁에서 관찰 가능한 일반 냉동 어류 12개를 `chapter03-household-frozen-fish-02` 배치로 처리했다. 냉동 연어·넙치류·정어리·고등어·전갱이·대구·명태·농어를 먼저 보았고 상어·가오리·어란·내장과 희귀 어종은 제외했다. 숫자 오름차순은 선택 기준으로 쓰지 않았다.

## 공식 자료와 소매 관찰

- 관세 분류: 관세청 2026 HSK10 분류 12개 세번, 모두 소비재
- 무역 통계: UN Comtrade 2025년 대한민국 수입, H6, 세계 합계와 품목별 상위 상대국
- 소매 관찰: 2026-09-22 공개 검색 색인에서 품목·형태·보관 상태가 확인된 쿠팡 상세 결과
- 공개 승인: 모두 `distributionApproved=false`
- 상품–HS 결속: `PendingHumanReview`

러시아산 선동 냉동 동태 7통 10마리 후보 1건을 남겼다. 나머지 11개는 정확한 냉동 어종과 제0303호 형태를 동시에 확인하지 못해 `SearchNoCandidate`로 보존했다. 냉장 원물, 필렛·순살, 반건조 제품, 건어물과 어종이 확정되지 않은 혼합 잡어를 대신 붙이지 않았다.
