# [기획 · 월드·공간·관찰 · PLAN-SYSTEM-KOREAN-PENINSULA-PUBLIC-DATA-WORLD · r19]

## 결정

지구본에서 건물 디오라마까지의 확대를 단순한 카메라 거리 변화가 아니라 **의미 확대 단계**로 관리한다.

```text
세계 지구본
  → 동아시아
    → 한반도
      → 부산–서울–도라산–개성–평양–신의주 서부 교류축
        → 개별 철도 거점
          → 승인된 지역·역세권 디오라마
```

각 단계는 그 정밀도에서 근거가 있는 별도 상태 사본을 읽는다. 상위 집계를 확대해 개별 역·건물·사람으로 자동 분해하지 않는다.

## 사용자 경험

1. 사용자는 자전하는 지구본을 돌려 대한민국과 한반도를 찾는다.
2. 동아시아까지 확대하면 국가와 주요 교류 방향을 본다.
3. 한반도까지 확대하면 남한·북한의 공간 구분과 부산–신의주 서부 교류축의 주요 거점을 본다.
4. 축을 선택하면 현재 국내 운행, 역사 운행, 현재 단절, 국제 회랑 기술과 시나리오가 서로 다른 선으로 표시된다.
5. 근거가 충분한 거점을 다시 선택하면 역 정보 카드 또는 승인된 상세 관찰 화면으로 들어간다.
6. 축소하면 상세 객체를 회수하고 이전 단계의 선택·카메라 방향·활성 자료층을 복원한다.

카메라 조작은 자료 선택과 표현만 바꾸며 운행·통행·교류 정책·Simulation·운영 상태를 변경하지 않는다.

## 확대 단계별 정보 계약

| 단계 | 화면 범위 | 기본 표시 | 선택 시 표시 | 표시하지 않는 정보 |
| --- | --- | --- | --- | --- |
| `Z0 WorldGlobe` | 전 세계 | 구체 지구본, 저해상 국가 경계, 국가 선택 가능 여부 | 국가명·ISO·수도·인구 기준연도·출처·자료 가용성 | 철도 세부, 역, 건물, 사람 |
| `Z1 EastAsia` | 동아시아 | 대한민국·북한·중국·일본과 주변 해역, 광역 교류 방향 | 국가별 자료 범위·최대 확대 수준 | 상세 국경 확정, 개별 역·건물 |
| `Z2 KoreanPeninsula` | 한반도 | 남·북 지역 구분, 부산·서울·도라산·개성·평양·신의주 거점, 서부 교류축 | 현재·역사·단절·국제 회랑·시나리오 자료층과 기준일 | 현재 통행 가능 추정, 미확인 정밀 좌표 |
| `Z3 WesternCorridor` | 선택한 교류축 | 구간별 상태, 거점 순서, 사건 연표, 출처 품질 | 구간·거점별 출처 카드와 결손 | 열차·차량의 현재 위치 추정, 임의 운행 애니메이션 |
| `Z4 StationHub` | 개별 역·거점 | 역명 후보, 국가·지역, 자료 권위, 운영 상태, 최대 관찰 수준 | 확인된 연혁·연결 사건·제한·관련 출처 | 미검증 출입구·건물·군사·보안 세부 |
| `Z5 LocalDiorama` | 승인된 지역·역세권 | 검증된 도로·건물·시설·업무 상태 사본 | 건물·시설 카드와 읽기 전용 생활·업무 관찰 | 승인되지 않은 북측 상세 복원, 현재 영업·통행 추정 |

`Z5`는 카메라가 충분히 가까워졌다는 이유만으로 열리지 않는다. 해당 거점의 `MaximumObservationLevel`, 출처 영수증, 공간 판본, 공개 범위와 디오라마 승인이 모두 있어야 한다. 현재 북측 거점은 `Z3` 또는 출처가 허용하는 제한된 `Z4`가 상한이다.

## 한반도 교류축의 첫 표현

### 거점 순서

```text
부산
  → 서울
    → 도라산
      → 판문 / 봉동 관계 검토 구간
        → 개성
          → 평양
            → 신의주
```

`판문`과 `봉동`은 r18 출처 대장의 동일성 검토가 끝나기 전까지 하나의 역으로 합치지 않는다. 지도에는 겹친 단일 점 대신 `관계 검토 구간` 또는 두 개의 조사 대상으로 나타낸다.

### 선의 의미

| 표현 | 의미 | 첫 적용 |
| --- | --- | --- |
| 현재 실선 | 기준일 현재 공식 운행이 확인된 구간 | 근거가 확인된 국내 구간만 |
| 회색 실선 | 역사적으로 시험·화물 운행이 확인된 구간 | 2007년 문산–도라산–판문–개성 관련 사건 |
| 끊어진 선 | 물리적·운영상 단절을 확인한 구간 | 2024년 연결부 단절 관측 |
| 점선 | 국제기구 회랑 기술 또는 장래 교류 시나리오 | 개성–평양–신의주와 확장 회랑 |
| 자료 없음 | 선을 만들 근거가 부족함 | 미확인 구간은 빈 상태와 이유 표시 |

선의 색이나 애니메이션만으로 상태를 전달하지 않고 범례·상태명·기준일·출처를 함께 표시한다.

## 카메라와 자료 수명

- 카메라 거리는 확대 단계의 입력 중 하나일 뿐 최종 권위가 아니다. 선택한 지역, 자료 준비도와 최대 관찰 수준을 함께 판정한다.
- 단계 진입과 이탈에 서로 다른 임계 구간을 두어 경계에서 화면이 반복 전환되지 않게 한다.
- 한 번에 현재 단계와 인접 단계 하나만 준비한다. 더 먼 단계의 역·건물·표식은 회수한다.
- 확대 전 카메라 방향, 국가·축·거점 선택, 활성 자료층을 복귀 문맥으로 보존한다.
- 자료 수신이 실패하면 더 상세한 화면으로 추정 진입하지 않고 마지막 검증 상태 또는 결손 화면을 유지한다.
- 구체 좌표, 한반도 지역 좌표와 역세권 로컬 좌표는 확대 관문에서 변환하며 하나의 거대한 Unity 좌표계로 강제하지 않는다.

구체적인 거리값·FOV·전환 시간은 실제 Unity 카메라와 화면 판독 시험 전까지 미정으로 남긴다.

## 서버 읽기 투영 후보

```text
WorldObservationLevelManifest
├─ ObservationLevelCode
├─ FocusStableId
├─ ParentFocusStableId
├─ MinimumSourcePrecisionCode
├─ MaximumObservationLevel
├─ AvailableLayerCodes[]
├─ DefaultVisibleLayerCodes[]
├─ CoverageStateCode
├─ SourceRevision / ProjectionHash
└─ LimitationCodes[]

PeninsulaCorridorSegmentProjection
├─ CorridorStableId
├─ SegmentStableId
├─ FromResearchSubjectId / ToResearchSubjectId
├─ SegmentStateCode
├─ ValidFrom / ValidTo?
├─ SourceReceiptStableIds[]
├─ DisplayStyleCode
└─ UnityProjectionAllowed
```

서버는 어떤 자료층과 최대 확대 수준이 허용되는지 결정한다. Unity는 거리와 선택 문맥에 맞는 사본을 요청·표시할 뿐 자료 정밀도를 승격하지 않는다.

## r18 DB 대장과의 연결

첫 데이터 수직 슬라이스는 r18에서 제안한 범위로 유지한다.

- 조사 대상: 도라산·판문·봉동·개성
- 출처 영수증 후보: 5건
- 사실 주장 후보: 7건
- 판문–봉동 관계: `AwaitingIdentityReview`
- Unity 공개: 기본 `false`

DB 적재와 독립 재조회가 끝나면 `Z2 KoreanPeninsula`와 `Z3 WesternCorridor`가 소비할 최소 읽기 투영을 만든다. 평양·신의주 및 부산–서울 세부 노선은 공식 출처가 추가된 뒤 별도 판본으로 확장한다.

## 구현 우선순위

1. r18 출처 5건·주장 7건을 원문 영수증과 함께 로컬 조사 원장에 적재하고 멱등 재조회를 검증한다.
2. `Z2`·`Z3`에 필요한 거점·구간 상태 읽기 투영을 만든다.
3. 기존 `GlobeRoot`와 국가 상세 전환 사이에 의미 확대 상태기를 추가한다.
4. `SimulationWorldShell`의 같은 `WorldMapRoot` 안에서 한반도·교류축 표현을 조립한다. 새 공식 Scene을 만들지 않는다.
5. 실제 Play Mode에서 지구본→한반도→교류축→도라산 카드→지구본 복귀를 검증한다.
6. 북측 상세 공간은 별도의 출처·권리·정밀도 승인을 받기 전까지 만들지 않는다.

## 검증 조건

- 같은 카메라 거리에서도 선택·자료 준비도가 다르면 허용된 상한을 넘지 않는다.
- 빠른 확대·축소를 반복해도 단계가 떨리거나 객체가 계속 누적되지 않는다.
- Z0에서는 역·건물 자료를, Z2에서는 건물 자료를 로드하지 않는다.
- 현재·역사·단절·시나리오가 범례 없이 같은 선으로 보이지 않는다.
- 판문과 봉동은 관계 검토가 끝나기 전 단일 안정 ID로 합쳐지지 않는다.
- 북한·접경 결손을 반복 건물·임의 좌표·가상 노선으로 채우지 않는다.
- 확대·선택·복귀가 운영·Simulation revision을 변경하지 않는다.
- 실제 Game View, Console 오류, 메모리 회수와 서버 projection hash를 별도 증거로 남긴다.

## 제외

- 이번 기획 판본에서 Unity 코드·Scene·Prefab·카메라 수치 변경
- 현재 남북 열차 운행 또는 출입 가능성 표현
- 38선과 군사분계선을 같은 경계로 취급하는 것
- 북측 역 주변 1km 디오라마와 건물·도로 복원
- 부산–신의주 전 구간을 실제 운행 가능한 단일 노선으로 확정하는 것
- 카메라 확대만으로 서버·Simulation·업무 상태를 변경하는 것

## 확정 / 미정 / 다음 질문 하나

- 확정: `Z0 세계 → Z1 동아시아 → Z2 한반도 → Z3 서부 교류축 → Z4 역 거점 → Z5 승인 디오라마`의 의미 확대 단계를 사용한다.
- 미정: 단계별 실제 카메라 거리·FOV·전환 시간, 부산–서울과 평양–신의주 세부 노선 출처, 판문–봉동 관계, 각 북측 거점의 최대 관찰 수준.
- 다음 질문 하나: 첫 Unity 수직 슬라이스를 `지구본 → 한반도 → 서부 교류축 → 도라산 정보 카드 → 지구본 복귀`로 제한할지 결정한다. 추천은 이 범위로 제한하고, 개성·평양·신의주는 축의 자료 상태 표식까지만 보이는 것이다.
