## 범위

생활 밀착 조사 우선순위의 세 번째 P0 묶음으로 제10·11류 생활 곡물·일상 제분품 HS6 12개를 조사했다. 종자 전용과 산업 제분 부산물을 앞당기지 않고 보리·귀리·현미·백미·메밀, 밀가루·옥수수가루·쌀가루·세몰리나·압착귀리를 `chapter10-11-everyday-grains-milling-01`에 결속했다.

## 공식 자료와 동결 입력

- 관세 분류: 관세청 2026 HS 부호 총대장과 HSK10 성질별 분류의 자식 24개 세번
- 무역 통계: UN Comtrade 2025년 대한민국 수입, H6, 세계 합계와 품목별 상대국
- 소매 관찰: 2026-09-21 쿠팡 공개 검색 색인의 품목·형태·가공·보관 상태 확인 결과
- 공개 승인: 모두 `distributionApproved=false`
- 상품–HS 결속: 확인 가능한 후보 9건 모두 `PendingHumanReview`

UN Comtrade 원본은 236행이며 원본·H6 참고 목록·상대국 참고 목록의 SHA-256을 수집 영수증에 보존했다. 옥수수가루 세계 합계 순중량 결손은 0으로 바꾸지 않았다.

## 전수 대장 재계산

전수 대장은 공식 분류 5,613행과 조사 상태 5,613행, 합계 11,226행이다. 이번 반영 뒤 판정 완료는 172개이며 대표 상품 후보 88개, 공식 제한 40개, 채널 부적합 8개, 검색 무결과 36개, 대기 5,440개다. 첫 적용은 상태 12개를 갱신했고 같은 입력의 두 번째 저장은 신규·수정 0행이었다. 별도 문맥 재조회도 11,226행과 일치했다.

## 수집기 보완

긴 배치 ID가 MySQL 8.4의 사용자 잠금 이름 64자 상한을 넘겨 첫 저장이 거절됐다. 잠금의 업무 접두사는 유지하고 배치 ID를 SHA-256 앞 24자로 축약해 충돌 가능성을 통제했다. 최상위 `MySqlException`도 번호와 SQLSTATE만 노출하도록 진단 경계를 보완했으며 연결 문자열과 오류 원문은 출력하지 않는다.
