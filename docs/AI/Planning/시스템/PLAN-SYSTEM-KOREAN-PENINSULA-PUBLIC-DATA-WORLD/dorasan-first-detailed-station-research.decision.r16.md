# [기획 · 한반도 철도 거점 · PLAN-SYSTEM-KOREAN-PENINSULA-PUBLIC-DATA-WORLD · r16]

## 결정

`도라산역`을 부산–서울–개성–평양–신의주–단둥 서부 교류축에서 **남측 마지막 상세 거점이자 첫 상세 조사역**으로 확정한다.

이 결정은 도라산역 1km 디오라마 구현, 실제 남북 운행, 접경 출입, Unity 배치 또는 운영 활성화를 승인하지 않는다. 첫 결과는 출처와 결손을 가진 역 거점 자료 대장과 이후 조사를 위한 관문이다.

## 목적

- 지구본의 대한민국 선택과 기존 사가정 상세 진입 사이에 `한반도 교류축 → 철도 거점 → 상세 조사역`의 확대 단계를 마련한다.
- 남측 공식 철도 자료와 국제기구·통일부의 남북 연결 자료를 같은 사실처럼 합치지 않고 자료 권위를 분리한다.
- 도라산역을 경계·단절·역사·장래 시나리오가 함께 보이는 첫 검토 거점으로 삼는다.
- 이후 봉동·개성·평양·신의주를 조사할 때 남측과 동일한 자료 정밀도를 가정하지 않는다.

## 첫 조사 범위

1. 국가철도공단·공공데이터포털에서 공식 역명, 노선, 역 코드, WGS84 기준점, 주소, 역 연혁과 자료 기준일을 확인한다.
2. 통일부 남북회담·출입 자료에서 도라산–봉동–개성 연결의 역사적 운행·조사·중단 상태를 사건별로 분리한다.
3. UN 아시아횡단철도 자료에서 도라산과 봉동·개성·평양·신의주가 어떤 국제 회랑 거점으로 기술되는지 확인한다.
4. 역 주변 상세 자료는 경계·도로·건물·출입구·철도 부지를 각각 별도 출처로 대조한다. 군사·보안·통행 제한 자료는 수집·추론·표현하지 않는다.
5. 정확한 근거가 없는 출입구, 통행선, 시설 용도, 운행 상태와 1km 생활권을 합성하지 않는다.

## 거점 자료 계약 후보

```text
RailwayStationHub
├─ TransitStationStableId
├─ SourceStationName / DisplayName
├─ CountryRegionStableId
├─ Latitude / Longitude
├─ LineStableIds
├─ HubRole
├─ EvidenceState
├─ OperationState
├─ MaximumObservationLevel
├─ SourceReceiptRefs
└─ LimitationCodes
```

`OperationState`는 최소한 `OperationalDomestic`, `Restricted`, `Disconnected`, `HistoricalConnection`, `ProposedModernization`, `ScenarioEnabled`를 구분한다. `ScenarioEnabled`는 실제 운행이나 정책 확정을 뜻하지 않는다.

## 확대와 표현 상한

| 단계 | 허용 표현 | 첫 조사 상한 |
| --- | --- | --- |
| 지구본 | 부산–서울–평양–신의주 교류축 후보 | 출처 있는 광역 선·거점 |
| 한반도 | 도라산·봉동·개성·평양·신의주와 연결 상태 | 현재·역사·구상 구분 |
| 역 정보 | 도라산 공식 역 정보와 자료 상태 | 허용 |
| 역 주변 | 검증된 공개 공간자료 | 조사 뒤 별도 승인 |
| 1km 디오라마 | 건물·도로·출입구·권리·결손이 결속된 사본 | 미승인 |

Unity는 서버가 제공하는 읽기 전용 자료 상태 사본만 표시한다. 카메라 확대와 역 선택은 실제 출입·운행·업무 상태를 변경하지 않는다.

## 첫 자료 후보

- [국가철도공단 철도역 정보](https://www.data.go.kr/data/15067652/fileData.do): 국내 역명·좌표·노선·주소·연혁 후보.
- [UN 아시아횡단철도 협정](https://www.unescap.org/sites/default/d8files/2022-11/Intergovernmental_Agreement_TAR_2022-EN.pdf): 도라산–봉동–개성–평양–신의주 국제 회랑 거점 근거.
- [통일부 새로운 교류협력 방안](https://www.unikorea.go.kr/web/unikorea/contents/neac_swt): 서울–평양–신의주 연결 구상과 자료 범위 확인.

후보 링크를 기록했다는 사실은 원본 수집, 권리 확정, DB 저장, Unity 적용을 뜻하지 않는다.

## 완료 조건

- 도라산역의 공식 식별·좌표·노선·연혁 후보와 기준일을 원본 hash·수집 영수증으로 재현할 수 있다.
- 도라산–봉동–개성 연결을 현재 운행, 제한, 단절, 역사 기록, 장래 구상 중 하나로 뭉개지 않고 사건별로 설명한다.
- 남측 자료와 북한·접경 자료의 권위·정밀도·시점 차이를 표시한다.
- 공개 가능한 정보만 남기고 전화번호·운영 비밀·군사·보안 세부는 Unity 투영 후보에서 제외한다.
- 자료 결손을 임의 좌표·건물·통행 가능 상태로 보충하지 않는다.
- 조사 결과만으로 역세권 디오라마 규칙이나 E 단계를 자동 승격하지 않는다.

## 제외

- DB 실제 적재와 읽기 API 구현
- Graph Map·배치맵·Unity Scene·Prefab·GameObject 변경
- 도라산역 1km 디오라마 생성
- 현재 남북 열차 운행 또는 출입 가능성 확정
- 봉동·개성·평양·신의주 상세 공간 복원
- 군사시설·경계 통과 절차의 구체적 재현

## 확정 / 미정 / 다음 질문 하나

- 확정: 도라산역을 첫 상세 조사역과 남측 마지막 상세 거점으로 사용한다.
- 미정: 첫 조사 결과 뒤 허용할 최대 확대 수준과 1km 디오라마 착수 여부.
- 다음 질문 하나: 도라산역 조사 뒤 두 번째 거점을 북측 첫 연결역 `봉동`으로 이어갈지, 교류 의미가 큰 `개성`으로 건너갈지 결정한다. 추천은 자료 계보를 끊지 않는 `봉동`이다.
