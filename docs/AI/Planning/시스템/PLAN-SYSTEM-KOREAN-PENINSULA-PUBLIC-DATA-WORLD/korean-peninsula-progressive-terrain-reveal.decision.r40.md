# [기획 · 월드·공간·관찰 · PLAN-SYSTEM-KOREAN-PENINSULA-PUBLIC-DATA-WORLD · r40]

## 요청 해석

지구본을 확대했을 때 한반도 정보 카드가 곧바로 화면을 대신하지 않게 한다. 사용자가 세계에서 동아시아와 한반도로 가까워질수록 한반도의 실제 해안 윤곽, 높낮이, 산지, 주요 하천이 공간 안에서 차례로 읽히고, 그 뒤에 거점·교류축·상세 카드가 나타나게 한다.

`동고서저`는 화면을 그렇게 보이도록 손으로 꾸미는 규칙이 아니다. 출처가 결속된 DEM을 같은 투영과 시각 과장 규칙으로 표현했을 때 동쪽 산지와 서쪽 저지대의 차이가 자연스럽게 읽혀야 한다는 검증 관점이다.

## 현재 기준선

- `SimulationWorldShell`의 지구본은 한반도 중심 시작 구도, 중국 왼쪽·일본 오른쪽 배치, 5초 시작 유지, 편집 모드 미리보기를 제공한다.
- 대한민국을 선택하고 카메라 거리가 진입 임계값 이하가 된 뒤 0.3초 안정되면 기존 `한반도교류축View`가 열리고, 8개 거점·7개 구간과 도라산 정보 카드를 표시한다.
- 현재 확대는 지구본 위에 2D 교류축 Canvas를 여는 방식이다. Unity 배포에 사용할 수 있는 한반도 전역 DEM 투영, 해안·하천 동결 투영, 지형 Mesh와 서버 상태 사본은 아직 없다.
- Git 제외 비공개 저장소에는 VWorld·국토지리정보원 `수치표고모델(DEM)_90M` 한반도 원본과 추출 IMG가 있다. 다만 기존 계보는 이를 국내 공식 비교 자료로 제한하고 있고 이용 조건이 `CC BY-NC-ND`로 기록돼 있으므로, 가공 Mesh·Unity 동봉·재배포 가능 범위를 별도로 확인하기 전에는 제품 투영 원본으로 사용하지 않는다.
- Unity에 있는 절차적 지형, value noise, 장식용 강 Prefab은 현실 지형 근거가 아니므로 한반도 지형으로 승격하지 않는다.
- Natural Earth `1:110m` 국가 윤곽은 세계 조망용 저해상 자료이며, 한반도 확대 지형이나 법적 경계의 정밀 근거로 쓰지 않는다.

## 확정한 단계적 확대

기존 `Z0~Z5` 의미 확대를 보존하고 `Z2 KoreanPeninsula` 안을 다음 표시 단계로 세분한다.

```text
Z0 세계 지구본
  → Z1 동아시아 문맥
    → Z2-A 한반도 해안 윤곽·바다
      → Z2-B DEM 높이·산지 음영
        → Z2-C 주요 하천
          → Z2-D 거점·교류축
            → Z3 선택 교류축
              → Z4 역·도시 정보 카드
                → Z5 승인된 지역 디오라마
```

| 단계 | 기본 표시 | 표시하지 않는 것 |
| --- | --- | --- |
| `Z2-A` | Natural Earth `1:10m` 기반 한반도 해안 윤곽과 주변 바다 | 산맥 이름, 역, 건물, 운행 가능성 |
| `Z2-B` | SRTM 기반 단순 높이 격자, 산지 음영, 명시된 시각 높이 과장 | 손으로 만든 산맥선, 공식 평야 경계 주장 |
| `Z2-C` | HydroRIVERS에서 절단한 한강·대동강·압록강·두만강 | 모든 소하천, 항행·도하 가능성 |
| `Z2-D` | 출처가 결속된 거점과 기존 교류축의 자료 상태 | 현재 통행 추정, 임의 역·노선 |

카드는 공간 표현을 대신하지 않고 선택한 지형·하천·거점의 상세 설명으로만 연다. 기존 2D 교류축 화면은 지형판이 열린 즉시 전체 화면을 가리는 자동 결과가 아니라, 거점·교류축 단계에서 사용자가 선택해 여는 보조 화면으로 낮춘다.

## 공간 전환 원칙

- 지구본 구체를 무한히 확대하지 않는다. `Z1 → Z2-A` 관문에서 선택 위경도와 안정 지역 ID를 한반도 지역 투영으로 인계하고, 구체 지구본과 3D 지형판을 짧게 교차 전환한다.
- 카메라 조작 중에는 이전 검증 화면을 유지한다. 마지막 입력 뒤 기존 0.3초 안정 관문이 통과됐을 때 최종 단계의 상태 사본만 요청한다.
- 단계 경계에는 진입·이탈 임계값을 다르게 둔다. 빠르게 확대·축소해도 해안·산지·하천·거점이 반복 생성되거나 떨리지 않아야 한다.
- 현재 단계와 인접 단계 하나만 유지하고, 더 멀어진 정밀 자료와 GameObject는 회수한다.
- 전환 실패 시 더 자세한 지형을 추정 생성하지 않는다. 마지막 정상 단계와 결손 이유를 유지한다.

## 자료와 표현 경계

첫 실제 자료 조합은 이미 확정한 다음 기준을 유지한다.

- 높이: NASA/USGS SRTM 1 Arc-Second Global을 한반도 범위로 절단·단순화한 동결 격자
- 해안: Natural Earth `1:10m` Physical
- 하천: HydroRIVERS Asia에서 한반도 범위와 첫 4대 하천만 절단한 선형 자료

서버·자료 도구는 원본 판본, 다운로드 시각, 이용 조건, 원본 SHA-256, CRS, 해상도, NoData, 수직 기준, 절단 범위, 단순화와 출력 hash를 가진 `한반도지형ProjectionManifest`를 만든다. Unity는 이 manifest가 허용한 읽기 전용 자료만 표시한다.

산지의 모양은 DEM에서 파생될 수 있지만 `태백산맥`, `낭림산맥`, `소백산맥` 같은 명칭과 범위는 DEM 밝기나 경사만으로 자동 확정하지 않는다. 산맥 명칭층은 별도 출처 영수증과 선·면 범위가 준비된 뒤 다음 확대 단계의 선택 자료층으로 연다.

## 다음 개발 묶음

이번 판본은 제품 코드 변경 승인이 아니라 다음 개발 인계의 기준이다. 개발 전에 다음을 동결한다.

1. 한반도 절단 범위와 지역 투영
2. Z2용 높이 격자 크기와 높이 과장 배율
3. Natural Earth·SRTM·HydroRIVERS 원본 영수증과 hash
4. 해안·DEM·4대 하천의 출력 manifest와 결과 hash
5. `세계지구본View → 한반도지형판View → 한반도교류축View` 전환 계약
6. 객체 수·메모리·회수 기준과 진입·이탈 임계값
7. 허용 쓰기 경로, 테스트 범위와 실제 Game View 검증 절차

새 공식 Scene이나 별도 Map Manager는 만들지 않는다. canonical `SimulationWorldShell/WorldMapRoot` 안에 읽기 전용 `한반도지형판View`를 결속하고, 카메라·선택·자료층 변경이 운영·Simulation revision을 변경하지 않게 한다.

## 검증 조건

- 동일 원본·설정으로 생성한 동결 투영의 byte와 SHA-256이 같아야 한다.
- 해안·높이 격자·4대 하천이 같은 투영에서 허용 오차 안에 결속돼야 한다.
- `동고서저`를 강제로 만드는 보정 없이 DEM 결과가 시각적으로 판독돼야 한다.
- 산맥 형태와 산맥 명칭을 구분하고, 출처 없는 이름·경계·평야를 만들지 않아야 한다.
- 확대 순서가 `해안 → 높이·산지 → 하천 → 거점`으로 읽히며, 축소 시 역순으로 회수돼야 한다.
- 빠른 휠 입력, 늦은 응답, 부분 자료 실패, 복귀를 시험하고 객체 수가 누적되지 않아야 한다.
- 실제 Play Mode·Game View에서 `지구본 → 한반도 지형판 → 4대 하천 → 거점·교류축 → 카드 → 지구본 복귀`를 확인하기 전에는 실제 지형 표현 완료나 Presentation E5 이상을 주장하지 않는다.

## 확정

- 한반도 확대는 카드 우선이 아니라 공간 우선으로 진행한다.
- `Z2` 안에서 해안, DEM 높이·산지, 4대 하천, 거점·교류축을 단계적으로 연다.
- `동고서저`와 산지 형태는 실제 DEM 결과의 판독 항목이며 손으로 만든 지형 규칙이 아니다.
- 기존 지구본·300ms 안정 관문·교류축·카드와 canonical `SimulationWorldShell`을 보존한다.
