# [기획 · 월드·데이터·관찰 · PLAN-SYSTEM-KOREAN-PENINSULA-PUBLIC-DATA-WORLD · 구현 r35]

## 범위

생활 밀착 조사 우선순위의 첫 P0 묶음으로 제4류 우유·유제품·식용란·천연꿀 HS6 12개를 조사했다. 기존 전수 대장의 코드 순서와 미처리 상태는 삭제하지 않고, 별도 반복 배치 `chapter04-dairy-daily-01`로 결속했다.

## 공식 자료와 동결 입력

- 관세 분류: 관세청 2026 HS 부호 총대장과 HSK10 성질별 분류의 소비재 23개 세번
- 무역 통계: UN Comtrade 2025년 대한민국 수입, H6, 세계 합계와 품목별 상위 상대국
- 소매 관찰: 2026-09-21 쿠팡 공개 색인 상세 결과
- 공개 승인: 모두 `distributionApproved=false`
- 상품–HS 결속: 모두 `PendingHumanReview`

UN Comtrade 원본은 291행이며 원본·H6 참고 목록·상대국 참고 목록의 SHA-256을 수집 영수증에 보존했다. HS6 12개 모두 세계 합계가 있는 `Observed`다.

`040120`은 제목만으로 유지방 1% 초과 6% 이하를 검증하지 못했고, `040140`은 정확한 유지방 범위의 크림 후보를 확인하지 못했으며, `040520`은 데어리 스프레드의 정확한 후보를 확인하지 못해 0건으로 보존했다. 우선순위가 높다는 이유로 유사 상품을 붙이지 않았다.

## 전수 대장 재계산

전수 대장은 공식 분류 5,613행과 조사 상태 5,613행, 합계 11,226행이다. 이번 반영 뒤 판정 완료는 148개이며 대표 상품 후보 72개, 공식 제한 40개, 채널 부적합 8개, 검색 무결과 28개, 대기 5,464개다. 같은 입력의 두 번째 저장은 신규·수정 0행이었고 별도 문맥 재조회도 11,226행과 일치했다.

## 로컬 DB 복구 경계

작업 도중 기존 이름의 MySQL 컨테이너가 모바일 현장 시험 Compose로 재생성돼 공공자료 표가 비어 있었다. 기존 로컬 연결 문자열을 명시적으로 제공한 경우에만 같은 `hongdal-mysql-1 / hongdal_dev / 127.0.0.1:13306`을 허용하도록 수집기를 보완했다. 기본 `docker-compose.dev-deps.yml` 검사는 그대로 유지한다.

관세청 23,796행, 기본 무역·소매 45행, 기존 반복 배치 14개 1,429행을 원본 해시 기반으로 복구하고 이번 193행을 추가했다. 이는 로컬 개발 DB 복구이며 원격 운영 DB 쓰기나 배포가 아니다.
