# [기획 · 월드·데이터·관찰 · PLAN-SYSTEM-KOREAN-PENINSULA-PUBLIC-DATA-WORLD · 확정 r33]

## 확정

- Play Mode가 시작되면 `KoreanPeninsulaHeroPose`를 즉시 적용한다.
- 시작 뒤 5초 동안 한반도 중심 구도를 유지한다.
- 5초 동안 사용자의 드래그·확대·선택 입력이 없을 때만 기존의 느린 자동 자전을 시작한다.
- 유지 시간 안에 사용자 입력이 생기면 시작 유지 타이머를 취소하고 즉시 자유 조작을 우선한다.
- 사용자가 `전체 보기` 또는 명시적인 `한반도 보기`를 선택해 시작 구도로 복귀할 때도 같은 5초 무입력 규칙을 다시 적용한다.
- 창 비활성화, 일시정지, 로딩으로 흐른 시간은 사용자가 한반도를 실제로 관찰한 시간으로 간주하지 않는다. 화면이 다시 활성화된 시점부터 남은 시간을 센다.
- 이 시간 규칙은 Presentation 동작이며 국가 선택, Simulation Tick, 운영 상태, 저장·Replay 시간을 변경하지 않는다.

## 검증 기준

1. 시작 직후 한반도 중심 구도가 유지된다.
2. 4.99초까지 자동 자전이 시작되지 않는다.
3. 5초가 지난 뒤 무입력 상태에서만 자동 자전이 시작된다.
4. 5초 전에 입력하면 자동 자전 시작 예약이 취소된다.
5. 명시적 구도 복귀 뒤 같은 규칙이 다시 적용된다.
6. Game View 캡처는 시작 직후, 5초 유지 중, 자동 자전 시작 뒤를 구분해 남긴다.

이번 판본은 기획 확정만 기록했다. Unity 코드·Scene·Play Mode·Game View 재검증·commit·push는 수행하지 않았다.
