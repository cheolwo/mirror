# [기획 · 월드·데이터·관찰 · PLAN-SYSTEM-KOREAN-PENINSULA-PUBLIC-DATA-WORLD · 구현 r31]

## 범위

HS 2022 법정 HS6 조사 대장을 오름차순으로 이어 `021019`부터 `030194`까지 12개 코드를 `chapter02-meat-06` 배치로 처리했다.

- 이번 배치: HS6 12개, 관세청 2026 HSK10 자식 22개.
- 누적 순차 범위: 제1류 전체 34개, 제2류 66개, 제3류 첫 6개로 합계 HS6 106개·HSK10 자식 187개.
- 관세청 HSK10 성질 분류와 WCO HS 2022 법정 HS6는 서로 다른 단위로 유지한다.

## 조사 판정

- 염장·건조·훈연 조건을 상품 상세에서 확인한 돼지 목심 `021019`, 한우 프로슈토 `021020`, 오리 가슴살 프로슈토 `021099`에 공개 색인 후보를 한 건씩 `PendingHumanReview`로 기록했다.
- 영장류 `021091`, 해양 포유동물 `021092`, 파충류 `021093`는 정확한 후보가 확인되지 않아 `SearchNoCandidate`로 기록했다.
- 살아있는 관상어·송어·뱀장어·잉어류·참다랑어 `030111`~`030194` 여섯 코드는 쿠팡 공식 생체동물 온라인 판매 제한 근거에 따라 `RestrictedOrSensitive`로 닫고 상품 후보를 만들지 않았다.
- 검색 무결과와 정책 제한은 법적 세번 확정이나 모든 채널의 판매 가능성 판정이 아니다. 모든 상품 후보는 `affiliate=false`, `distributionApproved=false`다.
