# 움직임 우선 관찰 시도 r20

2026-09-23 사용자 요청. 기존 지구본의 읽기 전용 운송수단 미리보기부터 좁게 수정했다. 트럭·고속도로·사가정 배달 모듈 확장은 이번 구현에 포함하지 않았다.

- 기본 큰 패널·전체 연결선을 숨기고 선박/항공 모형을 확대했다. 기본은 작은 통계 상징 안내만 표시한다.
- 모형 화면 위치에서 28px 안의 가장 가까운 대상을 선택한다. 지구 구체에 가려진 뒷면 모형은 제외하고, 7px 이상 드래그는 클릭으로 처리하지 않는다. 물리 Collider·업무 상태 변경 없음.
- 선택 시 해당 연결선 하나와 하단 작은 카드만 표시한다. 근거 자료는 추가 버튼으로 펼친다. 빈 곳 선택/닫기로 복귀한다. HS 전체 조회 화면은 이 모드를 열 때 해제하며 별도 메뉴로 다시 열 수 있다.
- 변경: Unity `운송수단관찰View`, `운송수단관찰Loader`. 실제 Play에서 기본 모형20·선택없음, 투영좌표 선택 결과0·활성 연결선1, 빈 화면 좌표 결과-1을 확인했다. API를 통한 선택 검증이며 실제 마우스 입력·드래그 충돌·작은 화면 상세 카드의 완전한 가독성은 후속이다.
- 실제 Game View: [기본 화면](../../../../assets/changes/2026-09-23-transport-preview/animation-first.png), [선택 카드](../../../../assets/changes/2026-09-23-transport-preview/animation-selected.png). 기본 화면에는 기존 해양 안내 패널이 일시적으로 남은 장면이 있어 기존 UI 숨김 순서도 후속 확인한다. 모형 밀집/해상도의 추가 다듬기가 필요하며 최종 UI 시안은 아니다.
- 통계는 실제 항로·운항 대수가 아니고 품목별 HS 운송량은 미결속이다. DB·원본 사본·23.5도 표시·기존 Scene 파일 변경 없음. Play 종료·Scene 저장·정식 빌드·commit·push 없음. 기존 서버 세션 오류 미해결, 전체 Console0 주장 없음. 새 디오라마 규칙 후보 없음.
