## 좁은 구현 명세

- 기존 관세청 품목·국가 API에서 품목 필터 없이 2025년 12개월을 요청한다. 공급원 연간 총계 1행만 이용하고 월/HS 상세와 중복 합산하지 않는다. 전체 기간·상대국·중복·필수 수치·음수·원본 hash를 검사한다. 세부 중량 합산과 공식 총계 차이는 기록한다.
- 기존 CLI/로컬 MySQL 원본 등록·정규화 저장 서비스를 재사용한다. 원문은 비공개 artifacts/local, 토큰 미포함, 5개 상대국만 유계 조회한다. 원본 최대 50MiB/국가, HTTP 90초, 자동 재시도/정기 수집 없음.
- DB 20개 지표(5국가×수출입×중량/금액) 독립 재조회 후 10흐름 읽기 사본을 export한다. 해상/항공 미확보이므로 `Unknown`을 유지하고 중립 화물만 표현한다.
- Unity Editor 전용 명시적 파일 로드. 기존 SimulationWorldShell/지구본에 결속, 통계 모드에서 r11의 장식 선박은 숨긴다. 화물은 통계 관계 곡선 위를 한국↔상대국 방향으로 이동한다. 항로·직항·실제 화물 개수가 아니다.
- 한 방향 흐름당 표시 수는 공통 선형 배율과 제한된 객체 풀로 정한다. 각 흐름의 이동 시간은 동일해서 긴 거리 때문에 더 큰 양으로 보이지 않도록 한다. 금액·중량·반영 시각·출처·배율을 상세 카드에 표시한다.
- 쓰기: 기존 CLI Program의 진입 분기, 신규 국가무역관찰Pipeline, 별도 Unity 신규 View/Loader/시험/meta, 관련 기획/현재 작업/캡처. 원격 DB/운영 API/결제/정식 빌드/Scene 저장/commit/push 없음.
