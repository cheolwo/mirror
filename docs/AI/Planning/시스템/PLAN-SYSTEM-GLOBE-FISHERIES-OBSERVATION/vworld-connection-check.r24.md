# VWorld 중간 지도 연결 점검 r24

일자: 2026-09-23. 상태: `AccessConfigured / BrowserRequestBlocked / UnityNotApplied`.

## 확인한 결과

- 사용자 승인으로 기존 개발키에 WMTS/TMS API를 추가했으며 포털의 저장 성공 안내를 확인했다. 기존 지오코더 설정은 유지했다.
- [공식 TMS 레퍼런스](https://www.vworld.kr/dev/v4dv_tmsguide_s001.do)에서 HTTPS 요청 형식과 Google Index Y/X 순서를 확인했다.
- 주소 형식은 `https://api.vworld.kr/req/tms/1.0.0/{key}/{tileMap}/{tileMatrix}/{tileRow}/{tileCol}.{tileType}`이다. Base는 6~19단계 PNG이며 tileRow는 Y, tileCol은 X다. 일반적인 XYZ 주소와 순서를 혼동하지 않는다.
- 서울 부근 Base 타일 한 장 요청을 시도했으나 내장 브라우저가 `ERR_BLOCKED_BY_CLIENT`로 차단했다. 서비스의 인증 성공/실패 응답이나 이미지 바이트를 확보하지 못했다. 이를 VWorld 서버 장애나 인증키 오류로 판정하지 않는다.
- 브라우저 도구 오류가 키 포함 요청 주소를 자동 출력했다. 문서·소스·설정에는 키를 복제하지 않았고 사용한 브라우저 실행 변수의 참조를 해제했다. 대화 기록에서의 삭제를 의미하지 않는다. 노출된 개발키는 사용자가 폐기·재발급하는 것이 권장된다.

## 재개 순서

1. 사용자가 노출된 키를 폐기·재발급한다. 인증정보 변경을 대신 수행하지 않는다.
2. 새 키는 채팅으로 전달하지 않고 저장소 밖 비밀 설정에 등록한다. 키 포함 URL·예외 원문을 출력하지 않는 클라이언트를 먼저 준비한다.
3. 공식 조건을 확인한 제한된 연결 시험으로 HTTP 상태·콘텐츠 유형·실제 이미지 크기를 확인한다. 설정 저장 성공과 API 성공을 구별한다.
4. 인증 시험 이후 서울→중랑구의 위경도 중심과 타일 경계를 기존 사가정 자료에 대조한다. 준비된 자료만 기존 SimulationWorldShell 표현 경로에 연결한다.
5. 실제 Play Mode와 Game View로 확인하기 전에는 Unity 적용 완료로 보고하지 않는다.

## 경계

지도 타일은 배경 표현이며 도로 주행 가능성·건물 높이·업무 장소의 권위 자료가 아니다. 장기 캐시·DB 저장·배포 자원 포함은 이용조건 확인 후 별도 판단한다. 이번에는 타일 수집·DB 저장·Unity 코드/Scene 변경·빌드·commit·push를 수행하지 않았다. 기존 r21 표현은 보존한다. 새 디오라마 규칙 후보 없음.
