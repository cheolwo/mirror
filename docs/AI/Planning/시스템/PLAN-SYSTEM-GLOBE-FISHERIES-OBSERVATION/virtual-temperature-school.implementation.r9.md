# 수온 반응 가상 실험 어군 r9

## 승인과 좁은 구현 범위

2026-09-23 사용자 “물고기 이동 … 가상 실험 어군으로 해도 괜찮지”로 r8의 선택을 수용했다. `ApprovedScopedLocalExperiment`. 기존 Editor 전용 수온 사본과 지구본에 비권위 가상 어군 하나를 붙인다. 실제 어종·서식·회유 예측·게임 성장·어획·재고·새 Scene·운영 API는 제외한다.

지금/여기/나/너/이렇게: 과거 수온 9격자에서 사용자가 선호 수온을 설정하고 가상 어군이 인접 칸으로 이동하는 이유를 관찰한다. 결과는 모의 위치와 이유이며 다음 선택은 목표 수온 변경·날짜 선택·정지·초기화다. 실패는 결측/이동 후보 없음으로 명시하고 값을 만들지 않는다.

- 실험 기본값 27.5°C, ±0.1°C 조절. 실제 생태 최적값이 아닌 수정 가능한 시연 설정이다.
- 중심 격자에서 출발한다. 상하좌우 0.05도 인접 칸 중 `abs(수온-선호값)`이 현재보다 엄격히 작은 칸을 고른다. 동률은 북→남·서→동 순서의 격자 인덱스로 결정한다. 자료 누락·육지·비정상 값은 후보에서 제외하며 현재 칸이 결측이면 정지한다. 국소 최선에서는 대기하고 표본 밖을 추정하지 않는다.
- 2초/칸은 관찰용 모의 재생 시간으로 실제 이동 속도가 아니다. 전이 도중 좌표는 표현 보간만 하며 끝에 모의 칸을 확정한다. 날짜 변경은 중앙에서 새 실험, 선호 변경은 마지막 확정 칸에서 재판정한다. 정지 중에는 시간 누적하지 않는다.
- 지도 표식은 실제 격자 좌표에 둔다. 지구본에서 매우 작은 표본이므로 물고기 모형 크기는 확대 기호이고, 기존 3×3 격자 카드에도 물고기를 함께 표시한다. 지도 위치·카드 확대 축척을 구분한다. 동일 모델 상태를 두 표현에 사용한다.
- r8 검증된 사본만 메모리로 사용, DB·원본 관측 수정 없음. 독립 순수 C# 결정 모델과 View를 분리하되 정식 Hosted Simulation/저장 규칙으로 승격하지 않는다.

- 논리 E5~E7 검증 의도: 모델 이동·대기·설정 변경·초기화가 같은 사본에서 닫히는지 확인한다. 별도 WI/Goal·기존 게임 성장·공용 Event는 자동 생성하지 않는다. 이번 로컬 표현 실험의 시험을 게임 통합 E 증거로 승격하지 않는다.

- 표현 E5~E7 검증 의도: 실제 World 및 카드에서 동일 모의 위치를 읽고 2초 보간·정지·재설정을 확인, 가능한 실제 Play Mode/Game View를 별도 기록한다. 카메라/격자 선택이 모델을 초기화하지 않아야 한다.
- 도구 MCP가 현재 세션에 없으므로 설치된 Unity CLI/Pipeline으로 검증한다. 기존 dirty 변경은 보존한다. commit·push 없음.

## 결과

- 기존 검증 사본의 해양 격자 9개로 독립 결정 모델을 연결했다. 원본 사본·DB 쓰기·외부 API 호출 없음. 화면 두 곳의 물고기는 같은 가상 어군 하나의 표현이며 개체 수나 실제 분포가 아니다.
- Unity 최종 컴파일 성공, 어군 전용 10/10·기존 수온 10/10 통과. 초기 테스트 검색 0건은 신규 파일 import 전 상태였고 재컴파일 후 실제 시험 이름·결과를 확인했다. 일부 CLI 요청 시간 초과는 재조회 결과와 구분했다.
- 실제 canonical `SimulationWorldShell` Play Mode에서 9월 1일 사본을 읽었다. 선호 27.5°C에서 중앙(4)→서쪽(3)→북서(0), 선호 28.2°C에서 중앙(4)→동쪽(5)→북동(2)으로 자동 시간 진행 후 각각 2회 이동 확인. 선호 버튼 7회는 onClick 호출이며 물리 마우스 입력 검증은 아니다.
- 일시 정지·초기화·날짜 변경 시 중앙/이동수 0·격자 선택·접기/열기 확인. 두 표현 객체 수 2 유지. 최종 [실제 Game View](../../../../Changes/2026-09-23-virtual-fish.md)를 확인했다.
- 화면 검증에서 발견한 CanvasRenderer 누락을 수정하고 회귀 시험을 추가했다. 작은 창에서 버튼이 잘리는 문제는 높이 기준 CanvasScaler로 수정했다. 격자 물고기 기호가 수온 숫자와 일부 겹치는 시각 마감은 후속 개선 여지가 있다. 실제 지구본 위치 변화는 표본 범위가 작아 육안으로 작으며 확대 격자가 이동 판독의 주 화면이다.
- Play Mode 종료, Scene 저장·commit·push 없음. 기존 월드/LocalCombat 초기화·종료 오류는 별도이며 전체 Console 0을 주장하지 않는다. 정식 Hosted·Save/Replay·배포 빌드·장시간 검증은 하지 않았다. 로컬 Editor 실험 완료이며 게임 통합 E 승격 없음. 새 디오라마 규칙 후보 없음.

r8과 같이 Play Mode에서 `Tools/Mirror/로컬 수온 사본 열기`로 검증된 `sst-preview.json`을 연다. 기본 선호 27.5°C로 실행되며 선호 ±0.1, 일시 정지/재생, 처음부터를 사용할 수 있다. 날짜 변경은 새 실험이다. 사본은 여전히 로컬 검토용으로만 읽는다.
