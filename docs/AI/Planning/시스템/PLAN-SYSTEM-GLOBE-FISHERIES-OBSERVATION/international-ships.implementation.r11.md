# 세계 해역 가상 선박 r11

2026-09-23 사용자 요청: 중국·동남아·일본·미국·호주 주변에서도 여러 선박이 계속 오가도록 한다. `ApprovedScopedLocalPresentation`. r10 Editor 연출을 확장하며 실제 AIS·항로·항구·국가 간 운송 계약을 의미하지 않는다.

## 범위·검증 명세

- 기존 동해 포함 6개 합성 경로, 경로당 2척, 고정 객체 왕복. 물고기는 유지한다.
- 날짜 변경선을 지날 때 최단 경도 차로 보간하고 기존 저해상도 국가 윤곽에서 육지 교차 경로만 차단한다. 안전 항로 인증이 아니다.
- E1~E4: 관찰·회전·숨김 외 업무 입력 없음. E5~E7: 경로별 바다 검사, 날짜 변경선, 왕복, 객체 고정과 실제 Play 확인. 게임 E 승격 없음.
- 쓰기 범위: 별도 Unity `해양생활연출View`, 새 `가상해양항로Catalog`와 meta, 기존 해양 시험, 이 기획·목차·현재 작업·화면 기록. Scene·DB·운영·빌드 배포·commit/push 제외.

## 결과

- Unity 컴파일·해양 EditMode 7/7 통과. 기존 동해 왕복·물고기 반지름 시험을 유지하며 6개 항로 바다 판정·국제 왕복 주기·날짜 변경선을 추가했다. 첫 검사에서 대만 육지 교차를 발견해 합성 경유점을 동쪽/남쪽으로 수정한 후 재시험했다. 작은 섬·수심·항만 안전을 증명하지 않는다.
- 실제 `SimulationWorldShell` Play Mode: 항로 6·선박 12·물고기 3. 자동 시계 7.61→22.51초 진행, 아시아/호주와 태평양 관점에서 [Game View](../../../../Changes/2026-09-23-international-ships.md) 확인. 카메라는 API로 돌렸으며 물리 드래그 검증은 아니다.
- 연출 갱신 1,000회 및 숨김/재표시 후 직접 자식 36개 유지·선박 12척·Collider 0개 확인. 신규 무한 생성이 아니라 기존 객체가 계속 왕복한다. 국제 항로 주기는 시연용 150초, 기존 동해는 50초다.
- `WorldTileStreamRequestFailed`, `Simulation*ServerSessionMissing`, LocalCombat/Nature 초기화 오류 등 기존 서버 연결 문제는 남아 전체 Console 0이 아니다. Play 종료·Scene 저장/빌드/commit/push 없음. 출처는 기존 국가 윤곽이고 항로는 합성이다. 새 디오라마 규칙 후보 없음.
