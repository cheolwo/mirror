# 지구본 해양 유영·선박 시연 r10

## 승인·범위

2026-09-23 사용자가 수면 위아래 물고기 애니메이션과 선박의 해양/해안 왕복 표현을 요청했다. `ApprovedScopedLocalPresentation`. 기존 곡면과 r9 가상 실험을 유지하며 로컬 Editor 시연만 추가한다. 실제 어종·항로·항만·AIS·운항 안전 판단·물류 완료를 만들지 않는다.

- 물고기 3개 기본 도형: 지구 중심 방향으로 잠수/부상, 꼬리 흔들기·몸 기울기·작은 물결. 위경도 이동 판정과 애니메이션 높이는 분리한다. 수온 사본을 열면 r9 어군 좌표를 읽되 그 상태를 수정하지 않는다. 사본이 없으면 명시적 합성 해역에서 장식 유영한다.
- 선박 2척: 합성 경유점의 구면 경로를 왕복하고 끝에서 짧게 대기한다. 해안 앞 바다 지점은 가상 접안 표식일 뿐 실제 항구로 등록하지 않는다. 육지 안으로 진입하거나 배달/입출고를 완료하지 않는다.
- 기존 Natural Earth 국가 경계로 경로를 촘촘히 검사해 육지 판정 시 해당 항로 표현을 차단한다. 저해상도 경계 검사는 실제 항로·수심·작은 섬의 안전을 입증하지 않는다.
- 모델 크기·주기·속도는 관찰용 과장 연출이다. 기존 지구본 카메라/공식 Scene 유지. 외부 자료 수집·DB·Scene 저장·commit·push 없음.
