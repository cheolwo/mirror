# 행정동 선택 → 준비된 디오라마 진입 r28

사용자 승인 범위: r27 지도에서 행정동을 선택하면 준비된 모듈만 열고 미준비 동은 지도를 유지한다. 별도 Scene·운영 상태 쓰기 없음.

## 연결과 경계

- 기존 2023-10-31 검토 경계에서 사가정 원점(127.0884106,37.5806971)의 변환 좌표 (0,0)를 포함하는 삼각형을 대조하여 `11260570` 면목7동을 확인했다. 기존 구성 대장의 행정동10자리 `1126057000`과 원본8자리 코드를 혼용하지 않는다.
- 면목7동 클릭은 **사가정 역세권 일부 보기**다. 행정동 전체 재현 또는 역세권과 행정동 경계의 동일성 주장이 아니다. 첫 연결 하나는 기존 `OpenRegionalDiorama`의 준비 관문을 재사용한다.
- 다른 동: ‘디오라마 준비 중’. 알려지지 않은 코드·현재 구 밖 선택은 무시한다. 준비된 모듈 열기 실패 시 지도와 안내를 유지한다. 다른 동을 사가정으로 임의 치환하지 않는다.
- `서울중간공간View`에 지명 버튼 및 카메라 ray/평면 교차·삼각형 내부 판정 기반 경계 클릭을 같은 `SelectDong` 경로로 연결했다. UI 상단/하단 영역은 도형 선택에서 제외한다.
- 복귀 시 기존 구·카메라 중심·확대 배율을 보존한다. 이제 무조건 사가정 단계로 복귀하지 않는다. 선택 안내도 보존한다.
- 신규 배포 자료·DB·Scene 저장 없음. r27 로컬 파일을 기존 메뉴로 열어 사용하는 Editor 검토 범위다.

## 검증

- Unity `서울중간공간Tests` **9/9**. 기존7건에 도형 안/밖 판정 및 첫 연결 allowlist 검증 추가.
- 실제 Play: 면목2동 선택 false, 지도 visible=true, 준비 중 안내 확인. 면목7동 선택 true로 기존 모듈 진입 후 복귀 visible=true, Stage=중랑구.
- 진입 전후 카메라 위치 `(10000.49,80,9973.63)`, orthographicSize `3.848799` 동일 확인.
- 실제 Game View `pending.png`, `diorama.png`, `returned.png`는 별도 Unity 저장소 `Documentation/Changes/2026-09-23-dong-entry/`에 보존했다. View 함수 호출 검증이며 실제 물리 클릭·휠 검증 아님.
- 첫 시험 요청은 Editor 재연결 중 Connection reset, 재요청 정상9/9. 기존 서버/Replay 오류와 업무 결과0 경계는 r26/r27과 동일하며 Console0·Windows 빌드·업무 E2E 완료 주장은 하지 않는다.
- 좁은 화면에서 지명 버튼 겹침이 남아 있다. 후속은 표시 밀도 정리 및 실제 클릭 입력 시험이다.

Play 종료, 기존 변경 보존, commit/push 없음. 기존 자료·권위 분리 규칙 지지, 새 디오라마 규칙 후보 없음, E 승격 없음.
