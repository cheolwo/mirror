## 구현 범위

- HS 판본 H6(HS 2022)·HS6·신고국 410·기간 2025·수입 M·상대국 M49·지표 단위로 묶는다. 기존 배치 간 같은 관측은 합산하지 않고 동일값이면 출처를 병합, 충돌이면 거부한다.

- 읽기 전용 CLI가 실제 MySQL 조회 후 결정적 HS 색인과 출처/hash 사본을 만든다. Unity는 검토 사본의 코드별 품목·세계합계·국가 통계를 읽는 작은 조회 화면을 갖는다. 기존 이동 모형의 양이나 선적 품목을 자동 바꾸지 않는다.
- 허용 경로: 기존 CLI Program·신규 HS 조회 Pipeline, Unity 신규 HS 조회 View/Loader/Tests/meta, 본 문서·목차·현재 작업. DB 쓰기·새 API·공개 게시·운영 상태 변경·commit·push 없음.
- 검증: 단위/판본/중복/결측 검사, 실제 DB 조회와 결정성, Unity 해석·표시. 코드·시험과 실제 Play를 구분한다. 새 게임 WI/Goal·E 승격 없음.
