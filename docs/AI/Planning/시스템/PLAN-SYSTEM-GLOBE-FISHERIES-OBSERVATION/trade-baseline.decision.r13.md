# [기획 · 무역 관찰 · PLAN-SYSTEM-GLOBE-FISHERIES-OBSERVATION · r13]

상태: `ScopeConfirmed / DataAcquisitionPending`. [r12 조사·제안](trade-weighted-transport.proposal.r12.md)의 근거와 미확인 사항을 보존한다. 2026-09-23 사용자는 중량 중심 표현·금액 상세 조회에 동의한 뒤, 제안한 2025년 기준으로 먼저 정리하는 데 동의했다. 전체 구현 완료나 자료 확보를 뜻하지 않는다.

## 확정

- 첫 기간: **2025-01-01~2025-12-31 연간**. 보고국은 대한민국, 상대국은 중국·일본·미국·호주·베트남이다. 베트남은 동남아 첫 사례이며 지역 전체 합계가 아니다.
- 5개 상대국의 **수출 5개·수입 5개 흐름을 분리**한다. 전체 상품 범위의 국가 합계가 첫 비교 대상이며 기존 일부 품목 자료로 대신하지 않는다.
- **중량**을 화면 운송량의 기본 기준으로 사용하고, 상세 카드에 **금액**도 표시한다. 통계 원단위를 보존하고 화면 단위 변환을 명시한다.
- 해상/항공이 근거로 확인된 경우에만 선박/항공기로 나눈다. 미확보는 중립 화물 표식으로 구분한다. 표시 객체 수는 상징적인 환산량이지 실제 운항 대수가 아니다.
- 2026년은 첫 범위에서 제외한다. 이는 비교 기간을 통일하기 위한 선택이며 2026년 자료가 없거나 적다는 사실을 검증한 것은 아니다. 후속 월별/누계 자료는 2025년 연간과 혼합하지 않는다.

## 자료 확인·후속 순서

1. 기존 수집기와 대상 API의 접근 권한·2025년 가용성·국가 코드·전체 품목 합계·수단 구분을 확인한다.
2. 연간 직접 통계를 우선 확인한다. 월별로 합산할 경우 12개월 완전성을 검사하고 연간/누계/월별 합계를 중복 더하지 않는다. 누락·미공표는 0이 아니다.
3. 원본·출처·기간·단위·조회 시각·hash·개정판을 기존 로컬 MySQL의 비공개 검토 자료로 저장하고 독립 재조회·동일 입력 멱등성을 검증한다. 저장했다는 증거 없이 완료 처리하지 않는다.
4. 실제 분포를 확인한 다음 기호당 중량과 전체 표시 상한을 정한다. 현재 r11의 합성 12척을 실제 통계에 따른 수량이라고 재해석하지 않는다.

## 미정

- 자료의 실제 가용성, 운송수단 구분, 기호당 배율·객체 상한은 아직 미정이다.
- 월별 갱신·2026년 확대·국가 추가·제품 배포는 별도 후속이다. 실제 자료 확인 전 Unity 항로·객체 수를 변경하지 않는다.

## 이번 반영·검증

승인 범위와 목차·현재 작업만 갱신했다. 실제 통계 수집·DB 저장·Unity 수정/실행·commit·push는 하지 않았다. 문서 링크·diff 검사를 수행한다. 새 디오라마 규칙 후보 없음.
