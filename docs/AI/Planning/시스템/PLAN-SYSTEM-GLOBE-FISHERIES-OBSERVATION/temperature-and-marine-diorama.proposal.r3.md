# [기획 · 지구본·수산물 관찰 · PLAN-SYSTEM-GLOBE-FISHERIES-OBSERVATION · r3]

## 확정된 의도와 승인 범위

- 2026-09-22 사용자 답변으로 [r2](first-scope.decision.r2.md)의 첫 대표 품목을 고등어·대서양 연어·대구 세 가지로 좁히는 질문을 수용했다. 이는 품목 후보 선정이며 세 품목의 한반도 실제 서식·동일 해역 공존이나 HS–생물종 대응의 승인 근거가 아니다.
- 추가 사용자 의도: 수온 변화와 연결된 물고기 이동을 보고 싶으며, 지구본을 충분히 확대하면 같은 공간을 평면에 가까운 해양 디오라마로 관찰하고 싶다.
- 아래 기술적 배치·행동 규칙·자료원·시간 재생 방식은 `Proposed`다. 기존 국가 수입 통계 카드와 사실/가상 분리 원칙을 유지한다.

## 공간 확대 제안

| 수준 | 화면 | 자료 |
| --- | --- | --- |
| 지구·동아시아 | 곡면 바다와 소수 품목 표식 | 국가 수산물 통계 및 준비된 해양 자료 범위 |
| 한반도·해역 | 같은 바다 위 수온 분포 또는 관측 지점, 선택 해역 | 관측 시각·깊이·해상도·품질이 확인된 수온 자료 |
| 로컬 해양 디오라마 | 가까이서는 거의 평면처럼 보이는 수면과 가상 어군 | 동일한 해역 원점·범위·시간과 모의 이동 규칙 |

[기존 의미 확대/타일 체계](../PLAN-SYSTEM-GEOSPATIAL-TILE-SEMANTIC-ZOOM/README.md)는 곡면→지역 ENU·배치맵 구조를 정의한다. 기존 구현 기록은 행정동/역세권 전환이며 해양 전환이 이미 구현됐다는 뜻은 아니다.

- 해양에서는 `국가→행정동→역`을 강제로 거치지 않고 선택한 해역→로컬 해역으로 분기한다. 의미 확대 Z, 자료 타일, H 공간 포함은 서로 다른 축이다.
- 원본 위경도·관측 ID·가상 어군 ID를 유지한다. 가까운 범위에서 지역 원점의 ENU 좌표로 재투영해 평면에 가깝게 표현하며 지리 좌표를 임의 수정하지 않는다. 넓은 해역 전체를 무조건 평탄화하지 않는다.
- 초점 지점·방향·크기·시각을 이어서 전환하고, 복귀 시 같은 바다를 본다. 별도 사각 사진판을 갑자기 띄우거나 새 공식 Scene을 만들지 않는다.
- 카메라 안정 대기·진입/복귀 임계값 차이·자료 준비 관문을 재사용해 경계에서 반복 전환되지 않게 한다. 하위 자료가 없으면 상위 표현을 유지한다.
- 확대해도 원자료 이상의 정밀도를 주장하지 않는다. 해수면 자료만 있을 때 해저 지형·수심별 온도를 임의 생성하지 않는다. 첫 기본은 위에서 비스듬히 보는 수면 디오라마이며 수중 단면은 후속 후보로 둔다.

## 수온 자료와 가상 이동의 분리

`공식 수온 관측 → 서버 검토·저장·읽기 사본 → 품목/어종별 모의 규칙 → 가상 어군 상태 → Unity 표현`.

- 수입 통계는 계속 국가·기간·품목에 귀속한다. 수입 중량을 어군 개체 수·밀도·서식 위치로 전환하지 않는다.
- 관측은 관측 ID, 위치/격자, 측정 깊이, 시각/기간, 섭씨 단위, 품질, 원본 해상도, 출처/판본, 승인·누락 상태를 보존한다. 실측·보간·분석 자료를 구분하고 표면 온도를 수층 전체 온도로 복제하지 않는다.
- 품목의 정확한 생물종 대응과 서식 근거를 확인한 뒤 모의 규칙을 만든다. 온도 선호·회피 범위, 이동 속도·응답 지연 등은 출처가 있거나 명시적 실험 매개변수여야 한다. 이번에 수치나 어종별 최적 수온은 확정하지 않았다.
- 수온 외에 수심·해류·산소·먹이 등 미반영 요인을 표시한다. 단순한 `따뜻해지면 전부 북상` 규칙이나 실시간 어군 예측으로 제시하지 않는다.
- 검증 전에는 `관측 수온 기반 가상 이동`으로 표시한다. 세 품목을 같은 시험 공간에 배치하더라도 실제 한국 해역의 서식 기록이 아니라 가상 실험임을 명확히 한다.
- 자료가 없거나 오래되면 상태를 표시하고 근거 기반 이동 갱신을 보류한다. 장식적 유영이 지속될 경우 통계 반응과 구분한다.
- 모의 시간·seed·환경 판본·규칙 판본으로 재현 가능하게 하고 카메라 확대가 시뮬레이션 시간·개체 수·어획·운영 재고를 바꾸지 않게 한다. Unity 밖 공통 Simulation 규칙과 표현 보간을 분리한다.

## 공식 자료 후보 확인 (2026-09-22)

- [국립수산과학원 OpenAPI 안내](https://www.nifs.go.kr/openApi/actionOpenapiInfoList.do): 어장환경 관측에 정점·위경도·측정일시·수심·수온 등 항목을 안내한다. 후보이며 신청/이용조건·해역별 자료 충실도는 아직 확인 관문이 남는다.
- [국립수산과학원 관측 조회](https://www.nifs.go.kr/portal/me/femoA/actionDataObsSearch.do): 관측 지점과 수심(m)·수온(ºC) 등을 구분하는 조회 구조를 확인했다. 특정 해역/날짜 관측값을 수집한 결과는 아니다.
- [NOAA CoastWatch 해수면 온도](https://coastwatch.noaa.gov/cwn/product-families/sea-surface-temperature.html): 위성 SST는 해수면 자료이며 센서·구름·해상도에 따른 제약과 관측/합성/분석 제품 차이가 있다. 전 지구 자료 후보이지 해저 수온 근거는 아니다.
- [NOAA 어류 이동 연구 설명](https://restoreactscienceprogram.noaa.gov/projects/fisheries-on-the-move): 수온은 주요 분포 요인이지만 수질·서식 환경·다른 생물과의 상호작용도 제한 요인이 될 수 있다고 설명한다. 특정 국내 어종의 이동 규칙을 검증한 근거로 확대하지 않는다.

이번은 기획용 공식 설명 확인이다. 원본 관측 수집·DB 저장·독립 재조회·자료 사용 승인은 하지 않았다. 실제 자료 확보 작업에서는 기존 수집·저장·재조회 관문을 따르며 API 키·권리·해역을 확인한 뒤 진행한다.

## 구현 제안 순서

1. 자료가 준비된 작은 해역 하나와 기간을 고르고 수온 관측을 저장·재조회한다. 수온 준비 전에는 기존 품목 카드/상징 이동과 섞어 성공 처리하지 않는다.
2. 공통 코어에 재현 가능한 온도 반응 모의 규칙 하나를 검증한다. 첫 품목 하나로 수직 검증 후 나머지 후보로 확장한다.
3. 기존 지구본→해역→로컬 디오라마 전환에 같은 초점·상태를 결속한다. 의미 위치·해양 마스크·자료 타일은 별도 관문이다.
4. 선택 카드에서 관측 수온, 모의 반응 이유, 국가 수입 통계를 구획별로 보여 준다. 일반 화면에서 상세 정보는 접는다.
5. 단계별 확대/복귀 캡처, 해안 침범·자료 누락·객체 수 상한·시간 재생·판본 불일치·권위 불변을 검증한다. Play Mode와 Game View는 별도 증거로 남긴다.
