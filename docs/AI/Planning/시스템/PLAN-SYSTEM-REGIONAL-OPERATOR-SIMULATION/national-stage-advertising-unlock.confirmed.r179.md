# [기획 · 전국 단계 광고 해금 · PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION · r179]

> **현행 후속:** [다섯 출발·테크트리 r183](multi-entry-management-research-tree.design.r183.md#6-광고-시작과-기존-전국-해금의-정합)은 최신 사용자 지시에 따라 광고 입문을 초기 선택에 포함한다. 이 문서의 모든 기초 광고에 대한 전국 선행 해석은 부분 대체되며, 전국 규모 광고망 확장의 단계 조건으로 구분해 읽는다. 당시 본문은 이력으로 보존한다.

- 기준일: 2026-11-14 · Unity Windows 경영 게임.
- 상태: `NationalStageAdvertisingUnlockConfirmed / DesignDocumented / UnlockCriteriaUnresolved / NotReadyToDispatch / ProductUnchanged`.
- 사용자 방향: “전국단위 지도가 열렸을 때” 광고 기능이 활성화되면 좋겠다는 후속 요청을 기록한다.
- 관계: [장소 검색·홍보 r176](place-search-advertising-and-demand.proposal.r176.md)의 사용 가능 시점을 제한하고, [중개업자 r177](underground-traffic-broker.gameplay.r177.md)·[소개 순서 r178](traffic-broker-introduction.confirmed.r178.md)의 앞에 전국 단계 해금을 붙인다. [시간·일일 보고 r174](live-calendar-daily-management.baseline.r174.md)는 유지한다.
- 범위: 가상 매장의 장소 검색·홍보 경영 기능이다. 기존 기사 모집 광고 등 다른 의미의 광고나 실제 서비스 광고 정책까지 이 조건으로 일괄 변경하지 않는다.
- 해석 기준: ‘전국 지도 열림’은 [게임·관찰자 모드 제안](../../../Handoffs/2026-11-13-Claude-게임모드-관찰자모드-설계제안.md)의 보기/경영 분리에 따라 **전국 단위 경영단계의 해금**으로 읽는다. 단순 카메라 이동·잠긴 지도 미리보기·관찰자 모드의 전국 자료 열람과 구별한다.
- WI·PlayableLoop·Graph Map: 미등록. 문서 기록이며 제품 코드·Unity 실행·DB·수집/예약·새 개발 작업을 변경하지 않는다.

## 확정 — 전국 단계가 열린 뒤 광고 경영을 시작한다

```text
동네·구 등 기존 단계에서 운영
→ 전국 단위 경영단계 해금
→ 가상 매장 정식 광고 기능 활성화
→ 정식 광고를 한 번 경험
→ 트래픽 중개업자 소개
→ 선택한 경우 중개 의뢰 조건 확인·확정
```

플레이어는 먼저 기존 단계의 운영을 경험하고 전국 단계에 도달했을 때 매장 홍보 경영을 새 선택지로 받는다. 그 후 정식 광고를 경험한 뒤 중개업자를 만나는 r178의 순서를 유지한다. 전국 단계가 열렸다는 이유만으로 중개업자를 곧바로 소개하지 않는다.

해금은 기능을 사용할 수 있게 되는 것이며 광고 계약·예산 집행·검색 순위·주문을 자동 생성하지 않는다. 소개도 중개 계약이나 비용 지급이 아니다. 광고/중개를 시작할지는 이후의 선택이다.

전국 지도에 처음 카메라가 도착하거나 잠긴 전국 지도를 둘러본 것만으로 광고를 활성화하지 않는다. 해금 판단은 경영 진행 상태와 연결한다. 지도 재진입·축척 전환·재접속·보고 재확인이 첫 광고 경험이나 소개를 반복 생성하는 조건이 되지 않도록 이력을 결속한다. 정확 저장/승계 방식은 후속 명세에서 정한다.

**해금 단계와 광고 대상 지역은 다른 문제다.** 전국 단계에서 광고 기능이 열린다고 모든 광고의 대상을 전국 전체로 고정하지 않는다. 동네 카페 한 곳의 홍보는 해금 뒤 기능을 비교할 작은 사례로 유지할 수 있다. r176의 첫 사례 제안은 초반 동네 단계에서 광고를 미리 사용할 수 있다는 뜻으로 읽지 않는다.

## 미정 — 기존 미답변은 유지한다

- 전국 경영단계 자체의 해금 조건. 기존 제안의 진출 구 수·물류 거점 조건을 이번 요청으로 승인하지 않는다.
- 정식 광고 한 번의 경험을 설정/계약·실제 게임 노출·결과 확인 중 어디까지로 판정할지.
- 해금 알림·광고 화면의 지도별 진입 위치와 광고 대상/도달 범위.
- 중개업자 소개의 정확 시점/연출·이력, 가격·효과·검증/제재·회복 및 구현 명세.

잠금 전 설명/미리보기를 광고 집행이나 첫 경험 완료로 기록하지 않는다. 관찰자 모드의 실제 음식점 자료를 광고 해금/성과 상태로 바꾸지 않으며, 기존 r174의 시간·일일 결산·부재중 처리 경계를 유지한다.

## 다음 질문 하나 — r178의 미답변 유지

정식 광고의 첫 경험은 게임 안에서 광고가 실제로 노출되고 그 결과를 확인한 시점으로 볼까? 전국 단계 해금의 이번 선택은 이 완료 기준에 대한 답변으로 간주하지 않는다.
