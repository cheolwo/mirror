## 골격 — 결정할 때 함께 작동하고, 결과는 한 번 더한다

```text
철학: 누구에게 생긴 변화이며, 이로움인가 부담인가? → 효과별 부호
과학: 기준과 비교해 실제로 얼마나 달라졌나?         → 효과별 크기
한 행위의 명덕 증감 = Σ (같은 효과의 부호 × 크기)
새 누적 명덕 = 기존 누적 명덕 + 확정된 행위 명덕 증감
```

철학은 수행 전 무엇을 살필지 정하고, 과학은 그 판단에 사용할 근거와 다음에 고쳐 볼 결과를 제공한다. 같은 효과의 부호와 크기만 서로 곱한다. 철학 연구값과 기술 연구값을 별도 점수로 만들어 또 더하거나, 기술 랭크만 높이면 피해도 함께 커지게 곱하지 않는다. 비교 기준안·대상·측정값·환산 규칙과 적용 판본을 남긴다. 0, 미확인, 아직 예상인 값을 구별한다. 필수 근거가 없으면 해당 부분의 평가는 보류한다.

**예시:** 한 건의 배차를 음식 준비 시각에 맞춰 조율한다. 기사 대기도 중요하다는 기준으로 사전에 준비 정보를 확인했고, 비교 기준 4분에서 실제 대기가 1분으로 줄었다. 다른 평가 항목이 변하지 않았다는 가상 사례에서 1분을 1점으로 두면 **(+1) × 3 = +3**, 적용 대상의 누적 명덕은 **20 → 23**이다. 이 변화는 배차(토) 기록으로 확인한다. 같은 일을 보기 위해 손님·가게·기사 화면을 차례로 열어도 여전히 한 행위이며 같은 결과가 다시 쌓이지 않는다.

명덕은 확인된 결과를 기준으로 지정 대상에 반영한다. 한 결과가 여러 대상에 관련될 때 전부에 그대로 복사하지 않고 기존의 역할·지역 귀속을 확인한다. 원 행위와 효과의 식별을 보존해 다시 보기·저장 열기·회차 재진입으로 중복 지급하지 않는다. ‘왜 했나’와 ‘어떻게 했고 무엇이 달라졌나’는 같은 카드의 세부 정보이며, 실제 수행·결과와 표현의 권위는 기존대로 구별한다.

## 1. 확정 방향 — 출발은 자유롭게, 깊이와 확장은 선택한다

새 플레이어는 다섯 분야 중 하나를 골라 그 분야의 작은 경영부터 시작한다. 같은 세계에서 운영 기록과 자본을 쌓고, 연구로 더 좋은 판단·운영 방식을 사용할 수 있게 된다. 한 분야에 계속 집중하거나 연결 연구를 통해 다른 사업을 추가한다.

배달→카페→광고→전자상거래→무역의 강제 순서는 두지 않는다. 무역으로 시작한 사람이 배달·카페를 먼저 마칠 필요가 없고, 한 분야의 심화 성장에도 다른 네 분야의 완주를 의무로 걸지 않는다. 타 분야 진출은 기존 성장을 지우는 전직이 아닌 선택적 사업 확장이다. 초기 선택/기존 세이브의 상세 승계 방식은 미정이다.

플레이 상황은 ‘지금 내 사업에서 무엇이 막히는가’로 시작한다. 여기에는 내가 운영하는 한 사업과 작업 공간, 필요한 고객/파트너가 있다. 나는 제한된 예산과 처리 여력을 가진 운영자이고, 상대는 약속 이행·메뉴/상품·홍보 효과 등 구체적인 필요를 가진다. 문제를 관찰하고 연구 과제를 골라 비용·시간·운영 부담을 감수한 뒤 결과를 비교한다.

상위 목적은 실제 게임 업무의 대기·재작업·불확실성을 줄여 고객과 참여자의 필요를 더 잘 충족하는 것이다. 직접 회복을 대신하는 보상 층으로 만들지 않는다. 기능 접근의 확대와 실제 개인 성장·경 유지·소득은 각 기록/규칙에 따라 구분한다.

아래 첫 작업·지원 구성은 독립 출발을 구체화하는 **제안**이다. 다섯 출발을 포함하는 방향과 실제 Windows 구현 완료는 별개다.

| --- | --- | --- | --- |

지도는 해당 시작 업무를 이해하는 관점이다. 무역에 필요한 거래처·항만 참조를 본다고 모든 전국/세계 경영권이나 다른 분야가 열린 것으로 처리하지 않는다. 시작별 화면/공간·자본·파트너 조건과 첫 완결 작업은 구현 전에 따로 정한다.

```text
        └─ 선택적 연결 연구: 다른 분야의 작은 입문 사업 추가
```

기초 잔액·현재 주문·기본 비용·필수 적격/안전/권한 정보는 처음부터 읽을 수 있어야 한다. 연구는 이 사실을 볼 권리를 판매하는 기능이 아니다. 비교 예측·대안 생성·배치/자원 조율 같은 판단 도구가 깊어지는 안이다.

| 공통 연구 후보 | 플레이어가 더 잘할 수 있는 판단 | 재사용 예 |
| --- | --- | --- |
| 비용·예산 비교 | 현재 사실을 바탕으로 여러 운영안의 비용/여유를 비교 | 배차안·캠페인·상품 구성·거래 조건 |
| 수요·처리 여력 | 들어올 일과 실제 처리 가능량의 차이를 검토 | 점심 주문·제조 대기·광고 유입·출고 물량 |
| 시간·약속 조율 | 준비·도착·마감의 예상과 실제를 함께 비교 | 픽업·포장·집행 구간·선적/납기 |
| 인계·협업 | 맡긴 업무의 조건과 결과를 추적 | 매장/기사·판매/배송·거래처/운송 |
| 불확실성·회복 | 지연/실패 시 대안과 부담을 비교 | 품절·캠페인 손실·미배송·공급 지연 |

공통 연구가 연결된 다른 분야에서도 같은 의미로 쓰이면 재사용하되, 배달 연구 하나로 무역의 분야별 판단까지 자동 숙달하지 않는다. 정확 노드와 선행 관계는 다음 후보를 바탕으로 정밀화한다.

## 4. 분야별 심화 갈래 후보

| 분야 | 입문 이후의 연구 후보 | 심화 방향 후보 | 확인할 운영 변화 |
| --- | --- | --- | --- |
| 배달 | 준비 시각 맞추기·추천 이유 비교 | 묶음 조율 / 권역 여력·회복 | 총 대기·약속 지연·이동 부담·보수/비용 |
| 카페 | 제조 동선 / 재고·발주 계획 | 피크 인력·설비 배치 / 복수 매장 표준화 | 제조 대기·품질·폐기·품절·참여자 부담 |
| 광고 | 검색 의도·소재 비교 / 유입·비용 측정 | 여러 매장 예산 배분 / 전국 광고망 | 유효 관심·정상 주문 기여·집행비·처리 여력 |
| 전자상거래 | 상품/재고 일치 / 포장·출고 계획 | 채널별 운영 조율 / 반품·보충 대응 | 약속 이행·재고 오차·반품·실제 기여 결과 |
| 무역 | 총 도착비용·납기 비교 / 요건·서류 진행 비교 | 공급처 분산 / 운송·조달 계획 | 비용·기한·자금 묶임·미해결 조건·회복 가능성 |

슬래시로 나눈 항목은 비교 가능한 갈래이며 모든 항목을 차례대로 마쳐야 한다는 뜻이 아니다. 심화 도구가 열려도 적은 물량에서는 간단한 방침을 계속 쓸 수 있다. 높은 연구 단계가 모든 상황의 최적해나 이익을 보장하지 않는다.

배달/화물의 판단 성장은 r153의 수기→추천 보조→시간 관리→묶음 조율→권역 계획을 재사용한다. 모든 분야를 이 다섯 단계에 억지로 끼우지 않는다. 카페·광고·전자상거래·무역은 각 업무의 선택·결과로 전문성을 읽는다.

## 5. 다른 분야로 이어지는 연결 연구

다음은 **독립적인 확장 예시**이며 하나의 진행 순서가 아니다.

| 현재 분야 → 추가 분야 | 연결 연구/준비 후보 | 새로 생기는 선택 |
| --- | --- | --- |
| 배달 → 카페 | 픽업 준비 이해 + 카페 입문 준비 | 직접 매장을 운영해 제조/픽업 약속을 조율 |
| 카페 → 전자상거래 | 상품화·포장/재고 연계 + 판매채널 입문 | 원두/가상 상품을 별도 주문 흐름으로 판매 |
| 광고 → 카페 또는 전자상거래 | 고객 전환 이해 + 대상 분야 입문 준비 | 홍보 대행을 유지하거나 자기 사업을 추가 |
| 전자상거래 → 무역 | 공급·납기 비교 + 무역 입문 준비 | 국내 조달 유지와 가상 해외 조달을 비교 |
| 무역 → 전자상거래 | 거래 품목/재고와 판매 이행 연결 | 거래한 가상 상품의 판매 경로를 직접 운영 |

연결에는 ‘관련 공통 역량과 현재 분야의 유효 운영 근거’ 또는 ‘기초를 보충하는 안내형 입문 과제’ 같은 대체 경로를 두는 안이다. 아직 열리지 않은 분야의 실제 완료 기록을 그 분야 진입의 유일한 필수 조건으로 걸지 않는다. 정확한 AND/OR 조건·대체 과제는 미정이다.

연결 연구 완료는 **진출을 검토할 수 있는 역량**이다. 실제 사업 추가에는 예산·공간/설비·파트너/인력·가용 상태 등 그 사업의 준비 조건을 별도로 확인한다. 연구 버튼으로 건물 소유·계약·재고·고객을 자동 지급하지 않는다. 기존 사업/성장을 지우거나 시작 지원을 반복 수령하는 경로로 만들지 않는다.

## 6. 광고 시작과 기존 전국 해금의 정합

최신 사용자 지시가 광고를 자유로운 출발 분야에 포함하므로 **광고 입문은 처음부터 선택할 수 있다.** 따라서 r179를 모든 기초 광고에 전국 단계가 필수라는 의미로 계속 적용하지 않는다. 이 선행 제한은 이번 판본에서 명시적으로 부분 대체한다.

| 구분 | 현행 방향 |
| --- | --- |
| 기초 정식 광고/입문 | 광고로 시작할 수 있어야 한다. 작은 가상 캠페인부터 시작하는 안이며 자기 매장 소유를 요구하지 않음 |
| 타 분야에서 광고로 확장 | 선택적 연결 연구와 광고 입문 준비를 통해 접근하는 안 |
| 전국 규모 광고망·전국 권역 간 예산 배분 | 기존 전국 경영단계 해금 방향을 유지하고, 관련 심화 연구·준비 조건을 결속하는 안. 정확 조건은 미정 |
| 트래픽 중개업자 | r178의 **정식 광고 경험 후 소개** 순서는 유지. 연구 완료 자체가 소개/계약을 생성하지 않음 |

동네·구 규모의 광고/예산 배분에 어떤 연구·진출 조건을 둘지는 별도 미정이며 이를 전국 해금에 일괄 묶지 않는다. 입문 캠페인을 중개업자 소개의 ‘광고 경험 완료’로 인정하는지도 기존 완료 기준과 함께 미정이다. 모든 광고/중개 기술을 시작 즉시 열거나 실제 플랫폼의 광고 권한을 부여하는 선택은 아니다. 실제 광고와 가상 검색·관심/순위·정상 고객 주문을 구분하는 r176~r180의 경계를 유지한다.

## 7. 연구가 경영 경험이 되는 순환

**운영 결과 → 막힌 이유 확인 → 연구 과제/대가 선택 → 검토·실험 → 기능 준비 → 도입/방침 선택 → 실제 운영 결과 확인**을 기본으로 둔다. r153/r175의 기존 환류를 재사용한다.

연구 자원은 게임 자본, 분야별 유효 운영 근거, 담당/설비 여력과 진행 시간의 조합을 후보로 둔다. 수치·기간·동시 연구 수·성공률은 미정이다. 통합 ‘연구 포인트’ 재화를 반드시 신설하거나 반복 클릭만으로 무제한 연구 근거를 쌓게 하지 않는다.

서로 다른 연구·현재 영업·도입 준비가 같은 자금이나 담당/설비 여력을 동시에 가용 자원으로 사용하지 않도록 기존 원장의 가용/예약 상태와 결속한다. 그 계약이 미준비면 구현 전에 별도 설계한다. 연구비와 도입비는 지출 목적·항목/시점을 구분하고, 같은 항목을 양쪽에서 중복 차감하지 않는다. 구체 예약·차감·해제/환불 시점과 금액은 미정이다.

연구 과제에는 다음을 먼저 보여주는 안이다.

- 지금 해결하려는 문제와 연구 전/후 플레이어가 고를 수 있는 차이.
- 선행 역량·대체 입문 과제·필요 자원, 당장 운영에 쓸 자원을 미루는 대가.
- 기대 변화와 불확실성, 유지/관리 부담, 실패·중단/재개·회복 선택.
- 연구 완료, 설비/인력 준비, 도입 확정, 실제 효과 확인의 서로 다른 상태.

효과가 없거나 부담이 늘면 이전 방침 유지·다른 갈래 선택·자원 보완·실험 재검토로 돌아갈 수 있다. 되돌림/환불 비용은 미정이다. 연구 사실이 과거 주문/정산을 다시 쓰거나 기존 선택의 비용을 되돌리지는 않는다.

## 8. 개인 성장·필수 규칙·구현 준비는 별개다

게임 내 연구는 사용할 수 있는 운영 도구/방침의 접근을 다룬다. [플레이어 행위·분야 성장](../../../../Architecture/플레이어행위기록과분야성장통합체계.md)의 이해도·현장 숙련·운영 숙련과 연결을 검토하되 기존 분야/WI/기여 계보를 재사용한다. 다섯 출발은 시작 선택을 위한 경영 구분이며 기존 분야 카탈로그를 다섯 개로 축소하거나 코드를 재정의하는 것이 아니다. 실제 결속은 필요한 분야/업무와 대조해 설계한다. 연구 구매로 숙련·경 유지·고객 만족·수익을 일괄 지급하지 않는다. 집중 직접 수행과 이완 위임/검토는 각각의 권위 결과 규칙을 따른다.

필수 안전·적격·재고·권한·계약 조건은 초급부터 동일하다. 연구가 검사나 동의·전문가 확인을 우회하게 하지 않는다. 무역의 기본 요건은 시작 시나리오에서도 유효하며 연구는 더 나은 비교/계획을 돕는다.

전자상거래는 [상품·채널출품 구조](../../../../Architecture/CommerceChannelIntegrationModule.md), 무역은 [주문·수출 원장 경계](../../../../Architecture/ExportLedgerModel.md)를 판단 소재로 참고한다. 해당 운영 코드가 게임 테크트리로 이미 통합됐다고 보지 않으며 실제 외부 출품·통관·결제 실행을 만들지 않는다.

게임 연구·실제 AI 모델 학습·공공자료 취득/예약·개발 전문 연구의 `Accepted`는 별개다. 연구 완료가 모델 가중치·자료 권리/최신성·개발 승인·E 단계를 자동 변경하지 않는다. 미구현 갈래는 제작/준비 상태를 분리해 표시하며 게임 잠금이 풀리면 실행될 것처럼 숨기지 않는다.

## 9. 한 번에 몰입할 초점과 공통 시간

시작 선택에서는 다섯 분야의 첫 질문·첫 작업·준비/부담을 간결하게 비교한다. 플레이 중 기본 화면은 현재 주 분야의 문제와 지금 검토할 연구 하나에 집중하고 나머지 갈래는 접어 두는 안이다. 전체 트리는 원할 때 펼쳐볼 수 있게 한다. 이는 표시 초점이며 실제 동시 연구 수를 확정하는 규칙은 아니다.

[한 동 집중 r182](single-dong-crowd-focus.confirmed.r182.md)은 첫 군중 비교 범위로 유지한다. 테크트리 자유 출발을 면목동 배달 강제 시작으로 되돌리거나, r182를 모든 분야/지도에 대한 영구 단일 지역 제한으로 확대하지 않는다.

연구는 오늘 준비에서 자원/과제를 선택하고 실행 구간의 실제 연구/검토 기록으로 진행하며 일일 결산에서 해당 결과를 읽는 안이다. 새 별도 턴·현실 달력은 만들지 않는다. r174의 작업 경과·날짜·보고·부재중 제한을 유지하고, 결산 확인·재접속·자정만으로 연구 완료/보상을 생성하지 않는다. 정확 연구 시간과 저장/재개 규칙은 미정이다.

## 10. 후속 노드 명세와 검증 후보

승인 후 각 노드는 연구 질문·플레이어 변화·부모/대체 선행 조건·도입 자원·행위 근거·산출 기능/방침·중단/회복·적용 범위·관련 기존 WI/모듈·준비 증거를 결속해야 한다. 기존 주문·재고·시간·행위/성장 원장을 또 만들지 않으며 연구 상태의 소유/저장만 필요한 범위에서 별도로 설계한다.

첫 검토는 다섯 시작 카드와 각 분야의 첫 연구 하나를 연결해, 다른 분야를 끝내지 않아도 시작/심화가 가능하고 연결 연구가 선택 사항으로 읽히는지 보는 안이다. 실제 구현은 승인·준비가 맞는 한 분야의 작은 연구 폐루프부터 정하며 다섯 분야를 한 WI/Goal로 묶지 않는다.

- 다섯 출발 각각에 해당 분야 내부의 첫 작업/결과가 있고 타 분야 소유/완료가 강제되지 않는가.
- 필수 정보/안전 규칙을 잠그지 않으며 도구 접근·도입·실제 업무 결과가 구별되는가.
- 같은 과제/자원/행위의 재처리가 중복 연구비·시작 지원·성장·보상을 만들지 않는가.
- 서로 다른 연구·영업·도입이 같은 가용 자금/담당·설비를 이중 배정하지 않고 연구비와 도입비를 구분하는가.
- 연결 선행 조건이 순환해 새 분야에 영원히 진입할 수 없는 상태가 없는가.
- 중단·자원 부족·부재중·판본 변경·기존 세이브에서 비용/진척의 권위가 보존되는가.
- 광고 입문/전국 확장·중개 소개 순서와 지도 보기/경영권·실제 자료가 분리되는가.

## 11. 확정 / 제안·미정 / 다음 질문 하나

- **확정 방향:** 다섯 분야 중 자유 출발, 연구를 통한 분야 전문화, 선택적 타 분야 확장을 포함한다. 광고 시작을 막는 전국 선행 제한은 위 범위에서 부분 대체한다.
- **제안·미정:** 시작 지원/첫 작업·구체 연구 노드/AND·OR 조건·비용/기간·대체 학습·전환/환불·지도별 범위·개인 성장 결속·정확 UI/저장/구현 명세. 모든 후보 노드의 수치/효과를 이번에 승인한 것은 아니다.
- **다음 질문 하나:** 연구의 기본 대가를 게임 자본과 유효 운영 기록의 조합으로 둘까? 다른 분야 입문에는 안내형 과제로 근거를 보완할 수 있게 하는 안을 함께 추천한다.

문서 전용 결과다. 노드 구현·실제 게임 입력·연구 진행/저장·분야별 완주·AI 학습·자료 수집을 이번에 검증하지 않았다.
