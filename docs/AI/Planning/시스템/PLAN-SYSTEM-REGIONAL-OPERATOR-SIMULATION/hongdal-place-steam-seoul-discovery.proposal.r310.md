## 첫 체험안

1. **사가정 주변을 검색한다.** 기존 세 화면의 역할 선택과 로딩을 거쳐 지도에 들어간다. 홍달 플레이스에서 ‘사가정역 카페’처럼 역과 업종을 고르면 지도와 매장 목록이 함께 바뀐다. 핀이나 목록에서 가게 카드를 열면 같은 장소가 강조된다. 홍달의 지도·카드 디자인을 사용한다. [역할 선택·로딩·지도 r309](role-perspective-research-and-relaxed-observation.design.r242.md) · [역과 음식 검색 r193](station-keywords-and-in-game-place-pages.proposal.r193.md)
2. **게임 속 가게 한 곳을 알린다.** 가상 카페의 광고에 쓸 게임 예산과 시간대를 정한다. 점심 노출을 늘릴지, 제조 여유가 있는 오후에 노출할지 선택한다. 하루 마감에서 게임 예산 지출, 모의 노출, 주문 의향을 비교한다. 주문 흐름이 연결된 뒤에는 같은 의뢰에서 가상 주문과 처리 결과도 본다. [배너 납품과 가상 실험 r307](traffic-broker-person-card-and-temporary-ranking.design.r239.md)
3. **동네를 더 둘러본다.** 실제 매장 소개가 준비되면 권리를 확인한 카드에서 업종·동네·공개 정보와 기준일을 읽는다. 참여 점포는 허락받은 사진·메뉴 소개나 공식 링크를 제공할 수 있다. 카드를 보는 동안 게임 수치와 순위에는 변화가 없다.

| 화면 표시 | 자료·판정 기준 |
| --- | --- |
| **동네 매장** | 공개 가능한 실제 정보를 사용한다. 지역·업종 적합도와 사용자가 고른 거리 기준으로 검색한다. 영업 신고 상태와 조회 기준일을 확인하고, 실제 영업시간·가격이 미확인일 때는 해당 칸을 비워 둔다. 참여 점포 소개는 점주 제공 자료임을 표시한다. |

## Steam 광고 기준과 첫 검증

Steamworks는 게임의 유료 광고 기반 수익 모델과 실제 광고 참여 보상·진입 제한을 지원하지 않는다. 게임 맥락에 어울리고 진행을 방해하지 않는 실물 브랜드 노출은 필요한 권리를 갖춘 경우 지원 범주에 있다고 안내한다. 첫 안은 가상 광고 운영을 게임 규칙에 넣고, 실제 매장은 선택적으로 둘러보는 소개 콘텐츠로 둔다. 유료 노출이나 후원이 생길 경우에는 구체 조건을 놓고 검토한다. [Steam 광고 정책](https://partner.steamgames.com/doc/marketing/advertising) · [Steam 등록 기준](https://partner.steamgames.com/doc/gettingstarted/onboarding)

첫 검증은 **한 역 검색 → 가상 카페 한 곳의 광고 결정 → 하루 마감 → 같은 지도 복귀**다. 둘러보기·실제 매장 링크는 가상 예산·순위·보상을 바꾸지 않고, 캠페인 확정과 결산은 같은 게임 의뢰의 결과를 한 번 남기는지 확인한다. 공개판 대상 파일의 출처·기준일·배포 범위를 개발 검증과 함께 확인한다.

**확정** · Steam을 목표로 서울 자료를 활용하는 홍달 플레이스를 만들고, 지역 매장을 알리는 경험을 게임에 담는다.

**미정** · 첫 공개판 실제 매장 소개 범위, 참여 매장 확보와 콘텐츠 이용 범위, 게임 내부 홍보 결과의 구체 지표.
