## 2. 확정 방향 — 무엇을 했는가보다 깨어서 했는가

명덕은 특정 업종의 성공 보상이 아니라 **깨어 있는 상태로 활동하면서 쌓는 게임 내 성장량**으로 잡는다. 배달·카페·창고·광고·전자상거래·무역 등 어느 분야에서 시작해도 같은 원리를 쓴다. 성공·매출·정산·작업 완료만을 필수 조건으로 붙이지 않는다.

- 배달의 이동/픽업/전달, 카페의 준비/제조, 창고의 입고/피킹/포장뿐 아니라 점검·훈련·관찰·계획/조회 등도 깨어서 수행하는 활동으로 다룰 수 있다. 특정 업무의 성공한 마지막 단계만 명덕을 주는 구조로 좁히지 않는다.
- 활동이 실패하거나 원하는 업무 결과를 얻지 못해도 **깨어서 활동한 사실**과 **업무 성공/실패**는 따로 읽는다. 실패를 성공 매출/인계로 바꾸지 않으며, 실패했다는 이유로 이미 성립한 명덕을 없애지 않는다.
- ‘모든 활동’의 원칙을 채택하되, 가만히 있는 시간·휴식·대기·화면을 떠난 동안을 어떤 활동 상태로 볼지는 후속 판정 대상이다. 읽기/관찰을 새 기획에서 무조건 제외하지 않는다.
- 같은 활동 기록/시간 구간을 화면 재열람·재전송·저장 복원으로 두 번 더하지 않는다. **같은 기록 중복 방지**는 실제 반복 활동의 성장 제한이 아니다.

기존 r204의 ‘보고 열람은 기여가 아니다’, ‘실제 업무 진척이 있어야 한다’는 일괄 제한은 새 방향의 명덕 조건으로 승계하지 않는다. UI 클릭 자체의 별도 고정 보너스나 클릭 횟수만의 산식도 이번에 확정한 것은 아니다. 기획의 중심은 그 활동에서 깨어 있는 상태가 유지됐는지다.

## 3. 정신 차림 — 주기적으로 돌아오는 플레이어 행동

**정신 차림 발동 → 현재 깨어 있음 유지 → 활동하며 명덕 축적 → 다시 차릴 때가 옴 → 재발동**을 반복하는 방향이다. 미니게임을 직접 수행할 때도, 운영을 관찰할 때도 현재 상태와 다음 차림의 필요를 알아차리게 한다.

플레이어에게 스킬이 있다는 것과 그 효과가 누구에게 적용되는지는 구분한다. 대상이 플레이어 자신의 현재 역할인지, 선택한 기사/작업자인지, 점포/동의 여러 인물인지는 미정이다. **선택한 한 대상부터 명시하는 방식**을 첫 검토안으로 권하되 이번에 범위를 확정하지 않는다.

| 항목 | 현재 방향/제안 | 아직 정하지 않은 것 |
| --- | --- | --- |
| 스킬 이름/행동 | 플레이어가 ‘정신 차림’을 주기적으로 발동 | 버튼 위치·단축키·대상 선택/범위 |
| 목적 | 깨어 있음을 유지하기 쉽게 하고 그 상태의 활동이 명덕으로 이어짐 | 경 상태 유지·현재 시간 연장/보충·소진 뒤 회복 중 어떤 효과인가 |
| 주기 | 발동 한 번으로 영구 유지하지 않고 다시 차리는 행동이 있음 | 지속시간·재사용 대기·미리 알림·비용·게임 시간/현실 시간 기준 |
| 명덕 증가 | 제안: 스킬 자체의 대량 경험치보다 깨어서 하는 활동에 연결 | 발동 자체의 활동 기여·증가율/단위·활동별 가중치 |
| 성장 | 기존 경 유지 능력·명덕·빛의 크기를 구분해 읽음 | 스킬 숙련/연구가 유지시간이나 재사용 주기에 미치는 영향 |

현재 ‘하루 한 번 점검’ 제한을 새 스킬에 그대로 적용하지 않는다. 반대로 반복 발동이 기존 일일 경 용량/소진·휴식 규칙을 무제한 초기화한다고 결정하지도 않는다. **정신 차림의 효과와 기존 경 용량/일말 성장의 관계**를 후속 승인 기획에서 명시한 뒤 구현해야 한다. `check`의 기존 의미/저장 값을 조용히 바꾸지 않는다.

## 4. 명덕과 빛으로 이어지는 판독

화면에서는 **현재 깨어 있음 / 정신 차림 사용 가능·다음 필요 / 누적 명덕 / 빛의 기준 크기**를 구별하는 안을 제안한다. 깨어서 활동하는 동안 명덕이 쌓이고 누적에 따라 빛이 더 커진다는 r205 방향을 유지한다. 잠깐 상태가 흐트러지거나 쉬어도 누적 명덕과 성립한 성장이 사라지지는 않는다.

집계 단위는 우선 **깨어 있는 활동 구간**을 기록하는 안을 추천한다. 활동 시간에 비례할지 동작마다 더할지, 동시 활동을 어떻게 한 구간으로 읽을지는 미정이다. 시간 방식으로 정하면 같은 대상의 겹친 구간을 여러 작업/창에서 중복 계산하지 않는다. 아직 증가율·스킬 효과 시간·빛 크기 곡선에 숫자를 넣지 않는다.

현재 경 상태의 권위와 활동 기록에 근거해 누적한다. 맥동이 움직이는 프레임·켜진 화면·미니게임 조작 여부만으로 상태/명덕을 확정하지 않는다. 게임 정지/배속/메뉴 전환과 스킬 지속/재사용 시간의 관계는 r174/r187의 공통 시간 계약에 결속하며 정확한 기준은 후속 확정한다.

## 5. 집중·관찰/위임과 귀환 — 제안/미정

명덕의 기본 원리는 집중 미니게임과 관찰/위임에서 동일하게 읽는 방향이다. NPC의 깨어 있는 활동과 플레이어의 직접 조작 추가 보너스는 구분한다. 정신 차림 버튼을 누르는 것이 활동을 강제로 완료하거나 명령/정산을 확정하지는 않는다.

관찰 중 플레이어가 언제 개입할지, NPC가 스스로 차릴 수 있는지, 유지 업무를 위임할 수 있는지는 미정이다. 주기적 발동이라는 새 방향을 관찰 모드 폐지나 모든 NPC에게 개별 타이머 클릭을 강제하는 승인으로 확대하지 않는다. 데이터만 보는 사용자의 경영/성장 참여 범위도 별도다.

상태를 놓쳤을 때 안내/기여 중단·재차림 뒤 재개 등은 후속 회복안으로 검토한다. 놓친 활동의 소급 가산, 기존 명덕 감점, 업무 강제 중단, 소진한 날 재발동 허용을 이번 문서에서 결정하지 않는다. 활동/스킬을 본 뒤 같은 대상·동의 운영 화면으로 돌아올 수 있게 하며 동 승급 판정은 r204의 단일 권위 통합 미정을 유지한다.
