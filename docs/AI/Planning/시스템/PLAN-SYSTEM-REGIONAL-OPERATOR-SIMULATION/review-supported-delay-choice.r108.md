## 지금·여기·나·너·이렇게

- **지금:** 주문 집중으로 조리가 늦어져 주문자에게 기다리기와 취소 요청 선택이 열렸다.
- **여기:** 주문자의 진행 주문 예외 카드와 취소 요청 확인 화면이다.
- **나:** 주문자는 더 기다릴 가치가 있는지 판단하고 싶지만 취소 권리와 환불 조건도 정확히 알아야 한다.
- **너:** 음식점은 많은 주문을 순서대로 준비하고 있고, 해당 메뉴에는 이전 주문자가 자발적으로 공개한 후기가 쌓여 있을 수 있다.
- **이렇게:** 기다리기 선택을 검토할 때 현재 메뉴와 관련된 검증 가능한 공개 후기를 함께 볼 수 있게 하되, 취소 버튼·환불 조건·예상 지연을 가리거나 약화하지 않는다.
- **결과:** 주문자는 다른 사람의 실제 경험을 참고해 기다릴지 취소를 요청할지 스스로 결정한다.
- **다음 선택:** 기다리기를 선택해도 지연 상태가 더 나빠지면 취소 요청과 고객센터 진입을 다시 열어 둔다.

## 확정

- 좋은 후기는 주문자의 불편한 감정을 억누르거나 취소를 막는 수단이 아니라, 기다릴지 판단할 때 참고하는 선택 정보로 사용한다.
- 후기 영역을 보여 주더라도 `기다리기`와 `취소 요청`은 같은 수준에서 식별 가능해야 한다. 취소 버튼을 숨기거나 단계·색·문구로 불리하게 만들지 않는다.
- 예상 지연, 현재 조리 상태와 환불·비용 조건을 후기보다 먼저 또는 같은 화면에서 명확히 보여 준다.
- 현재 주문한 메뉴와 직접 연결되고 공개 동의·노출 정책을 통과한 후기만 후보로 사용한다. 다른 메뉴나 음식점 전체 후기를 해당 메뉴의 근거처럼 섞지 않는다.
- 별점이 높은 후기만 임의로 골라 취소 시점에 노출하지 않는다. 노출 기준은 최신성·메뉴 관련성 등 사전에 공개된 중립 규칙을 사용하고 낮은 평가를 의도적으로 배제하지 않는다.
- 후기 작성자의 개인정보, 주문 상세, 배달 기사 정보는 노출하지 않는다.
- 후기 조회 실패나 관련 후기 부재는 기다리기·취소 요청의 가능 여부에 영향을 주지 않는다.
- 운영자나 음식점이 특정 주문자의 취소 화면에 직접 후기를 골라 넣지 않는다.

## 화면 원칙

```text
현재 상황과 예상 지연
  → 기다리기 / 취소 요청
  → 이 메뉴를 기다려 받은 사람들의 공개 후기 보기
  → 환불·비용 조건과 고객센터
```

후기는 기본 선택을 강요하는 전면 방해창보다 주문자가 펼쳐 보는 보조 카드로 시작한다.

## 미정

- 후기 카드의 기본 상태를 접힘으로 둘지 한 건만 미리 보여 줄지
- 메뉴 직접 후기 수가 부족할 때 음식점 전체 후기로 넓힐지
- 긍정·중립·부정 후기를 어떤 중립 규칙으로 표본화할지
- 취소 요청 이후에도 후기를 계속 보여 줄지

## 다음 질문 하나

지연 선택 화면에서 후기 카드를 처음에 어떻게 보여 주는 것이 좋을까?

1. `후기 보기`로 접어 두고 주문자가 원할 때 펼친다 — 추천. 선택권을 보존하고 취소를 심리적으로 방해하지 않는다.
2. 메뉴 관련 후기 한 건을 기본으로 보여 주고 나머지는 펼친다 — 따뜻한 분위기는 잘 드러나지만 취소를 만류하는 장치처럼 느껴질 수 있다.
3. 기다리기를 누른 뒤에만 후기를 보여 준다 — 취소 판단에는 영향을 덜 주지만 기다릴지 정할 때 참고할 수 없다.
