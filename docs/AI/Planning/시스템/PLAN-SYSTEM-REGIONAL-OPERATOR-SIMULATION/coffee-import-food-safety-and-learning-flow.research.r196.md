## 1. 먼저 구분할 등록과 담당

지금은 가상 카페가 쓸 원두를 준비하는 시점이다. 나는 점주 또는 직접 수입을 맡는 가상 사업자다. 해외 공급처와 제품 형태를 선택하고, 누가 어떤 등록/신고를 맡는지 확인한다. 준비된 국내 원두를 사는 선택과 직접 수입을 진행하는 선택의 시간·비용·책임을 비교한다.

| 구분 | 대상/담당 | 서로 대신하지 않는 것 |
| --- | --- | --- |
| 일반 사업자등록·점포 개업 | 해당 국내 사업/점포 | 수입식품 영업등록이나 해외시설 등록을 자동 완료하지 않음 |
| 수입식품등 수입·판매업 영업등록/교육 | 수입·판매 영업을 하는 국내 주체의 준비 | 카페 영업만으로 수입자 준비를 충족한 것으로 보지 않음 |
| 해외제조업소 등록 | 수입자 또는 해외시설 설치·운영자가 해당 해외시설을 등록 신청 | 해외 판매상과 계약한 사실, 산지 이름, 국내 점포 등록과 구별 |
| 화물별 식품 수입신고·검사 | 해당 수입 건과 제품/시설/서류 | 시설 등록만으로 모든 화물이 검사 적합이 되지 않음 |
| 식물검역 | 대상 품목/가공도·원산/경유국 등에 따른 별도 요건 | 식약처의 식품 안전검사와 다른 판정 |
| 세관 수입신고·심사·수리 | 화주/관세사 등의 신고와 세관 판단 | 항만 도착·식품검사 적합·창고 입고와 각각 구별 |

일반적인 국내 수입·판매 영업의 시설/영업등록·사전 위생교육은 [식약처 공식 FAQ](https://impfood.mfds.go.kr/CFEDD01F01)가 설명한다. 제조용 원료 등 다른 영업자 유형의 예외까지 모든 점주에게 같은 허가 묶음으로 요구하지 않는다. 이번 첫 범위는 상업용 무첨가 커피의 직접 수입을 검토하는 구조이며 개인 해외직구·여행자 반입·OEM·유기 표시·혼합제품은 별도 조건이다.

## 2. 해외제조업소 등록 조사 결과

확인한 법 본문은 **2026-10-08 시행, 법률 제21525호**다. 제5조는 수입자 또는 해외시설 설치·운영자의 수입신고 전 등록 신청, 등록일로부터 2년의 유효기간과 연장 구조를 규정한다. 다른 화면에 병기된 2027-03-16 시행 예정 조문을 현재 규칙으로 섞지 않는다. [날짜 고정 법 본문](https://www.law.go.kr/LSW/lsInfoR.do?ancYnChk=0&chrClsCd=010202&efYd=20261008&lsiSeq=285337)

공식 상세 안내도 수입신고 전 해외제조업소 등록을 안내하며, 실제 제조시설인지 수출/판매업소인지 구별하도록 한다. 명칭·소재지·생산 품목과 시설을 확인할 근거가 필요하다. [해외제조업소 상세 안내](https://impfood.mfds.go.kr/CFAAA01F01/%3FcvaaClsNo%3D1471000999101)

특히 **농산물은 최종 포장장소**를 등록하고 그 형태를 농장·농장혼합시설·집하장으로 구분한다는 공식 FAQ를 확인했다. 따라서 생두의 판매상·재배 산지·최종 포장시설을 한 대상으로 합치지 않는다. 볶은 제품도 실제 제조/최종 공정 시설과 수출상을 구별한다. [식약처 FAQ](https://impfood.mfds.go.kr/CFEDD01F01)

등록 유효기간 연장은 신규등록 시점과 다르다. **2026-09-30 시행, 총리령 제2158호** 시행규칙 제2조제4항은 만료 7일 전까지 연장 신청을 정한다. 오래된 자료의 ‘신규등록을 수입신고 7일 전’이라는 문구를 현행 공통 마감으로 재사용하지 않는다. [시행규칙 제2조](https://law.go.kr/LSW/lumLsLinkPop.do?chrClsCd=010202&lspttninfSeq=126970)

게임은 이미 유효한 시설인지 먼저 확인하고 필요한 경우 등록·변경·유효기간 연장을 구분하는 안이다. 모든 발주마다 새 시설을 등록하거나 연구 점수로 유효기간을 자동 연장하지 않는다. 유효기간이 있는 시설 등록과 개별 화물의 신고는 다른 기록으로 유지한다.

## 3. 생두·볶은 원두와 검역 조건

| 제품 프로필 | 식품 절차의 확인 초점 | 식물검역의 확인 상태 |
| --- | --- | --- |
| 생두 | 농산물 분류·최종 포장장소·품목/수량·수입신고 및 해당 검사 | 검역 대상/수입허용·증명서·원산/경유국 조건을 별도 확인 |
| 볶은 원두 | 제조/가공·포장시설·원재료/표시·식품 유형과 해당 검사 | 가공품 해당 여부와 관련 조건을 확인. 이름만 보고 일괄 면제하지 않음 |
| 추출·혼합·디카페인 등 추가 형태 | 성분/공정별 별도 분류·요건 | 위 두 프로필의 결과를 자동 복사하지 않음 |

검역본부의 [커피 원두 현장 자료](https://ebook.qia.go.kr/src/viewer/main.php?host=main&site=20260309_104647)는 컨테이너/마대/원두의 해충 확인 업무를 보여 준다. 다만 제2023-06호·2018~2022년 관측을 담은 참고 자료여서 현행 국가별 허용표나 볶은 원두 면제표로 쓰지 않는다.

가공품 기준은 2026-08-21 시행 **「가공품 해당여부 적용기준」 제2026-35호**가 확인 대상이다. [현행 고시 연결](https://law.go.kr/LSW/admRulLsInfoP.do?admRulId=2061166&efYd=0)과 [위임규칙 연결](https://www.law.go.kr/conAdmrulByLsPop.do?lsiSeq=283219)을 조사했지만, 이번에는 커피별 세부 적용표를 완전히 열람하지 못했다. **특정 국가의 수입 가능 여부·증명서/부기·볶은 커피의 가공품 판정을 미확정**으로 남긴다. 자료가 없다는 이유로 검역을 ‘해당 없음’으로 처리하지 않는다.

## 4. 화물 절차 — 분기하고 필요한 관문에서 합류한다

학습용 큰 흐름은 **제품/국가·공급처 확인 → 수입자/해외시설 준비 → 서류·운송 준비 → 식품 신고/해당 검사·필요 검역·세관 심사 → 반출 가능 → 국내 입고/검수 → 필요한 로스팅/납품**이다. 이는 전체 개념을 읽는 흐름이며 모든 신청이 그 순서대로만 시작된다는 법정 처리 순서가 아니다.

식품 검사에는 서류·현장·정밀·무작위표본검사 등 대상별 경로가 있다. 모든 화물이 네 검사를 순서대로 전부 마치도록 만들지 않는다. 적합 판정/수입신고확인증, 부적합에 따른 수출국 반송·제3국 반출·폐기 등의 분기도 구별한다. [식약처 수입검사 절차](https://www.foodsafetykorea.go.kr/portal/board/boardDetail.do?bbs_no=bbs031&ctgType=CTG_TYPE01&ctgryno=1138&menu_grp=MENU_NEW01&menu_no=4457)

관세청 안내는 품목분류·관련 요건 확인, 신고/심사·수리와 반출을 구별하고 도착 전 신고도 설명한다. 송품장·포장명세서·운송서류, 원산지/요건 증빙 등은 준비하되 실제 요구/적용 조건을 구분한다. 모든 화물에 같은 서류를 전부 의무 제출하는 게임 규칙으로 단순화하지 않는다. [관세청 수입통관 안내](https://customs.go.kr/kcs/cm/cntnts/cntntsView.do?cntntsId=817&mi=2819)

게임에서도 다음 세 상태를 따로 읽고 **필요한 요건과 세관 처리가 충족되는 반출 관문**에서 합류시키는 안이다.

- 식품: 미신고 / 접수·확인 / 해당 검사 중 / 적합·보완·부적합.
- 식물검역: 적용 확인 필요 / 적용 요건 준비 / 검사·결과 확인 / 근거가 있는 비대상 판정.
- 통관: 신고 준비 / 신고·심사 / 보완·보류 / 수리·반출 조건 확인.

정확 선후·병행 가능 조건은 제품/국가별 프로필로 결속한다. 식품검사와 검역을 끝내기 전에는 세관 신고 준비조차 못 한다고 고정하거나, 세관 수리만 보이면 모든 요건이 충족됐다고 임의 판단하지 않는다. 수리 전 반출·조건부 신고확인증 등의 예외 제도는 첫 학습 범위에서 상세 재현하지 않는다.

국내에 도착해도 보세 보관·검사 대기·반출 가능·운송·창고 입고/검수·가용 재고는 각각 다르다. 생두를 수입했다면 선택한 국내 공급 프로필에 따라 로스팅/포장이 더 필요할 수 있고, 볶은 원두를 샀다면 생두 로스팅 단계를 다시 강제하지 않는다. 국내 제조·영업의 별도 요건 전부를 이번에 확정한 것은 아니다.

## 5. 게임에서 자연스럽게 배우는 방법

카페의 `원두 준비` 원형 노드를 누르면 먼저 **국내 조달 / 직접 수입**을 선택하는 안이다.

| 선택 | 플레이어가 하는 일 | 학습 방식 |
| --- | --- | --- |
| 국내 조달 | 준비된 가상 로스터/도매 공급처의 품목·납기·조건을 보고 구매/인수를 판단 | `[원두가 온 과정]`에서 수입자·시설·입고 이력을 살펴봄. 점주에게 해외 등록 업무를 강제하지 않음 |
| 직접 수입 | 수입을 맡는 주체와 제품/국가·시설·서류·화물 진행을 관리 | 처음에는 현재 단계의 목적·담당·필요 정보·다음 관문을 한 장씩 안내 |
| 관찰/위임 | 준비된 가상 담당자가 진행하는 상태와 보완 요청을 확인 | 서류 준비와 정부기관 판정을 구별하면서 같은 진행 결과를 관찰 |

각 절차 카드는 **‘왜 필요한가 / 누가 하는가 / 지금 확인할 정보 / 완료 근거 / 다음 선택’**을 짧게 보여 준다. 처음부터 법령 목록을 시험처럼 풀게 하지 않는다. 등록된 시설 재사용, 서류 보완, 기다리는 동안 다른 매장 업무 보기 같은 선택으로 이해를 쌓는다.

첫 학습 예시는 해외 거래처가 보낸 자료에서 **판매회사와 최종 포장/제조시설을 구분하는 일**을 제안한다. 이미 유효한 시설을 확인하거나 실제 시설 정보를 요청하고, 필요한 등록 준비를 마친 뒤 같은 수입 계획으로 돌아온다. 이는 가상 상황 예시이며 실제 시설을 확인한 결과가 아니다.

등록 미완료/서류 불일치는 이유와 수정 대상을 읽고 보완할 수 있게 한다. 검사 부적합은 사용 가능한 재고로 바꾸지 않고 해당 화물의 보류/반송 등 결과를 따르며, 기존 국내 재고·다른 가상 공급처로 운영을 회복할 수 있게 한다. 법적 벌금·과태료·처리기간·검사 확률을 임의의 확정 수치로 넣지 않는다.

반복 수입에서는 확인한 등록/서류를 재사용하되 만료·시설 변경·제품/국가 조건의 차이를 검토한다. 연구/직원 숙련은 준비·누락 발견·계획 판단을 돕는 방향이며 정부의 등록/검사를 면제하거나 합격을 보장하지 않는다.

## 6. 지도·홍달 플레이스·현실 날짜와의 연결

직접 수입 노드는 r190의 전국 지도와 상대국 관계 패널, 확인된 화물/보관 시설을 연결한다. 농장·판매상·최종 포장/제조시설·선적/도착 거점·국내 창고를 구별한다. 수입 통계의 국가명이나 등록창고 목록을 잇는 것만으로 실제 공급망·거래·항로를 만들지 않는다. 좌표/관계가 미확인이면 현재 지도를 유지하고 자료/가상 후보를 표시한다.

흐릿한 운송 곡선/핀 등은 선택형 표현으로 기존 r184/r189를 따른다. 선박 도착 애니메이션이 식품검사·통관 수리·원두 입고를 완료시키지 않는다. 노드에서 점포로 돌아오면 선택 매장·원두 계획·지도 문맥을 유지한다.

홍달 플레이스의 사업자등록 연계는 고객용 장소 페이지 생성이다. 그 상태가 수입 영업등록·해외제조업소 등록·수입식품 신고를 대신하지 않는다. 가상 원두 이력을 메뉴 설명에 보이려면 해당 매장/원두와 확인된 게임 공급 이력이 연결돼야 한다. 특정 국가 수입 통계를 매장 원산지 표시로 자동 적용하지 않는다.

r174/r187의 현실 KST 날짜·일일 결산·같은 날 반복하는 운영 회차를 유지한다. `다음 회차`를 눌러 해외시설의 2년 유효기간을 소모하거나 법정 민원 일수를 강제로 넘기지 않는다. 게임의 작업/대기 시간과 공식 처리기한은 별도 필드/설명으로 둔다. 부재중 임의 영업·검사 합격·벌금·입고를 생성하지 않는다. 견적·예상 비용과 실제 게임 원장 비용/현금 이동도 구별한다.

## 7. 자료 범위·개발 준비와 검증 후보

[r190의 수집 기록](../../../DataCollection/Research/2026-11-14-cafe-opening-supply-chain-intake.md)의 통계9행·기존 자료와 등록 안내는 그대로 유지했다. 이번은 절차 조사이며 실제 해외시설/공급 계약·항만·선박·국가별 식물검역 조건을 새로 수집/DB 반입하지 않았다. 식약처/관세청 공개 안내를 확인했고 법령은 점검 페이지가 간헐적으로 나와, 직접 확인한 본문과 공식 검색 추출·미열람을 구분한다.

첫 구현 준비 후보는 **기존 카페 원두 준비에서 수입 담당/해외시설을 읽고 필요한 확인을 한 뒤 같은 계획으로 귀환하는 작은 절편**이다. 전체 해외 운송·센터·매장 통합을 첫 구현으로 강제하지 않는다. 원산국/제품 선정과 해당 검역/표시·HSK/세율·증빙의 추가 검토, 상태 계약·시안·작업 명세·개발 수용은 별도다.

검증 후보는 국내 구매 점주와 직접 수입자의 책임 분리, 유효 시설 재사용과 중복 등록 방지, 판매상/제조·포장시설 구분, 생두/볶음 및 검사 경로 분기, 보완/부적합 회복, 반출과 입고/가용 재고 분리, 지도/페이지 조회의 상태 불변·같은 계획 귀환이다. 미확인 조건은 `확인 필요`로 남기며 자동 적합 처리하지 않는다.

## 8. 확정 / 미정 / 다음 질문 하나

- **확정 방향:** 해외제조업소 등록을 포함한 원두 수입 절차를 조사하고 게임 흐름에서 자연스럽게 학습하도록 준비한다. 국내 조달과 직접 수입의 선택을 유지한다.
