## 확정

배달 플랫폼 운영 게임에서 산수몽은 수뢰둔의 결핍 상태에서 출발한 운영자가 실제 업무를 겪으며 배우고, 다른 역할의 처지를 이해하며, 작은 사람·물자·돈·정보를 모아 최소한의 안정을 갖추는 캠페인으로 해석한다.

- `배움`: 주문·조리·배차·이동·전달·정산·예외를 실제 Simulation에서 관찰하고 결과를 기록한다.
- `역지사지`: 운영자 관점만 고집하지 않고 주문자·음식점·기사·지원 담당자가 같은 사건을 어떻게 겪는지 비교한다.
- `물자 축적`: 필요한 장비·거점·픽업 기준점·지원 도구를 한꺼번에 주지 않고, 필요와 근거가 확인된 것부터 마련한다.
- `사람 축적`: 역할을 억지로 충원하지 않고 신뢰·가용성·권한을 확인한 사람부터 운영 관계에 연결한다.
- `돈 축적`: 수익만 최대화하지 않고 지급의무·준비금·고정비·정책비를 이해하며 최소 현금 방어선을 조금씩 넓힌다.
- `안정`: 모든 결손 제거가 아니라 정상 업무는 자동화하고 예외는 드러내며, 다음 실수를 학습할 수 있는 상태를 만든다.

산수몽에서 조언자나 도움말은 정답을 대신 선택하지 않는다. 운영자가 먼저 질문하고, 사건 기록과 역할별 결과를 본 뒤, Preview와 실제 결과를 비교해 자기 운영 원칙을 형성한다.

## 수뢰둔에서 산수몽으로의 흐름

```text
수뢰둔
뜻은 움직였으나 사람·물자·돈·정보가 부족함
        ↓
산수몽
실제 운영을 겪으며 무엇을 모르는지 알고
다른 역할의 처지를 배우며 작은 기반을 갖춤
        ↓
다음 괘 후보
배운 질서를 유지하면서 필요한 자원을 기다리고 기르는 문제
```

산수몽은 수뢰둔의 부족함을 즉시 해결하는 보상 단계가 아니다. 잘못 이해한 원인, 무리한 정책, 역할 간 손해 전가를 발견하고 고치면서 기반을 만드는 학습 단계다.

## 3·4, 5·6의 짝에 대한 인지

전통 괘서에서는 수뢰둔 다음에 산수몽이 오는 이유를 `만물이 처음 생기면 아직 어리고 몽매하므로 몽이 따른다`고 설명한다. 수뢰둔과 산수몽은 괘상을 위아래로 뒤집은 관계이며, 수천수와 천수송도 같은 방식의 짝을 이룬다.

다만 이를 `모든 홀수 괘는 양, 모든 짝수 괘는 음`이라는 고정 사실로 사용하지 않는다.

- 괘 자체의 음양 구성과 괘 번호의 홀짝은 별개다.
- 전통 배열에는 뒤집은 괘 또는 음양을 바꾼 괘의 짝이 많지만, 각 괘의 의미는 괘상·괘사·전후 맥락을 함께 본다.
- 프로젝트에서는 홀수·짝수 캠페인의 대비를 **발동과 성찰, 확장과 정돈, 문제 제기와 학습** 같은 창작 리듬으로 사용할 수 있다.
- 이 리듬은 기획 보조 규칙이며 Simulation 수치·성공 판정·공간 생성 권위가 아니다.

## 디오라마 보완 방향

산수몽 캠페인에서 공간은 학습과 역지사지를 돕는 방향으로 누적한다.

- 같은 주문 사건을 음식점·기사·주문자·운영자 관점에서 따라가는 위치 결속
- 조리 대기, 픽업 접근, 골목 이동, 전달, 기사 복귀의 판독 지점
- 자료가 확인된 공간과 미확정 공간을 구분하는 품질 표시
- 선택 전 예상과 실제 결과를 비교하는 운영 카드·디오라마 강조
- 새로 확보한 장비·거점·관계가 어디에 쓰이는지 보여 주는 상태 표현

역지사지는 NPC 감정이나 귀책을 임의 추정하는 기능이 아니다. 같은 권위 사건이 각 역할에 준 시간·비용·대기·위험·허용 조작의 차이를 보여 주는 방식으로 시작한다.

## 미정

- 홀수·짝수 괘의 짝 리듬을 모든 64개 캠페인에 얼마나 엄격히 적용할지
- 산수몽에서 처음 비교할 두 역할과 대표 사건
- 수뢰둔에서 이월되는 정확한 현금·인원·물자 결손
- 산수몽 완료 때 확보할 최소 운영 기반
- 다음 수천수 캠페인으로 넘어가는 조건

## 다음 질문 하나

64개 운영 캠페인에 홀수·짝수 괘의 대비를 어떤 강도로 사용할까?

1. `유연한 짝 리듬` — 추천. 앞 괘는 문제와 움직임을 열고 뒤 괘는 다른 관점에서 배우고 정돈하는 경향을 두되, 각 괘 원문이 다르면 억지로 맞추지 않는다.
2. `엄격한 양·음 교대` — 모든 홀수는 발동·확장, 모든 짝수는 수렴·안정으로 고정한다. 구조는 선명하지만 원문 의미가 훼손될 수 있다.
3. `짝 리듬을 사용하지 않음` — 각 괘를 완전히 독립적으로 해석한다.
