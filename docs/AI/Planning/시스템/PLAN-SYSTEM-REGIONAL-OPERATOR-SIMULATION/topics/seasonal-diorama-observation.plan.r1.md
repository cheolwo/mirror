기본 관찰 보기는 한국표준시의 오늘 날짜를 읽는 방향을 따른다. 기존 자료 창의 「절기 비교」에서 다른 날짜를 고르면 상단에 날짜·절기와 `비교 중`이 보인다. 시장 아이콘을 누르면 같은 품목을 읽고, 「현재로」를 누르면 오늘 보기로 돌아간다. 두 보기 사이를 같은 카메라와 장소 선택으로 오간다. 세션의 주문·장부·저장에는 별도 명령을 보내지 않는 읽기 전용 전환이다.

사계절은 풍경의 색·빛·옷차림을 고른다. 24절기는 한국천문연구원의 연도별 시작일을 찾아, 지역과 날짜가 맞는 자료를 연결한다. 첫 조회는 KST 날짜 단위로 시작일을 포함하고 다음 절기 시작일 전까지 적용한다. 월 통계는 기준 월, 계절 분류 자료는 공표 계절을 적는다. 이후 쉼터에는 공표 계절과 해당 날짜 개방 확인을 구분한다. 비교 날짜·지역에 연결할 비·눈 기록이 부족하면 `관측 자료 없음`을 보인다. 가격을 바꾼 원인과 계절별 주민 수는 후속 자료 검토 항목이다.
