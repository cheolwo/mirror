## 제안 — 사가정의 간단한 한 턴에서 두 동 비교로

| 순서 | 보이고 할 수 있는 일 |
| --- | --- |
| **공통 조작 익히기** | 사가정역 지도에서 내 도시 면목제3·8동을 누르면 지금 진행되는 일과 다음 행동 한 가지가 카드에 나온다. 기존 방침대로 한 턴을 넘기거나 할 일을 하나 고른다. 결과에서 같은 도시를 다시 찾을 수 있다. |
| **지도에서 고를 이유 발견** | 이웃 면목7동을 누르면 자기 동과 이웃 AI의 관련 상태를 본다. 지도는 두 동의 위치와 연결을, 업무 카드는 남은 재고·공동 입고 제안·도착 예정·비용을 제공한다. 공공 관측은 출처와 범위를, 운영 값은 해당 시뮬레이션 턴을 기준으로 읽는다. |
| **같은 조작으로 방향 정하기** | 내 동에 먼저 입고시키면 재고 부족을 빨리 해소할 수 있고 자기 비용을 부담한다. 이웃과 함께 입고하면 운송비를 나눌 수 있고 물량을 맞추느라 기다릴 수 있다. 이번 턴 미루기를 고르면 기존 방침으로 진행하며 이웃 AI는 자기 조건에 따라 움직인다. |
| **결과로 다음 턴 고르기** | 내 동의 재고가 얼마나 남았는지, 각자 부담한 비용과 도착이 어떻게 달라졌는지를 관련 동 카드에서 본다. 입고가 밀렸으면 앞당길 수 있는 조건을 읽는다. 다음 턴에 같은 방식을 이어가거나 지도에서 다른 상대와 조건을 살핀다. |

세 화면을 오갈 때 사용하는 조작은 **지도에서 누르기 → 카드에서 보기·선택 → 같은 지도에 돌아오기**다. 자료판을 접고 현재 선택의 조건만 펼치는 안을 추천한다. 자료와 이웃 보기로는 상태를 조회하고, 행동으로 확정한 계획은 기존 턴 전·후 기준에 따라 반영한다. 지도에서 먼저 둘러보고 싶은 사람은 첫 턴부터 그렇게 할 수 있게 제안한다. [턴 계획과 관찰 기준](../next-todo-fire-to-center-observation.design.r245.md) · [같은 칸의 입장별 자료](stance-tile-data.plan.r1.md)

첫 검토에서는 같은 초기 상태에서 두 운영 선택을 각각 한 번 따라간다. 선택 전에 비용과 도착의 차이를 읽을 수 있는지, 턴 후에는 결과와 다음 가능한 일이 달라지는지 확인한다. 첫 턴을 맡기거나 지도를 먼저 둘러보는 경우에도 기존 방침과 선택 위치를 제대로 이어받는지를 본다.

## 미정과 다음 질문 하나

첫 비교의 진입 위치, 비용·시간의 수치, 실제 휴대폰 입력과 턴 결과는 검토 대상이다. r1의 카드에서 지도에 자료 고정 방식도 미정이다. Graph Map 영향 후보는 도시·지도 조회와 같은 운영 결정·결과의 연결이며, 이번 판에서 원본이나 구현 상태를 변경하지 않는다.
