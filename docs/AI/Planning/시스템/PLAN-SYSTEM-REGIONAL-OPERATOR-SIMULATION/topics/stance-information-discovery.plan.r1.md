## 한 차례의 플레이에서 정보를 만나는 흐름

1. **들어올 때** 지도 위치와 내 역할, 당장 할 일에 필요한 장소·조건·행동을 보여 준다. 현재 선택의 위험·비용·실패 가능성과 취소·복귀 수단도 선택 전에 읽을 수 있다.
2. **일을 고르면** 그 장소와 대상에 해당하는 자료를 옆 카드에 보여 준다. 지도의 강조는 현재 선택한 대상과 기존 화면의 범위를 따른다.
3. **결과가 생기면** 다음 선택에 도움이 되는 새 정보 한 장을 덧붙이는 것을 첫 시험의 기본으로 제안한다. 성공 뒤에는 결과의 근거를 비교하고, 지연·실패 뒤에는 확인 가능한 이유나 누락과 다시 시도할 방법을 본다. 자동으로 맡긴 일도 플레이어가 결과를 열면 이 흐름을 이용할 수 있다.
4. **다시 둘러보면** 지금 확인한 정보는 필요할 때 자료 창에서 다시 찾는 방식이 후보이다. 여러 차례 플레이해도 지도에 늘어나는 것은 사용자가 고정한 자료이며, 장면 카드와 강조는 닫거나 다른 곳으로 가면 접히게 하는 편을 권한다.

| 입장 | 먼저 보이는 정보 | 일을 하면 열리는 정보와 다음 선택 |
| --- | --- | --- |
| 배달 기사 | 수락한 주문의 픽업지, 진행 상태와 현재 접근에 필요한 정보 | 도착 기록에서 「기사 도착 · 픽업 전」을 읽는다. 인계 기록 뒤에는 이번 도착→픽업 경과시간을 확인하고 다음 주문에서 준비 안내를 먼저 볼지 판단한다. |
| 음식점 사장 | 내 가게와 지금 맡은 일 | 새 입점 후보를 비교할 때 그 타일의 시간대별 생활인구·역 이용 자료를 본다. 그 시간대를 겨냥할지 후보를 바꿀지 고른다. 타일 자료가 없으면 공표된 상위 지역의 범위를 밝힌다. |
| 동네 주민 | 선택한 목적지와 갈 수 있는 길 | 환승을 고르면 해당 역과 정류장의 시간표를 읽고, 쉬어 가기를 고르면 근처 계절 쉼터의 공표 운영시간을 본다. 공개된 월 누계와 현재 혼잡은 화면에 각각 기준을 표시한다. |
| 화물·창고 | 이번 화물 건의 거점, 인계 상대와 수량 | 출고나 인수 결과를 확인하면 해당 건의 적재·인계 기록을 펼친다. 공표된 주차장 규모나 조사 운임을 주변 정보로 보되 실시간 빈자리나 확정 운임은 해당 근거가 있을 때 표시한다. |

관찰 모드에서 자료를 열어 보는 것은 읽기다. 맡긴 일의 실행은 기존 방침을 따르고, 미리보기·열람·입장 전환으로 결산·보상·역할 권한을 만들지 않는다. 사건 기록과 자료의 공표 시점을 함께 보존한다. 재연에서는 해당 시점에 읽을 수 있었던 기록을 쓰고, 준비 여부·위치·자료가 미확인인 경우 확인 범위를 밝혀 준다. 자료가 있는지, 열람 가능한지, 지금 지도에 표시할지는 각각 따로 판정한다.

## 첫 검토 후보 · 사가정역 주문 한 건

- **지금·여기·나·너** · 사가정역 주변 가상 주문을 이미 수락한 기사와 음식을 건네는 가게. 먼저 해당 주문 하나에서 픽업에 필요한 정보를 읽는다. [사가정역 첫 주문](../hongdal-place-station-first-loop.design.r313.md)
- **이렇게** · 같은 세션과 주문 ID에서 `pickup_arrived`를 읽고 「기사 도착 · 픽업 전」을 표시한다. `food_picked_up`이 기록되면 두 사건 사이의 경과시간 한 장을 붙인다. 첫 검토는 기존 Core의 도착·인계 기록을 재사용한다. 준비 완료 시각이나 실제 픽업문은 근거를 얻은 뒤 붙인다. [기존 Core 재현과 한계](stance-card-perspective-data.plan.r2.md#이번-실행과-자료로-확인한-것)
- **대가·실패·회복** · 새로운 자료를 본 행위의 별도 비용은 없다. 인계가 아직 없으면 대기와 현재 가능한 선택을 표시한다. 양 끝 기록이 없거나 확인된 순서가 다르면 경과시간을 계산하지 않는다. 같은 기록을 다시 조회할 때 새 카드나 보상을 중복 생성하지 않는다.
- **결과·다음 선택·귀환** · 이번 픽업의 경과시간을 읽고 다음 주문에서 확인할 사항을 생각할 수 있다. 카드를 닫으면 같은 주문 선택과 지도 위치·확대로 돌아간다. 관찰로 전환하면 기존 자료 목록을 펼칠 수 있다.

첫 검토는 결과 전에 정보가 과하게 뜨지 않는지, 일에 필요한 정보는 제때 읽을 수 있는지, 결과 카드가 다음 판단을 돕는지 비교한다. 도착→인계와 인계 전 대기, 원 주문과 입장 변경·복귀, 같은 기록의 반복 열기, 관찰 전환을 확인한다. 세로 화면에서는 기존 아래 판, PC에서는 기존 선택 카드에 붙이는 후보다.

**확정** · 각 입장의 플레이에서는 행위와 상황에 따라 자료를 조금씩 드러낸다. 관찰에서는 입장 자료를 펼쳐 볼 수 있다.

**미정** · 새 자료의 기본 표시 위치와 지도 고정 동작, 확인한 자료를 이후 다시 찾는 범위, 역할별 첫 장면.

**다음 질문 하나** · 새로 알게 된 정보는 **지금 하는 일의 카드에 먼저 보여 주고, 원하는 것만 지도에 고정**하는 걸 기본으로 할까요? 쉽게 찾으려면 한 번 눌러야 하지만 여러 일을 해도 지도에 표식이 쌓이지 않습니다.

Graph Map 영향 후보는 기존 역할·장소·주문의 발견 카드 연결이다. 문답과 화면 검토 뒤 결속하며 현재 판본은 개발 인계 상태를 올리지 않는다.
