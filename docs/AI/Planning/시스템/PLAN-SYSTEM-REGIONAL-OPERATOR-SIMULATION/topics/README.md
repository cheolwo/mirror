# 홍달 플레이스 주제별 판본

2026-11-20 KST · 상위 기획 `PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION`

홍달 플레이스의 현행 기획은 주제마다 `r1`에서 시작한다. 이 판은 기존 결정과 미정 사항을 이어받는 기준선이다. 기획 본문과 근거는 각 줄에서 연결한 기존 정본을 읽는다.

주제에서 빠진 플레이 요소는 [게임 기획 점검표](game-design-checklist.md)로 보고, 해당 화면과 연결 상태는 [기획·화면 연결과 첫 주문 표본](planning-screen-tree.md)에서 찾는다.

[겨울 기획·개발 검토 r1](winter-planning-review.plan.r1.md)에서 지금까지의 실행 근거, 모을 자료, 단계별 결과와 사가정역 첫 검토 범위를 함께 읽는다.

## 새 판을 기록하는 규칙

1. **한 주제가 바뀌면 그 주제의 판만 올린다.** 다음 광고 개정은 `광고 r2`다. 같은 시점의 `이익 환류 r1`이나 `배달 운영 r1`은 그대로 읽는다. 두 주제에 실질적인 변경이 있으면 해당 두 주제를 각각 개정한다.
2. 대화의 제목, 현재 작업, 새 인계의 표시명에는 `주제명 rN`을 쓴다. 가령 `r320`을 찾던 사람은 `배달 요금·정산 r1`의 원문 열에서 같은 절을 연다. 새 주제가 생기면 범위와 연결할 정본을 정한 뒤 그 주제도 `r1`에서 시작한다.
3. 이 표는 **주제 안에서의 현행 판, 상태, 정본 링크**를 관리한다. 결정 본문은 한 곳에서 개정한다. 기존 파일명·절 주소·기획 ID·과거 판본은 호환 참조로 유지한다. 개발 인계는 `주제명 rN`과 함께 승인 원문의 경로·절·판본·해시를 명시한다. 주제별 판본 부여로 기존 승인과 구현 상태가 바뀌지는 않는다. [기획 문서 관리 기준](../../../../../Architecture/기획문서독립관리체계.md)
