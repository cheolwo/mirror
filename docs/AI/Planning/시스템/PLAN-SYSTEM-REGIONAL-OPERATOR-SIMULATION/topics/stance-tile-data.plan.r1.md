정밀도가 다른 자료는 칸 위 위치 표시, 칸의 면적·추정값, 지역 카드의 세 가지 입구로 읽는다. 공공 원본 시설의 이름, 자료 기준일과 위치의 근거를 함께 둔다. 동네를 옮기거나 입장을 전환해도 동일한 시설과 세부칸은 같은 식별자를 쓴다. 모칸에서 검증된 값과 세부칸에 추정 배분한 값은 각각의 표시를 갖는다.

## 정보가 나타나는 순서

1. 입장 전환에서 첫 질문에 답하는 두 층으로 시작한다. 먼저 명시적으로 골라 켠 층은 같은 입장을 다시 볼 때 복원할 수 있다.
2. 칸을 고르면 약식을 펼친다. 무엇을 잰 값인지, 어느 시점·표본에서 왔는지, 해당 칸에 직접 연결됐는지 보여 준다. 두 동에 걸친 칸이면 두 동의 지역 값을 각각 읽는다.
3. 업무를 여는 행동이 있을 때 관련 기록을 읽는다. 같은 배달 한 건에서 기사는 픽업 대기, 사장은 준비 상태를 본다. 같은 업무 ID를 유지하며 상대 관점으로 전환할 수 있는 흐름은 기존 기획의 검토 범위를 따른다.
4. 관찰 중인 사용자는 자료 창에서 선택적으로 열고 닫는다. 입장으로 선택한 자료가 업무의 승인·지급·실행 권한을 바꾸지 않는다.

공용 자연층은 지도를 이해하는 바탕으로 둘 수 있다. 관측이 가려졌거나 해당 자료의 지역·시점 범위를 벗어나면, 화면에는 `자료 확인 전`, `공개 집계에서 가림`, `이 구역은 해당 자료 범위 밖` 중 해당 사유를 쓴다. 실제 원본이 0을 제공하고 그 행이 검증된 경우에 0을 쓴다.

## D1 우선 적용 제안

**첫 장면은 사가정역 북동 세부칸에서 기사·사장·경영자를 전환하는 장면**이다. 기사에게 길과 횡단보도, 사장에게 사람 흐름과 음식점, 경영자에게 영업점 분포와 도로 관측을 보여 준다. 동일한 등록 음식점 수를 서로 다른 업무 실적으로 해석하지 않는다. 첫 화면의 지도·자료 조회·정밀도 확인을 우선 닫은 뒤, 주민의 도서관과 화물의 주차, 다른 활동을 넣는다.

검토는 사가정·홍대입구·여의도·용마산과 서울 밖에 걸친 빈칸을 포함한다. 상권·공시지가·승하차의 지역/시설 차이, 독립 출처의 기간, 가려진 관측, 동 경계에 걸친 칸의 두 지역 카드가 각각 잘 보이는지 확인한다. [조회 예시와 D1 검증표](../../../../Handoffs/2026-11-26-Codex-타일자료수집-반환.md)
