## 한 장면씩 기획하고 시안과 실행 결과를 확인한다

큰 방향과 아이디어는 기획 트리에 두고, 한 번의 검토에서는 **플레이어 한 명이 한 상황에서 내리는 판단 하나**를 고른다. 대표 장면은 기획 초안이 설명하는 행동과 결과를 화면에서 읽을 수 있을 때 그린다. 진행 중 떠오른 아이디어는 해당 주제에 적어 두고 다음 검토에 꺼낸다.

| 순서 | 하는 일 | 다음 단계로 이어지는 기록 |
| --- | --- | --- |
| **1. 기획 한 건** | 최신 실행 화면이나 반환을 확인한다. 누가 어디에서 무엇을 보고 결정하는지, 성공·실패 뒤 무엇이 달라지는지를 짧게 쓴다. | 기획 판본, 대표 상황, 바꿀 부분, 시안에서 확인할 질문 하나 |
| **2. 이미지 시안 한 장** | 기존 화면 스타일에서 대표 상태 한 장을 보여 준다. 가정한 값이나 구현과 다른 부분은 시안 설명에 적는다. 다음 상태는 이번 판단에 필요할 때 이어서 본다. | 기준 캡처, 시안 판본, 이미지, 이번 질문 |
| **3. 시안 검토와 기획 개정** | 시안 한 장을 보고 채택·수정·보류 의견을 받는다. 시간이 필요한 경우 같은 판본과 질문에서 이어 본다. 의견을 기획에 반영하고, 화면에서 달라진 부분이 있으면 그 장면의 수정 시안을 다시 보여 준다. | 사용자 의견, 반영한 기획 판본, 남은 질문과 재개 지점 |
| **4. 개발계획과 구현** | 확인한 범위로 재사용할 곳과 연결할 곳, 완료 조건을 적는다. 기존 인계에서 승인·담당·기준판을 확인한 뒤 그 작업을 구현한다. | 인계와 수용 범위, 확인할 게임 조작 한 건과 정상·회복 결과 |
| **5. 실행 결과 검토** | Unity에서 같은 장면을 실제 조작한 화면과 상태 변화를 시안·기획에 견준다. 시간이 중요한 기능은 예상 시간과 실행에서 관측한 시간도 함께 본다. | 빌드와 실제 캡처, 결과 차이, 다음 장면 또는 돌아갈 단계 |

화면 배치가 어긋나면 해당 시안을 수정한다. 실제 규칙이나 플레이 결과를 바꿔야 하면 해당 주제의 기획으로 돌아간다. 실행 결과가 맞으면 그 결과에서 이어지는 다음 장면을 고른다. 화면 변화가 없는 배차 규칙이나 AI 비교는 같은 조건의 입력·판단·결과 표를 검토 자료로 쓴다. 이 순서는 기존 시안 제작과 Codex·Claude 양방향 인계를 따른다. [화면 시안과 검증 순서](../../../../../Architecture/화면시안선행제작절차.md) · [혼용 인계 기준](../../../../Handoffs/Codex-Claude-혼용운영안-2026-11-12.md) · [설계실과 제작실 인계](../../../../../Architecture/CodexPlayableLoopGoal운영체계.md#설계실제작실-인계)

## 기획 하나를 화면으로 옮기는 기준

**주제명과 판 → 역할과 상황 → 들어오는 화면 → 볼 정보와 할 행동 → 결과·예외 → 돌아갈 화면.** 하나의 장면을 다음 항목으로 확인한다.

| 질문 | 적는 내용 |
| --- | --- |
| **누가 언제 본다?** | 역할, 선택한 대상, 들어온 화면, 관찰 중인지 직접 결정할 때인지 |
| **뭘 보고 뭘 고른다?** | 결정을 내리는 데 필요한 정보와 주요 행동 한 가지. 관찰 화면이라면 어떤 상태와 변화를 보여 줄지 |
| **그 뒤에 어떻게 된다?** | 확정 뒤 업무 상태, 결정할 수 없는 경우의 이유와 가능한 다음 행동. 이미 만들어진 업무를 다시 열 때의 표시 |
| **같은 일을 어디서 다시 본다?** | 결과를 읽는 화면과 복귀 화면. 같은 주문·매장·역 식별자를 이어 받는 기준 |

판정에는 두 칸을 둔다. **기획**은 `확정 / 미정`, **확인 근거**는 `시안 / 코드 / 자동 촬영 / 실제 입력 / 미확인` 중 확인한 것을 적는다. 화면이 기존 빌드에서 보이는지와 원래 선택한 일이 끝까지 이어지는지는 각각 기록한다. 현재 화면을 재사용할 수 있는지 먼저 보고, 화면의 주요 행동이나 계층 변경이 필요하면 대표 상황의 시안을 함께 붙인다. | 화면과 연결 | 화면에 필요한 내용 | 기획과 현재 확인 근거 | 다음에 채울 것 |
| --- | --- | --- | --- |
