## 1. 확정 — 한 동에서 시간에 따른 변화를 읽는다

첫 군중 비교는 면목 지역의 행정동 하나에서 시작한다. 여섯 동을 합친 넓은 판을 첫 비교 범위로 채택하지 않는다. 플레이어가 하나의 익숙한 장소를 보면서 오전·점심·저녁의 군중 차이를 읽도록 한다.

**같은 행정동 → 같은 지도 범위·카메라 → 오전·점심·저녁 비교**를 유지한다. 공간을 옮겨 다니는 부담을 줄이고 시간대별 변화에 주의를 집중하는 것이 이 선택의 목적이다. 이 목적은 첫 검토 화면과 후속 시각 준비의 기준으로 남긴다.

한 화면에서 시간대 보기를 전환하는 방식을 추천하되 상세 UI는 미정이다. 이웃 동을 어둡게 하거나 숨기는 표현, 경계/줌 범위도 이번 선택으로 확정하지 않는다. 기존 동별 보기 기능·장기 복수 동 경영·구 지도를 폐지하거나 게임 전체를 영구히 한 동으로 제한하지 않는다.

## 2. 남은 범위와 데이터 경계

- 첫 행정동의 이름은 미정이다. 면목본동·면목2동 등 특정 동을 임의로 사용자 선택으로 기록하지 않는다.
- ‘면목동’이라는 법정동 전체와 행정동 하나를 구분한다. 선택한 행정동의 식별자·모듈/경계·자료 시점을 대조하고, 법정동 합계를 행정동 값으로 그대로 붙이지 않는다.
- 오전·점심·저녁은 r181의 확정 장면을 유지한다. 정확 시간구간·구간 길이 보정·사용 열 검증·밀도 변환/상한·가상 경로/자산은 r180/r181의 미정으로 남긴다.
- 같은 자료 판본·비교 척도에서 자료상 차이를 표현한다. 세 장면의 밀도 순서를 미리 정하거나 표시량을 실제 인구·고객·주문 수로 세지 않는다.
- 시간대 비교 보기는 날짜·작업 시간·정산/성장을 추가 진행시키지 않는다. 군중 숨김/축척 조절도 데이터·업무 결과를 바꾸지 않는다.
