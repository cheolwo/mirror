## 2. 무엇을 어디에 연결할까

| 대상 | 여기에 둘 정보 | 같은 건물 1층에 카페와 약국이 있을 때 |
| --- | --- | --- |
| 지도 건물 | 건물 고유 식별자, 원본 윤곽·높이 근거, 선택에 쓰는 도형 | 같은 건물을 누르고 기존 주소와 건물 카드를 읽는다. |
| 점포가 차지할 자리 | 층, 점유하는 벽면과 시작·끝, 폭·높이·앞 방향, 출입·픽업 후보 위치. 실제 자료에서 확인한 값과 게임에서 정한 값을 구별한다. | 카페는 왼쪽 전면만 사용한다. 약국 간판과 공동 출입구 영역을 따로 확보한다. 코너 점포는 정면·측면 두 면을 연결할 수 있다. |

| 브랜드 외관 팩 | 브랜드 식별자·디자인 판본, 적용 가능한 점포 형태·폭, 간판/차양/창면/외벽 모델과 재질, 축척별 표현, 허용된 자산·점포·표시 기간 | 같은 팩을 두 동에서 재사용한다. 각 점포에는 사용할 판본과 형태를 지정해 구형 간판과 새 외관을 함께 표현할 수 있다. |

행정동 모듈에는 건물과 자리의 참조를 두고, 외관은 현재 보이는 점포에 배치한다. 이렇게 하면 제휴사가 간판을 새로 제공해도 해당 자료만 갱신할 수 있다. 지도의 판본이 바뀌어 벽이나 건물 ID의 대응이 끊기면 점포 표식을 남기고 외장 재배치를 검토한다. 실재 상호와 주소가 일치하는 공공데이터는 위치 조사에 쓸 수 있다. 게임 속 제휴 대상 점포는 제휴 자료에서 지정한다.

## 3. 한 구조에서 수용할 세 가지 외관

| 적용 범위 | 브랜드가 표현할 수 있는 것 | 맞지 않는 자리에 배치할 때 |
| --- | --- | --- |
| 간판형 | 전면 글자 간판, 벽에서 나온 돌출 간판, 차양 색과 재질. 바탕과 글자의 두께·광택을 달리해 근거리에서 입체감이 난다. | 벽 폭에 맞는 짧은 간판 또는 별도로 준비한 심벌형을 쓴다. 글자와 로고 비율은 유지한다. |
| 점포 전면형 | 간판과 함께 쇼윈도 분할, 창틀·차양 깊이, 테이크아웃 창, 출입구 프레임을 한 벌로 구성한다. | 입점 가능한 폭·층고와 인접 점포 경계를 확인한다. 픽업창을 쓰면 안쪽 픽업대와 바깥 인수 위치가 같은 주문을 가리키도록 한다. |
| 전용 건물형 | 전 층을 쓰는 점포의 외피, 모서리, 지붕 실루엣과 출입부까지 하나의 모델로 표현한다. | 건물 전체 사용과 부지 적합성이 확인된 자리에서 선택한다. 윤곽·높이·도로 경계를 벗어나거나 자료가 부족하면 해당 브랜드의 전면형이나 기본 카페를 쓴다. |

지도 한 동을 축소해 볼 때는 회색 동네에서 **내가 운영하는 곳**이 먼저 읽혀야 한다. 중간 거리에서는 내 점포 표식의 작은 민트 테두리와 업종 기호를 쓰고, 가까이에서는 브랜드 고유의 색·재질·입체 간판을 드러낸다. 제휴한 타 점포도 같은 상표를 쓸 수 있으므로 운영권 표식은 플레이어의 점포에만 붙인다. 간판 야간 조명은 고정된 외관 조명으로 다루고, 명덕·기사 빛의 크기와 박동은 기존 게임 신호에 맡긴다. 거리 기준은 실제 화면에서 보이는 간판 크기로 정한다.

## 4. 제휴를 맺었을 때 교체하는 순서

1. **제휴사에서 받을 자료**는 적용할 점포·매장 유형, 로고 원본과 사용 색, 정면·측면 예시, 사용할 수 있는 간판 규격·3D 자료, 허용 매체와 기간이다. 협력사가 제공한 디자인을 어떤 재질과 크기로 옮겼는지 검토본에 함께 적는다.
2. **게임에서 적용할 때**는 확인된 판본을 허용 점포에 연결한다. 유상 노출은 점포 카드에서 제휴사와 기간을 확인하도록 한다. 외형 팩이 바꾸는 것은 표시 자산이며, 수요·주문·정산·홍달 플레이스 순위는 각 운영 규칙이 계산한다.
3. **팩 누락·기간 종료·철회 때**는 기본 가상 카페 외관으로 전환한다. 같은 저장에서 점포 ID, 직원·재고, 진행 중 주문, 기사 인수 위치를 계속 사용할 수 있어야 한다. 온라인 다운로드·갱신은 후속 선택이며 첫 비교는 로컬 팩 두 개로 충분하다.

## 5. Claude에게 넘길 첫 비교

**가상 외관 두 벌을 같은 건물과 카메라에서 비교**하는 안을 권한다. A는 얕은 차양·입체 글자·도로 쪽 픽업창을 가진 테이크아웃형, B는 목재 프레임·깊은 처마·큰 유리면과 안쪽 인수대를 가진 좌석형이다. 둘 다 같은 라떼 주문과 같은 점포를 사용한다. 독특한 건물 외형은 별도 전용 부지에 들어갔을 때 달라질 윤곽을 작은 별도 그림으로 설명하면 된다. 첫 개발 계획에는 기존 FBX에서 분리할 부품, 그대로 쓸 건물, 각 변형에만 필요한 새 모델을 적는다.

- **근경**에서는 로고 글자를 가려도 A와 B의 실루엣·창면·인계 방식이 구별되는지 본다.
- **동 전체와 거리 보기**에서는 내 점포와 기사 빛을 찾을 수 있고 옆 점포 간판이나 공동 출입구가 침범되지 않는지 본다.
- **검토 뒤 제작할 때**는 다른 행정동의 더 좁은 벽에 한 벌을 다시 놓고, 맞는 소형 간판 선택과 기본 외관 복귀, 같은 점포 카드·주문 유지까지 확인한다.

**확정 방향**은 향후 여러 브랜드를 수용하는 반실사 외관과 ‘아스트라 기획 → Claude 개발 계획·시안 → 사용자 검토 → 선택 범위 제작’ 순서다. **미정**은 첫 브랜드, 실제 제휴 여부, 각 점포 형태와 자산 규격이다. 이번 판본은 문서 제안이며 신규 모델·실행 검증과 새 디오라마 규칙 후보는 없다.
