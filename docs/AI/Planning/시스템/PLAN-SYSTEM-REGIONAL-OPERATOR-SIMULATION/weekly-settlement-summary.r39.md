- 목적: 매주 정산 확인에서 불필요한 진행률을 제거하고 운영자가 실제로 판단할 항목만 남긴다.

## 1. 주간 정산 기본 요약

매주 정산이 끝난 뒤 운영자에게 다음 세 항목을 기본 표시한다.

1. `이번 주 정산 총액`
2. `정산 후 가용현금`
3. `정산 확인 필요`

`정산 완료율`은 주간 마감 결과에 표시하지 않는다. 주간 정산은 정해진 주기마다 닫는 단위이므로 완료 뒤 비율을 다시 보는 실익이 작다.

## 2. 진행 중 상태와 마감 결과 분리

- 정산 batch가 실제 처리 중이면 내부 운영 상태로 `준비`, `처리 중`, `완료`, `일부 보류`, `실패`를 가질 수 있다.
- 처리 중 화면에는 완료율 대신 현재 상태, 시작시각, 예상 다음 확인시각과 중단 사유만 간결하게 표시한다.
- 마감 결과에서는 정상 건별 목록을 기본적으로 숨긴다.
- 운영자가 감사·문의·표본 확인을 원할 때만 정상 건별 내역을 펼친다.
- 예외 건은 `정산 확인 필요` 상세에서 원인·금액·기한·가능한 조작을 바로 확인한다.

## 3. 금액 범위

- `이번 주 정산 총액`은 기사 수행대금, 음식점 상품대금, 지사 운영보상, 고객 환급처럼 서로 다른 의무를 내부 하위 합계로 분리한다.
- 화면 첫 줄에서는 전체 외부 지급·환급 합계를 보여주고 선택하면 당사자 종류별 하위 합계를 연다.
- 플랫폼 수익과 통과 자금을 정산 총액에 섞어 매출처럼 표현하지 않는다.
- `정산 후 가용현금`은 확정 지급과 보호 준비금을 반영한 뒤 운영자가 실제 정책에 사용할 수 있는 금액이다.

## 4. 완료 조건

- 주간 마감 결과에 정산 완료율이 나타나지 않는다.
- 운영자는 정상 건별 목록을 읽지 않고도 이번 주 총 정산 규모, 남은 가용현금과 예외 유무를 이해한다.
- 총액에서 당사자별 하위 합계와 원 재무 사건까지 추적할 수 있다.
- 처리 중 상태와 마감 완료 결과를 혼동하지 않는다.
- 예외가 있는 정산 묶음도 정상 건 전체를 자동으로 보류하지 않는다.

## 5. r40에서 폐쇄된 질문

월간 운영 결산의 기본 수치 비교는 전월 실적만 사용한다. `월초 계획`은 사용하지 않고, 운영자가 스스로 세우는 비구속 방향인 `월초 서원`을 별도 회고 항목으로 둔다. 상세 기준은 `monthly-performance-and-vow.r40.md`가 소유한다.
