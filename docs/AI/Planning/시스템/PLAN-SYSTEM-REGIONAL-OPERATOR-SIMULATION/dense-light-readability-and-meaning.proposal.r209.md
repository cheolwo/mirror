## 2. 우선 고려할 다섯 가지 — 제안

### 2.1. 식별용 중심점과 성장하는 진한 빛을 구분한다

개별 매장을 찾기 위한 **작은 식별점**과 명덕을 표현하는 **진한 중심 영역**을 구별하는 안을 권한다. 식별점은 밀집해도 읽히고, 진한 영역과 연한 후광은 누적 명덕에 따라 함께 커진다. 중심점만 고정해 모든 진한 영역의 크기까지 같게 만들면 최근 시안의 성장 의미가 약해질 수 있다.

원형 경계선을 다시 기본 표현으로 추가하지 않는다. 어느 영역이 최대 범위인지 확인하는 상세 방법/선택 효과는 후속 시안에서 검토한다. 대가는 식별/성장 표현을 따로 조절해야 한다는 점이다. 이를 새 제품 구현 명령으로 해석하지 않는다.

### 2.2. 크기·현재 상태·맥동·색에 서로 다른 뜻을 맡긴다

| 시각 요소 | 권하는 의미 | 주의할 혼동 |
| --- | --- | --- |
| 진한/연한 영역의 기준 크기 | 해당 대상의 누적 명덕 | 순간 움츠러듦·밀집 보정·줌을 명덕 감소로 읽지 않음 |
| 현재 상태 표식/짧은 문구 | 깨어 있음·휴식·정신 차림 필요 등 검증된 상태 | 장식 맥동만으로 깨어 있다고 판정하지 않음. 새 스킬 상태는 아직 미구현 |
| 매장별 엇갈린 위상 | 개체를 구별하는 장식 | 빠르거나 먼저 퍼진 매장이 더 깨어 있거나 생산성이 높다는 뜻으로 쓰지 않음 |
| 주문/선택의 색·주목 효과 | 현재 업무와 선택 대상 | 현재 주문 대기 매장의 금색/빠른 맥동과 명덕 크기를 섞어 새 성장량으로 표시하지 않음 |

현재 값이 아직 명덕에 결속되지 않은 빛은 그 사실을 구별한다. 검토용0이나 임시값을 확정된 ‘명덕0’으로 읽게 하지 않는 안이다. 실제 게임 상태와 표시 방식의 결속이 먼저이며, 범례/설명은 필요한 순간의 짧은 카드로 제공한다.

매장별 위상은 대상 식별자와 결속하는 안을 추천한다. 재정렬·선택·줌 때문에 매장 정체성이 바뀌거나, 지붕 중심점과 땅/벽 후광이 서로 다른 박자로 움직이지 않게 한다. 실제 Core 매장ID와 집계용 제휴/배회 표시는 구분한다. 정확한 위상 식/저장·합성 빛 그림의 적용 방법은 Claude의 구현 범위에서 검토한다. 맥동이 정지 중 움직여도 스킬 시간/기여는 권위 시계를 따른다.

### 2.3. 겹쳐도 원하는 매장을 선택하고 돌아올 수 있어야 한다

후광의 크기가 커져도 클릭 범위를 함께 키우지 않는 기존 경계를 유지한다. 매장과 기사가 같은 자리에 있을 때 **누구를 골랐는지** 이름/카드로 확인하고 바꿀 수 있는지 먼저 본다. 빛 하나가 앞의 모든 입력을 가로채거나 계속 다른 대상을 고르게 해서는 안 된다.

같은 건물 안의 여러 점포처럼 실제 좌표가 겹치면 점만 분리하는 것으로 해결되지 않을 수 있다. 그 경우 건물/후보 목록에서 해당 점포를 고르고 같은 ID를 지도에서 강조하는 보완안을 검토한다. 점포 수·층/호수 근거가 없는 상태에서 가상 위치를 실제 주소처럼 옮기지 않는다.

선택 시 다른 빛을 약하게 하는4번과 목록에서 찾는5번은 이 문제를 풀 후보지만, 이번에 기능 적용/정렬 기본값을 승인한 것은 아니다. 선택을 바꿔도 명덕/업무·카메라 복귀 맥락은 유지한다.

### 2.4. 밀집·표시 상한과 실제 성장을 구분한다

매장이 많아 겹친 빛의 넓이나 밝기를 **동의 명덕 합계**로 읽지 않는다. r208대로 픽업 동에 실제 활동 기여가 많이 쌓일 수 있는 것과, 건물이 빽빽해 시각적으로 밝은 것은 다른 정보다.

밀집 보정으로 후광을 옅게 하거나 크기를 제한해도 실제 누적을 줄이지 않는다. 상한에 닿은 대상은 더 성장해도 실제 수치를 카드/목록에서 읽게 하는 안이다. 같은 종류·같은 줌·기준 크기로 비교하고, 서로 다른 위상의 한 장면만으로 명덕 순위를 판정하지 않는다. 대가는 지도만으로 정확한 수치를 모두 비교하기 어렵다는 점이다.

넓은 지도에서3번 묶음을 쓰게 된다면 **‘음식점 N곳’은 개수**임을 표시한다. 묶음을 한 명의 인물·한 매장·명덕을 합친 새 주체로 만들지 않는다. 묶음 해제/지역 변경이 명덕을 재지급하지도 않는다. 묶음의 적용 축척/기준/켜지는 수는 아직 미정이다.

### 2.5. 중요한 업무와 간단한 표현을 먼저 보존한다

새 주문·지연·전달 확인·정신 차림 필요를 모두 다른 장식 맥동으로 늘리기 전에, 플레이어가 지금 판단할 알림이 읽히는지 본다. 선택한 대상/진행 경로·중요 표식·도로 윤곽이 후광에 묻히지 않는 구성이 우선이다. 알림 종류/강도·새 스킬 안내의 실제 내용은 후속 확정한다.

r157의 간단히 보기/움직임 감소에서는 맥동을 줄이거나 멈춰도 식별점·선택·현재 상태·성장 정보를 유지하는 안이다. 시각 설정이 활동/명덕/주문·게임 시계를 바꾸지 않는다. 현 구현에 해당 세부 제어가 이미 있다고 보고하지 않는다.

성능상 밀집/축소 화면에서 후광 갱신을 줄이더라도 실제 기사/활동·명덕 계산을 줄이지 않는다. 화면 밖 대상을 덜 그리는 것과 업무가 멈추는 것을 나눈다. 최대 표현 수/갱신 간격·지원 기기 수치는 아직 정하지 않았다.

## 3. 적용 중인1·2번 반환에서 먼저 볼 장면 — 후속 검토안

추가 기능을 한꺼번에 늘리기 전에 같은 입력/장면으로 다음을 확인하는 순서를 권한다.

1. **드문 곳/밀집한 곳·확대/축소:** 중심점과 진한/연한 성장 영역, 선택 대상·도로가 읽히는가. 표시 상한에 닿아도 실제 값/미결속을 구별하는가.
2. **매장과 기사 겹침·같은 건물 점포:** 의도한 ID를 고르고 카드에서 확인할 수 있는가. 후광 크기/그리기 순서가 선택을 가로채지 않는가.
3. **같은 값·서로 다른 위상:** 커졌다 움츠러들어도 누적이 감소한 것으로 읽히지 않는가. 중심점/지붕/땅의 박자가 같은 대상에서 맞는가.
4. **정지/재개·동간 이동/귀환·복원:** 장식 시계와 업무/정신 차림 시계를 구분하며, 대상/기여·선택 맥락을 유지하는가.
5. **간단한 표현·밀집 성능:** 움직임/후광을 줄여도 중요한 업무/선택을 찾을 수 있고 권위 결과가 같은가.

이는 후속 검토 목록이며 지금 수행한 입력/성능 시험이 아니다. 현재 새 명덕 값/스킬이 연결되지 않은 항목은 준비된 검토용 상태로만 비교하고 실제 성장/발동 완주로 보고하지 않는다. 시안 정지화면과 실제 움직임·실제 입력 검증을 분리한다.
