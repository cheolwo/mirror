## 1. 확정 — 쌓인 기여가 빛의 크기로 보인다

명덕 기여가 적을 때는 기사/음식점 주변의 빛이 작고, 유효한 행위로 기여가 늘면 **주변으로 퍼지는 빛의 범위가 더 커진다**. 누적 수치를 매번 열어 보지 않아도 오래 쌓은 성장을 지도에서 느끼게 하는 방향이다.

기사/건물 모델 자체를 키우는 뜻이 아니다. 주변 후광·발광 영역의 크기를 표현 수단으로 삼는 안을 권한다. 반경 단위/배율·재질/빛 형태·최대 크기는 아직 정하지 않았다. 빛이 커져도 클릭/충돌 범위·실제 배달권·고객 수요·작업 능력·명덕 획득량이 자동으로 커지는 효과는 이번에 추가하지 않는다.

기사의 빛은 그 기사에게 귀속된 누적 기여, 음식점의 빛은 그 점포에 귀속된 누적 기여를 읽는 방향이다. 점포 기여를 작업자와 어떻게 연결하는지, 같은 행위를 누구에게 귀속하는지는 r204의 미정 사항이다. 기사 점수를 점포에 다시 더하거나 화면에 나타난 모든 사람의 점수를 임의 합산하지 않는다.

## 2. 현재 상태와 누적 성장을 함께 읽는 안

| 표현 | 뜻 | 확정 범위 |
| --- | --- | --- |
| 빛이 차지하는 범위/반경 | 해당 기사/음식점의 누적 명덕 기여 | 기여가 증가할수록 빛이 커지는 방향은 사용자 확인 |
| 안쪽 빛의 점등·명암 또는 별도 상태 표식 | 현재 깨어 있는가/쉬는가 등 검증된 현재 상태 | 구체 표현은 제안. 기존 경/무념 상태를 빛으로 새로 판정하지 않음 |
| 짧은 확장/맥동 | 방금 새 기여가 성립했다는 알림 | 선택형 연출 제안. 과거 기여를 다시 획득한 것으로 처리하지 않음 |
| 선택 카드의 수치/문구 | 누적 기여·이번 증가·현재 상태 | 정확한 수치와 귀속의 근거 확인용. 크기만으로 모든 정보를 읽게 하지 않음 |

예를 들어 같은 기사가 배달 업무를 유효하게 수행할수록 후광의 기준 크기가 조금씩 커진다. 이후 쉬는 중에는 상태 표식/안쪽 빛을 바꾸되 **축적된 기여가 사라졌다는 인상은 주지 않는 안**을 권한다. 누적 범위의 약한 테두리를 남기는 방식 등을 시안에서 비교할 수 있다. 휴식·경 상태 변화에 따른 명덕 감점/감쇠는 이번에 추가하지 않는다.

현재 빛의 크기만 보고 깨어 있는지 판정하지 않는다. 많이 기여하고 쉬는 기사와, 적게 기여했지만 지금 깨어 있는 기사를 구별할 수 있어야 한다. 음식점의 현재 상태는 기존 기사전용 모듈만으로 판정할 수 없으므로 점포 상태 권위는 후속 확정한다.

## 3. 크기 증가의 가독성 — 제안/미정

- 초반의 작은 성장이 보이면서 장기 누적은 완만하게 커지는 대응 곡선을 추천한다. **표시 크기의 상한/포화 여부·구간·배율은 미정**이며 임의로 점수 단위를 확정하지 않는다.
- 지도를 같은 배율로 볼 때 누적 기여가 더 큰 동일 종류의 대상은 더 큰 범위를 갖게 하는 안이다. 기사와 건물은 기준 크기가 다를 수 있으므로 서로의 빛만 보고 점수를 직접 비교하게 하지 않는다.
- 줌·선택 강조·일시 맥동으로 보이는 크기가 달라져도 실제 기여와 기준 크기는 바뀌지 않는다. 카메라를 줄였다고 성장한 것으로 처리하지 않는다.
- 여러 빛이 겹쳐도 기사·도로·건물 윤곽·주문 핀을 읽을 수 있도록 옅은 후광과 외곽선 등을 검토한다. 겹친 빛을 새 공동 점수·동 승급·영향권으로 해석하지 않는다.
- 기존 관리 매장의 색과 선택/주문 상태 의미를 유지한다. 빛 성장만으로 일반 건물의 관리 관계나 기본 회색 표현을 바꾸지 않는다.
- r157의 간단한 표현/효과 끄기에서는 발광·맥동을 생략하고 정적 범위 표식 또는 아이콘/수치로 같은 성장 정보를 제공하는 안이다. 표현 설정은 점수·기여 자격·동 성장에 영향을 주지 않는다.

## 4. 결과를 읽기만 하는 표현

빛은 권위 있는 누적 기여와 현재 상태를 읽어 그린다. 렌더러/애니메이션이 명덕을 추가하거나 점포/동 승급을 확정하지 않는다. 실제 점수·귀속·저장 계약은 r204의 후속 기획/명세에서 결속한다.

현재 외부 Unity 소스 `Runtime/SagajeongDispatchRoam.cs:92–107,161–181`의 배회 불빛은 동·순번·seed로 생성되며 개별 기사 고유 식별자와 연결되어 있지 않다. **개인 명덕을 표현하려면 실제 기사 식별자/기여 조회와 먼저 결속**해야 한다. 같은 파일의 현재 맥동은 `Time.unscaledTime`으로 움직이는 장식이므로 깨어 있음/업무 진행의 권위 근거로 재해석하지 않는다. 이는 소스 읽기 결과이며 이번에 게임을 실행한 확인은 아니다.

다른 동으로 갔다 돌아오기·같은 대상을 다시 선택하기·같은 결과 재수신·저장 복원으로 같은 기여를 새로 더하지 않는다. 최신 누적값으로 기준 크기를 다시 표시하고, 화면 밖에서 지난 효과를 한꺼번에 재생하지 않는 안을 권한다. 기사와 점포 양쪽의 표현이 같거나 달라도 동 집계의 동일 행위 결과 중복 방지 원칙은 유지한다.

## 5. 확정 / 미정 / 다음 질문 하나

**확정:** 명덕 기여가 쌓일수록 기사와 음식점의 빛이 더 커지는 방향. 현재 상태와 누적 기여를 구분하는 r204의 의미는 유지하되, 누적량에 반응하는 빛의 크기를 추가한다.

**미정:** 반경/곡선·최대 표시 크기·명암/맥동/색/겹침·움직임 감소·점포 기여 귀속과 현재 상태·시안/실제 구현. 행정동 승급의 점수/임계값과 기존 운영 단계의 통합도 여전히 미정이다.

**다음 질문 하나:** 이번 표현 방향 기록에는 추가 질문이 필요하지 않다. 다음 명덕 성장 논의는 r204의 **기존 동 성장과 명덕을 통합할지**에서 이어가며, 빛의 크기 선택을 그 결정까지 승인한 것으로 해석하지 않는다.
