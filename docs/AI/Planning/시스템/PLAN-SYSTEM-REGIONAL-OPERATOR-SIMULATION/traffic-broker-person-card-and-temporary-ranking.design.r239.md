## 2. 플레이 흐름과 인물 카드

**정식 광고 노출과 결과 확인 → 중개업자 소개 → 인물 카드에서 의뢰 조건 확인 → 게임 비용 지불 → 다음 색인의 점수·순위 변화 → 정상 고객의 노출/주문 결과 확인 → 종료·재의뢰·회복**을 제안한다.

인물 카드의 첫 가칭은 ‘트래픽 중개업자’다. 이름·초상·말투는 Claude 시안에서 정한다. 특정 실제 인물·업체의 행위를 묘사하는 카드로 만들지 않는다.

| 카드 앞면 | 펼친 상세와 행동 |
| --- | --- |
| 초상·이름·직업 | 소개 경로와 ‘일반 검색 순위 개입 의뢰’라는 서비스 설명 |
| 능력 요약 | 보유 가상 계정군의 가용량·현재 계약 여력·이미 확인된 과거 납품 결과 |
| 제안 한 줄 | 대상 점포·키워드·검색 지역·비용·효과 예상 범위·활성 운영 기간 |
| 현재 관계/의뢰 상태 | 소개됨·검토 중·수행 중·검토/종료·다시 의뢰 가능 |
| 가능한 선택 | 제안 보기·의뢰 조건 확정·보류·거절·기존 계약 확인/종료 |

첫 추천은 소개받은 카드를 인맥 목록에 계속 남기는 방식이다. 카드를 누르면 그 인물과 거래하며, 비용은 계약마다 지불한다. 카드 획득·열람·장착만으로 비용이나 트래픽·점수를 발생시키지 않는다. 카드를 소모해 즉시 순위를 올리는 일회성 마법 효과로 해석하지 않는다.

등장 자격은 이미 r194에서 정했다. 자기 매장 또는 담당 가상 고객사의 정식 광고가 게임 고객에게 실제 노출되고, 플레이어가 그 결과를 확인하면 된다. 주문 0건이나 손실도 인정한다. 전국 지도 해금·흑자·순위 상승을 추가 조건으로 붙이지 않는다. 소개 자격이 생긴 뒤 다음 안전한 운영 경계에 제안 카드 1장을 보이는 것은 이번 연출 추천이며 아직 미정이다. 소개·제안 열람은 계약 수락이 아니다.

일반 검색을 구현하더라도 그것만으로는 이 정식 광고 경험을 충족하지 않는다. 실제 성장 흐름에는 해당 광고 집행/결과의 선행 연결이 필요하다. 카드와 점수의 독립 시험에서는 소개 완료 상태를 명시한 가상 시험 자료를 사용할 수 있지만, 이를 플레이어가 광고를 경험한 저장 기록이나 실제 해금 근거로 승격하지 않는다.

## 3. 의뢰와 가상 주문자 계정의 역할

중개업자의 보유 자원은 시뮬레이션의 가상 주문자 계정군과 가용 관여량이다. 실제 IP·로그인 정보·이용자 계정은 필요하지 않다. 화면은 ‘가용 계정군’, ‘이번 의뢰에 배정한 규모’, ‘보고한 관여’, ‘반영된 점수’를 읽는다. 상세 행동 운용은 NPC 능력으로 추상화한다.

같은 가상 계정이 일반 고객으로 주문하는 기록과 중개 의뢰에 관여한 기록을 가질 수 있어도, 각 행위의 목적·출처를 분리한다. 계정 하나의 모든 기록을 실제 구매로 세거나 모두 가짜로 지우지 않는다. 중개 행동은 잠재 고객 수나 정상 구매 의향으로 변환하지 않는다.

첫 계약은 **게임 점포 1곳 × 키워드 1개 × 검색 지역 1개 × 유한한 활성 운영 기간**을 권한다. 매장 소유자나 담당 가상 고객사에 대한 게임 권한을 확인하고, 같은 조합의 의뢰를 중첩해 무한히 가산하지 않는다. 계정군 가용량도 진행 중 계약에 예약해 여러 계약이 같은 자원을 무제한 재사용하지 않게 한다.

계약에 필요한 의미는 인물/계약 ID, 대상·조건 판본, 비용과 지급 상태, 예약량, 시작할 색인 구간, 남은 활성 기간, 납품 보고, 반영된 색인/신호, 종료/해약/검증 사유다. 게임 비용은 기존 게임 자금 원장을 사용하고 카드 전용 돈을 별도로 만들지 않는다.

권장 상태는 제안 → 조건 확정·지급 → 다음 색인 대기 → 수행 중 → 종료/감쇠 → 결과 확인이다. 거절·기간 전 해약·검토/관련 신호 제외는 사유 있는 분기다. 동일 계약 확정·지급·종료의 재전송은 기존 결과를 읽고 두 번 차감/환급하지 않는다. 잔액 부족·대상 미준비·계정군 여력 부족이면 이유와 조건 수정/보류를 제공한다. 비용만 차감하고 계약이 사라지는 중간 상태를 피한다.

## 4. 장소 점수에 실제로 개입하는 방식

~~~~text
게임 비용과 계약 확정
 → 합성 계정군의 중개 관여 기록
 → 출처·계약이 붙은 미검증 잠정 관심
 → 다음 색인의 유효 정렬 점수에 한시 반영
 → 일반 검색의 순번·페이지와 정상 고객 노출 변화
 → 고객 선택·주문 의향 → 기존 주문 요청·이행
~~~~

첫 계산안은 r238의 기본 점수에 계약별로 제한한 잠정 관심을 더하는 방식이다. 이 항은 검색 서비스가 아직 걸러내지 못한 관심 신호를 뜻한다. 중개업자의 납품 주장과 실제 판정된 반영량은 각각 저장한다. 기본값은 그대로 두고, 게임 내부의 유효 정렬 점수가 달라져 일반 검색 순위가 실제로 올라갈 수 있게 한다.

유효 정렬 점수 = 기본 점수 + 유효한 잠정 관심 − 판정된 검색 제한 조정

첫 비교에서는 검색 제한 조정을 0으로 두고 잠정 관심의 상승/감쇠부터 확인한다. 검증으로 어떤 계약 신호를 제외했는지 기록하며 같은 사유를 가산 제외와 추가 벌점으로 두 번 차감하지 않는다. 별도의 노출 제한·추가 벌금·환불/분쟁 수치는 후속 미정이다.

기본 점수는 r238의 0~100점과 요소를 보존한다. 잠정 관심은 별도 항이므로 유효 점수는 100점을 넘을 수도 있다. Claude의 정수 천분의 1점 계획을 확장할 때도 기본 점수 범위를 몰래 다시 정의하지 않는다. 기본/잠정/제한 항과 총점·판본을 각각 읽게 한다.

검색 의도·지역·등록/서비스 자격에 맞는 후보에게만 적용한다. 카페 대상 의뢰를 피자 검색이나 모든 지역으로 전파하지 않는다. 원래 후보에서 탈락한 점포를 가산점만으로 등록하지 않는다. 상한·시장 경쟁 때문에 순위가 덜 오르거나 그대로일 수도 있고 1위도 가능한 경쟁 상황은 남긴다. 비용 지불만으로 1위·1페이지·주문량을 보장하지 않는다.

r238의 기존 색인은 불변으로 유지한다. 새 계약·기간 변화·검증 결과는 다음 색인 입력에 결속하며, 이미 검색한 고객의 페이지 이동 중 순위를 바꾸지 않는다. 동점은 기존 안정 점포 ID 정렬을 따른다. 가산 상태·기간과 지급/자원 예약도 저장·복원한다. 조회·재접속·운영 회차 마감은 집행이나 기간 소모를 추가하지 않는다.

## 5. 순위가 주문 기회에 미치는 규칙

정상 가상 고객의 인구 기반 검색 기회는 r238과 같은 예산을 소비한다. 중개 관여가 그 총량에 새 고객을 더하지 않는다. 키워드별 정상 검색량과 중개 관여량은 별도 집계한다. 후속에서 플랫폼 표면의 미검증 검색 집계를 보여 주더라도 내부 원장과 수요 계산에서는 출처를 유지한다.

순위 상승으로 앞 페이지에 들어온 내 매장을 더 많은 일반 고객이 볼 수 있다. 일부는 메뉴·거리·가격·대기 조건에 따라 선택하고 일부는 떠난다. 기존 다른 점포의 점유가 옮겨 오거나, 이전에 구매하지 않던 고객이 맞는 점포를 발견해 전환할 수 있다. 전체 정상 고객 기회를 넘는 주문을 조작된 관여로 직접 만들지 않는다.

가짜 관여는 직접적인 주문·매출·재고 차감·기사 보상·명덕을 생성하지 않는다. 실제 게임 주문은 기존 단일 주문 ID로 요청·수락·제조·배달·정산을 거쳐야 한다. **현재 r238은 주문 의향까지의 개발 계획이므로 첫 카드 시험도 순위·노출·의향에서 검증한다.** 검7의 주문 연결이 준비된 뒤 완료 주문·기여이익 증가까지 확인한다. 기존 동 묶음 매출·카페 제조·배달 전표에 같은 실적을 중복 가산하지 않는다.

정상 고객이 보인 반응은 출처가 검증된 기록만 다음 기본 점수 후보가 된다. 가짜 관심을 열람률·완료율이나 신규 명성으로 세탁하지 않는다. r238의 위치 보정·저표본 중립과 상한도 유지한다. 실제 서비스 개선과 정상 이행으로 얻은 기본 점수는 계약 종료 뒤에도 해당 근거/기간에 따라 남을 수 있다.

계약·조작 신호량이나 돈에 명덕 보너스를 붙이지 않는다. [깨어서 하는 모든 활동 r206](awake-activities-and-mindfulness-skill.design.r206.md)의 실제 활동 판정은 별도다. 중개를 선택했다는 이유로 성립한 깨어 있음·정상 작업 기록을 일괄 취소하지 않으며 명덕을 도덕 판정용 벌점으로 사용하지 않는다.

## 6. 비용·기간·검증과 회복

초기 밸런스는 **빠른 한시 노출과 비용/지속성의 대가**가 읽히게 잡는다. 정식 광고의 별도 광고 칸, 매장 개선의 기본 정보/운영 역량, 중개 의뢰의 한시적 일반 순위 개입을 같은 비용·성과 보고에서 비교한다. 특정 경로가 항상 우월하거나 모든 중개 계약이 강제 실패하는 규칙은 피한다.

| 상황 | 결과와 다음 선택 |
| --- | --- |
| 노출 증가·처리 여력 충분 | 정상 주문을 실제 처리해 비용을 회수할 기회. 다음 의뢰·유지·매장 개선 비교 |
| 노출 증가·재고/바리스타 부족 | 의향은 늘어도 미충족·대기·이탈 발생. 비용 손실 가능, 먼저 운영 개선 |
| 효과가 작음/납품 미달 | 보고량과 실제 순위 비교. 종료·계약 조건 변경·분쟁은 정의된 조건에 한함 |
| 유효기간 종료 | 잠정 관심 감쇠 후 0. 그때의 경쟁/정상 성과로 재계산 |
| 지연 검증에서 관련 신호 제외 | 해당 계약의 남은 가산 제거. 판정 사유·범위/남은 기간과 회복 상태 표시 |

기간은 첫 판의 검색 모형이 채택한 활성 구간 수로 제안한다. 현실 날짜·캠페인 영업일·운영 회차 버튼 수와 혼용하지 않는다. 부재중 집행·수익·검증 벌금을 임의로 계산하지 않는다. 계약 종료 후의 긴급 재계약/동시 중첩·해약/환불·정확 검증 시점과 확률은 미정이다.

관련 신호를 제외해도 정상 고객에게 이미 이행한 주문·정산은 보존한다. 회복은 의뢰 중단, 정해진 제한 기간 경과, 정확한 정보·정상 운영 근거의 축적과 정식 광고 전환으로 돌아오는 안이다. 같은 계약/판정 ID로 제재와 비용을 반복 적용하지 않는다. 회복 완료는 과거 1위 복구가 아닌 유효한 조건에서의 재계산이다.

## 7. 독립 예제와 첫 검토 범위

[재현 계산 예제](../../../../../artifacts/local/hongdal-place-broker-person-card-r239-20261115/examples/rank_trial.json)와 [계산 스크립트](../../../../../artifacts/local/hongdal-place-broker-person-card-r239-20261115/examples/rank_trial.py)는 전부 가상 수치다. 실제 매장·Naver 순위·운영 실적에 해당하지 않는다.

| 구간 | 기본점수 | 잠정 관심 | 유효 점수 | 순위·페이지 |
| --- | ---: | ---: | ---: | --- |
| 의뢰 전 | 63 | 0 | 63 | 13위·2페이지 |
| 반영 | 63 | 15 | 78 | 6위·1페이지 |
| 감쇠 1 | 63 | 8 | 71 | 10위·1페이지 |
| 감쇠 2 | 63 | 4 | 67 | 12위·2페이지 |
| 종료 | 63 | 0 | 63 | 13위·2페이지 |

13개 후보의 경쟁 조건을 동결한 예제다. 기본점수가 92인 1위는 그대로이며, 71점·67점 동점은 안정 ID로 정렬한다. 기본점수와 경쟁이 달라지는 실제 다음 구간에서도 항상 13위로 복귀한다는 뜻은 아니다.

검색 60회와 페이지/슬롯 탐색 조건을 고정한 독립 비교에서는 내 매장의 고유 노출이 12→36회가 되고 다른 매장 합계가 24회 줄었다. 이 조건에서의 총 420개 노출 보존은 예제 조건이며, 실제 매번 같은 탐색량이라는 규칙은 아니다. 계약비 30금액단위·추가 완료 1건의 기여이익 10단위를 가정하면 3건을 더 완료해야 비용을 회수한다. 이 예제는 주문이나 이익을 실제 생성하지 않는다. 게임 기본 가격·가산 15점·기간을 승인한 값도 아니다.

Claude의 r238 본체는 현재 담당 범위대로 진행한다. 이 후속은 인물 카드 시안·독립 계약 규칙·다음 색인의 잠정 점수 입력이라는 작은 확장으로 개발 계획을 따로 잡는다. 본체의 공유 계약을 바로 수정하라는 인계로 사용하지 않는다.

검토 순서는 카드 소개/재열람 → 조건/비용/대상 확인 → 한 번 지급/예약 → 다음 판에서 순위·페이지·노출 변화 → 감쇠/종료 → 미이행/검증·회복이다. 같은 세션의 판본 보존, 후보 탈락·동점·중복 계약/지급·저장 복원·일일 조회 불변을 확인한다. 주문 연결 이후에는 같은 고객/주문을 정식 광고·일반 검색·중개 성과에 중복 귀속하지 않는 검증을 추가한다. 주 유입과 계약의 보조 기여를 분리한다.

## 확정 / 미정 / 다음 질문 하나

**확정:** 비용을 받고 가상 주문자 계정의 트래픽으로 장소 점수·일반 순위 상승을 시도하는 인물을 인물 카드로 표현한다. 순위·노출 상승이 정상 고객의 주문 기회로 이어지는 게임 규칙을 별도로 기획한다. 기존 정식 광고 경험 후 소개 조건은 유지한다.

**미정:** 인물 이름/초상·카드 배치·소개 시점, 카드의 지속 보유, 의뢰 비용·납품/환불/해약·활성 구간 수, 가산점·감쇠·검증/제한·회복 수치와 실제 주문 연결이다. 본문의 수치·연락 카드·상태/산식은 추천이며 일괄 승인된 것으로 해석하지 않는다.

**다음 질문 하나:** 소개받은 인물 카드는 인맥 목록에 계속 남겨 두고, 필요할 때 계약별 비용을 내어 의뢰하는 방식으로 잡을까요? 인물과의 관계를 지속하면서 매번 예산과 효과를 판단할 수 있어 추천한다. 사용하면 사라지는 즉시 효과 카드는 이번 추천에서 채택하지 않는다.
