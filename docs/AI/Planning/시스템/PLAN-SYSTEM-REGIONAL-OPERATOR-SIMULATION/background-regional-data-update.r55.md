# [기획 · 관찰형 지역 Simulation · PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION · 백그라운드 지역 자료 갱신 r55]

- 이전 판본: [세션 자료 판본 고정 r54](session-pinned-public-data-revision.r54.md)

## 확정

새 호환 지역 자료 판본이 있어도 최신 다운로드가 끝날 때까지 게임 진입을 막지 않는다.

- 로컬에 검증된 기존 판본이 있으면 그 판본으로 즉시 Simulation 세션을 시작한다.
- 새 판본은 활성 캐시와 분리된 임시 영역에 백그라운드로 내려받는다.
- 파일별 hash·크기·계약 판본과 전체 `projectionHash`가 일치한 뒤에만 `ReadyForNextSession` 후보가 된다.
- 다운로드가 중단되거나 검증에 실패하면 후보만 폐기하고 활성 세션과 기존 검증 캐시는 유지한다.
- 다운로드 완료가 현재 세션의 건물·도로·주소·이동망을 바꾸지 않는다.
- 다음 세션 시작 화면에서 새 판본의 기준일, 주요 변경, 품질·결손, 용량을 보여 준다.

## 사용자 경험

| 순간 | 기본 표시 |
| --- | --- |
| 접속 직후 | 현재 사용할 검증 판본과 기준일 |
| 새 판본 발견 | `새 지역 자료 받는 중`과 전체 용량·진행 상태 |
| 다운로드 완료 | `다음 접속부터 적용 가능` |
| 검증 실패 | 기존 자료 유지와 간단한 실패 원인 |
| 네트워크 단절 | 기존 검증 판본으로 계속 진행 |

정상 다운로드는 게임 흐름을 가리지 않는 작은 상태 표시로 두고, 계약 불일치·저장공간 부족·반복 검증 실패처럼 사용자 조치가 필요한 경우에만 상세 카드를 연다.

## 자원·안전 경계

- 이동통신망 대용량 다운로드 허용 여부는 사용자 설정과 플랫폼 정책을 따른다.
- 지역별 필요한 타일만 받고 전국 자료를 일괄 다운로드하지 않는다.
- 캐시 정리는 활성 세션·저장 결속 판본과 최신 검증 판본을 보호한 뒤 오래된 비결속 후보부터 수행한다.
- 서버에서 검토 중이거나 `distributionApproved=false`인 자료는 다운로드 후보에 포함하지 않는다.

## 미정

- 첫 설치에 포함할 지역 자료 기준선
- 로컬 검증 자료가 전혀 없는 첫 실행·오프라인 처리
- 기본 캐시 용량과 자동 정리 한도
- 업데이트 알림의 사용자 설정 범위

## 다음 질문 하나

첫 설치에 로컬 검증 지역 자료가 하나도 없을 때 어떻게 시작할까?

1. `검증된 사가정역·면목제3·8동 최소 기준선을 게임에 동봉` — 추천. 첫 실행부터 관찰 가능하고 온라인 연결 뒤 최신 승인 판본을 백그라운드로 갱신한다.
2. `첫 실행에서 서버 다운로드를 필수로 요구` — 설치 용량은 작지만 네트워크가 없으면 게임을 시작할 수 없다.
3. `합성 튜토리얼 지역만 동봉` — 오프라인 시작은 가능하지만 첫 경험이 현실 공공자료 기반이라는 목표와 약해진다.
