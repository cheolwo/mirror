## 1. 확정 — 같은 면목동을 세 시간대로 본다

플레이어는 같은 면목동 지도 범위를 오전·점심·저녁 장면으로 비교한다. 건물·도로·관리 매장과 카메라 범위는 같은 조건으로 두고, 각 시간대 자료에 대응하는 대표 군중 표현을 살펴본다. 사람이 드물게 걷는 구간과 작은 무리의 차이를 읽되 정확한 골목 위치/동선은 r180의 가상 분배임을 표시한다.

| 비교 장면 — 확정 | 원본 시간구간 대응 후보 — 미정 |
| --- | --- |
| 오전 | 06–11시 |
| 점심 | 11–14시 |
| 저녁 | 17–21시 |

표의 시간 경계는 기존 수집본의 구간을 이용할 수 있다는 후보이며 이번 사용자 답으로 확정하지 않는다. 구간 길이가 각각 달라 원본 합계를 그대로 순간 밀도로 비교하지 않는다. r180의 사용 열 검증·공급자 정의 확인·비교 가능한 보정/표현 모델이 먼저 필요하다.

같은 기준분기/자료 판본·지도 범위·카메라/축척·표현 척도와 비교 조건을 유지한다. 시간대의 지표에 따른 차이를 보여주며 ‘점심이 가장 많다’ 같은 밀도 순서는 미리 정하지 않는다. 자료상 차이가 작거나 같으면 그 결과를 유지하고 장면 차이를 만들려고 임의로 인원을 증감시키지 않는다.

자료가 미확인되거나 공간 대응/시간대 열 검증이 끝나지 않았으면 해당 장면을 **자료 미확인**으로 표시한다. 별도 합성 예시를 만들 경우 자료 기반 장면으로 보고하지 않는다. 캐릭터 수를 실인구·고객·주문 수로 읽지 않는다.

## 2. 공간 범위와 비교 화면의 후속 결정

‘면목동’이라는 지역 선택과 개별 행정동 모듈 선택을 구별한다. 법정동 면목동 전체인지, 기존 면목 6개 행정동 모듈 중 어느 범위부터 비교할지는 미정이다. 면목본동 하나를 사용자 선택으로 임의 확정하거나 여러 동의 집계를 한 동에 중복 붙이지 않는다.

기존 경계/모듈·집계의 시점과 식별자 대응을 확인한 뒤 정확한 비교 범위를 정한다. 그 범위는 세 장면에서 동일하게 유지한다. 시간대 버튼 전환과 나란히 보기 중 어떤 화면을 사용할지, 인물 수·경로·자산·보정식/상한은 후속 시각/개발 준비 항목이다.

세 장면을 열어보는 것은 비교를 위한 조회/표현이다. 오전에서 저녁 장면으로 바꿔 본다고 게임의 현실 날짜·작업 시각이나 정산을 진행시키지 않는다. 게임/관찰자 모드의 시간·정지·자료 판본 경계는 r174/r180을 따른다.
