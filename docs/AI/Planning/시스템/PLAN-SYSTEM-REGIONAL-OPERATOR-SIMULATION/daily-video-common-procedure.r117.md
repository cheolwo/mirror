## 이번에 정리한 공통 책임

1. 자료 도착·업로드 완료와 실제 처리 시작을 구분한다. 지금은 절차 준비이며, 후속 일괄 요청 시 대상 원본 목록과 입력 판본을 고정한다.
2. 접수/분석 → 선분/건물 연결 → 디오라마 보완/환류의 시작 조건·실제 수행·통과 범위·인계 기록을 정한다. 기존 세부 단계 식별자에 대응시키고 새 저장 상태를 만들지 않는다.
3. 원본·실제 시점·관측·지도/건물/표현 판본·현재 보호·출력 참조·확인/미검토 범위와 복구를 공통 인계 검사로 둔다.
4. 보류에는 이유·마지막 유효 결과·재개 조건·다음 작업을 남긴다. 실패/입력 변경/환류 미완료를 구분하고 해당 범위부터 재개한다.
5. 묶음 목록을 고정하되 원본/구간별 작은 단위로 처리한다. 기존 번호순 대기열을 보존하고 도로 전체 경로의 확정을 독립 건물 관측의 선행조건으로 두지 않는다.
6. 새 결과를 검사한 뒤 참조하고, 일부 실패가 기존 결과를 덮거나 전체 완료로 집계되지 않게 한다. 신규·보완·재사용·비공개 시안·정본 실제 반영을 분리한다.
