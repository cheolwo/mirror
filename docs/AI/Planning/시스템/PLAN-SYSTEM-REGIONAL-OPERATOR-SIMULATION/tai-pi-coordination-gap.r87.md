# [기획 · 배달 플랫폼 운영 캠페인 · PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION · 지천태·천지비 조정 관리자 필요 r87]

- 상태: `Draft / TaiPiOperationalMeaningConfirmed / SharedCoordinatorGapConfirmed / TemporaryCommunicationDistinguishedFromSustainableOrder / ExceptionFirstManagerRoleAsked / NotReadyForImplementation`
- 범위: 제11괘 지천태와 제12괘 천지비의 운영 캠페인 상위 의미
- 제외: 관리자 권한 세부표, 자동화 규칙, Campaign 상태 전이, Graph Map, 디오라마, Unity 구현

## 확정

제11괘 지천태와 제12괘 천지비는 단순히 `소통이 잘됨`과 `소통이 막힘`만을 대비하지 않는다. 두 괘 모두 위와 아래 사이에서 상태를 모으고, 서로 다른 입장을 번역하며, 충돌과 예외를 조정할 관리 기능이 아직 없다는 공통 결손을 드러낸다.

### 지천태 — 관리자가 없어도 당장은 통하는 듯한 상태

- 역할과 자원이 자연스럽게 맞아떨어져 위아래가 서로 통하는 것처럼 보인다.
- 참여자들의 자발적 협력과 초기 호의 덕분에 정상 흐름은 이어질 수 있다.
- 그러나 전체 상황을 보는 조정자가 없으므로 우선순위 충돌·누락·예외·책임 공백을 지속적으로 정리하지 못한다.
- 따라서 지천태의 통함은 완성된 조직 질서가 아니라 `관리 기능 없이도 잠시 성립한 좋은 흐름`이다.

### 천지비 — 관리자의 부재가 실제 불통으로 드러난 상태

- 각 역할은 자기 일과 자기 정보만 보며 위아래가 분리된다.
- 정상 흐름에서 가려졌던 인계 누락·정보 단절·책임 공백이 수요 증가나 예외 사건을 만나 표면화된다.
- 중간에서 서로의 상태를 연결하고 판단을 돕는 주체가 없어 각 부분이 존재해도 전체 운영은 막힌다.
- 천지비는 지천태와 전혀 다른 조직이라기보다, 같은 조정 결손이 조건 악화 뒤 드러난 모습이다.

## 두 괘가 함께 드러내는 필요

```text
자연스러운 협력으로 잠시 통함
    ↓
우선순위·예외·인계 결손 누적
    ↓
소통 단절과 운영 정체
    ↓
중간 조정 관리자 필요를 인식
```

필요한 관리자는 모든 업무를 직접 명령하고 대신 수행하는 지배자가 아니다. 다음 기능을 맡는 운영 조정자다.

- 위·아래와 역할별 상태를 함께 관찰한다.
- 정상 흐름은 기존 OS와 자동화가 계속 수행하게 둔다.
- 서로 다른 표현과 요구를 번역해 필요한 상대에게 전달한다.
- 인계 누락·우선순위 충돌·책임 공백·예외 사건을 찾아 조정한다.
- 결정과 근거를 기록하고 결과가 다시 각 역할에 돌아가게 한다.

## 경계

- 관리자가 서버의 업무 원장이나 각 OS의 생명주기를 임의로 덮어쓰지 않는다.
- Unity의 운영자 표현은 읽기 전용 관찰과 Simulation 정책 선택이며 실제 운영 권위가 아니다.
- 관리자의 존재만으로 지천태가 영구 유지되거나 천지비가 자동 해소되지 않는다.
- 사람의 상하 가치가 아니라 업무 역할 사이의 정보·책임 연결을 관리한다.
