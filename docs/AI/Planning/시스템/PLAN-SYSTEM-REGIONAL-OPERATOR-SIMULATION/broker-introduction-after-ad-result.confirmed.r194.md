## 확정 — 실제 게임 노출과 결과 확인을 첫 경험으로 인정한다

```text
대상 매장의 정식 광고가 게임 고객에게 실제 노출됨
→ 플레이어가 그 광고의 결과를 확인함
→ 첫 광고 경험 완료 · 중개업자 소개 조건 충족
→ 후속 소개에서 제안을 보고 선택
```

광고 설정만 저장한 상태와 실제 노출을 구분한다. 결과 확인에서는 해당 캠페인의 노출·비용·정상 고객 반응을 읽을 수 있어야 한다. 주문이 없거나 손실이 났더라도 노출과 결과 확인을 마쳤으면 경험으로 인정한다. 매출 증가·흑자·특정 검색 순위를 추가 조건으로 두지 않는다.

점주는 자기 매장, 광고업자는 담당하는 가상 고객사 매장의 정식 캠페인으로 같은 기준을 충족할 수 있다. 자기 매장 소유나 전국 광고망 해금을 입문/소개에 일괄 요구하지 않는 r183의 경계를 유지한다.

**소개 조건 충족과 실제 소개 연출은 별도다.** 첫 경험이 끝났다는 사실만으로 진행 중 작업을 중단하거나 NPC 창을 즉시 열도록 확정하지 않는다. 실제 소개 시점과 전달 방법은 아래 미정이다.

소개는 연락/제안의 기회를 여는 것이다. 소개나 제안 열람으로 계약·비용 지급·합성 트래픽·순위 상승을 발생시키지 않는다. 의뢰는 기존 [r177](underground-traffic-broker.gameplay.r177.md)의 조건 확인·선택·확정을 따르는 별도 단계다. 소개 이후에도 의뢰를 거절/보류하고 정식 광고·매장 개선을 계속 선택할 수 있다.

## 미정 — 연출과 의뢰의 상세는 유지한다

- 소개를 같은 날의 안전한 작업 경계, 다음 접속 등 언제 보여 줄지와 NPC/연락 카드의 구체 연출.
- 경험/소개 이력의 저장·기존 플레이어 승계·재소개·거절/보류 후 다시 확인하는 방식.
- 중개 계약 가격·환불·효과/기간·검증/제재·회복, 광고 과금/집계의 상세.
- r193의 화면 배치·페이지당10곳·정확 검색 규칙·개발 명세와 수용.

이 문답은 위 미정까지 승인한 것이 아니다. [r174](live-calendar-daily-management.baseline.r174.md)의 현실 날짜·일일 결산과 부재중 임의 영업 금지, 실제 자료/가상 게임 규칙 구분도 유지한다.
