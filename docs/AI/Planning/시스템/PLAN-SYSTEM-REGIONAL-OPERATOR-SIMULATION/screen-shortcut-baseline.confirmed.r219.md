## 확정한 기본 배치

| 키 | 기본 역할 |
| --- | --- |
| **F1** | 조작·단축키 도움말 |
| **F2** | 현재 동의 관리 창 |
| **F3** | 선택한 내 매장의 운영 창 |
| **F4** | 그 매장의 재료·발주 탭 |
| **F5** | 그 매장의 설비 탭 |
| **F6** | 그 매장의 인력 탭 |
| **M** | 오른쪽 아래 작은 지도 ↔ 업무 요약 |
| **Esc** | 현재 설정 열기/닫기 유지 |
| **Enter / 키패드 Enter** | 현재 결정 순회 의미 유지. 실제 운영 회차 마감으로 재배정하지 않음 |

F2~F6은 화면/탭을 여는 행동이다. 발주·구입·채용·배정·작업 시작을 자동 확정하지 않는다. 같은 점포/동·진행 작업·회차·미확정 초안을 보존하고, 대상이 없거나 지원되지 않으면 선택 필요/현재 지원 범위를 안내한다. 다른 점포의 전역 사본을 대신 쓰지 않는다.

F3은 같은 매장을 다시 열 때 기존 탭/목록·초안을 유지하며 첫 진입의 요약 기본 후보를 따른다. M은 [r217](minimap-default-and-work-summary-toggle.confirmed.r217.md)의 보기 형식 전환이고 미니맵의 동/구 축척이나 접기와 별개다. 새 F키/M은 모달·텍스트 입력·게임 포커스·키 반복/수정키를 구분해야 한다. Esc의 현재 예외/설정 처리까지 이 승인으로 조용히 변경하지 않는다.
