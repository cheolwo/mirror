## 확정

기사 개인 슬롯에 장착한 타로는 해당 기사의 무념 상태를 읽는다. 기사가 무념을 유지할 때는 정방향이다. **무념 상태가 깨지는 순간이 카드가 역방향으로 뒤집히는 직접 원인이다.** 화면에 표시할 역방향 사유는 **무념 상태가 깨졌습니다**로 통일한다. 무념이 다시 성립하면 개인 타로도 정방향으로 돌아간다.

| 기사 상태 변화 | 장착한 개인 타로 | 표시 사유 |
| --- | --- | --- |
| 무념 유지 | 정방향 | 무념 유지 |
| 무념 유지 → 깨짐 | 역방향 | 무념 상태가 깨졌습니다 |
| 무념 깨짐 → 회복 | 정방향 | 무념 회복 |

경 시간은 무념을 더 얼마나 유지할 수 있을지 보여 주는 예상 시간이다. 기사 자신의 무념 상태 전이가 타로 방향을 결정한다. 지사 운영의 배차·교대 정보는 별도로 읽는다.

## 미정

무념 깨짐과 회복을 판정하는 게임 사건, 판정 시점, 방향별 수치 효과를 정해야 한다. 첫 검토에서는 기사 개인 슬롯에 정방향·역방향과 그 사유가 함께 보이는지 확인한다.
