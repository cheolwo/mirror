# [기획 · 운영·시뮬레이션 · PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION · 지천태·천지비 이화 전환축 r106]

- 기준일: 2026-09-17
- 상태: `Confirmed / TaiPiLiTransitionAxisConfirmed / CommunicationGapPreserved / ManagerNeedPreserved / MeaningFirstContinues`
- 선행 판본: [9~16괘 핵심효 중심 국소 삼효상 r105](hex09-16-minority-line-local-trigram.r105.md)
- 범위: 제11괘 지천태와 제12괘 천지비의 9~14괘 사이 전환 역할 확정
- 제외: 실제 관리자 NPC, 운영체제 구현, 상태 전이, 코드·Unity

## 확정

제11괘·제12괘를 `9·10괘의 숨어 있는 이화가 13·14괘의 드러난 이화로 넘어가기 전에, 음양 두 집단의 소통·불통과 중간 조정자의 필요를 시험하는 전환축`으로 해석한다.

## 구조

```text
9 풍천소축 · 10 천택리
다섯 양효 속 하나의 음효
→ 핵심효 주변에 숨어 있는 이괘
→ 작은 업무를 모으고 자리·절차를 밝힘
    ↓
11 지천태 · 12 천지비
양효 셋과 음효 셋의 두 덩어리
→ 같은 기준으로 하나의 이괘·감괘로 축약하지 않음
→ 위·아래 집단의 소통과 불통을 시험
→ 중간 조정자·운영체제·소통 도구의 필요를 발견
    ↓
13 천화동인 · 14 화천대유
이괘가 실제 하괘·상괘로 드러남
→ 공동 행동과 자원·성과를 밝게 다룰 수 있게 됨
```

## 제11괘 지천태

- 위의 곤과 아래의 건이 서로 향해 움직여 일시적으로 통한다.
- 아직 명시적인 조정 체계가 없어도 구성원들의 선의와 상황의 호조로 일이 이어질 수 있다.
- 이 상태는 완성된 질서가 아니라 `조정 장치 없이도 잠시 통하는 가능성`을 보여 준다.
- 운영자는 이때 잘 흐른다는 이유로 구조적 결손을 놓치지 않아야 한다.

## 제12괘 천지비

- 위의 건과 아래의 곤이 서로 멀어지며 같은 조정 결손이 실제 불통으로 드러난다.
- 역할별 정보·책임·언어가 갈라지고, 각자 가진 힘과 사정만으로는 서로를 이해하기 어려워진다.
- 제11괘에서 보이지 않았던 중간 관리자·운영체제·소통 도구의 필요가 명확해진다.

## 전환의 결과

제11괘와 제12괘를 통과하며 플랫폼은 사람의 선의나 우연한 소통에만 기대지 않고 다음을 마련할 필요를 깨닫는다.

- 역할 사이 상태를 번역하는 공통 업무 계약.
- 반복 업무를 연결하는 운영체제.
- 예외와 갈등을 중재하는 관리자 역할.
- 현재 상태와 다음 행동을 알려 주는 소통 도구.

이 보완이 이루어져야 제13괘의 공동 행동과 제14괘의 큰 자원을 실제로 다룰 수 있다. 다만 이번 의미 확정만으로 관리자 NPC나 코드가 자동 생성되지는 않는다.
