## 확정 — 두 가지 표현에 집중한다

**동네에는 사람이 살고 있다는 생활감이 있고, 내가 관리하는 매장은 한눈에 찾을 수 있는 지도**를 목표로 한다. 기존 지도·카메라·업무 화면 위에 회색 배경과 운영 매장의 색 구분, 가벼운 보행 움직임만 더한다.

플레이어는 같은 동네에서 운영 매장을 찾고 그 매장에 집중하거나 기존 업무로 돌아간다. 보행자는 주변 생활감을 보조한다. 입지 추천·수요 힌트·시험 영업·매출·고객 유입 판단은 r142의 별도 기획으로 남기며 이번 표현에 붙이지 않는다. 이 표현은 상위 경영·성장을 돕는 보조 층이며 보행자 수나 매장의 색 변화 자체를 경·소득·성장의 성과로 판정하지 않는다.

## 1. 회색 배경과 운영 매장의 색

| 대상 | 표시 규칙 |
| --- | --- |
| 일반 건물·관리하지 않는 매장 | 형태와 입구를 읽을 수 있는 낮은 대비의 회색. 건물과 도로의 구별은 유지한다. |
| 내가 운영·관리하는 매장 | 간판·차양·입구·매장 앞면을 기존 화면과 맞는 민트 계열로 강조하고 작은 `운영` 표식을 붙인다. |
| 여러 매장이 들어 있는 건물 | 건물 본체와 다른 매장은 회색으로 두고 관리하는 매장 부분만 강조한다. |
| 선택하거나 거래만 한 매장 | 선택 테두리·작은 거래 표식으로 구별한다. 선택·픽업·거래 사실만으로 운영색을 부여하지 않는다. |
| 정확한 매장 부분이 확인되지 않는 곳 | 기존 매장 핀과 `운영` 표식으로 표시한다. 임의의 층·외벽·건물 전체를 운영 매장으로 칠하지 않는다. |

운영 여부는 현재 게임에서 확인된 관리 관계를 읽는다. 직접 운영 또는 관리 대상으로 확인된 가맹점이 대상이며, 같은 브랜드라는 이유만으로 포함하지 않는다. 관리 관계가 없거나 미확인이면 회색을 유지한다. 색을 표시하기 위해 소유·계약 상태를 새로 만들지 않는다. 현재 소비판의 가맹 경영 규칙은 미구현이므로 후속 시안의 예시 운영 매장은 가상 상황으로 표시한다.

확인된 관리 관계가 해제되면 운영색과 `운영` 표식을 제거한다. 매장을 눌러 선택하거나 상세를 닫는 행동은 관리 관계를 바꾸지 않는다. 축소로 앞면을 읽기 어려운 경우에도 기존 핀의 운영 표시를 통해 찾을 수 있게 한다.

### r141 거래 흔적과의 관계

r143은 **회색/운영색의 의미**를 소유한다. r141의 픽업 기반 거래 흔적과 임시·지속 입체 표현은 별도 축으로 보존한다. 거래한 비관리 매장은 낮은 입체 표현이나 작은 거래 표식이 남아도 기본 색은 회색이다. r141의 시안에 표현된 색을 관리 관계의 근거로 사용하지 않는다. 후속 시안·구현에서는 두 규칙을 함께 대조한다.

## 2. 생활감만 주는 보행 움직임

- 작은 회백색 사람 형상이 보도·골목을 따라 걷다가 잠깐 멈추거나 모퉁이를 돌아간다. 첫 동네 검토 화면은 약 10명으로 시작하며 이는 실제 인구 수가 아닌 표현량이다.
- 강한 발광·밀집 빛·업종 말풍선·군중 집중 효과는 넣지 않는다. 사람의 대비와 크기는 기존 기사·주문·운영 매장보다 낮게 둔다.
- 운영 매장과 관계없이 동네 여러 곳에서 움직인다. 내 매장으로 몰려가는 연출이나 손님 전환·구매·매출 계산을 만들지 않는다.
- 검토한 가상 보행 경로를 사용해 건물과 차도를 가로지르지 않게 한다. 기존 도로 중심선 자료를 실제 보도 경로라고 해석하지 않는다. 경로를 확인하지 못한 구간에는 보행자를 배치하지 않는다.
- 보행자는 클릭을 받지 않는다. 기존 매장·기사 선택, 휠 확대·축소와 지도 끌기를 유지한다.
- 축소하면 표시 인원을 줄이고, 가상 일시정지·배속을 따른다. 표시 여부가 주문·정산·도시 상태를 바꾸지 않는다.
- 보행 움직임을 끌 수 있게 한다. 끈 상태에서도 운영 매장 색과 표식, 기존 지도 업무를 그대로 읽고 조작할 수 있어야 한다.

이는 지도에서 재생하는 가벼운 배경 움직임의 기획이다. 사전 제작한 영상을 지도에 붙이는 방식이나 외부 영상 생성·실제 인구 추적을 이번 요구에 추가하지 않는다.

## 3. 첫 시각 검토와 실제 적용의 구분

후속 첫 시각 검토는 **같은 회색 동네에 운영 매장 두 곳과 작은 보행자가 있는 한 화면**으로 한다. 한 곳은 여러 매장이 있는 건물의 일부만 관리하는 예시로 두고, 나머지 건물·매장은 회색으로 유지한다. 운영 관계와 매장 위치는 시안용 가상 설정임을 표시한다.

정적 시안에는 가상 보행 경로를 짧은 설명으로 붙여 걷기·잠깐 멈춤·방향 전환 의도를 확인한다. 정적 이미지가 움직임을 검증한 것으로 보고하지 않는다. 기존 r141의 네 이미지와 r137·Claude 시제품 실행 기록도 r143의 색 구분·보행 검증으로 승계하지 않는다.

이번 완료는 기획 본문과 목차·분야 진입·현재 작업의 연결까지다. 시안 이미지·애니메이션·영상·새 게임 빌드는 생성하지 않는다. 시각 검토 뒤 실제 게임 적용을 인계할 때 승인 판본·hash, 준비된 주체와 WI 하나의 E1~E7 명세, 허용 쓰기 경로와 검증 상한을 별도로 결속한다.

공개 API·계약·저장 형식·운영 상태는 이번에 바꾸지 않는다. 관리 관계는 확인된 상태의 조회 결과를 표현하며 Unity 외형에 상태 확정 권한을 주지 않는다. 실제 관리 관계 조회와 매장 부분 결속이 준비되지 않았으면 후속 개발이 미구현 경영 규칙을 임의로 채우지 않고 그 부분을 차단으로 반환한다.

## 4. 후속 검증 기준

| 확인 장면 | 통과 기준 |
| --- | --- |
| 일반·운영 매장 비교 | 설명 전에도 운영 매장을 찾을 수 있고 회색 배경의 도로·건물 형태를 읽을 수 있다. |
| 복합 건물 | 운영 매장의 앞면만 강조되며 같은 건물의 다른 매장을 내 매장으로 혼동하지 않는다. |
| 위치 불명·관리 미확인 | 확인된 관리 매장의 위치 불명은 기존 핀으로 표시하고, 관리 관계 미확인은 회색으로 남긴다. |
| 선택·거래·관리 해제 | 선택/픽업만으로 운영색이 생기지 않으며 관리 해제 후 색은 제거되고 독립적인 거래 흔적은 보존된다. |
| 걷기·정지·방향 전환 | 검토한 경로 안에서 건물·차도를 통과하지 않고 움직이며 기사·주문·경로를 가리지 않는다. |
| 지도 입력·확대/축소 | 보행자가 클릭을 가로채지 않고 지도 조작과 운영 매장 찾기가 유지된다. |
| 일시정지·배속·움직임 끄기 | 보행은 기존 가상 시간에 맞추며 끈 상태에서도 운영 매장 구분과 기존 업무 조작이 유지된다. |
| 기존 업무 결과 | 보행 표시·운영색·선택·상세 복귀가 기존 주문·배차·가상 정산·거래 기록을 변경하지 않는다. |

문서 단계에서는 링크·경로·diff와 문서 전용 검증만 확인한다. 색과 배치의 판독은 후속 시안, 움직임·입력·업무 보존은 실제 Windows 실행에서 확인해야 하며 이번 문서화로 통과했다고 보고하지 않는다.

## 미정과 다음 검토 하나

회색 배경·부분 매장 운영색·작은 운영 표식·회백색 보행자 약 10명·영상 보류는 승인 기준이다. 정확한 회색/민트 값, 보행 모델·걷기 자산과 속도, 개별 가상 경로는 시각 준비·구현 인계에서 확정한다.

다음 검토 하나는 **한 동네 화면에서 운영 매장의 강조 정도와 보행자의 크기·밀도가 적절한가**다. 이미지·영상 제작이나 실제 적용을 이번 문서 완료에 포함하지 않는다.
