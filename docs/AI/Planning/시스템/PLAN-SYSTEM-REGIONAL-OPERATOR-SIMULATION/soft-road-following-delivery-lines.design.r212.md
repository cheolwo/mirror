## 2. 권하는 모습 — 도로를 따라 매끄럽게 이어지는 선

**도로를 따라 이어지는 가느다란 선에 둥근 이음과 끝처리를 주는 방식**을 권한다. 기존 도로의 꺾임은 유지하고, 구간 사이가 각진 막대처럼 끊겨 보이지 않게 한다. 옅은 가장자리/약한 빛을 더하는 것은 시안 후보이며 정확한 굵기·불투명도는 미정이다.

픽업과 전달 위치는 기존 표식/짧은 이름으로 구별한다. 명시적인 큰 화살촉·전국 지도의 높은 호 형태를 기본으로 붙이지 않는다. 부드러움을 위해 도로 모퉁이를 가로질러 건물/막힌 구역을 통과하는 선을 만들지 않는다. 표현 다듬기가 실제 경로·거리·기사 위치·예상 시간에 영향을 주지 않는다.

방향은 필요하면 **선 위를 목적지 쪽으로 흐르는 작은 빛/짧은 강조**로 보조하는 안이다. 장식 선택형이며 효과를 꺼도 선과 장소/현재 단계로 방향을 읽게 한다. 빛의 이동 속도·개수·음악 박자를 실제 기사 진행률/도착 시간·명덕으로 읽지 않는다.

### 기사 빛과 경로선의 색을 맞춘다 — 사용자 확인

**한 기사의 빛·픽업 접근 점선·전달 실선은 같은 기사 기준색을 공유한다.** 기사빛이 민트 계열이면 두 선도 민트 계열로 읽히게 하는 방향이다. 현 구현에서 전달선이 쓰는 `RiderColor(courier.id)`와 같은 대상 식별/색 연결을 재사용할 후보이며, 접근선의 고정 금색은 기사 기준색으로 맞춘다.

기준색은 화면에서 흰 식별점이나 배경/빛이 합성된 픽셀을 따오는 뜻이 아니다. 기사ID의 공통 표현색을 읽고, 예정/현재·선택 강조의 불투명도·두께를 조절하는 안이다. 명덕 크기/음악 맥동·상태 알림의 순간 밝기가 색의 정체성을 바꾸지 않게 한다. 현재 제한된 A/B 팔레트를 더 많은 기사로 확장하는 규칙은 별도 미정이다.

색을 통일한 뒤 단계는 **접근 점선 / 전달 실선·짧은 상태 문구**로 구분하는 안을 추천한다. 색만으로 어느 기사/단계인지 판단하게 하지 않고 선택 카드의 기사·주문 이름을 함께 읽는다. 아직 기사 미배정인 예정 연결은 다른 기사의 색을 임의로 빌리지 않고 중립 표현/예정 문구를 검토한다. 이 경우의 정확한 색/노출은 미정이다.

## 3. 현재 이동과 픽업→전달 예정 연결을 구분

| 업무 상태 | 현재 이동/확정된 사실 | 제안하는 선의 판독 |
| --- | --- | --- |
| 미배정/추천 검토 | 아직 그 기사가 실제 배달 중인 것은 아님 | 고른 주문의 확인된 예정 경로가 있다면 ‘예정’으로 구별. 운행 중처럼 빛을 흐르게 하지 않음 |
| 픽업하러 이동 | 기사 출발지→픽업 매장이 현재 구간 | 이 구간을 먼저 읽게 함. 준비된 픽업→전달 예정 경로는 옅게 구별하는 후보 |
| 매장 도착/픽업 대기 | 기사는 정차했고 인수 결과를 기다림 | 계획 연결을 유지하더라도 진행 중 선과 구별. 선이 매장에 닿았다고 픽업 완료로 보지 않음 |
| 전달하러 이동 | 픽업→전달 경로를 따라 현재 기사 위치가 갱신됨 | 기사와 두 장소가 이어짐을 읽게 함. 지나온/남은 구간을 나누려면 실제 진행 근거가 필요 |
| 전달/수령·정산 | 각각의 현재 권위 상태가 있음 | 운행 중 강조를 정리하고 해당 상태를 읽음. 실제 수령/정산과 애니메이션 끝을 구분 |

기본 추천은 **선택한 기사 한 명의 현재 단계 경로를 또렷하게, 해당 주문의 다른 예정 연결은 옅게** 읽는 안이다. r189의 ‘남은 구간 선명’은 상세 진행 근거가 준비된 경우의 후속 표현으로 두며 현재 route만으로 통과/잔여 비율을 임의 산정하지 않는다. 기사와 선의 기준색 일치는 사용자 확인이며 정확한 팔레트/위계·완료 후 보존은 제안/미정이다. 취소/재배정은 현재 구현됐다고 전제하지 않고 해당 계약이 준비되는 경우의 후속 판독 조건으로 둔다.

Core에 이미 계산된 배송 경로를 재사용할 자리부터 검토한다. 현재 DTO가 내보내지 않는 전체 경로를 화면에서 임의 새 길찾기로 복원하거나 픽업/전달 사이 직선을 실제 도로 경로처럼 쓰지 않는다. 근거가 없으면 ‘경로 미연결/확인 중’과 목록을 사용한다. 요약 관계선을 따로 쓸 때는 실제 도로 주행선과 구별한다.

## 4. 밀집·동 경계·선택 — 제안

모든 기사/주문 선을 같은 강도로 펼치기보다 선택한 대상의 선을 중심으로 읽는 안이다. 기본 선 노출 범위·미선택 선 생략/약화는 아직 확정하지 않는다. 선은 매장 중심점·기사·주문 알림을 덮거나 클릭/드래그·휠을 가로채지 않게 한다. 카드에서 기사/주문/픽업/전달을 확인하고 같은 대상으로 돌아올 수 있어야 한다.

한 동에서 다른 동으로 배달할 때 같은 기사/주문·경로 판본을 유지한다. 현재 동에 보이는 확인된 구간과 ‘다른 동으로 배달 중’ 안내를 연결하고, 사용자가 원할 때 따라가기/도착 동 보기로 옮기는 r207 후보를 따른다. 경계 밖 점을 숨겼다고 업무를 취소하거나 다른 기사로 재생성하지 않는다. 매 배달마다 카메라를 강제로 이동하지 않는다.

겹치는 경로는 같은 화면 상태에서 선택 대상이 분명한지 본다. 지도 투영/모듈 위치·경계로 선이 어긋나지 않는지, 과거 revision 경로가 남지 않는지 확인한다. 음악/빛 효과 설정이나 동 선택이 실제 길·시간/명덕을 바꾸지 않는 경계를 유지한다.

## 5. Claude에 연결할 작은 검토 — 제안

첫 시안 후보는 **기존 실제 기사/주문 한 건의 현재 경로**다. 기존 각진 선과 부드러운 이음/끝처리의 얇은 선을 비교하고, 픽업 전·대기·전달 중·완료에서 선의 뜻이 맞는지 본다. 다음에 기존 Core 배송 경로의 읽기 전용 투영과 동 경계 연속성을 결속한다. 새 배차/길찾기 엔진이나 가상 주문을 먼저 만들지 않는다.

시안과 실제 입력/저장 검증은 별개다. 미배정 주문의 경로를 진행 중 주문처럼 보여 주지 않고, 선택 변경/패널 닫기·동 이동/귀환·취소/재배정에서 같은 대상과 최신 경로를 읽는지를 후속 명세에 넣는다. 이번에는 시안/코드/게임을 새로 만들거나 실행하지 않았다.

## 6. 확정 / 미정 / 다음 질문 하나

**사용자 방향:** 픽업지·전달지가 부드러운 선으로 이어져 이동을 읽을 수 있게 한다. 큰 호 곡선/뚜렷한 화살표를 전제로 하지 않는다. 점선·실선은 해당 기사 빛과 같은 기준색을 공유한다.

**제안:** 기존 도로 경로를 유지하며 이음/끝을 둥글게 하고 선택한 기사 중심으로 현재 단계와 예정 연결을 구별한다. 작은 빛 흐름은 선택형 보조 후보다.

**미정:** 세부 팔레트/선 굵기/둥글기·강조/기본 노출 범위·예정/진행/완료 구분·움직임 기본값, 미배정 중립 표현·전체 경로 투영/동 경계·시안/검증·실제 개발 수용. 기사색과 선색을 맞추는 방향 자체는 미정으로 되돌리지 않는다.

**다음 질문 하나:** 우선 기존 한 건의 부드러운 선 시안으로 체감을 검토한다. 지금은 방향 기록이며 정확한 선 스타일/선택 전용·기본값을 묶어 승인하지 않는다.
