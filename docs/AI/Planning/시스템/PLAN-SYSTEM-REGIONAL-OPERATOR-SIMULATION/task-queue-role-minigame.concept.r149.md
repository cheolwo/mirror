## 1. 시안에서 읽을 흐름

| 순간 | 플레이어가 보는 것과 하는 일 |
| --- | --- |
| 이완 관찰 | 회색 동네와 색이 있는 운영 장소를 보며 경영한다. 실행 가능한 일이 생기면 하단 작업 원이 채워진다. |
| 작업 선택 | 배달·픽업·커피·피킹·포장·입고 중 원하는 작업을 고른다. 선택한 원에 테두리와 `진행 중`을 표시한다. |
| 현장 진입 | 해당 작업의 장소·역할 화면으로 이동한다. 예시는 창고 내부 선반·통로·포장대와 작업자다. |
| 집중 수행 | 포장 대상의 바코드 중앙에 가로 빨간 선이 왔을 때 Space를 누른다. 선은 위아래로 움직이고 타이밍 뒤 품목을 확인한다. |
| 완료·복귀 | 정식 업무 완료·정산 조건을 만족하면 기본 보상과 자격이 있는 직접 수행 보너스를 확인하고 대기열·경영 화면으로 돌아온다. |

왼쪽과 오른쪽은 **같은 사용자의 전환 전·후**를 나란히 설명한 그림이다. 두 역할을 동시에 직접 조작하는 화면이라는 뜻이 아니다. 여섯 원은 직무별 모양을 비교하기 위한 예시이며 여섯 개의 고정 역할 메뉴를 확정한 것이 아니다.

`현장으로 이동`은 카메라·업무 초점을 해당 장소로 바꾸는 뜻이다. 작업자·물품의 위치나 소유권을 순간이동으로 바꾸지 않으며 실제 접근·수행 조건과 공통 가상 시간은 기존 업무 규칙을 따른다.

## 2. 원 하나는 실제 대기 작업을 가리킨다

- 채워진 원은 현재 수행 가능한 작업, 윤곽만 있는 원은 아직 준비되지 않은 자리의 시각안이다. 채움 자체가 보상이나 업무 완료를 뜻하지 않는다.
- 실제 연결은 역할 분류가 아니라 기존 작업 고유 식별자·장소·담당·현재 단계에 대응한다. 같은 역할의 두 작업도 구별할 수 있어야 한다. 장소명·잔량·대기 시간의 표시 방식과 동일 역할 묶음 여부는 후속 검토다.
- `꺼낸다`는 현재 작업으로 선택한다는 뜻이다. 선택 즉시 작업을 삭제하거나 재고·정산을 확정하지 않는다. 이미 다른 주체가 수행했거나 조건이 달라졌다면 현재 상태를 확인하고 진입 가능 여부를 다시 알린다.
- 대기열은 선택 진입 창구다. 작업을 선택할 때 기존 r146의 안전한 수행 인계로 직접 입력 주체를 한 명으로 정하며, 다른 작업을 만드는 별도 원장으로 두지 않는다.
- 그림의 왼쪽→오른쪽 배치가 강제 선입선출 순서나 자동 배차 정책을 확정하지 않는다. 정렬·우선순위·만료·최대 표시 수는 미정이다.

## 3. 중간 귀환과 보상의 의미

`이완으로 돌아가기`는 언제나 보상 획득 버튼이 아니다. 미완료라면 확정된 스캔·집품·재공품·재료 사용·가방·경과 시간을 보존하고 기존 규칙으로 자동 주체에게 인계한다. 대기열에는 실제 현재 상태를 반영하며 같은 작업의 복제본을 새로 만들지 않는다.

완료 후 보상은 r146/r147의 기본 보상·역할별 상위 구간 직접 완료 자격·정식 정산을 따른다. 큐 선택·화면 이동·스캔 한 번·재시도마다 돈을 주지 않는다. 그림의 선물 표식은 보상 안내이며 재고 이동이나 지급 성공의 증거가 아니다. 금액·지급 귀속·정산 시점의 구체 계약은 이번 시안에서 추가로 결정하지 않았다.
