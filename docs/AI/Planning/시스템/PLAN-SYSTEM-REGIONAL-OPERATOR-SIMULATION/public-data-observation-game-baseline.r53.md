## 첫 제품 목표

첫 제품은 Unity에서 실행하는 `현실 공공자료 기반 지역 관찰 Simulation 게임`으로 둔다.

```text
공식 공공자료
→ 서버 수집·검증·판본화·게시 승인
→ Unity 접속 시 최신 승인 manifest 확인
→ 필요한 지역 자료만 내려받아 로컬 캐시
→ 현실 기준선 디오라마 관찰
→ 별도 가상 생활·운영 Simulation 합성
→ 게임 선택·시간 경과·결과 관찰
```

사용자가 게임에 접속하면 서버가 게시한 최신 승인 자료가 있는지 확인한다. 여기서 `업데이트를 받는다`는 것은 Unity가 원본 기관에 직접 접속하거나 공공자료를 서버에 다시 올린다는 뜻이 아니라, 서버의 검증된 지역 자료 판본을 내려받는다는 뜻이다.

## 자료층 분리

| 층 | 소유자 | Unity 표현 | 변경 권위 |
| --- | --- | --- | --- |
| 현실 기준선 | 서버 공공자료 원장·불변 지역 투영 | 행정동 경계, 도로, 건물, 주소, 필지, 공개 시설·사업장 후보 | 서버의 수집·검증·게시 절차 |
| 가상 생활 상태 | Simulation Core | NPC, 차량, 주문·조리·배달·귀환, 시간·날씨 반응 | 같은 seed·정책·revision의 Simulation |
| 운영 정책 | 서버 또는 Local/Remote 동일 Core의 가상 정책 원장 | 알림, 피크 할증, 예산, 정책 카드와 결과 | 권한 있는 Simulation Command |
| 표현 | Unity | Mesh, 아이콘, 카드, 이동, 카메라, LOD | 표현만 소유하며 현실·업무 사실을 확정하지 않음 |

공공자료가 없거나 오래됐으면 최신인 것처럼 보정하지 않고 `미수집`, `검토 중`, `판본 오래됨`, `표현 불가`를 그대로 보여 준다.

## 접속·동기화 흐름

1. Unity는 자신의 계약 판본과 보유한 지역 자료 hash를 서버에 제시한다.
2. 서버는 `schemaVersion`, `sourceVintage`, `projectionHash`, `readinessCode`, 품질·출처·권리와 타일 목록을 가진 manifest를 반환한다.
3. hash가 같은 타일은 다시 받지 않고 변경된 타일과 새 메타데이터만 받는다.
4. 다운로드는 임시 영역에서 hash·크기·계약 판본을 검증한 뒤에만 활성 캐시로 전환한다.
5. 검증 실패 시 마지막으로 검증된 캐시를 유지하고, 자료 결손과 실패 원인을 표시한다.
6. Unity는 현실 기준선 위에 별도 Simulation 상태 사본을 합성한다.

## 첫 관찰 폐루프

첫 번째로 닫을 게임 흐름은 다음과 같다.

1. 사가정역·면목제3·8동 자료 준비도 확인
2. 최신 승인 지역 판본 내려받기
3. 디오라마 전체 조망과 자료층 켜기·끄기
4. 음식점·기사·주문자 또는 건물 하나 선택
5. 합성 음식배달 정상 생명주기 관찰
6. 기사 부족 같은 운영 사건에서 정책 Preview 또는 기본값 유지
7. 시간 경과 뒤 서비스·재무 결과 비교
8. 저장·종료 후 같은 지역 판본과 Simulation 상태로 재진입

공공자료 갱신 자체를 게임 성과로 취급하지 않는다. 현실 자료는 무대의 기준선이고, 플레이 결과는 별도의 가상 상태와 정책 revision에 남는다.

## 전국 확장 경계

- 클라이언트 계약은 사가정 전용 구조가 아니라 `지역 stable ID + manifest + tile + overlay`로 만든다.
- 첫 실제 품질 기준은 사가정역·면목제3·8동에서 닫되, 다른 행정동은 같은 계약과 증거 관문을 통과해 추가한다.
- 전국 자료를 한 번에 내려받지 않고 사용자가 선택한 지역과 인접 관찰 범위만 캐시한다.
- 지역별 자료 품질과 게시 가능성 차이를 숨기지 않는다.

## 다음 질문 하나

플레이 중 서버에 더 최신 공공자료 판본이 생기면 언제 적용할까?

1. `접속 시 최신 승인 판본을 제안하고, 시작한 Simulation 세션은 선택한 판본에 고정` — 추천. 저장·재현성을 지키면서 다음 접속이나 명시적 재시작 때 새 자료로 전환한다.
2. `플레이 중 즉시 자동 교체` — 최신성은 높지만 건물·도로·주소가 움직여 진행 중인 NPC 경로와 저장 재현성이 깨질 수 있다.
3. `새 게임에서만 적용` — 가장 안전하지만 장기 저장이 현실 자료 갱신을 거의 받지 못한다.
