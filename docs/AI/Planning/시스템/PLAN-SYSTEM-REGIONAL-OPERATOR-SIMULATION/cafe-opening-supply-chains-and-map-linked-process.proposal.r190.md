## 1. 플레이 상황과 목적

**카페 한 곳을 누르면 “개업까지 무엇이 준비됐고, 어디서 누가 어떤 일을 해야 하는가”가 보인다.** 첫 화면은 네 가지 큰 가지로 요약하고 필요할 때 동그란 세부 노드를 펼친다.

- 지금: 선택한 가상 카페가 입점 검토/개업 준비 중인 때. 공간·원료·설비·인력 준비는 병렬일 수 있다.
- 여기: 현재 집중하는 한 행정동의 점포. 필요할 때 같은 세계의 구/전국·시설 내부 정보로 이동한다.
- 나: 가상 점포 운영자 또는 본부 역할의 플레이어. 해당 역할의 권한 안에서 준비 상황을 읽는다.
- 너: 임대/공간·원료 공급·창고·기사·시공/설치·바리스타 등의 준비 결과와 자료. 실제 업체/직원 배정과 역할 후보는 구별한다.
- 이렇게: 점포→개업 준비→가지/노드 선택→관련 지도/자료/다음 행동 확인→점포로 돌아온다. 부족하면 기존 조달/보충·대기·다른 계획 선택으로 회복하며, 보기만 한 것을 발주/인수/개업으로 만들지 않는다.

이 그래프는 준비·협업의 관계를 이해하는 보조 층이다. 노드를 읽는 것만으로 회복·숙련·수익을 적립하지 않는다. 괘·오행을 새 준비 재화나 업무 완료 산식으로 넣지 않는다.

## 2. 네 가지 큰 가지와 합류

| 기본 가지 | 펼쳤을 때의 준비 | 개업 점검에 가져오는 것 |
| --- | --- | --- |
| 공간 | 점포 후보/입점 조건 → 공간·급배수·전기·인테리어, 해당 신고/등록 확인 | 선택한 카페 프로필에 맞는 공간·절차 확인 결과 |
| 원두·재료 | 조달 방식 → 필요한 경우 직접 수입 → 필요한 로스팅·국내 보관 → 원료 납품·인수 | 해당 메뉴의 초기 가용 재료 |
| 설비 | 모델/공급처·재고 선택 → 필요한 경우 제조/조립 → 출고·운송 → 현장 설치·시험·인수 | 선택한 장비의 사용 가능한 상태 |
| 운영 준비 | 담당 인력·레시피·작업 준비 → 시험 운영 | 선택한 메뉴를 실제로 수행할 준비 |

네 가지가 **개업 준비 점검**으로 합류하는 형태를 추천한다. 세부 기준·비용·기간·필수/선택 항목은 운영 프로필과 기존 업무 계약에서 정한다. 원형 노드 개수13개·조건부 연결16개는 자료 색인의 제안 예시이며 승인된 게임 선행조건/법적 순서를 뜻하지 않는다.

제조는 새 주문마다 항상 일어나는 단계가 아니다. **기존 창고의 확인된 가용 재고를 구매하면 제조 가지를 건너뛰고 출고→납품→설치**로 이어진다. 주문 제작을 선택하거나 재고가 없을 때 제조/조립을 검토한다. 실제 가용 재고가 없는데 공장·창고 등록 사실만으로 재고를 채우지 않는다.

원두도 **국내 로스터/도매 재고 구매**와 **직접 수입**을 나눈다. 국내 구매 점주에게 직접 수입자의 절차를 강제하지 않는다. 생두·볶은 원두·추출/혼합 원료는 상품 분류와 필요한 공정을 구분하며, 국내 원료 조달에서도 출처 맥락은 별도로 읽을 수 있다.

r167·r183의 카페 독립 Fixture/가상 파트너를 유지한다. 첫 카페를 열기 위해 별도 Hub·공장·무역 사업을 플레이어가 먼저 설립/완주할 필요는 없다. 상세 공급망은 준비된 외부 공급 연결이나 선택적 심화로 다룬다. Farm/Hub/City 간 운송 사슬을 이번 첫 구현 단위로 지정하지 않는다.

## 3. 원형 노드를 눌렀을 때

점포 카드의 `개업 준비`에서 같은 점포의 그래프를 연다. 첫 화면에는 네 가지 큰 가지와 현재 막힌 이유/확인할 다음 일을 먼저 보여준다. 세부 노드는 펼친 가지에서 읽고, 한 번에 선택 노드 하나의 상세를 표시한다.

| 선택 노드 | 관련 지도/화면 | 강조할 대상·확인 정보 |
| --- | --- | --- |
| 점포/공간 | 동네·건물 내부 | 선택 점포/확인된 공간, 준비 항목·해당 속성/도면 근거 |
| 직접 수입 | 전국 + 국가 관계 자료 패널 | 관측기간/상품별 국가 통계, 확인된 수입 업무가 있을 때 그 작업/거점. 통계만으로 특정 항만을 찍지 않음 |
| 로스팅/국내 보관 | 구 또는 전국, 선택 시설 내부 | 확인된 공급/보관 시설·품목·현재 작업. 등록시설 후보는 후보 목록으로 구분 |
| 기계 재고/제조 | 구/전국, 선택 시설 정보 | 모델/분류·가용/예약, 실제 제조 주체/작업이 연결됐을 때 그 결과 |
| 원료/기계 배송 | 확인된 운송 범위의 동네/구/전국 | r189의 같은 운송 주체·다음 정차·경로·적재/단계 |
| 설치/시험 | 동네·카페 내부 | 선택 장비의 설치 위치·전기/급배수 조건·담당/시험·인수 상태 |
| 운영 준비/개업 점검 | 동네·카페 내부/관련 확인 패널 | 담당·레시피·초기 재고·미충족 항목·기존 다음 행동 |

노드 클릭은 관련 맥락을 보겠다는 명시적인 탐색 요청이다. 준비된 지도에서는 해당 공간으로 한 번 초점을 옮기고 관련 대상만 강조한다. 근거/위치가 없는 노드는 현재 지도를 유지하고 `위치 미확인`·자료/후보 목록을 보여준다. 다른 지역 중심이나 아무 항만을 대신 찍지 않는다.

화면 위에는 `선택 점포 › 원두 준비 › 국내 보관` 같은 현재 문맥과 `점포로 돌아가기`를 유지하는 안이다. 선택 점포/노드·카메라 위치/확대·필터·열어 둔 계획 초안을 보존하고, 이전 위치로 돌아온다. 구 지도 내 서울 전체 연속 축소·구↔전국이라는 r184를 유지하며 독립 서울 단계를 추가하지 않는다.

세계 지도/현재 지구본의 연결은 이번에 새로 구현하지 않는다. 국가 관계를 보여줄 지도 결속이 없으면 전국을 유지한 채 상대국·관측기간 패널로 읽는다. 지도 보기/잠긴 단계 미리보기가 상위 사업 해금이나 직접 수입 권한을 뜻하지 않는다.

## 4. 노드·선·상태의 의미

노드는 짧은 이름과 상태 기호를 가진 원으로, 선택은 테두리로 표시하는 안이다. `미시작/계획/대기/진행/확인 필요/준비 완료/보류`는 표시 후보이며 실제 업무 상태와 결속한 뒤 사용한다. 색만으로 구분하지 않고 키보드/목록에서도 같은 노드를 고를 수 있게 한다.

선의 의미는 범례에서 구분한다. **준비 의존**, **실제 게임의 물건/업무 인계**, **공공 통계 관계/참고**를 같은 확정 운송선으로 그리지 않는다. 두 노드가 연결됐다고 그 사이 기업이 실제 거래한다는 뜻은 아니다. 필요한 자료가 없으면 확인할 조건과 부족한 근거를 표시한다.

지도 강조는 r143의 관리색을 보존한다. 선택한 후보 공장·창고를 내 사업처럼 민트색으로 칠하지 않고 선택 테두리/역할 표식으로 구분한다. 필요한 경우 r189의 운송 표현을 사용하고 기본 간단히·선택 효과를 유지한다. 빛/경로가 끝점에 닿거나 원이 채워지는 연출이 설치·검수·개업 완료를 만들지 않는다.

r188의 선택 사업 자원 요약은 같은 점포의 가용/예약 자금·재고·진행을 읽는다. 예정 구매·견적은 예상으로, 실제 차감·미수/지급·가용/예약 변화는 기존 원장 의미로 구별한다. 등록시설 면적이나 연간 수입금액을 개별 점포의 재고/설비비·단가로 환산하지 않는다.

## 5. 실제 확보한 자료와 부족한 연결

[수집 보고](../../../DataCollection/Research/2026-11-14-cafe-opening-supply-chain-intake.md)가 수량·출처/권리·검증의 정본이다. 공식 신규 원문14개(수치2·메타데이터8·안내4)를 저장했고, 커피 수입 관측9행·기존 커피숍 인허가1743관측·등록창고6011행·장비 조건부 참고16사실·건축 필드정의12개를 분리해 색인했다. 코드 사전의 국가310행·HS6940행도 관측과 구분한다.

새 공장등록·가맹 부담금·조달 물품의 원문은 **카탈로그**이며 개별 공장/모델/브랜드의 실제 관측 데이터 취득은 아니다. 건축 기존8동은 학교부지 표본이라 카페 후보로 쓰지 않는다. 인허가1743건도 현재 현장 영업·가맹/관리 관계·입점 가능 공간을 보증하지 않으며 행정동 후보/좌표계가 아직 확정되지 않았다.

수입통계는 **2025년 한국·상품/상대국 집계**다. 세계합계+선택국, HS4+HS6를 중복 합산하지 않는다. 선택4상대국은 표본이고 실제 원산농장·거래 기업·선박·입항 항만·특정 국내 거점을 증명하지 않는다. 공개 시설 목록끼리 가까운 주소를 잇는 것으로 공급망 사실을 만들지 않는다.

실제 거래/운송/설치 관계, 현재 모델별 가격·재고·납기·시공 견적/BOM·위치/출입구·작업 담당/결과는 미확보다. 검증된 공개 사실, 후보/참고, 가상 시나리오를 각각 표시한다. 로컬 자료 색인의 모든 지도 대상은 현재 미결속이며 게임에 바로 찍을 준비가 끝난 팩이 아니다.

## 6. 제도 노드의 담당과 범위

자료는 주체/행위와 연결한다. 본부의 정보공개서 등록, 수입 주체의 준비, 점포의 해당 업종 영업/공간 준비를 한 점주의 필수 신고 목록으로 합치지 않는다. 정부24의 본부 정보공개서 등록 안내와 식약처의 해외제조업소 등록 안내도 서로 다른 주체/절차 참고다.

관세청의 수입통관 일반 안내와 식약처의 해당 등록 안내를 저장했다. 생두/볶음/추출물의 현행 품목·원산국별 검역/검사, HS/HSK 세분류·세율/비용·기한 전부를 확인한 것은 아니다. 해당 조건은 현재 공식 근거를 추가 검토한 뒤 게임용 프로필과 실제 절차 참고를 구분한다. 게임의 고정 턴/클릭 수를 법정 기한으로 제시하지 않는다. 기존 r170 건축/재건축과 단순 입점·인테리어/설비 설치도 같은 절차로 합치지 않는다.

## 7. 첫 시안/구현 후보와 확인 기준

첫 후보는 **기존 가상 카페 한 곳의 읽기 전용 개업 준비 그래프**다. 공간·원두·설비·운영 준비 네 가지와 선택 노드의 자료/대상, 지도 이동/강조·점포 귀환을 보여준다. 미확인 위치/관계를 정확히 표시하는 상태도 함께 시안으로 검토한다. 모든 발주·수입·제조·창고·차량·설치를 동시에 구현하는 범위가 아니다.

[시안 선행 절차](../../../../Architecture/화면시안선행제작절차.md)에 따라 현재 실제 화면/소스의 재사용 범위를 먼저 대조한다. 이번에는 자료와 문서만 준비했으며 새 이미지 시안·Unity 화면을 만들지 않았다. 이후 승인 판본/hash·기존 주체/WI 재사용·E1~E7 명세·정확한 쓰기 경로/소유와 검증 상한을 결속해 Claude가 별도로 수용한다.

후속 확인 기준:

1. 병렬 가지와 조건부 수입/제조 생략, 각 역할의 책임이 읽히고 국내 조달만으로 시작하는 독립 카페를 유지하는가.
2. 노드→관련 지도/자료→대상 강조→같은 점포/노드/초안 귀환이 이어지며 위치 결측도 읽을 수 있는가.
3. 등록시설/통계·가상 후보·게임 업무를 구분하고, 같은 자료를 클릭해도 신규 수집/발주/지급/재고/설치 완료를 만들지 않는가.
4. 병렬 작업/보류·기존 재고·현장 조건 불충족을 표시하고 기존 복구/대기 경로로 돌아오는가.
5. 노드 조회/카메라 이동/오늘 결산이 추가 Tick·현실 날짜 변경·회차 마감·전체 초기화로 이어지지 않는가. r174/r187의 자연 시간 경과는 별도 유지하는가.
6. 공통 지도/시설/자료 팩의 기존 판본·업무 상태·다른 플레이어/진행 작업·권리 경계를 보존하는가.
