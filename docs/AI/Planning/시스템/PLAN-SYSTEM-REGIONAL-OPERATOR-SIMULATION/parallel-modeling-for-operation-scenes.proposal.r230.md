## 먼저 보이게 할 장면

카페에 주문 한 잔이 들어오면 작업대에 빈 컵이 놓인다. 직원이 준비·추출·조립을 하고, 뚜껑을 닫은 컵이 픽업대로 옮겨진다. 지도에서는 기사 빛이 매장을 향하고, 내부에서는 컵의 자리와 작업 중인 장비를 본다. 플레이어는 작업 하나에 집중하거나 맡긴 채 지켜보고, 완료 뒤 같은 매장 운영 화면으로 돌아간다. 준비·완료·인수의 데이터가 모델의 표시 상태를 결정한다. [커피 공정·지도별 결정 r214](coffee-one-cup-chain-and-multiscale-balance.design.r214.md)

처음 내부 화면은 **지붕을 걷고 제조대를 크게 보는 작은 카페 작업 구역**을 추천한다. 좌석·벽 전체를 꾸미는 작업은 제조 동선이 잘 읽히는지 본 뒤 더한다. 현재 원본 카페 정면 뒤에 실제 내부 평면 자료가 있는 것은 아니므로 내부 구성은 가상 매장으로 기록한다.

카페와 창고의 원본 파일은 별도 작업 경로를 쓰고, 공통 컵·상자·팔레트와 재질은 소유자를 하나씩 둔다. 작업 묶음마다 원본, 출력 FBX, 필요한 텍스처·재질, 치수·연결점, 미리보기, 상태별 표시와 확인 기록을 함께 반환한다. 하나의 거대한 매장·센터 파일에 모든 담당이 동시에 쓰는 방식은 피한다.

회차 안내·배달 인계·일일 결산·고용 명부·명덕 귀속·엔진 연구 규칙은 모델과 별개로 진행할 수 있다. 명덕의 빛, 기사 경로, 수요·광고 수치는 기존 표시·UI·선으로 확인할 수 있다. 홍달 플레이스의 매장 사진은 준비된 점포 모델에서 렌더한 그림을 재사용하는 후속 후보로 둔다.

## 추천하는 첫 발주와 다음 판단

첫 추천은 **카페 장비 한 벌 + 공통 소품 한 벌 + 창고 한 작업셀의 기초 조립**이다. 각각 별도 작업으로 진행하며, 작업자 동작은 이들 치수·골격을 확인해 붙인다. 로우폴리를 고정 조건으로 두지 않고 가까이서 읽는 부품에 곡면과 재질을 사용한다. 첫 장면의 수량·거리·재질과 성능을 함께 보고 다음 제작량을 정한다.

- **확정**은 필요한 모델과 병렬 제작을 지금 기획하라는 사용자 요청, 기사의 지도상 빛 표현, 로우폴리로 제한하지 않는 방향이다.
- **미정**은 내부 화면 시안·제작 묶음의 착수, 실제 장비 종류·치수, 작업자 골격·클립, 원거리 세부 수준과 최종 구매 품목이다.
- **다음 질문 하나**는 “카페 내부의 첫 장면을 제조대 중심으로 크게 보고 컵이 픽업대로 옮겨지는 범위부터 잡을까요?”다.
