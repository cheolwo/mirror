## 1. 제안 — 투자가 일하는 조건을 개선하고 사람의 성장이 이익으로 돌아온다

```text
업무 결과에서 얻은 게임 자본
→ 배차 개선 과제에 투자·준비·비교 시험
→ 새 판단 방침을 선택해 실제 게임 운영에 적용
→ 대기·지연·무리한 일정과 참여자 부담의 변화 확인
→ 참여자별 운영 만족과 안정적인 수행 조건 개선
→ 실제 유효 수행에서 경 유지 기록이 쌓이고 개인이 성장
→ 준비된 수요를 더 안정적으로 이행·정산
→ 참여자 소득과 운영 성과 확인 → 다음 투자/유지 선택
```

투자의 직접 결과는 **사용할 수 있는 판단 기능과 운영 조건의 변화**다. 경 유지 성장과 이익은 그 조건에서 실제 수행된 결과로 확인한다. 투자 버튼에 경 시간·만족도·수입을 한 번에 지급하는 효과를 붙이지 않는다. 이는 기존 r153의 경험 기반 기능 성장과 r133의 사람/소득 목적을 연결하는 안이다.

초기에는 도입/시험 비용으로 가용 자금이 줄고 이후 지연·헛이동·재작업 부담이 감소해 장기 성과가 좋아질 수 있게 한다. 효과가 작은 상황에서는 다른 개선 과제나 기존 방침을 유지하는 선택도 의미 있게 둔다. 모든 업그레이드가 모든 물량에서 이익을 보장하지 않는다.

## 2. 무엇에 투자할까

| 개선 분야 | 음식 배차 후보 | 화물 배차 후보 | 확인할 변화 |
| --- | --- | --- | --- |
| 준비/도착 예측 | 조리 준비와 기사 도착 시점 비교 | 상하차 준비·진입·접안 가능 시간 비교 | 예측 오차·총 대기·약속 이행 |
| 일정 조율 | 다음 픽업·전달과 기존 주문의 여유 비교 | 시간창·중간 정차·차량 기존 약속 비교 | 일정 충돌·지연·재배정 부담 |
| 묶음/자원 조율 | 가능한 합배송과 기사별 부담 비교 | 구간 적재·취급 적합·합짐 후보 비교 | 이동·처리 부담·가용 여유 |
| 회복/권역 대응 | 점심 기사 부족·교대 지원 후보 | 복귀 회차·센터 지연·대체 거점 후보 | 끊긴 흐름 회복·공차/대기·후속 약속 |

필수 적격성·유효 경로·현재 가용·적재/취급·시간창·수락/권한은 성장 전후 동일한 기존 조건이다. 엔진은 후보·이유·예상을 내고 확정은 플레이어/허용된 방침과 Core 명령이 맡는다. 음식 투자 성과가 화물의 자격/성장까지 자동으로 이전되지는 않는다.

투자 항목은 개선할 문제·준비 비용·시험 조건·기대 변화/불확실성·추가 운영 부담을 보여주는 안이다. 정확 금액·준비 기간·유지비·해금/상한은 미정이다. 투자 계획·실제 지출·기능 준비 완료·방침 채택을 구별하고 같은 확인으로 지출을 반복하지 않는다.

## 3. 만족도는 누구의 결과인지 구분한다

| 주체 | 만족/부담의 게임 내 근거 후보 |
| --- | --- |
| 주문 고객 | 약속 대비 지연·취소·수령/인수 결과와 확인된 품질 문제 |
| 기사/차량 수행자 | 총 대기·불필요한 이동·일정 변경·보수/비용·점검/교대 여유 |
| 점포/화주·현장 작업자 | 준비와 픽업/상하차 시점의 일치·재작업·인계 혼선·수행 부담 |
| 경영 운영자 | 서비스 이행·문제 대응 부담·참여자 소득·도입/운영 비용과 성과 |

첫 기획에서는 이를 **분리된 운영 만족 지표/설명 후보**로 둔다. 실제 사람의 감정이나 영적 상태를 관측했다는 의미가 아니다. 단일 종합 점수·가중치·설문 방식·판정 기간은 미정이다. 개인 자기 점검의 ‘작은 여유에도 만족하는가?’와 서비스 만족도 지표도 별개다.

한쪽 대기가 줄어도 다른 곳의 대기·이동·부담이 늘었으면 함께 드러낸다. 고객 만족 상승을 곧바로 기사 개인의 경 시간 증가로 바꾸지 않고, 해당 기사의 안정적인 수행·회복 조건도 확인한다. 만족도와 그 근거인 대기 감소를 각각 별도 배율로 곱해 같은 개선을 두 번 보상하지 않는다.

## 4. ‘깨어 있는 시간’과 개인 성장의 연결

이 제안의 ‘깨어 있음’은 **기사·현장 작업자의 게임 내 경·무념 유지**다. 개인별 상태와 실제로 수행한 게임 기록을 읽는다.

| 항목 | 뜻 | 투자와 연결하는 안 |
| --- | --- | --- |
| 남은 경 시간 | 현재 상태를 얼마나 더 유지할 수 있을지 보여주는 예상 | 현재 업무·부담에 맞춘 상태 조회. 투자비 지출만으로 잔량을 채우지 않음 |
| 유지 가능 시간 | 개인이 준비된 상태에서 시작할 때의 성장 능력 | 기존 자기 점검·수행·정상 종료의 유효 기록을 통해 성장 |
| 확인된 유지 기록 | 게임 업무에서 실제로 유지한 구간 | 개선된 환경에서 안정적으로 수행했는지 확인하는 결과 |
| 근무/가용 시간 | 출근·교대·휴식과 현재 맡은 일의 운영 계획 | 경 지표와 구별해 계획하며 시간 증가만으로 신규 업무를 강제 배정하지 않음 |

r132의 여유 있게 이어지는 픽업·이동·전달 흐름을 첫 연결 근거로 삼는다. 배차 개선으로 불필요한 부담이 줄면 **무념 유지에 도움이 되는 수행 조건**을 만들 수 있다. 그 도움이 어떤 상태/사건으로 작용할지와 강도는 후속 게임 규칙 제안이며 현실의 인과 법칙으로 주장하지 않는다.

개인의 기본 능력·시작 등급과 훈련 성장은 기존 r125/r126처럼 분리한다. 교육/자기 점검·휴식/회복과 실제 유효 수행 기록을 유지하고, 같은 수행을 기존 개인 성장과 엔진 투자 보상에서 중복 가산하지 않는다. 주문 없는 대기·정해진 휴식·보고 열람·분리된 비교 시험을 유효 수행 기록으로 새로 보상하지 않는다. 업무에 결속된 대기의 시간 귀속은 기존 작업·성장 구간 정의를 따른다. 숫자/일별 상한·현실 KST 집계와 기존 가상 영업일의 연결은 실제 명세에서 확인한다.

기사 개인 타로 방향은 기존 무념 상태를 따른다. 엔진 단계나 고객 만족 점수가 개인 카드 방향을 직접 바꾸지 않으며, r174의 절기 운영 카드는 일반 추천 우선순위 역할을 유지한다.

## 5. 장기 이익을 읽는 법

투자 효과는 **같은 참여자·같은 길이의 관찰 구간**에서 비교한다. 신규 인원·수요/날씨·출근시간 변화는 별도로 표시하고 이를 엔진 개선 성과와 섞지 않는다.

- 개인: 경 유지 기록과 그 사람에게 귀속된 보수/소득의 추세. 원장의 비용 범위가 연결되지 않았으면 순소득을 완성값으로 표시하지 않는다.
- 업무: 약속 이행·총 대기/이동·완료/인수·실패와 회복. 픽업 대기 장소만 바뀐 경우도 총 부담으로 확인한다.
- 경영: 기록된 운영 수익/비용과 도입·유지/시험 부담. 게임 내 투자 회수의 비교 근거를 표시하되 결산 화면이 수익을 새로 지급하지 않는다.
- 운영의 한계: 수요·점포 준비·차량/기사·재고·인수 처리 여력이 부족하면 효과가 제한된다. 경 시간이 늘어났다는 이유로 주문이나 수입을 생성하지 않는다.

일일 결산에는 오늘 바뀐 대기·경 유지·참여자 금액과 투자 지출의 근거를, 주간 검토에는 누적 변화와 비용 대비 개선을 읽게 하는 안이다. 절기 변화와 수집 자료 판본은 비교 문맥으로 표시한다. 누락 자료는 개선 없음/만점으로 추정하지 않는다. r174의 보고·정산·지급·시각 기준을 유지한다.

## 6. 첫 검토 후보 — 음식 픽업 대기 개선

1. 같은 기사·주문/수요·도로·준비 조건에서 조리/도착 오차와 총 대기가 큰 구간을 본다.
2. ‘준비 시각 고려’ 개선 과제의 비용/기대 변화/부담을 검토한다.
3. 별도 비교 시도에서 기존 거리 중심과 준비 시각 고려 방침을 같은 외부 조건으로 대조한다. 비교 시도 결과는 실제 플레이의 돈/성장으로 지급하지 않는다.
4. 플레이어가 이후 운영의 방침을 채택한다. 적격성·기존 약속·기사 가용/휴식과 다른 주문의 영향은 유지한다.
5. 실제 운영 기록에서 대기/이동·지연·참여자 금액과 경 유지의 변화가 이어지는지 읽고 다음 투자를 고른다.

준비 예측이 좋아져도 다른 곳의 유휴/이동이 늘거나 보수가 낮아졌다면 그 결과를 드러낸다. 새 기능이 불리하면 이후 추천에 기존 방침을 다시 쓰되 완료/정산·개인 성장 기록을 되감지 않는다. 화물은 같은 투자 틀을 사용하되 별도의 차량/적재/시간창·개인 상태 명세로 검토한다.

기존 구현 대조에서는 Windows의 기사 경·등급 계산은 Unity 쪽 임시 계산으로 확인됐다. 현재 만족도→투자→경 성장의 공통 권위나 화물 개인 성장까지 완료됐다고 보지 않는다. 기획 수용 후 기존 공유 규칙/성장 상태·저장/조회와의 결속이 별도 개발 과제다.
