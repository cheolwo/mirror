## 확정

게임 접속 시 서버의 최신 승인 지역 자료 판본을 확인하고, 시작한 Simulation 세션은 사용자가 선택한 판본에 고정한다.

- 세션은 `administrativeAreaStableId`, `manifestRevision`, `projectionHash`, `sourceVintage`, `schemaVersion`을 저장한다.
- 저장·재생·결과 비교는 같은 지역 자료 판본과 Simulation seed·정책 revision을 사용한다.
- 플레이 도중 더 최신 자료가 게시돼도 활성 세션의 건물·도로·주소·출입구·경계·이동망을 즉시 교체하지 않는다.
- 새 자료는 다운로드·검증·캐시할 수 있지만 활성 세션으로의 전환은 다음 접속, 명시적 세션 재시작 또는 별도 Migration Preview 뒤에만 한다.
- Unity 표현만 몰래 새 판본으로 바꾸지 않는다. 현실 기준선과 표현 타일은 같은 `projectionHash`를 가져야 한다.

## 접속 판정

| 상태 | 기본 의미 |
| --- | --- |
| 서버와 로컬 hash 동일 | 현재 검증된 캐시로 즉시 시작 가능 |
| 새 호환 판본 존재 | 변경량·출처·기준일·품질·예상 용량을 제시하고 다운로드 후보 생성 |
| 계약 판본 불일치 | 호환 Adapter 또는 클라이언트 갱신 없이는 새 자료 활성화 금지 |
| 다운로드·hash 검증 실패 | 실패한 후보를 폐기하고 마지막 검증 캐시 유지 |
| 사용 가능한 캐시 없음 | 자료 없는 상태를 명시하고 지역 디오라마 시작 차단 또는 제한 모드 후보 |

## 저장·재진입

- 기존 저장을 열 때 저장에 결속된 자료 판본이 로컬에 있으면 그 판본으로 재진입한다.
- 서버가 과거 판본을 더 이상 배포하지 않아도 이미 검증된 로컬 캐시는 보존 정책 안에서 사용할 수 있다.
- 새 자료로 옮길 때는 건물·주소·경로 결손, 삭제·분할·병합 대상과 이동 중 Actor 영향을 Preview한다.
- Migration이 실패하면 기존 저장과 자료 판본을 유지한다.

## 미정

- 새 호환 판본의 다운로드가 끝날 때까지 진입을 막을지
- 오프라인에서 마지막 검증 캐시로 시작할 수 있는지
- 지역 자료 캐시 보존 용량과 과거 판본 정리 정책
- 저장 Migration의 첫 지원 범위

## 다음 질문 하나

접속할 때 새 호환 자료 판본이 있으면 다운로드와 게임 진입을 어떻게 할까?

1. `기존 검증 판본으로 바로 시작하고 새 판본은 백그라운드 다운로드` — 추천. 다운로드가 끝나면 다음 세션 적용을 안내한다.
2. `최신 판본 다운로드가 끝날 때까지 진입 차단` — 항상 최신으로 시작하지만 네트워크가 느리면 게임을 못 한다.
3. `사용자가 업데이트를 눌러야만 다운로드` — 통제는 명확하지만 오래된 자료를 장기간 사용할 수 있다.
