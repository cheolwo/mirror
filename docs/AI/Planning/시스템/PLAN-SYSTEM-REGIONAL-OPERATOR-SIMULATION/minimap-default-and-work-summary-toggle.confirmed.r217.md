## 3. 확정한 보기 동작

1. **기본은 작은 지도:** 별도 보기 선호가 정해지지 않은 첫 진입은 A를 기준으로 한다. 현재 위치/선택 동·점포의 위치를 읽는 지도다. 그림의 예시 경계를 실제 경계로 사용하지 않는다.
2. **사용자가 업무 요약으로 전환:** 같은 오른쪽 아래 영역에 시안 B처럼 현재 진행/확인할 업무를 보여 준다. 미구현 작업·가상 시안 건수를 실제 업무로 채우지 않는다.
3. **다시 작은 지도로 전환:** 같은 문맥의 지도로 돌아온다. 바꿀 때마다 다른 매장/동이나 새 작업으로 이동하지 않는다.
4. **전환은 표현 선택:** 선택 동·매장·현재 업무/회차 대상·진행 중 작업·미확정 발주/고용 초안을 보존한다. 집중/이완 모드나 운영권을 바꾸는 행동이 아니다.

전환 명령은 작업/회차를 완료·재시작하거나 시계·돈·재료·명덕을 추가 변경하지 않는다. 정상적인 시간 경과/기존 작업 진행은 계속 기존 규칙을 따른다. 지도/업무 요약 어느 쪽을 선택해도 실제 업무 결과는 동일한 상태 사본을 읽는다.

## 4. 상세 조작과 후속 범위

`작은 지도 / 업무 요약`처럼 이름이 드러나는 전환 조작을 두는 안을 권한다. 머리 탭인지 아래 버튼인지·정확 크기/단축키는 후속이다. **접기**와 **업무 요약으로 전환**은 다른 행동이며, 단순히 숨기기를 누른 것을 업무 요약 선택으로 취급하지 않는다.

같은 세션에서는 선택한 보기로 돌아오는 안을 따른다. 설정·매장 창·다른 지도에서 복귀할 때 미확정 초안/선택을 초기화하지 않는다. 창/지도 전환만으로 A/B를 자동 교체하지 않는다. 재실행까지 선호를 저장할지·세션별/사용자별 범위는 미정이다. 그 선택 전에는 영구 저장을 구현 완료로 보고하지 않는다.

현재 미니맵을 숨기는 오른쪽 카드·r215 왼쪽 매장 창과의 실제 공존/배치는 별도로 결속한다. 숨김/접힘 상태를 복원할 때도 보기 선택과 업무 상태가 섞이지 않아야 한다. 데이터 미준비는 안내하고 현재 대상을 유지한다. 준비되지 않은 지도 때문에 업무 요약으로 강제 전환하지 않는다.

회차 버튼의 정확 책임·위치/이동과 Enter 연결은 r216의 후속 검토를 유지한다. 이번 보기 선택만으로 `Cycle.Press()`를 연결하거나 ‘다음 결정/회차 마감/다음 작업/오늘 결산’을 하나의 명령으로 만들지 않는다. 구 안 서울 전역 보기·구↔전국, 한 동 집중·현실 일일 결산도 유지한다.
