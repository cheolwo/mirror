## 1. 전국 화면에서 보이는 모습

출발 거점의 핀에서 가볍게 솟아올라 도착 거점의 핀으로 내려가는 **아치형 운송선**을 제안한다. 전국의 여러 운송은 배경에 옅게 남고, 사용자가 고른 한 건의 곡선과 양 끝 이름을 선명하게 보여 준다. 가장자리만 부드럽게 번지게 하고, 선택선의 중심과 방향은 읽을 수 있어야 한다.

| 상황 | 표현 |
| --- | --- |
| 미선택 운송 | 가늘고 투명한 곡선. 옅은 청회색을 첫 후보로 삼고 큰 발광은 피한다. |
| 선택한 운송 | 같은 곡선을 조금 굵고 밝게, 출발/도착 이름·현재 운송 상태와 함께 표시한다. |
| 방향 | 정적인 작은 화살표 또는 구별되는 출발/도착 표식으로 읽는다. 색만으로 구별하지 않는다. |
| 같은 두 권역의 여러 건 | 대표 곡선과 실제 운송 건수로 요약하고 선택하면 개별 운송을 구별한다. |
| 반대 방향 운송 | 해당 복귀/반대편 운송이 실제로 있을 때만 표시한다. 양방향을 함께 고르면 곡선을 약간 벌려 겹침을 줄일 수 있다. |
| 미리 보는 후보 | `후보` 표시와 다른 선 모양으로 확정 운송과 구분한다. 그림이 생겼다고 출발한 것으로 보지 않는다. |

곡선 높이·폭·투명도·번짐 정도는 시각 검토 전 미정이다. 높은 아치를 더 좋은 운송·더 빠른 이동·더 높은 비행 고도로 해석하지 않는다. 지도 확대/이동 뒤에도 같은 거점에 붙어 있고 휠 조작 때 휘는 방향이 갑자기 뒤집히지 않게 한다.

## 2. 운송 관계와 실제 도로 경로

곡선은 **어디에서 어디로 운송하는지**를 설명한다. 선택한 운송의 상세에서 확인된 도로 경로·남은 정차 순서를 별도로 읽을 수 있게 한다. 아치의 길이·높이·휘는 모양으로 거리·시간·운임·ETA를 계산하지 않는다. 선이 산·바다 위를 지나 보이더라도 실제 주행 가능이나 별도 운송 연결이 확보됐다는 뜻이 아니다.

정확한 거점 좌표가 확인되면 그 위치를 사용한다. 권역 집계만 있으면 `권역 요약`임을 표시하고 해당 권역의 확인된 표시 앵커를 쓰며, 이를 실제 센터 위치로 표시하지 않는다. 좌표가 불명인 개별 운송은 주변 거점이나 지역 중심에 임의 배치하지 않고 기존 목록에서 확인한다.

중간 정차가 있는 운송은 현재 권위 일정의 인접 정차를 연결한다. 전국 요약을 위해 일부를 묶더라도 중간 상하차가 사라진 단일 직행 운송처럼 표시하지 않는다. 복귀 후보는 확정된 복귀 운송과 구별하며 편도 배차에서 왕복 주문을 자동 생성하지 않는다.

## 3. 기존 핀·파동과 공통 처리

기존 r154의 상태/사건 관찰·중복 확인·위치 해석과 지도 투영을 함께 사용하도록 제안한다. 현재 상태에서 유지하는 곡선과 새 사건에 한 번 쓰는 낙하/파동은 다른 표현 프로필이다. 새로 지도를 열거나 축척을 바꿔도 같은 운송이 다시 출발한 것처럼 재생하지 않는다.

- 핀 낙하와 파동은 `새 사건을 알아차림`, 아치형 선은 `운송 관계`, 상세 도로선은 `확인된 주행 경로`를 맡는다.
- 운송선의 생성·강조·선택·그리기 완료가 배차·출발·도착·배송/하차 완료·정산을 실행하지 않는다. 취소/완료 상태가 바뀌면 최신 상태를 읽어 선을 정리한다.
- 대표선 개수와 실제 운송 건수를 구별한다. 필터·집계·화면 밖 처리로 화물/차량 상태를 삭제하지 않는다.
- 일반 선은 지도 입력을 가로채지 않는다. 선택이 필요한 경우 기존 안정 표식·목록과 같은 운송 ID에 연결하고 지나치게 좁은 곡선만 클릭하도록 강제하지 않는다.
- 곡선은 업무 패널·선택 표식·중요 알림을 가리지 않게 한다. 시설의 운영색과 지역 선택의 의미도 보존한다.

## 4. 선택하지 않은 움직임과 후속 검토

선 위로 작은 빛이 출발→도착 방향으로 천천히 흐르는 표현은 후속 선택지다. **이번 사용자 요청으로 자동 채택하지 않는다.** 채택한다면 방향 안내인지 실제 운송 진행률인지 먼저 정해야 하며 장식 이동을 차량의 GPS 위치나 도착 예측으로 표시하지 않는다. 움직임 감소에서는 정적인 방향/문구로 같은 정보를 유지한다.

후속 시각 검토는 한 곡선의 기본/선택, 여러 겹침·양방향·후보, 지도 확대/이동·패널 가림을 우선한다. 실제 구현 시에는 같은 운송 ID/Revision과 핀·곡선·상세 정차의 일치, 재조회/복원·취소/완료·움직임 감소와 업무 상태 불변을 확인한다. 이번에 새 시안 이미지·애니메이션·Unity 실행을 만들거나 검증하지 않는다.

- **확정된 사용자 방향:** 전국 운송 연결은 옅고 부드러운 아치형 곡선으로 표현하고 싶다는 방향을 기록한다.
- **미정:** 세부 색·투명도·굵기·곡률·집계 방식·상태별 표현과 선 위 움직임. 기존 전국 배차의 첫 역할/시범 회차도 별도 미정이다.
- **다음 질문 하나:** 곡선 위에 작은 빛이 출발→도착으로 천천히 흐르는 **방향 안내**도 넣을까? 실제 차량 위치와 구분되는 약한 표현을 후보로 제안한다.
