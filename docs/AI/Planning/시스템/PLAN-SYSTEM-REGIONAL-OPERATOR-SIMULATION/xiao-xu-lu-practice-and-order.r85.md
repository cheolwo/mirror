# [기획 · 배달 플랫폼 운영 캠페인 · PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION · 풍천소축·천택리 실천과 정돈 r85]

- 상태: `Draft / XiaoXuLuOperationalMeaningConfirmed / LearningPutIntoPracticeConfirmed / OverlookedWorkOrganizedConfirmed / OrderBeginsToEmergeConfirmed / NotReadyForImplementation`
- 범위: 제9괘 풍천소축과 제10괘 천택리의 운영 캠페인 상위 의미
- 제외: 효사별 사건, 정확 업무 목록·수치, Campaign 상태 전이, Graph Map, 디오라마, Unity 구현

## 확정

제9괘부터 제10괘까지는 제1괘부터 제8괘까지 배우고 익힌 것을 실제 운영에 옮기는 시기다. 실천을 시작하자 그동안 미처 살피거나 정리하지 못했던 사람·자원·역할·절차·기록의 결손이 드러나고, 이를 하나씩 정리하면서 운영 질서가 잡히기 시작한다.

### 제9괘 풍천소축

- 배운 내용을 작은 실천으로 옮긴다.
- 흩어진 자원·정보·신뢰·절차를 한꺼번에 장악하려 하지 않고 조금씩 모은다.
- 실제로 움직여 보아야 발견되는 누락과 미정리 항목을 찾아낸다.
- 아직 질서가 완성된 것은 아니며, 운영을 정돈할 재료가 모이기 시작한 단계다.

### 제10괘 천택리

- 풍천소축에서 모으고 발견한 항목을 실제 역할·권한·책임에 맞게 배치한다.
- 누가 무엇을 하고, 어디까지 결정하며, 어떤 기록을 남겨야 하는지 정리한다.
- 정돈된 기준을 따라 업무를 수행하면서 처음으로 반복 가능한 운영 질서가 나타난다.
- 이 질서는 아직 작고 흔들릴 수 있으므로, 완성된 제도나 안정 운영으로 승격하지 않는다.

## 두 괘의 연결

```text
1~8괘에서 배운 것
    ↓
작게 실천함
    ↓
미처 정리하지 못한 결손이 드러남
    ↓
자원·역할·절차·기록을 정돈함
    ↓
운영 질서가 처음 형상을 갖춤
```

따라서 제9괘와 제10괘의 중심은 `작은 축적 → 경계 있는 실행`이라는 추상적 표현보다 `배운 것을 실천하면서 드러난 미정리 업무를 정돈해 첫 질서를 만드는 과정`에 둔다.

## 경계

- 괘의 의미만으로 누락 업무나 정책을 자동 생성하지 않는다.
- 실제 결손은 음식배달 OS·운영 원장·관찰 자료에서 확인한다.
- 정돈 결과는 Simulation 기획이며 실제 운영 정책이나 Unity 구현을 자동 승인하지 않는다.
- 사람을 통제하는 것이 아니라 업무의 책임·권한·정보 흐름을 정돈한다.

## 미정

- 제11괘와 제12괘에서 이 첫 질서가 잘 통하는 경우와 막히는 경우를 어떻게 경험할지
- 사가정·면목제3·8동에서 첫 정돈 대상으로 삼을 구체 업무
