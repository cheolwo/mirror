## 확정한 사용 흐름

1. 경영 지도를 보다가 **M키**를 누른다.
2. **직사각형 선택창 안에 행정동 디오라마 카드**들이 나타난다.
3. 보고 싶은 동의 카드를 클릭한다.
4. 메인 지도에 해당 동의 디오라마가 표시되고 그 동을 볼 수 있는 위치로 이동한다.

행정동 이름·코드와 모듈 고유 식별자를 함께 사용한다. 같은 이름의 다른 동은 구 이름으로 구별한다. 목록의 화면 순서를 저장 키나 지도 위치로 사용하지 않는다. 지도를 바꾸는 행동만으로 고용·입점·발주·정산·턴 마감을 수행하는 규칙은 추가하지 않는다.

## 선택창의 첫 시안 제안

화면 가운데에 직사각형 창을 두고 카드를 여러 열로 배치한다. 카드 하나에는 **해당 동의 작은 디오라마 미리보기, 구·동 이름, 현재 보고 있는 동 표시**를 둔다. 여러 동을 오갈 때 미리보기의 지형·큰길·건물 배치로 장소를 알아볼 수 있게 한다.

미리보기는 해당 모듈의 실제 건물·도로·경계에서 만든 정적 썸네일을 우선 권한다. 동일한 시점·조명·배율 기준으로 만들고 썸네일과 모듈 판본·내용 지문을 연결한다. [공통 생성 절차](../../../../Architecture/행정동디오라마공통생성절차.md)와 기존 [65동 비교 검토](../../../Handoffs/2026-11-15-Codex-기사빛-행정동-디오라마-r4.md)의 자료를 재사용할 수 있다.

카드를 클릭하면 선택창을 닫고 해당 동 전체가 보이는 「이 동만」 보기로 들어가는 것을 첫 제안으로 둔다. 현재 동을 다시 눌러도 같은 동의 경계에 시점을 맞춘다. M을 다시 누르거나 창의 닫기를 누르면 이동 없이 닫는 안을 권한다. Esc는 이 창이 열렸을 때 창 닫기를 먼저 처리하고 평소에는 기존 설정 역할을 따른다.

목록이 길어지면 스크롤을 제공한다. 첫 시안에서 정확한 열 수·창 크기·정렬을 비교한다.

## 카드와 지도 이동의 연결

- 카드에 사용할 목록은 해당 소비판의 지도 명세에서 읽는다. 동 이름을 직접 나열한 별도 목록이 실제 로딩 상태와 어긋나지 않게 한다.
- 로드된 모듈·경계·건물 색인이 같은 판본인지 확인하고, 카메라 이동을 끝낸 뒤 현재 동 표시를 갱신한다. 역 중심 보기의 같은 판 안에서도 실제 목표 동으로 이동해야 한다.
- 목록 전체에 미탑재 동을 보여 주는 후속안을 쓰면, 카드에는 자료 상태와 현재 이동할 수 없는 이유를 표시한다. 다른 동의 썸네일·건물을 대신 연결하지 않는다.
- 읽기 실패 시 기존 지도·선택·진행 중 초안을 보존하고 카드에서 이유를 읽을 수 있게 한다. 실패한 이동을 완료 상태로 표시하지 않는다.
- 동 이동은 화면의 관심 지역을 바꾸는 흐름이다. 다른 동에 열려 있던 발주·점포 초안은 원래 동·매장 식별자를 유지한다. `OpenDongDesk`가 고용·관리 창까지 여는 동작을 단순 이동에 섞지 않는다.
- [개인 픽업 위치 검사 r234](pickup-location-verification-before-lighting.research.r234.md)의 자료를 함께 볼 때에도, 기록이 있다는 이유로 소유 매장이나 경영 해금으로 판정하지 않는다. 선택창은 같은 동 이동을 제공하고 기록 레이어의 선택은 해당 레이어가 맡는다.

## Claude에 넘길 시안과 확인 항목

첫 시안은 현재 실행판에서 읽는 여섯 동을 카드로 보여 주고, 현재 동과 옮겨 갈 동이 함께 보이는 한 장면이다. 다음에는 선택 전·선택 후를 같은 판본으로 비교한다. 첫 시안에 일반판과 별도 r4의 여섯 동 목록을 섞지 않는다.

검토할 상호작용은 M 열기, 카드 선택과 실제 카메라 이동, M 다시 열기/닫기, Esc 닫기와 설정 중복 방지, 같은 동 재선택, 긴 목록 스크롤이다. 카드 위의 클릭·휠이 뒤의 건물 선택·지도 줌·입점으로 새지 않는지도 확인한다. 글 입력·수정키·키를 계속 누르는 경우·설정과 정책 창의 우선순위는 기존 단축키 경계와 함께 대조한다.

이미 구현한 M 전환의 도움말·알림 문구와 `keyM/keyMBack` 검사도 새 의미로 갱신할 대상이다. 기존 업무 요약의 화면 버튼은 같은 기능을 수행하는지 별도로 확인한다. 실제 키보드 입력·모듈 로드·지도 이동·다시 닫기의 Unity 화면 검증은 개발 반환에 기록한다.

**확정**은 M으로 행정동 디오라마 선택창을 열고 카드를 클릭해 해당 지도에 가는 흐름이다. **제안**은 중앙 카드 창·정적 미리보기·선택 후 닫기·「이 동만」 진입과 M/Esc 닫기다. **미정**은 창 위치·크기·열 수·정렬, 마지막 시점 기억과 전체 목록 범위다. **다음 질문 하나**는 Claude 시안에서 중앙 직사각형 카드 창의 위치와 크기가 관리 지도를 오가기 편한지다.
