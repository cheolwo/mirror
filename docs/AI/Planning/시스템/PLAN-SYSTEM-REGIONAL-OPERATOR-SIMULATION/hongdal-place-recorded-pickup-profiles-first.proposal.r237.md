## 2. 먼저 경험할 흐름

**홍달 플레이스 열기 → 내 기록에 있는 음식점 찾기 → 기본정보·메뉴 근거·내 배달 요약 읽기 → 지도에서 보기 → 이후 빛과 연결**을 권한다.

처음에는 날짜 하나나 행정동 하나로 목록을 줄일 수 있고, 같은 지점의 전체 기록도 펼쳐 볼 수 있다. 빛이 보이기 전부터 사용자는 어떤 음식점인지, 어느 주소인지, 내가 어떤 날 기록했는지 알아볼 수 있다.

기록 장소에는 로컬 전용의 안정적인 프로필 ID를 주고 기존 branch_id를 보존한다. 이름·주소 문자열이나 목록 순서를 ID로 삼지 않는다. 같은 건물에 음식점이 여러 곳이면 각 지점의 프로필을 유지한다. 공공 인허가 관리키와 건물 ID는 출처 관계로 연결한다.

주소·좌표가 없는 곳도 목록에서 상호와 남아 있는 기록을 읽는다. 지도 연결이 준비된 장소에는 해당 건물로 가는 행동을 제공하고, 미해결 장소에는 어떤 정보를 더 확인해야 하는지 표시한다. 다른 매장의 핀을 가져와 채우지 않는다.

배달비를 메뉴 가격으로 사용하지 않는다. 대표 음식명에 가격이 없는 원본은 가격을 미입력으로 유지한다. 개인 배달 기록의 상세 옵션·고객 정보·전달 주소·원시 주문번호는 프로필에 복사하지 않는다.

첫 시안에서는 기본정보와 내 기록을 우선하고, 실제로 준비된 메뉴 관측이 있을 때 해당 영역을 펼쳐 볼 수 있게 한다. 사진·후기·영업시간이 빈 영역을 임의 값으로 채우지 않는다.

## 4. 실제 기록 장소와 내 게임 매장

홍달 플레이스 한 곳에서 다음 문맥을 제공하는 안이다.

- **내 기록의 음식점**에서는 이번 로컬 기록에 있는 장소와 공개 자료의 정보를 읽는다. 개인 방문 날짜·빈도는 해당 사용자의 로컬 요약에서만 가져온다.
- **내 게임 매장**은 기존 r195의 게임 사업자등록 완료에 따른 자동 등재 방향을 따른다. 운영 정보·판매 메뉴·광고·게임 고객 경험은 해당 게임 점포의 상태를 읽는다.

이 둘의 관계는 표시용 분류와 명시적 연결로 관리한다. 개인 픽업 지점, 공공 인허가, 게임 점포의 ID를 각각 보존한다. 두 목록에 같은 상호가 있어도 자동으로 같은 운영 주체에 배정하지 않는다.

개인 기록 프로필의 열람과 검색은 조회 행동이다. 가상 고객의 광고 노출·일반 검색 반응·주문·돈·명덕을 만드는 입력은 기존 시뮬레이션이 별도로 판정한다. 실제 기록 장소에 가상 중개업자 평가나 이용후기를 붙이지 않는다. [검색·고객 행동의 기존 경계 r193](station-keywords-and-in-game-place-pages.proposal.r193.md)

## 5. 로컬 자료와 지도 빛의 연결

이번 [자료 초안](../../../../../artifacts/local/hongdal-place-delivery-profiles-20261115/profiles/summary.json)은 배달과 연결된 864지점을 대상으로 한다. 기본 프로필과 개인 방문 요약을 나눠 보존하고, 공공 정보는 정확한 원본 연결이 있는 범위만 추가한다.

준비한 파일은 기본 프로필, 개인 방문 요약, 개인 메뉴 관측이다. 353곳에는 정확한 인허가 연결, 289곳에는 인허가 주소의 층 표현, 318곳에는 위치 시안 후보 상태가 있다. 이 수들은 서로 겹친다. 공공 허가번호로 연결한 대표 메뉴는 이번 개인 지점 집합에서는 한 곳의 한 관측이며, 나머지 메뉴를 다른 음식점의 메뉴로 채우지 않았다.

개인 메뉴 관측 598지점은 원래 앱 행의 해시·날짜와 기존 배달 기록의 명시적 연결을 대조했다. 연결된 앱 기록 1,007건 중 상세 메뉴를 읽을 수 있는 999건을 사용했고, 옛 원장 574건의 방문 단위 메뉴는 개별 주문에 자동 배분하지 않았다. 현재 판매 여부·가격·전체 메뉴를 확정한 값으로 쓰지 않는다.

프로필은 기존 지점의 안정적인 ID로 재조회한다. 공공 자료 보완이나 지점 별칭을 확인해도 같은 프로필의 출처 관계를 갱신한다. 이름 변경·주소 변경·관측 시점 차이는 이력으로 남긴다. 지점 병합·분리가 필요하면 근거와 예전 ID의 참조를 보존하는 후속 처리를 정한다.

r235는 익명 빛 표현용 파일을 제안했다. 여기서는 개인이 보는 실명 프로필을 로컬 자료로 준비하고, 빛은 불투명 지점 ID로 그 프로필을 찾아가게 한다. 공유·시안용 익명 표현과 개인이 읽는 상세 정보의 소비 경로를 연결하는 확장이다. 현재 사용자에게 실제 매장명을 보여 주는 작업을 익명 시안만으로 대체하지 않는다.

개인 자료를 연결하거나 끄는 동작은 해당 로컬 목록의 수명에 적용한다. 공공 배포 팩이나 공용 장소 순위에 방문 이력을 합치지 않는다. 게임 점포의 개점 상태나 경영 원장을 바꾸는 명령으로 취급하지 않는다.

첫 화면의 배치·열기 위치·탭 수·목록 정렬과 기간 기본값은 시안에서 검토한다. M키는 r236 행정동 선택의 의미를 따른다. 기존 점주용 명령창을 실제 픽업 매장의 상세로 사용하지 않는다.

인허가 연결 353곳과 미연결 장소, 층 충돌, 메뉴·사진 미수집, 같은 건물의 여러 매장, 좌표 없는 장소, 취소만 기록된 장소를 검토 사례로 둔다. 같은 입력을 다시 읽을 때 프로필과 방문 건수가 늘지 않는지, 조회·검색·지도 왕복 뒤 기존 날짜·주문·돈·명덕이 그대로인지도 확인한다.
