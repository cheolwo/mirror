# [기획 · WPF 우선 고도화 · PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION · r139]

## 확정

당분간 기존 Windows WPF 실행판에서 홍달 경영 시뮬레이션의 데이터 관계·게임 규칙·업무 흐름을 고도화한다. 지금은 3D 표현이나 Unity·모바일 전환을 개발의 선행조건으로 두지 않는다. WPF에서 충분히 검토한 뒤 사용자가 전환 필요를 다시 선택하면 Unity가 같은 공통 코어를 소비하도록 한다.

현재 WPF는 `Ssalddel.Sagajeong.Core`를 직접 참조한다. 이 코어는 .NET Standard 2.1이며 Unity·Android 없이 실행된다. 따라서 이미 만든 공통화는 유지하고 모바일 화면·문서 포트·검토 결과도 후속 참고로 보존한다. 코어를 WPF 안에 다시 복제하거나 기존 코드를 되돌리지 않는다.

## 고도화 기준

- 기존 음식 배달 회차의 주문·매장·기사·경로·수량·상태·가상 정산 관계부터 명확하게 한다. 구현되지 않은 기능이나 데이터 연결을 완료로 표시하지 않는다.
- 음식·화물·창고·가맹점은 기존 기능과 승인된 기획의 범위에 따라 한 구간씩 검토한다. 전체 영역의 새 구현을 이번 방향 변경만으로 시작하지 않는다.
- 현실 자료의 비공개 연습 활용, 게임 결과의 검토 후 운영 계획 활용, AI 경험의 출처·사람 검토·평가 구분은 유지한다. 가상 실적·금액을 실제 원장으로 합산하지 않는다.
- WPF에서 업무 규칙과 데이터 계약을 정리하고 확인한 뒤, Unity 전환에서는 가능한 한 표현·입력 부분을 교체한다. 시점·그래픽·플랫폼은 전환 때 다시 결정한다.

## 미정·보류

Unity 재개 시점과 모바일/3D 표현 방식은 미정이다. Android 빌드 모듈 설치·공간 확보·APK·기기 검증은 현재 WPF 작업의 선행조건이 아니다. 기존 예약을 재개하거나 추가하지 않는다. 이번 회차는 방향·우선순위 기록만 바꾸며 제품 코드·화면·실행판은 변경하지 않는다.
