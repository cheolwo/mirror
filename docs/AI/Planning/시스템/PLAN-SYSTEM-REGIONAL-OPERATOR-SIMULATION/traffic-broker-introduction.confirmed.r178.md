## 확정 — 정식 광고를 경험한 뒤 중개업자를 소개받는다

플레이어는 먼저 가상 매장의 정식 광고를 한 번 경험한다. 그다음 트래픽 중개업자를 소개받고, 정식 광고와 다른 제안을 비교할 수 있다. 처음부터 두 경로를 한꺼번에 제시하는 순서는 채택하지 않는다.

```text
정식 광고를 한 번 경험
→ 트래픽 중개업자 소개
→ 제안 확인과 선택
→ 선택한 경우 중개 의뢰의 비용/조건 확인·확정
```

게임 안의 상황은 광고를 경험한 점주가 같은 동네의 매장 경영 중 새 인물을 소개받는 것이다. 플레이어는 앞서 본 광고 노출/유입과, 중개업자가 주장하는 일반 검색 순위 상승을 비교한다. r177의 비용·효과/불확실성·운영 여력과 위험을 판단한 뒤 같은 매장 경영으로 돌아온다.

**소개는 계약이 아니다.** 소개나 제안 열람만으로 비용 지급·중개 트래픽·순위 변화가 시작되지 않는다. 수락·거절·나중에 검토 같은 응답 방식은 상세 화면 후보이며, 실제 의뢰는 별도 조건 확인/확정을 거치는 r177의 경계를 유지한다. 소개를 받은 뒤에도 정식 광고·매장 개선을 계속 선택할 수 있다.

## 미정 — ‘광고를 경험했다’는 완료 기준과 구체 연출

- 광고 설정/계약, 실제 게임 내 광고 집행/노출, 결과 확인 중 어디까지를 첫 경험의 완료로 볼지.
- 경험 완료 뒤 같은 날의 안전한 작업 경계에서 소개할지, 다음 접속/다음 날 소개할지와 소개 연출·연락 방식.
- 경험/소개 이력의 저장 범위, 이미 경험한 플레이어의 승계, 거절·보류 후 다시 만나는 방식.
- 중개 계약 가격·지급/환불·효과/기간·검증/제재/회복, 정확 화면·WI/구현 범위.

광고의 성공·매출 증가·특정 순위 달성을 소개 조건으로 추가 승인한 것은 아니다. 위 완료 기준과 연출은 개발자가 임의 확정하지 않는다. 시간·부재중 처리·실제 음식점 관찰 자료의 분리는 r174/r176/r177을 유지한다.
