[거점 경영 목표 r2](daekan-participant-awakening-and-income.proposal.r133.md#거점-경영-목표-r2--첫-승리와-각-구성요소의-역할)는 지도에서 고른 운영 선택이 거점의 영업 결과와 함께 일하는 사람의 경·소득에 어떤 변화를 주었는지 결산에서 함께 읽는 구조를 제안한다.

```text
홍달 플레이스 · 00 오행 총괄판
├─ 어디를 보고 있는가 · 지도
│  ├─ 전국 지도 · 넓은 사업권과 거점
│  └─ 구 지도 · 역을 골라 들어가는 화면
│     └─ 역 · 주변 칸과 성장 결과를 보는 거점
│        └─ 행정동 · 운영과 데이터를 연결하는 칸
│           └─ 장소 · 음식점, 픽업지, 전달지
├─ 누가 맡는가 · 운영
```

## 혼동하기 쉬운 연결

| 개념 | 기준과 연결 |
| --- | --- |
| **역과 행정동** | 역은 플레이어가 주변 칸을 살피는 거점이다. 행정동은 인구·매장 자료와 업무 위치를 연결하는 칸이다. 현재 사가정역에서 면목5동·면목7동·면목3·8동을 보는 구성을 재사용한다. 여러 역이 한 동을 둘러볼 때 성장 실적을 어느 역에 표시할지는 별도 규칙으로 확인한다. |
| **행정동과 지사** | 행정동은 장소의 소속을, 지사는 주문을 맡은 운영 주체를 가리킨다. 한 지사의 배달권은 여러 동으로 확장될 수 있다. 픽업지와 전달지가 다른 동이어도 배정 지사와 주문 번호를 계속 사용한다. |
| **내 매장과 제휴 음식점** | 내 매장은 직접 운영하는 사업이다. 제휴 음식점은 주문을 준비하고 지사와 함께 처리하는 협력 상대다. 같은 음식점이 지도·플레이스·주문 상세에 보일 때는 같은 장소 식별자로 연결한다. |
| **세트와 주문** | 세트는 본사가 지사에 배정하는 완료 목표다. 개별 주문은 음식점 준비, 기사 수락, 픽업, 전달의 기록을 갖는다. 해당 세트의 실적은 전달이 확인된 주문을 한 번씩 센다. 세트당 건수의 가안은 원 기획에서 관리한다. |
| **장소와 검색 이름** | 공공데이터의 역명·동명·업종명·확인된 업소명을 원문대로 보여 준다. 역과 행정동은 각각의 ID·코드로, 업소는 출처와 인허가 관리번호처럼 고유하게 정해진 값으로 연결한다. 지도와 플레이스에서 같은 장소를 열면 동일한 위치를 가리킨다. |
| **전달·결산·역 성장** | 전달 완료는 개별 주문에 기록하고 지사 실적으로 집계한다. 하루 결산은 그날의 활동을 모아 보여 준다. 빛은 해당 조건을 충족한 업무 결과와 연결한다. 역의 단계가 오르면 맡을 수 있는 사람 자리와 운영 여력이 늘어나는 방향이다. 교육과 스스로의 노력으로 깨어나는 과정은 별도로 기록한다. |

## 플레이에 붙이는 순서

1. **할 일 한 건.** 사가정역에서 면목3·8동 주문을 골라 지사 카드와 기사 후보를 본다. 같은 주문이 전달되면 역의 화면에서 처리 결과와 그날 실적을 확인한다.
2. **다음 날의 선택.** 주문이 밀리면 지사의 처리 여력을 살핀다. 처리 여유가 있으면 `사가정역 치킨`과 같은 역·업종 키워드의 게임 광고 예산을 검토한다. 게임에서 계산한 광고비와 유입 주문은 같은 회차 결과로 읽는다.
3. **다른 역으로 확장.** 첫 역에서 한 건의 업무와 결과 연결을 확인한 뒤 인접 역과 지사 확장을 잇는다.
4. **2.0에서 현장 보기.** 같은 동·장소의 건물·출입구·골목을 동 디오라마에 표시한다. 2.0 전략 기능은 이 현장 위에서 별도의 선택을 제공할 수 있다. [1.0·2.0 분리 결정](../../../Handoffs/2026-11-19-Claude-사용자결정-판가름-구지도1.0과동지도2.0.md) · [면목 정밀 모듈 r57](../PLAN-SYSTEM-ADMIN-DONG-DIORAMA/myeonmok-precision-and-strategy-input.r57.md)
