## 1. 포함 방향 — 유동 규모가 군중으로 읽히는 동네

플레이어는 같은 동네의 한산한 시간과 붐비는 시간을 지도에서 구별한다. 공간·시간 기준과 공급자 정의를 확인해 비교 가능하다고 검증한 표현 지표를 사용한다. 이 지표가 큰 지역/시간구간에는 대표 보행자가 더 많이 나타나고, 작은 곳에는 드문드문 걷는다. 규모 차이를 숫자표를 열지 않고도 알아볼 수 있게 한다.

관찰의 다음 선택은 그 지역/시간 자료를 확인하거나, 관리 매장·입지 시험·기존 업무로 이동하는 것이다. 사람이 많다는 이유만으로 매출/사업 성공을 확정하지 않는다. ‘지금 이 지역은 어떤 흐름인가’를 읽는 보조 층이다.

기존 r143의 약 10명은 첫 검토의 가상 표현량으로 보존한다. 이를 실제 인구나 모든 동의 고정 군중 수로 쓰지 않고, **자료가 연결된 보기에서는 상대 규모에 맞춰 대표 표현량이 달라지는 방향**으로 확장한다. 회색 동네와 관리 매장 강조·가벼운 움직임·기존 영상 제작 보류는 유지한다.

군중 보기는 초기 동네 단계부터 가능한 방향으로 제안한다. [r179의 전국 광고 해금](national-stage-advertising-unlock.confirmed.r179.md)은 광고 경영의 조건이며 군중 보기의 해금 조건으로 확대하지 않는다.

## 2. 보유 자료를 어떤 의미로 쓸까

기존 수집 기록과 원본 메타데이터에서 상권·행정동별 추정 유동인구와 시간대/요일 항목, 영역 코드·대표좌표/면적을 확인했다. 해당 보유 범위는 2021년 1분기~2026년 2분기이며 11월 12일 취득본이다. 시간대는 00–06·06–11·11–14·14–17·17–21·21–24시의 여섯 구간이며 요일 항목은 일곱 개다. 실제 소비 때는 최신 검증 원본/색인의 해시·기간·필수 열·코드 대응을 다시 확인한다. 과거 r138의 250m/시간 단위 안내 검토를 원자료 확보로 승계하지 않는다.

| 입력 | 표현에 사용하는 의미 | 그대로 주장할 수 없는 것 |
| --- | --- | --- |
| 상권·행정동 유동인구 집계 | 해당 권역/시간구간의 상대 규모 | 현재 길 위에 동시에 있는 사람 수 |
| 시간대별 항목 | 자료가 구분한 시간구간 간 차이 | 분/초 단위 실시간 관측이나 개별 도착시각 |
| 요일별 항목 | 같은 기준기간 안의 요일 차이 | 시간대×요일의 결합분포가 없을 때 그 교차 셀의 실측값 |
| 코드·대표좌표·면적 | 지역 참조와 비교 문맥 | 행정동/상권 폴리곤이나 골목별 실제 밀도 |
| 별도로 검토한 경계·보행 경로 | 배치 가능 공간과 표현 경로 | 그 길의 실제 보행 궤적/통행량 |

분기 집계는 일평균·고유 방문자·동시 체류인원으로 임의 변환하지 않는다. 각 시간구간의 길이가 다르므로 원본 합계가 크다는 이유만으로 그 순간 더 붐빈다고 해석하지 않는다. 길이/면적 등을 어떻게 보정해 표현 지표를 만들지는 별도 모델로 정하고 가정과 판본을 남긴다. 시간대/요일 항목을 조합해 추가 장면을 만들 때도 새 실측 통계로 부르지 않는다. 유동인구·생활인구·상주인구·이동량은 같은 지표로 합치지 않는다.

현재 수집 정책의 숫자 검증이 총 유동인구에 설정됐다는 사실을 시간대/요일 전열의 숫자·합계 검증까지 통과한 것으로 확대하지 않는다. 소비 전 각 사용 열의 인코딩/숫자·결측·유효 범위와 공급자 합계 정의를 별도로 확인한다. 검증이 끝나기 전에는 해당 열로 자료 기반 군중을 활성화하지 않는다. 과거 파생 색인의 DB/게임 반입 없음도 그 색인의 범위이며 후속 DB 저장 사실을 부정하지 않는다.

행정동·법정동·상권·경계의 시점과 식별자를 보존한다. 현재 동 모듈의 2023 역사 경계 후보와 다른 시점의 집계를 이름만으로 연결하지 않는다. 검토한 대응이 없거나 복수 후보면 미해결로 표시한다. 행정동 합계를 각 골목이나 이웃 동마다 그대로 복제하지 않는다.

## 3. 자료에서 화면까지의 표현 규칙 후보

```text
검증된 지역/기간별 집계
→ 사용 가능한 시간구간·공간 대응 확인
→ 같은 기준 집합에서 상대 규모 계산
→ 화면 범위/축척·표현 상한에 따른 목표량
→ 검토된 보행 경로 위의 대표 군중 배치
```

적음/보통/많음 같은 단계 또는 완만한 변환 곡선을 후보로 둔다. 공간·시간 기준과 공급자 정의를 확인해 같은 척도로 비교 가능하다고 검증한 표현 지표가 클수록 더 높은 밀도 단계로 읽히게 한다. 화면 표시 상한에 도달한 차이는 정적 밀도 표시/지표로 보완한다. 비교 기준·변환식·상한·기본 표시량은 미정이다. 자동 재축척 때문에 다른 동으로 이동할 때 같은 밀도의 의미가 달라지지 않도록 비교 범위와 범례를 유지한다.

원본의 지역 집계는 그대로 보존하고, 동 안의 세부 배치는 **가상 분배된 대표 표현**으로 별도 기록한다. 역·상가·골목 등 가상 배치 가중치를 쓰는 경우 그 근거/가정을 남긴다. 확인하지 못한 길에 관측된 사람이 몰린다고 표시하지 않는다. 원본/표현에 없는 통행 방향·속도·체류시간을 실측값으로 만들지 않는다.

캐릭터 하나는 실제 한 명을 뜻하지 않는다. 표시량을 늘리거나 줄인다고 원본 집계나 게임 수요를 증감시키지 않는다. 같은 지역에 여러 통로를 그릴 때도 하나의 지역 표현 예산을 나눠 쓰며, 같은 집계를 통로마다 중복 적용하지 않는다.

자료가 없거나 대응/단위 검증에 실패하면 **자료 미확인**으로 남긴다. 결측을 0명으로 표시하지 않는다. 별도 합성 장면을 보여줄 수는 있지만 ‘자료 기반’과 명확히 구분하고 혼잡 사실처럼 표시하지 않는다.

## 4. 걷고 머무는 모습과 지도 높이

| 지도 관점 | 보이는 것 |
| --- | --- |
| 동네 확대 | 낮은 대비의 작은 사람 형상이 걷거나 잠깐 멈춤. 규모에 따라 드문 보행과 작은 무리의 차이 |
| 구 | 동별/지원 영역별 상대 밀도와 기준기간. 개별 사람은 줄이거나 생략 |
| 서울·전국 | 지원 자료 범위의 집계 요약. 서울 자료를 전국 실측으로 확장하지 않음 |

보행 통로는 건물·차도와 충돌하지 않도록 검토한 경로만 쓴다. 도로 중심선이 보도라는 가정을 하지 않는다. 유효 경로가 없는 지역은 경로 미준비를 표시하고 집계 요약으로 대체하는 안이다. 흐름 방향의 실제 근거가 없다면 배경 걷기를 가상 동선으로만 표현한다.

군중은 업무 기사·주문 핀·운영 매장보다 낮은 대비에 두고 선택을 가로채지 않는다. 줌/화면 밖 영역은 표시량을 줄여도 집계/업무 상태를 초기화하지 않는다. 전환은 급격한 생성/소멸을 줄이는 방향이며 구체 자산·애니메이션·표시 상한·성능 기준은 후속 시각 준비에서 정한다.

움직임/군중 숨기기와 정적 밀도 보기의 선택을 제안한다. 표현을 꺼도 자료/업무 결과는 유지한다. [직접 주행 r145](direct-riding-delivery-minigame.design.r145.md)의 충돌 가능한 교통/보행 주체와 이 생활 군중은 별도다. 장식 군중의 수·숨김 설정으로 충돌·벌점·주문 이행을 바꾸지 않는다.

## 5. 게임·관찰자·입지 시험과 광고의 관계

- **게임 모드:** 검증된 자료를 지역 환경의 문맥으로 사용하고 가상 분배/움직임임을 표시한다. 시간구간 선택과 진행은 r174의 현실 날짜/작업 시간 경계를 따른다. 카메라 이동/군중 재생이 날짜나 작업을 추가 진행시키지 않는다.
- **관찰자 모드:** 공공 집계의 지역·기준분기/시간구간·단위·출처를 읽는 합성 표현이다. 현재 순간의 실제 거리 영상이나 사람 추적처럼 보이지 않게 한다. 자료 시간구간을 살펴보는 동안 게임 시계·돈·작업은 관찰자 모드의 정지 상태를 유지한다.
- **r142 무료 입지 시험:** 군중 표현과 방문/대기 해석을 참고할 수 있지만 시험 장면·조건·고객/결과는 분리한다. 무료 시험의 방문을 영업 주문·정산으로 전환하지 않는다.
- **r176~r179 광고/중개:** 유동인구 집계·대표 군중과 검색/조작 트래픽은 다른 기록이다. 광고가 관심 고객의 선택에 영향을 줄 수 있어도 군중 표현량이 직접 주문을 만들지 않는다. 합성 IP·계정 트래픽을 길 위 사람으로 추가하지 않는다.
- **참여자 성장:** 군중 증가·표시/숨김으로 기사·현장 작업자의 경 유지나 소득/성장을 지급하지 않는다. 실제 업무 결과는 기존 모듈을 따른다.

입지 힌트/고객 전환 규칙이 미준비여도 군중 표현과 자료 상세는 독립적으로 검토할 수 있다. 새 수요 엔진·자동 입점 추천·매출 보상까지 이 요청으로 승인하지 않는다.

## 6. 첫 검토 범위와 후속 검증

공간·시간 해석과 보정/표현 모델을 확정한 뒤, 먼저 사용 가능한 동 모듈 한 곳에서 **같은 지도·카메라의 서로 다른 원본 시간구간**을 비교하는 안이다. 비교 가능한 지표가 낮고 높은 경우의 대표 군중 차이, 회색 건물/관리색/기사·주문 표식의 가독성을 확인한다. 미확인 자료 장면도 함께 읽을 수 있게 한다. 새 시안·영상·Runtime은 이번에 제작하지 않는다.

후속 구현 명세는 아래를 확인해야 한다.

- 원본 수치/결측·단위·지역/기간과 표현량이 분리되고, 표현 변환/가상 분배의 판본이 남는가.
- 같은 자료/비교 집합·시드에서 같은 밀도 단계와 대표 흐름을 재현하는가.
- 원본 시간구간보다 세밀한 실측·골목별 실인구나 현재 실시간이라는 주장을 만들지 않는가.
- 줌·화면 이탈/복귀·숨김·자료 열람이 집계/주문/충돌/정산·성장에 영향을 주지 않는가.
- 유효 경로 밖 배치·건물 관통·차도 보행을 피하고 기존 선택/조작을 보존하는가.
- 소스 갱신은 기존 수집/검증·안전한 판본 전환을 따르고 진행 중 자료/모듈을 임의 교체하지 않는가.

## 7. 확정 / 미정 / 다음 질문 하나

- **포함 방향:** 유동인구에 따라 지도에 대표 군중이 등장하고 상대 밀도가 달라지는 요소를 기획에 넣는다. 기존 관리 매장 강조와 가벼운 생활감 표현은 유지한다.
- **제안·미정:** 첫 동/시간구간·밀도 변환과 상한·경로/가상 분배·대표 인물 자산·기본 표시/정적 대체·자료 판본 결속·저장/개발 명세. 관찰 집계와 가상 움직임, 업무 고객/결과는 구분한다.
- **다음 질문 하나:** 첫 검토는 동 모듈 한 곳에서 원본의 오전·점심·저녁 시간구간을 비교하는 화면으로 잡을까? 같은 공간에서 유동 규모 차이를 읽기 쉽다는 이유로 추천하며 첫 동과 정확 구간은 미정이다.

## 8. 출처·디오라마 규칙 점검

자료 근거는 기존 수집 문서가 연결한 원본/영수증·파생 색인이며 새 원본 취득이나 출처 영수증을 만들지 않았다. [기존 규칙 대장](../../../../../eng/execution-ledgers/station-diorama-evidence-rules.json)의 `diorama-rule:mixed-spatial-layers-preserve-source-time-crs-and-authority.v1`과 출처 시점·좌표계·결손/권위 분리를 대조했다. 기존 `Candidate`와 정합하나 이번 기획 문서가 새 실행 관찰이나 규칙 적용 승인을 제공하지는 않는다.

실제 World/통행 관찰을 추가하지 않아 기존 규칙을 강화·약화·무효화하는 새 증거는 없다. 새 `Observed`·`Candidate`, Logic/Presentation E 결속/승격은 기록하지 않는다. **새 디오라마 규칙 후보 없음.**

문서 전용 결과다. 실제 자료 연결·보행 경로 배치·캐릭터 움직임·가독성/성능·Unity Runtime 검증을 완료했다고 보지 않는다.
