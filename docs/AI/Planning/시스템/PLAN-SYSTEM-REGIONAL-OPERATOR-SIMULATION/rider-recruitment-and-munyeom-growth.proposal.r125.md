# [기획 · 기사 모집과 무념 성장 · PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION · r125]

[r126](./rider-profile-draw-and-academy-film.proposal.r126.md)은 수료자의 시작 등급을 기사별 사전 프로필로 바꾼다. 이 문서의 일괄 신사 등록은 이전 제안이다.

- 기준일 2026-11-10
- 상태 `ProposedDesign / ImplementationPending`
- 범위는 사가정 개인용 Windows 게임의 가상 음식 배달이다. [현재 실행판](../../../../../tools/Ssalddel.Sagajeong.Engine/README.md)의 가상 시계·기사 A/B·지도·배차·가상 정산을 출발점으로 한다.

## 사용자 방향

플레이어는 가상 기사를 더 모집할 수 있다. 지원자는 먼저 입교를 신청하고 교육을 받은 뒤, 자기 안의 신성을 스스로 알아차리며 무념이 어떤 상태인지 알게 된다. 수료 때 0번 바보 카드를 받아 신사로 첫 운행을 시작한다. 기사 개인은 무념을 더 오래 유지하는 법을 익히며, 실제 게임에서 그 시간이 늘어나는 것이 기사 등급으로 이어진다. [r124](rider-munyeom-tarot-direction.decision.r124.md)의 개인 타로 방향은 현재 무념 상태에 따른다. 지도 영상과 카드 창 효과음은 이후 표현 작업에서 다룬다.

## 지사 기사 한 명을 늘리는 첫 흐름

1. 운영자는 사가정 배달권에서 배차 대기·배송 중·휴식 기사 수와 미배정 주문을 본다. 인력이 부족하면 배달권에 속한 면목동을 골라 가상 모집 광고 한 건을 낸다.
2. 다음 영업 시작에 가상 주민 C가 지원한다. C는 지사에 입교 신청서를 낸다. 운영자가 신청을 수락하면 C가 해당 지사의 교육생으로 나타난다. 첫 판은 대기 중인 공고 한 건과 가상 교육생 한 명으로 시험한다.
3. C가 교육을 마치고 0번 바보 카드를 받으면 신사 등급으로 등록된다. 근무 준비 뒤 배차 대기가 된다. 운영자가 기존 기사 마커와 주문 매장 핀으로 주문을 지정한다. 합류와 실제 주문 배차는 각각 확인할 수 있다.
4. C의 첫 배달·수령·가상 정산을 기존 흐름으로 마친다. 재실행 뒤에도 C의 소속과 등급이 유지된다.

공고가 대기 중이거나 C가 합류한 뒤 같은 조작을 다시 해도 C는 한 명이다. 교육생은 교육 현황에 표시한다. 정식 기사 수는 수료와 등록 뒤, 가용 기사 수는 근무 준비 뒤에 늘어난다. 기존 [가용 의향 알림](README.md#문답-r2--점심-피크와-가상-기사-가용-의향-알림)은 이미 있는 기사에게 오늘 일할 수 있는지 묻는 별도 흐름이다.

## 입교 신청부터 첫 운행까지

| 단계 | 화면과 선택 | 결과 |
| --- | --- | --- |
| 입교 신청 | 가상 주민 C가 이름·희망 지사·배우려는 이유가 담긴 신청서를 낸다. 운영자는 신청을 읽고 입교를 수락한다. | 지사에 교육생 C가 표시된다. |
| 교육 | 기존 사가정 지도에서 매장 확인 → 도로 이동 → 픽업 → 전달·수령을 가상 연습 주문으로 한 번 따라간다. 출발 전 잠깐 멈춰 자기 마음을 살피는 연습도 한다. | 연습을 끝내면 수료 장면을 열 수 있다. |
| 내면의 신성과 무념 알아차림 | 교육을 돌아보며 C가 자기 안의 신성을 알아차린다. 그 알아차림을 통해 무념이 어떤 상태인지 알고, 어떤 마음으로 일을 시작할지 스스로 정한다. 아이처럼 처음 배우는 마음이 이 장면의 주제다. | 무념을 처음 알아차린 장면과 C가 선택한 첫 마음을 수료 기록에 남긴다. |
| 0번 바보 수여 | 교육을 마치면 **0번 바보(The Fool) · 초심**을 C의 개인 보관함에 한 번 수여한다. | 수료·카드 수여·신사 등록이 함께 기록된다. 근무 준비를 마치면 첫 실제 게임 주문을 받을 수 있다. |

0번 바보는 [기존 여정의 출발점](../../../../Architecture/게임기획통합기준.md)의 의미를 수료에 연결한다. 개인 보관함의 수료 표식으로 남기며, 뽑기·능력치 보정·무념에 따라 뒤집히는 장착 카드와 분리한다. 연습 주문은 수료 확인용으로 기록하고 지사의 완료 건수와 가상 정산은 첫 정식 주문부터 집계한다. 수료를 다시 열거나 저장을 다시 불러와도 카드와 신사 등록은 한 번이다.

## 기사 개인이 성장하는 첫 흐름

수료에서는 무념이 어떤 상태인지 알아차린다. 이후 기사 성장은 운행 중 그 상태를 얼마나 오래 유지했는지에 따라 이어진다.

| 기사 정보 | 의미 | 표시 예 |
| --- | --- | --- |
| 현재 무념 | 기사 개인의 현재 상태 | 유지 / 깨짐 / 휴식 |
| 경 시간 | 현재 무념을 더 유지할 수 있는 예상 시간 | 4분 남음 |
| 유지 가능 시간 | 해당 기사가 준비된 상태에서 시작할 때의 가상 능력 | 시작 기준 9분 |
| 유지 기록 | 업무 중 무념을 연속 유지한 시간의 실제 게임 기록 | 8분 이상 1/2회 |
| 기사 등급 | 다른 영업일에 다시 확인한 유지 기록으로 얻은 성장 | 신사 |

- 출발 전 또는 휴식 뒤 기사가 스스로 마음을 점검한다. 첫 질문은 `지금 마음이 어떤가?`와 `작은 여유에도 만족할 수 있는가?`다. 플레이어는 기사에게 점검과 휴식 시간을 마련한다. 답변의 좋고 나쁨으로 등급을 매기지 않는다.
- 첫 시험에서는 실제 업무를 수행하는 동안 가상 시계 기준으로 경 시간을 쓴다. 주문이 없는 대기와 휴식은 유지 기록에 합산하지 않는다. 2배·4배도 같은 가상 시간 규칙을 쓴다.
- 그날의 첫 유효 기록은 **자기 점검을 하고 시작한 뒤, 배달 한 건 이상을 수령·정산까지 확인하고 무념 상태에서 근무를 정상 종료한 경우**에 만든다. 그날의 유효 기록은 한 건이다. 이 기록을 반영할 때 다음 근무의 유지 가능 시간이 가상 1분 늘어나는 안을 시험한다.
- 다음 주문 예상 수행시간에 여유 1분을 더해 현재 경 시간과 비교한다. 부족하면 다른 기사나 휴식을 권한다. 근무 중 경 시간이 소진돼 무념이 깨지면 개인 타로가 즉시 역방향이 되고 **무념 상태가 깨졌습니다**를 표시한다. 진행 중인 주문은 기존 이행 흐름에서 마치고 신규 배차는 휴식과 점검 후에 다시 연다.
- 회복으로 타로는 정방향으로 돌아간다. 이미 획득한 등급은 그 순간의 상태 변화와 별도로 보존한다. 첫 판에서 등급은 속도나 정산 보수를 바꾸지 않으며, 유지 시간이 길어지면서 선택 가능한 주문과 교대 판단이 달라진다.

사용자가 기사 등급명과 순서를 확정했다. 교육 수료 후 첫 등급은 **신사**이며, 승급은 다음 등급으로 한 단계씩 진행한다.

| 순서 | 기사 등급 | 첫 시험 기준 |
| --- | --- | --- |
| 1 | 신사 | 입교 교육 수료와 0번 바보 수여. 준비된 시작 기준 가상 6분 |
| 2 | 문사 | 서로 다른 두 영업일에 각각 가상 8분 이상 유효 유지 |
| 3 | 학사 | 서로 다른 두 영업일에 각각 가상 10분 이상 유효 유지 |
| 4 | 양사 | 미정 |
| 5 | 경사 | 미정 |
| 6 | 수사 | 미정 |
| 7 | 정사 | 미정 |
| 8 | 대사 | 미정 |
| 9 | 대종사 | 미정 |

1분 증가량, 6·8·10분, 여유 1분, 두 영업일 조건은 전부 첫 시제품에서 조절할 숫자다. 실제 운행 안전·사고율이나 기사 평가에 적용하지 않는다.

## 첫 플레이 검증 범위

- 모집하지 않았을 때 A/B 2명으로 시작한다. 모집을 선택한 판에서는 면목동 공고 → C 입교 신청 → 교육·수료 → 0번 바보 수여 → 지도에 정식 기사 3명 → C의 배달 한 건 마감이 이어진다. 교육 중에는 배차 대기 수가 늘지 않고 수료를 다시 열어도 카드가 중복 수여되지 않는지 확인한다. A가 배송 중이고 B가 쉬는 같은 주문 상황에서, C 합류 전후의 배차 대기·완료 건수와 기존 가상 정산을 비교한다.
- 성장 검증에는 기존에 8분 유효 기록을 한 번 쌓은 가상 기사 B를 사용한다. 두 번째 영업일에 8분 유효 기록을 쌓으면 문사로 한 단계 승급한 결과가 한 번만 표시된다. 같은 조건에서 경 시간이 먼저 소진되면 기록 대신 무념 깨짐과 카드 역방향을 확인한다. 휴식·회복 뒤에도 이전 등급과 소속을 확인할 수 있다.
- 기사 마커를 누르면 기존 오른쪽 상세에서 **배차 상태·남은 경 시간·등급과 다음 등급까지의 기록**을 우선 표시한다. 지사 목록에는 총원과 지금 배차할 수 있는 인원을 따로 표시한다. 첫 화면은 지도 한 곳과 기사 상세 한 곳으로 검토한다.
- Simulation이 가상 시계·소속·등급·휴식·개인 타로 방향을 판정하고 저장한다. Unity는 지도와 상세 화면을 그린다. 같은 초기 저장과 입력 순서로 재생하면 입교·수료·카드 수여·승급·카드 전환이 같은 순서로 보이는 것이 완료 기준이다. 기존 주문·배차·정산 결과를 대조한다.

## 표현 후속

지도 기사 움직임은 기존 도로와 위치를 따라 실시간으로 표현한다. 영상은 지사 합류나 승급처럼 특정 순간에 짧게 보이는 연출 후보로 둔다. 카드 창 열기, 타로 방향 전환, 합류, 승급의 효과음도 각 상태 사건에 나중에 연결한다.

## 다음 검토

첫 시안은 **면목동에서 C의 입교 신청을 받아 교육을 마치고 0번 바보를 수여한 뒤, 세 번째 기사의 첫 배차를 확인하는 흐름**이다. 실제 성장 속도와 표시 용어는 시안에서 확인한다.
