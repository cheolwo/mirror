## 확정 — 관찰에서 선택과 결과 비교로 이어진다

사용자는 지도에서 사람들이 모이는 모습을 보고 “여기에 음식점이나 커피집을 놓아볼까”라고 생각한다. 먼저 움직임을 관찰하고 장소를 눌러 근거를 읽은 뒤 업종과 위치를 선택한다. 가상 시험 영업에서 선택 전후의 변화를 보고 다른 선택을 시도한다.

플레이어의 직접 결과는 **입지·업종 선택에 따른 가상 방문과 수요 충족의 차이를 확인하는 것**이다. 군중 증가 자체를 성공으로 판정하지 않는다. 방문 수요를 배달 주문이나 실제 창업 수익으로 전환하지 않는다.

| 상황 요소 | 첫 검토의 정의 |
| --- | --- |
| 지금 | 같은 동네의 오전과 점심을 각각 관찰·비교한다. 시간 구간은 시험 시작 전에 고른다. |
| 여기 | 사가정 동네의 역 주변과 주거 골목. 실제 점포 입지 추천이 아닌 합성 상황이다. |
| 나 | 군중을 관찰하고 음식점·커피집의 시험 위치를 선택하는 플레이어다. |
| 너 | 시간대별 필요와 이동·체류를 가진 대표 군중, 주변 공급과 시험 매장이다. |
| 이렇게 | 장소 관찰 → 힌트 → 후보 배치 → 명시적 시험 시작 → 결과 비교 → 재배치. |
| 대가 | 첫 시험은 개설 비용을 쓰지 않는다. 위치·업종에 따라 대기와 충족되지 않은 수요가 남는 선택의 대가를 보여준다. |
| 회복·귀환 | 배치 취소·시험 중단·종료 뒤 같은 지도에서 위치나 업종을 바꿔 재시험한다. 기존 배차로 복귀할 수 있다. |

## 1. 지도 위 움직임과 관찰 뒤 힌트

반투명한 사람 형상과 은은한 빛으로 사람들이 들어오고, 잠시 머물고, 흩어지는 모습을 지도 위에 겹친다. 독립된 영상 창 대신 지도 좌표에 붙은 짧은 반복 움직임을 표현 방향으로 둔다. 실제 표시 방식·자산은 후속 시각 준비에서 정하며, 이번에 영상 파일이나 애니메이션을 제작하지 않는다.

가까이에서는 대표 인물의 이동·머무름을, 멀리에서는 부드러운 밀집과 유입·유출 방향을 보여준다. 대표 인물 하나를 실제 사람 한 명이나 고객 한 명으로 세지 않는다. 시간대에 따라 흐름이 달라지고, 단순히 사람이 많은 정도만으로 업종을 결정하지 않는다.

장소를 누르기 전에는 업종 추천을 띄우지 않는다. 누르면 시간대, 통행과 체류, 식사·음료의 필요, 주변 공급을 짧게 보여준다. 음식점과 커피집 각각의 적합 이유와 불리한 조건을 함께 제시하며 성공을 보장하는 점수는 만들지 않는다.

첫 합성 상황은 오전 역 주변의 짧은 음료 구매와 점심의 식사 체류를 대비한다. 주거 골목은 같은 시간대에 상대적으로 다른 통행·체류와 공급 조건을 보여주는 비교 장소다. 실제 상권을 조사한 결과로 표기하지 않는다.

## 2. 시험 배치와 영업·비교

1. 장소를 고르면 그 주변의 지정된 배치 후보를 표시한다. 도로·기존 건물과 겹치는 위치는 후보로 제공하지 않는다.
2. 음식점 또는 커피집 모형을 반투명하게 놓는다. 확정 전에는 후보 사이 이동과 취소가 가능하다. 첫 기획에서 메뉴·가격·인력·업종별 처리 능력은 시나리오 고정값이며 플레이어는 위치와 업종만 선택한다.
3. `시험 영업 시작`으로 선택을 확정하고 선택한 시간 구간을 재생한다. 일부 군중이 매장으로 향해 이용하거나 기다리고, 충족되지 않은 수요는 남는다. 단순 군중 수와 실제 이용 결과를 구별한다.
4. 시험 중에는 배치를 잠근다. 중단하면 비교를 완료한 결과로 저장하지 않고 배치 단계로 돌아간다. 정상 종료하면 결과를 표시한다.
5. 완료된 시험은 시작 전과 후의 방문·이용·대기·충족되지 않은 수요를 보여주고 차이가 난 이유를 짧게 설명한다. 기준 화면은 시험 매장이 없는 같은 구간의 합성 상황이다.
6. 재시험은 같은 초기 수요·주변 공급·시간 구간을 재사용하고 위치 또는 업종 중 하나만 바꿔 비교한다. 시간대를 바꾸면 별도 조건의 시험으로 표시해 같은 조건의 개선으로 해석하지 않는다.

시험 결과는 별도 가상 상황 안에서만 계산한다. 기존 주문·기사·정산·픽업 매장의 거래 흔적을 변경하지 않는다. 시험 매장을 정식 소유 매장이나 r141의 거래한 매장으로 등록하지 않는다. 이번 기획의 시험 결과는 영구 저장 요구를 두지 않으며 후속 저장 설계로 실제 게임 세이브를 확장하지 않는다.

## 3. 다섯 장면 정의

아래는 후속 시안 제작에 사용할 장면 정의이며 제작된 이미지·영상 목록이 아니다. 같은 지도와 카메라에서 비교하고 배치·군중 변화만 필요한 만큼 바꾼다.

| 장면 | 사용자가 보는 것 | 행동과 확인할 의미 |
| --- | --- | --- |
| ① 군중 발견 | 역 주변으로 들어오고 잠깐 머무는 반투명 사람들, 상대적으로 한산한 골목 | 장소를 누른다. 설명 전에도 사람의 모임과 흐름 차이를 알아본다. |
| ② 장소 힌트 | 시간대·통행/체류·음료/식사 필요·주변 공급의 짧은 설명 | 음식점과 커피집 중 무엇을 시험할지 근거를 갖고 고른다. |
| ③ 시험 배치 | 유효 후보와 반투명 매장, 이동·취소·시험 시작 | 배치 확정 전까지 비교하고 되돌릴 수 있다. |
| ④ 영업 변화 | 일부 인물의 매장 접근·이용·대기와 남은 흐름, `시험 중` 표시 | 수요가 있어도 모두 손님이 되지 않으며 처리 능력에 따라 대기가 남음을 본다. |
| ⑤ 비교 결과 | 시작 전후의 네 결과와 이유, 재배치·업종 변경·지도 복귀 | 선택의 결과를 설명하고 한 조건을 바꿔 재시험한다. |

## 4. 판독·입력·상태 경계

- 군중과 빛은 기존 기사·주문 표식보다 낮은 대비로 두고 도로·건물을 가리지 않는다. 개별 군중은 클릭을 받지 않고 선택 가능한 장소 영역으로 힌트를 연다.
- 장식 움직임을 줄이거나 꺼도 밀집·이동 방향·체류 단서와 장소 설명을 정적으로 확인할 수 있어야 한다. 움직임만으로 필요한 정보를 전달하지 않는다.
- 장소 상세는 하나만 표시하고 명시적으로 시험 흐름을 종료하면 기존 지도·배차 선택으로 복귀한다. 시험 중단·취소를 기존 업무 명령으로 전달하지 않는다.
- 후보가 없는 장소에서는 배치 불가 이유와 다른 장소 선택을 제공한다. 이용자가 없거나 대기가 늘어도 결과를 숨기지 않고 위치·업종 재검토로 연결한다.
- 모든 화면은 합성 수요·가상 시험임을 표시한다. 공공자료의 실제 적재, 실시간 인구 관측, 현실 창업·실제 매출로 표현하지 않는다.

## 5. 검토·후속 구현의 완료 조건

| 확인 범위 | 통과 기준 |
| --- | --- |
| 관찰·이해 | 긴 설명 없이 모이는 곳과 이동·체류의 차이를 구별하고, 힌트를 읽어 선택 이유를 설명할 수 있다. |
| 선택·결과 | 같은 합성 조건에서 위치 또는 업종을 바꾼 결과와 그 원인을 비교할 수 있다. |
| 미충족·회복 | 군중이 많아도 공급·시간대·수용 능력에 따라 미충족이 남으며, 배치 불가·이용 없음·대기 증가 뒤 다른 선택이 가능하다. |
| 재현·중단 | 동일한 입력은 같은 결과를 내며, 중단을 완료 결과로 취급하지 않는다. 시간대 변경을 같은 조건의 비교로 표시하지 않는다. |
| 판독·입력 | 군중 표시와 움직임 끄기 상태 모두에서 단서를 읽고 기사·매장 선택과 지도 조작을 유지한다. |
| 기존 업무 보호 | 취소·중단·재시험·복귀가 기존 배차 선택·주문·정산·거래 흔적을 변경하지 않는다. |

문서 단계에서는 링크·경로·diff와 문서 전용 검증을 확인한다. 위 플레이 기준은 후속 실제 구현의 검증 조건이며 이번 문서 작성으로 통과했다고 보고하지 않는다. 게임 구현 전에는 승인 판본·hash와 WI 하나의 E1~E7 명세, 주체 준비·전문 연구 필요 여부·담당/쓰기 경로·검증 상한을 별도로 결속한다.

Graph Map 영향은 관찰 장소 → 힌트 → 업종/후보 → 시험 결과 → 재선택의 플레이 관계와 배치 후보의 공간 제약이다. 원본·생성물은 이번에 수정하지 않으며, 담당의 정식 반영이나 Unity Scene·실제 입력·E 승격을 선언하지 않는다.

## 미정과 다음 질문 하나

확정한 것은 관찰 뒤 힌트, 두 업종의 시험 배치와 가상 영업 비교, 합성 상황을 이용한 문서 범위다. 홀로그램의 구체 외형·높이·밝기·밀도, 시험 길이와 업종별 수요·처리량의 수치, 구현 자산·프로젝트는 후속 검토로 남긴다. 실제 창업·정식 소유·개설 비용·손익·인력 운영·배달 주문 연결은 이번 범위에 넣지 않는다.

다음 질문 하나: **후속 시각 검토에서 반투명 사람 형상을 중심으로 볼지, 사람 형상에 밀집 빛을 함께 더해 볼지?** 이번 문서화에는 시안 제작이 포함되지 않는다.
