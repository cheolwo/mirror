## 0. 한눈에

- **무대:** 동부권 다섯 지역 — 중랑구 · 동대문구 · 광진구 · 노원구 · 구리시(r3).
- **나:** 가상 배달 플랫폼의 본사 운영자. 여러 역할을 조정하는 사람이다(r319).
- **한 판 = 하루(7~23시).** 실제 기록처럼 점심과 저녁에 두 번 고비가 온다.
- **넓히기:** 사가정역 3동 → 중랑구 16동 → 동대문구 · 광진구 → 노원구 · 구리시. 배차 엔진의 범위(행정동 칸)와 지사가 함께 넓어진다.
- **목표:** 이익을 많이 남기는 것이 아니다. **조정 풀이 버티는가 · 약속 시간을 지키는가 · 기사가 제대로 버는가** — r3의 「수익 · 배송 품질 · 참여자 보수의 균형」을 조정하는 곳의 말로 읽었다.
- **돈(확정):** 배달비 3,000원 → 조정 풀 / 수수료 **음식값의 5%** → 운영 칸(할증 · 서버 비용) / 기사 배달료는 실제 규칙.

## 9. r322 켜 두기와 직접 개입 — 보상을 나눈다

2026-11-20 14:42 KST. **사용자:** 「이미지 시연을 좀 보여줬으면 좋겠고 … 그냥 켜두기만 해도 그냥 성장을 하는 … 직접적으로 플레이를 하는 경우 사용자에게 더 이제 보상을 더 주는 … 구분을 해서 할 필요가 있겠다 … 관찰형 게임이면서 개입을 할 수 있는 게임으로 그렇게 처음에 기획을 했었으니까」

- **이미 정해진 원칙(r146):** 이완에서도 정상 수익과 성장이 계속된다. 직접 조작은 **기본 수익은 같고, 직접 완료한 구간만큼 추가 보너스**다. 앱을 꺼 둔 동안의 따라잡기 수익은 없다 [r146 집중 · 이완](../focus-relax-shared-management.design.r146.md).
- r146의 「직접」은 기사를 직접 모는 것(r145)이었다. 이번에 **본사 운영자의 직접 = 고비에서 결정을 내리는 것**으로 넓힌다(제안).

| 무엇 | 중 · 켜 두기 | 화 · 직접 개입 |
| --- | --- | --- |
| 하는 일 | 엔진 · 지사가 기본 방침대로. 큰 지출 · 지사 개설만 카드로 묻는다 | 고비 카드를 직접 처리: 기사 보내기 · 광고 멈춤 · 엔진 방침(묶음 먼저 등) |
| 배달 수익 · 조정 풀 · 운영 칸 | 같다 | 같다 |
| 빛(명덕) | 끝까지 닫힌 주문 한 건마다 | + 해결한 고비 카드마다 |
| 엔진 경험 | 닫힌 주문 한 건마다 | + 개입 보너스 |
| 사람(기사 · 지사장) 성장 | 천천히 | 빨리 |

- **보상은 돈이 아니라 성장으로(가안).** 켜 두기만 해도 손해가 없고, 경제(배달비 3,000원 · 수수료 5%)가 흔들리지 않는다. 직접 하면 더 빨리 넓어진다.
- 엔진 레벨업에 **돈 + 경험**이 필요하게 하면(시안 2의 정할 것), 개입 보너스가 넓히는 속도로 이어진다 [r153 판단 엔진의 다섯 단계](../engine-evolution-gameplay.proposal.r153.md).
- 사람 성장은 지사장 · 기사 카드의 성장으로 잇는다 [r277 지사장 카드](../people-development-and-scoped-delegation.design.r224.md).
- **또 하나의 직접:** 기사 한 명을 직접 몰아 배달하면 구간마다 보너스(r145 · r146) — 배달 기사 입장(입장 갈래 2)에서 정한다 [r145 직접 타는 배달](../direct-riding-delivery-minigame.design.r145.md).

## 10. r323 그래픽 기본 — 역사 문양 아이콘과 흐르는 빛 알갱이

2026-11-20 15:10 KST. **사용자:** 「그래픽으로는 전에 뭐 지하철 역사 관련한 그런 이제 아이콘이 나오고 했던 그런 이제 시안이 더 나은 것 같아서 … 빛이 막 알갱이들이 막 이동하고 막 그런 것도 그게 더 나았어가지고 그거를 활용을 하는 거를 좀 기본으로 했으면 좋겠어 지금은.」

## 11. r324 성장 보상은 결국 돈을 더 잘 버는 힘으로

2026-11-20 15:32 KST. **사용자:** 「근데 결국 보상으로 얻은 게 돈을 더 잘 벌게 되는 그런 이제 구조로 하면 좋을 것 같아.」

- **정한 방향:** 직접 개입의 보상은 그 자리에서 돈으로 주지 않는다. 대신 **성장(엔진 경험 · 사람 · 빛)으로 주고, 그 성장이 돈을 더 잘 버는 힘이 된다.** 한 건의 배달비 3,000원 · 수수료 5%는 누구에게나 같다. 달라지는 것은 **같은 하루에 몇 건을 얼마나 싸게 처리하느냐**다.

| 보상 | 무엇이 자라나 | 그래서 돈이 어떻게 느나 |
| --- | --- | --- |
| 엔진 경험 | 엔진 레벨이 빨리 오른다 | 처리 여력 +12%/Lv(지금 코드) · 범위가 넓어져 받을 수 있는 주문이 는다 · 묶음 배차로 한 기사가 한 번에 두 건 [r153 판단 엔진의 다섯 단계](../engine-evolution-gameplay.proposal.r153.md) |
| 사람(기사 · 지사장) | 기사가 빨라지고 정시가 는다 · 지사장에게 동을 맡길 수 있다 | 지연 · 취소가 줄어 닫히는 주문이 는다 · 맡긴 동이 늘어 같은 시간에 더 많은 동을 운영 [r277 지사장 카드](../people-development-and-scoped-delegation.design.r224.md) |
| 빛(명덕) | 동네가 밝아지고 깨어 있는 사람이 는다 | 그 동의 주문 수요가 는다(역 키워드 · 깨어 있는 인구와 잇기) |

**검산 예시(숫자는 가안)** — 실제 기록 평균으로 한 건이 닫히면 조정 풀 +160원, 운영 칸 +363원, 합 **+523원**이 남는다(r321).

- 하루 380건을 처리하는 Lv2 플랫폼이 Lv3에 오르면 처리 여력이 ×1.12 → ×1.24, 약 11% 는다. 주문이 충분하면 하루 380건 → 약 421건, **하루 +21,400원**이다.
- 켜 두기만 하면 닫힌 주문 한 건에 경험 1. Lv3에 경험 1,500이 필요하다면 약 4일이 걸린다.
- 고비 카드 하나를 직접 해결할 때 경험 +30, 하루 고비 카드가 여섯 장이면 하루 +180 — 약 3일로 당겨진다. 그만큼 **+21,400원짜리 하루가 하루 먼저** 온다. 이것이 개입의 보상이다.

**그래서 엔진 레벨업은 돈 + 경험(제안).** 돈만으로 오르면 경험 보상이 돈으로 이어지지 않는다. 지금 코드는 돈만 본다(60,000원부터 두 배) [r291 성장 수치](../delivery-branch-growth-play-loop.design.r257.md#r291-보존--배달-플랫폼의-성장-수치와-해금).

### 정할 것 — 하나씩

1. **(다음 질문) 엔진 레벨업을 「돈 + 경험」으로 할까.** Claude 의견: 그렇게 — 개입으로 쌓인 경험이 레벨을 당기고, 레벨이 하루 수입을 올린다.
2. 고비 카드 한 장의 경험 보너스 · 레벨별 필요 경험(위 1,500 · +30은 가안).
3. 하루 한 판의 길이(가안: 1시간 = 1분).
4. 결산의 세 가지 — 나란히 / 합침.
