# [기획 · 배달 플랫폼 운영 캠페인 · PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION · 배움에서 초기 경영으로 넘어가는 1~16괘 구간 r84]

- 상태: `Draft / Hex01To08LearningArcConfirmed / Hex09To16EarlyManagementArcConfirmed / DisorderToEmergingOrderConfirmed / Hex16EndStateAsked / NotReadyForImplementation`
- 범위: 배달 플랫폼 운영 캠페인에서 제1괘부터 제16괘까지의 상위 이야기 구간
- 제외: 개별 효사 대응, 강제 캠페인 순서, 수치·상태 전이, Graph Map, 디오라마, Unity 구현

## 확정 — 제1괘부터 제8괘까지는 배움의 구간

이 구간은 운영자가 이미 완성된 경영자라는 전제로 시작하지 않는다. 뜻과 가능성이 생기고, 현실의 결핍과 위험을 만나며, 실제 업무와 여러 역할의 처지를 배우고, 사람·물자·돈·정보를 조금씩 모으는 과정이다.

| 범위 | 상위 이야기 의미 |
| --- | --- |
| 1~2괘 | 움직일 힘과 그것을 받아 줄 현실 기반을 인지한다. |
| 3~4괘 | 부족한 상태에서 시작하고, 시행착오와 가르침을 통해 배운다. |
| 5~6괘 | 힘이 생겨도 위험을 기다리고 살피며, 갈등을 겸손하게 다루는 법을 배운다. |
| 7~8괘 | 외부 과시보다 내실을 닦고, 그 내실을 바탕으로 자발적 신뢰와 협력을 경험한다. |

따라서 제1괘부터 제8괘까지의 대표 호흡은 `발동 → 현실 접촉 → 배움 → 내실 → 신뢰 형성`이다. 이는 각 괘의 전체 의미를 없애는 분류가 아니라 여러 캠페인을 하나의 성장 구간으로 읽게 하는 상위 이야기다.

## 확정 — 제9괘부터 제16괘까지는 초기 경영·질서 형성 구간

이 구간에서는 배운 것을 실제 조직과 업무에 적용하기 시작한다. 다만 안정된 제도와 질서가 이미 완성된 경영이 아니라, 통제 기준과 역할을 만들고 시행착오를 거쳐 점차 운영의 형상을 갖추는 단계다.

| 범위 | 초기 경영의 이야기 후보 |
| --- | --- |
| 9~10괘 | 작은 자원·신뢰·절차를 모으고, 역할·권한·책임의 경계에 맞춰 조심스럽게 실행한다. |
| 11~12괘 | 흐름이 통하는 조건과 막히는 조건을 함께 경험하며 제도의 취약점을 드러낸다. |
| 13~14괘 | 여러 주체와 협력하고 자원이 늘어날 때 공동 목적과 배분 책임을 배운다. |
| 15~16괘 | 힘이 커져도 겸손하게 균형을 잡고, 사람과 자원을 움직일 수 있는 첫 운영 리듬을 만든다. |

대표 호흡은 `소규모 축적 → 경계 있는 실행 → 순환과 막힘의 학습 → 협력과 자원 관리 → 절제된 동원`이다. 제16괘에 도달해도 완전히 안정된 경영 체계가 끝난 것으로 자동 해석하지 않는다.

## 용어 경계

사용자가 말한 `간괘에 해당하는 면`은 이 문서에서 `관리·통제·경영의 성격이 강해지는 구간`이라는 취지로 이해했다. 전통 팔괘의 `간(艮)`이나 제52괘 중산간을 가리키는 고유 명칭과 혼동하지 않도록 현행 기획 명칭은 `초기 경영·질서 형성 구간`으로 둔다.

이 구간 구분은 창작과 운영 학습을 위한 상위 이야기 구조다. 개별 괘의 고전 의미를 구간표에 억지로 맞추거나, 괘 번호만으로 업무 상태·보상·난이도·Unity 공간을 자동 생성하지 않는다.
