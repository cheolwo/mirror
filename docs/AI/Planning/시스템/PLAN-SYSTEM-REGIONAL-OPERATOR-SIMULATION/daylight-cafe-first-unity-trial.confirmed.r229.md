## 확정한 시험

플레이어는 한 동을 보다가 가게를 찾고, 가까이에서 정면을 보고, 같은 건물을 눌러 본다. 멀리서는 민트색 표식, 가까이서는 밝은 차양과 쇼윈도, 지도에서는 기사의 움직이는 빛을 읽는다. 배경 건물과 도로는 r4의 실제 자료에 둔다. 검토용 가상 점포는 게임의 소유 원장과 분리한다.

| 단계 | 작업과 확인할 결과 |
| --- | --- |
| 준비 | 실제 면목제3·8동 건물의 원본 ID·외곽·표시 높이를 고정한다. 역할표에서 카페의 건물을 확인할 수 없으면 시험용 건물과 정면을 기록한다. |
| 외장 | Blender에서 민트 프레임, 크림색 차양, 유리와 실내를 만든다. Unity에서 건물 지면과 벽에 맞추고 동과 함께 숨기거나 표시한다. |
| 조작 | 검토판에서 동 전체와 300m로 전환한다. 재질을 바꿔도 같은 건물과 기사에 대한 기존 선택 동작을 유지한다. 정면의 재질은 추가 확대에서 비교할 수 있다. |
| 반환 | 같은 위치·렌즈로 미술 적용 전후의 실제 Windows 화면을 기록한다. 원본 ID·표시 상태·관측 가능한 성능을 검토한다. 업무 성과나 실점포의 운영 사실은 여기서 추론하지 않는다. |
