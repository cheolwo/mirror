# [기획 · 운영·회계 Simulation · PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION · 예외 우선 재무 확인 r38]

- 상태: `Draft / NormalFlowAutomated / ExceptionFirstOperatorReviewConfirmed / AffectedCaseIsolationConfirmed / WeeklyMonthlyThirteenWeekReviewConfirmed`
- 상위 기획: `README.md` r38
- 선행 기획: `operator-integrated-accounting-summary.r37.md`
- 목적: 정상 거래의 반복 확인을 없애고 운영자가 예외와 정기 결산에 집중하도록 확인 주기를 확정한다.

## 1. 확정 원칙

- 정상 주문·정산·지급 사건은 서버가 자동 집계·대사하고 운영자에게 건별 승인을 요구하지 않는다.
- `정산 확인 필요`가 발생하면 관련 주문·지급·환급 사건만 격리하고 나머지 정상 업무는 계속한다.
- 중복 지급, 지급 대상 불명, 금액 불일치처럼 외부 효과가 위험한 항목은 해당 사건만 보류한다.
- 단순 자료 지연처럼 지급을 막을 필요가 없는 예외는 경고 상태로 두되 담당자와 해결기한을 부여한다.
- 운영자는 예외를 수시로 확인하고 정상 경로는 주간·월간·13주 정기 확인에서 요약으로 검토한다.

## 2. 확인 주기

| 주기 | 자동 처리 | 운영자가 확인하는 것 | 결과 |
| --- | --- | --- | --- |
| 상시 | 업무 Event 기록, 자동 대사, 중복·누락 탐지, 예외 분류 | 긴급하거나 기한이 임박한 `정산 확인 필요` 사건 | 담당 배정, 해당 사건 보류·재처리·해제 |
| 매주 | 정산 묶음 집계, 13주 이동 전망 한 주 전진 | 이번 주 정산 총액, 정산 후 가용현금, 남은 예외, 다음 13주 최저점 | 주간 정산 확인 판본 |
| 매월 | 월 누계·미수·미지급·준비금·정책 영향 집계 | 월 손익 후보, 현금 변화, 반복 예외, 예측 대비 차이 | 월 운영 결산 판본 |
| 13주마다 | 13주 actual/forecast와 정책별 성과 집계 | 최저 현금, 예측오차, 서비스 수준, 예외 추세, 다음 13주 정책·자금 방어선 | 13주 종합 검토 판본 |

13주 전망 자체는 매주 앞으로 이동하며 갱신한다. `13주마다 확인`은 전망을 그때만 계산한다는 뜻이 아니라, 13주 누적 실제 결과와 예측 정확도·정책을 깊게 재검토하는 별도 종합 점검이다.

## 3. 일마감과 운영자 확인의 분리

시스템은 필요하면 매일 자동 대사·일마감 후보를 만들 수 있다. 정상이고 기준 안에 들어온 일마감은 운영자에게 매일 승인을 요구하지 않는다. 다음 조건만 즉시 운영자에게 올린다.

- 금액이나 건수가 허용 범위를 벗어난 대사 차이
- 중복 지급·중복 환급 가능성
- 지급기일이 임박했는데 대상·금액이 확정되지 않은 사건
- 증빙 누락으로 정산 묶음을 닫을 수 없는 사건
- 마감 뒤 과거 값을 바꾸려는 조정·재개 요청

## 4. 운영자 화면

- 평상시에는 상단 네 지표와 다음 정기 확인 시각만 보여준다.
- 예외가 없으면 정상 거래 목록을 운영자의 할 일 목록에 만들지 않는다.
- `정산 확인 필요` 상세에는 원인, 영향 범위, 금액, 기한, 자동으로 수행한 조치, 운영자가 고를 수 있는 조작만 표시한다.
- 주간·월간·13주 확인 화면은 같은 통합 운영 화면의 기간별 조회이며 별도 회계 앱이 아니다.
- 정상 건별 자료는 감사·문의 때만 추적 조회한다.

## 5. 검증

- 정상 거래만 있는 기간에는 운영자 예외 할 일이 0건이어야 한다.
- 한 사건의 불일치가 다른 정상 주문·지급을 막지 않아야 한다.
- 외부 효과를 보류한 사건은 관리자 확인 또는 안전한 자동 재대사 없이 지급·환급되지 않아야 한다.
- 주간 합계 4개가 월간 합계와 이어지고, 13주 actual 합계와 원 재무 사건 합계가 일치해야 한다.
- 매주 갱신한 13주 전망과 13주 종합 검토를 중복 집계하지 않아야 한다.
- 모든 확인 판본은 기간, source revision/hash, 자동 처리 결과, 남은 예외와 확인자를 기록한다.

## 6. r39에서 폐쇄된 질문

주간 마감 결과에는 `정산 완료율`을 표시하지 않는다. `이번 주 정산 총액`, `정산 후 가용현금`, `정산 확인 필요`만 기본 표시하고 정상 건별 목록은 필요할 때만 연다. 상세 기준은 `weekly-settlement-summary.r39.md`가 소유한다.
