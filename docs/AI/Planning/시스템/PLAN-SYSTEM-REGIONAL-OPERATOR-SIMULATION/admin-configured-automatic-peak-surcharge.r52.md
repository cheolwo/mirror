## 확정

피크 부족 할증은 `관리자 설정 + 정책 범위 안 자동 적용`으로 운영한다.

관리자는 정책 판본에서 다음을 정한다.

- 적용 배달운영권역과 행정동
- 기본 피크시간과 요일·공휴일 예외
- 유상 할증 단계 수와 단계별 건당 정액
- 기사 부족 판정 기준과 단계 진입·해제 조건
- 최소 유지시간과 재활성화 대기시간
- 주문당·시간대별·일별 총예산
- 가용현금 방어선과 신규 할증 중단 조건
- 날씨 등 다른 할증과의 합산 상한
- 수동 중단·원복과 긴급 예외 승인 역할

시스템은 승인된 정책 판본 안에서 다음을 자동 판정한다.

1. 현재 시각이 피크시간에 포함되는지 확인한다.
2. 위험 주문·가용 기사·복귀 예정·알림 반응으로 실제 부족 단계를 계산한다.
3. 남은 예산과 현금 방어선을 검사한다.
4. 적용 가능한 할증 단계와 지속 가능 예상시간을 Preview한다.
5. 자동 적용 권한이 있는 범위에서는 해당 단계를 활성화하고, 범위를 벗어나면 운영자 확인을 요청한다.

관리자가 정책을 바꾸면 새 정책 revision부터 신규 배차 제안에 적용한다. 이미 기사가 수락한 주문의 지급액은 이전 revision대로 보존한다.

## 자동화 경계

- 시스템이 정책 범위 밖의 금액·시간·대상을 새로 만들어 적용하지 않는다.
- 피크시간이라는 이유만으로 실제 기사 부족 근거 없이 유상 할증을 켜지 않는다.
- 실제 부족이 피크시간 밖에서 발생하면 정책이 허용한 비정기 부족 규칙이 있을 때만 자동 적용한다.
- 가용현금 하락은 이미 확정된 기사 지급액을 줄이는 근거가 아니다.
- 예산 부족이나 현금 방어선 충돌은 기사 부족 해소로 기록하지 않고 `재무 제한으로 신규 할증 불가` 사건으로 분리한다.

## 현금 연동의 두 방식

### A. 금액은 고정하고 활성 범위를 제한

- 단계별 건당 금액은 관리자 정책대로 유지한다.
- 가용현금은 새 할증 활성 여부, 총예산과 지속시간을 제한한다.
- 기사에게 제시되는 금액이 안정적이고 재현·정산이 쉽다.

### B. 현금에 따라 건당 금액도 변화

- 현금 수준별 계수를 단계 정액에 곱한다.
- 더 유연하지만 동일 부족 단계의 금액이 시점마다 달라져 기사 설명·회계·분쟁 대응이 복잡해진다.

어느 방식이든 수락된 주문의 지급액은 소급 변경하지 않는다.

## 미정

- 현금을 건당 금액에 반영할지, 활성 범위에만 반영할지
- 유상 단계 수와 실제 원화 금액
- 자동 적용 권한 범위와 운영자 확인 기준
- 최초 Simulation용 피크시간 Fixture

## 다음 질문 하나

가용현금은 피크 할증에 어떻게 반영할까?

1. `단계별 금액은 고정하고, 현금으로 신규 활성·총예산·지속시간을 제한` — 추천. 기사 금액은 예측 가능하게 유지하면서 플랫폼의 현금 방어선을 지킨다.
2. `현금 수준에 따라 건당 할증액도 자동 증감` — 유연하지만 같은 부족 단계에서도 금액이 흔들린다.
3. `현금은 경고만 표시하고 자동 적용에는 반영하지 않음` — 단순하지만 운영자가 놓치면 지급의무가 방어선을 넘을 수 있다.
