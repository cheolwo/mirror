## 확정

스토리·캠페인·코드 구현보다 64괘 각각의 괘상 의미를 먼저 정립한다.

- r100의 코드 구조와 r101의 첫 시즌 이야기는 삭제하지 않고 `DeferredReference`로 보존한다.
- 두 문서는 향후 의미 확정 뒤 다시 검토할 후보이며, 현행 구현·스토리 기준선으로 승격하지 않는다.
- 현재 괘의 의미가 확정되지 않은 상태에서 운영 사건·상태 전이·수치·UI·Unity 표현을 먼저 만들지 않는다.
- 기존 코드와 Unity 작업도 이 의미 문답 때문에 자동 변경하거나 되돌리지 않는다.

## 괘별 검토 순서

각 회차는 두 괘를 다음 순서로 살핀다.

1. 괘 이름과 여섯 효의 모양.
2. 상괘·하괘와 각각의 자연상.
3. 원형 의미와 두 괘의 대비·연결.
4. 지금까지 이어진 전체 흐름 안에서의 의미 후보.
5. 사용자의 해석과 보완.
6. 의미 확정 여부.

효사는 괘 전체 의미를 이해하는 데 필요한 경우에만 참고한다. 효별 운영 단계·퀘스트·API·WI로 자동 변환하지 않는다.

## 현재 위치

- 제1괘~제20괘: 지금까지의 문답에서 운영·성장 흐름의 의미를 정리했다.
- 제21괘 화뢰서합·제22괘 산화비: 괘상·상괘·하괘와 원형 의미를 검토했으나, 현재 이야기 안의 최종 의미는 아직 확정 전이다.
- 다음 순서: 21·22괘 의미를 닫은 뒤 제23괘 산지박·제24괘 지뢰복의 괘상을 검토한다.

## 이후 재개 관문

64괘 의미 정립이 충분히 진행된 뒤에만 다음을 다시 연다.

```text
괘상 의미 확정
→ 상위 이야기 구간 정리
→ 운영 캠페인 후보 선정
→ 실제 업무 사건과 결속
→ 코드 Profile·상태 전이 설계
→ 앱·Unity 표현 설계
```

스토리와 코드는 괘상 의미에서 영감을 얻지만, 괘의 배열이나 상징을 강제 상태 기계로 만들지 않는다.
