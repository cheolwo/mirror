## 기존 기획에서 확인한 재사용 구조

기존 절기 기획은 다음 구조를 이미 확정하거나 승인 기준선으로 보유한다.

1. `실시간 현장 플레이 → 일 단위 WorldTick → 절기 마감 전략 턴`의 세 시간층.
2. 한 절기를 `초반 → 중반 → 후반`으로 나누고 사이에 두 번의 전략 분기를 둔다.
3. 새 절기 시작에 동결된 덱에서 아르카나 세 장을 제안하고 한 장과 대응을 선택한다.
4. 카드가 생산·운송·재고·업무 완료를 직접 만들지 않고, 기존 규칙이 허용한 입력과 보정 후보만 제공한다.
5. 카드 선택은 Preview와 명시적 Confirm을 거치며 판본·seed·제안·선택·버림·재섞기 이력을 보존한다.
6. 절기·날씨·제철 원자료와 게임 해석을 분리하고, 절기 이름만으로 수요·가격·생산·성공을 확정하지 않는다.
7. 절기 표현은 권위 상태 사본을 읽는 Presentation이며 복장·식생·날씨 화면이 업무 상태를 확정하지 않는다.

Farm 방어·공세, 개인 학습 카드와 NPC 교습 내용은 배달 플랫폼 운영 게임으로 자동 이식하지 않는다. 시간층, 캠페인 마감, 아르카나 제안·선택·효과 권위와 결정성만 재사용한다.

## 배달 플랫폼 운영 캠페인으로의 번역

### 실시간 운영 회차

- 점심·저녁 피크와 평시 주문·조리·배차·이동·전달·기사 복귀를 디오라마에서 진행한다.
- 운영자는 기사 공급 알림, 피크 할증, 자동화 범위와 예외 처리를 선택한다.
- 개별 Actor 직접 조작보다 정책과 자원 배분을 우선한다.

### 일 단위 운영 마감

- 주문 완료·미완료·취소·지연, 기사 수행대금과 플랫폼 비용을 집계한다.
- 정상 재무 사건은 자동 처리하고 `정산 확인 필요`만 예외로 올린다.
- 다음 날의 기사 가용성·음식점 운영 상태·정책 예산과 현금 전망을 갱신한다.

### 절기 캠페인 마감

- 초·중·후반의 서비스 수준, 기사 공급, 음식점 부담, 고객 지연, 정책 비용과 현금 변화를 비교한다.
- 실제 공공자료의 기준일·품질·날씨·시장·제철 관측과 Simulation 해석을 분리해 보여 준다.
- 다음 절기에 유지·수정·원복할 운영 정책을 Preview한다.
- 절기 마감은 자동 화면 연출이 아니라 상태 사본과 명시적 마감·재조회로 확정한다.

## 절기 초·중·후반의 두 운영 분기

| 구간 | 운영자가 보는 것 | 선택 후보 예시 |
| --- | --- | --- |
| 초반 | 이전 절기 이월, 예상 수요, 기사 공급, 제철·기상 자료 품질 | 안전 기본값, 기사 알림 준비, 예산 배분 |
| 분기 1 | 실제 수요와 기사 반응, 음식점 병목, 첫 현금 오차 | 피크 시간 조정, 할증 범위, 음식점 보호 |
| 중반 | 정책 효과와 부작용, 인접 권역 유입·유출 | 유지, 축소, 확대, 협력 권역 지원 후보 |
| 분기 2 | 후반 수요·기상 위험·예산 잔액 | 회복·재정비, 제한적 확대, 원복 |
| 후반·마감 | 서비스·재무 결과와 다음 절기 이월 | 캠페인 결산과 다음 카드 대응 준비 |

정확한 절기 길이와 현실 날짜 동기화는 기존 기획처럼 별도 시간 Profile이 소유한다.

## 아르카나 카드의 운영 역할

절기 시작에 세 장을 제안하고 한 장과 운영 대응을 선택하는 기존 구조를 재사용할 수 있다.

| 카드 예시 | 배달 운영 질문 예시 | 허용 가능한 첫 연결 |
| --- | --- | --- |
| 전차 | 빠른 배차, 안전 운행, 합배송 중 무엇을 우선할까 | 배차 후보 점수·묶음 허용 상한의 Simulation 보정 후보 |
| 정의 | 공정 배분, 분쟁 재검토, 증거 강화를 어디까지 할까 | 기사 제안 편중·예외 검토 기준의 보정 후보 |
| 절제 | 기사 공급·주문 허용·현금 방어의 균형을 어떻게 잡을까 | 할증 예산·알림 빈도·완충 범위의 보정 후보 |
| 여제 | 음식점·지역 상품의 성장과 노동 부담을 어떻게 조절할까 | 합성 메뉴 수요·음식점 처리 여유의 보정 후보 |

카드는 실제 공공자료, 주문, 기사, 지급이나 매출을 직접 바꾸지 않는다. 같은 카드라도 선택한 대응·방향·정책 판본에 따라 Simulation의 허용된 계산 입력만 조정한다. 카드가 없어도 핵심 배달 운영은 기본 규칙으로 완주 가능해야 한다.

## 제철·공공자료 연결

- 제철 품목은 `원천 사실 → 검토한 절기 대응 → 게임 해석`의 세 층을 유지한다.
- 공식 자료가 말한 월별 추천, 제철, 출하, 가격, 기상 관측을 서로 같은 사실로 합치지 않는다.
- 제철 품목은 합성 메뉴·시장 관심·주문 구성의 후보 입력이 될 수 있지만 주문량 증가를 자동 확정하지 않는다.
- 사가정시장 등 지역 시설의 공개 자료가 검증되면 캠페인 배경과 물류 거점 후보로 연결할 수 있지만 실제 점포·메뉴·재고를 추정하지 않는다.
- Unity는 절기·기상·제철 상태를 복장·식생·시장 아이콘·주문 구성으로 표현할 수 있지만 그 표현이 수요나 가격 권위가 되지 않는다.

## 13주 전망과 캠페인

13주 현금 전망은 캠페인과 경쟁하는 별도 달력이 아니다. 각 일·절기 운영 결과의 재무 사건을 계속 받아 이동 전망을 갱신한다. 절기 마감은 서비스·정책 회고 단위이고, 13주 전망은 지급의무와 가용현금 방어를 보는 재무 도구다.

## 제안하는 중첩 구조

```text
피크 운영 회차 여러 개
→ 일 단위 운영 마감
→ 절기 초·중·후반과 두 전략 분기
→ 절기 캠페인 마감
→ 약 13주 운영 장(여러 절기)의 종합 결산
```

정확한 일수는 시간 Profile 승인 전 고정하지 않는다.

## 미정

- 절기 캠페인과 13주 운영 장의 최종 중첩 관계
- 첫 절기와 카드 덱·대응 후보
- 실제 시간과 Simulation 시간의 비율
- 제철 품목 자료가 주문 구성 후보로 들어가는 최초 범위
- 카드별 보정값·상한·하한과 현금 안전선

## 다음 질문 하나

배달 운영 캠페인의 기본 규모를 어떻게 묶을까?

1. `피크 회차 → 일 마감 → 절기 캠페인 → 13주 운영 장`의 중첩 구조 — 추천. 짧은 운영 결과와 절기 변화, 장기 현금 흐름을 모두 연결한다.
2. `절기 하나만 독립 캠페인` — 단순하지만 13주 현금 흐름과 장기 성장 연결이 약하다.
3. `13주 전체를 하나의 캠페인` — 장기 운영은 보이지만 짧은 피크 회차의 성취와 실패가 흐려진다.
