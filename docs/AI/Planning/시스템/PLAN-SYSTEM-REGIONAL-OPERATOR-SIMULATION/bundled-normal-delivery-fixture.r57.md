## 확정

초기 기준선 패키지에 `사가정 정상 음식배달 1건`을 재현 가능한 합성 Fixture로 동봉한다.

- 실제 주문·결제·음식점 영업정보·기사·주문자·GPS를 사용하지 않는다.
- 공개 가능한 현실 공간 기준선 위에 합성 음식점 역할, 합성 기사, 합성 전달지와 합성 주문을 결속한다.
- 같은 지역 자료 판본, Fixture 판본과 seed에서 같은 업무 단계·경로 후보·시간·결과가 나와야 한다.
- Unity는 단계 결과를 만들지 않고 서버 또는 동일한 Local/Remote Simulation Core의 상태 사본을 읽어 표현한다.

## 정상 7단계

1. 주문 접수
2. 음식점 수락
3. 조리 진행
4. 기사 배차·수락
5. 음식점 도착·픽업
6. 전달지 이동·전달
7. 완료·기사 가용 복귀

각 단계는 같은 `WorkStableId`, 증가하는 revision, 가상 시각, 행위자 역할과 직접 결과를 가진다. Unity의 도착 Animation이나 화면 전환만으로 단계 완료를 확정하지 않는다.

## 첫 표현

- 전체 조망에서 음식점·기사·전달지를 식별할 수 있다.
- 대상 선택 시 합성 데이터 표시, 현재 단계, 다음 예상 단계와 마지막 갱신시각을 보여 준다.
- 검증된 이동 graph 구간만 경로 이동으로 표시한다.
- 공간 연결이 없는 구간은 `이동 중`과 마지막 확인 지점으로 표현하며 실제 골목 경로를 추정하지 않는다.
- 정상 흐름에는 예외 카드·피크 할증·재배차를 자동으로 끼워 넣지 않는다.

## 완료·검증

- 첫 실행은 인터넷 없이도 동봉 지역 판본과 Fixture로 끝까지 재생 가능해야 한다.
- 일시정지·배속·대상 선택 뒤에도 상태 revision이 뒤섞이지 않아야 한다.
- 저장 후 재진입하면 같은 지역 자료 판본과 Fixture 진행 지점으로 돌아온다.
- 같은 seed 반복 결과와 Save/Replay 결과를 비교할 수 있어야 한다.

## 미정

- 첫 실행 중 허용할 사용자 개입 범위
- 기본 Simulation 시간 배율과 예상 완주 시간
- 합성 음식점·메뉴·기사·전달지의 표시명
- 검증된 이동망 결손 구간의 첫 Fixture 경로 선정
