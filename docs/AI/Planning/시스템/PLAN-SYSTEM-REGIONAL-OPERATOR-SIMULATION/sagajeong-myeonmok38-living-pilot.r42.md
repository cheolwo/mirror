## 1. 이번에 확정한 기준

사가정역에서 이미 발전시킨 1km × 1km 디오라마를 첫 생활상 참조 창으로 유지한다. 이 창은 화면과 관찰의 기준이며 행정동 경계에서 잘라내거나 다시 만들지 않는다.

사가정역의 대표 행정동과 첫 운영·집계 권위는 `면목제3·8동`으로 둔다. 면목제7동 등 관찰 창과 겹치는 다른 행정동은 인접 생활 맥락으로 계속 보이게 하되 면목제3·8동 집계나 운영 객체로 복제하지 않는다.

```text
사가정역 1km 관찰 창
  ├─ 면목제3·8동: 첫 운영·집계 권위
  ├─ 면목제7동 등: 인접 맥락, 자기 행정동 귀속 유지
  └─ Unresolved: 현재 경계·위치 근거로 판정할 수 없는 객체
```

- 건물은 검증된 대표점으로 정확히 한 행정동 또는 `Unresolved`에 귀속한다.
- 도로·보행선은 경계를 가로지를 수 있으므로 행정동별 선분으로 나누되 같은 실체의 계보를 유지한다.
- 인접 행정동 객체를 면목제3·8동 객체로 복제하지 않는다.
- 1km 창 밖에서 들어오거나 나가는 합성 Actor는 경계 연결점과 상태 사본이 준비된 뒤에만 표현한다.
- 현재 디오라마의 카메라·건물 밀도·색·배치·성능과 Game View는 후속 변경의 회귀 기준선이다.

## 2. 생활상 표시 계층

한 장면에 모든 의미를 섞지 않고 다음 표시 계층을 독립적으로 켜고 끌 수 있게 발전시킨다.

1. **현실 공간 바탕**: 건물 윤곽·높이 근거, 도로, 역 출구, 주소·필지 참조.
2. **경계·귀속**: 행정동 경계, 건물의 단일 귀속, 경계 교차 도로, 결손·출처·판본.
3. **이동 기반**: 차로·이면도로·골목·보도·횡단보도·정지선·신호 후보. 검증 전에는 통행 권위로 쓰지 않는다.
4. **건물 역할·사업장**: 한 건물 안의 음식점·주거 전달지·창고 등 복수 역할과 공개 가능한 사업장 후보.
5. **생활 업무**: 주문자·음식점·기사의 음식배달 7단계와 실제 발생한 지연·재배차·수령자 부재 예외.
6. **운영·재무**: 점심 피크, 기사 가용성, 주간 정산, 월간 전월 비교, 13주 현금 전망과 `정산 확인 필요`.
7. **정책·서원·카드**: 승인 판본을 참조하는 운영 정책과 비구속 서원·아르카나·주역 표현. 아래 계층의 사실을 변경하지 않는다.

## 4. 현재 확인된 결손

- 사가정 화면 건물 4,062개는 주소 판정과 PNU 판정을 갖지만 고유 PNU 3,774건의 실제 필지 경계 도형은 현재 0건이다.
- 현재 면목제3·8동 projection의 건물 250·도로 선분 722·타일 3은 사가정 기준 건물 602개와 역사적 경계에서 만든 좁은 후보이며 현행 공식 경계 결속을 대체하지 않는다.
- 출입구, 현행 통행 graph, 차로 방향, 정지선, 신호 현시·주기는 아직 같은 판본으로 닫히지 않았다.
- 횡단보도·교차로·보행망 후보는 통행 가능성이나 신호 제어를 확정하지 않는다.
- 사업장 후보는 현재 영업, 건물·출입구 결속, 공개·광고 승인 전까지 주문 목적지나 Unity 상호명 표식으로 쓰지 않는다.
- 공공 통계는 밀도·시간대 후보의 근거일 뿐 실제 주민의 직업·행동이나 개별 NPC 수요를 증명하지 않는다.

## 5. 첫 생활상 수직 절편

첫 절편은 면목제3·8동에 귀속이 확인된 음식점 역할 건물 하나, 합성 기사 한 명, 전달지 역할 건물 하나를 사용한다. 실제 개인·실제 주문·실제 결제는 사용하지 않는다.

```text
합성 주문 접수
  → 음식점 수락
  → 조리 중
  → 픽업 준비
  → 기사 픽업
  → 이동
  → 전달 완료
```

- 서버와 Unity는 같은 `WorkStableId`, revision, 행정동 귀속과 일반화 표시 좌표를 사용한다.
- 면목제7동 등 인접 배경은 보이지만 이 절편의 면목제3·8동 운영 집계에는 포함하지 않는다.
- 검증된 이동 graph가 없으면 Actor를 실제 도로를 따라 움직였다고 주장하지 않고 기존 상대 경로 후보 또는 정적 단계 표현에 머문다.
- 정상 7단계를 먼저 닫은 뒤 조리 지연·보호 재배차·수령자 부재를 서로 다른 후속 절편으로 연다.

## 6. Graph Map 영향 후보

기존 역 관찰 창·행정동·업무 객체의 안정 식별자를 재사용한다. 이번 기획에서 Graph Map 원본을 직접 수정하거나 관계를 확정하지 않는다.

- `RepresentativeObservationWindowFor`: 사가정 1km 창이 면목제3·8동 생활상 첫 관찰 기준임을 나타내는 후보.
- `PrimaryAdministrativeAuthority`: 첫 운영 집계가 면목제3·8동을 기준으로 함을 나타내는 후보.
- `IntersectsAdministrativeArea`: 관찰 창이 면목제7동 등 다른 행정동과 겹침을 나타내는 후보.
- `ProjectsOperationalStateFrom`: 서버 상태 사본이 Unity 표현으로 투영됨을 나타내는 후보.

상태는 `ReadyForGraphMapReview`이며 Graph Map 담당 검토 전 `Integrated`로 보고하지 않는다.
