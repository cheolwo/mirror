## 확정

배달 플랫폼 운영 기획에서는 효사 여섯 개를 각각 운영 단계로 대응하지 않는다. **괘 하나를 전체 의미로 읽어 운영 캠페인 하나의 주제·압박·판단·회복 방향으로 기획한다.**

- 64괘는 최대 64개의 운영 캠페인 의미 틀로 사용할 수 있다.
- 각 캠페인의 실제 단계 수는 해당 운영 사건과 기존 업무 수명주기에 따라 정한다.
- 캠페인이 여섯 단계일 필요는 없고, 효의 순서가 API·상태 전이·Unity 진행 순서가 되지 않는다.
- 효사는 괘 전체를 이해하거나 세부 장면의 영감을 얻기 위한 참고 자료로 남지만, 효별 완료 조건·공간·WI를 자동 생성하지 않는다.
- 기존 64괘 스토리 정본의 효별 연구와 운영 게임의 괘 단위 캠페인은 서로 다른 기획 투영이다. 어느 한쪽이 다른 쪽의 승인 상태를 바꾸지 않는다.
- 64개 캠페인을 한 번에 구현하거나 정식 순서대로 강제 플레이하지 않는다. 현재 필요한 운영 상황을 하나씩 문답하고 승인된 캠페인만 개발 인계한다.

## 괘 단위 캠페인 카드

각 괘는 다음 한 장으로 먼저 기획한다.

| 항목 | 의미 |
| --- | --- |
| 괘 전체 의미 | 캠페인이 다루는 변화·긴장·판단의 중심 |
| 운영 상황 | 실제로 관찰되는 주문·기사·음식점·지원·재무 사건 |
| 운영자 역할 | 무엇을 보고 어디까지 결정할 수 있는가 |
| 압박 | 아무 조치를 하지 않거나 잘못 선택했을 때 악화되는 것 |
| 선택 | 기본값 유지, 제한 정책 적용, 원복 등 허용된 조작 |
| 대가 | 서비스·노동·현금·신뢰·자료 품질에 생기는 부담 |
| 성공 | 완벽한 결과가 아니라 캠페인 의미를 충족한 안정 상태 |
| 실패·회복 | 숨기지 않을 결손과 가장 이른 회복 진입점 |
| 공간 보완 | 운영 판단을 위해 디오라마에 추가로 필요한 판독 요소 |
| 다음 선택 | 자유 운영, 다른 캠페인, 같은 캠페인 재도전 |

이 카드는 괘의 뜻을 수치 공식으로 바꾸는 표가 아니다. 먼저 사람과 업무 사건을 구체화하고, 괘는 그 사건을 어떤 방향으로 읽고 판단할지 정하는 의미 틀로 사용한다.

## 수뢰둔 캠페인의 전체 해석

사가정·면목제3·8동 첫 점심 피크는 수뢰둔 전체를 다음과 같이 사용한다.

> 새 플랫폼에 주문과 움직임이 생기기 시작했지만 기사·음식점·경로·자료·현금의 연결은 아직 충분히 정리되지 않았다. 성급히 처리량과 권역을 키우지 않고, 작은 범위에서 책임·관계·정보·안전선을 세워 혼란을 운영 가능한 질서로 바꾼다. 다만 계속 판단을 미루며 적체를 방치하지 않고, 필요한 제한 조치와 회복을 실행한다.

따라서 수뢰둔 캠페인의 실제 진행은 음식배달 OS와 Campaign Core가 요구하는 사건 흐름을 따른다.

`피크 징후 관찰 → 원인·자료 품질 확인 → 기본값 또는 제한 정책 Preview → Confirm → 시간 경과와 예외 관찰 → 결산·유지·원복·회복`

이 단계들은 효사에 1:1 대응하지 않으며 운영 사건에 따라 합쳐지거나 반복될 수 있다.

## 디오라마 축적 원칙

공간도 효별 여섯 묶음으로 만들지 않는다. 괘 단위 캠페인 카드에서 운영 판단에 필요한 공간 보완을 한 묶음으로 추출한다.

- 주문 밀집과 가용 기사 분포를 읽는 행정동 오버레이
- 실제 음식점·픽업 접근점·도로·골목과 자료 품질
- 기사 부족·조리 지연·위치 중단 등 예외의 원인별 위치 결속
- 플랫폼 부담 정책의 적용 권역과 비용 영향
- 자료가 없는 이동의 `이동 중` 또는 `자료 미확정` 표현

기존 현실 공간 기준선을 보존하고, 승인된 운영 판단에 필요한 오버레이·앵커·표현만 누적한다. 괘를 선택했다는 이유만으로 건물·도로·H·Graph Map을 새로 만들지 않는다.
