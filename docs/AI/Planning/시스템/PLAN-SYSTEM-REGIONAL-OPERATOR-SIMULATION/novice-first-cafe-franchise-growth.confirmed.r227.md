## 2. 기본 경로 — 초보를 키워 다음 점포를 맡긴다

```text
플레이어가 1호점의 기초 운영을 익힘
  → 초보 가족/직원이 합류해 함께 배우고 현장 작업을 맡음
  → 그 사람이 현장 책임을 연습하고 맡길 범위를 검토
  → 준비된 사람이 다음 점포의 현장을 맡음
  → 기존 점포에 새 초보가 들어와 같은 과정을 배움
  → 준비된 지도자가 다음 사람을 키우며 3·4·5호점으로 확장
```

이 기본 모집에서는 **가족도 외부 직원도 카페 실무 초보**다. 가족과 함께 준비하며 소통/인계가 익숙할 수는 있지만, 그것이 바리스타 경력·제조/관리 숙련을 가진다는 뜻은 아니다. 혈연만으로 실무/권한을 지급하지 않는 r226 경계는 유지한다.

외부 초보를 맞이해 익히고 맡기는 경험 자체가 기본 게임의 성장이다. 경력자만 찾아 점포를 즉시 늘리는 것을 기본 성공 전략으로 안내하지 않는다. 2호점 이후 모든 신규 직원도 초보로 시작하며, 단계가 높아졌다고 모집 풀을 자동으로 경력자로 교체하지 않는다.

가족 기반 없이 외부 초보와 시작하거나 작은 사업을 유지하는 경로도 가능하다. 인원/점포 수만으로 수요·매출·지도 능력이나 플랫폼 권한이 생기지 않는다. 같은 상권 수요를 점포마다 복제하지 않는다.

## 6. 육성의 반복에서 생기는 선택과 귀환

- 지금/여기: 현재 한 동의1호점에서 새 초보와 일하며 다음 점포를 검토하는 운영 회차.
- 나: 직접 일도 하고 발주·정산·예외를 결정하는 플레이어. 가르칠 사람/시간·자금·본부 검토 여력을 준비해야 함.
- 너: 같은 실무 초보로 들어온 가상 인물과 정해진 작업·지도자/자리·실습 근거.
- 이렇게: 작은 작업을 함께 익힘→수행/실패·도움 요청 확인→정상 운영/보고/재개 실습→맡길 범위 검토/배치→기존 점포/후속 인재로 귀환.
- 대가/회복: 지도자의 생산/검토 여력과 보수·재료/시간·확장 지연. 부족하면 추가 연습·업무 축소·지원 배치·다음 출점 보류. 초보 합류만으로 영업/숙련을 자동 완료하지 않음.
- 상위 목적: 다른 사람이 일을 이해하고 깨어서 수행하도록 지원하며 그 사람에게 보수/기여가 돌아가는 r223/r224 목적을 경험한다. 실패/관찰/교육도 깨어 있는 활동의 대상이라는 r206 방향을 유지하고 숙련·의식/명덕·업무 성공은 구분한다.

직접 시범/집중 플레이와 관찰·준비된 지도자에게 맡기는 참여 방식은 유지한다. 모든 사용자가 매 교육을 직접 미니게임으로 수행해야 한다는 새 강제 규칙은 아니다. 실제 학습/지원과 결과를 같은 인물/현장으로 연결하고 장면을 열어 본 횟수로 숙련을 지급하지 않는다.

**다음 질문 하나:** 현장 책임은 교육 횟수만으로 넘기지 않고 **정상 운영과 이상 보고·플레이어 결정 후 재개를 실제로 확인한 뒤 맡길 범위를 검토하는 방식**으로 잡을까요? 초보가 자란 경험을 읽기 쉽지만 실습/실패·회복의 구체 업무와 지도자 결속이 필요하다.
