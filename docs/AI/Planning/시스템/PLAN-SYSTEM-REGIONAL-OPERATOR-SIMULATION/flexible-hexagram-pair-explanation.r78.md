## 확정

64괘 운영 캠페인을 설명할 때 전통 배열에서 짝을 이루는 괘는 가능한 한 함께 설명한다.

- 앞 괘에서 열린 문제·움직임·욕구와 뒤 괘에서 드러나는 반대 관점·성찰·정돈을 나란히 본다.
- 수뢰둔·산수몽처럼 괘상을 위아래로 뒤집은 관계와 서괘의 전후 의미를 우선 대조한다.
- 모든 홀수 괘를 양, 모든 짝수 괘를 음으로 고정하지 않는다.
- 짝 관계는 캠페인 주제와 전환을 이해하는 기획 도구이며 상태 전이·성공 수치·공간 생성 규칙이 아니다.
- 각 괘는 여전히 독립 Campaign 상태와 선택·결과·회복을 가지며, 앞 캠페인 완료가 뒤 캠페인의 자동 성공을 뜻하지 않는다.

## 설명 형식

향후 괘 설명은 효사별 풀이 없이 다음 순서로 진행한다.

1. 두 괘의 전체 괘상과 상괘·하괘
2. 각 괘의 중심 의미
3. 두 괘가 서로 뒤집힐 때 달라지는 관점
4. 배달 플랫폼 운영에서 사용할 수 있는 캠페인 방향 후보
5. 사용자 선택 전에는 확정하지 않을 수치·공간·업무 결속
