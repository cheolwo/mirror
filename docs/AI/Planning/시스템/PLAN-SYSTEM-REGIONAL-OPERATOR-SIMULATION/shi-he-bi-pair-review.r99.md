## 제21괘 화뢰서합(火雷噬嗑)

```text
━━━━━━  상괘 리(離) — 불·밝음·분별
━━  ━━
━━━━━━
━━  ━━  하괘 진(震) — 우레·움직임·실행
━━  ━━
━━━━━━
```

### 괘상

- 아래에서는 우레가 움직이고 위에서는 불과 번개가 밝힌다.
- 진괘가 행동을 일으키고 리괘가 무엇이 막고 있는지 분명히 드러낸다.
- `서합(噬嗑)`은 입안에 낀 단단한 것을 깨물어 없애 위아래의 이가 다시 맞물리게 한다는 형상이다.
- 관계와 업무가 합쳐지지 못하는 이유를 찾아 장애를 제거해야 비로소 통한다.

### 원형 의미

- 사실과 책임을 밝게 확인한다.
- 모호한 기준을 명확한 규칙으로 바꾼다.
- 사람 사이를 가로막는 위반·누락·분쟁을 방치하지 않는다.
- 행동할 때는 근거·절차·비례성을 갖추며, 힘만으로 상대를 꺾지 않는다.
- 전통 원문의 형벌·옥사 의미는 현대 기획에서 자동 처벌이 아니라 증거·절차·이의 제기를 갖춘 분쟁 해결의 경계로 번역한다.

### 현재 이야기 후보

- 지택림에서 뿌리를 내리고 풍지관에서 정착 계획을 세운 뒤 실제 실행을 시작한다.
- 실행 중 중복 권한·끊긴 API·모호한 책임·미완료 인계 같은 장애가 드러난다.
- 운영자는 원장과 증거를 확인해 장애를 분류하고, 책임 있는 담당과 회복 절차를 연결한다.
- 플랫폼이 세상에 정착하려면 좋은 의도만이 아니라 막힌 일을 풀 수 있는 공정한 규칙이 필요하다는 것을 배운다.

## 제22괘 산화비(山火賁)

```text
━━━━━━  상괘 간(艮) — 산·경계·멈춤
━━  ━━
━━  ━━
━━━━━━  하괘 리(離) — 불·밝음·형상
━━  ━━
━━━━━━
```

### 괘상

- 산 아래의 불이 주변을 비추어 산의 형태와 무늬가 드러난다.
- 리괘의 밝음과 표현을 간괘의 경계가 절제하여, 실질을 알아보기 좋은 형태로 정돈한다.
- `비(賁)`는 꾸밈·문채·형식을 뜻하지만, 내용 없는 장식이 실질을 대신한다는 뜻은 아니다.

### 원형 의미

- 복잡한 일을 다른 사람이 이해할 수 있도록 밝고 질서 있게 표현한다.
- 일상의 여러 행정과 업무를 명료하게 만드는 데 형식과 표현이 도움을 준다.
- 그러나 화려한 화면이나 문구만으로 중대한 분쟁·형벌·책임을 판정해서는 안 된다.
- 표현은 실질을 돕는 작은 전진이며, 근거와 내용보다 앞서면 안 된다.

### 현재 이야기 후보

- 화뢰서합에서 정리한 규칙·상태·회복 절차를 앱 화면과 Unity 디오라마에서 이해하기 쉽게 보여 준다.
- 주문자·음식점·기사·운영자가 자기에게 필요한 상태와 다음 행동을 구분할 수 있게 한다.
- 건물 카드·NPC 상태·운영 사건·지역 레이어가 같은 원장을 서로 다른 관점으로 표현한다.
- 시각 효과·아르카나·괘상·색상은 분위기와 해석을 돕지만 업무 상태나 판정 권위를 바꾸지 않는다.
