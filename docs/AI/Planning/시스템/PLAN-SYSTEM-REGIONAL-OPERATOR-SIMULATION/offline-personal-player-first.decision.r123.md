## 확정한 우선순위

상시 서버나 유료 API를 필수로 두지 않는 Windows 개인용 게임을 먼저 준비한다. 실제 배달 운영·계정/결제/배차·협업 서비스를 지금 활성화하는 방향으로 확대하지 않는다. 사용자 발화의 비용 의도는 직접 답변으로 확인했으며 경제 상황이나 총 제작비를 추정하지 않는다.

장기 방향은 사가정에서 시작하는 디오라마 경영 게임과 롱폼 영상 활용이다. 첫 실행 파일은 현재 구현된 로컬 기능을 재사용한 작은 체험판으로 만들고, 실제 실행/저장과 설치 경로를 검증한다. 기존 [서버·Simulation·Unity 책임](../../../../Architecture/OperationsSimulationUnity작업흐름분리.md)과 Solo/LocalProcess 원칙은 유지한다.

## 첫 실행판에 실제로 담을 것

현재 `SagajeongFoodLife` 로컬 프로필의 3D 음식생활 관찰을 재사용한다. 재생/일시정지·1초 진행·전체 보기/기사 추적·로컬 저장을 기존 Runtime이 처리한다. 새 경영 규칙이나 주문 선택·대가를 이번 포장 작업에서 임의로 추가하지 않는다. 기존 기능의 실제 Windows Player 동작은 빌드 후 별도로 확인한다.

현재 r114/r53의 2,247건물·세 점포 상세·공통 표면층은 Editor 전용 비공개 연구다. 첫 Player를 빌드한다고 이 표현이 자동으로 들어가지 않는다. 작은 기존 사가정 생활 관찰과 최신 상세 디오라마를 구분하고, 후자의 Runtime 이식은 자료 사용 범위·모듈 조립·상호작용 명세를 결속한 후속 작업으로 둔다. MP4 재생기를 3D 게임으로 표시하지 않는다.

## 구현·설치 경계

- 공식 `SimulationWorldShell` Scene만 빌드한다. 기존 RoadReviewGame 빌더의 root 전체 삭제/치환 방식을 재사용하거나 새 공식 Scene을 만들지 않는다. 기존 Scene과 다른 모듈을 보존한다.
- 별도 Unity checkout의 새 Editor 빌드 도구 `사가정개인용PlayerBuild.cs`로 Windows x64 Mono 산출물을 만든다. 원본 Scene은 보존한다. 초기 PlayerSettings 원문 보존 사고의 정확 복구는 미완료이며 현재 기준 원문 사본·복귀·해시는 별도로 확인한다.
- 포장 관문은 canonical 정책/진입 Scene, 사가정 자료 결속·로컬 프로필/조회 차단, 원본 보존과 실제 Player에 한정한다. 초기 추가 점검의 전체 월드 검사는 `SimulationWorldShellBuilder.cs:842`에서 구성 요소의 null 참조로 실패했다(attempt5/6). Missing Script 가능성을 조사했으나 첫 엔진 집계는 0이어서 원인·GUID를 단정하지 않는다. 전역 검사·Scene·누락 슬롯을 고치거나 제거하지 않으며, 이 알려진 실패의 원래 stack·객체 경로·개수를 별도 진단으로 보존한다. 그 외 예외는 빌드를 중단한다. 사가정 포장 통과를 Farm/Hub 전체 배선·canonical 전체 정상·E 승격으로 해석하지 않는다.
- `운영관찰WorldController.cs`는 사가정 로컬 프로필에서 Transport/Client 생성과 OnEnable/Update 조회를 명시적으로 차단한다. 기존 연결 파일이 없다는 우연에 의존하지 않는다. 다른 프로필의 기존 조회 동작은 보존한다.
- 실행기는 자식 게임 프로세스에만 로컬 프로필과 전용 저장 경로를 설정한다. 운영/다른 시연 프로필의 상속 인자를 정리하고 전역 환경변수를 바꾸지 않는다.
- 게임 파일과 개인 저장 파일은 분리한다. 설치/업데이트가 기존 세이브나 다른 앱을 덮어쓰지 않도록 한다. 설치 파일·실행판 ZIP·실제 설치/실행·서명/공개 준비를 각각 판정한다.
- 산출물은 `artifacts/local/sagajeong-personal-game-r123/`에 새 판본으로 보존한다. 현재 개인 서명 인증서는 확인되지 않았고, 상업 공개 배포나 인증서 구매를 진행하지 않는다.

## 실제 검증

1. 현재 로컬 프로필의 기존 기획·코드/시험과 작업 범위를 대조한다. 포장/실행 검증을 새 게임 WI나 E 승격으로 해석하지 않는다.
2. 로컬 프로필에서는 연결 파일 유무와 무관하게 운영 조회 객체·대기 요청이 생기지 않는 회귀를 확인하고, 다른 프로필의 초기화 경로를 보존한다.
3. Windows Player의 파일/의존성·진입 Scene·빌드 결과를 확인하고 실제 실행에서 3D 표시·재생/정지·추적·저장과 재실행을 본다.
4. 설치 파일은 실제 payload와 경로/해시를 결속한다. 개인별 설치·시작 메뉴 실행과 저장 경로, 설치 전후/원본 보존을 가능한 범위에서 확인한다. 아직 하지 못한 항목은 완료로 기록하지 않는다.

## 확정·미정·다음 질문 하나

- 확정: 운영비 부담을 줄이는 개인용 게임·설치판을 먼저 준비한다. 기존 사가정 로컬 기능의 독립 실행/포장부터 검증한다.
- 미정: 정식 게임의 첫 사건·판단/대가·자유 운전과 최신 상세 표현의 Runtime 이식, 다른 권역, 공개 출시/판매. 무료라는 이유로 외부 서비스 사용조건이나 모든 제작 비용이 사라진다고 주장하지 않는다.
- 다음 질문 하나: 기존 기능의 포장/검증은 진행한다. 실제 실행 화면을 보여준 뒤 첫 직접 플레이에서 확장할 행동 한 가지를 검토한다.
