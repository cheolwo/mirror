## 1. 자료에서 확인한 것과 게임에서 새로 만드는 것

《대학》 첫머리는 **「大學之道，在明明德，在親民，在止於至善。」**이다. 주희 주석의 **「明，明之也。」**처럼 앞의 明은 밝히는 동작이고 明德은 그 대상이다. 주희는 가려진 본래의 밝음을 드러내는 것으로 설명한다. 본문의 親民과 주석의 親，當作新을 따로 보존하며 원문을 임의로 新民으로 바꾸지 않는다.

홍익학당 **대학과 중용12강 14:45–15:27 / 18:00–18:33**의 기존 저장 자막을 읽고 직접 요약했다. 판단/수양과 실제 행위로 밝은 덕을 드러낸다는 잠정 해석이다. 자동 자막이며 음성 대조 전이다. 13강44:07–44:28은 오인식과 지지/비판 맥락이 불확실해 검수 후보로만 둔다. 고전콘서트7부는 제목/공식 연결만 확인했다.

원전과 강의가 **배달 점수·동 경험치·임계 승급**을 제시했다는 뜻은 아니다. 아래 수치화는 사용자가 제안한 게임 해석이다. 게임 인물의 행위 기여를 표현하며 실제 사람의 정신/덕성 측정이나 가입·신뢰·검색 순위·역할 자격 판정에 적용하지 않는다.

## 2. 플레이어가 읽는 성장의 흐름 — 제안

**깨어 있는 인물의 유효한 업무 행위 → 명덕 실천 기여 → 기사/점포에서 확인 → 선택한 행정동의 누적 성장 → 다음 선택**으로 읽게 하는 안을 권한다.

예를 들어 같은 동에서 준비된 주문을 정확히 확인해 인수하고, 기사에게 전달된 주문을 올바른 수령 지점에 인계하면 실제 진척이 생긴다. 행위 시점의 경/무념 상태와 결과가 확인될 때 해당 행위의 기여를 남긴다. 이후 동의 성장 창에서 **이번 회차에 무엇이 얼마만큼 기여했는지와 다음 단계까지 남은 양**을 읽는다. 정확한 점수는 아직 정하지 않는다.

| 구분 | 무엇을 뜻하는가 | 다른 값과의 관계 |
| --- | --- | --- |
| 경/무념 상태·유지시간 | 지금 깨어 있는가, 어느 구간까지 유지했는가 | 행위 자격의 참고 상태. 누적 명덕 점수와 같은 단위가 아님 |
| 명덕 실천 수치 | 깨어 있는 동안 실제 일에 기여한 고유 행위의 게임 기록 | 기존 행위 기록/성장 처리와 결속할 후보. 별도 통화로 확정하지 않음 |
| 기사/작업자 성장 | 기존 유효근무·등급·유지 가능 시간과 신규 기여의 관계 | 기존 일말 성장을 명덕으로 다시 곱해 중복 보상하지 않음 |
| 점포의 빛·기여 | 점포에서 이뤄진 작업/협업 결과를 읽는 표현 | 건물 자체가 의식을 가진 것으로 처리하지 않음. 작업자 상태 또는 점포 운영 기여의 뜻은 후속 확정 |
| 행정동 레벨 | 그 동의 누적 운영 성과가 다음 경영 선택을 여는 게임 성장 | H2/H3 공간 성립·E 검증 단계·공공 인구 수치와 별개 |

## 3. 유효 행위와 집계의 경계

### 실제 반복은 성장하고 같은 결과의 재처리는 늘어나지 않는다

기존 [플레이어 중심 개발 구조](../../../../Architecture/플레이어중심게임개발업무구조.md)는 **가능하면 매 유효 반복 동작**의 성장 방향을 유지한다. 모든 배달/작업 전체를 ‘한 번만 보상’으로 제한하는 규칙은 이번에 새로 채택하지 않는다.

- 픽업 확인·제조/피킹·포장 확인·인계처럼 **실제 다른 진척을 만든 고유 행위/구간**은 각각 기여 후보가 된다. 첫 확인 범위는 이미 경 상태가 있는 기사 업무로 좁히는 안을 권하며 모든 직무 구현을 전제하지 않는다.
- 같은 Command/완료 결과 재전송·재스캔·저장 복원·화면 재열람은 새 기여를 만들지 않는다. 빈 클릭·제자리 이동·보고 열기도 성장 근거가 아니다.
- 실패가 성공으로 세어지지는 않는다. 실제 오류 확인·격리·복구·도움/교대가 유효 결과를 냈다면 별도 기여 후보로 검토한다. 실패/휴식의 명덕 차감·도움 거절 페널티는 정하지 않았다.
- 기사와 점포 창에 같은 기여가 함께 보일 수 있어도 동 합계에서는 **같은 행위 결과를 한 번**만 더한다. 서로 다른 제조/인계/배달 행위는 별도 결과다.
- 행정동 귀속은 **행위 장소/담당 동/수혜 동 중 어느 의미인지 미정**이다. 경계를 통과할 때마다 가산하지 않으며 코드·경계 판본·귀속 정책을 기여에 결속해야 한다.

### 직접 플레이와 관찰/위임

NPC가 유효한 업무를 깨어서 수행한 기본 기여와 플레이어가 집중 미니게임을 완료한 추가 보너스는 구분한다. 관찰/위임에서도 정상 운영의 성장을 읽을 수 있어야 한다. 직접 조작을 했다는 이유만으로 그 기사/점포가 깨어 있다고 확정하거나 같은 행위를 양쪽에서 다시 가산하지 않는다. 추가 보너스의 적용/수치는 기존 r146과 후속 승인 범위를 따른다.

## 5. 지도에서 보이는 방식 — 표현 제안

선택한 행정동 하나를 중심으로 다음만 먼저 읽게 한다.

1. 기사/점포의 현재 빛: **지금의 상태**를 보여 준다. 축적량과 같은 뜻으로 쓰지 않는다.
2. 유효 행위 직후 짧은 기여 알림: 무엇을 잘 처리했는지와 증가량을 보여 준다. 정확한 수치/색/애니메이션은 시안·상세 승인 전이다.
3. 동 카드: **동 레벨 / 명덕 누적 / 이번 회차 증가 / 다음 단계까지**를 구분한다. 조건이 미결정이면 확정 수치처럼 표시하지 않는다.
4. 성장 도달: 다음 경영 선택을 안내하고 같은 동으로 돌아온다. 레벨별 기능/연구/시설·다른 동 개방은 기존 해금과 결속을 정한 뒤 제안한다.

누적 기여와 현재 밝기를 분리하므로 쉬거나 경 상태가 바뀌어도 이미 성립한 기여가 사라지는 표현을 만들지 않는다. 누적 감쇠/감점은 이번에 추가하지 않는다. 간단한 표현/효과 끄기에서도 같은 상태와 결과를 읽을 수 있게 한다. 이는 시안 지시 후보이며 새 이미지/Unity 화면은 만들지 않았다.

## 6. 확정 / 미정 / 다음 질문 하나

**확정된 사용자 방향:** 원문·강의를 참고하고, 깨어 있는 기사/음식점의 행위에 따른 명덕 증가와 행정동 성장으로 연결한다. 빛의 표현과 한 동에 집중하는 기존 방향을 유지한다.

**미정:** 인정 행위/상태 시점·가중치/임계값/곡선, 점포의 경 상태 권위, 동 귀속, 기존 운영 단계와 명덕의 통합, 레벨별 보상/해금·회복/자동 수행 세부와 정확한 저장/명령 계약. 원전/강의 해석과 게임 점수의 관계도 계속 구분한다. 숫자를 공공데이터나 고전에서 직접 얻은 값처럼 채우지 않는다.

**다음 질문 하나:** 지금은 자료 수집 결과를 먼저 확인한다. 수치화 논의를 이어갈 때는 **명덕을 기존 동 성장의 주조건으로 통합할지**부터 한 가지씩 묻는다. 임계값/보상/해금 묶음을 한 번에 승인받은 것으로 해석하지 않는다.
