## 2. 첫 기본안 — 창은 F키, 작은 보기 전환은 M

**운영 화면은 F키 순서로 모으고, 지도/요약은 M 하나로 바꾸는 안**을 권한다. 키 자체는 화면을 열거나 초점을 옮기며 업무를 확정하지 않는다.

| 키 | 추천 기능 | 대상/동작 |
| --- | --- | --- |
| **F1** | 조작·단축키 도움말 | 현재 문맥에서 가능한 키와 뜻. 도움 화면은 신규 준비 대상 |
| **F2** | 동 관리 열기 | 현재 집중/선택 동. 지역 확장·내 점포 목록 |
| **F3** | 선택한 내 매장 운영 창 열기 | 같은 점포의 기존 탭/목록·초안으로 복귀. 첫 진입만 요약 기본 후보 |
| **F4** | 그 매장의 재료·발주 탭 | 재고/본부 발주/검수 등을 **확인**. 발주 명령은 별도 확정 버튼 |
| **F5** | 그 매장의 설비 탭 | 장비/준비 상태 확인. 자동 구입/설치 없음 |
| **F6** | 그 매장의 인력 탭 | 직원/직무·준비 상태 확인. 자동 고용/배치 없음 |
| **M** | 오른쪽 아래 작은 지도 ↔ 업무 요약 | r217의 보기 형식 전환. 미니맵 동/구 축척·접기와 별개 |

F2/F3은 서로 다른 왼쪽 창을 가리킨다. F4~F6은 새 독립 창을 늘리기보다 F3의 **같은 점포 창 안에서 탭을 직접 여는 키**다. F3을 누를 때마다 요약으로 초기화하거나 다른 카페를 선택하지 않는다. 이미 열린 창은 그곳으로 초점만 모으는 안이며 반복 누름으로 닫았다 열지 않는다. M은 두 보기를 왕복하는 전환 키다.

해당 매장/동이 선택되지 않았거나 운영권/연결이 없으면 선택 필요/현재 지원 범위를 알린다. 임의의 카페1호점·가까운 건물로 명령 대상을 채우지 않는다. 현재 카페 한 곳만 지원하는 구현에서는 그 범위의 상태를 읽고 타 점포가 지원되는 것처럼 표시하지 않는다.

**M은 신규 제안 키다.** 현재 업무 요약/두 보기 전환 자체가 후속인 상태이므로 이 키가 이미 작동한다고 적지 않는다. 단독 M을 기준으로 하고 수정키 조합의 충돌은 실제 입력 검토에서 정한다. 한글 입력기/한영 상태와 텍스트 입력 중 동작도 실제 Windows 환경에서 확인해야 한다.

| **Enter / 키패드 Enter** | 현재 결정 순회 유지. 실제 회차 마감/다음 작업 시작으로 몰래 확대하지 않음 |

방향키/Space 운전과 스캔은 [r145 직접 배달](direct-riding-delivery-minigame.design.r145.md)·[r148 바코드](barcode-scan-timing-minigame.design.r148.md)의 문맥 한정 기획이다. 현재 WindowsGame에 그 조작이 이미 구현됐다는 뜻은 아니다. 앞으로 넣을 때도 입력창·설정·다른 업무 창에서 오토바이/픽업/스캔이 작동하면 안 된다.

‘회차 마감’, ‘다음 결정 확정’, ‘다음 작업 시작’은 서로 다른 결과를 만든다. 이들을 전부 Enter/Space 하나로 실행하는 안은 이번에 채택하지 않는다. 실제 회차 주 행동의 키를 바꿀 필요가 있으면 기존 Cycle 핸들러·확정된 주 버튼 책임·실행 조건을 함께 검토한다.

## 4. 입력 문맥과 상태 보존

1. **게임 창에 입력 초점이 있을 때만** 처리한다. 다른 Windows 앱의 전역 단축키/입력기를 가로채지 않는다.
2. **설정/모달 우선:** 새 화면 키가 뒤 지도·매장 창을 열거나 업무 명령으로 전달되지 않는다. Esc/Enter의 기존 처리와 예외는 별도로 대조한다.
3. **텍스트 입력 우선:** 권역 이름 등 입력 중에는 새 F키/M의 전역 처리를 막는다. 이 규칙을 현재 Esc의 동작까지 이미 바뀐 것으로 해석하지 않는다.
4. **한 번 누름에 한 번:** 길게 누른 키 반복으로 M이 계속 왕복하거나 여러 창/작업이 열리지 않는다. 처리한 이벤트를 다른 입력 경로가 다시 소비하지 않게 한다.
5. **대상 우선:** 현재 선택 점포/동의 ID·운영 범위를 유지한다. F4~F6에서 현재 점포를 잃거나 타 점포 재고/자금에 연결하지 않는다.
6. **키는 해당 화면의 마우스 진입과 같은 의미:** 키 자체가 별도의 시간 진행/정지·지급/차감·발주/고용을 만들지 않는다. 기존 Esc 설정의 정지/복원 등 해당 화면의 규칙은 유지한다.
7. **진행/초안 보존:** 선택 동·매장/상품·발주 수량/초안·진행 작업·회차 대상을 창 이동으로 초기화하지 않는다. 정상 시간 경과/기존 작업은 그대로 따른다.

새 키는 정확한 modifier도 구분해야 한다. 현 Enter 핸들러가 수정키를 확인하지 않으므로 Ctrl/Alt/Shift+Enter를 신규 기능에 붙이면 기존 순회까지 실행될 수 있다. 이번 첫안은 그런 조합을 사용하지 않는다.

## 5. 화면에 익히게 하는 방식

해당 버튼/창의 제목 옆에 `동 관리 F2`, `매장 운영 F3`, `재료 F4`, `설비 F5`, `인력 F6`처럼 짧게 표시하고, 마우스를 올리면 같은 뜻을 읽게 하는 안이다. 모르는 키가 있어도 기존 마우스 경로로 같은 일을 할 수 있어야 한다.

설정의 조작 안내·사용자 재배정/충돌 표시·기본값 복원은 후속 후보로 둔다. 현재 지원 기능으로 보고하지 않는다. 설정 저장은 입력 취향이며 업무 규칙/원장을 변경하는 설정과 구분한다. 정확한 메뉴 자리·키 선호 저장 범위·이미 사용 중인 조합을 충돌로 판단하는 방식은 제작 명세에서 결속한다.

첫 검토는 F2→F3→F4/F5/F6과 M 왕복이다. 선택 없음/지원되지 않는 점포·텍스트 입력·설정·길게 누름·창 복귀에서 실제 키보드 입력을 확인한다. 자동 규칙/함수 호출 촬영은 실제 키 입력 증거와 별도로 보고한다. 새 도움말/키 표시가 필요하면 기존 화면 기준의 시안/시각 검토를 거쳐 개발이 수용한다.
