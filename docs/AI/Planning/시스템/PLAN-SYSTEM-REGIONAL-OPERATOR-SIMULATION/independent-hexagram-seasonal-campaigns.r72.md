## 확정

현재 단계에서는 `수뢰둔 운영 캠페인`과 `절기 캠페인`을 서로 독립적으로 운영한다.

- 수뢰둔의 육효는 점심 피크 운영 상황이 변화하는 여섯 국면이다.
- 절기 캠페인은 초·중·후반, 제철·날씨 관측, 아르카나 선택과 절기 결산을 독립적으로 소유한다.
- 수뢰둔의 효 진입·완료가 절기 구간을 자동 진행시키지 않는다.
- 절기 변경이나 카드 선택이 수뢰둔 효를 자동 성공·실패시키지 않는다.
- 두 캠페인은 각각 안정 식별자, 상태, revision, 명령 기록, 저장·재생과 완료 조건을 가진다.
- 같은 Simulation 시계와 행정동·배달운영권역을 관찰할 수 있지만 상태 소유권은 합치지 않는다.

## 허용하는 느슨한 연결

독립 운영은 서로의 존재를 숨긴다는 뜻이 아니다. 다음 정보는 읽기 전용 문맥으로 함께 표시할 수 있다.

- 현재 날짜·시간대와 활성 절기
- 검증된 날씨·제철·공공자료의 기준 시각과 품질
- 같은 행정동 디오라마와 운영 상태 사본
- 두 캠페인이 각각 만든 비용·수요·기사 가용성의 Simulation 결과

한 캠페인이 다른 캠페인의 값을 사용할 필요가 생기면 원본 상태를 직접 변경하지 않고, 판본화된 관측값을 명시적 입력으로 복사한다. 입력이 오래됐거나 없으면 해당 효과를 적용하지 않고 결손을 표시한다.

## Unity 조합 원칙

Unity에서는 같은 운영자 화면 안에 두 캠페인을 나란히 관찰할 수 있지만 하나의 상태 기계로 합치지 않는다.

```text
공통 시간·지역 상태 사본
├─ 수뢰둔 점심 피크 Campaign 화면 모델
└─ 절기 Campaign 화면 모델
```

- 선택한 캠페인만 주 카드와 디오라마 강조를 소유한다.
- 비선택 캠페인은 작은 상태 요약으로 남기며 진행 조작을 자동 노출하지 않는다.
- 한쪽 자료 갱신 실패는 다른 쪽의 마지막 정상 상태나 조작을 임의로 지우지 않는다.
- 운영자 화면의 결합은 Presentation 편의이며 서버·Simulation 상태 권위를 합치는 근거가 아니다.

## 디오라마 축적 영향

공간 보완 묶음도 캠페인별로 출처를 구분한다.

- 수뢰둔 묶음: 기사 부족, 주문 적체, 픽업 접근, 예외 위치와 회복을 판독하기 위한 공간
- 절기 묶음: 날씨, 식생, 제철 상품, 시장·계절 분위기를 판독하기 위한 표현
- 공통 재사용: 실제 건물·도로·보도·주소·행정동 경계처럼 캠페인과 무관한 현실 기준선

같은 건물이나 경로를 두 캠페인이 사용해도 원본 공간 객체를 복제하지 않고, 각 캠페인의 오버레이와 상태 결속만 별도로 둔다.

1. `행정동 권역 오버레이 + 디오라마 위치 결속` — 추천. 주문 밀집, 가용 기사, 자료 미확정 경로를 권역에서 보고 선택하면 실제 디오라마 위치와 예외 카드로 이동한다.
