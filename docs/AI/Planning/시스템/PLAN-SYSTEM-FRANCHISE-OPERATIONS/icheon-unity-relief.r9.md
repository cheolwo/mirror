# 이천 실제 높이 기반 Unity 표현 r9

2026-09-23 사용자 방향 승인: r8 확보 정보를 Unity에 활용하여 실제 지형에 가까운 입체감을 표현한다. 사진 판 위에 객체만 놓는 방식으로 완료하지 않는다.

## 확정 방향

- r8의 이천 약 4km 검토 창만 대상이다. 전체 한반도 고도화·새 Scene·운영 업무 변경은 제외한다.
- DSM 높이로 메시 정점의 높낮이를 만들고 위성영상은 같은 좌표에 정렬한 표면 색 자료로 사용한다. 영상의 명암을 높이로 간주하지 않는다.
- 기본 높이 배율은 1배를 제안한다. 시각적 과장이 필요하면 배율을 명시하며 실제 고도로 오인시키지 않는다.
- 기존 지구본과 확대 경로를 유지한다. 이천 상세 자료가 준비된 범위만 상세 지형으로 연결하고, 없는 영역을 임의 지형으로 채우지 않는다.
- 가상 공장은 합성 시나리오 오버레이이며 후속이다. 실제 공장·부지 승인·도로 주행 가능성을 주장하지 않는다.

## 현재 확인과 구현 선행 조건

`한반도지형미리보기View`는 GlobeRadius와 ReliefRadius, 곡면 메시·단계별 타일을 사용한다. 기존 표현을 재사용하되 r8 DSM을 이미 소비한다고 볼 근거는 없다. 실행 대장의 이천 명세도 검색에서 확인되지 않았다.

1. 영상/파생 자료 계보 등록과 이용조건 검토를 닫는다. 현재 원본은 `PendingHumanReview`, `NoUnityDistribution`이며 이번 방향 승인만으로 이를 배포 승인으로 바꾸지 않는다.
2. EPSG:4326 DSM과 EPSG:32652 영상을 같은 미터 좌표계·범위·원점으로 정렬한다. 원본 수직 기준을 확인하고 Unity 상대 높이 기준을 기록한다.
3. 대표 타일의 정점 높이·UV·북쪽 방향·경계 연속성·결측 거부·원본 hash를 검증한다. 약 30m급 DSM을 잘게 보간해도 관측 정밀도가 향상됐다고 표현하지 않는다.
4. 승인 판본/hash·허용 쓰기 경로·표현 검증 명세를 결속한 뒤 기존 canonical Scene에 연결한다. 첫 범위는 지형 관찰뿐이며 Collider·길찾기·공장·운송 실행은 포함하지 않는다.
5. 동일 위치의 원경/근경/비스듬한 시점 Game View와 Console을 확인한다. 코드 또는 자료 생성만으로 화면 구현 완료를 선언하지 않는다.

## 이번 결과

방향과 구현 선행 조건을 기록했다. Unity 제품 코드·Scene·데이터 배포 자원은 변경하지 않았으며 Play Mode·화면 캡처도 하지 않았다. r8 수집/DB 시험을 이번 검증 결과로 재보고하지 않는다. 새 디오라마 규칙 후보 없음.

미정: 자료 검토 해제, 수직 기준, 정확한 대표 타일과 결속 명세. 다음 사용자 질문은 없음. 먼저 자료/명세 준비를 마친 뒤 실제 표현을 검증한다.
