# 이천 지구 결속 연속 확대 r12

2026-09-23 r11 후속 보완 요청. 작은 구현 범위는 기존 지구본 표면에 실제 위경도를 가진 이천 메시를 결속하고 동일 카메라로 휠 왕복 확대하는 로컬 검토다. 구/동 전체 통합과 배포는 제외한다.

쓰기 경로: `eng/public-spatial/build-icheon-preview.py`, Unity `Assets/Ssalddel/Presentation/WorldMap/이천지구연속확대View.cs`/meta, 현행 기획과 변경 기록. 기존 `세계지구본View`/`서울중간공간View`의 공용 구현은 수정하지 않는다. 임시 검토가 끝나면 카메라·컴포넌트/선 표시 상태를 복원한다.

검증 순서: 원본 hash·좌표 범위→위경도별 구체 정점→바깥쪽 삼각형 방향→동일 카메라·초점 화면 좌표→원경/중경/근경→축소/종료 복원. 운영 Command·Scene 저장·E 자동 승격 없음. 자료는 외부 로컬 검토 파일이며 배포 자원에 넣지 않는다.

구체는 기존 축소 반경18을 사용하고 높이 배율은 `18/6371000`이다. 기존 지형 음영층과 깊이 충돌을 피하는 반경18.076 검토 껍질을 사용한다. 이는 절대 고도/수직 datum 정합을 해결한 것이 아니다. 완전한 floating origin·부모 DEM 타일 스트리밍은 후속이며 현재 약3km 상세면 경계가 남을 수 있다.

## 구현 결과와 남은 결손

- Python 출력에 EPSG32652→WGS84 정점별 위경도 추가. 출력 hash `62dc1373bae78c42262d8e5435865d768e31dda5e6436181574fab68a972dec7`. 기존 r10 데이터의 additive 필드로 읽기 호환.
- Unity 신규 View는 기존 GlobeVisualRoot의 자식이며 기존 지구본 카메라만 사용한다. 로그 거리 보간·마우스 휠 입력으로 같은 이천 위경도 초점을 유지한다. 검토 중 지구본 자체 입력을 잠시 중단하고 종료 시 카메라·지형층·선 Renderer 상태를 복원한다.
- 실제 Play에서 API로 확대값 0→0.4→1→0 왕복. 초점 viewport 좌표는 각 검사에서 (0.50,0.50) 유지. 새로운 카메라 생성 없음. 생성/실행은 성공했지만 직접 마우스 휠 시험과 EditMode suite는 미실행.
- `Documentation/Changes/2026-09-23-icheon-continuous/`의 globe/peninsula-final/local-final은 기존 지구본 카메라 렌더이며 전체 Game View UI 캡처가 아니다. 초기 region/local은 지형 음영 활성화 전 중간 증거다.
- 화면상 미완료: 주변 저해상도와 이천 상세면 사이 색·해상도 단절, 중간 확대 시 선박 기호 과대 표시, 구/행정동 경계 미통합. 아직 사용자가 요청한 자연스러운 계층 전체 완성으로 판정하지 않는다.
- 기존 공용 지구본 진입은 보존했다. `Tools/Mirror/지구에서 이천 연속 확대`로 외부 검토 JSON을 여는 로컬 기능이며 자동 일반 배포 경로가 아니다. Play 종료, Scene 저장·DB 쓰기·commit/push 없음. 새 디오라마 규칙 후보 없음.
- 다음은 주변 부모 지형 자료와 영상 해상도 단계 연결, 기호의 화면 크기 제한, 기존 구/행정동 경계의 지리 결속 순이다. 동일 카메라 유지 자체가 이런 결손을 해결하지는 않는다.
