# 실제 높이와 한강 지구본 표본 r23

2026-09-23 사용자 승인: 한반도 한 구간의 높이·하천을 먼저 같은 지구본 위에 구현한다. 기존 사진형 한반도 표현 제외 결정은 유지한다.

## 자료와 범위

- 기존 [이천 r10](icheon-local-preview.r10.md)의 Copernicus DSM N37E127 원본 49,403,795 bytes, hash `4f8fef79da8c18ed9a9a0fb97b3d2695c4681181e013e039d87044e5479f7df6` 재사용. 2021 release 기록, 원래 30m급 표면 높이(건물·수목 포함). 원본 datum 변환 없음. 자료의 로컬 검토/배포 미승인 경계를 유지한다.
- 기존 한반도 하천 manifest가 검증한 Natural Earth 1:10M 한강 feature506/name Han을 재사용. 원본 archive hash `ded71b01870855ccfe19b51f2ec14c9bb48fae23c0e9f3c11974d426433b5c38` 확인. 새로운 하천을 추정하지 않는다.
- 범위 경도127.05~127.95·위도37.05~37.95, 201×201(약500m) 표본. 원본30m를 더 넓은 관찰용으로 낮춰 추출한 것이며 정밀도 향상이 아니다. 높이3.56~1139.53m, 표시1배. 지형40,401정점·80,000삼각형.
- 한강 선은 범위 내 절단·세분 후 지형 높이를 보간해 표시한다. 정확한 하상/수면/강 폭 또는 실제 흐름의 증거가 아니다. 작은 하천·전국 산맥 재현은 제외한다.

## 구현

- eng/public-spatial/build-globe-relief-review.py: 원본 hash, 결측/높이 범위 확인, 고정 입력 재생성, 로컬 v3 context의 선택적 terrainPatch 결속.
- 파생파일3,855,558 bytes, SHA256 `395ceaca9ce9a28702e619b9df806aa16877488761298e59268ade15f095d9c3`, 반복 생성 일치. 기존4MiB 읽기 상한 유지. Editor 자동 준비 경로/hash를 이 파일로 갱신한다.
- Unity 지형높이Patch: 로컬 검토 계약·좌표·높이·하천 범위 검증과 미터 단위 보간. 서울중간공간View: 같은 지구본 곡면·기존 육지 재질·기울어진 관찰 카메라, 산·강 표본 버튼. 지역 확대 범위에서만 지형/강을 표시한다.
- 운영 상태/Collider/통행/업무/Save·Replay 영향 없음. DSM/하천 파생 사본을 Resources나 Scene에 넣지 않는다. 신규 수집·DB 쓰기·배포 없음.

## 검증

관련 EditMode19/19 통과. 실제 Play/Game View 결과는 아래에 별도 기록한다. 원본 한계·표본 외부 경계 단절·하천/DSM 해상도 차이는 남아 있다. 새 디오라마 규칙 후보 없음. Scene 저장·commit·push 없음.

실제 Play에서 TerrainVertexCount40,401·IsTerrainVisible=true 확인, 기울어진 관찰에서 산줄기/계곡을 확인했다. 기존 서울 평면 구역이 한강 선을 가려 지형 표본 관찰 중에만 평면 구역을 숨겼다. 파란 한강 선은 확보된 127.05~127.18E·37.51~37.58N 일부 구간이며 한강 전체가 아니다. UI 포함 캡처는 Unity Documentation/Changes/2026-09-23-globe-relief-r23에 보관. 카메라 조작은 API-direct이며 물리 입력 완주/빌드 검증은 아니다.
