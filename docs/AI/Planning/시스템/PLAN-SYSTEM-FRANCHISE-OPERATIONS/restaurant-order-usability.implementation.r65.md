## 승인 범위와 구현 기준

기존 음식점 앱의 주문 목록·상세에서 현재 상태·다음 행동·필수 주문 정보를 먼저 보여준다. 기존 페이지·메뉴·하단 탐색·라우트·API·DB·요율·업무 규칙을 유지하고 당일 정산·모의 지급 기능은 이번 묶음에서 구현하지 않는다. 직접 승인된 현재 체크아웃 구현이며 다른 작업실로 실행을 인계하거나 외부 운영을 활성화하지 않는다.

제품 writePaths는 `RestaurantDeskApp/Components/Pages/OrderInbox.razor`, `OrderDetail.razor`, `RestaurantDeskApp/wwwroot/app.css`다. 기존 화면 계약 검사 2개에서 바뀐 공개 표시 문구와 접힌 배차 정보의 표현을 정합시킨다. 검증 기록·실제 캡처·페이지 검토 결과와 PLAN/기획/현재 작업 목차를 갱신하며 다른 미커밋 작업은 보존한다.

주문 목록은 상태·메뉴와 수량·금액·접수시각과 `주문 보기`를 중심으로 표시한다. 상세의 강조 버튼은 기존 가능 여부에 따라 `주문 확인`→`조리 시작`→`픽업 준비 완료` 중 하나다. 기사 배정 전에는 대기 안내를 표시한다. 거절 사유와 조리시간 변경은 보조 영역, 배차/조리 기준·주문번호·복구 출처는 접히는 상세 정보에 둔다. 조회 실패·오래된 목록·인증·전표 출력 실패는 기본 화면에서 확인한다.

모바일 버튼 최소48px·본문16px, 긴 내용 줄바꿈·가로 넘침 방지를 적용한다. 조회 실패를 빈 목록이나 주문 없음으로 바꾸지 않고 마지막 성공 내용을 구분한다. 상세를 읽지 못한 동안 상태 변경을 비활성화하고 새로고침으로 복구한다. 처리 중 중복 입력은 차단하며 업무 요청·출력 실패의 의미를 보존한다.

## 검증 계획과 결과

기존 Android 앱에서 같은 합성 주문의 확인→배정 대기→배정 완료→조리→픽업 준비→전달/수령 확인을 대조한다. 기사·주문자 전이는 기존 Client 실행을 사용한다. 360px·412px, 긴 주문 내용, 최초 로딩·빈 목록·실패·재연결·세션 만료·전표 실패·중복 입력을 확인한다. 에뮬레이터·실제 휴대폰·HTTP·APK·실지급 증거를 구별한다.

구현과 실제 Android 확인을 마쳤다. [페이지·코드·DB 검증 기록](../../../../ProjectOverview/page-docs/restaurant-order-usability-r1.md), [실제 화면 캡처](../../../../Changes/2026-10-02-restaurant-order-usability-r1.md)에 결과를 연결한다. 주문 목록·상세 2페이지와 기존 CSS를 보완했고 공개 API·DB·AvailableActions·배차/조리 업무 규칙은 유지했다.

Android API36 에뮬레이터에서 같은 합성 주문 `FOOD-20261002060514840`의 확인→배정 대기→배정 완료→조리→픽업 준비→전달→수령 확인을 대조했다. 음식점 행동은 실제 APK 화면, 기사·수령 확인은 기존 Client 호출이며 같은 주문의 종료를 음식점 화면에서 다시 읽었다. 최종 APK에서는 360px·412px 무넘침, 강조52px·보조48px, 상세 접기·거절 사유 입력·조리시간 선택, 상세 조회 실패 시 내용 유지/처리 차단·복구를 확인했다. 긴 내용은 실제 화면 DOM의 배치 시험이며 실제 대량 주문 입력 검증이 아니다.

Android Debug 패키지 build·서명·16KiB 정렬·설치, 집중27/27 통과. Task 전체는 5,515/5,522 통과이고 기존7실패와 이름·오류 내용이 일치한다. 전체 검증 성공으로 표시하지 않는다. 물리 휴대폰·빈 수신함·최초 로딩 순간 캡처·강제 세션 만료·모든 예외 업무·실결제·당일 지급·은행 입금·공개 Release 배포는 이번 완료 범위가 아니다. 전표 출력 창 실패는 계속 안내하며 해결한 것으로 표시하지 않는다.

소스 baseline, APK SHA-256, 전이별 JSON/PNG, 로그·기존 실패 대조는 `artifacts/local/restaurant-order-usability-r1/`에 보존한다. 전체 생명주기 조작과 최종 APK 배치 확인의 판본 차이는 검증 기록에 구별한다. commit·push·외부 배포는 실행하지 않았다.
