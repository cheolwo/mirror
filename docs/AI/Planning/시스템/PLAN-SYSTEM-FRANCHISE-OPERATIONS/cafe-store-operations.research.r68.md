# 카페 가맹점 운영과 음식점 앱 특화

[기획 · 가맹본부와 카페 운영 · PLAN-SYSTEM-FRANCHISE-OPERATIONS · r68]

조사일은 2026-11-09, 기준 지역은 대한민국이다. 상태는 **조사 완료 · 운영 설계 제안 · 제품 구현 대기**다. [공급 계약·가맹점 물류 r67](supplier-franchise-logistics.research.r67.md)과 [메뉴–재료–조달 규격 r39](menu-ingredient-supply-analysis.plan.r39.md)에 카페 매장의 제조·판매·소모·재발주를 연결한다. 기존 r4의 가상 원두 제조·배송 사례를 이어받는다. 첫 매장의 면적, 판매 채널, 재료량과 손익 입력은 비교용 가정이다.

## 어떤 부분을 업종별로 바꿀까

**같은 음식점 앱에서 매장별 운영 유형을 선택하고, 업종마다 필요한 제조·재고 화면과 규칙을 적용한다.** 여러 유형을 쓰는 매장은 메뉴별 작업대를 지정한다. 기존 카페·디저트 분류는 고객의 탐색에 쓰고, 작업 유형은 매장 관리자가 명시적으로 정한다.

| 운영 유형 | 주문 이후 달라지는 일 | 재고와 설비에 반영할 것 |
| --- | --- | --- |
| 카페 | 온도·크기·샷·우유 선택, 추출·조립·포장, 여러 잔 동시 제조 | 원두 g·우유 mL·얼음 g·용기 개, 그라인더·머신·제빙·냉장, 음료별 작업대 |
| 치킨·튀김 | 손질→튀김→소스→포장, 같은 솥의 배치 용량·완료 시각 | 냉장·냉동 원료와 손질 수율, 튀김유 사용·교체, 튀김기와 환기 |
| 피자·오븐 | 도우 해동·숙성, 사이즈·토핑·오븐 슬롯 | 도우 개·토핑 g, 작업대·오븐·냉장·박스 규격 |
| 국물·한식·분식 | 일괄 준비한 육수·밥의 소분, 주문 조립, 반찬·포장 | 생재료→배치 수율→1인분, 배치 보관·판매 가능 시간, 보온·냉장 |

현재 [음식점 수신함](../../../../../RestaurantDeskApp/Components/Pages/OrderInbox.razor)과 [주문 상세](../../../../../RestaurantDeskApp/Components/Pages/OrderDetail.razor)는 주문 수락, 조리 시작, 픽업 준비와 전표를 제공한다. 서버의 [음식점 주문 진행 정책](../../../../../Ssalddel/Services/Food/음식점주문진행Policy.cs)은 배달 주문의 기사 배정과 조리 시작을 확인한다. 카페의 매장·포장·예약 픽업에는 각 채널에 맞는 제조 시작 조건이 필요하다. [메뉴 계약](../../../../../Ssalddel.Contracts/Food/음식점메뉴관리Dtos.cs)은 기본 가격·공개·품절·판본을 관리한다. 판매 변형, 표준 레시피, 원료 로트, 제조 능력은 추가로 설계할 업무다. [식자재 요청 화면](../../../../../RestaurantDeskApp/Components/Pages/IngredientSupplyRequest.razor)은 화면 검증용이므로 본사에 발주하고 입고하는 기능의 근거로 삼지 않는다.

## 카페 한 곳의 시작 구성

첫 표본은 **테이크아웃 중심 매장, 아이스 음료 3종, 주문 수신에서 제조와 재고 차감까지**다. 음료 종류를 넓히기 전에 공용 원재료와 동일 작업대를 쓰는 메뉴를 함께 시험한다. 아래 배합은 16oz 시범 컵의 시작값이다. 컵 실용량, 얼음 모양과 희석, 맛, 홀더·뚜껑 규격을 실물로 확인한 뒤 판본을 확정한다.

| 메뉴 | 시범 레시피와 작업 | 확대 시 추가할 것 |
| --- | --- | --- |
| 아이스 아메리카노 | 원두 18g → 추출액 36g, 물 180mL, 얼음 150g | 핫 컵·슬리브, 사이즈·디카페인·추가 샷 |
| 아이스 카페라떼 | 같은 에스프레소, 우유 170mL, 얼음 150g | 핫 스팀과 온도, 대체우유·알레르기 안내 |
| 아이스 바닐라라떼 | 같은 라떼에 바닐라시럽 20mL | 펌프 1회 실제 토출량·세척, 용량 검증 |
| 레몬에이드·프라페·개별 포장 디저트 | 후속 후보. 에이드는 탄산수·레몬 베이스, 프라페는 블렌더·파우더, 디저트는 납품품 1개부터 비교 | 개봉 후 기한, 가열·해동·진열, 용기와 배송 형태를 품목별로 확인 |

18g 대 36g은 [라마르조코의 공개 추출 예](https://home.lamarzoccousa.com/using-espresso-brew-ratios/)에서 가져온 비율이다. [모닌의 아이스 바닐라라떼 공개 배합](https://monin.us/products/iced-vanilla-latte)은 시럽·우유·추출액을 미국 액량 온스로 제시한다. 제조사 배합과 시범 수량은 별도로 저장한다. 추출액 g을 mL로 바꿔 원두를 역산하거나, 특정 매장의 주문명에서 실제 배합을 추정하지 않는다. 매장별 판매 가능 변형과 알레르기 정보를 관리하는 공개 사례도 있다. [빽다방 커피 메뉴](https://paikdabang.com/menu/menu_coffee/).

모델 선정은 제조사 사양과 국내 납품 견적을 대조한다. [라마르조코 한국 장비 가이드](https://www.lamarzoccokorea.co.kr/another/guide.html)는 규모와 설치 환경에 맞춰 그룹 수를 선택하도록 설명한다. [Linea Classic S 제조사 사양](https://nz.lamarzocco.com/commercial-products/espresso-machines/linea-classic-s/)과 [Scotsman CU50 시험조건](https://www.scotsman-ice.com/products/Cube/Undercounter/CU50)은 회로·수질·급배수와 조건별 제빙량을 비교할 때 쓴다. 해외 사양은 국내 판매 모델 확인 항목의 근거다.

핫 메뉴를 더한 용량 예에서 하루 140잔 중 아이스 70%이면 150g씩 **14.7kg/일**을 쓴다. 140잔 전부 아이스라면 **21kg/일**이다. 피크 30분에 아이스 24잔이면 30분 동안 **3.6kg**이 필요하다. 여름 조건 22.2kg/일인 제빙 사례를 단순 환산하면 30분 생산량은 약 0.46kg이다. 마감 손실·여유분을 별도로 두고 피크 시작 전 저장량, 여름의 실제 생산량과 회복 속도를 측정한다. 커피머신도 샷 시간만으로 정하지 않고 동시 주문에서 바리스타·추출·얼음·포장 중 어디가 막히는지 잰다.

## 본부가 매장에 제공할 운영 기준

**직영 표본 운영 → 다른 점포에서 같은 조건의 재현성 확인 → 가맹 전환 검토** 순서로 제안한다. 직영에서는 주문·폐기·인건비·공급 이탈을 기록한다. 두 번째 점포를 검토할 때는 다른 직원과 설비에서도 음료와 운영 품질이 유지되는지, 본부가 공급과 교육 비용을 감당하는지 본다. 실제 가맹으로 전환할 때는 신규 정보공개서 등록 요건을 먼저 확인한다. 현행법상 동일 영업표지와 품질기준 또는 영업방식의 직영점이 없거나 운영기간이 1년 미만이면 등록을 거부하거나 변경을 요구할 수 있다. 대통령령상 예외가 있다. [가맹사업법 제6조의3](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1026807595).

- **표준화 대상**은 원두·핵심 시럽/베이스·포장 적합성, 레시피 판본, 추출 품질과 제조 안전이다. 범용 우유·청소용품 등은 품질 규격·대체품 승인 기준을 먼저 검토한다. 자율 구매, 추천, 계약상 구매 조건을 각각 표기한다.
- **구매·배송**은 원두와 건식품의 공급자 직송을 초기 비교안으로, 우유·냉동품의 냉장·냉동 배송과 여러 점포의 3PL 합배송을 확장 비교안으로 둔다. 공급가격·배송비·최소 주문·마감·납기·잔여 기한·대체 승인·품절·검수·클레임·정산을 계약별로 남긴다. 매도인·청구자·운송 책임과 실제 수행 방식은 [r67](supplier-franchise-logistics.research.r67.md)의 원장을 따른다.
- **가맹점 지원**은 입지 검토, 점주·직원 교육, 시운전과 가오픈, 판매 데이터 점검, 공급 이상 대응과 로트 회수다. 가맹사업 계약 전에 정보공개서·인근가맹점 현황과 계약서 제공 및 법정 대기기간을 각각 확인한다. 지정 거래의 품목·공급가격 산정방식과 불리한 조건 변경에 대한 협의 절차를 판본으로 관리한다. [가맹사업법 제7조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1024960735), [제11조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1026807703), [시행령](https://www.law.go.kr/LSW/lsInfoP.do?ancYnChk=0&chrClsCd=010202&efYd=20260804&lsiSeq=288453), [거래조건 변경 협의 고시](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000249984).

## 원가·손익과 운영 용량의 연결

점포 공헌이익은 **주문 매출 − 재료비 − 포장 − 입고 운임 배분 − 점포 부담 결제·플랫폼·배달비 − 주문별 할인/기타 변동비**다. 동일 운임을 매입가와 별도로 두 번 넣지 않는다. 잔당 재료비에 수율과 통상 로스를 적용하고, 별도 폐기 비용은 중복을 피한다. 배달 주문에는 여러 잔이 포함될 수 있으므로 BEP의 분모는 잔당 마진이 아니라 주문당 마진이다.

다음은 모델 검사용 수치다. 원두 30,000원/kg·사용가능 93%, 우유 3,000원/L·95%, 시럽 15,800원/L·98%, 물과 얼음 45원/잔을 적용했다. 잔당 재료비는 약 **626원 / 1,162원 / 1,485원**이다. 시럽값은 위 관측을 참고했으며, 배송·계약·실제 폐기 반영 전이다. 각 잔의 판매가 3,000/4,000/4,500원과 잔 믹스 50/35/15%를 가정했다.

| 주문 입력 | 포장 픽업 | 배달 |
| --- | ---: | ---: |
| 잔 수와 매출 | 1잔, 평균 3,575원 | 2잔, 평균 7,150원 |
| 포장 가정 | 120원 | 잔당 120원 + 주문당 250원 |
| 결제·플랫폼 및 점포 배달 부담 가정 | 2%, 배달 0원 | 합산 10%, 주문당 1,800원 |
| 공헌이익 | 약 2,441원 | 약 2,260원 |

입고 운임·기타 변동비는 아직 별도 견적을 적용하지 않은 예시다. 월 현금 고정비 650만 원(임차 180, 직원 350, 공과금·서비스 80, 정기 위생·기타 40), 26일 영업, **주문** 기준 포장 픽업 80%와 배달 20%를 가정하면 평균 공헌이익은 2,404.88원이다. 점포 현금 BEP는 **월 2,703건, 하루 평균 목표 104건**이다. 점주 목표소득 250만 원과 장비 적립 40만 원을 더하면 **월 3,909건, 일 151건**이다. 같은 단가에서 배달 주문 비중만 50%로 바꾸면 일 107건과 154건이 된다. 주문당 잔 수가 각각 1.2잔, 1.5잔으로 달라지므로 주문 수와 제조 능력을 함께 비교한다. 예를 들어 140잔/일을 용량 기준으로 잡으면 기본 시나리오의 현금 BEP는 약 125잔/일, 점주 목표는 약 181잔/일에 해당한다. VAT·세금, 임차보증금, 대출, 정산 지연, 계약상 가맹료, 배송·입고비의 별도 적용은 견적 모델에서 추가한다.

| 계산 주체 | 다음에 확보할 입력 |
| --- | --- |
| 점포의 현금·점주 목표 | 매장/포장/배달 채널별 객단가·수수료·쿠폰 분담, 영업일·임대·실근무, 재료·입고·포장·폐기 |
| 개업 자금과 회수 | 보증금·권리금·설비·공사·교육·초도 재고·예비자금, 미정산/재고 기간, 세금·부채, 회수 가능한 보증금과 누적 현금흐름 |
| 본부 운영과 확장 | 공급 매출·가맹료·로열티 구조, 매입·OEM·품질·물류·교육·지원·클레임, 점포 수와 점포당 주문량, 본부 재고와 매입대금 기간 |

본부 월 고정비를 점포 한 곳의 월 반복 공헌이익으로 나누면 본부 손익분기 점포 수를 구할 수 있다. 점포당 반복 공헌이익에는 로열티·공급 마진에서 배송·반품·변동 지원비를 차감한 금액을 사용한다. 개점비와 반환 의무가 있는 보증금은 반복 수익에서 제외한다.

## 프로젝트 자료의 연결과 첫 검증

배달 통합 DB **20261109-r3**을 읽기 전용으로 대조했다. 메뉴 정규화 이름에 아래 문자열을 포함하는 행과 연결을 센다. 유사명과 파생 메뉴가 포함될 수 있으며, 앱 주문 항목은 연결된 행 수로 수량 합계와 다르다. 참고 레시피 연결 수는 서로 다른 매장 메뉴 수이며 해당 매장의 조리법 승인 상태는 별개다.

| 검색어 | 메뉴 행 | 앱 주문 항목 행 | 참고 레시피가 연결된 메뉴 |
| --- | ---: | ---: | ---: |
| 아메리카노 | 63 | 34 | 59 |
| 카페라떼 | 20 | 11 | 19 |
| 바닐라라떼 | 11 | 8 | 11 |
| 레몬에이드 | 4 | 3 | 0 |
| 프라페 | 2 | 1 | 0 |

같은 DB의 조달 조회에서 이름에 원두·에스프레소·바닐라시럽·얼음·레몬을 포함한 연결 가격은 확인되지 않았고, 우유 포함 명칭은 가격 관측 1건이다. 동일 규격은 개별 상품 ID로 대조해야 한다. 판매 관측은 메뉴 선택에, 공개 레시피는 실험에, SKU·로트·가격은 조달에 쓴다. 파일 원본과 관측 ID를 보존한다.

앱과 서버에서 연결할 최소 단위는 **매장과 주문 품목 → 판매 변형 → 확정 레시피 판본 → 재료 g/mL/개 → 점포 로트와 재고 이동 → 재발주 초안**이다. 판매 시점의 레시피를 주문에 고정한다. 입고는 포장 SKU를 소비 단위로 환산하고, 품질 검수 중인 수량과 확정 가용량을 구분한다. 제조 시작에 예약하고 제조 완료에 실제 사용을 기록하는 설계의 경우, 취소로 예약을 풀 때와 이미 사용한 재료를 폐기할 때의 이벤트를 구분한다. 재전송 시 같은 주문 품목·같은 이벤트는 한 번만 처리한다. 본부는 규격·판본·공급안, 점포는 판매·실사·검수·폐기를 담당한다.

**첫 시뮬레이션**은 한 점포의 세 메뉴와 우유 한 로트에 한정한다. 1,000mL에서 라떼 3잔 제조 완료와 제조 후 취소 1잔은 판매 대응 510mL와 폐기 170mL, 가용 320mL를 남긴다. 제조 전 취소 1건의 예약은 반환된다. 다음 입고까지 라떼 20잔, 가용 수율 95%, 안전량 1,000mL이면 1L 단위 보충 초안은 5팩이다. 같은 이벤트 재시도, 우유 부족으로 라떼만 판매 보류, 제빙기 고장으로 아이스 메뉴만 제한, 레시피 개정 후 진행 중 주문의 기존 판본, 타 점포 재고 접근 차단을 검증한다. 첫 단계는 발주 초안까지 확인하고, 실제 납품과 부분 인수는 [r67의 검증 범위](supplier-franchise-logistics.research.r67.md)에 결속한다.

현장에서 확인할 지표는 30분당 잔수·주문당 잔수, 주문→제조 완료·픽업의 중앙값과 90백분위, 재료 실사차·폐기율, 품절 시간, 포장 불량, 설비 중단시간, 채널별 주문당 공헌이익이다. 계절·평일/주말 차이를 관측한 뒤 메뉴·채널·직원 수를 조정한다.

확정 범위는 카페를 기준으로 업종별 앱 업무와 가맹점 운영을 조사하는 것이다. 점포 면적·상권·실제 견적과 실험 성능, 출시 형태는 미정이다. 다음 검토 질문은 **포장 픽업 중심 한 점포를 먼저 검증한 뒤 배달 주문을 추가할지**다. 같은 주문 원장을 쓰면서 배달 수수료·포장·기사 대기가 추가됐을 때의 차이를 측정할 수 있다.
