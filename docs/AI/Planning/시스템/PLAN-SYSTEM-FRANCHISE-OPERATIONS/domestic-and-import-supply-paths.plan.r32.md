# 국내·수입 조달 경로와 근거 수준 구분 r32

- 기준일: 2026-09-24

- 자료 기준선: [기존 국내 가격·HS 무역 조사 기록](../../../../Changes/2026-09-24-menu-ingredient-price-research.md)

## 확정

공급 관계를 수입 원재료 → 제조시설 → 음식점이라는 단일 경로로 고정하지 않는다. 국내 생산, 중도매인 매입, 식자재 업체 납품, 가맹본부 공급, 직접 매입 등 여러 조달 경로를 표현한다. r31의 원두 흐름은 예시 하나로 유지하며 모든 재료의 기본 경로로 사용하지 않는다. 제조·가공시설을 거치지 않는 경로도 허용한다.

개별 매장의 공급자를 아직 모르더라도 가능한 공급 경로를 추론 후보로 정리할 수 있다. 다만 일반적인 구조의 설명과 특정 음식점의 실제 거래 사실을 별도 관계로 보관한다. 후보를 작성했다는 사실이 발주·입고·인수 또는 비용 발생을 뜻하지 않는다.

## 경로 예시

아래는 설계가 수용할 개략 경로이며, 특정 업체의 거래 조사 결과나 국내 유통 비중에 관한 통계가 아니다. 생략된 시장 절차·검수·운송 등의 세부 업무는 실제 대상 조사 때 연결한다.

| 조회할 경로 후보 | 개략 흐름 | 설계에서 필요한 구별 |
| --- | --- | --- |
| 중도매인 매입 | 국내 생산자 → 도매시장 경유·중도매인 → 음식점 | 시장이라는 장소와 중도매인이라는 거래 주체를 구별 |
| 식자재 업체 납품 | 생산자 또는 국내 유통사 → 식자재 업체 → 음식점 | 식자재 업체의 소재지로 원재료 원산지를 판정하지 않음 |
| 가공품 공급 | 원재료 공급처 → 제조·가공시설 → 식자재 업체 또는 가맹본부 → 음식점 | 제조시설과 공급 주체, 원재료와 가공품의 규격을 구별 |
| 직접 조달 | 생산자 → 음식점 | 중도매인·제조시설을 필수 노드로 만들지 않음 |
| 수입품 국내 유통 | 해외 공급처 → 수입업체 → 국내 유통사/식자재 업체 → 음식점 | 수입 경로와 국내 매입 경로가 이어질 수 있음 |

한 음식점도 재료별·시기별·물품 묶음별로 다른 공급처를 가질 수 있다. 매장 하나에 공급 경로 하나 또는 원산지 하나를 고정하지 않는다. 가맹본부가 실제 판매자·물류 주체인지 단순 계약/관리 주체인지는 근거에 따라 나누며, 이름만으로 모든 역할을 부여하지 않는다.

## 독립적으로 기록할 정보

1. **원산지 근거:** 국내산·수입산·복수 원료의 원산지·미확인을 구별한다. 복합 가공품은 성분별 근거가 필요하며 국내에서 가공했다는 사실만으로 모든 원재료를 국내산으로 표시하지 않는다. 이 분류는 법적 원산지 판정을 대신하지 않는다.
2. **조달 경로:** 누구에게 매입하고 누가 납품하는지, 실제 물품이 어디를 거치는지 나눈다. 국내 업체에 매입했다는 사실은 국내산의 증거가 아니다.
3. **제품 상태:** 원물·세척·절단·냉동·가공·완제품 등 규격을 연결한다. 같은 재료 이름의 서로 다른 상품을 같은 가격 대상으로 합치지 않는다.
4. **근거 수준:** 확인된 관계, 추론 후보, 미확인을 나눈다. 확인 범위·출처·시점과 반례/보류 이유를 함께 둔다. 검증되지 않은 확률이나 신뢰 점수를 임의 생성하지 않는다.

위는 조회 의미의 제안이며 새로운 API enum·테이블·실행 모드를 확정한 것이 아니다. 기존 관계의 상태/근거 필드를 먼저 재사용한다.

## 추론 후보를 다루는 방식

- 일반 레시피·재료 규격·사용자 설명 등에서 가능한 공급 경로 후보를 만들고, 후보를 만든 이유와 입력 판본을 남긴다. 공식 근거를 확인하지 않은 설명에는 출처를 꾸며 넣지 않고 설계 가설임을 적는다.
- 개별 공급처를 모르면 `중도매인 미확인`, `식자재 공급업체 미확인` 같은 역할 자리로 표현한다. 실제 업체명·시설 위치·납품 실적을 임의 결속하지 않는다.
- 공개된 특정 업체의 취급 품목을 확인하더라도, 그 업체가 관찰 음식점에 납품했다는 증거로 사용하지 않는다.
- 원산지 표시, 구매 증빙, 당사자 확인 등은 각각 증명하는 범위만 연결한다. 원산지 표시만으로 공급처·매입가격까지 확인됐다고 하지 않는다.
- 실제 거래 근거가 추가되면 해당 관계·기간만 확인 상태로 갱신하고 이전 가설과 수정 이유를 보존한다. 다른 기간·다른 재료의 경로까지 일괄 확정하지 않는다.
- 화면은 `가능한 공급 경로`와 `확인된 거래 경로`를 구별한다. 확정 근거만 볼 때 후보 경로를 숨길 수 있어야 하며, 후보 조회가 운영 원장에 쓰기를 발생시키지 않는다.

## 국내 가격과 HS 연결

국내 조달 경로는 KAMIS 등 기존 국내 가격 관측을 참고할 수 있지만 해당 음식점의 계약 단가는 아니다. 국내 시장에서 조사된 가격이라는 의미와 국내산이라는 의미를 구별하고, 관측에 원산지/품종/등급이 명시된 범위만 연결한다. 원 단위·기준일·도소매·지역·결손과 축산물 해석 제한은 기존 조사 기록을 유지한다.

HS는 품목 분류 후보로 연결할 수 있으나 그 코드가 있다는 사실만으로 수입품이라고 표시하지 않는다. 수출입 통계 연결 여부와 실제 조달 경로를 독립 관리한다. 가격 관측이 없으면 미확인으로 남기고 수입 단위가액을 국내 매입가의 대체값으로 자동 채우지 않는다.

## 다음 작은 범위

기존 조사에 있는 **양파**를 국내 조달 경로 비교 예시로 제안한다. 중도매인 매입과 식자재 업체 납품을 병렬 후보로 놓고 원물/가공 규격·원산지·가격 관측의 일치 여부를 확인한다. 국내산 여부와 실제 공급자는 별도 근거가 없으면 미확인이다. r31의 커피 예시는 삭제하지 않으며 어느 하나를 이미 실제 납품 관계로 저장했다고 보고하지 않는다.

미정: 첫 시안 재료, 개별 음식점의 실제 원산지/납품처, 매입 단가, 경로별 상세 근거와 새 저장 계약. r31의 메뉴 중심 진입 방향은 유지하되 국내 조달을 포함한다.

다음 질문 하나: **첫 비교 예시는 양파로, 중도매인 매입과 식자재 업체 납품 두 경로를 함께 보여줄까?** 추천은 기존 국내 가격 자료를 재사용할 수 있는 이 범위다. 상세 공급자는 조사 전 임의 선정하지 않는다.

이번 작업은 기획 보완이다. 신규 외부 조사·DB 조회/쓰기·제품 코드·Graph Map 원본·Unity·commit·push 변경 없음. 새 디오라마 규칙 후보 없음.
