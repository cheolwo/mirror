# 지구본·한반도·서울 단계별 화면 확인 r18

사용자의 단계별 스크린샷 요청에 따라 실제 SimulationWorldShell Play에서 같은 지구본 Camera의 세 단계를 순서대로 확인했다. 제품 코드는 이번에 변경하지 않았다.

- 지구본: 한반도 초기 자세, 거리53, 경계 자동 준비 Ready.
- 한반도 확대: 거리32, 의미 확대 처리 후 지형 관찰층 활성/ZoomBlend1. 사진형 지형은 켜지지 않는다.
- 서울: 서울 초점 조건 true 후 기존 지역 선택 함수 호출, 곡면 경계/89개 영역 확인.

원본 캡처와 재현 기록은 별도 Unity 저장소 `Documentation/Changes/2026-09-23-globe-seoul-stages-r18/`의 README 및 `01-globe.png`, `02-peninsula.png`, `03-seoul.png`에 보관했다. API-direct 검증이며 물리 휠/클릭 검증은 아니다. 자동 회전 유예는 촬영 중에만 적용하고 Play 종료로 해제했다.

## 보완 우선순위

1. 한반도 확대 단계 위경도선 밀도·안내 패널을 줄여 경계와 거점 판독을 우선한다.
2. 전국 시도/광역 자료를 확보해 한반도→서울 사이 정보 깊이를 보완한다. 없는 경계를 임의 생성하지 않는다.
3. 연속 확대 중의 초점·속도와 물리 휠 입력을 검증한다. 스크린샷만으로 자연스러운 전환 완성을 주장하지 않는다.

자료 출처와 배포 제한은 r16/r17 유지. 새로운 수집/DB 저장 없음. Console 오류 0 미검증. Scene 저장·commit·push 없음. 새 디오라마 규칙 후보 없음.
