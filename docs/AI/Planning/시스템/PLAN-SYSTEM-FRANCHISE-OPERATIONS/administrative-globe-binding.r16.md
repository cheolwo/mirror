# 서울 행정 경계의 지구본 결속 r16

2026-09-23 사용자 속행 요청. r15의 포함 관계를 실제 지구본 표면과 기존 카메라에 연결하는 좁은 로컬 검토 구현이다.

## 변경

- 기존 서울 공식 경계 원본과 hash를 재검증하고 EPSG:5181→4326 변환으로 중심/링/삼각형 각 점에 위경도를 추가했다. `seoul-intermediate-preview.v3`를 별도 파일로 생성한다. 기존 v1/v2 사본은 덮어쓰지 않는다.
- Unity `서울중간공간View`는 v3일 때 같은 `GlobeVisualRoot`에 경계 메시를 결속하고 기존 지구본 Camera를 사용한다. 별도 평면 Camera는 v1/v2 호환 경로에만 남는다.
- 카메라는 구면 바깥 방향/거리 보간으로 서울→선택 구를 확대한다. 관찰 종료 시 위치·회전·near/far/FOV·지구본 제어와 임시 숨긴 기호 상태를 복원한다.
- 지명 버튼은 화면상 겹침을 피한다. 숨겨진 지명도 경계 MeshCollider로 선택할 수 있다. 업무나 NPC 상태를 변경하지 않는다.
- v3 최대 입력은 4MiB로 제한하며 기존 sha256 검증을 유지한다.

## 자료와 검증

- 서울 25개 구 + 중랑/동대문/광진/노원 64개 행정동. 기준일 2023-10-31, 서울특별시·서울신용보증재단, 공공누리 제1유형. 현행 법적 경계로 승격하지 않는다.
- 재생성 두 번 결과 동일: 2,564,753 bytes, SHA256 `d286faaa8899801c7f3af3141ee665e0e706fde2e69518028ac31e5301d907b0`. 도형 유효성/삼각형 면적/좌표 원점 왕복 검사 통과.
- 서울중간공간Tests 13/13 통과(기존 계약 + 위경도 누락/무한값 거절). 관련 diff 검사 통과.
- 실제 SimulationWorldShell Play: v3 로드, IsCurved=true, 89개 영역/Collider 생성, 서울→중랑구→복귀 함수 호출 확인. 대표 면목7동 삼각형으로 향한 Raycast 성공. 카메라 위치 (0,0,-53), near=.3 복원 확인.
- UI를 포함한 실제 ScreenCapture: Unity `Documentation/Changes/2026-09-23-admin-globe-r16/seoul.png`, `jungnang.png`.
