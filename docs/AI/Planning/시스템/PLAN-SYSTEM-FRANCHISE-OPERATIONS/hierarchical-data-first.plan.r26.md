# 계층별 자료 축적 선행·카메라 연출 후행 r26

- 기준일: 2026-09-24
- 상태: 방향 승인 / 기획 기록만
- 선행: [행정 권역 r24](administrative-regions-first.r24.md)
- 후속 후보: [고속도로 관찰 r25](highway-observation.plan.r25.md)

## 확정

사용자는 카메라 이동을 당장 정교하게 만드는 것보다 계층별 데이터를 축적·관리하는 일을 우선하도록 정했다. r24의 행정 권역 구분은 유지하되, 자료 준비 단계에서 자연스러운 카메라 전환을 완료 조건으로 요구하지 않는다. 기존 카메라를 제거하거나 되돌리는 요청은 아니다.

1. 국가·시도·시군구·읍면동의 고유 식별자와 실제 상위·하위 관계를 먼저 정리한다. 지역별 계층 차이를 허용하고 행정동·법정동을 혼합하지 않는다.
2. 각 지역에 경계·출처·기준일·판본/hash·권리·확보 및 누락 상태를 연결한다. 경기도의 하위 자료부터 준비하고 다른 지역으로 확장한다.
3. 도로·시설·업무 객체는 해당 지역과 관계로 연결한다. 여러 지역을 지나는 도로·차량은 하나의 정체성을 유지하며 지역별 조회를 위해 원본을 중복 생성하지 않는다. 역세권·디오라마는 행정구역의 고정 자식 계층이 아니라 별도 관찰 범위로 연결한다.
4. 카메라 없이도 특정 지역의 하위 목록과 자료 묶음을 조회·검증할 수 있게 한다. 자료 없음·미수집·준비 중을 빈 성공이나 합성 자료로 숨기지 않는다.
5. 자료 기반이 준비된 뒤 확대 수준과 선택 지역에 맞는 자료 로드를 결속한다. 이후 카메라 이동·전환·시각적 연속성을 다듬어 각 계층을 관찰하도록 한다.

이는 모든 전국 자료가 완성될 때까지 조회 검증을 미룬다는 뜻이 아니다. 작은 지역 묶음부터 자료 관계와 조회 결과를 확인하되, 카메라 연출은 별도 후속 검증으로 분리한다. 데이터 의미 계층, 렌더링 타일/LOD, 기존 H 공간 체계도 같은 것으로 합치지 않는다.

## 현재 우선순위와 제외

우선순위는 **기존 자료 재고 → 행정 관계·출처 정리 → 지역별 조회 검증 → 확대에 따른 로드 → 카메라 연출**이다. 고속도로·차량 관찰 의도는 r25대로 보존하지만 이번 턴에는 수집·구현하지 않는다. 산맥 상세화도 후순위로 유지한다.
