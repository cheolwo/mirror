# 메뉴 간 공통 재료와 공급 관계 분석 r39

> 후속 사용자 정정: 첫 결과물의 매장별 재료 관계는 실제 사용을 암시하지 않도록 [r40](ingredient-reference-unity-exploration.plan.r40.md)의 메뉴 유형–참고 레시피–재료 관계로 범위를 좁힌다. 공급망 관심은 유지하되 실제 매장·납품 사실은 확인 전까지 연결하지 않는다. 아래 질문은 즉시 반복하지 않고 기존 자료 점검부터 구체화한다.

- 기준일: 2026-09-25
- 상태: 메뉴 간 재료 연결 우선 확정 / 수집 상세 제안 / 구현·새 수집 전
- 선행: [콘텐츠 순환 r38](delivery-content-data-cycle.plan.r38.md), [재료·공급 관계 r31](ingredient-supply-graph.plan.r31.md), [공통 기반 r34](ingredient-foundation.implementation.r34.md), [공급망 총괄 r35](franchise-supply-to-sales-coordination.plan.r35.md)

## 확정

사용자는 방문 빈도보다 **메뉴들이 어떤 재료로 연결되는가**를 우선 분석한다. 축적한 관계를 공급망 관리와 프랜차이즈 운영을 생각하는 기반으로 활용한다. r38의 첫 분석 중심 선택은 이 답변으로 종결한다. 실제 공급 업체·거래 관계가 확인됐다는 뜻은 아니다.

## 첫 수집 층 — 메뉴와 재료의 근거 있는 연결

기존 날짜별 메뉴 전체를 같은 항목으로 정리하고 기존 재료 ID·관계 색인을 재사용한다. 하나의 메뉴나 재료만 깊게 파는 방식으로 r33의 수평 적층을 대체하지 않는다.

| 수집 항목 | 구체 내용 |
| --- | --- |
| 메뉴 식별 | 매장·지점, 원문 메뉴명, 정리된 메뉴명, 옵션·세트 여부 |
| 재료 연결 | 메뉴에 연결된 재료명, 공통 재료 ID 또는 미확정 후보, 주재료·부재료·소스 등 역할 |
| 근거 구분 | 매장·브랜드 공식 명시, 일반 참고 레시피, 분석 가설을 별도로 보존 |
| 조달 규격 | 부위, 가공 상태, 냉장·냉동, 포장 단위 등 확인된 조건. 미확인은 결손으로 보존 |
| 추적 정보 | 출처, 확인일, 원본 판본, 연결 이유와 확인 상태 |

같은 재료 계열과 같은 발주 품목은 다르다. 예를 들어 닭고기라는 공통 계열로 묶을 수 있어도 부위·가공 상태·보관 조건이 다르면 동일한 조달 품목으로 합치지 않는다. 소스 등 복합 재료의 구성은 별도 근거가 있을 때만 연결한다.

## 축적 후 분석과 확장 순서

1. 메뉴→재료와 재료→메뉴를 양방향으로 조회한다. 재료별 연결 메뉴·매장 수와 근거 수준·결손을 함께 집계한다.
2. 재료 계열의 공통성과 실제 규격이 일치하는 조달 후보를 구분한다. 같은 메뉴의 반복 방문은 메뉴 연결 수를 부풀리지 않게 한다.
3. 자료가 갖춰지면 공급 가능한 업체·취급 품목·규격·배송 가능 지역·최소 주문량 등의 공개 근거를 조사한다. 공급 가능성 후보와 실제 거래는 분리한다.
4. 실제 메뉴별 사용량·판매량·수율·재고·매입 조건이 확보된 범위에서만 소요량·원가·발주량 등을 계산한다. 영상 방문 횟수를 판매량으로 대신하지 않는다.
5. 공통 재료의 중앙 가공·공동 조달·매장별 마무리 조리 등 프랜차이즈 운영 검토와 근거를 연결한 후속 콘텐츠 초안에 활용한다. 아직 경제성이나 운영 효과를 확정하지 않는다.

첫 결과물은 **재료별로 어떤 메뉴·매장이 연결되고 무엇이 확인되지 않았는지 보여주는 관계표**를 제안한다. 가격 비교나 공급 업체 순위부터 만들지 않는다.

## 다음 수집 범위 제안

원재료뿐 아니라 소스·육수·반조리품·완제품도 서로 다른 조달 단위로 함께 기록하는 방식을 제안한다. 실제 매장에서 직접 만드는지 외부에서 공급받는지는 근거가 없으면 미확인으로 남긴다. 복합 재료 자체와 그 구성 원재료를 같은 층에서 합산하지 않는다.

미정: 조달 단위의 초기 포함 범위, 실제 자료원과 접근 가능 범위, 공식 설명에 없는 재료의 참고 연결 기준.

다음 질문 하나: 첫 재료 목록에 소스·육수·반조리품 같은 가공된 재료도 함께 포함할까? 제안은 포함하되 원재료와 구분하는 방식이다.
