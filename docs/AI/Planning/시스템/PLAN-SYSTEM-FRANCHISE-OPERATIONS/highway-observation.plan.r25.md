# 전국·시도 고속도로 관찰 후속 기획 r25

- 기준일: 2026-09-23
- 상태: 기획 기록만 / 자료 조사·수집 및 구현 미착수
- 선행: [행정 권역 우선 r24](administrative-regions-first.r24.md)
- 사용자 요청: 전국과 시도 구분을 바탕으로 주요 고속도로도 표현하고 싶으나, 지금은 기획으로만 남긴다.

## 확정

- 행정구역 포함 관계와 단계적 확대를 먼저 마련한다. 고속도로는 그다음 같은 지리 공간에 얹는 별도 관찰 층으로 준비한다.
- 전국·시도 수준에서 지역들을 연결하는 주요 고속도로의 흐름이 보이도록 한다. 이번 기획의 우선 대상은 고속도로이며 국도·지방도·골목길 전수 표현으로 범위를 넓히지 않는다.
- 확대하면 준비된 구간의 연결부·거점 등 더 세밀한 정보를 볼 수 있는 방향으로 한다. 행정 경계선 자체를 도로나 차량 경로로 사용하지 않는다.
- 장차 트럭 등 차량이 지역 사이를 이동하는 생활·물류 관찰로 연결한다. 확대 수준이나 행정 경계를 넘었다고 같은 차량·운송 건을 새로 만들거나 진행 상태를 초기화하지 않는 방향을 유지한다.
- 관찰 지도와 상세 디오라마를 분리된 새 Scene으로 늘리지 않는다. 실제 운영 상태와 가상 운행은 구분하며, 이동 애니메이션으로 업무 완료를 확정하지 않는다.

## 미정

첫 노선, 표현할 구간·거점, 원본 공급자와 기준일·권리, 줌별 표시 기준, 차량 수·속도·운행 경로는 아직 정하지 않는다. 고속도로 도형 확보만으로 차량 통행 가능 경로나 길찾기가 검증된 것으로 취급하지 않는다.

## 다음 질문·재개 조건

다음 질문은 지금 없음. 행정구역 기반을 먼저 마련하고, 사용자가 고속도로 작업 재개를 요청하면 기존 자료·코드를 조사하여 작은 적용 범위를 제안한다. 이번 기록은 수집·개발·자동 실행 승인이 아니다.

문서만 변경했다. 외부 자료 조사·다운로드, DB 저장, 제품 코드·Unity 설정·Scene 변경, 실행 시험·캡처, commit·push는 수행하지 않았다. 새 디오라마 규칙 후보 없음.
