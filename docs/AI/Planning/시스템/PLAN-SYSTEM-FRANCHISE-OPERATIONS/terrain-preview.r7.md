# 한반도 지형 위 물류 시각 검토 r7

2026-09-23 사용자가 r6의 별도 모형 대신 기존 한반도 지형 위 생활·물류 흐름을 요청하고 실제 화면 재확인을 승인했다. r6은 비채택 시각 실험으로 보존한다.

범위: 기존 SimulationWorldShell/GlobeVisualRoot의 구면 좌표를 사용해 이천권→서울권 합성 연결선과 트럭1대를 표시한다. 실제 도로/시설이 아닌 상징적 거점이며 직선·보간 연결은 주행 가능 경로가 아니다. 동일 차량을 한반도/수도권 시점에서 관찰한다. 새 Scene·별도 지형판·공장 모형을 만들지 않는다.

Editor 전용·임시 표현이며 샘플 시간만 진행한다. 업무 WI·Command·DB·인수·재고·서버 완료와 무관하고 E 승격 없음. UI는 가상 경로 안내와 관점 선택으로 제한한다. 기존 카메라 상태는 닫을 때 복원한다.

허용 수정: Unity `Assets/Ssalddel/Presentation/WorldMap/한반도물류시각표본View.cs`와 meta, 관련 EditMode 시험/meta, `Documentation/Changes/2026-09-23-terrain-logistics/`; Hongdal 현행 PLAN/목차/현재작업. 기존 자료/Scene 저장/운영 코드 변경 금지.

검증: 기존 위경도 변환 재사용, 구면 반경 유지, 시작/끝점/정지, 표본 중복 방지, 실제 Play 이동 및 두 시점 캡처. 표현 검토이지 실제 도로·공급망 검증 아님. 실패 시 별도 모형으로 대체하지 않는다. 실제 지리/경로 수집은 후속. 새 디오라마 규칙 후보 없음.
