# 행정 권역 기준점 우선 r24

- 기준일: 2026-09-23
- 상태: 방향 승인 / 기존 코드·로컬 사본 조사 완료 / 경기 하위 경계 구현 전
- 승인 근거: 사용자가 산맥 표현보다 경기도와 다른 도의 하위 행정 권역 구분을 먼저 마련하도록 요청했다.
- 선행: [행정 포함 관계 r15](administrative-hierarchy-refactor.r15.md), [광역 참고 r19](capital-admin-context.r19.md).
- 후순위: [산·강 표본 r23](globe-relief-review.r23.md). 코드·원본·캡처는 보존하며 화면 만족도 승인이나 기본 확대 경로로의 채택으로 취급하지 않는다.

## 확정 방향

지구본의 같은 지리 위치 위에서 국가 → 시·도 → 시·군 및 필요한 구 → 읍·면·동 → 준비된 디오라마 순으로 정보를 구체화한다. 모든 지역에 동일한 깊이의 구 계층을 강제하지 않는다. 경기도부터 작게 검증한 뒤 다른 도에 같은 조회·선택 구조를 적용한다.

행정 경계는 탐색·자료 분류 기준이다. 산·강·도로는 이후 같은 좌표계에 추가할 별도 표현 층이며, 행정 경계를 도로나 업무 경로로 사용하지 않는다. 행정동과 법정동, 역세권과 배달권은 별도 유형과 관계로 유지한다. 서울·인천을 경기도의 자식으로 넣지 않는다.

## 구현 우선순위

1. **경기 자료 재고·원본 대조:** 기존 수집 대장·DB에서 시·군 경계, 공식 코드, 부모 관계, 기준일, 좌표계, 출처·권리·hash를 조회한다. 부족한 자료만 공식 출처에서 보충한다. 과거 자료와 현행 경계를 구별하며 자료 없는 지역을 임의 폴리곤으로 채우지 않는다.
2. **좁은 계약 확장:** 기존 서울 v1~v3 검증은 호환 경계로 보존한다. 기존 포함 관계 조회를 재사용하고 지역 유형·부모 고유 식별자·원본 코드 체계·기준 판본·도형·상세 준비 상태를 갖춘 지역 중립 사본을 결속한다. 이름 전면 변경이나 새 Map Manager는 하지 않는다.
3. **첫 수직 표현:** 기존 지구본에서 경기도 선택 → 확보된 시·군 경계 표시 → 한 시·군 선택 → 상위로 복귀를 검증한다. 카메라 초점과 지리 위치를 유지하고 새 Scene이나 별도 지형 판을 만들지 않는다. 하위 자료가 없으면 현재 권역을 유지하며 준비 상태만 표시한다.
4. **다른 도 확장:** 경기도에서 확인한 자료·계약·선택 경로를 재사용한다. 전국 도형을 한 번에 Scene에 생성하거나 모든 읍·면·동을 동시에 로드하지 않는다. 선택한 권역과 확대 수준에 필요한 자료만 준비한다.
5. **상세 디오라마·지형 후속:** 준비된 읍·면·동/역세권과 기존 디오라마를 연결한다. 산맥·하천의 높이와 표현 개선은 이 탐색 기준선이 확인된 다음 진행한다.

## 후속 검증 기준

- 공식 원본의 기준일별 목록과 수량 대조. 전국에 하나의 고정 개수나 계층 깊이를 강제하지 않는다.
- 중복 ID·고아·순환, 잘못된 부모, 코드 체계 혼용, hash 불일치 거부.
- 경계의 섬·구멍·공유 변 보존, 좌표 변환 왕복과 인접 경계 이음 확인. 참고 광역 자료와 상세 공식 자료의 판본/해상도 차이를 숨기지 않는다.
- 경기도 → 하위 시·군 → 복귀 시 다른 도나 서울로 잘못 이동하지 않는지 확인.
- 기존 서울 → 구 → 동 선택 회귀 및 실제 Play Mode/Game View를 별도 증거로 남긴다. 애니메이션·카메라 이동으로 업무 상태를 변경하지 않는다.

## 미정·다음 질문

다음 질문: 지금은 없음. 첫 범위는 경기도의 시·군 구분이며 산맥 상세화보다 앞선다. 이는 방향 승인이지 미확보 자료나 배포 권리·실행 증거를 승인하는 뜻은 아니다.

이번 작업은 기존 코드·사본 확인과 기획 갱신만 수행했다. 제품 코드, Editor 설정, Scene, DB는 변경하지 않았다. r23 삭제·롤백·별도 백업 생성도 하지 않았다. 공공자료 신규 수집·실행 시험·캡처·commit·push 없음. 기존 출처/권위 분리 원칙 유지, 새 디오라마 규칙 후보 없음, E 승격 없음.
