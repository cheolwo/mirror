# 행정구역 포함 관계 리팩토링 r15

사용자 요청에 따라 r14의 행정 경계 우선 방향을 작은 코드 변경으로 연결했다.

## 변경 범위

- Unity `행정구역Hierarchy`는 명시적인 ID/부모 ID를 사용한다. 고정 깊이나 코드 접두사로 포함 관계를 추정하지 않으며 중복·고아·순환을 거절한다.
- 기존 `서울중간공간View`의 하위 동 표시·선택·도형 hit 판정을 이 조회 모델에 연결했다. 4개 구 버튼 목록은 실제 하위 자료가 있는 부모에서 얻는다. 구 이름 버튼으로 하위 경계를 선택하며 미확보 구는 준비 중이라고 표시한다.
- 확대만으로 중랑구를 자동 선택하던 동작을 제거했다.
- 서울 v1/v2 입력 계약과 고정 개수 검증은 기존 자료 호환용으로 보존한다. v1의 중랑구 부모 보충은 별도 변환 경계에 격리했다. 이 계약을 전국 데이터 계약으로 사용하지 않는다.

## 남은 범위

전국 시도/시군구/읍면동 경계 수집·DB 저장, 좌표/판본/출처를 가진 전국 사본 계약 및 같은 곡면 지구본 결속은 아직 구현하지 않았다. 현재 서울 View의 별도 평면 카메라도 유지한다. 이번 변경은 포함 관계와 선택 경로의 기반 정리이지 전국 지도나 자연스러운 카메라 전환 완성이 아니다. 법정동/행정동을 혼합하지 않으며 미확보 지역은 생성하지 않았다.

자료 출처는 r14에 연결한 기존 서울 검토 사본이며 새 자료 수집은 없다. 기존 출처 보존·임의 경계 금지 원칙을 유지한다. 새 디오라마 규칙 후보 없음.

검증: 행정구역Hierarchy EditMode 6/6 및 서울중간공간Tests 10/10 통과. 관련 tracked diff 검사 통과. Play Mode·Game View 미검증. Scene 저장·commit·push 없음.
