# 지구본 행정 경계 우선 r14

2026-09-23 사용자 변경 지시: 사진형 한반도 지형이 지구본 디자인과 어울리지 않으므로 화면에서 제외하고, 서울뿐 아니라 경기도·충청권 등 전국을 상위 지역→하위 지역으로 먼저 분류한다. r11~r13의 위성영상 상세 확대는 우선순위에서 내린다. 조사 원본 삭제는 하지 않는다.

## 구현한 표시 변경

- Unity `한반도지형미리보기View.PhotoSurfaceEnabled=false`: Natural Earth 음영·L1/L2 이미지 및 래스터 하천층을 표시하지 않는다. SetStage/SSE 비교에서도 다시 켜지지 않는다. 해안 벡터·거점/기존 계약은 보존한다.
- 패널은 사진형 지형이 보인다고 설명하지 않도록 수정했다. 기존 세계지구본/화면오차 시험의 표시 기대값을 새 정책에 맞추되 상세도 선택 계산 자체는 유지했다.
- 자료 파일/소스·과거 검토 결과는 삭제하지 않았다. 이천 로컬 실험은 정식 경로가 아니며 자동 실행하지 않는다.

## 새 우선순위

1. 동일 판본의 전국 **시·도 경계**를 실제 지리 위치에 결속한다. 현대 행정구역을 기본으로 하며 역사적 팔도는 별도 선택 자료가 필요할 때만 추가한다.
2. 시·도 선택/확대 → 해당 **시·군·구** 경계. 특별한 계층은 생략/추가 가능해야 하며 모든 도시에 구가 있다고 가정하지 않는다.
3. 시·군·구 선택/확대 → **읍·면·행정동**. 법정동은 별도 BoundaryKind와 대응 관계로 관리한다.
4. 준비된 하위 구역에만 기존 디오라마를 연결한다. 역세권은 여러 동과 겹칠 수 있는 별도 범위이며 행정동의 고정 자식이 아니다.

경계는 사진판이 아닌 기존 지구 곡면 위 얇은 선·저채도 구역 색으로 표시한다. 동일 카메라·위경도 초점을 유지한다. 구체 메시에 임의 직선으로 구역을 나누지 않으며 원본 다중 폴리곤·섬·구멍을 보존한다. 경계는 지형 고도나 도로가 아니다.

## 자료·계약 준비

기존 `서울중간공간View`는 25개 구/특정 동 개수·사가정 기준 로컬 좌표에 묶여 있다. 기존 v1/v2를 깨거나 서울 기준 상대 좌표를 전국에 그대로 확장하지 않는다. 전국 경계 사본은 지역 ID, 부모 ID, 지역 종류, 경계 종류, 유효 기준일, 원본 코드 체계, CRS, bbox, 다중 폴리곤, 출처/hash, 하위 자료 준비 상태를 함께 가져야 한다. 부모 코드 문자열 접두사만으로 계층을 추정하지 않는다.

- [SGIS 자료제공](https://link.mods.go.kr/view/pss/openDataIntrcn): 센서스용 행정구역 경계를 시도/시군구/읍면동 단계와 기준연도로 제공한다. 우선 후보이며 실제 파일 다운로드·이용조건·현재 공급 범위는 수집 단계에서 확인한다.
- [SGIS 지도 도움말](https://sgis.kostat.go.kr/view/newhelp/tc_help_20_1): 단계별 행정구역 조회와 지도 중심 지역 정보의 예시.
- [국토교통부 법정구역정보](https://www.data.go.kr/dataset/15012631/openapi.do)는 법정구역 자료이며 행정동 경계 대체물로 묵시 사용하지 않는다.

북한은 남한 코드를 부여하지 않고 원본 행정체계·판본/출처를 구분한다. 최신성과 권리 확인 전 임의 도/군 경계를 그리지 않는다. 이번 탐색에서 실제 파일이 확인된 경계는 기존 서울 범위이며 전국 경계 확보/DB 저장/화면 완성은 미완료다.
