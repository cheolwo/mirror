# 수도권 해안 윤곽 기반 육지 메시 r21

2026-09-23 사용자 승인: 기존 지구본의 수도권 주변 거친 육지를 작은 폴리곤으로 교체한다. 기존 관찰 표현의 좁은 보완이며 업무 WI/운영 상태나 새 Scene을 만들지 않는다.

## 구현·근거

- 원본/이용조건은 [r19](capital-admin-context.r19.md)의 Natural Earth 1:10M 광역 참고 자료를 재사용한다. 새 외부 수집·DB 쓰기 없음. 현행 공식 행정동 또는 측량 지형으로 해석하지 않는다.
- build-korea-admin-context.py가 원본 KOR/PRK 육지 면을 결합해 위도36~39·경도125~128 범위를 절단한다. 0.1도 셀 안에서 constrained triangulation을 수행해 해안/섬/구멍을 보존한다. 바다를 사각형으로 채우지 않는다.
- 2,193 꼭짓점·2,738 삼각형. 삼각형이 원본 도형 안에 있는지 검사하며 면적 합 오차 5.51e-14 제곱도. 면적 검사는 지리적 정확도 인증이 아니라 원본 도형 재현 검사다.
- 사본 3,129,844 bytes, SHA256 `1c44716d9249daa69936981ac48694c8227a840213bc26bfea518339f22e5545`. 두 번 생성해 동일 hash. 기존 v3/context.v1에 선택적 landPatch를 추가하고 기존 사본도 허용한다.
- Unity 서울중간공간View는 같은 곡면 위에 육지 면을 조립하고 관찰 중에만 기존 육지 메시의 지정 범위 삼각형을 제외한 복제본을 사용한다. 지구본 복귀/해제 시 원본 메시를 복원한다. 범위 밖과 Scene 자산은 보존한다.

## 검증·한계

Pipeline EditMode 서울중간공간Tests 18/18 통과. 범위·인덱스·NaN 검사를 포함한다. 고도/하천·전국 해안 교체·최신 공식 행정 경계·경기/인천 하위동은 범위 밖이다. 절단 가장자리에서는 기존 저해상도 자료와의 연결 오차가 남을 수 있다.

새 디오라마 규칙 후보 없음. commit·push·Scene 저장 없음.

실제 Play API-direct 수도권 진입에서 육지 삼각형 2,738개를 확인했다. 원래 육지 인덱스 78,702→78,096으로 해당 영역만 제외하고 복귀 시 원본 참조 복원, 재진입 시 같은 복제 메시 재사용을 확인했다. Game View에서 서해 육지/섬 윤곽 확인. 새 메시에는 구면 바깥 방향 법선을 명시해 기존 재질 조명을 유지한다. 기존 localhost:5204 연결 실패가 남아 Console 오류 0은 아니다. 물리 입력 완주/빌드 검증 없음.
