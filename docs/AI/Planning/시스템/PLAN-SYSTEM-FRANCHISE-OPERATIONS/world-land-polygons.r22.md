# 전 세계 육지 폴리곤 r22

2026-09-23 사용자 요청: 수도권뿐 아니라 전 세계 육지를 폴리곤으로 표현한다. 현행 배포 승인 세계 Catalog 전체에 적용하는 표현 변경이며 국가 원장·행정구역 권위·Scene·운영 상태는 바꾸지 않는다.

## 원본 범위와 구현

- 기존 Unity WorldGlobeCountryCatalog.json의 Natural Earth Admin0 1:110M 판본 `ca96624a56bd078437bca8184e78163e5039ad19` 및 해당 Catalog의 출처·이용조건을 재사용한다. 새 외부 수집·DB 쓰기는 없다. 177개 국가/영역은 국제적 국가 승인 판단이나 전 세계 모든 섬이 수록됐다는 뜻이 아니다.
- build-world-land-polygons.py가 177개 영역·288개 폴리곤·내부 구멍1개를 전수 변환한다. 1도 셀마다 원본을 절단해 constrained triangulation을 수행한다. 셀 전체를 육지로 채우지 않는다.
- 공유 꼭짓점37,438개·삼각형63,405개, 양면 렌더링 인덱스는 두 배다. 출력1,598,541 bytes. 반복 생성 SHA256 `9d570172ae1905a6adafe33a123b6f649a31aebdb4f6feeab0dd7558fdc75575` 일치.
- 원본 polygon마다 면적 합 비교, 삼각형이 절단 도형 내부인지 검사. 최대 면적 차이9.095e-12 제곱도. country:ba/rs의 미세 자기 교차와 country:kp의 퇴화 부분은 make_valid로 정리하되 면적 변화1e-9 제곱도 이상이면 실패한다. 실제 변화는 최대7.728e-13이며 원본 파일은 변경하지 않고 파생 사본에 내역을 기록한다.
- 세계지구본View의 격자 표본 육지를 제거하고 WorldLandPolygons 읽기 전용 Resource를 사용한다. 구면 법선·공유 꼭짓점·UInt32 인덱스를 사용한다. 국경선도 원본 꼭짓점을 유지한 채 구면 보간한다.
- 세계육지Polygon사본은 Catalog bytes hash, 범위, 크기 상한, 인덱스, 삼각형 최대1도 범위를 검증한다. 날짜변경선/남극을 포함한다. hash 불일치는 격자 fallback으로 숨기지 않는다.
- 기존 수도권 r21은 더 상세한 별도 원본을 쓰는 지역 교체로 유지한다. 전 세계1도 절단선과 수도권 정수도 범위가 맞아 영역별 메시 교체를 계속 사용할 수 있다.

## 검증과 한계

Unity Pipeline 세계지구본Tests 23/23, 서울중간공간Tests 18/18 통과. 기존 국가 선택/카메라 시험 포함. 원본의 1:110M 일반화 한계는 그대로이며 정밀 측량·최신 공식 경계·고도/산맥/하천 상세는 이번 완료가 아니다. 전 세계 1:10M 자료를 새로 수집한 작업도 아니다.

새 디오라마 규칙 후보 없음. Scene 저장·commit·push 없음.

실제 canonical Scene Play에서 177영역·37,438꼭짓점 확인. 아시아·북미·남극을 API-direct로 관찰해 UI 포함 Game View를 Unity `Documentation/Changes/2026-09-23-world-land-polygons-r22`에 남겼다. 수도권 상세 메시 진입 시 세계 메시 복제본으로 교체되고 복귀 시 원본 참조가 복원됨을 확인했다. 기존 서버 연결 오류/해양생활연출 LookRotation 경고가 있어 Console 0을 주장하지 않는다.
