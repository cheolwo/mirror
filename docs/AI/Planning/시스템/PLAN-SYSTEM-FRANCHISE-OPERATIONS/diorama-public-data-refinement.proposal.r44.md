# 기존 자료를 바탕으로 한 사가정 디오라마 정밀화 제안서

[기획 · 거리·부지 정밀화 · PLAN-SYSTEM-FRANCHISE-OPERATIONS · r44]

- 작성일: 2026-09-26
- 상태: 제안서 작성 완료 / 후속 실행은 제안 단계
- 사용자 요청: “그냥 있는 거를 바탕으로 일단 좀 제안서를 작성을 해줘.”
- 관계: [r41](delivery-street-diorama-detail.proposal.r41.md)의 거리 재현 목표, [r42](diorama-existing-data-first.proposal.r42.md)의 영상 미전달 조건, [r43](public-spatial-data-first.collection.r43.md)의 공공자료 확인 결과를 합쳐 당면 실행안을 정리한다. 기존 공간 수집 관문과 자료별 이용 범위는 유지한다.
- 이번 범위: 보유 파일·기존 확인 기록을 바탕으로 한 문서 작성. 추가 수집·DB 반입·Unity 구현은 진행하지 않는다.

## 1. 제안의 핵심

**사가정의 짧은 거리 한 구간을 골라, 공공자료와 기존 공간 사본으로 기본 배치를 정리하고 촬영 자료로 외관을 보완하는 방식을 제안한다.** 처음부터 동네 전체를 정밀하게 만들기보다, 한 구간에서 자료를 연결하고 수정하는 절차를 완성한 뒤 주변으로 넓힌다.

첫 결과물은 약 100~200m 구간의 **검토 지도와 보완 목록**이다. 건물 윤곽·도로 배치·높이 근거를 한눈에 확인하고, 무엇을 추가로 수집하거나 촬영해야 하는지 알 수 있어야 한다. 정확한 구간은 현재 사본을 점검한 뒤 추천하며 아직 특정 주소로 확정하지 않는다.

이 기반이 생기면 사용자에게는 촬영·수정할 대상이 명확해지고, 향후 보는 사람에게는 거리와 매장 사이의 공간 관계가 더 잘 전달된다. 배달 기록과 메뉴·공급망 표현도 이후 확인된 장소에 연결할 수 있다.

## 2. 현재 활용할 수 있는 자료

아래 수량은 자료의 보유·검사 범위다. 현재 현장과의 일치나 공간 정밀화 완료를 뜻하지 않는다.

| 자료 | 확인한 상태 | 활용 방법과 한계 |
| --- | --- | --- |
| 기존 사가정 공간 사본 | `SagajeongReference.json`, 판본 `sagajeong-reference.r3`, 건물 602개·도로 구간 2,397개 | 구간 비교와 배치 점검의 출발점. OSM 기반 참고 사본이며 도로 폭은 상징값, 높이 미상은 기본 4m, 지형·통행 검증은 없음 |
| 기존 높이 보완 자료·조립 코드 | r42에서 파일·경로 확인 | 기존 구조를 재사용해 근거가 있는 대상부터 보완. 적용 여부·공간 정확도는 후속 점검 |
| 공식 도로명 자료 | 202608 전체분 원본 확보. 사가정로·면목로·용마산로·면목천로의 선택 11행 검사 완료 | 총괄 4행·개별 법정동 관계 7행. 촬영 발화의 도로명을 공식 코드에 연결할 참고 사전이며 위치·도로 형상·실제 건물번호 존재를 증명하지 않음 |
| 현행 행정구역·건물·출입구 자료 | r43에서 공식 제공·신청 경로 확인, 해당 원본 미확보 | 확보 후 공식 코드·좌표·판본을 대조할 후속 수집 대상 |
| 보도 폭·포장 참고 자료 | r43에서 서울시 보도통계 제공 페이지 확인, 파일 미확보 | 후속 수집 후보. 노선 통계를 특정 매장 앞의 실측 폭으로 사용하지 않음 |
| 거리 촬영 | 사용자 촬영 가능, 현재 전달 불가 | 길 이름·건물번호·매장명·방향을 음성으로 남겨 추후 연결 |

도로명 선택 결과와 자체 검사 25건은 기존 로컬 기록으로 확인했다. 해당 실행은 `databaseWriteAttempted=false`, `committed=false`, `unityApplied=false`이며 **DB 반입·독립 재조회는 미실행**이다. 기존 사본의 전체 공간 감사도 아직 수행하지 않았다.

## 3. 먼저 할 일과 나중에 할 일

| 우선순위 | 후속 작업 | 사용자에게 남길 결과 | 완료 기준 |
| --- | --- | --- | --- |
| 1 | 보유 자료 점검과 구간 선정 | 자료 상태표, 후보 최대 3개와 추천 구간 1개 | 각 파일의 판본·출처·사용 범위 확인. 좌표·ID·누락·중복을 점검하고 구간 선택 근거 제시 |
| 2 | 선택 구간의 평면 배치 정리 | 건물 윤곽·도로 중심선·근거 상태가 보이는 검토 지도 | 원본 대상과 지도 표시가 연결되고, 미확인 높이·입구·보도 폭이 구별됨 |
| 3 | 필요한 공식 공간자료 보완 | 원본·연결표·불일치 목록 | 기존 관문에 따라 경계→동일 배포 세대 건물/건물군→출입구 순서로 검증. 비공개 저장·독립 재조회·중복 방지 확인 |
| 4 | 검토한 자료의 Unity 표현 보완 | 한 구간의 전후 비교와 대상 선택 화면 | 동일 구간·시점에서 비교. 개별 건물 교체·되돌리기와 중복 배치·선택 해제 확인 |
| 5 | 촬영으로 외관과 최근 변화 보완 | 간판·문·창문·캐노피·단차 보완 목록과 적용 결과 | 촬영 장소·시점 확인 후 해당 대상만 수정. 치수는 별도 근거가 있는 범위만 확정 |

1~2단계는 현재 자료로 준비할 수 있다. 3단계의 접근 대기는 보유 자료 점검을 막지 않으며, 접근을 기다리는 자료를 확보한 것으로 처리하지 않는다. 4단계는 각 자료의 사용 범위와 검토 상태를 충족한 부분부터 진행한다.

공간자료 수집의 기준은 기존 [현행 경계→건물/건물군→출입구 관문 r16](../PLAN-SYSTEM-ADMIN-DONG-DIORAMA/current-boundary-building-entrance-collection-gate.decision.r16.md)이다. 한 구간은 검토·표현의 첫 범위이며 기존 30개 행정동 수집 범위를 임의로 변경하지 않는다. 도로명 사전을 확보한 사실만으로 이 관문을 통과시키지 않는다.

## 4. 첫 작업에서 받을 결과

후속 실행의 첫 묶음은 **자료 점검과 검토 지도까지**로 제안한다.

1. 보유 자료표: 파일·판본·기준일·좌표계·이용 범위와 찾지 못한 원천 사본을 정리한다.
2. 구간 추천: 기존 건물·도로 연결이 비교적 분명하고 나중에 재촬영하기 쉬운 구간을 고른다.
3. 검토 지도: 건물·도로와 확인 필요 항목을 구분해 표시한다. 건물 ID를 유지해 이후 수정 대상을 찾을 수 있게 한다.
4. 다음 보완 목록: 공식 자료로 채울 것과 촬영으로 확인할 것을 구분한다.

자료 점검에서는 중복 ID, 범위를 벗어난 좌표, 퇴화한 윤곽, 길이 0인 도로 구간, 높이 출처 누락을 확인한다. 상세 기준과 원천 파일 결손은 [r42](diorama-existing-data-first.proposal.r42.md)를 재사용한다. 원천 파일을 찾지 못한 항목은 파생 사본의 내부 검사까지만 평가한다.

완료 기준은 “더 사실적으로 보인다”만으로 잡지 않는다. **표시 대상의 출처를 찾을 수 있고, 무엇이 확인됐고 무엇이 부족한지 보이며, 후속 수정 대상을 다시 찾을 수 있는 상태**를 첫 성과로 삼는다.

## 5. 촬영은 간단한 공통 형식으로 연결

촬영 때는 다음 정도로 말하면 된다.

> “○○로, 건물번호 ○○번, ○○매장 앞, ○○ 방향.”

방문 순서와 건물번호를 구분하고, 건물번호를 모르면 길 이름·매장명만 남겨도 된다. 촬영일과 원본 파일을 보관하면 나중에 장면별 시각을 연결할 수 있다. 지금 별도 편집본이나 복잡한 입력 양식을 만들 필요는 없다.

영상이 전달되면 발화·화면·공식 주소를 대조해 기존 건물 후보와 연결한다. 입구 위치, 외벽·간판·창문, 계단·경사와 최근 변경을 보완한다. 애매한 장소 연결은 확인 대기로 두고, 영상만으로 정확한 미터값이나 건물 내부 구조를 단정하지 않는다.

## 6. 작업량을 쓰는 순서

작업은 **자료 진단 → 검토 지도 → 공식자료 보완 → Unity 비교 → 촬영 반영**으로 나눈다. 각 묶음마다 결과 파일·남은 결손·다음 입력을 남겨 중간에 쉬었다가 이어갈 수 있게 한다. 실제 사용량과 소요시간은 각 묶음 실행 후 기록하며, 리셋권 한 장으로 어느 범위가 끝난다고 약속하지 않는다.

지금은 좌표·식별자·자료 연결과 비교 가능한 결과에 작업을 집중한다. 주변 지역 확대, 모든 매장의 상세 외관, 차량·보행자 움직임, 메뉴·공급망의 공간 표현은 첫 구간의 검토 절차가 자리 잡은 뒤 순차적으로 붙인다.

## 7. 현재 결론과 다음 출발점

**확정:** 이번에는 보유 자료에 근거한 제안서까지만 작성한다. 공공자료로 기본 공간을 보완하고 촬영으로 외관·최근 변화를 채우는 방향을 반영한다.

**미정:** 정확한 첫 구간, 원천 자료의 확보 시점, 실제 현장 오차와 후속 구현 범위.

**다음 질문:** 지금 없음. 후속 실행의 첫 작업으로 보유 사본 점검과 한 구간의 검토 지도를 추천한다.

기존 서버의 수집·출처·관계 관리와 Unity 조립 구조를 재사용한다. 원본·정규화 자료·검토 후보·Unity 표시를 구분하며 자료 확보를 자동 적용이나 증거 단계 승격으로 해석하지 않는다. 이번 제안은 별도 출구 Blender 작업의 중지 상태를 바꾸지 않는다.

이번 문서의 확인 근거는 r42·r43, 실제 `SagajeongReference.json`, 보존된 도로명 `preview.json`·`self-test.json`이다. 자료 목록의 공식 링크와 수집 기록은 r43에서 관리한다. 새 공간 관찰이나 반례는 추가되지 않았으며 **새 디오라마 규칙 후보 없음**이다.
