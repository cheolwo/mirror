# 배달 영상 재사용을 위한 디오라마 정밀화 r27

- 기준일: 2026-09-24
- 상태: 활용 방향 기록 / 상세 범위 제안 / 구현·편집 미착수
- 선행: [계층별 자료 선행 r26](hierarchical-data-first.plan.r26.md)

## 확정한 의도

사용자는 별도 `배달` 프로젝트의 2026-09-22·23 영상처럼 실제 방문 흐름이 있는 자료를 향후 편집에 활용하기 위해 디오라마 자체를 먼저 정밀하게 만들고자 한다. 특정 영상 전용 일회성 배경보다 날짜가 달라도 재사용할 수 있는 동네 공간 기반을 지향한다. 지금 영상 재편집·렌더링·확정본 교체를 요청한 것으로 해석하지 않는다.

계층별 자료 축적 선행·카메라 연출 후행이라는 r26은 유지한다. 경기도/다른 도의 행정 관계 확장과 기존 동네 디오라마의 국소 정밀화는 다른 범위이며, 전국 자료 완성을 영상용 한 구역 검토의 필수 조건으로 만들지 않는다.

## 정밀화 순서 제안

1. 두 날짜의 최신 방문 기록에서 공개 매장·지점·좌표와 확인 근거를 대조한다. 반복 방문은 같은 매장 ID와 별도의 방문 ID로 구별한다. 실제 경로·매장 외형을 영상만으로 확정하지 않는다.
2. 기존 디오라마의 도로·블록·건물과 확인된 매장 위치를 연결한다. 건물 결속이 불명확하면 검토 대장에 남기고 임의의 가까운 건물·출입구로 대체하지 않는다.
3. 대표 구역 하나에서 상대 위치·도로 연결·건물 윤곽/높이 근거와 지도 핀 착지점을 먼저 검증한다. 외관 디테일·간판·소품은 근거와 사용 조건이 준비된 것부터 후속으로 추가한다.
4. 영상용 화면에서 매장과 방문 번호가 읽히는지, 실제 촬영 화면과 연결했을 때 위치가 혼동되지 않는지 검토한다. 기능/UI 화면 캡처와 편집용 출력은 구별한다.
5. 공간 기반이 준비되고 사용자가 편집 시도를 요청하면 기존 7곳 지도 요약 중 한 구간만 비교용으로 만든다. 시안은 확정본을 덮어쓰지 않는다.

## 자료와 편집의 경계

- 기준 공간에는 검증된 장소·도로·건물·출처를, 날짜별 기록에는 방문 순서·영상 구간·편집 시각을 둔다. 매일 공간 전체를 다시 만들지 않는다.
- 공개 매장만 사용하며 주문자 주소·얼굴·번호판·전표·실제 출입 권한을 공개 지도에 옮기지 않는다.
- 방문 순서 연결선은 실주행 경로가 아니다. 실제 경로 근거가 없으면 차량이 실제 도로를 주행한 것처럼 재현하지 않는다.
- 배달 저장소의 편집 전 주소/좌표/핀 검증과 전체 정보 충족 관문을 따른다. 미확인 위치를 생략하거나 임의 대체하여 렌더링하지 않는다.
- 확정본/검토본, 실제 촬영/재구성 장면, 원본/추정값을 구분한다. 기존 원본·확정본은 보존한다.

## 미정·다음 질문

미정: 두 날짜의 실제 중복 매장·지역 분포, 기존 디오라마와의 겹침, 첫 대표 구역, 필요한 상세 자료와 자산. 아직 전체 영상을 재검토하거나 매장 대조를 완료하지 않았다.

다음 질문은 지금 없음. 후속 조사에서 두 날짜 방문 목록과 기존 디오라마를 비교하여 첫 구역 후보를 제시한다. 이번에는 기획만 기록하며 자료 수집·모델링·코드·Unity·영상 편집·캡처·commit·push는 하지 않았다. 기존 출처·개인정보·표현/사실 분리 원칙 유지, 새 디오라마 규칙 후보 없음.
