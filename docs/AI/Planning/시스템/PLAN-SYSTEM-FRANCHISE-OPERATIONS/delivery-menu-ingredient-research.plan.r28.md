# 배달 메뉴에서 재료·가격·무역 자료로 이어지는 조사 기획 r28

- 기준일: 2026-09-24
- 상태: 사용자 방향 기록 / 첫 조사 대상 미정 / 자료 조사 실행 전
- 관련: [배달 영상용 디오라마 r27](delivery-video-diorama-detail.plan.r27.md), [계층별 자료 선행 r26](hierarchical-data-first.plan.r26.md)

## 확정한 방향

당분간 사용자가 배달하면서 접한 음식점 메뉴를 분석의 출발점으로 삼는다. 기존 배달 기록에서 메뉴를 정리하고, 근거 자료로 재료 후보를 조사하여 국내 가격과 수입·수출 통계에 연결한다. 축적한 정보는 나중에 영상 편집의 짧은 설명 카드나 Unity 디오라마의 선택 상세 자료로 활용할 후보이다. 카메라·모델링·기존 영상 재편집을 선행 조건으로 요구하지 않는다.

## 자료 관계

방문 기록 → 공개 매장/지점 → 확인된 메뉴 → 근거 수준을 표시한 재료 후보 → 재료 규격 → 국내 가격 관측 및 HS 분류 후보 → 해당 기간·국가·방향의 무역 관측.

- 같은 메뉴의 반복 방문은 방문 기록으로 누적하되 메뉴·재료 원본은 중복 생성하지 않는다. 재료 가격은 기준일별 관측으로 관리한다.
- 브랜드·매장의 공식 설명에 명시된 재료, 신뢰할 수 있는 일반 조리 자료의 재료, 추론 후보를 구분한다. 일반 레시피를 해당 지점의 실제 배합·원산지·납품처로 단정하지 않는다. 메뉴 이름만으로 알레르기나 성분의 부재도 보장하지 않는다.
- 재료와 HS는 항상 1:1이 아니다. 원물/가공·냉장/냉동·부위·혼합 여부와 코드 판본을 확인하고 불명확하면 복수 후보/미매핑으로 남긴다. 매핑은 해당 음식점이 실제 수입 재료를 쓴다는 증거가 아니다.
- 국산/수입, 도매/소매, 품종·등급·포장량, 지역, 조사일·단위·통화를 보존한다. 환산은 입력값과 계산식·환율 기준일을 함께 남긴다.
- 무역금액과 순중량/수량의 범위가 일치하고 분모가 양수일 때만 참고 단위가액을 계산한다. 무역 단위가액을 국내 판매가격·매장 매입가격·메뉴 원가로 표시하지 않는다. 수입/수출의 평가 기준 차이는 원자료 설명과 함께 확인한다.

## 기존 기능과 결손

별도 배달 저장소의 `premiere-control/menu_pipeline.py`와 메뉴 근거 기록을 재사용할 후보로 확인했다. Hongdal의 `eng/Ssalddel.PublicDataPortalImport/Hs무역조회Pipeline.cs`는 현재 조회 사본에서 2025년 한국 수입·H6/HS2022 범위를 검사하며 `exportStatus=NotCollected`를 출력한다. 따라서 이 경로에 수출 가격까지 이미 준비됐다고 보고하지 않는다. 메뉴→재료→HS 연결과 국내 가격 결속은 별도 조사·검증이 필요하다. 이번에는 DB 재조회나 통계 갱신을 수행하지 않았다.

## 작은 조사 단위 제안

9월22·23일의 확인된 메뉴 중 하나를 선택 → 대표 재료 2~3개 조사 → 규격이 맞는 국내 가격과 무역 관측 대조 → 출처·판본·결손을 포함한 조사 카드 한 장으로 검토한다. 실제 반복 메뉴·첫 대상은 아직 집계/선정하지 않았다. 모든 재료·전국 음식점 분석을 한 번에 시작하지 않는다.

실제 조사 착수 시 기존 수집/가져오기와 로컬 DB 파이프라인을 먼저 대조하고 출처·이용조건·hash·비공개 검토 상태·중복 방지·독립 재조회를 남긴다. 키·자료 접근·DB 환경 불일치로 막히면 그 단계만 명시하고 운영 DB로 우회하거나 문서 작성만으로 수집 완료 처리하지 않는다.

## 미정·다음 질문

미정: 첫 메뉴와 재료, 실제 매장 설명 근거, 적합한 국내 가격 공급자, 기간·규격을 맞출 수 있는 무역 자료, 추가 수집 권한. 공급자의 최신 제공 범위·가격·권리는 실제 조사 때 공식 근거로 확인한다.

다음 질문 하나: 우선 두 날짜에 이미 확인된 메뉴 중 하나를 골라 대표 재료 2~3개로 조사 표본을 만들까? 추천은 이 범위이며 아직 메뉴를 임의 확정하거나 새 수집을 시작하지 않는다.

이번 변경은 기획 문서·목차·상태뿐이다. 실제 메뉴 성분/가격·수출입 자료 수집, DB 저장·재조회, 코드·Unity·영상 편집·commit·push 없음. 새 디오라마 규칙 후보 없음.
