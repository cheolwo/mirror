# 원두 배송 시각 샘플 r6

2026-09-23 사용자 요청: 간단하게 Unity에서 만들어 생활상을 확인한다.

## 승인 범위

기획 시안의 로컬 Editor 시각 표본만 구현한다. 게임 업무 WI·제조·재고·운송 실행은 이번에 추가하지 않는다. 따라서 WI Goal 활성화나 업무 E 승격 대상이 아니다. 기존 canonical SimulationWorldShell에 저장하지 않는 임시 루트로 조립하며 다른 Scene을 만들지 않는다.

- 합성 제조시설/카페2곳·트럭1대·담당자2명·상자와 단순 도로. 실제 이천/서울 지도나 실제 건물 재현 아님.
- 표본 시계로 출발 대기→이동→인계 대기를 연출한다. 자동 완료/인수/재고 쓰기·반복 운행 없음.
- 전체/카페 카메라 관점 변경은 같은 객체를 유지한다. 상세 선택·표본 재생·닫기만 허용한다.
- 외부 API·DB·운영 서버·기존 물류 체크포인트를 호출하지 않는다. 서버 관찰 실패를 대체하지 않는다.
- 수정 경로: 별도 Unity 저장소 `Assets/Ssalddel/Presentation/WorldMap/원두배송시각표본View.cs`와 `.meta`, 관련 EditMode 시험과 `.meta`, `Documentation/Changes/2026-09-23-coffee-preview/`; Hongdal의 본 기획·목차·현재 작업만.

## 검증 경계

준비/표본 입력은 이번 문서, 논리는 표본 시간과 위치 보간에 한정한다. 실제 플레이 폐루프 E1~E7 완료를 뜻하지 않는다. 시간 경계·끝점 정지·반복 없음·ID 보존을 자동 시험하고, Play Mode에서 생성/이동/정차·카메라·Game View를 별도로 확인한다. 시각 실패 시 배치/카메라로, 컴파일 실패 시 코드로 돌아가며 업무 상태를 변경해서 해결하지 않는다.

미포함: 기존 행정동 경계와 정확 좌표 결속, 계층별 스트리밍, 제조 Lot 인계, 운영 데이터 연결, 실제 도로, 빌드 배포. 후속 연결은 r5의 계약·WI 검증 관문을 유지한다.

출처: 사용자가 승인한 합성 표현 기획. 실제 지리 근거 없음. 새 디오라마 규칙 후보 없음.
