## 첫 구간에서 할 일

1. 기존 건물·도로·자료 출처를 같은 구간에 모으고, 실제로 빠졌거나 단순화된 형상을 확인한다. 관찰 가능한 기초 형상과 자료 결손을 한 표에 기록한다.
2. 확보한 원본에 더 자세한 건물 외곽·분리된 건물 부분·빈 공간이 있다면 현재 화면에서 소실되는 지점을 먼저 고친다. 없는 형상을 추정해 사실로 채우지 않는다.
3. 도로 실폭·보도·출입구는 해당 원본이 있는 항목부터 연결한다. 차선이나 도로 중심선만으로 폭·통행 가능성을 확정하지 않는다.
4. 같은 카메라의 전후 화면으로 변화와 남은 결손을 확인한다. 하나의 작은 구간이 개선된 후 인접 구간이나 후속 동으로 옮긴다.

첫 구간의 완료 기준은 자료 수나 선분 수 증가가 아니라, 선택한 거리의 건물·길 관계가 전보다 구체적으로 읽히고 그 변화가 원본과 연결되는 것이다. 출입구·외관·높이처럼 자료가 없는 항목은 미확인 상태로 보인다. 촬영 자료를 현재 전달받을 수 없는 조건에서 가능한 작업을 우선한다.

읽기 전용 감사에서 현재 면목제3·8동 상세 보기의 건물 `vworld:al-d010:0000208470354536004400000000`에 구체적 결손을 확인했다. 원본 `AL_D010:Seoul:20260809`에는 닫힌 점 13개·선분 12개의 내부 ring 한 개가 있으나 현재 외곽선 32점 표현에서는 생략된다. 짧은 선분·중복·외곽선 포함 실패는 없다. 이 한 건의 표현 보완을 첫 검토 후보로 둔다. 안뜰·출입구·통행 또는 실제 건물 절삭 의미는 아직 확인되지 않았으며 원본의 `RightsConflictUnresolved`도 유지한다.

범위 축소 직전 작성된 `eng/neighborhood/administrative_dong_building_interior_ring_private_review_r1.py`는 미실행·미검증 초안으로만 보존한다. 관련 실행 프로세스는 종료됐고 r8 결합 생성기·새 세대·Unity 적용은 시작하지 않았다. 이 초안을 완료된 생성기로 사용하지 않는다.

## 작업량·검증 상한

- 자료 감사는 선택 구간 우선, 생성과 실제 화면 확인은 활성 동 1개 우선이다. 기존 생성기가 전체만 지원하면 좁은 선택 기능을 먼저 준비하며 문서 변경을 구현 완료로 보고하지 않는다.
- 코드 변경에는 관련 집중 시험을 실행한다. 공통 계약 변경으로 전체 영향이 생길 때만 적절한 회귀 범위를 넓히고, 수정할 때마다 30개 화면을 다시 찍지 않는다.
- r38의 완료 입력·31개 화면·44/44 시험은 이전 전체 기준선으로 재사용한다. 미완성 다음 세대가 있으면 별도 후보로 보존하고 완료 세대와 섞지 않는다.
- 이번 변경은 작업 범위와 우선순위다. 새로운 도형 생성·Unity 표현 변경·Scene 저장·현행 경계 승인·DB/공개/통행/Gameplay 권위 승격을 뜻하지 않는다.
