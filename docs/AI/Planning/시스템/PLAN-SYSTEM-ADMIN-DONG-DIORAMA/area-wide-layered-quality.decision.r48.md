## 확정과 이전 선택의 대체 범위

**현재 작업 범위 전체의 공통 품질을 먼저 맞추고, 같은 범위에 상세 표현을 한 층씩 누적한다.** 한 골목이나 건물만 먼저 최대 수준으로 완성해 주변과 큰 격차가 생기는 제작 순서는 이 결정으로 대체한다.

r46의 **한 작은 구역을 충분히 정밀화한 다음 옆 구역을 연다**는 우선순위를 수정한다. r47에서 선택한 디테일한 디오라마의 분위기는 장기 시각 목표로 유지하되, 상세를 더하는 순서와 분포를 바꾼다. 사진 전면을 갖춘 몇 점포가 주변의 공통 품질을 앞질러야 한다는 요구로 해석하지 않는다.

여기서 전체는 **현재 시안·검토 대상으로 고정한 디오라마 범위 전체와 연결해 표시하는 이웃 부분**이다. 공통 표현을 기존 모듈에 재사용할 방향이며, 새 지역 무제한 편입이나 과거 30동 자료 재생성·Unity 전면 적용을 일괄 승인한 것은 아니다. 첫 250m 창은 빠른 비교·성능/회귀 시험의 표본으로 유지한다. r47의 건물 세 곳은 공통 표현을 시험하는 표본이며 그 건물만 별도 완성 구역으로 만들지 않는다.

## 전체에 반복해서 더할 표현 층

| 작업 순서 | 범위 전체의 목표 | 확인과 자료 경계 |
| --- | --- | --- |
| 1. 전체 바탕 | 벽/지붕의 기본 구분, 공통 색·재질·조명·음영과 건물 사이 틈 판독 | 중심·주변·경계가 같은 기본 품질을 갖는지 확인. 실제 외곽/높이·도로 위치와 근거 종류 보존 |
| 2. 건물 공통 표현 | 검토된 지붕 가장자리·벽/창 표현을 같은 규칙과 밀도로 누적 | 특정 건물만 과도하게 튀지 않도록 전체/근접/경계를 비교. 실제 지붕·층수·창 개수는 근거 없이 확정하지 않음 |
| 3. 거리·보행 | 기존 두 층 위에 도로·보행·경계가 자연스럽게 이어지는 표현 | 실제 면·실폭·출입구는 정확 자료가 있는 구간부터 결속. 미확인 구간은 공통 기본 표현으로 연결하고 통행 권위를 생성하지 않음 |
| 4. 매장·지역 고유 정보 | 공통 기본 수준 위에 근거 있는 점포 전면·실제 사진·방문 기록을 연결 | 상호/건물/호실 동일성·사진 이용조건·데이터 상태 확인. 미확인 곳을 허구 상세로 채우지 않음 |

작업층 번호는 계획 순서이며 G/E 성숙도나 LOD 단계가 아니다. 지역마다 서로 다른 실제 형상·높이·용도를 같은 모양으로 만들지 않는다. 공통 품질은 표현의 일관성이며 자료의 종류·양·정확성이 모두 같다는 뜻이 아니다.

## 한 층의 제작·검토 순환

1. 원본 ID·형상·높이 종류가 고정된 작은 표본에서 공통 규칙과 시안의 차이를 확인한다. 전체에 반복 사용할 수 있는 재질·표현 규칙을 우선하고 개별 전면 조각을 첫 목표로 삼지 않는다.
2. 같은 작업층을 현재 고정 범위 전체에 적용할 후보와 결손 상태를 준비한다. 자료가 없어 적용할 수 없는 부분은 기본 표현과 이어지도록 검토한다.
3. 같은 카메라의 전체·근접·경계 및 이웃 지역 전환/복귀에서 품질이 갑자기 바뀌는지 확인한다. 성능도 같은 장치·입력 판본·카메라로 비교한다.
4. 이번 층의 사용자 화면 검토와 남은 결손을 기록한 뒤 다음 층으로 간다. 새 지역은 현재 공통 기본 품질로 들어오도록 계획하고, 지역 고유 상세는 자료가 확인된 뒤 보탠다.

상세 전환은 카메라 거리와 판독 필요에 맞게 일관되게 적용한다. 지역 경계만으로 상세 수준이 급격히 달라지지 않는지 확인하되, LOD 수치·성능 한도·실제 자료 결손을 시안만으로 해결됐다고 기록하지 않는다.

## 수정 시안

내장 `image_gen`으로 **전체 바탕 정리 → 건물 표현 추가 → 거리와 매장 연결**의 세 패널을 만들었다. 작업 폴더는 `artifacts/local/store-diorama-binding-20261029/layered-visual-preview-r48/`이며 선택한 `01-area-wide-layered-detail.png`, `prompt.json`, `preview-manifest.private.json`을 보관한다.

같은 구역에 같은 층을 누적한다는 제작 의도를 보여주는 생성 시안이다. 세 패널의 배치·카메라가 결정적으로 일치하는 실행 비교나 실제 건물 ID/원형·높이·외관의 검증 결과가 아니다. 새 지붕·벽/창·보행면·점포 전면은 표현 제안이며, 원천 숫자 높이와 임시 4m를 실제 구현에서 바꿀 승인으로 사용하지 않는다.
