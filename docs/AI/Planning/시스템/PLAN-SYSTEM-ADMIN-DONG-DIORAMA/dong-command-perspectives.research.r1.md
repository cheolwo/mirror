## 각 입장에서 보이는 것과 결정

배경은 별도 가상 동의 **흑광 경보 한 건**이다. 골목과 건물은 동 디오라마의 외형을 참고한 합성 모형으로 두고, 인물·건물·사건은 가상 식별자를 쓴다. 화면을 바꾸어도 사건과 기록은 이어진다.

| 입장 | 지금 보는 정보 | 플레이어의 선택 | 선택이 확인되는 곳 |
| --- | --- | --- | --- |
| **분대장** | 내 대원의 활동·휴식 상태, 확인이 필요한 주민 안내 요청 | 내 분대의 휴식을 요청하거나, 확인한 상황을 보고한다. | 분대 카드에 요청 접수가 뜨고, 다음 보고에 휴식 시작이 표시된다. |
| **중대장** | 소대별 요약, 보고 갱신 시각, 교대 가능한 팀, 미처리 요청 | 어떤 팀을 먼저 쉬게 할지, 어떤 요청에 지원을 우선할지 정한다. | 교대가 승인된 이유와 지연된 요청이 목록에 남는다. |
| **대대장** | 중대별 지원 대기, 공용 지원 잔량, 주민 안내와 회복 현황 | 공용 지원을 어느 중대에 우선 배정할지, 이번 회차에 얼마나 남길지 정한다. | 결정, 배정, 도착을 나눠 기록하고 중대장 화면에서도 결과를 확인한다. |

보고 상태는 **확인됨 · 갱신 대기 · 미확인**으로 구분한다. 상위 화면에는 마지막 보고 시각을 붙이고, 확인되지 않은 수치를 0으로 세지 않는다. 역할을 바꿔 같은 선택의 전후를 읽을 수 있게 한다. 관찰을 선택했을 때는 사건 흐름을 따라가고, 직접 개입할 때는 현재 역할에 해당하는 선택을 한 건씩 펼친다. [홍달의 관찰과 선택적 개입](../PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION/optional-observation-and-intervention.design.r328.md)

## Claude 시안에 넣을 첫 장면

1. **경보**가 뜨면 가상 동과 첫 분대 카드가 열린다. 분대장은 피로를 확인하고 휴식을 요청한다.
2. **중대장 카드**를 선택하면 같은 요청이 올라와 있다. 교대 가능 상태를 보고 일정을 승인하거나 추가 정보를 요청한다.
3. **대대장 카드**를 선택하면 여러 중대의 요청이 요약된다. 공용 회복 지원을 승인하면 대기에서 배정으로 바뀌고, 도착은 이후 보고에서 확인한다.
4. **경보 종료** 뒤 결산에서 주민 안내 완료, 대원 휴식·복귀, 미처리 요청을 확인한다. 지원이 늦으면 미처리 항목의 이유와 다음에 확인할 일을 남긴다. 분대 카드를 다시 열어 처음 요청이 어떻게 처리됐는지 보고 같은 동 화면으로 돌아온다.

기존 시안의 분대 카드 위치를 활용해 역할 이름, 가장 중요한 수치, 선택 한 건을 먼저 보인다. 중대·대대에서 여러 하위 팀이 필요할 때는 가상 예시 카드로 비교하고, 첫 장면의 관찰 범위는 맡은 동에 둔다. 시안의 검토 기준은 세 화면에서 각자 결정할 것이 서로 다르고, 중대와 대대의 선택이 분대에도 보이며, 같은 사건의 결산으로 돌아오는지다.
