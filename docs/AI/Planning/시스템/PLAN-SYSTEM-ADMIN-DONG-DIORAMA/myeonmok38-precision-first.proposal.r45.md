## 먼저 대조한 실제 차이

면목제3·8동의 기존 Game View는 건물 2,700개·도로 중심선 291개의 광역 기초 표현이다. 건물은 공통 결합 Mesh의 단색 재질·평평한 지붕 압출, 도로는 실제 폭이 아닌 2.4m 기호 선분이다. 전체 건물 중 1,809개의 4m 높이는 원천 측량값이 아니라 fallback이다. 한 건물의 빠진 내부 ring은 r40에서 원본에 맞춰 복원했다.

사가정의 재질·조명과 세 점포 창틀·차양·간판·유리 전면은 서로 다른 비공개 시범이다. 상세 전면은 세 대상 상한과 정확 건물 ID/사진 근거를 요구하고 정본 적용은 0건이며 Game View·FPS는 검증되지 않았다. 이를 행정동 전체 건물에 일괄 복사하거나 현재의 실측 외관으로 표시하지 않는다.

## 첫 250m 공간 연구 창

면목제3·8동의 기존 공통 ENU 좌표 `centerX=28.5m`, `centerZ=140.6m`, `halfExtent=125m`인 정사각형 창을 첫 비교 대상으로 둔다. 이는 실제 배달 매장 위치가 모인 사가정역 주변의 **비공개 작업 창**이며 새 행정동 경계나 운영 구역이 아니다. 원본 모듈과 매장 후보 대장의 고정 지문은 r44에 있다.

| 이 창의 실제 후보 자료 | 수량 | 표현 상한 |
| --- | ---: | --- |
| 창과 교차하는 건물 외곽 | 346개 | 역사 경계·2026-08-09 GIS 후보 원형 |
| 원천 숫자 높이 | 91개 | 값 출처를 보존; 지붕·층수·실측 전면 추론 금지 |
| 기호 높이 4m | 255개 | 실제 건물 높이로 설명하지 않음 |
| 개인 배달 매장 위치 | 17개 | 건물 16개에 점 포함 후보, 매장/호실 동일성 미확정 |

`artifacts/local/store-diorama-binding-20261029/precision-window.private.json`에 좌표·수량·원천 지문을 남기고, `myeonmok38-precision-window.private.png`는 **같은 후보 외곽과 높이값만으로 만든 비공개 2.5D 연구 그림**이다. 이것은 새 Unity 캡처가 아니며 창·지붕·간판·도로 실폭을 추가하지 않았다. 별도 생성한 정밀화 목표 이미지는 시각 방향 시안일 뿐 건물별 실측 자료가 아니다.

## 정밀화 순서와 재사용 범위

1. **원형과 높이 감사:** 346개에서 기존 모듈/원본 `AL_D010_11_20260809.zip`의 외곽·내부 ring·높이 종류를 대조한다. 빠진 내부 ring은 해당 원본 건물 ID가 정확히 맞을 때만 보완한다. 지붕 유형·창 개수·층수는 자료 없이 생성하지 않는다.
2. **공통 화면 품질:** 광역/근접 카메라에서 같은 공간 판본의 건물 간 틈, 원형 판독, 기호 높이와 숫자 높이의 구분, 거리별 간략화, 중립 재질·광원·가림과 선택 윤곽을 개선할 표현 설계를 만든다. r113의 사가정 시범을 방법 참고로 사용하되 새 구역과 동일 렌더러/설정 적용이라고 주장하지 않는다.
3. **도로·보행의 사실성:** 현재 2.4m 선분은 위치 안내로만 남긴다. 실제 도로면·보도 폭과 출입구, 지형 높이는 해당 공식 원본·좌표계·기준월과 정확 구간 결속이 마련된 뒤 표현한다. 없는 면을 화면의 사실로 채우지 않는다.
4. **근접 외관:** 창 안의 매장 후보 17개 중 정확 지점·촬영 원본·현재 보호·사용 조건이 확인된 건물만 별도 사진 참조 전면 연구 대상으로 고른다. 기존 세 점포의 전면 모델을 다른 매장에 복제하지 않는다. 원형/중간/상세 전환과 로딩 실패·해제 원형 복귀를 대상별로 검증한다.
5. **지역 확장:** 첫 창의 원형·표현·선택·복귀·성능과 실제 Game View 근거를 닫은 뒤, r44의 다른 창·행정동에도 같은 `G0~G4+G6` 검사표를 적용한다. 지역마다 건물 수·외관 자료량이 달라도 결손을 숨기지 않는다.

## 적용 전 연구·개발 관문

이 작업은 건물·공간 표현이 실제 플레이 경험을 좌우하므로 건물 원형/높이/도로/외관을 소유하는 전문 연구를 `Required`로 분기하고, 출처·권리·후보 판본·반례·시각 목표·원형 복구 조건을 사람 검토해 `Accepted`로 다시 결속해야 한다. 기존 r40의 단일 건물 승인과 r113/r114의 사가정 전용 허용 경로는 346개 창 또는 행정동 전체의 자동 구현 승인이 아니다.

새 Unity 구현 전에는 이 PLAN의 `Approved` 판본/hash, 대표 WI의 E1~E7 상호작용 수직 검증 명세, 현재 Goal/소유 경로와 `ReadyToDispatch` 작업 명세를 결속한다. 기존 `SimulationWorldShell`과 `행정동디오라마검토MeshBuilder/View`를 유지하며 Scene·원장·운영 DB와 현재 공간 pointer를 조용히 바꾸지 않는다. 행정동 GIS 원본의 `RightsConflictUnresolved / DistributionNotApproved`는 계속 비공개 검토 상한이다.

## 검증할 화면과 상한

같은 카메라의 기존/새 후보/복구 비교, 건물 외곽·빈 공간·높이 종류의 판독, 다른 건물 불변, 건물 선택·해제·지역 재진입, 관련 Unity 시험, 실제 Play Mode·Game View·Console·Scene/원본 hash와 근접 성능을 분리 기록한다. AI 시안이나 이번 2.5D 연구 그림은 새 Unity 실행 증거가 아니다. 실제 외관 사진·현행 건물/출입구·도로 폭·지형 DEM·공개 사용이 미확인인 경우 그 층의 완료를 주장하지 않는다.
