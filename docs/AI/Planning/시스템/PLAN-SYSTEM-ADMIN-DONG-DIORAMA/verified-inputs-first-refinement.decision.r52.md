## 작업을 고르는 기준

이미 확인된 자료로 가능한 개선을 먼저 실제 결과까지 마친다. 짧게 확인할 수 있는 항목은 필요한 부분만 검증하고 이어간다. 근거가 부족한 한 항목 때문에 준비된 다른 일을 멈추지 않는다.

| 현재 상태 | 바로 할 일 | 완료 근거 |
| --- | --- | --- |
| 확인됨·사용 가능 | 기존 입력·에셋·허용 경로로 작은 보완 | 같은 입력/카메라의 전후 결과와 검증 |
| 지금 검증 가능 | 입력 판본·실제 활성 경로·출처 대응 등 필요한 부분만 확인하고 통과한 내용으로 작업 | 확인한 자료/조건·결과 및 이어진 보완 |
| 근거 부족·새 선택 필요 | 해당 부분은 후보/미확인으로 보존하고 준비된 다른 작업 진행 | 부족한 자료, 필요한 결정 또는 대체안 |

단순히 확인했다는 보고에서 끝내지 않고 **작은 대상 선정→보완/수집→전후 비교→입력/결과 보존**을 한 회차로 닫는다. 그날 사용할 수 있는 자산과 현재 검증 환경에 따라 닫을 수 있는 범위를 고른다. 실행 가능한 항목이 없을 때에는 이유와 필요한 입력을 짧게 남긴다.

## 사가정에서 우선할 수 있는 개선

아래는 기존 근거를 재확인한 뒤 선택할 작업 후보이며, 이번에 새 구현을 완료했다는 뜻이 아니다.

1. **공통 표현층:** 확인된 건물 외곽·높이·배치를 보존하고 벽/지붕 명암·창 격자·재질의 일관성을 opt-in 사본에서 개선한다. [전체 구역 품질층 r48](area-wide-layered-quality.decision.r48.md)대로 현재 구역에 같은 층을 누적한다.
2. **도로 연결과 경계:** 기존 노드·선분을 보존하면서 눈에 보이는 접합 틈·표면 경계·그림자 가림을 보완한다. 현재 자료에 없는 실폭·통행 방향을 새로 만들어 넣지 않는다.
3. **확인된 전면과 촬영 판독성:** 사진 근거가 있는 점포의 전면·차양·문틀 표현과 [픽업/라이딩 r122](../PLAN-SYSTEM-REGIONAL-OPERATOR-SIMULATION/pickup-riding-threeway.prototype.r122.md)의 같은 구간에서 가림·촬영 높이를 대조한다. 보이지 않는 뒤쪽 외관을 실제 관측처럼 채우지 않는다.

[사가정 제작 추출 r50](sagajeong-construction-recipe.extract.r50.md)에서 기존 자산과 실제 활성 경로를 먼저 확인하고 변경된 원문만 추가로 읽는다. Synty와 공간층의 배타 조건을 무시해 동시에 켜거나 비공개 후보를 정본으로 승격하지 않는다. 영상/시안이 잘 보이는 것과 실제 장소 동일성·업무 완료는 구분한다.

## 질문과 보고

현재 승인 범위의 일상 구현 선택은 매번 다시 묻지 않는다. 이미 준비된 작업을 진행하고, 새 외관/스타일의 제품 선택·추가 에셋 구매·근거 없는 실제 형상 확정이 필요할 때만 구체적인 후보와 이유·대체안을 보고한다. 기존 시안 선행·전후 대조·출처/권리·소유 경계는 유지한다.

보고는 **무엇이 어떻게 좋아졌는지 / 무엇으로 확인했는지 / 아직 무엇이 미확인인지**를 중심으로 짧게 쓴다. 필요한 자료/에셋과 다음 작은 작업을 붙이되, 확인되지 않은 아이디어를 완료나 현재 사실로 표현하지 않는다.

## 확정·미정·다음 질문 하나

- 확정: 사용자 표현은 ‘고도화’다. 확인된 입력과 지금 검증 가능한 항목을 우선하고 같은 조건의 전후 결과까지 이어간다. 사가정 시작·전체 품질층 누적·매일 한 번의 순환은 유지한다.
- 미정: 각 회차의 실제 결손·자료 접근·활성 경로와 선택할 작은 작업은 그날 확인한다.
- 다음 질문 하나: 이 방향은 확정했으므로 다시 묻지 않는다. 준비된 범위를 진행하고 실제 새 에셋/표현 선택이 필요할 때 그 차이 한 가지만 검토한다.
