## 화면에서 읽을 것

- 왼쪽 지도에서 민트 실선은 기존 주 도로망, 옅은 갈색 실선은 주 도로망과 끊긴 골목이다. 금색 점선은 OSM 후보 도형이다. 양 끝의 원은 실제 접속을 확인할 곳이며, 작은 점은 검토 중인 건물 7채의 위치다.
