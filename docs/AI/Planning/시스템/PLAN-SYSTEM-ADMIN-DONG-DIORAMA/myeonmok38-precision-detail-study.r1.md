## 연구 질문과 사용 문맥

사가정역 주변을 관찰하는 플레이어가 한 구역을 확대했을 때 건물 원형·높이 출처·골목의 위치 관계를 구체적으로 읽을 수 있도록 무엇을 먼저 보완해야 하는가? 대상 건물 선택과 근거 확인 뒤 해제·재진입했을 때 같은 공간으로 돌아오는 읽기 전용 관찰을 준비한다. 배달 매장 위치는 별도 후보 층이며 방문 기록이나 사진 자체가 건물 동일성을 확정하지 않는다.

현재 직접 결과는 관찰과 선택 상태다. 경영 점수·수익·실제 배달 상태 변화는 이번 연구에 없다. 선택한 대상만 상세히 보는 동안 다른 정보가 접히며, 불확실한 위치·사진·높이는 확인 대기로 남는다는 기존 r44의 대가·회복 의미를 유지한다.

| 대안 | 기대 효과 | 비용·위험 | 판정 |

연구 기준선은 첫 창의 원형·높이 감사, 연속된 교차로/골목의 근접 판독, 기존 선택·해제·복귀를 묶는다. 어떤 건물을 고칠지는 원본 대조에서 나온 결손으로 정한다. 공통 재질·조명의 시각 후보는 같은 카메라로 비교하며 현장 외관 복원과 구별한다.

## Building — 측정과 보완 후보

1. 346개 stable ID를 원본과 대조한다. 원본의 모든 외곽/분리 부분·내부 ring 수, 현재 모듈의 외곽, 공통 좌표 변환과 면적 차이를 대상별 기록한다.
2. 소실된 형상이 있으면 원본에서 직접 복원 가능한지와 기존 r40 보완 여부를 구분한다. 안뜰·출입구·통행 의미는 도형으로 추론하지 않는다.
3. 91개 숫자 높이는 출처와 값 보존을 확인하고 255개 fallback은 실제 높이 확보 전까지 기호값으로 유지한다. 대장 근접·필지 일치만으로 높이를 이식하지 않는다.
4. 지붕·전면·층수·사진·정확 출입구는 별도 후보 대장에 근거가 있는 대상만 준비한다. 상세 모델의 무자료 일괄 생성을 하지 않는다.

원본 대조의 결과 파일은 `artifacts/local/store-diorama-binding-20261029/precision-source-audit-r1/`에 둔다. 원본/모듈 지문·실행 코드 지문·stable ID별 결과를 남기고 발견되지 않은 결손은 생성하지 않는다.

### 이번 원본 감사 결과

원본 695,761개 레코드를 순회해 대상 건물 346개가 각각 유일하게 일치했다. 도형은 346개 모두 유효하며, 기존 1mm 정규화 뒤의 외곽·높이값·높이 종류가 346/346 일치한다. 원문 비정규화 도형과 모듈의 소수 면적 차이는 좌표 반올림 전후 차이로 보존하며 원문 자체가 byte 단위로 같은 도형이라는 뜻으로 쓰지 않는다.

이 창의 원본은 전부 단일 Polygon·내부 ring 없음으로, 누락된 내부 ring 0개·추가 분리 부분 0개·새 형상 복원 후보 0개다. r40의 복원 건물은 창 밖이다. 91개 원천 숫자 높이와 255개 기호 4m도 재확인했다. 이 결과는 기존 모듈이 원본에서 형상을 빠뜨렸다는 가정을 지지하지 않는다. 현재 건물의 실측 정확성·Unity 적용·외관 완성 근거와는 다르다.

따라서 첫 창의 다음 정밀화 연구는 실제 높이·지붕/전면·도로/보행 자료를 특정 대상과 연결하는 일과 공통 재질·카메라 판독 비교에 둔다. 형상 복원을 보여주기 위한 임의 변경은 만들지 않는다.

## Spatial — 화면과 복귀

- 같은 창·카메라에서 광역/근접의 기존·후보·복구 비교를 준비한다. 카메라 위치·방향·투영·해상도와 입력 판본을 기록한다. 정확 카메라 값은 기존 실제 뷰 재고를 확인한 뒤 정하며 `Draft` 동안 임의 수치를 승인값으로 만들지 않는다.
- 건물 간 틈·원형·빈 공간과 선택 윤곽이 가림·조명 때문에 사라지는지 확인한다. 재질/광원 변경은 실제 외관 자료의 대체가 아니다.
- 건물 선택·해제·지역 재진입에 이전 선택·외관이 잔류하지 않는지 확인한다. 잘못된 데이터나 외관 로딩 실패는 기존 원형으로 돌아오는 조건을 작업 명세에 적는다.
- 기존 도로 중심선은 위치 안내 범위다. 실폭·보행면·출입구·경사·Collider/NavMesh는 정확한 자료와 별도 사용 승인 전까지 통행 가능한 공간으로 승격하지 않는다.
- 성능은 같은 장치·창·카메라에서 프레임 시간 중앙값/p95, draw call·삼각형·메모리와 로딩 시간을 전후 비교한다. 기존 수치·목표값·허용 회귀 폭은 아직 미측정이며 인계 전에 정한다.

## 자산·권위·호환 영향

- 주 표현은 원본 도형에서 얻은 기초 형상과 기존 공통 재질이다. Synty Prefab·새 H1/H2/H3·Actor를 도입하지 않으므로 이번 범위의 재고/조합은 `NotApplicable`이다.
- 사진 기반 상세 전면은 정확 건물 동일성·촬영 원본·보호/이용조건·대체 표현을 별도로 결속하기 전까지 보류한다.
- 서버·Simulation·운영 DB·원장·현재 공간 pointer를 바꾸지 않는다. H Capability·World/Area의 성립을 새로 주장하지 않는다.
- Save/Replay·LocalProcess/RemoteHost의 권위 상태 변화는 없다. 실제 개발에서 선택 저장 또는 신규 조회 계약이 필요하면 연구와 WI 검증 명세를 다시 연다.
- Logic·Presentation의 실제 E 단계는 이번 연구로 승격하지 않는다. 구현용 명세에서 원형/데이터 계약은 Logic E1부터, 배치·카메라 판독은 Presentation E1부터 영향 검토한다.
- Graph Map은 `ReviewRequired`: 기존 관찰/선택 관계 재사용과 형상 보완이 필요한 노드·제약에 미치는 영향만 검토한다. 연구가 Graph Map 원본·생성물을 직접 수정하지 않는다.

## 검증·무효화·검토

자동 감사는 원본 지문·CRS·대상 ID·도형·높이 종류와 수량을 확인한다. 기존 r40 대상과 다른 건물의 불변을 대조한다. 새 형상 구현 시 관련 자료/Unity 집중 시험과 실제 Play Mode·Game View·선택/해제/재진입·복구 화면을 같은 판본으로 검증한다. 연구·정적 그림만으로 실행 검증을 대신하지 않는다.

원본 지문·CRS·대상 경계·직접 건물 대응이 달라지거나 실제 화면에서 거리 관계를 판독하지 못하면 이 연구를 다시 연다. 사진·도로면·DEM·저장·새 행위가 추가되면 해당 분야와 WI 영향도 재검토한다.

- 검토 근거: r46의 제작 방법 동의; r45의 수량·지문·연구 그림 검증; 첫 창 346개 원본 감사 완료·신규 형상 복원 후보 0개.
- 남은 미정: 연속 거리 선택, 실제 높이·외관·도로/보행 자료의 대상 결속, 카메라·성능 수치, 대표 WI·정확한 개발 쓰기 경로와 검증 명세.
- 승인 상태: `Draft`. 사용자 발언은 집중 정밀화 후 확장 방법을 확정했고, 미완성 연구 기준선 전체를 `Accepted`로 승인한 것은 아니다.
- 새 디오라마 규칙 후보 없음.
