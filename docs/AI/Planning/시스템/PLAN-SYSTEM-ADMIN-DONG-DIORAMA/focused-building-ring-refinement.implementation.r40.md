## 우선순위와 첫 대상

기존 30개 행정동 자료와 표현을 보존하며 새로운 게임 기능 확장보다 실제 형상 결손 해소를 우선한다. 첫 적용은 면목제3·8동 `region:kr:hjd:1126057500`의 건물 `vworld:al-d010:0000208470354536004400000000` 한 곳이다. r39에서 찾은 원본 내부 ring 13점·12선분이 현재 최대 외곽선만 사용하는 표현에서 빠져 있다. 이를 원본 경계에 맞는 지붕 삼각분할과 내부 벽으로 복원한다. 내부 빈 공간을 안뜰·출입구·통행 공간으로 해석하지 않는다.

동결 `AL_D010_11_20260809.zip`과 r7 Unity 비공개 검토 세대를 읽는다. 자료의 `RightsConflictUnresolved`를 유지하고 이번 결과는 로컬 비공개 형상 검토다. 기존 외곽선·높이·다른 건물·도로·행정동 경계와 공개·DB current pointer·Runtime·Traversal·Gameplay 권위는 바꾸지 않는다. 높이 4m는 기존 기호값이며 측량 높이로 보고하지 않는다.

## 구현과 검증

1. 별도 단일 대상 생성기에서 원본 ZIP/기존 세대 hash·좌표계·건물 동일성을 확인한다. 기존 미완성 전지역 내부 ring 초안은 실행하거나 덮어쓰지 않는다.
2. EPSG:5186 원본을 기존 공통 ENU/1mm 정밀도로 변환하고 외곽선이 기존 건물과 정확히 일치함을 확인한다. 내부 ring·삼각분할 지붕·출처와 차단 상태를 별도 불변 검토 세대에 저장한다. 재검증은 원본을 다시 읽어 bytes/hash를 대조한다.
3. 기존 Unity MeshBuilder에 명시적인 단일 대상 보완 인자를 추가한다. 입력이 없으면 기존 출력과 동일하다. 잘못된 대상·도형·권위를 거부하고, 읽기 전용 선택도 빈 공간을 막힌 지붕으로 선택하지 않게 보완한다.
4. 자료 시험과 Unity 집중 회귀를 실행한다. 지붕 union·면적·중복·빈 공간 겹침·내벽·다른 형상 동일성을 확인한다. 월드 담당이 동일 카메라의 전후 실제 Game View를 캡처하며 Scene을 저장하지 않는다.

실제 입력 검증 중 발견한 높이 근거 분류 오류도 좁게 정정한다. 생성기의 정확한 `:SymbolicHeightFallback` 표식과4m가 함께 있는 건물은 `SymbolicFallback4m`으로 읽는다. 수치 높이와 기존 표시 색은 유지하며 층수에서 새 높이를 계산하지 않는다. 실제 원천 높이4m는 기호값으로 바꾸지 않는다. 첫 건물의 결속은 정정된4m/기호 종류를 요구한다. 이는 기존 출처 계약의 오류 수정이며 다른 건물 형상 변경이나 실제 높이 확보를 뜻하지 않는다.

촬영 준비의 기존 기준은 유지한다. 이번 보완의 직접 근거는 확보한 공식 원본 도형이며, 미검토 영상에서 외관·수치 폭·높이를 추정하지 않는다. 보도·도로 실폭·출입구는 원본과 장소 결속이 확보된 다음 별도 보완 대상으로 둔다. 절대 지형 높이는 r36의 수직 메타데이터/consumer 차단을 우회하지 않는다.
