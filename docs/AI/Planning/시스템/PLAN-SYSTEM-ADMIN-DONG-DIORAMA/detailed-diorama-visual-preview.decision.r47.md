첫 장의 왼쪽은 r45의 실제 후보 도형 그림을 참고해 **생성한 기초 표현 요약**이며 원본 캡처를 그대로 붙인 전후 시험이 아니다. 오른쪽은 사가정의 기존 비공개 재질·조명 시범을 참고해 만든 개선 목표다. 두 패널은 동일 카메라·동일 건물 ID·346개 전수 배치를 보증하지 않는다. 새 지붕·창·층수·외관·보도/도로 폭·가로 시설의 정확 위치는 표현 제안이다.

두 번째 장의 벽돌 건물·주황 차양·상호 없는 전면은 예시 외관이다. 오른쪽 사진 영역에는 실제 사진 대신 빈 연결 영역을 표시했고, 배달 기록도 `방문 기록 연결 예정`으로 표시했다. 실제 매장·음식 사진·수익·배달 수·운영 상태를 꾸며 넣지 않았다. UI의 `M 지도`, `구역 전체`, `선택 해제`도 동작 목표이며 실제 입력 구현 증거가 아니다.

## 이번에 확정한 시각 기준

사용자는 단순화한 장난감풍보다 **지금 시안 수준의 디테일한 디오라마**를 선택했다. 다음 후보 표현은 벽·지붕의 재질 차이, 창틀의 깊이, 매장 전면·입구·차양, 경계석과 보행면, 부드러운 그림자와 가림을 통해 가까이서도 장소 관계가 구체적으로 읽히는 수준을 목표로 한다.

구역을 확대하고 한 건물을 선택했을 때의 화면 구성까지 시안으로 공유했다. 실제 데이터 연결은 r44의 건물 하나에 여러 매장이 있을 때의 선택, 위치·사진 미확인, 해제·지역 재진입의 귀환 조건을 유지한다. 예시 건물의 형태나 옥상 설비·보도 폭을 실측 사실로 승인한 것은 아니다.

시각 기준을 다시 묻지 않는다. 이후 실제 자료와 선택한 표현을 연결할 때 생기는 구체적인 차이만 대상별 비교로 반환한다.

## 실제 제작 입력으로 바꾸는 순서

1. **기존 건물과 대응:** 첫250m의 실제 건물 ID·원형·91개 숫자 높이/255개 기호 높이를 유지하고, 시안 속 가상 건물을 실제 건물로 대체한다. r46 감사에서 새 형상 소실0개를 확인했으므로 근거 없는 형상 복원을 만들지 않는다.
2. **좁은 표현 후보:** 실제 자료와 매장 후보 위치가 함께 있는 작은 대상부터 공통 재질·조명·근접 카메라를 비교한다. 원천 숫자 높이가 있는 대표 건물도 현행 실측/외관 동일성은 따로 확인한다. 장식·사진 전면 후보는 출처와 대체 표현을 기록한다.
3. **도로·외관 결속:** 시안의 도로/보도·입구·지붕/전면을 그대로 복사하지 않고 공식 공간 자료·정확한 촬영 원본으로 확인되는 대상부터 조립한다. 자료가 없는 층은 기존 기초 표현을 유지한다.
4. **실제 뷰 비교:** 연구 기준선과 구현 인계가 준비되면 기존 `SimulationWorldShell`의 허용 범위에서 같은 카메라의 기존/후보/복구·선택/해제·재진입·성능을 검증하고 사용자에게 실행 화면을 반환한다. 이 결과를 보고 첫 구간의 다음 보완 또는 인접 확장을 정한다.

첫 후보는 작은 원형과 매장 후보 한 곳으로 최소 표현을 준비하기 좋다. 세 번째는 한 건물의 복수 매장 선택을 살필 후속 비교 후보다. 이 선정은 자료 대조이며 사진 외관·출입구·현행 실측·매장 동일성 수용 또는 새 Unity 작업 활성화가 아니다. 시안의 벽돌 코너 건물을 이들 실제 건물의 모습이라고 부르지 않는다.

이번 답변은 **표현 밀도·분위기의 선택**을 확정한다. 건물·공간 연구는 `Draft`이며 아직 미정인 실제 외관/도로 자료·카메라/성능 수치·WI/E1~E7 명세·정확 경로의 구현 인계를 자동으로 `Accepted / Approved / ReadyToDispatch`로 바꾸지 않는다. 제품 코드·Unity Scene·Game View·운영 DB·공개·E 단계·commit/push를 변경하지 않았다.

## 시안 검토와 디오라마 규칙

두 PNG를 시각 확인했다. 첫 장은 오해를 줄이기 위해 왼쪽 표제를 `현재 기초 표현`에서 `기초 표현 참고`로 한 번 수정했다. 최종 두 장의 한국어 표제·범례, 예시 매장·사진 대기·기록 대기·선택 해제와 하단의 시안 표시를 확인했다. 최종 프롬프트 묶음은 같은 폴더의 `prompts.json`이다.

복사한 PNG2개의 SHA-256이 manifest와 일치하고 프롬프트3종 JSON을 재조회했다. 대표 후보3곳의 높이·외곽 면적·창 안 매장 점 수를 독립 계산해 대조했다. 새 문서의 로컬 링크3개·4문서 Fast/diff 검사·디오라마 규칙 r5 Validate가 통과했다. Fast 로그는 `artifacts/local/validation/20261029-165639/`이며 문서 변경으로 build/test를 생략했다. Unity 실행 검증은 수행하지 않았다.

원본 도형·기호 높이·생성 표현·실제 기록/사진의 경계를 유지한다. 이 선택은 개별 시각 기획이며 새 공통 규칙이나 E 증거 승격이 아니다. **새 디오라마 규칙 후보 없음.**
