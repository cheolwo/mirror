Codex는 입력 지문·경계 취득 기록과 대조한 결과를 별도 점검표에 먼저 적는다. 다음 굽기에서 공식·후보·미확인의 실제 값을 전달하도록 고치고 구판과의 호환을 검사한다. 공식 경계 확인, 화면에서 열기, 주행 검증, 게임 검증, 배포 승인은 각각 별도의 증거가 필요한 항목이다.

## 인계 시점과 미정

Codex의 첫 인계 단위는 **두 동의 모듈 목록·품질표·대표 배달 경로·원래 자료로 재현하는 절차**다. Claude는 2.0 시험 사본에서 이를 열고 정상 진입, 실패 뒤 복귀, 실제 배달 관찰의 실행판 기록을 반환한다. 관찰용 판은 지문 검증과 모형·건물 선택 확인으로 판정한다. 배달 가능 판은 문과 길의 연결, 경계 통과, 동일 주문 확인까지 통과해야 한다. 적재시간·최대 메모리는 같은 PC에서 첫 진입/재진입/인접 동 왕복 때 측정한 뒤 허용 예산을 정한다.

**미정**은 2.0의 대외 배포 범위와 성능 목표, 첫 두 동 이후의 추가 편입 속도다. **다음 결정 한 가지**는 두 동의 Windows 결과를 본 뒤 중랑 16동에 관찰 기능을 먼저 열지, 배달 경로까지 검증된 동부터 열지다. 이 결정은 첫 두 동의 자료 준비를 막지 않는다. 이번 판본에서 제품 코드·세이브·빌드·굽기 결과의 변경은 없다. 기존 경로 비교를 계획 근거로 사용했고 새 디오라마 규칙 후보는 없다.
