# 본인 중심으로 시작하고 선택한 자료를 추가로 불러온다

- 판본·기준일: r7 / 2026-09-26
- 상태: `SelfCenteredInitialViewConfirmed / OnDemandObservationConfirmed / ProductImplementationDeferred`.
- 기준선: [가게 중심 지역 관찰 r6](store-centered-regional-observation.direction.r6.md), [GPS 없는 단계 표현 r5](stage-based-delivery-observation.decision.r5.md).
- 사용자 답변: r6의 전체 반경 요약→선택 지역 확대 제안을 수용하고, 본인 중심으로 먼저 조회한 뒤 원하는 부분의 자료를 추가로 불러오는 방향을 확인했다.
- 기존 질문 의미 ID: `store-centered-observation-initial-view` / `Answered`. 기존 미답변 질문의 묶음 승인은 아니다.
- 작업 범위: 기획 문서만. 새 Goal·WI 등록 없음, `ReadyToDispatch=false`. 제품 구현·전국 자료 확보·실행 승인이 아니다.

## 확정한 관찰 순서

1. **본인 중심 첫 화면:** 로그인한 관점에 연결된 가게·업무를 중심으로 주변 관찰 범위를 간략히 보여 준다. r6 음식점 관점에서는 가게를 중심으로 반경 전체의 요약을 먼저 본다.
2. **원하는 지역 확대:** 사용자가 지역을 선택하거나 확대하면 그 부분에 필요한 준비된 지도·건물·도로 자료를 추가로 불러온다. 처음부터 전체 반경의 상세 객체를 모두 만들지 않는다.
3. **원하는 대상 조회:** 가게·기사·주문 같은 대상을 선택하면 현재 권한으로 허용된 업무 상세를 추가 조회한다. 지역 확대와 상세 카드 조회는 서로 다른 요청이다.
4. **다시 넓게 보기:** 축소하거나 다른 곳으로 이동하면 기존 표현 수명 정책에 따라 불필요한 상세 표현을 정리한다. 서버의 업무나 원장을 취소·삭제하지 않는다.

‘본인 중심’은 사용자의 장치 GPS를 자동 수집하거나 카메라를 사람의 현재 위치에 계속 고정한다는 뜻이 아니다. 음식점 관점은 등록 가게 위치를 사용하고, 기사·주문자 등 다른 역할의 최초 중심점은 역할별 후속 기획에서 정한다. 이번에 모든 역할의 첫 화면을 음식점 위치로 고정하지 않는다.

## 유지하는 경계

- r6의 **지도 관찰 범위 / 주문·배달 운영 범위 / 자기 업무 권한**은 계속 분리한다. 더 넓게 탐색하거나 자료를 추가 조회해도 주문 가능 거리·배차 후보·다른 사람의 비공개 업무 권한은 늘어나지 않는다.
- 추가 조회는 기존 서버·보유 자료에서 제공 가능한 정보를 요청하는 것이다. 아직 없는 공간자료의 외부 수집·구매·전국 자동 생성까지 승인한 것이 아니다. 자료가 없거나 불러오기에 실패하면 기존 요약과 해당 상태를 유지한다.
- 업무 관련 사람과 목적지 표현은 r5/r6처럼 허용된 역할·일반화된 기준점만 사용한다. 실시간 GPS는 필요하지 않으며 애니메이션 종료를 실제 도착·업무 완료로 처리하지 않는다.
- 로그인·영업점 전환·권한 회수 때 개인 사본을 분리·삭제하고, 이전 조회가 늦게 도착해 새 관점에 섞이지 않게 하는 r6 경계를 유지한다.
- 초기 전체 요약의 구체 배율·카메라 거리, 확대 임계값·자료 예산·조회 주기·추가 탐색 가능 범위는 이번에 수치로 정하지 않는다. 7/10km 탐색 정책을 실제 배달 허용 반경으로 바꾸지 않는다.

## 후속 구현에 남길 확인점

기존 r6의 ‘한 가게→관찰 범위→준비된 타일→관련 배달 한 건’ 후보에 **첫 요약 표시→선택한 부분만 추가 조회→축소 복귀**를 인수 흐름으로 결속한다. 권한 없는 상세 거절, 자료 부족, 빠른 선택 변경의 역순 응답, 개인 사본 정리도 함께 확인한다. 구현 경로·명세·판본/hash·검증 상한은 착수 전에 별도로 결속하며 이번 문답만으로 완료 처리하지 않는다.

Graph Map에는 기존 가게·관찰 범위·지역·업무 대상의 선택/조회 연결과 위 제약을 후속 인계 대상으로 남긴다. 원본·생성물·공간 권위·E 증거를 이번에 변경하지 않는다. 새 디오라마 규칙 후보 없음.
