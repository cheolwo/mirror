# 역할 앱 오류 안내·업무 복귀 r1

- 상태: CompletedLocalDeviceValidation / RemainingRoleFindings
- 승인: 2026-10-21 사용자의 서버 통신 검증·전체 역할 앱 조사·예외 다이얼로그와 정상 업무 복귀 요청
- 범위 명세: [작업 지시](role-error-recovery.r1.work-order.json)

## 화면 책임

오류 안내는 ‘무슨 문제가 생겼고 지금 무엇을 해야 하는가’만 설명한다. 기존 화면·원장·초안·업무 상태의 소유권은 각 ViewModel에 둔다. 공통 컴포넌트는 상태/권한/금액을 판단하거나 명령을 재전송하지 않는다.

1. 전체 기존 역할 앱의 서버 주소·오류 표시·미확정 처리·복귀 경로를 대표 소스로 조사한다. 소스 조사와 실제 앱·통신 검증을 구분한다.
2. 공통 조회 오류는 짧은 중립 다이얼로그와 재조회/안전한 업무 복귀를 제공한다. 긴 기술 원문을 제품 화면에 출력하지 않는다. 반복 polling의 같은 오류로 창을 계속 열지 않는다.
3. 완료/신고/입고/결제 응답이 불명확하면 성공·실패를 단정하거나 원장을 떠나도록 자동 이동하지 않는다. 기존 ‘결과 확인’ 절차와 사진/입력·요청 ID를 보존한다.
4. 첫 적용은 공통 업무 상태 컴포넌트의 기술 오류, 화주 상세 Frame, 기사 현재 운송·상하차 조회 실패다. 음식/주문자/판매자/창고/인사/운영자의 나머지 개별 화면은 조사 결과에 적용 여부를 명시한다.
5. 화주 자동 재조회가 성공하면 조회 실패만 지우며 중요한 명령 결과 안내는 유지한다.

## 복귀 원칙

- 일시 연결 실패: 다시 시도는 GET 재조회만 한다.
- 찾을 수 없는 대상: 현재 업무/의뢰 목록으로 사용자가 선택해 이동한다.
- 로그인 필요: 기존 로그인 route와 반환 문맥을 유지한다.
- 명령 미확정: 결과 확인을 우선하고 자동 재전송·강제 복귀를 하지 않는다.
- 창 닫기: 화면 안에 짧은 미완료 상태와 다시 열기 행동을 남긴다. 오류가 사라진 것처럼 표시하지 않는다.

## 검증

공통 정책·렌더/복구 회귀, 소비 client build, 기존 서버 정본·휴대폰 재조회, 실제 오류 창/닫기/재시도/복귀를 검증한다. 필요시 새 로컬 USB 시험 APK를 설치하되 기존 서명·앱 데이터를 유지한다. 새 운영·실수금·FCM·배포·학습·commit/push는 범위가 아니다.
