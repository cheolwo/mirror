## 한 가지 결과

오토바이·다마스의 적재 제원을 기존 관리자 API로 등록할 수 있고, 미확인 제원을 적합 판정으로 오인하지 않는다. 임의 공통 실차 수치와 합성 학습 수치를 초기 운영 자료로 넣지 않는다.

## 구현 경계

1. 소형차 초기 자료는 수치 미확인·추천 비활성 템플릿으로 추가한다. 기존 코드의 실차 값과 활성 여부는 반복 시드에서 보존한다. 기존 1톤 이상 초기 자료·플래그·원장·자격 검사는 유지한다.
2. 기존 관리자 추천 기준 수정 API에 선택적인 적재함 길이·폭·높이·최대 중량을 추가한다. 생략 필드는 보존한다. 잘못된 수치는 변경 전 거절한다. 활성화하려면 양수 길이·폭·최대 중량이 필요하며 소형 밀폐차에는 높이도 필요하다. 운영 권장 중량/CBM은 실제 최대값을 넘을 수 없다.
3. 적재 엔진은 요청된 중량·부피·팔레트·치수 축을 검증할 수 없으면 제외 사유를 반환한다. 입력에서 생략한 모든 축을 새 필수값으로 만들지는 않는다. 중량은 물리 최대값과 운영 권장값 중 작은 값으로 제한한다. 기사 제원 자체가 없으면 적합으로 반환하지 않는다.
4. 공식 조사 출처·대상/시장·판본·확인일·필드별 미확인 상태를 별도 카탈로그에 보존한다. 장비 외형 치수·해외 제원을 국내 공통 적재함 수치로 승격하지 않는다.

## 분담과 검증

- Engine 담당: 순수 적재 판정과 기사 적합성, 관련 회귀 시험.
- Catalog 담당: 추가 전용 시드 카탈로그와 멱등/보존 시험, 공식 출처 대장.
- 통합 담당: 기존 관리자 계약·Command·API의 검증과 영속 시험, 결과 문서.
- 공유 작업 트리의 관련 없는 변경을 보존한다. 담당별 허용 경로는 연결된 작업 명세를 따른다.
- 집중 시험 → 영향 소비자 컴파일 및 Fast → Task. 검증 결과는 별도 변경 기록에 남기며 이 승인 문서의 해시는 구현 도중 수정하지 않는다.

## 완료 기준과 남은 일

- 미완성 템플릿은 활성화 거절·추천 제외, 합성 측정 제원을 등록한 시험에서는 정상 후보 반환.
- 상한 초과 수정은 저장/추적 객체 변경 없이 거절. 반복 시드는 운영 수정값을 보존.
- 실제 모델별 측정·서류 대조, 관리자 화면 편집기, 모바일 상세 입력 일치, 추정 부피/회전/적층의 원장 보존, AI 조합/학습은 별도 후속이다.
