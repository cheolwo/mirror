# 누적 참여·이익 공유 홈 r10

상태: Approved / CompletedLocalValidation / FinancialAggregateAndOtherBusinessCountsPending. 2026-10-22 사용자는 홈 앞에 참여·플랫폼 이익·공유 현황을 두고 역할 진입을 유지하도록 요청했고, 기본 기간은 전체 누적으로 선택했다.

## 구현 범위

홈은 `함께 만든 성과`와 전체 누적 기준을 먼저 표시한다. 플랫폼 확정 이익과 실제 분배 지급액은 기존 원장에서 확정된 공개 집계 근거를 찾지 못했으므로 미집계로 유지한다. 모의 경제성 후보·예정 지급액·거래 총액을 대신 쓰지 않는다.

기존 화물 완료 투영에서 운송 완료 기록 건수와 확인된 참여 화주·기사 계정 수만 서버가 읽기 전용으로 집계한다. 기사 하차 완료 기준이며 화주 수령 확인·정산 완료가 아니다. 연결 의뢰, 모의 수행 여부, 계정 실재와 기사 결속을 대조한다. 확인되지 않은 계정은 추정하지 않고 누락 가능 상태를 보존한다. 계정 수를 합쳐 전체 인원으로 표시하지 않는다. 음식·공간 참여 실적으로 확대하지 않는다.

현재 실행 모드는 집계의 출처 표시이며 개별 기록의 실제 운영·감사 완료 증거가 아니다. Simulation은 시험 집계라고 명시한다. 운영에서도 기록 기준과 회계 확정은 구분한다. 공개 응답에는 숫자·범위·기준 시각·집계 상태만 포함하고 사용자/운송/주문 식별자·연락처·좌표는 포함하지 않는다.

원격 조회와 요약 표시를 분리하며 조회 실패에도 기존 3+4+생활·창고 역할 진입은 즉시 사용할 수 있다. 미집계·실제 0·조회 실패를 구분한다. 거래·개인정보·서비스 안내는 하단에 보존한다.

## 경계와 검증

배차·운임·수행·정산·지급·권한·원장 스키마를 변경하지 않는다. 기존 dirty 작업·r9 기록을 보존하고 커밋·푸시는 하지 않는다. 집계 필터/중복/미확인 계정, 공개 응답의 최소 정보, 실패 시 진입 유지, 소비 client 빌드와 실제 모바일·넓은 화면 렌더를 검증한다. 로컬 합성 검증과 실제 운영 실적은 별도로 기록한다.
