# 주문 원장 중심 퀵 한 건 마감 r70

- 기획 ID: `PLAN-OPERATIONS-DISPATCH-CORE`, 판본 `dispatch-core.r70`, 2026-10-19.
- 상태: `ApprovedInCurrentThread / ReadyToDispatch / LocalImplementationAuthorized / OperationalDisabled`.
- 승인 근거: 사용자가 “그렇게 막는 문제부터 보완”하도록 요청하고, 상위 주문 원장을 중심으로 화주·기사·운영자가 주문 한 건을 처리하는 화면과 흐름을 단계적으로 검증하도록 했다. APK는 Google Drive에 보관하고 GitHub에 다운로드 안내를 연결하는 방향을 수용했다.
- 선행 범위: [r69 마감 집중 방향](dispatch-decision-manual.design.r69.md), [r68 실제 API 검증과 남은 화면 결함](cargo-ai-device-verification.implementation.r68.md). 같은 스레드의 명시적 구현 승인으로 수용하며 다른 작업실의 미승인 변경이나 미답변 정책까지 수용하지 않는다.

## 이번 한 건의 결과

화주가 접수한 주문의 배차 대기·추천·기사 수락·픽업·전달·완료 확인을 같은 주문 식별자로 연결한다. 주문 원장은 업무 이유와 전문 원장 참조를 소유하고, 추천·운송·증빙·정산의 실제 상태는 기존 전문 원장이 소유한다. 주문 원장에 하위 상태를 복제해 새 권위로 만들지 않는다.

1. 추천 시작·만료의 UTC 의미를 응답/공유 계약에서 보존하여 한국 시간대에서도 유효한 추천을 수락할 수 있게 한다. 만료 검사·유효 시간·추천 차수·현재 후보 재검사는 유지한다.
2. 고객 청구액과 기사 보수를 구분한다. 수락 전에는 소형 전용 동결 요금 또는 기존 원의뢰에 결속된 기사 약정액, 수락 후에는 운송 원장의 동결 기사액을 표시한다. 누락·음수·소수·근거 충돌은 임의 계산하지 않는다. 수락 직전 재조회에서 본 보수가 달라지면 확인을 다시 받는다.
3. 동일 주문의 화주·기사·운영자 조회와 다음 행동을 대조한다. 정상 한 건을 끝까지 닫는 데 필요한 기존 경로의 결함만 수정하고 새 역할·요금 체계·학습 정책은 추가하지 않는다.
4. 같은 원장에 대한 서버 HTTP·공통 앱 ViewModel/Razor·저장 결과를 로컬에서 검증한다. 직접 API 수락 성공을 앱 화면 수락 성공으로 대신하지 않는다. 이전 r114 실패와 원본 자료는 보존한다.

## APK 배포 준비

기존 빌드·서명·릴리즈 목록·설치 안내를 우선 재사용한다. Google Drive 사본은 파일 해시·앱 식별자·버전·서명·서버 주소·시험/운영 구분을 남기고 GitHub 안내에서 해당 사본을 가리킨다. 로컬 전용 서버 주소가 들어 있는 APK를 일반 사용자 운영용으로 표시하지 않는다. 현재 업로드 도구·접근 권한·재현 가능한 빌드 확인 전 실제 공유 성공을 보고하지 않는다. 업로드·공유 권한·GitHub 게시·설치·통신·기기 완주는 각각 별도 결과다.

## 검증과 제외

- 회귀: UTC/Local/Unspecified/null·wire JSON→공통 앱·만료 유지·지도 시간, 고객 18,000원/기사 6,200원 분리·보수 누락/충돌·수락 전 변경·수락 후 동결액·기존 소형 표시 보존.
- 소비자: 서버·공유 UI·기존 앱 소비자 컴파일, 집중 시험 후 현재 `validate-changes.ps1` Fast/Task 경로 범위 검증.
- 로컬: 격리 Simulation 호스트/시험 DB, 새로운 시험 주문, 기존 인증·멱등/권한·사진·완료 재조회. 기존 DB/사례를 초기화하지 않는다.
- 별도 관문: 실제 휴대폰·FCM·알림음·GPS·실카메라·ready/migration·외부 서버·실결제/입금·공개 운영. 현재 요청으로 이를 완료/활성화하지 않는다.
- 제외: 배차 가중치·대기 초기화·지원 알림 수신 동의 등 미답변 정책, 모델 가중치 학습, Unity·배달 영상·원본 정리, 기존 코드 삭제, commit/push.

승인된 설계 내용과 hash는 작업지시서에 고정한다. 구현 결과·실패/한계는 별도의 변경 기록과 현재 작업 snapshot에 기록한다.
