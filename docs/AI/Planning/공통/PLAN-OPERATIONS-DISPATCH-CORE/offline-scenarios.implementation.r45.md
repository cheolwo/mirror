## 실행 범위

실제 모델을 시작하지 않는 별도 개발 도구다. 서버 실행 모드나 제품 기능을 추가하지 않는다. 고정 합성 주문 도착표·기사 유입표·가상 시간으로 반복 실행하며, 참여 판단에는 실제 `음식배달수요참여Policy.평가`를 호출한다. Python의 단순 인원 계산을 제품 정책으로 복제하지 않는다.

정책 OFF 가정, 관측 수요 기준, 정확한 미래량을 아는 모의 AI, 과소·과대 예측, 응답 없음·무효·만료를 같은 입력에 비교한다. 정확한 모의 AI는 시험 시간표의 미래를 읽는 상한 비교값이며 실제 예측 성능이 아니다. 오류·무효·만료는 예측을 버리고 관측 기준으로 복귀한다. 이 연결은 도구 내부에만 존재하며 운영 서버에 AI 예측 경로를 활성화하지 않는다.

12개 사례를 시간당 계획 처리량 3·3.5·4건으로 비교한다. 120분 동안 주문을 받고 120분 동안 잔여 업무를 정리한다. 저수요·기사 과잉, 급증·급감, 초기 수행 3건, 수요 0과 장기 대기, 기사 부족, GPS 만료·신규 제안 OFF, 수요 관측 누락·만료, 긴 수행시간을 구분한다.

## 가상 처리의 한계

기사별 실제 이동·주문별 조리·멀티 경로 최적화는 재현하지 않는다. 합성 주문은 FIFO로 대기하고 한 기사에게 최대 3건까지 가상으로 할당하되 **수행 시간은 기사별 순차 누적**한다. 병렬 배송으로 처리량을 부풀리지 않는다. 동일 도착·수행·유입표에서 참여 순서만 비교한다. GPS/OFF 장애는 새 제안의 자격 제한을 가정하며 이미 수락한 업무를 취소하지 않는다. 기사 사고·조리·재조리·취소·수령·Outbox는 새 가상 상태 기계를 만들지 않고 기존 서버 코드 시험을 별도 실행한다.

기사 처리량·대기·배분 편차는 이 가정 아래의 결과다. 실제 수입, 실시간 경로, 실제 서버 부하, 운영 정원 원자성, 실제 AI 정확도·속도, HTTP·DB·APK·알림·입금·운영 안정성을 입증하지 않는다. 음식과 화물 업무를 합치지 않는다.

## 결과와 판정

입력 SHA-256, 정책/계약 소스 SHA-256, 실행 assembly SHA-256, 고정 시계, 정책 판본, 각 실행의 결정적 결과 해시를 남긴다. 입력 사본·전체 결과·보고서는 근거 해시별 폴더에 보존하고 최신 포인터만 갱신한다. 완료·미완료·미배정, 배정 대기 p95/최대, 완료 주문의 접수~가상 수행 종료 p95/최대, 미완료 업무 경과시간, 장기 대기 주문, 기사별 가상 처리량·배차 편차, 보호·승격·대기 권고, 규칙 복귀·자료 만료, 동시 수행 최대와 불변식 위반을 기록한다. 권고 인원을 실제 배차 건수로 세지 않는다.

재실행 결과 일치, 입력 순서에 무관한 정책 판단, 과소 예측·오류·무효·만료의 관측 기준 일치, 부적격 선택 없음, 동시 3건 이하, 기존 적격 활동 보호, 주문 보존을 검사한다. 임계치를 넘긴 결과도 보존하고 성공으로 숨기지 않는다. 모의 배정 대기 10분 이상·모의 완료소요 45분 초과 또는 미완료가 있으면 운영 검토 대상으로 표시한다. 임계값은 탐색용 가정이며 실제 메뉴별 SLA나 자동 취소/운영 설정이 아니다.

Ollama/LLM 실행·차단 해제·권한 완화·대체 추론 실행·모델 HTTP 호출·운영 DB 쓰기·외부 알림·기사 운행 상태 변경·실제 배차·요금/지급·새 UI·Unity·APK·Azure·배포·commit/push는 포함하지 않는다. 모든 외부 효과는 0회이며 서버 수요 참여 기능 기본 OFF를 유지한다.
