# 무료 퀵·화물 등록 준비 보완 r71

- 기획 ID: `PLAN-OPERATIONS-DISPATCH-CORE`, 판본 `registration-readiness.r71`, 2026-10-19.
- 상태: `ApprovedInCurrentThread / CompletedLocalValidation / OperationalDisabled`.
- 승인 근거: 사용자가 등록 준비 감사를 확인한 뒤 “개정법의 등록 기준에 따라서 … 보완을 … 진행”하도록 요청했다. [직전 감사](../../../../Changes/2026-10-19-freight-platform-registration-readiness-audit.md)를 구현 입력으로 수용한다.
- 적용 법령: [법률 제21970호 개정문](https://law.go.kr/LSW/lsRvsDocListP.do?chrClsCd=010202&lsId=001748&lsRvsGubun=all). 2027-09-23 시행과 세부 국토교통부령 위임을 구분한다. 구현이 등록 신청·수리나 법정 적격 확정을 뜻하지 않는다.

## 구현 결과의 책임

1. 기존 기사 ID에 수단별 검토 자료와 실제 차량 내부 참조를 연결한다. 면허·종사자격·운송사업자/소속·차량·보험을 구분하고 자격증 번호·주민번호·원본 사진을 새로 수집하지 않는다.
2. 본인 제출·상태 조회와 기존 서버관리자의 근거 검토·승인/반려/정지·재검토를 연결한다. 자기 승인, 타인 변경, 오래된 판본 덮어쓰기, 공식기관 확인 허위 표시는 거절한다. 이미 승인된 자료도 바뀌면 재검토한다.
3. 신규 화물의 운행 시작·후보 생성·AI 입력·추천 조회·수락 직전 공통 서버 검증을 적용한다. 의존성이 없거나 자격/차량/플랫폼 준비가 불명확한 Operational 실행은 허용하지 않는다. Simulation 예외는 명시적 설정에만 허용하고 승인으로 저장하지 않는다.
4. 이미 수락한 운송의 조회·사진·전달·안전 인계·같은 수락의 결과 재확인은 보존한다. 자격 정지가 기존 업무 삭제나 인계 없는 종료를 뜻하지 않는다.
5. 무료 연결 설정과 요금을 0원으로 일치시키되 과거 원장·유상 기능을 삭제하지 않는다. 플랫폼 등록·사업계획·약관/요금·사무실·법 위반 고지/신고/제한의 준비를 관리자 전용으로 조회한다. 실제 기관 신고를 실행하거나 미확인 절차를 완료 표시하지 않는다.
6. Operational 신규 접수에는 법령상 화물 종류·중량·치수·출도착 입력을 확인한다. 작성 초안과 Simulation의 예시는 구분하고 미확인 치수를 임의 계산하지 않는다.

## 역할별 화면

- 기사: 내 정보에서 자격 상태·필요 자료·재제출 확인. 기존 운행 지도에 서류 입력을 섞지 않는다.
- 관리자: 기사 관리에서 해당 기사 검토, 운영 관리에서 플랫폼 등록 준비 조회. 기존 권한만 사용한다.
- 화주: 기존 화물 입력에서 누락 자료를 확인한다. 새 계약/요금 상품을 추가하지 않는다.

## 수정 범위와 검증

- 허용 범위: 자격 Domain/Contracts/DB 구성·마이그레이션, 해당 UseCase/API, 서버 공통 검증과 기존 운행·배차 진입 연결, 기존 역할 UI/내비게이션, 무료 설정, 관련 시험과 문서.
- 기존 작업 트리 351개 변경은 보존하며 담당별 비중첩 경로를 사용한다. 서버 DI·통합·회귀·최종 기록은 root가 소유한다.
- 검증: 승인/반려/만료/정지/차량 변경·자료 재제출·판본 충돌·권한·정보 최소화, 자격 없는 운행/추천/수락 차단, 명시적 Simulation 예외, 기존 운송/멱등 수락 보존, 소비 client 빌드와 실제 공통 화면 렌더.
- 운영 전용 DB 마이그레이션 적용·외부 인증 조회·기관 등록/신고·FCM·실금융·APK 배포·공개 영업·Unity·영상·commit/push는 이번 범위에서 실행하지 않는다.
