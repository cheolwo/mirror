# 화물 업무 화면 문구 최소화 r1

- 날짜: 2026-10-21
- 상태: `Completed / PhysicalDeviceReadbackVerified`
- 승인: 사용자가 실제 이용자에게 필요한 핵심 단어만 남기고 불필요한 설명을 줄이도록 요청했다.
- 범위: 직전 휴대폰 검증의 기사 현재 운송·상차·하차와 화주 의뢰 상세·진행·증빙·결제 화면. 새로운 업무나 상태는 추가하지 않는다.
- [작업 명세](cargo-concise-ui.r1.work-order.json)

현재 상태·주소·금액·확인 항목·다음 행동을 기본으로 표시한다. 화면 제목과 같은 설명, 정상 조회 알림, GUID/adapter/endpoint 같은 구현 설명과 내부 화면 번호를 제거한다. 필요 없는 문단을 짧은 문단으로 바꾸어 계속 나열하지 않는다. 오류·결과 미확인·재시도·동의·사진 필수·테스트 결제/실입금 구분 등 판단에 필요한 안내는 짧고 정확하게 남긴다.

업무·상태 판정·금액·API·원장·권한·차량·추천·사진 관문·멱등/복구는 보존한다. 실제 증빙이 없는데 확인 완료로 바꾸거나 결제·정산·인수증·배송 완료를 하나로 합치지 않는다. 기존 컴포넌트와 동작을 사용하고 책임 카드는 기존 상세 문서에 반영한다. 사진·확인 정보가 긴 페이지의 스크롤과 기존 주/보조 행동을 유지한다.

검증은 집중 회귀·소비 client 빌드와 실제 호스트의 좁은 화면, 가능하면 기존 USB 단말에서 변경 화면을 확인한다. 기존 완료 주문을 재완료하지 않고 읽기 전용 상태 또는 별도 화면 시나리오로 확인한다. 이전 화면과 새 화면 PNG는 서로 다른 판본으로 보존한다. APK 빌드·설치·실제 화면·서버 업무 완료를 각각 구분한다. 운영 활성화·외부 푸시·금융·모델 학습·commit/push는 포함하지 않는다.

## 완료

[구현·시험·실제 전후 화면](../../../../Changes/2026-10-21-cargo-concise-ui-r1.md)이 결과 정본이다. 정상 조회 알림·구현 문단·반복 설명을 제거하고 핵심 상태·주소·금액·행동, 오류/미확정 결과·필수 사진·동의·테스트 금전 경계를 유지했다. 소비 빌드·집중355개 및 최종 전체 재시험14,139개 통과/16개 미실행을 확인했다. 초기 시간 초과1건·단독 재시험·전체 재시험은 별도 보존했다.

두 시험 APK201을 데이터 보존 업데이트하고 설치 바이트를 재확인했다. 실제 기기에서 기존 완료 운송9의 기사·화주 화면을 조회하고 전후8PNG를 남겼다. 의뢰 번호는 기본 접힘·펼쳐 확인을 검증했다. 새 업무/결제/완료 요청·현장 운송·새 촬영은 실행하지 않았다. 원장/추천차수/동결보수·실제 AI 감사는 그대로이며 이 변경은 모델 학습이나 운영 활성화가 아니다.
