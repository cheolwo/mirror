# [기획 · 월정액 화물 정보추천 운영 방향 · PLAN-OPERATIONS-DISPATCH-CORE · r4]

2026-10-26. `DirectionConfirmed / ReadOnlyPreparationImplemented / LocalServerAndUiValidated / FullConsumerBuildBlocked / LegalApplicabilityOpen / OperationalDisabled`.

사용자는 건별 중개수수료를 받지 않고 월정액 플랫폼 이용료로 정보를 취합하여 실시간으로 추천하는 방향을 선택했다. 기사님은 추천을 수락하거나 거절할 수 있고 계약 당사자가 최종 결정한다. 월 5,000원과 10,000원은 후보이며 하나의 확정 가격이나 두 개의 출시 요금제로 정하지 않았다. 유료 정보 서비스를 계획한다는 뜻이며 무료·무상 사업으로 표시하지 않는다.

이 문서는 최신 요금·추천 운영 방향의 단일 기준이다. [정보 우선 법적 검토 r1](cargo-information-first-legal-review.r1.md), [독립 공고 r2](cargo-information-publication.implementation.r2.md), [지도 중심 고정 활동권역 r3](cargo-map-first-workloop.design.r3.md)는 각각 법령 대조·공고 수명·기사 업무 설계의 근거로 보존한다. 이번 작은 구현은 기존 관리자 등록 준비 조회에 향후 모델을 읽기 전용으로 표시하는 범위다. 실제 청구·입금 처리·요금 설정 변경·추천/계약 전환·배차 활성화는 포함하지 않는다.

## 현재 요금 설정과 향후 계획의 분리

현재 `기사이용료정책Options`의 기본값과 기존 설정은 무료 배차·기본 이용료 0원·월 상한 0원이다. 기존 `월누적이용료계산`은 유료로 설정하면 `min(배차건수 × 기본이용료, 월상한이용료)`를 계산한다. 이는 정액 구독이 아니므로 기본 이용료나 월 상한에 5,000원·10,000원만 넣어 새 모델을 구현했다고 표시하지 않는다.

기존 관리자 준비 조회는 현재 무료 설정의 일치 여부와 향후 월정액 정보추천 계획을 별도로 보여준다. 후보 배열은 두 금액을 유지하고 확정 금액은 `null`로 둔다. 준비 화면의 계획은 청구 정책·납부 완료·회원 이용권·실제 추천 권한이 아니며 기존 정산으로 전달하지 않는다. 무료 설정이라는 사실도 허가 면제나 법적 무상성 판정을 뜻하지 않는다.

계약의 `PlannedInformationSubscription`은 `MonthlyInformationSubscriptionDraft` 모델의 계획 사본이다. 새 준비 항목 코드는 `information-subscription-classification`이며 기존 근거 판정의 기관 확인 경계를 사용한다. `Confirmed` 문자열만이 아니라 유효한 검토 근거와 기관 회신 참조가 있어야 충족된다. 계획과 회신을 읽는 것만으로 추천·계약·청구가 실행되지 않는다.

기존 준비 상태의 `FreeConnectionConfigured`, 등록·주선 허가·요금/약관 신고 상태와 `CanActivateOperations`의 의미는 보존한다. 월정액 후보가 있다는 이유로 실제 등록·유상 주선 적격·청구 허용·운영 활성화를 자동 판정하지 않는다. 새 법적 분류 확인은 기존 준비 근거 기록과 기관 회신 참조를 사용하며 별도 승인 DB나 기관 전송 기능을 만들지 않는다.

## 법령 대조와 확인할 경계

2026-10-26 공식 조문 확인 기준이다. 현행 법 제2조제4호의 유상 운송계약 중개·대리와 제24조의 주선사업 허가를 적용할 때 실제 행위를 확인한다. 월정액 이용료도 서비스의 대가이므로 건별 수수료가 없다는 이유만으로 유상성이 없거나 허가가 불필요하다고 확정하지 않는다. 수락·거절 버튼이나 당사자 직접계약이라는 표기만으로 법적 분류를 끝내지 않는다.

법률 제21970호는 2026-09-22 공포됐으며 플랫폼 등록제 관련 시행 예정일은 2027-09-23이다. 신설 제34조의6의 이용요금 신고와 제34조의7제1항의 건별 중개수수료 제한, 제2항의 무허가 유상 중개 제한을 따로 확인한다. 플랫폼 등록과 주선사업 허가는 서로 대체하지 않는다. 사무실·설비·요금·신고의 세부 수치나 신청 가능 여부는 확정 하위법령과 실제 사업 형태를 대조하며 임의로 만들지 않는다.

## 이번 구현의 정확한 범위

기존 관리자 등록 준비 조회의 계약·Service·공통 화면과 관련 시험을 보완한다. 새 가입/결제 페이지나 요금 편집 화면은 만들지 않는다.

1. 현재 무료 설정과 향후 정액 정보추천 계획을 한 화면에서 혼동하지 않게 표시한다.
2. 월 금액 후보 두 개와 미확정 금액, 건별 수수료 없음, 실시간 추천·기사 수락/거절·당사자 최종 결정이라는 사용자 방향을 읽기 전용으로 전달한다.
3. 유료 정보추천이 주선업에 해당하는지에 대한 법적 분류·기관 회신 확인 항목을 기존 준비 상태에 연결한다. 회신과 검토 근거가 없으면 확인 완료로 승격하지 않는다.
4. 운영·청구·원장·권한·금융 상태를 변경하지 않고 기존 관리자 전용 조회 권한을 보존한다.

[작업 명세](cargo-information-subscription.r4.work-order.json)가 정확한 수정 경로와 제외 범위를 소유한다. 관리자 화면의 표시 보완은 실시간 추천·고정 활동권역·전용 단건 제안·실제 회원 납부를 새로 완성한 결과가 아니다. 해당 후속 구현은 기존 r3 설계와 각 업무 관문을 따른다.

## 검증 상태와 다음 확인

이번 읽기 전용 준비 조회는 구현했고 관련29개·서버 전체16,220개 통과/환경16개 생략, 계약·공통UI·서버 및 별도 소비 호스트 빌드와 390/1280px 실제 공통 화면을 확인했다. 전체 소비 솔루션은 Android 리소스/Java 생성 오류로 실패해 전체 Task와 APK 호환성은 미완료다. [실제 결과와 남은 경계](../../../../Changes/2026-10-26-cargo-information-subscription-r4.md)를 따르며 이전 r2의 시험 수·화면을 이번 검증으로 승계하지 않는다.

실제 청구·입금·자동 갱신·실시간 추천 운영·APK/휴대폰·기관 제출/회신·등록/허가 수리·배포는 미실행이며 운영 활성화는 없다. 다음 확인의 우선순위는 구체적인 추천/계약/대금 흐름을 결속한 서면질의와 기관의 적용 답변이다. 후보 요금 확정과 실제 청구 구현은 그 확인 및 미정 요금 조건을 정리한 뒤 별도로 다룬다.
