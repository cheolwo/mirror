## 먼저 제안하는 분야: 주민 수요 신호

[r94](workflow-operating-decisions.design.r94.md)의 실적 기반 입고 추천은 실제 재고·출고·공급 준비·이용 기간을 다룬다. 여기에 ‘무엇을 원하는가’라는 주민 의견을 구분해 참고하는 기획을 제안한다. 실적 기반 추천 방향을 새 기능으로 다시 확정하거나 AI 실행 권한을 확대하지 않는다.

```text
주민의 관심·입고 희망
└─ 공급업체가 지역별 수요 참고
   └─ 공급 가능 상품·수량·일정 제안
      └─ 공간 제공자와 조건 합의 → 기존 입고 예약·실입고 흐름

실제 구매 주문
└─ 별도의 주문·재고·거래 조건으로 처리
```

관심 표시, 입고 희망, 확정된 구매 주문을 다른 신호로 두는 제안이다. 희망 수량만으로 구매 의무·주문·재고 예약·확정 매출·지급 재원을 만들지 않는다. 업체와 공간 제공자의 자율적인 입고 판단을 유지하며 운영자나 AI가 희망 수량을 강제 입고량으로 바꾸지 않는다.

기존 [생활 교류 r6](exchange-mvp.r6.md)의 제공/필요 글을 먼저 검토할 연결 후보로 둔다. 새 게시판·DB·수요 엔진을 추가하기로 정한 것은 아니다. 주민별 상세 생활정보를 공급업체에 공개하는 범위, 지역 집계·유효 기간·희망 철회·중복 집계·허위/오래된 신호 처리 등은 이 분야를 선택한 뒤 구체화할 미정이다.

[r93](workflow-operating-decisions.design.r93.md)의 공간 이용 종료 전 잔여 물품 회수와 실제 반출 토대는 보존한다. 후보 3의 이동 판단·비용 부담은 그 기능이 이미 있다는 이유로 완료된 기획으로 간주하지 않는다.
