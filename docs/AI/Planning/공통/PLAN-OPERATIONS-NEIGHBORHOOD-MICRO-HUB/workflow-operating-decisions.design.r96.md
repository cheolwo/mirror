## 수용한 방향

입주자가 단지에 보관된 상품을 저렴하게 구매하고, 본인 주문의 물품을 직접 피킹·수령하는 선택을 제공하는 방향을 수용한다. 도매가에 가까운 구매 가격은 지향점이며, 공급업체가 모든 상품의 도매 판매를 승인했거나 실제 도매가·매입 원가가 확인됐다는 뜻은 아니다.

r95의 `resident-goods-visibility-scope`는 `Asked / Unanswered / Preserved`로 유지한다. 이번 답변은 입주자 가격·직접 수령의 추가 방향이며 상품 조회 항목 전체·관계 확인 방법·운영 권한을 일괄 승인한 답변으로 확대하지 않는다.

## 구매·수령 방식의 제안

| 입주자 선택 | 실제 업무 | 가격·보수에서 구분할 항목 |
| --- | --- | --- |
| 직접 피킹·직접 수령 | 허용된 시간·구역에서 본인에게 예약된 상품을 찾아 수량 확인 후 가져감 | 기사 배송은 없으며 생략한 타인 피킹·포장 업무의 비용 반영은 합의로 결정 |
| 준비된 상품 직접 수령 | 작업자가 피킹·필요한 포장을 하고 입주자가 인수 | 수행된 피킹·포장 보수 유지, 기사 배송 비용 없음 |
| 기사 배송 | 합의한 담당자가 피킹·포장하고 기사가 인수·배송 | 실제 수행자별 작업비와 배송비를 구분 |

공간 제공자가 허용한 운영 방식과 상품별 조건 안에서 선택한다. 입주자라는 이유만으로 모든 선반·다른 사람의 예약 상품·사적 출입 구역에 접근하게 하지 않는다. 공간 제공자가 상주 작업자 운영을 선택했다고 자가 피킹을 강제하지 않으며, 진행 중인 작업을 수령 방식 변경만으로 취소하거나 보수를 삭제하지 않는다.

## 입주자 가격을 정하는 제안

첫 방식은 **판매 권한을 가진 공급업체·판매자가 입주자 판매가와 수령 방식별 가격을 직접 정하는 것**이다. 플랫폼은 실제 생략 가능한 작업과 비용을 참고자료로 보여줄 수 있다. 가격은 주문 전에 확인·합의하며 미확인 공급가를 임의로 채우거나 기존 판매가에서 비용을 자동 차감하지 않는다.

```text
공급업체·판매자가 정한 입주자 상품 가격
  + 해당 주문에서 별도로 부담하기로 합의한 서비스 비용
  = 주문 전에 확인할 결제·거래 금액
```

상품 가격에 이미 포함한 비용은 서비스 비용으로 다시 더하지 않는다. 실제 생략한 업무의 비용 절감을 판매가에 어느 만큼 반영할지는 당사자가 정할 사항이다. ‘직접 수령’이라는 이유만으로 입고·보관·공간·재료 등 모든 비용이 사라지는 것으로 계산하지 않는다. 기존의 입고·보관비 부담 주체 질문은 미정으로 보존하며 이 비용을 자동으로 입주자에게 전가하지 않는다.

공급 계약의 비공개 원가·다른 사람의 보수·수익을 주민 화면에 공개할 필요는 없다. 입주자에게는 자신의 상품 가격·추가 서비스 비용·최종 금액을 우선 보여주는 제안이다. 실제 도매가 대비 할인율은 비교 근거가 확보된 경우에만 표시하는 후속 검토 사항이다.

## 주문 원장과 자가 피킹의 연결안

```text
입주자 상품 선택
└─ 가격·직접 수령 조건 확인 → 주문·재고 예약
   └─ 본인 주문과 출고 가능한 상품·수량 확인
      └─ 허용 구역에서 피킹 → 실제 수량·인수 확인
         ├─ 기존 주문에 연결한 출고·재고 차감 결과
         ├─ 본인 수령 결과
         └─ 발생한 판매대금·작업 보수·정산 근거
```

기존 r22/r23 직접 수령은 기사 운송 원장을 만들지 않는 정상 흐름이다. 자가 피킹을 넣기 위해 가짜 배차·배송 완료·기사 보수 원장을 만들지 않는다. 다만 기존 직접 수령 구현만으로 주민의 선반 자가 피킹·출고·재고 차감·실제 인수까지 검증됐다고 표시하지 않는다.

자가 피킹은 기존 선반/상품 코드 입력 토대를 검토하되, 서버가 현재 본인 주문·예약 재고·품목·수량·허용 단계·이미 처리된 요청을 확인하는 후속 설계가 필요하다. 물품을 찾는 피킹, 재고를 반영하는 출고, 본인이 인수한 수령의 의미는 구분한다. 하나의 명확한 제출로 함께 처리할 수 있는 경우에는 불필요한 확인 버튼을 늘리지 않는다. 통신 결과가 불명확하면 같은 요청 결과를 조회해 중복 출고·중복 차감을 막는다. 미수령·수량 부족·다른 상품에는 재확인과 해당 업무의 기존 문제 처리 흐름을 연결한다.

## 활동 보수·원가 배부·기금의 보존

다른 사람이 이미 완료한 입고·보관·피킹·포장 보수는 주민 할인 때문에 없애지 않는다. 입고 작업 보수의 발생과 여러 주문에 대한 원가 배부를 별도로 유지하고 같은 비용을 새 채무로 반복 생성하지 않는다. 구매자가 본인 물품을 피킹했다는 사실만으로 작업자 보수·배달 보수·공동 성과금이 자동 발생하지 않는다. 별도 유상 작업을 맡기는 경우는 구별된 합의가 필요하다.

지역 기금·성과 분배는 기존 합의와 확정된 잔여 재원을 기준으로 검토한다. 입주자 가격을 낮추기 위해 타인의 기본 보수나 이미 귀속된 기금을 임의로 빼지 않는다. 구체 단가·할인·마진·기금 비율과 실제 수익성은 이번 문서에서 확정하지 않았다.
