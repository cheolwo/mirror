# 생활 공간 분산 입고·기사 피킹·다거점 배송 구현 r30

2026-10-08. 상태 `Implemented / LocalValidated / ApkPrepared / DeviceAndOperationalPending`. 사용자의 `Implement the proposed plan.`으로 아래 범위가 승인됐다. 기사 직접 피킹, 최초부터 다거점, 운영자 설정 시간대의 주문 마감·픽업·전달 창을 사용한다. 최신 정정에 따라 전체 피킹 후 전달만 강제하지 않으며, 피킹과 전달을 섞어 예상 총 소요 시간이 작은 유효 순서를 선택한다. 이전 r4의 단일 거점 우선과 전체 피킹 선행은 이번 범위에서 대체한다.

## 데이터와 권위

공공 주소·사가정/면목제3·8동 건물 자료는 `PlaceId / PublicCandidateRef` 후보로 연결한다. 주소 후보가 공간 사용 동의·건물 소유권·실제 출입구를 증명하지 않는다. 기존 창고의 인증 소유자와 지정 관리자 동의를 각각 저장하고 철회하면 신규 입고·예약·피킹을 차단한다. 공간 아래 층·구역·적재 위치 고유 ID와 바코드를 두며 정확한 출입 정보는 권한 있는 업무 조회로만 제공한다.

첫 등록은 기존 창고가 있는 계정만 가능하도록 막지 않는다. 기존 창고의 HR 등록 권한과 분리된 이번 Simulation profile 안에서 본인이 확인한 공간 이름·도로명주소·픽업 좌표로 최소 창고를 등록하고 본인 소유·관리의 동의 대기 거점으로 연결한다. 다른 사람의 소유권·전역 직원 권한을 만들지 않으며, 등록 자체는 법적 소유권이나 현장 검증 완료 인증이 아니다. 공개 주소 자료에서 실제 출입구나 좌표를 자동 추정하지 않는다.

기존 입고상품이 실재고의 기준이다. 기존 입고 원천이 없는 판매자는 본인 상품명·SKU·전체 예정 수량과 소유·판매 확인 근거를 명시해 원천을 등록할 수 있다. 이 선언과 거점별 분할 예정만으로 실재고를 늘리지 않으며 관리자의 실제 수령을 별도 기록한다. 다른 사람의 상품 소유권을 자동 부여하지 않는다. 분할 입고 예정·수령, 상품 소유자/판매자·SKU·lot·적재 위치, 주문 예약과 기존 출고 예정 연결을 기록한다. 새 예약은 조건부 재고 갱신으로 처리하고 이미 예약된 출고 예정은 재예약하지 않는다. RequestId·기대 revision·트랜잭션·수량별 피킹/전달/반납 영수증으로 반복 요청과 응답 유실을 보호한다. 주문 취소는 미피킹 예약 해제와 이미 인수한 물품의 반납 대기를 구별한다.

기사는 기존 화물 의뢰·배차 수락을 소비한다. 배차 수락 뒤 해당 순회·거점·위치·예약·시간에만 유효한 피킹 접근을 얻으며 전역 창고 인사 권한을 주지 않는다. 여러 화물 수락 중 일부 실패는 미완료 상태로 재조회·복구한다. 새 운임·결제·실지급이나 음식 배달과의 통합은 만들지 않는다.

## 배송 순서

같은 장소의 현재 피킹 가능한 물품은 방문 한 번으로 묶는다. 각 주문에 필요한 예약 물품을 모두 인수하기 전에는 해당 고객에게 전달할 수 없다. 기존 경로 자료·시간창·적재 제한을 소비하고 이동+대기+피킹/스캔+전달 시간을 비교한다. 총 예상 소요 시간을 우선하고 거리를 다음 기준으로 삼으며 선택한 정차 순서·근거·판본을 저장한다. 제한된 후보 탐색 결과를 전역 최적해로 표현하지 않는다. 완료 전 재계획은 기존 인수·전달 사실을 보존한다.

기존 역할 선택·지도 작업공간·세션을 재사용한다. 공간동의/재고입고/내주문/현재순회/운영시간대는 각 독립 화면에 둔다. 서버의 허용 행동을 기준으로 버튼을 제공하고 명령 ACK 뒤 동일 원장을 재조회한다. 결과 불명확한 요청 ID를 새 명령으로 덮어쓰지 않는다. 지도와 접는 카드는 기존 r34 기준을 유지한다.

사용자의 최신 정정 `지금은 유니티 쪽 건드리지 말고 모바일 앱이랑 서버 쪽에서 ... 가능하도록`에 따라 Unity 코드를 이번 구현 범위에서 제외한다. 이번 작업에서 신규 작성한 Unity 소스와 메타만 회수하고 기존 Unity 변경은 보존한다. 기존 공개 도로명·건물번호 자료는 서버 공간등록의 선택 후보를 위한 읽기 자료로만 재사용한다. 공간의 상세주소·연락처·사용자 ID·바코드는 공개 표시 자료에 넣지 않는다.
