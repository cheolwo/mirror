## 수용한 방향과 법 적용 판단의 구분

- 이전 질문 의미 ID: `worker-contribution-consent-and-before-acceptance-display`
- 이전 상태: r98의 `Asked / Unanswered`
- 현재 상태: `Answered / UpfrontFixedWorkFeeAccepted`

운영비·공동주택 기여분을 미리 고려하여 **작업자에게 지급할 건별 피킹료·포장료를 업무 수락 전에 산정·제시하고, 작업자가 그 조건을 보고 수락하는 방향**을 수용한다. 주 화면은 해당 작업의 범위·수량·기한·보수와 다음 행동을 우선 보여준다. 사용자가 의도한 계약 형태는 건별 프리랜서 용역이며 실제 법적 지위를 이번 기획으로 확정하지 않는다.

사용자의 ‘프리랜서이므로 근로기준법·최저임금을 무시해도 된다’는 법 적용 판단은 정책으로 수용하지 않는다. 계약 명칭·건별 지급·수락 동의만으로 근로자 여부나 적용 의무를 일괄 제외할 수 없다. 가격 제시 방식의 수용과 특정 사업의 합법성·근로자성 판정은 별개다.

r98의 개인 보수를 먼저 발생시키고 일부를 기여하는 제안과 이번 **업무 총예산을 먼저 나누어 제안 보수를 정하는 안**을 구분한다. 이전 판본은 이력으로 보존한다. 이미 개인에게 약속한 보수의 이름을 총예산으로 바꿔 소급 감액하는 안이 아니다.

## 가격 산정과 표시의 제안

```text
사전 합의한 업무 총예산
├─ 확인된 운영비 배정
├─ 해당 단지 공동기여금 배정
└─ 작업자에게 제안할 피킹료·포장료
   └─ 작업자가 조건 확인·수락 → 해당 약정 보수 확정
```

이것은 새 약정의 예산 구성 제안이다. 운영비의 실제 항목·지급자·단지 기여금의 기준액·5%/10% 중 적용 비율·각 수령자는 아직 미정이다. 보수 구성에 필요한 값이 없으면 이를 0으로 채워 확정 견적을 만들지 않는다. 매출·상품대금 전체를 자동 업무 예산으로 사용하지 않는다.

기여율만 반영하는 산술 예로 업무 총예산 10,000원에 단지 배정 500원과 제안 보수 9,500원을 구성할 수 있다. 10% 예는 단지 배정 1,000원과 제안 보수 9,000원이다. 이 예에는 추가 운영비·세금·보험 등의 금액을 포함하지 않았으며 실제 적용 단가·세후 수령액·실제 지급을 뜻하지 않는다. 예산 10,000원이 이미 개인에게 약정된 보수라면 이 예를 적용해 다시 나누지 않는다.

주 업무 화면에는 ‘이 작업 보수 ○원(세전)’을 우선 제시하는 안이다. 합의에 필요한 공동기여 조건과 상세 산정 근거는 수락 전에 확인 가능해야 한다. 단지 기여금의 존재나 비용 부담 주체를 감추거나 실제 공제를 운영비라는 이름으로만 바꿔 표시하지 않는다. 법정 세금·보험 공제와 단지 기여 배정은 구분한다.

수락 시 제안 금액·범위·수량·단가·비용 포함 관계·기한·완료 증빙·지급 조건과 정책 판본을 연결한다. 나중에 운영비나 기여율이 바뀌어도 수락된 작업의 보수를 조용히 다시 계산하지 않는다. 범위가 늘거나 조건 변경이 필요하면 기존 약정과 구별된 추가 협의·보수 근거로 처리하는 후속 설계가 필요하다.

## 원장과 관리비 경로

원주문·입고 Lot·실제 작업 근거에 개인 작업 보수, 운영비, 단지 기여 배정의 항목·부담자·수령자·적용 판본을 구분해 연결하는 안이다. 기존 전문 원장의 완료·보수 발생·확인·지급 조건은 보존한다. 예산의 합계와 수령자별 배정 합계를 대조하고 개인 작업 보수는 한 번만 발생시킨다.

별도 예산으로 배정된 단지 기여금은 실제 개인 보수에서 납부된 기여금과 구분한다. 배정 예정·확정 채무·실제 납부·단지 수령·관리주체의 관리비 반영은 각각 기록한다. 기여율 계산만으로 단지 현금이 입금됐다고 표시하지 않는다. 같은 돈을 운영비·공동기여금·지역 기금·성과금으로 중복 배분하지 않는다.

r97의 개인 보수로 본인 관리비를 납부하는 선택과 단지 공동재원으로 전체 관리비를 지원하는 두 경로를 유지한다. 본인 보수 사용, 단지 운영 수익과 관리규약·관리주체의 실제 반영은 계속 별도다. r61의 플랫폼 잔여금 보유율과 단지 기여율도 합치지 않는다.

## 공식 근거와 아직 확인하지 않은 운영 실질

2026-10-15 다음 공식 자료를 확인했다. 단지·플랫폼·개별 계약의 실제 운영에 관한 근로자성 판단이나 법률 의견을 완료한 것은 아니다.

- [대법원 2023. 8. 31. 선고 2023도6323](https://www.law.go.kr/LSW/precInfoP.do?precSeq=238955): 근로제공의 실질과 지휘·감독, 시간·장소 구속, 독립 사업 가능성, 위험 부담, 보수 성격, 계속·전속성 등을 종합해 판단한다. ‘프리랜서’ 표시나 거절 기능 한 가지가 법 적용 제외를 보장하지 않는 근거다.
- [고용노동부 2026-01-20 근로감독 발표](https://www.moel.go.kr/news/enews/report/enewsView.do?news_seq=18868): 프리랜서 업무위탁계약에서도 실제 운영의 지휘·감독 등을 확인해 근로자로 인정한 사례와 개별 사실관계에 따라 판단이 달라진 사례를 설명한다. 방송업 사례를 본 물류 운영의 자동 판정으로 확대하지 않는다.
- [최저임금법 제3조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0003&lsiSeq=218303&urlMode=lsScJoRltInfoR)·[제6조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0006&lsiSeq=218303&urlMode=lsScJoRltInfoR): 적용 대상 근로자에게는 최저임금 지급 의무가 있으며 그에 미달하는 약정 부분은 무효다. 법정 적용·예외를 확인해야 하며 사전 동의가 법정 기준 미달을 유효하게 바꾸지는 않는다.
- [근로기준법 제47조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0047&lsiSeq=285279&urlMode=lsScJoRltInfoR): 도급 등 제도로 사용하는 근로자에게도 근로시간에 따른 일정 임금 보장 규정이 있다. 건별 지급과 근로자성이 양립하지 않는다고 단정할 수 없는 근거이며, 본 업무에 적용되는 구체 범위는 미확인이다.

따라서 제안은 자율적인 건별 업무와 사전 보수 확인을 지원하되 실제 관계에 적용되는 보호·지급 규정을 보존하는 방향이다. 법 적용을 피하기 위한 표현 변경이나 근로관계를 독립 용역으로 자동 분류하는 옵션을 만드는 기획이 아니다. 실제 관계가 근로관계이면 해당 임금 지급·최저 기준 등을 반영해야 한다.
