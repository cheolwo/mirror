## 수용한 구현 결정

기존 Site·Location·Agreement·Plan·Line·Lot와 요청 영수증을 재사용한다. 공간 수용 정책, Lot에 결속된 협의/입고 예약, 보관 합의의 미확정 변경 조건을 nullable JSON으로 확장한다. null은 과거 흐름을 보존하며 기존 명령 JSON에 기본값 필드를 추가해 과거 영수증 해시를 바꾸지 않는다. 과거 원장/수령/정산을 소급 변경하지 않는다.

공간 소유자만 허용/거부 품목과 식품·포장·온도·같은 단위의 공간 전체 용량을 설정한다. 농가/공장 등 공급자 유형은 소개이며 상품 분류와 동의 권한을 대신하지 않는다. 분류·식품 여부·수용 단위/상품당 점유량·선택한 중량/부피 제한의 근거가 불명확하면 승인을 보류한다. 다른 소유자의 실보관량과 확정 미수령 물량을 합산하고 Site revision과 Serializable 명령으로 중복 용량 확정을 막는다. 이미 보관된 물품의 조건/점유량을 추정하지 않는다.

정책 설정 공간의 공급자는 기존 입고 초안을 만든 뒤 행별 상품 특성·희망 수량·도착 시간창·보관 기간·기존 보관 합의/판본·공급/위탁 책임·비용 또는 무상·회수 조건을 제안한다. 물품 소유자와 공간 소유자가 같은 제안 판본에 명시적으로 동의해야 예약을 확정한다. 위탁 판매자의 제안 권한은 물품 소유자 대신 동의하는 권한이 아니다. 대화 메모/수정 제안·거절·취소·재협의를 기존 행에 결속하고, 메모나 읽음은 동의로 해석하지 않는다.

계약의 유효 조건과 미확정 변경 조건을 분리한다. 변경 제안만으로 현 계약을 Draft로 바꾸지 않으며 새 판본에 양측 동의한 뒤 적용한다. 예약이 참조한 계약이나 공간 정책이 달라졌으면 수령 전에 현재 조건을 다시 확인한다. 승인된 범위를 임의 확대하지 않는다. 계약 철회/만료는 기존 물품과 진행 배송의 책임을 지우지 않는다.

기존 사진/바코드/실수량/관리 권한 검사는 유지한다. 수용 정책이 설정된 공간은 유효한 예약이 없으면 Receive·Import 등 다른 경로로 수령을 우회할 수 없다. 승인된 입고의 부분 수령만 실제 재고/작업 근거로 확정하며 미수령 예약을 보수 발생이나 원가로 만들지 않는다. 수령 이후 취소는 실물을 지우지 않으며 차이/반송 협의가 필요하다. 공급자 반송 완료를 기존 배송 취소 반환과 동일하게 표시하지 않는다.

r60/r61 입고·보관/출고·배송 약정과 원가 귀속을 재사용한다. 비용의 확인·채무 발생·고객 수령·성과금·실제 지급은 구분하고 이번 계약/승인이 자동 지급을 실행하지 않는다.

## 화면 책임

- 내 공간 수용 조건: 해당 공간에서 받을 수 있는 상품/용량/시간을 설정한다. 계약·검수와 입력 수명을 분리한다.
- 입고 협의 상세: 선택 행의 현재 제안/판본·다음 담당·대기 이유·수락/거절/수정·협의 기록을 확인한다. 다른 소유자의 계약/상세 재고는 노출하지 않는다.
- 보관 조건: 현재 계약과 변경안을 별개로 표시하며 본인의 해당 판본 동의만 수행한다.
- 입고 검수: 유효 예약이 있는 현재 행만 기존 사진·실수량 절차로 처리한다. 실패/불명확 응답은 입력·요청 번호를 유지하고 영수증/정본을 재조회한다.

기존 지도 중심 역할 화면과 단계 선택을 유지한다. 별도 앱이나 Unity·운영 공개 화면을 새로 만들지 않는다. 설명·상태·버튼은 한국어로 표시한다.

## 검증과 완료 상한

새 순수 정책의 농산물 거부/공산품 허용/식품·분류 미확인, 실제 SQLite UseCase의 양측 동의·판본/권한·거절/취소/부분 수령·계약 변경·만료·재전송·공간 전체 용량 경합·사진 입고 선행 관문·기존 초안 호환, 정산 원가 연결과 UI 렌더/상태 행동을 검증한다. nullable DB 확장·암호화·snapshot을 대조하고 기존 소비 프로젝트 빌드 및 Fast/Task 검증을 수행한다.

기능 기본 OFF·기존 Simulation profile을 유지한다. 실제 MySQL/Mongo 공유 DB 적용·휴대폰/카메라·Azure·실제 계약·공급자 출하·외부 알림/지급·commit/push는 별도다. 실제 공급자·공간·비용 데이터는 임의로 만들지 않고 시험에서는 명시적 합성 자료를 사용한다. 상세 실행 결과와 제한은 작업 명세·변경 기록에 반환한다.
