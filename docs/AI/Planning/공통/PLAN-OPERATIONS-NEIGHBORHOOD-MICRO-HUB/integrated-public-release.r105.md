# 전체 역할 통합 공개 r105

2026-10-16 승인, 2026-10-17 로컬 검증. `Approved / LocalPreparationVerified / ExternalReleasePending / OperationalDisabled`.

사용자는 음식·퀵·화물·공간·현장 작업을 함께 준비해 공개하는 계획을 승인했다. 퀵만 먼저 공개하는 직전 방향을 대체한다. 현재 소스·시험 결과·외부 운영을 구분하고 미완료 항목을 다른 역할의 통과로 대신하지 않는다.

## 확정 범위

- 웹과 통합 Android 앱 중심. 기존 음식/화물 기사 전용 앱은 선택 설치를 유지한다. 운영자 웹과 인력 관리자 PC 조회를 재사용하며 별도 앱을 삭제하지 않는다.
- 정상 업무는 서버와 당사자 합의, 미해결 신고·금전·안전 사건만 비상 담당자 검토. 기존 관리자/신고 보류 권한을 지우지 않는다.
- 서버 24시간, 실제 작업 가능 시간은 참여자가 설정. 지역 제한 없이 준비하되 기사·공간·수용량 없이 즉시 수행을 보장하지 않는다.
- 상품·음식 대금은 당사자 직접 거래. 배송·피킹·포장 등 합의된 서비스 비용부터 플랫폼 수납·주간 지급을 준비한다.
- 한국 시간 수요일 00시~다음 수요일 00시 미만의 완료 실적을 목요일 09시 지급 예정으로 묶는다. 지급업체 계약·수령자 자격·실가용 재원·은행 영업일·공급자 최종 결과를 확인하기 전 실송금하지 않는다.
- 월 예산 500,000원은 부하·저장·전송·백업 측정의 한도이며 현재 클라우드 견적이나 무제한 운영 보장이 아니다.
- Unity·해외 업무·새 인사급여 기능은 포함하지 않는다.

## 공통 업무 트리

```text
등록/요청
├─ 직접 거래: 조건 합의 → 당사자 이행·확인 (상품대금은 외부 직접 거래)
└─ 유상 서비스: 조건·보수 합의 → 확인된 수납/재원
   ├─ 음식: 음식점 수락 → 유효 기사 배정 → 조리 → 준비 → 픽업 → 전달
   ├─ 퀵/화물: 추천 → 수락 → 상차 증빙 → 운송 → 하차 증빙 → 전달
   └─ 공간/작업: 공간 동의 → 입고/검수/적재 → 피킹/포장 → 인계 → 전달
      ↓
   작업 증빙 + 지급 재원 + 미해결 신고 없음
   → 기존 보수 채무 → 완료 주별 명세 → 지급 요청 → 공급자 최종 지급 확인

예외
├─ 일반 일정/수량/비용 변경: 같은 판본에 당사자 동의 → 전문 업무 명령
├─ 물품 보유 중 중단: 보유자 유지 → 반송/재전달 합의 → 실물 인계 확인
└─ 신고/피해/금전 충돌: 관련 정산 보류 → 비상 담당 검토 → 전문 후속 → 실제 결과 확인
```

기사 전달, 주문자 수령, 정산 확정, 실제 지급, 지원 사건 종결은 각각 별개다. 주문 원장은 업무 이유와 전문 원장 참조만 소유한다. 입고 보수 발생과 판매 주문별 원가 배부도 분리한다.

## 구현·검증 순서

1. 최근 미검증 UI를 소비 앱과 함께 빌드·시험하고 오류를 고친다. 입력·포커스·필터·계정 전환의 실제 루프백 렌더를 남긴다.
2. 역할 간 인계 공백을 전문 원장에서 세로 구현한다. 기존 RequestId/ExpectedRevision/동결 근거/권한을 재사용하고 불확실한 POST는 재조회한다.
3. 자동 명세 준비는 서버 내부 포트에만 둔다. 기존 관리자 HTTP API는 관리자 권한 유지. 옵션·업무 기능·Operational을 실행 직전에 검사하며 기본 OFF다. 새 채무·승인·송금·자동 보류 해제를 만들지 않는다.
4. Azure VM Compose 단일 app 인스턴스의 통합 준비 profile을 만든다. 운영/시험 DB·키·볼륨·증빙을 분리한다. 19~23시 자동 종료를 상시 운영 profile에 적용하지 않는다. 다중 인스턴스/슬롯의 동시 배경 작업은 별도 영속 lease 검증 전 금지다.
5. 같은 서버·앱 판본으로 정상·취소·반송·신고·부족·업로드 실패·재접속·중복·서버 재시작을 검증한다. HTTPS/실기기/수납/지급/독립 복구는 로컬 시험과 다른 증거다.
6. 모든 필수 항목이 현재 공개 후보 소스·APK·서버 이미지·설정과 결속된 후 함께 공개한다. 준비 안내를 운영 중 광고로 바꾸는 것도 이 관문 이후다.

통합 소개는 `/services`, 기존 `/quick`은 호환 별칭이다. 미검증 APK URL, 허구 후기/통계, 전국 즉시 배차, 실제 입금 보장을 넣지 않는다.

## 외부 완료 조건

- Toss 서비스 비용 수납·기사/작업자 지급 계약과 수령자 등록 자격, 운영 키, 실제 정산 잔액을 확인한다. PG 승인/가상계좌 발급을 가용 지급 재원으로 오인하지 않는다.
- 은행 영업일 달력, 지급 멱등 키, 요청 유실 재조회, 웹훅·최종 결과 대조를 완료한다. 현재 준비 전용 Gateway는 Operational 송금을 차단한다.
- Release 서명·같은 package 업데이트·실제 HTTPS 다운로드 hash·휴대폰 독립 통신·배경 알림/청취를 검증한다. 통합앱 일반 회원 push 설정은 아직 미연결이며 서버 알림함 조회로 push 검증을 대신하지 않는다.
- 비공개 사진 접근과 권한 만료, 데이터 보존/파기, 관리자 최소 권한과 미성년자 정책 OFF를 확인한다.
- VM 밖 암호화 백업을 독립 환경에 복원하고 보호 데이터·주문/하위 원장·Outbox·사진·중복 지급 방지를 확인한다. 이미지 롤백은 DB 복구가 아니다.
