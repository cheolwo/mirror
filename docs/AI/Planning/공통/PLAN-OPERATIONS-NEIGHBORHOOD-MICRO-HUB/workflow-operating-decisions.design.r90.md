- 사용자 요청 원문: **“이렇게 하고 뭔가 지도상에 빈 공간이 있으면은 입구 업체가 그런 건물 관련한 공간들을 지도로서 살펴보면서 어디다가 입구를 할지 그냥 거기 그냥 각각의 업체가 결정을 할 수 있도록 이렇게 했으면 좋겠다라는 생각이 존재하네. 그렇게 하긴 하는데 건물주분들의 입장에서는 뭐랄까 수익성이 있는 그런 물품을 입구를 시킬 수도 있긴 한데 내가 보기에는 약간은 그래도 공동분배 기억은 있어가지고 이게 너무 이렇게 차등화를 해가지고 해서 다툼이 크게 생기지 않도록 좀 조정을 할 필요가 있겠다라는 생각이 있어.”**

## 수용한 방향

업체가 지도로 제공 가능한 공간을 살펴보고 입고할 장소를 스스로 선택하는 방향을 수용한다. 공간 제공자의 수익 관심도 고려하면서 공동분배를 활용해 과도한 차등과 갈등을 줄이려는 목적도 수용한다. 구체적인 공동 재원 범위·출연 비율·수익 차이 상한이나 입고 자동 배분 정책은 아직 정하지 않는다.

## 지도 선택에서 입고까지

```text
공간 제공자가 공개에 동의한 공간·수용 조건 등록
└─ 업체: 지도에서 입고일·상품 조건에 맞는 공간 탐색
   └─ 공간 선택 → 입고 품목·수량·기간·조건 제안
      └─ 공간 제공자와 협의·같은 조건 판본 동의
         └─ 입고 예약 → 순회 납품 → 실수량·사진 확인
```

‘빈 공간’은 등록자가 제공에 동의한 공간의 확인 가능한 수용 여력으로 해석한다. 지도나 공개 건물 정보만으로 사적 공간이 비어 있거나 입고에 동의했다고 추정하지 않는다. r88의 실제 제공 규모·보관 조건·제공 업무와 r89의 입고 일정을 함께 비교한다. 지도 선택은 입고 협의의 시작이며 공간 제공자의 동의·유효 예약을 대신하지 않는다.

지도 기본 카드에는 대략적 위치·규모·잔여 용량/단위·취급 가능 조건·입고 가능한 시간·제공 업무·확인 가능한 약정 조건을 제시하는 안이다. 정밀 사적 위치·출입 방법은 승인된 담당자에게 필요한 범위로 제공한다. 다른 업체의 계약 금액·개별 수익·상세 재고를 비교용으로 일괄 공개하지 않는다.

## 기본 보수와 공동 성과금의 구분

| 구분 | 제안 방향 |
| --- | --- |
| 기본 보수 | 실제 제공 공간·보관·입고·피킹·포장·배송에 대해 합의한 대가를 각 업무 근거로 보존한다. |
| 주문별 공동 성과금 | r59/r61의 비용·예비금 반영 후 잔여금과 확인된 주문별 기여, 사전 합의 비율을 재사용한다. |
| 여러 공간 간 공동분배 | 사용자 목적에 맞는 확장 후보다. 참여 범위·기간·모을 잔여금·배분 기준을 별도로 합의한 뒤 설계한다. |

r59의 현재 공동 성과금은 원주문의 확인된 참여자·완료 수량과 사전 합의 활동 가중치로 계산한다. r61은 입고·보관 비용의 주문별 귀속과 플랫폼 몫·참여자 풀을 구분한다. 따라서 기존 주문별 성과금을 그대로 이용하는 것만으로 공간들 사이의 수익 차이가 완화됐다고 보고하지 않는다. 공간 제공·보관 수량×기간을 주문별 기여로 연결하는 부분도 근거가 불충분하면 보류하는 기존 한계를 유지한다.

여러 공간 공동분배를 선택한다면 기본 보수·상품대금·타인에게 지급할 채무를 임의로 합치는 대신, 사전에 참여 동의한 범위의 확정 잔여금 중 약정 부분을 연결하는 안이다. 실제 재원 확인과 계산 근거를 보존하고, 주문별 이미 배분한 금액을 기간 재원에 다시 넣어 이중 분배하지 않는다. 특정 비율·플랫폼 선지급·모든 공간의 동일 수익 보장은 확정하지 않는다.

공간 제공자는 상품의 수익성뿐 아니라 실제 보관 조건·업무 부담·기간·기본 대가·성과금 조건을 보고 수락하거나 수정 협의할 수 있도록 제안한다. 공동분배 조건은 계약 전에 비교하고 같은 판본에 동의한다. 기존 계약의 보수나 성과금을 사후에 임의로 줄이지 않는다. 업체의 선택과 공간 제공자의 수락을 유지하며, 강제 배정·숨은 순위 조정·수익 상한을 이번 요청에서 임의 도입하지 않는다.
