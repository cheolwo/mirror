## 수용한 답변과 방향

실제 출고 속도·남은 재고·공간 이용 기간을 보고 다음 입고량을 추천하는 방향을 수용했다. 점수·예측 기간·자료 충분성·학습 방법·자동 실행은 아직 미정이다.

공동주택 입주자 등 해당 공간의 관계자가 어떤 상품이 입고되는지 볼 수 있게 하고, 공간 제공자가 상황에 맞는 운영 방식을 선택하는 방향을 수용한다. 외부 기사가 직접 피킹·출고하거나 상주 작업자가 건별 피킹·포장 보수를 받고 준비한 뒤 기사에게 인계하는 형태를 함께 고려한다. 별도 스캐너 구매를 첫 이용의 전제로 두지 않고 휴대폰 스캔을 작업 처리에 연결하는 토대를 재사용·보완하는 기획이다.

## 운영 방식의 선택안

| 방식 | 실제 업무 흐름 | 보수·책임의 구분 |
| --- | --- | --- |
| 기사 직접 작업 | 합의·배정된 기사가 선반에서 피킹하고 필요한 포장·출고 후 배송 | 실제 맡은 피킹/포장과 배송 실적을 분리하여 약정에 연결 |
| 상주 작업자 운영 | 담당 작업자가 피킹·포장 → 기사가 준비된 포장물을 인수·배송 | 작업자의 피킹/포장비와 기사의 픽업·배송비를 구분 |
| 혼합 운영 | 상품·시간대·가능 인력에 따라 위 방식을 선택 | 각 주문·단계의 담당을 명확히 하고 중복 처리·보수 발생 방지 |

이는 선택 가능한 운영 방식의 제안이며 구체 동작·기본값은 후속 설계 대상이다. 공간 제공자는 보관 공간만 제공하고 작업을 다른 담당자에게 맡길 수도 있다. 선택만으로 기사·작업자에게 동의하지 않은 업무를 강제하지 않는다. 이미 진행 중인 주문의 담당·약정·보수를 운영 방식 설정 변경만으로 바꾸지 않는다.

개별 공간의 제공자와 공동주택 공용 공간의 운영 조건을 정할 권한이 있는 주체는 구분한다. 입주자라는 사실만으로 공용 공간 전체를 등록·관리할 권한을 부여하지 않는다. 이는 업무 권한을 설계할 구분이며 실제 소유권·법적 관리권한을 이번 문서로 검증한 것은 아니다.

## 관계자에게 보이는 정보의 제안

```text
해당 단지·공간의 열람 관계가 확인된 이용자
├─ 입고 예정: 공개된 상품·예정일·예정 상태
└─ 현재 이용 가능: 공개된 판매 상품·가격·주문 가능 수량

작업 담당자·배정 기사
└─ 본인이 맡은 상품·위치·수량·수행 단계·필요한 출입 정보

공간/상품 운영 담당자
└─ 권한 있는 계약·입고 예약·재고·작업·보수 근거
```

입고 예정량과 실제 주문 가능 재고는 구분한다. 상품이 입고됐다는 사실만으로 공간 제공자나 모든 입주자가 그 상품을 판매할 권한을 얻는 것은 아니다. 판매 권한이 있는 당사자가 공개한 판매 정보와 재고 조건을 연결하는 안이다.

입주자 열람은 해당 공간·단지 관계와 공개 동의 범위에 한정하는 제안이다. 근처 GPS·주소를 안다는 이유만으로 관계를 자동 인증하지 않는다. 입고 원장 전체·공급 계약 금액·타인의 수익/정산·고객 상세정보·사적 출입 방법은 일반 상품 열람과 분리한다. 정확한 관계 확인 수단과 조회 범위는 아직 정하지 않았다.

## 휴대폰 스캔 토대와 현재 확인 범위

r53의 기존 문서는 합성 선반 QR/Code128을 카메라로 인식해 입력을 돕는 표본을 기록한다. 사용자 상품·수량 확인은 별도이며 실제 Android 촬영·APK 결속은 당시 완료 범위에 포함하지 않았다. r58은 담당 기사·현재 배정·포장·전표 판본을 검사하여 QR 문자열/번호 제출로 인수를 처리하는 소프트웨어 연결이다. 이를 모든 운영 방식의 실제 휴대폰 스캔·출고 완료 증거로 확대하지 않는다.

재사용할 절차는 현재 맡은 업무 열기 → 해당 선반/상품 또는 포장물 코드 입력 → 서버의 주문·상품·수량·상태·담당 검증 → 필요한 수량/사진 확인·처리 결과 기록이다. 선반에서 상품을 모으는 **피킹**과 준비된 상품을 기사에게 넘기는 **픽업**을 같은 코드·행동으로 합치지 않는다. 유효 포장 전표 제출로 인수 의사가 명확한 기존 흐름에는 불필요한 중복 확인 버튼을 임의로 추가하지 않는다.

오인식·다른 상품/선반·권한 거절·카메라 미지원에는 재확인·재스캔·허용된 직접 입력으로 이어가는 안이다. 통신 결과가 불명확하면 같은 요청의 결과를 먼저 조회하고 성공으로 가정하거나 중복 출고하지 않는다. 사진 증빙이 필요한 업무는 기존 증빙 관문을 유지하며 스캔 한 번이 배송 완료·고객 수령·실제 지급 완료까지 뜻하지 않는다.

전용 스캐너·프린터·포장재 관리의 확대는 실제 운영 규모에 맞춘 선택 후보로 둔다. 모든 상품의 실바코드 확보·장치 지원·실물 포장 준비·휴대폰 설치 시험을 완료했다고 표시하지 않는다. 이번에는 기존 문서의 범위를 대조했으며 새 코드·브라우저·카메라·기기 시험은 실행하지 않았다.
