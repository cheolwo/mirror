## 수용한 방향

초기에는 혼잡한 도심부 진입·대규모 물류 처리보다 **중랑구 등 서울 외곽의 제공 가능한 공간부터 단계적으로 시작**한다. 소음·민원·상하차 어려움과 플랫폼의 큰 시설 자본 부담을 줄이려는 목적이다. 도심부 확장은 후순위로 두며 서울 전체의 동시 운영을 첫 목표로 삼지 않는다.

사용자의 ‘도심’은 혼잡한 도심부의 운영 여건에 대한 표현으로 보존한다. r91의 공식 도심권 3개 구와 모든 혼잡 지역을 동일시하거나 그 권역 기금 노드를 삭제하는 뜻으로 확대하지 않는다. 중랑구 전체가 조용하고 저렴한 물류 입지라는 판정도 아니다.

저렴한 공간·활용 가능한 빈집은 사용자가 원하는 후보 조건이다. 공개 검색에서 과거 [공식 빈집 실태조사 붙임 자료](https://ms.smc.seoul.kr/record/appendixDownload.do?key=1d4124eabc9a390a88f4c6ed3ba145c00afcfa88fe1d925724ea6f4befc85a8c062f887a492eec56)를 찾았지만, 최신 중랑구 빈집 수·현재 임대료·제공 의사나 물류 적합성을 확인한 것은 아니다. 2026-10-15 검색 결과를 현재 이용 가능한 공간 목록으로 승격하지 않으며 과거 수치를 최신 현황으로 쓰지 않는다.

## 초기 전개의 제안

```text
장기 구조: 서울 → 강북/강남 묶음 → 5권역 → 자치구 → 참여 공간
└─ 초기 시범 후보: 동북권의 중랑구
   └─ 제공 동의·실제 여건이 확인된 소수 공간
      └─ 소수 공급업체·적은 품목/물량의 일정 협의
         └─ 상품 준비·순회 입고
            └─ 실제 수령·재고 → 피킹·출고·배송 → 보수 확인
               └─ 운영 결과를 보고 인접 외곽 지역 확장 판단
```

중랑구는 사용자가 먼저 언급한 시범 후보 지역이다. 특정 주소·공간 수·업체·상품·운영 개시일을 이번 답변에서 확정하거나 실제 모집·계약을 시작하지 않는다. 플랫폼은 기존 업체와 공간 제공자의 업무를 지원하며 상품 매입·창고 신축·대형 차량 확보를 필수로 두지 않는 방향을 유지한다.

확장 판단에는 실제 주문·입고/출고 회전·배송 효율·주변 영향·관리 부담·합의 보수의 처리 결과를 함께 보는 안을 제안한다. 공간을 많이 등록한 수치만으로 확장 성공을 판단하지 않으며 구체 기준값은 아직 정하지 않는다.

## 후보 공간에서 함께 확인할 항목

| 항목 | 기획에서 확인할 내용 |
| --- | --- |
| 제공 의사와 사용 범위 | 권한 있는 제공자의 동의, 실제 사용할 보관 구역·기간·출입 담당 |
| 차량 진입·상하차 | 진입 가능한 차량, 합의된 적재·수령 위치, 주변 통행에 미치는 영향 |
| 주거 환경과 운영 일정 | 주변 주거 환경, 소음이 생기는 작업·빈도, 입출고 가능한 합의 시간 |
| 실제 수용 조건 | 상품 요구 조건·공간 용량·기보관 물품·미수령 예약과의 충돌 |
| 실제 비용과 관리 부담 | 보관·작업·시설 준비 비용, 수령·피킹 담당자의 대응 가능 범위 |

위 항목은 후보 비교 기준의 제안이다. 지역 이름·집값·빈집 통계만으로 적합 판정이나 공간 사용 동의를 대신하지 않는다. 고정 소음 기준·운영 시간 제한·차량 규격이나 별도 허가 절차를 이번 기획에서 임의로 확정하지 않는다. 건물별 현재 상태와 실제 운영 조건을 확인해야 하며 현장 조사 완료를 주장하지 않는다.

작게 정한 물량과 합의 시간으로 입고·작업을 시험하고, 소음·통행 문제나 관리 부담이 확인되면 당사자와 신규 입고량·시간을 조정하는 예외안을 제안한다. 신규 입고 조정과 이미 보관 중인 물품·진행 배송의 안전한 마무리는 구분하며 계약·재고·기존 보수 기록은 보존한다. 자동 운영 중단이나 현장 조치 권한을 새로 구현한 것은 아니다.

## 공동기금과 기존 미정의 보존

r91의 서울 전체 기금 트리는 장기 구조로 보존한다. 초기 참여 공간의 실제 기여·잔여금·출연 동의가 확인된 범위에서만 기금 설계를 구체화하며 미참여 지역의 수익·출연·분배 실적을 만들어 넣지 않는다. 권역별 통계와 실제 보유 자금·이전·지급은 구분한다.

`regional-fund-contribution-and-balance-shares`는 이번 입지 우선순위 발언으로 답변된 것이 아니므로 미정으로 보존한다. 비용 부담·도착 시간 변동의 기존 질문도 유지한다. 초기 지역을 좁힌다고 기본 보수·공동 성과금의 기존 구분이나 실제 재원 확보 조건을 바꾸지 않는다.
