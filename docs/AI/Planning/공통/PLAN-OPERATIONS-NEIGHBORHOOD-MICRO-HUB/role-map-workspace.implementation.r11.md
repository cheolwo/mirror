# 역할 선택 홈·역할별 지도 통합 r11

2026-10-05. 사용자 승인: 전체 8역할 선택과 같은 통합 앱 안에서 역할 전환. `Implemented / ValidatedLocal / PublicDeploymentPending`. [책임 카드](../../../../ProjectOverview/page-docs/role-map-workspace-r11.md)가 기본·상세 정보와 입력·인증 분리를 소유한다.

통합 Android/Web의 메인 홈은 역할 선택으로 진입하고 각 역할은 지도·현재 업무 카드·필요시 목록으로 진행한다. 생활 지도 r10을 재사용하고 주문자·음식점·음식 기사·화주·화물 기사·창고·운영자의 기존 API/DTO와 상태별 행동을 role adapter로 연결한다. 계정별 역할 선택은 서버 권한을 부여하지 않으며 음식·화물과 관리자 인증을 분리한다. 기존 전문 앱과 direct routes를 유지한다.

조회·상태 명령은 기존 서버 계약을 사용한다. 입력·로그인은 독립 화면에서 수행하고 선택 대상과 지도 문맥으로 복귀한다. 네이티브 음식 기사 단계 판정은 공용 표현에서 재사용한다. 좌표가 없으면 목록으로 제공하고 직선 후보선은 실제 도로 경로로 설명하지 않는다. Google 표시 host와 기존 음식 경로 데이터를 연결하며 Android 키 미설정은 목록으로 복구한다.

공통 셸/메모리 상태, 역할별 조회·명령 adapter, 플랫폼 지도·위치·인증 저장을 분리한다. 역할/계정 변경·중단에는 이전 비공개 데이터와 callbacks를 제거하고 현재 원장을 재조회한다. 입력 수명·멱등 요청 ID·사진 증빙·확인 조건은 기존 업무 요구를 유지한다.

순서: 홈/공통 계약 → 생활·음식 역할 → 화물·창고·운영자 → 집중 시험/Task → 실제 공용 UI와 모바일 화면 → 내장 APK 검증. 실제 휴대폰·Azure·외부 입금·Android 지도 타일·Figma 증거는 별도로 보고한다. 관련 없는 dirty 변경·배달 영상·MYBOX를 보존하고 이번 요청에 commit/push/외부 배포는 포함하지 않는다.

최종 Task `20261005-173938` 전체 빌드와 7,402/7,402 시험을 통과했다. 실제 통합 WASM은 미로그인 역할 진입·로그인 취소 복귀·입력 경로와 새로고침을, 예시 공통 화면은 카드·확인·로그아웃·모바일 배치를 검증했다. 실제 서버 업무 완료/휴대폰/지도 타일과 구별하며 [변경 기록](../../../../Changes/2026-10-05-role-map-workspace-r11.md)에 화면과 APK 근거를 연결한다.
