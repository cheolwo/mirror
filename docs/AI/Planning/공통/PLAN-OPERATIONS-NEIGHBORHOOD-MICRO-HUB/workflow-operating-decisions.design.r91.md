## 공식 조사: 서울의 5개 권역과 25개 자치구

조회 기준은 2026-10-15다. 서울시 균형발전포털은 도심·동북·서북·서남·동남의 5개 권역생활권을 설명한다. 현재 서울주거포털의 2026년 보도자료에서도 같은 5권역의 자치구 구성을 확인했다. 도시계획·통계의 지역 구분을 프로젝트 기금의 지리적 기준으로 이용하는 제안이며, 이를 공통 기금 운영 제도로 읽지 않는다.

| 공식 권역 구분 | 포함 자치구 | 자치구 수 |
| --- | --- | --- |
| 도심권 | 종로구, 중구, 용산구 | 3 |
| 동북권 | 성동구, 광진구, 동대문구, 중랑구, 성북구, 강북구, 도봉구, 노원구 | 8 |
| 서북권 | 은평구, 서대문구, 마포구 | 3 |
| 서남권 | 양천구, 강서구, 구로구, 금천구, 영등포구, 동작구, 관악구 | 7 |
| 동남권 | 서초구, 강남구, 송파구, 강동구 | 4 |

출처: [서울시 균형발전포털의 생활권 구분](https://uri.seoul.go.kr/web/contents/50.do?mid=1079), [서울주거포털의 2026년 보도자료 내 생활권별 자치구 구분](https://housing.seoul.go.kr/site/main/tvReportedInfo/list?cp=3). 표의 단위는 자치구 수이며 합계 25개다. 보도자료 목록 위치는 게시물 추가 시 바뀔 수 있어 관측한 구성과 조회일을 이 판본에 보존한다.

서울시의 현재 신속통합기획 아카이브에서도 [도심권](https://news.seoul.go.kr/citybuild/plan-downtown), [동북권](https://news.seoul.go.kr/citybuild/plan-northeast), [서북권](https://news.seoul.go.kr/citybuild/plan-northwest), [서남권](https://news.seoul.go.kr/citybuild/plan-southwest), [동남권](https://news.seoul.go.kr/citybuild/plan-southeast) 구분을 확인했다. 별도 경계 도형·주소 좌표를 내려받거나 실제 참여 공간을 조사한 것은 아니다. 소속·경계 변경은 향후 공식 자료와 다시 대조할 대상이다.

## 프로젝트 공동기금 트리 제안

5권역 위에 두는 강북·강남 묶음은 **기금 운영을 위해 명시적으로 제안하는 상위 분류**다. 모든 기관·사업의 강북/강남 구분과 동일하다고 주장하지 않는다. 이 제안에서는 강북에 도심·동북·서북을, 강남에 서남·동남을 넣어 25개 구가 한 번씩만 속하게 한다. 여기서 강북권은 강북구 하나, 강남권은 강남구나 강남 3구만을 뜻하지 않는다.

```text
서울 전체 공동기금
├─ 강북 묶음 공동기금 [프로젝트 제안: 14개 구]
│  ├─ 도심권: 종로·중·용산
│  ├─ 동북권: 성동·광진·동대문·중랑·성북·강북·도봉·노원
│  └─ 서북권: 은평·서대문·마포
└─ 강남 묶음 공동기금 [프로젝트 제안: 11개 구]
   ├─ 서남권: 양천·강서·구로·금천·영등포·동작·관악
   └─ 동남권: 서초·강남·송파·강동

각 권역 아래: 자치구 공동기금 → 참여 공간·업무 기여
예: 서울 → 강북 묶음 → 동북권 → 중랑구 → 참여 공간
```

지도에서 공간을 선택하는 구조와 지역 공동기금에 참여하는 조건은 별개로 관리한다. 같은 권역에 있다는 사실만으로 기금에 가입시키거나 계약·출연·수령 권한을 확정하지 않는다. 세부 행정동 단계는 필요할 때 기존 행정동 자료에 연결하는 후속 후보로 두며 이번 트리에 임의로 모두 추가하지 않는다.

## 모으는 돈과 나누는 돈의 설계 제안

1. 기본 작업비·상품대금·공급자에게 지급할 의무·환불/분쟁 보류금을 먼저 구분한다. 지역 기금의 재원은 새 약정에서 사전에 참여·출연에 동의한 범위의 **확정 잔여금 중 별도 약정 몫**을 대상으로 제안한다. 예상 매출을 확보 재원으로 승격하지 않는다.
2. 공간·주문·수행 근거와 원 출연금을 연결하고 자치구·권역·강북/강남·서울 단계의 보유분과 상위 이전분을 구분한다. 어떤 단계를 실제로 운영할지와 비율은 미정이다. 모든 단계에서 별도 수수료를 새로 떼는 것으로 확정하지 않는다.
3. 상향 이전은 하위 기금 잔액 감소와 상위 기금 잔액 증가를 동일 근거로 연결한다. 이전을 새 매출·새 잔여금으로 기록하거나 각 계층의 누적 집계액을 합쳐 현금이 늘어난 것처럼 계산하지 않는다. 출연금별 실제 이동 경로는 하나로 유지하고 다른 지역 통계 축은 별도 조회로 둔다.
4. 하향 분배·지원은 해당 기금의 실제 배분 가능 잔액·정책 판본·담당·대상·근거를 남기는 안이다. 한 번 지급한 금액을 다른 계층에서 또 지급하지 않으며 계획·계산·지급 지시·실제 입금은 구분한다.

r59/r61의 주문별 공동 성과금과 플랫폼 몫을 이미 나눈 과거 금액을 새 지역 기금에 다시 가져오지 않는다. 기존 기간 성과환원에서도 이중 분배를 막는 경계를 유지한다. 지역 출연을 선택하는 새 약정은 기존 참여자 성과금·플랫폼 몫과의 관계를 명시하고 영향을 받는 당사자의 동의를 받아야 한다. 실제 비율과 계정·외부 수납/지급 구조는 별도 기획 대상이다.

## 균형 분배의 두 가지 목적

| 구분 후보 | 목적 | 아직 정하지 않은 기준 |
| --- | --- | --- |
| 업무 기여에 따른 분배 | 실제 공간 제공·보관·입출고·배송 등의 확인된 기여에 보답 | 기여 종류·측정 단위·가중치·기간·필수 근거 |
| 지역 균형 지원 | 주문·작업 기회가 적은 참여 지역이 계속 협업할 수 있도록 지원 | 지원 대상·기회 부족 지표·상한·재검토·지원 방식 |

위 두 몫의 분리는 제안이다. 강북·강남이라는 이름만으로 가난함·우수함·지원 자격을 추정하거나 모든 지역에 무조건 같은 금액을 지급하지 않는다. 실제 플랫폼 안에서 확인할 수 있는 참여·업무 기회·수요·비용 근거를 논의한 뒤 판단한다. 지도 추천의 숨은 순위 조정이나 공간 강제 배정으로 수익 차이를 자동 보정하는 정책도 아직 승인하지 않았다.

## 변경·검증 범위

공식 공개 자료 조사와 기획 문서·목차·현재 작업만 갱신한다. 25개 자치구의 중복·누락, 상위 묶음의 합계, 문서 링크·경로와 diff 공백 오류를 확인한다. 제품 코드·DB·지도/UI·기금 계좌/실제 출연·분배/송금·외부 알림·commit/push는 변경하지 않는다. 지역 균형 개선 효과나 실제 자금 확보·운영을 검증한 것은 아니다.
