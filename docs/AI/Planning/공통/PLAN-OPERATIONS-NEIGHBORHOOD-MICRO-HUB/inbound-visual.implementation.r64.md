# 입고 협의 시각 정돈 r64

- 상태: `Implemented / LocalValidated / OperationalDeferred`.
- 승인: 현재 사용자의 디자인 개선 요청 및 후속 ‘색이 들어간 이모지는 피함’ 정정을 직접 수용한다. r63의 서버·원장·권한·판본·복구·기본 OFF는 유지한다.
- 범위: 기존 공간·입고·보관 합의 공통 역할 화면. 전역 테마·Community·Figma·네이티브 기사·Unity는 범위 밖이다.

## 수용한 표현

기존 Material Outlined 아이콘을 단색 currentColor로 재사용한다. 색이 들어간 이모지·새 이미지·외부 패키지를 사용하지 않는다. 작은 아이콘과 짧은 섹션 제목, 본문과 보조 라벨의 굵기·간격으로 정보 위계를 만든다. 공통 역할 토큰에 fallback을 두고 기존 distributed-work 아래 inbound-visual 클래스 안으로 CSS를 한정한다.

입고 상세는 현재 상태 배지·예정/실제 수량·다음 담당·대기 이유를 먼저 둔다. 물품 특성, 일정/보관, 공급/책임을 구분선으로 묶고 짧은 항목은 반응형 2열로 정렬한다. 양측 동의는 서로 구분된 상태로 표시한다. 긴 값은 잘라 숨기지 않으며 개인정보에 따라 없는 공급 조건의 빈 섹션도 만들지 않는다. 기존 보조 details와 주 행동/확인 체크, 활성/비활성 조건은 보존한다.

공간 수용 조건은 허용·거부·보관 방식과 용량·출입을 구분하고 보관 변경안은 현재 조건과 분리한다. 독립 업무/route·필드·새 접기 기능을 만들지 않고 기존 입력을 재배치한다. 모든 request 바인딩·handler·Model.Allows·revision 초기화·멱등 요청은 변경하지 않는다.

## 검증

기존 실제 Razor 입력·동의/권한/부분 수령 회귀 시험을 재사용한다. 공통 UI와 소비 앱을 포함한 Fast/Task 검증을 수행한다. 실제 HtmlRenderer 출력과 소스 CSS를 로컬 Edge 320/390/768px에서 확인하고 단색 아이콘·가로 넘침·긴 값·터치 영역·키보드 포커스를 점검한다. 대표 PNG 3장은 새 이름으로 보존하며 r63 PNG는 덮어쓰지 않는다. 정적 Razor 렌더는 실제 로그인 HTTP/물리 휴대폰/카메라 검증이 아니다.
