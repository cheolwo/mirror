# 비공개 APK 배포 준비와 화주 인수증 연결

상태: Implemented / LocalValidated / CloudPublicationDeferred. 기준일: 2026-10-15. 외부 배포는 보안 업데이트·시험 서버·참가자 접근·실기기 확인 후 진행한다.

사용자는 전용 Android폰과 소수 참가자의 비공개 APK 사용을 준비하고, 현재 만들어진 기능을 인지할 수 있게 정리하며 우선 부족한 부분을 보완하도록 요청했다. 기존 국내 화물 흐름과 서명 APK 제작 도구를 활용한다.

## 수용한 범위

1. 화주 증빙 화면에서 실제 연결 운송의 인수증 번호를 입력하고 기존 보호 API에 등록한다. 완료 전 등록, 다른 계정·의뢰 응답, 중복 클릭과 늦은 응답을 보호한다. 응답이 불확실하면 같은 의뢰를 재조회하며 자동 재전송하지 않는다. 인수증 등록을 입금·정산·지급 완료로 표현하지 않는다.
2. 기존 Release manifest와 APK 바이트·서명·패키지·버전을 재검사하는 GCS 비공개 배포 준비 도구를 만든다. 기본 동작은 로컬 준비이며 실제 업로드·공개 권한·다운로드 링크 발급은 실행하지 않는다. 버전·해시별 변경 불가 경로와 이후 비공개 저장소 확인·업로드·원격 바이트 대조·만료 링크 발급 절차를 준비한다. 시험 주소와 내부 fixture를 실제 배포 준비 통과로 판정하지 않는다.
3. 역할별 구현 기능, 코드·로컬 검증, 물리 기기·외부 서버 확인을 구분한 현황과 소수 화물 시험의 다음 순서를 정리한다. 기존 기본 기능 플래그와 실행 설정을 바꾸지 않는다. 공통 설정의 Operational 기본값을 시험 환경의 Simulation 증거로 사용하지 않는다.
4. 일반·화주와 화물기사 앱의 독립 실행 가능한 로컬 시험 APK를 기존 Debug 서명으로 준비한다. 최신 소스·패키지·버전·서명·ABI·파일 해시를 확인하고 PC loopback 시험 서버 연결용으로 기록한다. 이는 GCS 배포용 Release·휴대폰 설치·서버 통신 완료가 아니며 새 키를 생성하지 않는다.

## 완료 기준

- 인수증 입력·등록·동일 의뢰 재조회와 오류·충돌·페이지/계정 수명 반례를 의미 있는 시험으로 확인한다.
- GCS 준비 도구는 경로 이탈, APK/manifest 변조, 다른 서명·패키지·버전, 시험 endpoint, 잘못된 버킷·중복 출력과 미확인 상태를 거부한다. 오프라인 시험과 실제 저장소 접근을 구분한다.
- 공통 UI의 소비 앱 빌드, 좁은 Fast와 Task를 직렬 실행한다. 가능하면 실제 호스트 렌더를 확인하며 휴대폰이 없으면 네이티브 촬영·지도·알림·업데이트를 미검증으로 남긴다.
- 기존 dirty 파일 278개의 바이트 기준선은 Git 제외 `artifacts/local/private-apk-preparation-r70/baseline.json`에 있다. 허용 경로 외 변경을 보존한다.

실제 서버 배포, GCS 업로드/링크 발급, 새 서명키 생성, 계정 초대/권한 변경, 실제 운송·송금, Unity, commit/push는 이번 준비에 포함하지 않는다. [작업 명세](private-apk-preparation.r70.work-order.json)가 담당별 쓰기 경로를 소유한다.
