## 좁은 변경 범위

1. 기존 분산이행PageViewModel의 주문 후보·선택/연결·추가/취소/수령은 Orders partial로, 사진 촬영/검증/업로드/완료는 Photos partial로 원문 그대로 이동한다. 계정·수명·조회·명령·영수증과 Recovery partial은 기존 흐름을 유지한다. 새 서비스·interface·DI·저장 형식·공개 API를 만들지 않는다.
2. 반복된 품목·포장·온도·식품·입고 협의 상태·이력·대기 이유 표시를 기존 분산이행표시 파일로 모은다. 문맥별 미확인 문구, 일반 상태와 입고 협의 상태의 차이, 기존 InboundReason의 null 반환 계약을 보존한다.
3. 기존 페이지 책임 문서에서 실행·표시·복구의 소유 위치와 남은 보완을 짧게 연결한다. 새 화면·탭·접기·필드는 만들지 않는다.

## 검증과 범위 밖

이동 전후 C# 멤버 본문/서명/초기값이 같음을 정적으로 대조한다. 기존 VM·사진·복구·입고 렌더/interaction 시험을 Fast로, 전체 소비 앱과 Task를 최종 검증한다. 기존 실제 Razor 캡처를 전후 보존하고 같은 화면의 HTML/표시 문구 및 CSS 파일 해시를 대조한다. 업무가 달라지는 코드를 이번 이동에 섞지 않는다.

서버 입고 상태 순서 의존, 보관 변경안 입력 보존, 조회/실행 용량 검사 일치, 새 작성 진입, DB 조회 최적화는 후속 보완으로 남긴다. 기능 확장·운영 활성화·실제 DB 변경·물리 단말·Azure·Unity·commit/push는 포함하지 않는다.
