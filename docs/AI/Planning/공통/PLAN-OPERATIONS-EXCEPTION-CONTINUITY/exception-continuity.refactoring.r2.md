2. 음식 역할별 입력 검증·고정 요청 본문 구성을 내부 준비 책임으로 분리한다. 기존 ViewModel 공개 메서드·속성은 유지하고 계정·세대·취소 수명, 전송·정본 재조회·명시적 동일 요청 재시도는 ViewModel이 조율한다. 역할별 입력을 작은 Razor 구성요소로 나누되 표시 문구·DOM 구조·순서·CSS·버튼 조건을 보존한다.

## 페이지 책임·호환

음식 행동 페이지는 선택 업무 한 건의 확인·실행·결과 확인을 소유한다. 지원 사건 페이지는 사건 판단과 연결 배송 인계를 구분하며 사건 종결만으로 배송·수령·정산·지급을 완료하지 않는다. 독립 route·PageKey·API·contract·DB·저장 형식·72시간 만료 정책은 변경하지 않는다. 현재 음식/운영자 pending의 화면·계정 수명을 재시작 영속 복구로 확대하지 않는다. 물류 접수·사진·보호 저장 경계 및 역할별 전문 원장의 완료 의미를 유지한다.
