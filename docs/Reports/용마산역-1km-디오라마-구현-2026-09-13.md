## 결과

- 사본 schema: `ssalddel.station-spatial-snapshot.v1`
- revision: `yongmasan-station-spatial-snapshot.private-review.r1`
- 상태: `LocalPrivateReview / PassedWithMissingCoverage`

## 공간 범위와 자료 계보

표현 창의 OSM 요청 bbox는 `127.0811416,37.5692469,127.0924624,37.5782568`이다. 2026-09-13 04:21:31 UTC에 해당 범위만 한 번 수집해 원본과 영수증을 동결했고, 이후 생성·감사는 네트워크 요청 없이 이 원본을 재사용했다.

건물 원천의 이용조건 충돌과 법정동 경계 결손은 그대로 유지한다. OSM bbox 응답도 범위 밖 member를 생략할 수 있으므로, 완전한 지리·통행 권위로 해석하지 않는다.

## 로컬 영속화

기존 `eng/Ssalddel.PublicDataPortalImport`의 `yongmasan-station-spatial-*` 명령으로 로컬 Docker MySQL `hongdal-mysql-1 / hongdal_dev` 비공개 검토 원장에 네 건을 저장했다.

- ID 58: OSM XML 원본
- ID 59: OSM 수집 영수증
- ID 60: 용마산역 공간 사본
- ID 61: coverage 감사 결과
- 같은 입력 재적용: 신규 0건, 기존 ID 58~61 유지
- 별도 프로세스 `verify`: 같은 네 건과 hash·수량·결손 재조회
- 공유 운영 DB·원격 DB·기존 Mongo 행정동 current projection: 미변경

## 서버 조회 경계

역세권 manifest 후보에는 용마산역 사본의 revision·hash·파일 크기·수량·결손을 결속했다. 다만 기존 행정동 current projection을 역 중심 좌표계 자료로 덮어쓰지 않기 위해 다음 경계를 유지한다.

- `Availability=WaitingForSpatialCoverage`
- `RegionStableId` 없음, `AreaProjections` 0개
- `ServerLoadable=false`
- `DistributionApproved=false`
- `TraversalReady=false`
- `GameplayReady=false`

따라서 이번 변경은 station-scoped 서버 payload 제공이나 공개 API 적재 완료가 아니다. 독립된 역 범위 저장·조회 계약이 생기기 전에는 metadata와 비적재 후보 fingerprint만 제공한다.

## Unity 표현

별도 Unity 저장소의 공통 역세권 descriptor에 용마산역을 등록하고, 정확한 `openstreetmap:yongmasan-station-0723-r1` 영수증을 요구하도록 읽기 경계를 강화했다. 용마산 경로가 없을 때 면목역·사가정역 자료로 fallback하지 않으며, 다른 역 OSM 영수증을 섞은 사본도 거부한다.

Unity `6000.5.6f1`의 canonical `SimulationWorldShell`에서 저장하지 않는 임시 host로 실제 Play Mode를 실행했다.

- 조립 상태: `LocalPrivateReview / PartialCoverage / Ready`
- 실제 해석: source receipt 5, 건물 2,859, 도로 116, 표면 41, 행정동 4, coverage cell 100
- 결손: 항목 6개, `MissingCoverage` cell 10개
- Mesh: 4×4 chunk 16개, renderer 16개, vertex 88,589개, triangle 47,213개
- Collider: 0개
- 공통 View가 `SinglePlayerRuntimeEnvironmentRegistered`를 자동 등록한 뒤 여러 frame이 지나도 renderer 16개를 유지
- 용마산역·`StationDiorama` 관련 Console Error/Warning: 0개

Game View에는 용마산역 1km의 건물 높이 차, 도로·표면, coverage 결손과 비공개 검토 상태가 함께 표시됐다.

- 캡처: `artifacts/local/validation/yongmasan-station-gameview-r1/yongmasan-station-playmode-gameview-final.png`
- 캡처 SHA-256: `920DE479DD8FA27FD0F621FB209B0E7E6607065FFDF0E6E91F777394C9B7C63A`
- 실행 전후 canonical Scene SHA-256: `36D81A6986598F08D1EA1EA94E83F7FC7BD2D67B166FE6ABA4ED2A1395A34C55`로 동일
- Scene 저장: 없음, 종료 후 `isDirty=false`

canonical Scene에는 서버 미연결·기존 replay·missing script와 관련된 기존 Error/Warning 20건이 남아 있다. 이들을 용마산 성공으로 숨기지 않았고, 이름에 `Yongmasan`, `용마산`, `StationDiorama`, `역세권공간표현`이 들어간 오류는 0건이었다.
