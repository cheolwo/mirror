# 중랑구 7호선 역 기준자료 수집

2026-09-13 사용자 요청에 따라 사가정역 참조 구현을 면목역·용마산역으로 확장할 때 필요한 도시철도역 기준자료를 먼저 수집했다. 이번 범위는 역 식별·공식명·노선·운영기관·출처 보고 WGS84 기준점의 비공개 검토 원장까지다. 역 중심 1km × 1km의 건물·도로 coverage, Unity 배치, 공개 배포 또는 운영 권위는 만들지 않았다.

## 실제 수집과 저장

공식 원천은 [공공데이터포털 국가철도공단 도시광역철도 역사정보](https://www.data.go.kr/data/15093755/fileData.do)와 포털이 연결한 [철도 데이터 포털 역사정보](https://data.kric.go.kr/rips/M_01_01/detail.do?id=32)의 XLSX다. 원본 파일 SHA-256은 `cdf1d84a7e5c898b2aacd622783ba8ba9af35c40bee0561dc97d55ce8e063f94`이고, 15개 필드·전국 1,099행을 확인한 뒤 다음 3행만 선택했다.

| 안정 식별자 | 원천 역명 | 노선·역번호 | WGS84 위도·경도 | 운영기관 | 원천 기준일 |
| --- | --- | --- | --- | --- | --- |
| `station:kr:kric:s1107:0721` | 면목 | `S1107`·`0721` | 37.588671, 127.087503 | 서울교통공사 | 2024-12-31 |
| `station:kr:kric:s1107:0722` | 사가정 | `S1107`·`0722` | 37.580912, 127.088502 | 서울교통공사 | 2024-12-31 |
| `station:kr:kric:s1107:0723` | 용마산(용마폭포공원) | `S1107`·`0723` | 37.573752, 127.086802 | 서울교통공사 | 2024-12-31 |

역번호는 전국에서 단독으로 유일하지 않으므로 노선번호와 결합했다. 선행 0은 버리지 않는다. `RegionStableId`에는 새 지역 종류를 억지로 추가하지 않고 `point:kr:rail:{lineNumber}:{stationNumber}`를 쓰며, 도시철도역의 주 식별자는 정규화 행 `StableId`가 소유한다. 역사 전화번호는 원본에만 남고 정규화 투영에는 넣지 않았다.

기존 로컬 Docker MySQL `hongdal-mysql-1 / hongdal_dev`와 공공자료 수집 원장을 재사용했다. 첫 적용은 원본 사본 1건과 정규화 3건을 삽입했고, 같은 입력 재적용은 신규 0·기존 3이었다. 별도 연결의 독립 재조회에서도 3건과 원본 hash를 확인했다. 정규화 품질은 `OfficialSourcePendingHumanReview`이고 `PrivateReviewOnly`, `NoPublicDistribution`, `NoOperationalAuthority`, `NoAreaCoverageInference`를 유지한다.

## 자료가 사용되는 경계

```text
공식 역사정보 XLSX
└─ 원본 사본·hash·수집 시각
   └─ 역 기준자료 3행 · 비공개 검토 원장
      └─ 서버 역 승인 대장 후보
         ├─ GET api/v1/world/stations
         └─ GET api/v1/world/stations/{transitStationStableId}/diorama-manifest
            └─ 기존 행정동 500m 공간 tile을 선택 참조
               └─ Unity의 휘발성 읽기 전용 역세권 모듈
```

역 기준점은 역세권 면적이나 출구 위치를 뜻하지 않는다. 일반역의 1km × 1km는 별도의 표현 정책이며, 공간 manifest가 준비되지 않은 역은 `WaitingForSpatialCoverage`로 남긴다. 사가정 자료를 면목·용마산에 복제하거나 결손을 합성 공터로 채우지 않는다.

서버 첫 조회 절편은 원본·행 hash, 수집시각, 이용조건 관측과 검토 제한을 manifest에 보존한다. 기존 지역과 행정동 사본은 schema·정확 식별자·읽기 전용 `GET` endpoint·관찰 표현 전용 권위·tile 중복 및 수량을 검증한 뒤에만 참조한다. 사가정은 현재 검사를 통과한 기존 교차 tile만 `PartialCoverage`이며, 면목·용마산은 metadata-only다. 사용자가 “역마산역”은 용마산역을 뜻한다고 확인했으므로, 공식 원천명은 유지하고 API 표시명만 `용마산역`, 확인 상태는 `UserConfirmedDisplayName`으로 분리한다.

## 이용조건과 검토 한계

공공데이터포털 dataset metadata에는 `이용허락범위 제한 없음`과 2024-12-31 파일이 표시되지만, 철도 데이터 포털의 현재 연결 파일은 `전체_도시철도역사정보_20260630`이다. 두 페이지의 판본 표기가 서로 달라 정확한 현재 파일의 권리 결속은 사람 검토 대상으로 유지했다. 다운로드 성공과 dataset 수준의 표시만으로 재배포 승인이나 Unity 자산 게시를 선언하지 않는다.

원천 행의 데이터 기준일은 2024-12-31이다. 현재 역사 현황, 출구 중심점, 현장 실측 좌표 또는 역 반경 건물·도로의 완전성을 증명하지 않는다. 사용자 확인은 “역마산역”이라는 표현이 용마산역을 가리킨다는 뜻만 확정하며, 공식 원천명·현장 정확도·공간 coverage·권리 검토 상태를 승격하지 않는다.
